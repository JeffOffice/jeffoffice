# Pestaña Presentación con diapositivas
<!-- keywords: pestaña presentación con diapositivas, cinta de opciones, desde el principio, desde la diapositiva actual, presentación personalizada, presentaciones personalizadas, ocultar diapositiva, configurar, configurar presentación con diapositivas, ensayar intervalos, usar intervalos, monitores, usar vista moderador, vista moderador, ensayar, reproducir, presentar, f5 -->

La pestaña **Presentación con diapositivas** inicia la presentación y la configura.

- **Iniciar presentación con diapositivas** contiene **Desde el principio** (F5) y **Desde la diapositiva actual** (Mayús+F5). **Presentación personalizada** muestra sus presentaciones personalizadas por su nombre para que pueda reproducir una. Su comando **Presentaciones personalizadas** permite crearlas, modificarlas, copiarlas y eliminarlas.
- **Configurar** contiene **Configurar presentación con diapositivas**, que permite elegir el tipo de presentación, qué diapositivas se reproducen, si se repite en bucle y cómo avanza. **Ocultar diapositiva** excluye de la presentación la diapositiva en la que se encuentra. **Ensayar intervalos** reproduce la presentación y registra cuánto tiempo dedica a cada diapositiva. La casilla **Usar intervalos** hace que la presentación avance sola cuando termina el tiempo de cada diapositiva.
- **Monitores** contiene la casilla **Usar Vista Moderador**, para cuando tenga dos pantallas, y **Vista Moderador** (Alt+F5), que abre la presentación en una ventana pequeña con la Vista Moderador al lado, para que pueda ensayar en una sola pantalla.

Durante la presentación, presione Ctrl+P para usar el lápiz, Ctrl+I para el marcador de resaltado, Ctrl+L para el puntero láser y Ctrl+E para el borrador. Presione Ctrl+A o Esc para volver a la flecha.

Consulte [Reproducir la presentación con diapositivas y usar la Vista Moderador](show).
