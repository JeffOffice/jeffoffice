# Pestaña Presentación con diapositivas
<!-- keywords: pestaña presentación con diapositivas, cinta de opciones, desde el principio, desde la diapositiva actual, presentación personalizada, presentaciones personalizadas, ocultar diapositiva, configurar, configurar presentación con diapositivas, ensayar intervalos, usar intervalos, monitores, usar vista moderador, vista moderador, mostrar presentación en, pantalla, ensayar, reproducir, presentar, F5 -->

La pestaña **Presentación con diapositivas** inicia la presentación y la configura.

- **Iniciar presentación con diapositivas** tiene **Desde el principio** (F5) y **Desde la diapositiva actual** (Mayús+F5). **Presentación personalizada** muestra sus presentaciones personalizadas por nombre, para que pueda reproducir una. Su comando **Presentaciones personalizadas** permite crearlas, cambiarlas, copiarlas y eliminarlas.
- **Configurar** tiene **Configurar presentación con diapositivas**, que elige el tipo de presentación, qué diapositivas se reproducen, si se repite en bucle y cómo avanza. **Ocultar diapositiva** excluye de la presentación la diapositiva en la que se encuentra. **Ensayar intervalos** reproduce la presentación y registra cuánto tiempo dedica a cada diapositiva. La casilla **Usar intervalos** hace que la presentación avance sola al cabo del tiempo de cada diapositiva.
- **Monitores** tiene la casilla **Usar Vista moderador**, para cuando tiene dos pantallas; la lista **Mostrar presentación en**, que elige la pantalla que muestra las diapositivas (Automático, o una pantalla por su nombre y tamaño); y **Vista moderador** (Alt+F5), que abre la presentación en una ventana pequeña con la Vista moderador junto a ella, para que pueda ensayar en una sola pantalla.

Mientras se reproduce la presentación, pulse Ctrl+P para el lápiz, Ctrl+I para el marcador de resaltado, Ctrl+L para el puntero láser y Ctrl+E para el borrador. Pulse Ctrl+A o Esc para volver a la flecha.

Consulte [Reproducir la presentación con diapositivas y usar la Vista moderador](show).
