# Animaciones
<!-- keywords: animación, animaciones, entrada, salida, énfasis, trayectoria de movimiento, trayectoria, compilación, por párrafo, paso de clic, aparecer, desvanecer, barrido, reproducir, efectos, todavía no, modificar animaciones, editar animaciones -->

Una **animación** mueve o cambia un objeto de una diapositiva mientras se reproduce la presentación con diapositivas: una viñeta que aparece de forma gradual, una imagen que entra volando desde un lado o una forma que se desplaza por una trayectoria.

## Las animaciones se reproducen en la presentación con diapositivas

JeffDeck reproduce las animaciones que contiene un archivo de presentación. Cada clic en la presentación con diapositivas reproduce el siguiente **paso**. Por ejemplo, primero puede aparecer un título y, después, cada viñeta puede aparecer con su propio clic. Algunos pasos empiezan por sí solos cuando aparece la diapositiva o justo después del paso anterior.

Se reproducen estos tipos de movimiento:

- Aparecer y desaparecer.
- Desvanecer y barrido.
- Desplazamiento, giro y cambio de tamaño.
- Trayectorias de movimiento.
- Compilaciones por párrafo, que muestran una lista párrafo a párrafo.

Cualquier otro efecto se reproduce como un desvanecimiento.

En la presentación con diapositivas, un clic mientras se reproduce un paso finaliza ese paso y no hace nada más. Presione Flecha izquierda, Retroceso o P para retroceder un paso. Consulte [Reproducir la presentación con diapositivas y usar la Vista Moderador](show).

## Todavía no se pueden modificar las animaciones

En esta versión preliminar, JeffDeck no tiene ninguna pestaña ni panel para agregar, cambiar o quitar animaciones. No se pueden crear animaciones nuevas. Pero no se pierde nada: las animaciones de una diapositiva se conservan con ella y JeffDeck las vuelve a escribir al guardar. Al duplicar una diapositiva, o al reutilizar una de otra presentación, sus animaciones la acompañan.
