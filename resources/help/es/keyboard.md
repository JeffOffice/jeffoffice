# Usar JeffPub con el teclado
<!-- keywords: teclado, métodos abreviados, atajos de teclado, teclas de método abreviado, teclas de acceso rápido, keytips, sugerencias de teclas, tecla alt, f6, tecla tab, tabulador, teclas de dirección, flechas, sin ratón, navegar, desplazarse, teclas de acceso, foco, cinta de opciones con teclado -->

Puede llegar a los comandos de la cinta de opciones, a la lista Páginas y a los objetos de la página sin usar el ratón. Hay tres formas de hacerlo: métodos abreviados de teclado para los comandos habituales, KeyTips para la cinta de opciones y desplazarse con F6, Tab y las teclas de dirección.

## Moverse entre las partes de la ventana

Presione **F6** para mover el **foco** del teclado (el lugar al que va la siguiente tecla que presione) a la siguiente parte de la ventana. El orden es: la cinta de opciones, la lista Páginas, la página y de nuevo la cinta de opciones. Presione **Mayús+F6** para ir en sentido contrario. Si la lista Páginas está oculta, se omite. Cuando usa el teclado, un contorno de color indica qué control tiene el foco.

Presione **F1** para obtener Ayuda sobre lo que está haciendo. Presione **Ctrl+F1** para contraer o expandir la cinta de opciones.

## Usar KeyTips en la cinta de opciones

Los KeyTips son pequeñas letras que aparecen en la cinta de opciones. Permiten llegar a cualquier botón sin el ratón.

1. Presione y suelte **Alt**. Aparecen letras en el botón **Archivo**, en cada pestaña y en la Barra de herramientas de acceso rápido. Los botones de la Barra de herramientas de acceso rápido usan los números del 1 al 4.
2. Presione la letra de la pestaña que desee, como **H** para **Inicio**. Aparecen las letras de los botones de esa pestaña.
3. Escriba las letras del botón que desee. Por ejemplo, **T** y después **B** corresponde a **Dibujar cuadro de texto**.

También puede mantener presionada Alt y presionar la letra de una pestaña en un solo paso. Alt+H abre la pestaña **Inicio**. Alt+F abre la página **Archivo**. Alt+Y abre la pestaña **Ayuda**.

Presione **Esc** para retroceder un paso. Presione cualquier otra tecla para ocultar las letras. Las letras atenuadas pertenecen a un botón que no puede usar en ese momento, como uno que necesita un objeto seleccionado.

## Moverse por la cinta de opciones con las teclas de dirección

1. Presione F6 para situarse en la pestaña actual.
2. Presione **Izquierda** o **Derecha** para cambiar de pestaña.
3. Presione **Abajo** para entrar en los botones. Use las teclas de dirección para moverse entre ellos. **Tab** y **Mayús+Tab** también llevan al control siguiente o al anterior.
4. Presione **Entrar** o **Espacio** para usar un botón. Un botón con menú abre su menú.
5. Presione **Esc** para volver a la página.

## Trabajar en la página

Haga clic en el área de la página o presione F6 hasta llegar a ella. A continuación:

- **Tab** selecciona el objeto siguiente. **Mayús+Tab** selecciona el anterior.
- Las **teclas de dirección** desplazan el objeto seleccionado un paso pequeño. Mantenga presionada **Alt** para el paso más pequeño. Para establecer el tamaño del paso, vea [Cambiar la configuración de JeffPub](options).
- **Entrar** o **F2** permite modificar el texto del cuadro de texto, la forma o la tabla seleccionados. También puede empezar a escribir directamente.
- **Supr** elimina el objeto seleccionado. Si hay celdas de una tabla seleccionadas, borra su texto.
- **Esc** deja de modificar el texto. El cuadro de texto sigue seleccionado. Presione Esc de nuevo para anular la selección.

Mientras escribe en una tabla, **Tab** pasa a la celda siguiente. Tab en la última celda agrega una fila.
