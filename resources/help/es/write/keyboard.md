# Usar JeffWrite con el teclado
<!-- keywords: teclado, métodos abreviados, atajos de teclado, teclas, teclas de acceso rápido, KeyTips, ctrl, alt, navegar, desplazarse, mover, seleccionar, punto de inserción, cursor -->

Puede hacerlo todo en JeffWrite con el teclado. Esta página enumera las teclas.

## Desplazarse y seleccionar

- Las **teclas de dirección** mueven el punto de inserción. El **punto de inserción** es la línea intermitente que indica dónde se escribirá el texto.
- **Ctrl+Izquierda** y **Ctrl+Derecha** mueven una palabra.
- **Inicio** y **Fin** llevan al principio y al final de una línea. **Ctrl+Inicio** y **Ctrl+Fin** llevan al principio y al final del documento.
- **Re Pág** y **Av Pág** desplazan una ventana de texto.
- Mantenga presionada **Mayús** con cualquiera de estas teclas para seleccionar texto mientras se desplaza.
- **Ctrl+A** selecciona todo.

## Escribir y eliminar

- **Entrar** inicia un párrafo nuevo. **Mayús+Entrar** inicia una línea nueva en el mismo párrafo.
- **Ctrl+Entrar** inicia una página nueva.
- **Esc** cierra el encabezado o pie de página que está modificando y, si está modificando una nota al pie, vuelve al texto.
- **Tab** agrega una tabulación. En una lista, baja el elemento un nivel. **Mayús+Tab** lo sube un nivel.
- **Retroceso** y **Supr** eliminan texto. Mantenga presionada **Ctrl** para eliminar una palabra.

## Acceder a la cinta de opciones

Presione **Alt** para mostrar una letra en cada pestaña. Presione la letra para abrir la pestaña y, después, las letras que aparecen para llegar a un botón. Presione **Esc** para retroceder. **F6** mueve el teclado entre la cinta de opciones y la página.
