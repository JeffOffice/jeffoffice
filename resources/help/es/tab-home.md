# Pestaña Inicio

<!-- keywords: pestaña inicio, cinta de opciones, portapapeles, grupo fuente, grupo párrafo, galería de estilos, objetos, grupo edición, herramientas de formato, inicio, barra de herramientas, formato -->

La pestaña **Inicio** siempre está en la cinta de opciones. Contiene las herramientas que más usa al escribir y diseñar una página.

- **Portapapeles** tiene **Pegar**, **Cortar**, **Copiar** y **Copiar formato**, que copia el aspecto del texto en otro cuadro. Consulte [Dar formato al texto](formatting-text).
- **Fuente** cambia la fuente, el tamaño, el color y el estilo de las letras. Consulte [Dar formato al texto](formatting-text).
- **Párrafo** incluye viñetas, numeración, sangrías, alineación y espaciado para párrafos completos. Consulte [Viñetas, numeración y tabulaciones](lists-tabs).
- **Estilos** es una galería de aspectos con nombre que puede aplicar con un solo clic, además de una forma de crear los suyos. Consulte [Usar estilos](styles).
- **Objetos** dibuja un cuadro de texto, inserta una tabla, agrega imágenes y dibuja formas. Consulte [Agregar y dar formato a cuadros de texto](text-boxes).
- **Organizar** controla cómo los objetos ajustan el texto, se apilan, se agrupan, se alinean y se giran. Consulte [Mover, alinear, agrupar y superponer objetos](arrange).
- **Edición** tiene **Buscar**, **Reemplazar**, **Ir a** y **Seleccionar**, que permite elegir todo el texto de un cuadro, todos los objetos o todos los objetos de un tipo. **Ir a** (Ctrl+G) pide un número de página y mueve el cursor a esa página. Consulte [Buscar y reemplazar texto](find-replace).
