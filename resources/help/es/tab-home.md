# Pestaña Inicio
<!-- keywords: pestaña inicio, cinta de opciones, portapapeles, grupo fuente, grupo párrafo, galería de estilos, objetos, grupo edición, herramientas de formato -->

La pestaña **Inicio** siempre está en la cinta de opciones. Contiene las herramientas que más se usan al escribir y diseñar una página.

- **Portapapeles** contiene **Pegar**, **Cortar**, **Copiar** y **Copiar formato**, que copia el aspecto del texto en otro cuadro. Vea [Dar formato al texto](formatting-text).
- **Fuente** cambia la fuente, el tamaño, el color y el estilo de las letras. Vea [Dar formato al texto](formatting-text).
- **Párrafo** contiene viñetas, numeración, sangrías, alineación y espaciado para párrafos completos. Vea [Viñetas, numeración y tabulaciones](lists-tabs).
- **Estilos** es una galería de aspectos con nombre que puede aplicar con un clic, y también permite crear los suyos propios. Vea [Usar estilos](styles).
- **Objetos** dibuja un cuadro de texto, inserta una tabla, agrega imágenes y dibuja formas. Vea [Agregar cuadros de texto y darles formato](text-boxes).
- **Organizar** controla cómo los objetos ajustan el texto, se apilan, se agrupan, se alinean y giran. Vea [Mover, alinear, agrupar y superponer objetos](arrange).
- **Edición** contiene **Buscar**, **Reemplazar** y **Seleccionar**, que selecciona todo el texto de un cuadro, todos los objetos o todos los objetos de un tipo. Vea [Buscar y reemplazar texto](find-replace).
