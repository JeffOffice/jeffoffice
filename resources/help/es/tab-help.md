# Pestaña Ayuda
<!-- keywords: pestaña ayuda, ayuda, soporte, asistencia, contactar con soporte, comentarios, sugerencias, novedades, notas de la versión, métodos abreviados de teclado, atajos de teclado, F1, informar de un problema, sugerir una idea -->

La pestaña **Ayuda** siempre está en la cinta de opciones, después de la pestaña **Vista**. Úsela para obtener ayuda, informar de un problema o sugerir una idea.

- Grupo **Ayuda**: cuatro botones. Vea [Bienvenido a JeffPub](start) y [Obtener ayuda e informar de problemas](support).

| Botón | Qué hace | KeyTip |
|---|---|---|
| **Ayuda** | Abre el panel de Ayuda a la derecha. También puede presionar F1 o hacer clic en el botón **?** del extremo derecho de la fila de pestañas. | Alt, Y, H |
| **Comentarios** | Abre una página de GitHub donde puede informar de un problema o sugerir una idea. Necesita una cuenta gratuita de GitHub. | Alt, Y, K |
| **Métodos abreviados de teclado** | Abre el tema de Ayuda sobre el uso de JeffPub con el teclado, con una lista de las teclas de todos los comandos. | Alt, Y, S |
| **Novedades** | Abre en el navegador web las notas de su versión de JeffPub en GitHub. | Alt, Y, W |
