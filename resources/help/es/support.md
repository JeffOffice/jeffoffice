# Obtener ayuda e informar de problemas
<!-- keywords: soporte, asistencia, contactar con soporte, informar de un problema, error, fallo, comentarios, sugerencia, sugerir, solicitud de función, idea, github, versión, bloqueo, cierre inesperado, mensaje de error, ayuda, acerca de, actualizaciones -->

Si JeffPub hace algo extraño o tiene una idea para mejorarlo, comuníqueselo a las personas que lo desarrollan. Puede hacerlo en GitHub, un sitio web donde registran los problemas y las ideas.

## Buscar primero una respuesta

- Presione **F1** o haga clic en **Ayuda > Ayuda > Ayuda** y escriba unas palabras en el cuadro de búsqueda. Vea [Bienvenido a JeffPub](start).
- Haga clic en **Ayuda > Ayuda > Métodos abreviados de teclado** para ver las teclas. Vea [Usar JeffPub con el teclado](keyboard).
- Haga clic en **Ayuda > Ayuda > Novedades** para leer las notas de su versión.
- Si perdió trabajo después de que JeffPub se cerrara, vea [Recuperar trabajo no guardado](recover).
- Compruebe que tiene la versión más reciente. Haga clic en **Archivo > Acerca de** y, después, en **Buscar actualizaciones**. Puede que el problema ya esté corregido.

## Informar de un problema o sugerir una idea

1. Haga clic en **Ayuda > Ayuda > Comentarios**. Se abre una página de GitHub en el explorador web. Necesita una cuenta gratuita de GitHub para publicar en ella.
2. Escriba un título breve, como "El texto desaparece al imprimir" o "Idea: más estilos de borde".
3. En **What would you like to tell us?**, explique qué falló o qué le gustaría. Anote cualquier mensaje que haya visto.
4. Si se trata de un problema, en **What did you do just before it happened?**, enumere los pasos en orden para que otra persona pueda reproducirlos.
5. No borre la última línea. Indica su versión de JeffPub y su sistema operativo. Si falta, agregue el número de versión que aparece en **Archivo > Acerca de**.
6. Use el botón de la página de GitHub para enviarlo.

Una imagen del problema es de ayuda. No publique una publicación que contenga información privada.

## Acerca de JeffPub

Haga clic en **Archivo > Acerca de** para ver el número de versión, buscar actualizaciones y leer la licencia y los créditos. La página también tiene vínculos al código fuente, a las descargas y a **Informar de un problema**. Para las opciones de actualizaciones y estadísticas, vea [Cambiar la configuración de JeffPub](options).
