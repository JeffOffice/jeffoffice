# Pestaña Formato de texto artístico
<!-- keywords: formato de texto artístico, herramientas de texto artístico, pestaña de texto artístico, pestaña contextual, estilos de texto artístico, cambiar forma, efectos de sombra, efectos 3D -->

La pestaña **Formato de texto artístico** aparece, bajo la etiqueta **Herramientas de texto artístico**, cuando selecciona un texto artístico. Desaparece cuando selecciona otro elemento.

- **Texto de texto artístico** contiene **Modificar texto**, **Espaciado**, **Igualar alto**, **Texto vertical de texto artístico** y **Alinear texto**. Consulte [Agregar texto artístico](text-art).
- **Estilos de texto artístico** contiene la galería de 30 estilos, **Relleno de forma**, **Contorno de forma** y **Cambiar forma**, que curva las letras en forma de arco, onda, círculo y otras. Consulte [Agregar texto artístico](text-art).
- **Efectos** contiene **Efectos de sombra** y **Efectos 3D**. Consulte [Agregar texto artístico](text-art).
- **Organizar** controla el ajuste del texto, el orden de apilamiento, la agrupación, la alineación y el giro. Consulte [Mover, alinear, agrupar y superponer objetos](arrange).
- **Tamaño** establece el alto y el ancho. Consulte [Mover, alinear, agrupar y superponer objetos](arrange).
