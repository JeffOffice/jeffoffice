# Elegir una función
<!-- keywords: función, funciones, elegir una función, insertar función, fx, fórmula, argumento, categoría, buscar, todas las funciones, Autosuma, Mayús+F3 -->

Elija **Elegir una función** en la pestaña Fórmulas (**Mayús+F3**) o **Todas las funciones** en el menú **Autosuma**.

Escriba en el cuadro de búsqueda un nombre o lo que quiere hacer ("redondear hacia abajo", "unir texto") y la lista mostrará las funciones coincidentes, primero las que empiezan por las palabras que escribió. **Tipo** limita la lista a funciones financieras, de fecha y hora, matemáticas y trigonométricas, estadísticas, de búsqueda y referencia, de texto, lógicas, de información o de base de datos.

Elija una función para ver cómo se escribe, qué hace y cuáles son sus argumentos. Un argumento entre corchetes es opcional, y "más del mismo tipo" significa que puede indicar tantos como necesite. Presione **Aceptar** (o haga doble clic en la función).

La celda pasa al modo de edición con la fórmula iniciada: **=SUMA()**, con el cursor entre los paréntesis, listo para los argumentos. Si ya está escribiendo una fórmula, la función se inserta en la posición del cursor. Solo se muestran las funciones que JeffCrunch puede calcular.

## Mensajes en las celdas

Una celda que tiene una regla sobre lo que se puede escribir en ella también puede tener un mensaje (un título y una frase). El mensaje se muestra junto a la celda mientras esta está seleccionada. También funcionan las listas que leen celdas de otra hoja.
