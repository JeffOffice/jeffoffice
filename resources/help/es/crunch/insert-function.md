# Elegir una función
<!-- keywords: función, elegir una función, fx, fórmula, argumento, tipo, buscar, todas las funciones, Suma, Mayús+F3 -->

Elija **Elegir una función** en la pestaña **Fórmulas** (**Mayús+F3**), o **Todas las funciones** en el menú **Suma**.

Escriba en el cuadro de búsqueda un nombre o lo que desea hacer («redondear hacia abajo», «unir texto») y la lista muestra las funciones que coinciden, con los nombres que empiezan por sus palabras en primer lugar. **Tipo** limita la lista a las funciones financieras, de fecha y hora, matemáticas y trigonométricas, estadísticas, de búsqueda y referencia, de texto, lógicas, de información, de base de datos o de ingeniería.

Elija una función para ver cómo se escribe, qué hace y cuáles son sus argumentos. Un argumento entre corchetes es opcional, y «más del mismo» significa que puede indicar tantos como necesite. Pulse **Aceptar** (o haga doble clic en la función).

Después de **Aceptar** se abre el cuadro de diálogo **Argumentos de función** para esa función, donde podrá completar sus argumentos con el resultado mostrado mientras escribe (consulte [Introducir una función con el cuadro de diálogo Argumentos de función](function-arguments)). **Aceptar** allí escribe la fórmula en la celda, por ejemplo **=SUMA(A1:A3)**. Si ya está escribiendo una fórmula, la función se inserta en el cursor. Solo se muestran las funciones que JeffCrunch puede calcular.

## Mensajes en las celdas

Una celda que tiene una regla sobre lo que se puede introducir también puede tener un mensaje (un título y una frase). Se muestra junto a la celda mientras esta está seleccionada. Las listas que leen celdas de otra hoja también funcionan.
