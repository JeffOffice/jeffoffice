## Notas

Una **nota** es un texto breve que se guarda con una celda. Una celda que tiene una nota muestra una pequeña marca roja en la esquina superior derecha. Sitúe el puntero sobre la celda y la nota aparecerá a su lado; al apartar el puntero, desaparecerá.

Para agregar una nota a una celda, selecciónela y use **Revisar > Nueva nota** (o presione **Mayús+F2**). Escriba el texto y haga clic en **Aceptar**. En una celda que ya tiene una nota, el mismo comando se llama **Modificar nota**. Si borra todo el texto, la nota se elimina.

- **Eliminar nota** quita las notas de las celdas seleccionadas.
- **Mostrar u ocultar nota** mantiene visible en todo momento la nota de las celdas seleccionadas, en un cuadro junto a cada celda, o vuelve a ocultarla.
- **Mostrar todas las notas** hace lo mismo con todas las notas de la hoja; después, el mismo botón se llama **Ocultar todas las notas**.
- **Nota anterior** y **Nota siguiente** permiten pasar de una celda con nota a la siguiente.

Cada una de estas acciones es un paso que se puede deshacer. Una nota acompaña a su celda cuando se insertan o eliminan filas o columnas, y cuando se ordenan las celdas. **Borrar todo** quita las notas de las celdas que borra.

Un libro puede contener una conversación de comentarios con respuestas. JeffCrunch muestra toda la conversación como una nota y la conserva al guardar, pero no la modifica: la nota es de solo lectura.

Las notas se pueden guardar en un libro .xlsx. Un libro abierto desde un tipo de archivo más antiguo, o desde un archivo de texto, solo conserva sus notas si lo guarda como libro .xlsx.

## Vínculos

Un **vínculo** le lleva a otro lugar cuando lo sigue: a una página web, a un archivo, a una dirección de correo electrónico o a un lugar de este libro (una celda, un rango de celdas o un nombre).

Para agregar un vínculo a una celda, selecciónela y use **Insertar > Vínculo** (o presione **Ctrl+K**). Elija el destino, escriba la dirección o el lugar y, si lo desea, el texto que debe mostrar la celda y una **información en pantalla**. En una celda que ya tiene un vínculo, el mismo comando se llama **Modificar vínculo**. **Quitar vínculo** quita los vínculos de las celdas seleccionadas.

Sitúe el puntero sobre una celda con un vínculo para ver adónde lleva. Para seguirlo, mantenga presionada la tecla **Ctrl** y haga clic en la celda, o seleccione la celda y use **Abrir vínculo** en el menú contextual. Un clic normal solo selecciona la celda.

JeffCrunch nunca abre nada por sí solo. Una página web o una dirección de correo electrónico se abren en el programa que use habitualmente cuando sigue su vínculo. Un vínculo a un archivo, o a otro tipo de dirección, le pide confirmación primero. Un vínculo que ejecutaría un script no se abre nunca.

Un vínculo acompaña a su celda cuando se insertan o eliminan filas o columnas, y cuando se ordenan las celdas, y se guarda con el libro.
