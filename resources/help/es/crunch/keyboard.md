# Usar JeffCrunch con el teclado
<!-- keywords: teclado, métodos abreviados, atajos de teclado, teclas, teclas de acceso rápido, flecha, ctrl, mayús, inicio, fin, re pág, av pág, tabulación, entrar, seleccionar todo, copiar, F9, F1, zoom, teclas de acceso, KeyTips -->

En un Mac, la tecla **Comando** (⌘) hace lo mismo que **Ctrl** en las tablas siguientes, salvo donde la tabla indique otra cosa.

## Moverse y seleccionar

| Teclas | Qué hacen |
| --- | --- |
| Teclas de dirección | Mueven la celda activa una celda, omitiendo las filas y columnas ocultas |
| Mayús+tecla de dirección | Amplía la selección una celda |
| Ctrl+tecla de dirección | Va al borde de los datos (Esc detiene una búsqueda larga) |
| Ctrl+Mayús+tecla de dirección | Amplía la selección hasta el borde de los datos |
| Inicio | Va a la primera columna de la fila |
| Ctrl+Inicio | Va a la primera celda (A1, o la primera celda que se desplaza cuando hay filas o columnas inmovilizadas) |
| Ctrl+Fin | Va a la última celda que contiene algo o tiene formato |
| Av Pág, Re Pág | Baja o sube una pantalla |
| Tab, Mayús+Tab | Se mueve a la derecha o a la izquierda (por las celdas seleccionadas, si hay varias) |
| Entrar, Mayús+Entrar | Se mueve hacia abajo o hacia arriba (por las celdas seleccionadas, si hay varias) |
| Ctrl+Espacio | Selecciona toda la columna |
| Mayús+Espacio | Selecciona toda la fila |
| {key:SelectAll} | Selecciona todo |

## Cambiar celdas

| Teclas | Qué hacen |
| --- | --- |
| Cualquier carácter | Empieza una entrada en la celda activa, en lugar de lo que contiene |
| F2 | Modifica en la celda lo que contiene la celda activa; mientras escribe una fórmula, alterna entre señalar celdas y modificar el texto |
| F4 | Mientras escribe una fórmula, fija con $ partes de la referencia en la que está el cursor (A1, $A$1, A$1, $A1) |
| Entrar, Mayús+Entrar | Confirma la entrada y se mueve hacia abajo o hacia arriba |
| Tab, Mayús+Tab | Confirma la entrada y se mueve a la derecha o a la izquierda |
| Esc | Descarta la entrada |
| Alt+Entrar | Inicia una nueva línea en la celda |
| Supr | Borra las celdas seleccionadas |
| {key:Undo}, {key:Redo} | Deshacer, rehacer |
| {key:Save} | Guardar |
| {key:Cut}, {key:Copy}, {key:Paste} | Cortar, copiar, pegar (Esc quita el borde de las celdas copiadas) |
| Ctrl+Alt+V | Pegado especial |
| Ctrl y la tecla más, Ctrl y la tecla menos | Insertar, eliminar (filas o columnas si hay filas o columnas completas seleccionadas) |
| Ctrl+D, Ctrl+R | Rellenar hacia abajo, rellenar hacia la derecha |
| Alt y el signo igual | Suma |
| Ctrl+0, Ctrl+9 | Ocultar las columnas, ocultar las filas |
| Alt+Abajo | Abre la lista de una celda que tiene una |
| {key:Find} | Buscar |
| Ctrl+H (en un Mac, Opción+Comando+F) | Buscar y reemplazar |
| F5, Ctrl+G | Ir a una celda, un rango o un nombre |
| Ctrl+Mayús+L | Activa o desactiva el filtro |
| Mayús+F3 | Elegir una función |
| Ctrl+F3 | La lista de nombres |
| F9, Mayús+F9 | Volver a calcular todo, recalcular esta hoja |
| Tab, Entrar | Mientras escribe una fórmula: toma la función o el nombre marcado en la lista |
| Esc | Detiene una búsqueda, una ordenación o un filtro en curso |

## Teclas de acceso

Presione **Alt** para ver una letra en cada pestaña y comando de la cinta de opciones y, a continuación, presione las letras. Presione **Alt** y luego **F** para ir a la pantalla Archivo. Presione **Esc** para retroceder.
