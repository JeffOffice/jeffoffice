# Usar JeffCrunch con el teclado
<!-- keywords: teclado, métodos abreviados, teclas, atajos, teclas de acceso, flecha, ctrl, mayús, inicio, fin, re pág, av pág, tabulador, intro, seleccionar todo, copiar, F9, F1, zoom, información de teclas, combinaciones de teclas -->

La pestaña **Ayuda** tiene **Ayuda** (F1), **Métodos abreviados de teclado**, que abre esta página, **Novedades** y **Comentarios**, que abren sus páginas web.

En un Mac, la tecla **Comando** (⌘) hace lo mismo que **Ctrl** en las tablas siguientes, salvo que una tabla indique otra cosa.

## Desplazarse y seleccionar

| Teclas | Qué hacen |
| --- | --- |
| Teclas de flecha | Mueven la celda activa una celda, saltando las filas y columnas ocultas |
| Mayús+flecha | Amplía la selección una celda |
| Ctrl+flecha | Va al borde de los datos (Esc detiene una búsqueda larga) |
| Ctrl+Mayús+flecha | Amplía la selección hasta el borde de los datos |
| Inicio | Va a la primera columna de la fila |
| Ctrl+Inicio | Va a la primera celda (A1, o la primera celda que se desplaza cuando hay filas o columnas inmovilizadas) |
| Ctrl+Fin | Va a la última celda que contiene algo o tiene formato |
| Av Pág, Re Pág | Bajan o suben una pantalla |
| Tab, Mayús+Tab | Van a la derecha o a la izquierda (por las celdas seleccionadas, si hay varias) |
| Intro, Mayús+Intro | Van abajo o arriba (por las celdas seleccionadas, si hay varias) |
| Ctrl+Espacio | Selecciona toda la columna |
| Mayús+Espacio | Selecciona toda la fila |
| {key:SelectAll} | Selecciona todo |

## Modificar celdas

| Teclas | Qué hacen |
| --- | --- |
| Cualquier carácter | Inicia una entrada en la celda activa, en lugar de lo que contiene |
| F2 | Edita el contenido de la celda activa, dentro de la celda; mientras escribe una fórmula, alterna entre señalar celdas y editar el texto |
| F4 | Mientras escribe una fórmula, fija partes de la dirección en el cursor con $ (A1, $A$1, A$1, $A1) |
| Intro, Mayús+Intro | Confirman la entrada y van abajo o arriba |
| Tab, Mayús+Tab | Confirman la entrada y van a la derecha o a la izquierda |
| Esc | Cancela la entrada |
| Alt+Intro | Inicia una nueva línea en la celda |
| Supr | Borra las celdas seleccionadas |
| {key:Undo}, {key:Redo} | Deshacer, rehacer |
| {key:Save} | Guardar |
| {key:Cut}, {key:Copy}, {key:Paste} | Cortar, copiar, pegar (Esc quita el borde de las celdas copiadas) |
| Ctrl+Alt+V | Pegado especial |
| Ctrl y la tecla más, Ctrl y la tecla menos | Insertan o eliminan (filas o columnas, si se seleccionan completas) |
| Ctrl+D, Ctrl+R | Rellenar hacia abajo, rellenar hacia la derecha |
| Ctrl+E | Relleno relámpago |
| Alt y el signo igual | Suma |
| Ctrl+0, Ctrl+9 | Ocultan las columnas, ocultan las filas |
| Alt+Flecha abajo | Abre la lista de una celda que tiene una |
| {key:Find} | Buscar |
| Ctrl+H (en un Mac, Opción+Comando+F) | Buscar y reemplazar |
| F5, Ctrl+G | Ir a una celda, un rango o un nombre |
| Ctrl+Mayús+L | Activa o desactiva el filtro |
| Mayús+F3 | Elegir una función |
| Ctrl+F3 | La lista de nombres |
| F9, Mayús+F9 | Volver a calcular todo, volver a calcular esta hoja |
| Tab, Intro | Mientras se escribe una fórmula: toman la función o el nombre marcado en la lista |
| Esc | Detiene una búsqueda, una ordenación o un filtro en curso |

## Teclas de acceso

Pulse **Alt** para ver una letra en cada pestaña de la cinta de opciones y en cada comando, y después pulse esas letras. Pulse **Alt** y después **F** para ir a la pantalla Archivo. Pulse **Esc** para retroceder.
