# Usar JeffCrunch con el teclado

La ficha **Ayuda** tiene **Ayuda** (F1), **Métodos abreviados de teclado**, que abre esta página, **Novedades** y **Comentarios**, que abren sus páginas web.

En un Mac, la tecla **Comando** (⌘) hace lo que **Ctrl** en las tablas siguientes, salvo que una tabla indique lo contrario.

## Desplazarse y seleccionar

| Teclas | Qué hacen |
| --- | --- |
| Teclas de flecha | Mueven la celda activa una celda, saltando las filas y columnas ocultas |
| Mayús+flecha | Amplía la selección una celda |
| Ctrl+flecha | Va al borde de los datos (Esc detiene una búsqueda larga) |
| Ctrl+Mayús+flecha | Amplía la selección hasta el borde de los datos |
| Fin, y después una flecha | Va al borde de los datos (la barra de estado muestra FIN) |
| Ctrl+E | Selecciona el bloque alrededor de la celda activa y, después, toda la hoja (toda la hoja de una vez cuando la selección ya es mayor que el bloque) |
| Ctrl+Mayús+* | Selecciona el bloque alrededor de la celda activa |
| Ctrl+clic o Ctrl+arrastrar | Agrega un rango a la selección |
| Ctrl+Mayús+Intro | Introduce la fórmula como fórmula matricial sobre las celdas seleccionadas |
| Inicio | Va a la primera columna de la fila |
| Ctrl+Inicio | Va a la primera celda (A1, o la primera celda que se desplaza cuando hay filas o columnas inmovilizadas) |
| Ctrl+Fin | Va a la última celda que contiene algo o tiene formato |
| Av Pág, Re Pág | Baja o sube una pantalla |
| Tab, Mayús+Tab | Se mueve a la derecha o a la izquierda (por las celdas seleccionadas, si hay varias) |
| Intro, Mayús+Intro | Baja o sube (por las celdas seleccionadas, si hay varias) |
| Ctrl+Espacio | Selecciona la columna completa |
| Mayús+Espacio | Selecciona la fila completa |
| {key:SelectAll} | Selecciona todo |

| F4 | Mientras escribe una fórmula, fija partes de la referencia en el cursor con $ (A1, $A$1, A$1, $A1) |
| Intro, Mayús+Intro | Confirma la entrada y baja o sube |
| Tab, Mayús+Tab | Confirma la entrada y se mueve a la derecha o a la izquierda |

| Alt+Intro | Inicia una nueva línea en la celda |
| Supr | Borra las celdas seleccionadas |
| Ctrl+Q (Control+Q en un Mac) | Abre el Análisis rápido para las celdas seleccionadas |
| {key:Undo}, {key:Redo} | Deshacer, rehacer |
| F4 | Repite el último comando sobre las celdas seleccionadas (Ctrl+Y también lo hace, cuando no hay nada que rehacer) |
| {key:Save} | Guardar |
| {key:Cut}, {key:Copy}, {key:Paste} | Cortar, copiar, pegar (Esc quita el borde de las celdas copiadas) |
| Ctrl+Alt+V | Pegado especial |
| Ctrl y la tecla más, Ctrl+Mayús y la tecla más, Ctrl y la tecla menos | Inserta o elimina (filas o columnas si se seleccionan completas; las teclas más insertan celdas cortadas o copiadas sin cambios posteriores, y en otro caso celdas en blanco) |

| Ctrl+D, Ctrl+R | Rellenar hacia abajo, rellenar hacia la derecha |
| Ctrl+E | Relleno relámpago |
| Alt y el signo igual | Suma |
| Ctrl+0, Ctrl+9 | Oculta las columnas, oculta las filas |
| Alt+Flecha abajo | Abre la lista de una celda que tiene una |
| {key:Find} | Buscar |
| Ctrl+H (en un Mac, Opción+Comando+F) | Buscar y reemplazar |
| F5, Ctrl+G | Ir a una celda, un rango o un nombre |
| Ctrl+Mayús+L | Activa o desactiva el filtro |
| Mayús+F3 | Elegir una función |
| Ctrl+F3 | La lista de nombres |
| F9, Mayús+F9 | Volver a calcular todo, volver a calcular esta hoja |
| Tab, Intro | Mientras se escribe una fórmula: toma la función o el nombre marcado en la lista |
| Esc | Detiene una búsqueda, una ordenación o un filtro en curso |

## Elija sus propios métodos abreviados de teclado

Puede cambiar las teclas de cualquier comando, o asignar una tecla a un comando que no tiene ninguna. Haga clic en **Archivo > Opciones** y, después, en la ficha **Personalizar**.

1. Escriba en el cuadro **Buscar** para encontrar un comando por su nombre o por sus teclas. La lista se agrupa por las fichas de la cinta de opciones, y cada comando muestra sus teclas. Los comandos que no están en la cinta de opciones aparecen en **Otros**.
2. Haga clic en el comando. Sus teclas aparecen en **Teclas de este comando**.
3. Haga clic en el cuadro **Pulse las nuevas teclas** y pulse las teclas que desea, por ejemplo **Ctrl+Mayús+B**. Después, haga clic en **Asignar**. Un comando puede tener hasta cuatro teclas.
4. Para quitar una tecla, haga clic en ella en la lista y, después, en **Quitar**.

Si otro comando ya tiene las teclas que pulsó, JeffCrunch le indica cuál. Haga clic en **Reasignar** para dar las teclas a este comando; el otro comando las pierde. Nada cambia hasta que haga clic en **Aceptar**. Después, todas las ventanas abiertas de JeffCrunch usan sus teclas, y también todas las ventanas que abra más adelante. Las sugerencias, los menús y la tabla de métodos abreviados de abajo muestran sus teclas.

Un símbolo también puede tener teclas. Consulte **Insertar un símbolo** en [Escribir en celdas](edit-cells): haga clic en **Tecla de acceso directo** en el cuadro Símbolo. Entonces aparece en esta lista como cualquier comando.

**Restablecer uno** devuelve las teclas habituales del comando elegido. **Restablecer todo** devuelve las teclas habituales de todos los comandos. JeffCrunch solo conserva los comandos cuyas teclas ha cambiado, de modo que un comando que no ha modificado recibe las teclas mejores que le asigne una versión posterior.

Algunas teclas no se pueden asignar a un comando, porque el sistema o la escritura las necesitan. JeffCrunch indica **reservada** cuando pulsa una de ellas. Las teclas reservadas son **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z**, **Ctrl+A**, **Tab**, **Mayús+Tab**, **Intro**, **Esc**, **Retroceso**, **Supr**, **Alt+F4**, las teclas de flecha, **Inicio**, **Fin**, **Av Pág**, **Re Pág** y **Espacio**, **F1**, **F6**, **Mayús+F6**, **Ctrl+Y**, **Ctrl+Mayús+Z**, **Ctrl** con una flecha, **Inicio**, **Fin**, **Retroceso** o **Supr** (con o sin **Mayús**, cuando tiene sentido en un cuadro de texto), y una tecla de letra, número o símbolo pulsada sola o con **Mayús**. Una tecla que ya usa otra parte de la ventana también está reservada. **Guardar**, **Deshacer** y **Rehacer** siempre conservan al menos una tecla. En un Mac, **Ctrl** aquí significa la tecla **Comando**.

## Teclas de acceso

Pulse **Alt** para ver una letra en cada ficha y comando de la cinta de opciones, y después pulse las letras. Pulse **Alt** y, después, **F**, para abrir la pantalla Archivo. Pulse **Esc** para retroceder.
