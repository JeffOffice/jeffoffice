# Usar JeffCrunch con el teclado

La ficha **Ayuda** tiene **Ayuda** (F1), **Métodos abreviados de teclado**, que abre esta página, **Novedades** y **Comentarios**, que abren sus páginas web.

En un Mac, la tecla **Comando** (⌘) hace lo que **Ctrl** en las tablas siguientes, salvo que una tabla indique otra cosa.

## Desplazarse y seleccionar

| Teclas | Qué hacen |
| --- | --- |
| Teclas de flecha | Mueven la celda activa una celda, saltando las filas y columnas ocultas |
| Mayús+flecha | Amplía la selección una celda |
| Ctrl+flecha | Va al borde de los datos (Esc detiene una búsqueda larga) |
| Ctrl+Mayús+flecha | Amplía la selección hasta el borde de los datos |
| Fin, y después una flecha | Va al borde de los datos (la barra de estado muestra Fin) |
| Ctrl+A | Selecciona el rango alrededor de la celda activa y, después, toda la hoja (toda la hoja de una vez cuando la selección ya es mayor que el rango) |
| Ctrl+Mayús+* | Selecciona el rango alrededor de la celda activa |
| Ctrl+clic o Ctrl+arrastrar | Agrega un rango a la selección |
| Ctrl+Mayús+Intro | Introduce la fórmula como fórmula matricial en las celdas seleccionadas |
| Inicio | Va a la primera columna de la fila |
| Ctrl+Inicio | Va a la primera celda (A1, o la primera celda que se desplaza cuando hay filas o columnas inmovilizadas) |
| Ctrl+Fin | Va a la última celda que contiene algo o tiene un formato |
| Av Pág, Re Pág | Bajan o suben una pantalla |
| Tabulador, Mayús+Tabulador | Se desplazan a la derecha o a la izquierda (por las celdas seleccionadas, si hay varias) |
| Intro, Mayús+Intro | Bajan o suben (por las celdas seleccionadas, si hay varias) |
| Ctrl+Espacio | Selecciona la columna completa |
| Mayús+Espacio | Selecciona la fila completa |
| {key:SelectAll} | Selecciona todo |

| Alt+Intro | Inicia una nueva línea en la celda |
| Supr | Borra las celdas seleccionadas |
| {key:Undo}, {key:Redo} | Deshacer, rehacer |
| F4 | Repite el último comando en las celdas seleccionadas (Ctrl+Y también lo hace, cuando no hay nada que rehacer) |
| {key:Save} | Guardar |
| {key:Cut}, {key:Copy}, {key:Paste} | Cortar, copiar, pegar (Esc quita el borde de las celdas copiadas) |
| Ctrl+Alt+V | Pegado especial |

| {key:Find} | Buscar |
| Ctrl+H (en un Mac, Opción+Comando+F) | Buscar y reemplazar |
| F5, Ctrl+I | Ir a una celda, un rango o un nombre |
| Ctrl+Mayús+L | Activa o desactiva el filtro |
| Mayús+F3 | Elegir una función |

## Elegir sus propios métodos abreviados de teclado

Puede cambiar las teclas de cualquier comando, o asignar una tecla a un comando que no tenga ninguna. Haga clic en **Archivo > Opciones** y, después, en la ficha **Personalizar**.

1. Escriba en el cuadro **Buscar** para encontrar un comando por su nombre o por sus teclas. La lista se agrupa por las fichas de la cinta de opciones, y cada comando muestra sus teclas. Los comandos que no están en la cinta aparecen en **Otros**.
2. Haga clic en el comando. Sus teclas aparecen en **Teclas de este comando**.
3. Haga clic en el cuadro **Pulse las nuevas teclas** y pulse las teclas que desee, por ejemplo **Ctrl+Mayús+B**. Después, haga clic en **Asignar**. Un comando puede tener hasta cuatro teclas.
4. Para quitar una tecla, haga clic en ella en la lista y, después, en **Quitar**.

Si otro comando ya tiene las teclas que pulsó, JeffCrunch indica cuál es. Haga clic en **Reasignar** para dar las teclas a este comando; el otro comando las pierde. Nada cambia hasta que haga clic en **Aceptar**. Después, todas las ventanas abiertas de JeffCrunch usan sus teclas, y también todas las ventanas que abra más adelante. Las información sobre herramientas, los menús y la tabla de métodos abreviados siguiente muestran sus teclas.

Un símbolo también puede tener teclas. Consulte **Insertar un símbolo** en [Escribir en celdas](edit-cells): haga clic en **Tecla de acceso directo** en el cuadro Símbolo. Entonces aparece en esta lista como cualquier comando.

**Restablecer uno** devuelve las teclas habituales del comando elegido. **Restablecer todo** devuelve las teclas habituales de todos los comandos. JeffCrunch guarda solo los comandos cuyas teclas cambió, de modo que un comando que nunca cambió recibe las teclas mejores que le asigne una versión posterior.

Algunas teclas no pueden asignarse a un comando, porque el sistema o la escritura las necesitan. JeffCrunch indica **reservada** cuando pulsa una de ellas. Las teclas reservadas son **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z**, **Ctrl+A**, **Tabulador**, **Mayús+Tabulador**, **Intro**, **Esc**, **Retroceso**, **Supr**, **Alt+F4**, las teclas de flecha, **Inicio**, **Fin**, **Re Pág**, **Av Pág** y **Espacio**, **F1**, **F6**, **Mayús+F6**, **Ctrl+Y**, **Ctrl+Mayús+Z**, **Ctrl** con una flecha, **Inicio**, **Fin**, **Retroceso** o **Supr** (con o sin **Mayús**, cuando tiene sentido en un cuadro de texto), y una tecla de letra, número o símbolo pulsada sola o con **Mayús**. Una tecla que ya usa otra parte de la ventana también está reservada. **Guardar**, **Deshacer** y **Rehacer** siempre conservan al menos una tecla. En un Mac, **Ctrl** aquí significa la tecla **Comando**.

## Teclas de acceso

Pulse **Alt** para ver una letra en cada ficha y comando de la cinta de opciones, y, después, pulse las letras. Pulse **Alt** y, después, **A** para abrir la pantalla Archivo. Pulse **Esc** para volver atrás.
