# Печать публикации

Печать выполняется на странице **Печать**. Параметры выбираются слева, а предварительный просмотр каждой страницы показан справа. **Масштаб** над просмотром увеличивает страницу больше размера, при котором она помещается в окне; прокрутите, чтобы увидеть остальное.

## Печать публикации

1. Нажмите Ctrl+P или выберите **Файл > Печать**. На **панели быстрого доступа** тоже есть кнопка **Печать**.
2. Рядом с кнопкой **Печать** задайте **Копии**.
3. Выберите **Принтер**. В конце списка находится **Сохранить как PDF**, который создаёт файл PDF вместо печати на бумаге. При нескольких копиях **Разобрать по копиям** печатает весь комплект заново для каждой копии (1, 2, 3, затем снова 1, 2, 3), а при выключенном параметре копии каждой страницы выходят вместе (1, 1, 2, 2, 3, 3). Файл PDF создаётся один раз, каким бы ни было число копий.
4. В группе **Диапазон** выберите **Все страницы**, **Текущая страница**, **Выделенный фрагмент** (только выделенные объекты на их местах на текущей странице; объект в группе печатается вместе со всей группой, объекты главной страницы не выводятся, а просмотр показывает только то, что будет напечатано; пункт недоступен, когда ничего не выделено) или **Страницы**. Для **Страницы** введите страницы в поле **Страницы**: номера страниц и диапазоны через запятую, например 1-3, 5.
5. Выберите остальные нужные параметры. Они перечислены ниже.
6. Нажмите **Печать**.

Нажмите **Свойства принтера…**, чтобы открыть системное окно печати с параметрами вашего принтера. Выбранное там сохраняется для задания, а копии, разбор по копиям и бумага возвращаются на эту страницу. При печати на обеих сторонах листа **Последняя страница первой** сохраняет каждую лицевую сторону вместе с оборотной.

На просмотре справа есть стрелки для перехода от страницы к странице. Включите **Показывать линейки** или **Показывать номера страниц**, чтобы видеть их на просмотре.

## Выбор макета

Список **Макет** задаёт, как страницы размещаются на бумаге:

- **Одна страница на листе** печатает каждую страницу отдельно. Страница, которая не помещается на бумагу, печатается по частям. Страница, немного превышающая размер листа, уменьшается, чтобы поместиться.
- **Несколько страниц на листе** размещает разные страницы на одном листе.
- **Несколько копий на листе** повторяет одну страницу по всему листу. Используйте для визиток и наклеек.
- **Буклет, сгиб сбоку** и **Буклет, сгиб сверху** помещают две страницы на каждый лист в правильном порядке, чтобы сложенная стопка читалась по порядку. При сгибе сбоку две страницы стоят рядом. При сгибе сверху одна страница находится над другой.
- **Плитка (плакаты и баннеры)** печатает большую страницу по частям на нескольких листах с небольшим перекрытием, чтобы листы можно было совместить.

## Дополнительные параметры

- **Бумага**: Letter, Legal, Tabloid, A4, A3 или **Как в публикации**.
- **Последняя страница первой** печатает листы в обратном порядке, чтобы стопка выходила по порядку. Пункт недоступен при печати на обеих сторонах вручную, потому что тогда порядок задаёт сама программа JeffPub.
- **Печать на сторонах**: **Печать на одной стороне** или **Печать на обеих сторонах** с переворотом по длинному или по короткому краю. **Печать на обеих сторонах вручную** предназначена для принтера, который не может печатать на обеих сторонах. JeffPub печатает первую, третью, пятую и т. д. страницы (для буклета — стороны листов), затем сообщение просит перевернуть стопку и вернуть её в принтер. После нажатия **ОК** программа печатает остальные страницы, начиная с последней. Задание из одной страницы не требует переворота. При сохранении в PDF выбор недоступен, потому что у файла нет сторон. Просмотр тогда показывает, на каком листе и на какой стороне находится каждая страница.
- **Цвет**: **Составной RGB** для полноцветной печати или **Составной в оттенках серого** для оттенков серого.
- **Вывести все записи слияния почты**: доступно, когда в публикации есть список получателей. См. [слияние почты](mail-merge).

## Метки печати и цветоделение

Эти параметры нужны для работы, которую передают в типографию. Уточните у типографии, что ей нужно.

- **Метки обреза** показывают, где обрезать. **Метки выпуска за обрез** показывают дополнительный край. **Метки приводки** помогают совместить цвета. **Плотностные шкалы** и **Цветовые шкалы** позволяют типографии проверить краску. **Сведения о задании** выводят имя, страницу и дату.
- **Разрешить выпуск за обрез** печатает объекты, которые выходят за край страницы, поэтому после обрезки не остаётся белой кромки. Этот дополнительный край называется **выпуском за обрез**.
- Метки печатаются за пределами страницы, поэтому используйте бумагу большего размера, чем страница.
- **Цветоделение (пластины CMYK)** в группе **Цвет** печатает отдельный лист для каждой краски: **голубой**, **пурпурный**, **жёлтый** и **чёрный**, а также все плашечные цвета, которые использует публикация (плашечный цвет — это специально подготовленная готовая краска). Отметьте или снимите отметки с нужных пластин.

Чтобы подготовить PDF для передачи в типографию, см. [файлы PDF и типографии](pdf).
