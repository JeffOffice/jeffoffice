# Слияние почты, конверты и наклейки
<!-- keywords: слияние почты, слияние, рассылки, получатели, список адресов, форма письма, наклейки, конверты, поле слияния, блок адреса, строка приветствия, правила, если то иначе, пропустить запись, следующая запись, просмотр результатов, завершить и выполнить слияние, каталог, сообщения эл. почты, csv, xlsx, ods, vcard, штрихкод, рассылка -->

**Слияние почты** создаёт множество копий одного письма, в каждой из которых стоят данные разных людей. Письмо вы пишете один раз. Данные людей хранятся в **списке**. JeffWrite вставляет имя и адрес первого человека в первую копию, второго человека — во вторую копию и так далее.

Инструменты находятся на вкладке **Рассылки**. Для пошагового порядка нажмите **Рассылки > Начать слияние > Пошаговый мастер слияния почты**.

## Выберите, что создаёте

Нажмите **Рассылки > Начать слияние** и выберите один вариант:

- **Письма**: одна копия страницы для каждого человека. Каждая копия начинается с новой страницы.
- **Сообщения эл. почты**: одно сообщение для каждого человека. См. раздел «Отправка сообщений эл. почты» ниже.
- **Конверты** и **Наклейки**: страница, подготовленная для них. См. разделы ниже.
- **Каталог**: один общий список всех людей без разрыва страницы между ними. Используйте его для телефонного справочника или каталога.
- **Очистить тип слияния** возвращает документу обычный вид.

JeffWrite сохраняет вид слияния и имя списка внутри файла при сохранении. При повторном открытии файла слияние сохраняется.

## Выберите получателей

**Получатель** — это человек, который получает копию. Нажмите **Рассылки > Выбрать получателей**:

- **Ввести новый список**: введите людей в открывшемся окне. Для каждого нажмите **Новая запись**. Затем JeffWrite предложит сохранить список как файл .csv.
- **Использовать существующий список**: выберите файл, который уже является списком. Это может быть файл .csv или текстовый файл с табуляцией (одна строка на каждого человека, первая строка содержит названия столбцов), электронная таблица (.xlsx, .xls или .ods, из JeffCrunch или другой программы) или файл контактов (.vcf).
- **Выбрать из контактов**: выберите файл контактов (.vcf). Большинство адресных книг и телефонов могут сохранить контакты в таком файле.

Затем нажмите **Рассылки > Изменить список получателей**, чтобы проверить список:

- Снимите отметку со строки, чтобы исключить человека.
- Щёлкните заголовок столбца, чтобы выполнить сортировку.
- Введите текст в поле **Фильтр получателей**, чтобы показать только строки, в которых есть ваши слова.
- **Найти дубликаты** снимает отметки с повторов.
- **Проверить адреса** выделяет цветом строки, где нет адреса или почтовый индекс выглядит неверно.

## Вставьте данные в письмо

**Поле слияния** — это место-заполнитель. Оно показывает название столбца в двойных угловых кавычках, например «Имя». В каждой копии оно заменяется данными этого человека.

Щёлкните место, куда пойдут данные, затем используйте **Рассылки > Записать и вставить поля**:

- **Вставить поле слияния** показывает столбцы вашего списка. Выберите один из них.
  - **Штрихкод из поля** в том же списке вставляет штрихкод, значение которого берётся из столбца, например, артикул или 13-значный ISBN книги. Выберите столбец, затем тип и вид в окне **Вставка штрихкода** (введённое там значение служит только образцом). Окно предлагает только то, что может содержать поле: тип, размер, высоту штрихов, цифры и уровень QR. Оно не включает цену книги, дополнение, контрольный символ и прозрачный фон, которые поле передать не может; ISBN книги — это EAN-13. В документе поле отображается как штрихкод, образцом выбранного типа до слияния; чтобы изменить тип или вид, дважды щёлкните его либо щёлкните правой кнопкой и выберите **Изменить штрихкод**. При слиянии в каждой копии появляется штрихкод со значением этого человека, нарисованный как рисунок в строке, поэтому он печатается и сохраняется в PDF как любой рисунок. Значение — только данные: кавычки или обратная косая черта в нём ничего не меняют. Если значение пусто, штрихкода нет. Если код не может вместить значение (буква в EAN-13 или более 500 знаков в Code 128), вместо него в копии появляется короткое сообщение в квадратных скобках, а остальные копии не затрагиваются. Одно слияние создаёт не более 2 000 штрихкодов, считая и значения, которые не удалось вывести; если программа сообщает, что их слишком много, объедините меньше людей. В сохранённом файле `.docx` поле является полем DISPLAYBARCODE с названием столбца внутри, поэтому оно сохраняется при повторном открытии файла. Поле со значением, введённым вручную, или поле типа, который JeffWrite не рисует (например, UPC-E), остаётся без изменений. При слиянии по эл. почте значение вставляется как текст.
- **Блок адреса** вставляет полный почтовый адрес: имя, компанию, улицу и город. Выберите нужные строки. Строка без данных пропускается. Также можно указать страну, которую нужно не выводить, например свою. **Предварительный просмотр** показывает адрес первого человека.
- **Строка приветствия** вставляет фразу вида «Уважаемый доктор Фенвик,». Слова выбираете вы. Первый вариант, «Уважаемый доктор Фенвик,», использует звание человека. Если звания нет, используются имя и фамилия, например «Уважаемая Нора Пелл,». Если имени нет, приветствие имеет другой текст, например «Уважаемые дамы и господа,», который можно изменить.
- **Сопоставить поля** сообщает блоку адреса и строке приветствия, в каком столбце находится каждая часть, если названия столбцов необычные.

## Правила

**Правило** делает копию отличающейся для некоторых людей. Нажмите **Правила** и выберите один вариант:

- **Если…То…Иначе**: показать один текст, если в столбце есть значение, и другой текст, если его нет. Например, если в поле «Область» указано «Москва», напишите «Добро пожаловать домой».
- **Пропустить запись, если**: исключить человека, если столбец удовлетворяет заданному условию, например, если фамилия пуста.
- **Следующая запись** и **Следующая запись, если**: использовать данные следующего человека на том же месте. Наклейки используют это правило, чтобы на каждой наклейке был другой человек.
- **Номер записи слияния** вставляет номер строки человека в списке. **Порядковый номер слияния** считает уже созданные копии.
- **Запрос** и **Ввод данных**: задать вам вопрос при завершении слияния. Запрос сохраняет ответ под именем. Ввод данных вставляет ответ в текст.
- **Установить закладку**: присваивает имени значение. Перекрёстная ссылка на это имя показывает значение.

## Просмотр результатов

Нажмите **Рассылки > Просмотр результатов**. Откроется область, которая показывает страницу для одного человека. Используйте **Первая запись**, **Предыдущая запись**, **Следующая запись** и **Последняя запись», чтобы перемещаться по людям, или введите номер. **Найти получателя** переходит к следующему человеку, у которого в данных есть ваши слова.

**Выделить поля слияния** затеняет серым поля слияния на странице, чтобы было видно, где они находятся. Другие поля, например номера страниц, не затеняются. Затенение видно на экране и никогда не печатается.

Ваш документ не меняется. **Проверить на ошибки** сообщает, если в списке нет столбца для поля или если никто не включён в слияние.

## Завершите слияние

Нажмите **Рассылки > Завершить и выполнить слияние**:

- **Изменить отдельные документы** создаёт новый документ со всеми копиями. Его можно изменить перед печатью.
- **Печать документов** создаёт этот документ и открывает страницу **Печать**.
- **Сохранить как PDF** сохраняет все копии в одном файле PDF.
- **Отправить сообщения эл. почты** создаёт для каждого человека файл сообщения .eml в выбранной вами папке. Выберите столбец с адресами эл. почты и введите тему. JeffWrite не отправляет сообщения. Откройте файлы в своей почтовой программе.

Люди, с которых вы сняли отметку в списке, исключаются.

Файл сообщения создаётся только для человека, чей адрес состоит из одного адреса эл. почты. Если в адресе два адреса (через запятую или точку с запятой), есть имя рядом с адресом или нет домена, этот человек не получит сообщения, и JeffWrite сообщит их количество. Длинная тема сохраняется по частям, которые почтовые программы собирают обратно.

Во время слияния показывается окно хода выполнения, а кнопка **Отмена** останавливает его. Если правило задаёт вопрос (Запрос или Ввод данных), вам задаётся каждый разный вопрос один раз, до 20 вопросов. После этого остальные используют ответы по умолчанию. Если вы отмените вопрос, всё слияние остановится. Слияние останавливается и сообщает об этом, если получилось бы более 10 000 страниц, чтобы очень длинный документ с очень длинным списком не занимал часы. Вместо этого сливайте часть списка за раз.

## Конверты

Нажмите **Рассылки > Конверты**. Введите адрес получателя и свой обратный адрес и выберите размер конверта из списка. Размеры указаны шириной и высотой. Нажмите **Добавить в документ**, чтобы поместить конверт на отдельную страницу в начале документа, или **Печать**, чтобы напечатать его. Страница имеет ширину длинной стороны конверта, именно так большинство принтеров принимают конверты.

Чтобы создать конверты для слияния, нажмите **Начать слияние > Конверты**. В каждом конверте будет блок адреса.

## Наклейки

Нажмите **Рассылки > Наклейки**. Введите адрес и выберите лист из списка. Лист назван по количеству наклеек на нём и по размеру каждой наклейки. Если вашего листа нет в списке, выберите **Свой лист** и введите размеры: сколько наклеек в ряд и по вертикали, размер наклейки, расстояние сверху и сбоку до первой наклейки и расстояние между наклейками.

- **Полная страница одинаковых наклеек** помещает один и тот же адрес на каждую наклейку листа.
- **Одна наклейка** помещает адрес на одну наклейку, чтобы можно было использовать частично занятый лист. Укажите строку и столбец.

Нажмите **Новый документ**, чтобы создать документ, который можно просмотреть и изменить, или **Печать**, чтобы напечатать его.

Чтобы создать наклейки для слияния, нажмите **Начать слияние > Наклейки**. На первой наклейке будет блок адреса, а каждая следующая начинается с правила **Следующая запись**. Если вы измените первую наклейку, нажмите **Обновить наклейки**, чтобы скопировать изменение на все остальные.

## Что хранит файл

Вид слияния, имя и место списка, тема и столбец адресов эл. почты сохраняются в вашем файле .docx. Какие люди исключены из списка и выбор «Сопоставить поля» не сохраняются, их нужно указать заново после открытия файла. Список каждый раз читается заново из своего файла. Если файл находится не там, где был, JeffWrite ищет его рядом с документом, а затем просит вас выбрать его.

Список может содержать до 1 000 столбцов и 4 000 000 ячеек всего; слияние использует первые 100 000 человек. Если в файле больше, JeffWrite использует то, что помещается, и сообщает об этом. Строки без данных из списка исключаются.
