# Создание указателя

<!-- keywords: указатель, отметить элемент, отметить все, подэлемент, перекрёстная ссылка, см, поле XE, INDEX, диапазон страниц, номер страницы полужирным, столбцы, в строку, заголовки по буквам, Alt+Shift+X, обновить указатель, индекс, предметный указатель -->

**Указатель** — это алфавитный список слов и понятий с номерами страниц, на которых они встречаются. Сначала вы **отмечаете** слова, которые должны войти в указатель, а затем **вставляете** сам указатель.

## Отметить элемент

1. Выделите слово или слова, которые нужно включить в указатель, или щёлкните место, на которое должен указывать элемент.
2. Нажмите **Ссылки > Отметить элемент** или сочетание клавиш **Alt+Shift+X**.
3. Проверьте **Основной элемент**. Если у элемента есть часть, которая относится к нему, введите **Подэлемент**. Например, основной элемент `Яблоки` с подэлементом `Фуджи`.
4. Выберите, что будет показывать номер страницы:
   - **Текущая страница** — выводится страница, на которой находится метка.
   - **Диапазон страниц** — указываются страницы, которые охватывает закладка, например 5–7.
   - **Перекрёстная ссылка** — вместо страницы выводятся слова, например «См. Фрукты».
5. Включите **Полужирный номер страницы** или **Курсивный номер страницы**, если номер должен выделяться.
6. Нажмите **Отметить**, чтобы отметить только это место, или **Отметить все**, чтобы отметить все места, где встречаются те же слова (с теми же прописными буквами).

Метка представляет собой скрытое **поле элемента указателя** (поле XE). На странице оно ничего не показывает.

## Вставить указатель

1. Щёлкните место, где должен располагаться указатель.
2. Нажмите **Ссылки > Вставить указатель**.
3. Выберите оформление: **С отступами** выводит каждый подэлемент на отдельной строке, а **В строку** — выводит подэлементы после элемента, в одну строку. Укажите, нужно ли **выравнивать номера страниц по правому краю**, выбрать заполнитель табуляции и нужно ли выводить букву в качестве заголовка каждой группы.
4. Нажмите **ОК**.

Элементы указателя выводятся в алфавитном порядке. Номера страниц одного элемента выводятся по одному разу каждый, по порядку страниц, через запятую.

## Поддерживать указатель в актуальном состоянии

Щёлкните в указателе и нажмите **Ссылки > Обновить указатель** или клавишу **F9**. Добавленные вами метки будут включены в указатель, удалённые метки исчезнут, а номера страниц будут вычислены заново.
