# Безопасность: к чему может обращаться файл

Файл может ссылаться на другие объекты: файлы, веб-страницы, видео, даже программы. На странице **Безопасность** вы решаете, как JeffWrite поступает в таких случаях. Выберите **Файл > Параметры**, затем вкладку **Безопасность**. Нажмите **ОК**, чтобы сохранить изменения, или **Отмена**, чтобы отказаться от них.

Эти параметры относятся ко всем приложениям JeffOffice: если изменить один из них в одном приложении, он изменится во всех остальных. Строка для того, чего в приложении нет, имеет надпись **Не применяется** и выделена серым.

## Макросы

Макросы — это небольшие программы, хранящиеся внутри файла. JeffWrite сохраняет их в файле, поэтому они остаются на месте при сохранении, но программа **никогда их не запускает**. Нет параметра, который бы их запускал.

## Связанные файлы и связи с книгами

В JeffWrite это не применяется: здесь нет связанных файлов, которые нужно обновлять. Строка выделена серым.

## Связанные видео и звуки

В JeffWrite это не применяется: здесь нет связанных видео или звуков для воспроизведения. Строка выделена серым.

## Файлы из интернета или с других компьютеров

Файл, который вы загрузили или который находится на другом компьютере вашей сети, может быть небезопасным. Этот параметр определяет, как JeffWrite его открывает.

- **Сначала открывать только для чтения** — обычный выбор. Файл открывается для чтения, но изменить его нельзя. Под файлом появится полоса с соответствующим уведомлением. Нажмите **Включить редактирование** на этой полосе, чтобы изменить только этот файл (до закрытия программы). Когда вы затем сохраните его на прежнем месте, метка загрузки снимается с файла. Или используйте **Сохранить как**, чтобы создать копию, либо переключите этот параметр на следующий вариант.
- **Открывать обычным образом** — все файлы открываются одинаково.

Файл, который вы открываете командами **Открыть копию**, **Открыть и восстановить** или **Открыть только для чтения** на экране **Файл**, открывается указанным способом независимо от этого параметра.

## Связи, которые запускают программы

Связь, которая запустила бы программу или сценарий (файл с расширением .exe, .bat, .sh и т. п.), **всегда отклоняется**. JeffWrite сообщает об этом, и ничего не запускается. Связь с файлом на другом компьютере никогда не открывается без вашего запроса. Никакой параметр этого не меняет.
