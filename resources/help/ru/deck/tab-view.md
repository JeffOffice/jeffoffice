# Вкладка «Вид»
<!-- keywords: полноэкранный режим, f11, вкладка вид, лента, образец слайдов, режимы образцов, обычный, режим структуры, сортировщик слайдов, страница заметок, режим чтения, линейка, сетка, направляющие, заметки, масштаб, по размеру окна, режимы просмотра презентации, вид, окно, новое окно, переключить окна, несколько окон -->

Вкладка **Вид** меняет то, как слайды выглядят на экране во время работы. Эти параметры не изменяют сами слайды.

- **Режимы просмотра презентации** переключают между режимами **Обычный**, **Режим структуры** и **Сортировщик слайдов**. См. [Режим структуры, Сортировщик слайдов и режим образца слайдов](views).
- **Режимы образцов** содержит кнопку **Образец слайдов**, которая открывает режим образца слайдов для изменения образцов слайдов и макетов.
- **Показ** содержит флажки **Линейка**, **Сетка** и **Направляющие** для слайда, а также кнопку **Заметки**, которая показывает или скрывает поле заметок. См. [Заметки докладчика](notes).
- **Масштаб** содержит меню **Масштаб** от 400% до 10% и кнопку **По размеру окна**, которая подгоняет слайд под размер окна. См. [Навигация по окну](window).
- **Окно** содержит кнопку **Полноэкранный режим** (F11), которая разворачивает окно на весь экран; чтобы вернуться, нажмите **F11** или **Esc** (сначала **Esc** снимает выделение с выбранного объекта или прекращает ввод текста). Там же есть кнопка **Новое окно**, которая открывает файл презентации во втором окне (у презентации, которая ещё не сохранена в файл, откроется новое пустое окно), и кнопка **Переключить окна**, которая показывает список открытых окон, чтобы можно было выбрать нужное. Пример: изменение, сделанное в одном окне, появится в другом, если после сохранения открыть файл в нём заново.
