# Безопасность: к чему может обращаться файл

<!-- keywords: центр управления безопасностью, безопасность, макросы, связанные файлы, связи, связанные рисунки, связанные мультимедиа, интернет, загруженные, только для чтения, защищённые, внешние связи, программы, безопасно, доверие, безопасность файлов -->

Файл может ссылаться на другие объекты: файлы, веб-страницы, видео, даже программы. На странице **Безопасность** вы решаете, как JeffDeck с ними поступает. Нажмите **Файл > Параметры**, затем вкладку **Безопасность**. Нажмите **ОК**, чтобы сохранить изменения, или **Отмена**, чтобы отказаться от них.

Эти параметры общие для всех приложений JeffOffice: если изменить один из них в одном приложении, он изменится во всех. Строка для того, чего в приложении нет, пишет **Не применяется** и отображается серым.

## Макросы

Макросы — это небольшие программы, которые хранятся внутри файла. JeffDeck сохраняет их в файле, поэтому они остаются на месте при сохранении, и он **никогда не запускает их**. Нет параметра, который бы их запускал.

## Связанные файлы и связи с книгами

Этот пункт не применяется в JeffDeck: программа не работает со связанными файлами, которые нужно обновлять. Строка отображается серым.

## Связанные видео и звуки

Речь идёт о видео или звуке, на который слайд **ссылается**, а не о том, который хранится внутри презентации.

- **Никогда не воспроизводить** — обычный выбор. Связанное видео или звук помечается как связанный и не воспроизводится.
- **Спрашивать перед запуском** запрашивает разрешение один раз для каждого связанного файла при первом воспроизведении.
- **Воспроизводить** проигрывает файл без запроса.

Даже при **Воспроизводить** проигрывается только видео- или звуковой файл, путь к которому указан на этом компьютере. Веб-адрес, файл на другом компьютере, программа, ссылка или специальный файл, а также файл, который на самом деле не является видео или звуком, никогда не воспроизводятся. Связанный файл может быть размером до 256 МБ. Файл читается в фоновом режиме не более 20 секунд, поэтому медленный диск не может заморозить JeffDeck. Сетевой диск, который выглядит как локальный (сетевой диск или папка в /Volumes или /mnt), читается как локальный файл, поэтому может работать медленно. При выборе **Спрашивать перед запуском** показ слайдов один раз, в момент начала, запрашивает разрешение на все связанные в нём файлы.

## Файлы из интернета или с других компьютеров

Загруженный файл или файл, находящийся на другом компьютере в вашей сети, может быть небезопасным. Этот параметр определяет, как JeffDeck его открывает.

- **Открывать сначала только для чтения** — обычный выбор. Файл открывается для просмотра, но изменить его нельзя. Под файлом появляется полоса, которая сообщает об этом. Нажмите **Включить редактирование** на полосе, чтобы изменять именно этот файл (до закрытия программы). Если затем сохранить его на месте, отметка загрузки с файла снимается. Также можно использовать **Сохранить как**, чтобы создать копию, или выбрать следующий вариант этого параметра.
- **Открывать обычным образом** — все файлы открываются одинаково.

Файл, который вы открываете командами **Открыть как копию**, **Открыть и восстановить** или **Открыть только для чтения** на экране **Файл**, открывается так независимо от этого параметра.

## Ссылки, которые запускают программу

Ссылка, которая запустила бы программу или сценарий (файл с расширением .exe, .bat, .sh и т. п.), **всегда отклоняется**. JeffDeck сообщает об этом, и ничего не запускается. Ссылка на файл на другом компьютере никогда не открывается без вашего разрешения. Этот порядок не меняется ни одним параметром.
