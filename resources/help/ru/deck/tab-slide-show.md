# Вкладка «Показ слайдов»

Вкладка **Показ слайдов** запускает показ и настраивает его.

- В группе **Начать показ слайдов** есть команды **С начала** (F5) и **С текущего слайда** (Shift+F5). Команда **Произвольный показ** показывает ваши произвольные показы по именам, поэтому любой из них можно запустить. Команда **Произвольные показы** создаёт, изменяет, копирует и удаляет их.
- В группе **Настройка** есть команда **Настройка показа слайдов**: она задаёт вид показа, какие слайды будут показаны, зацикливание и способ перехода к следующему слайду. Команда **Скрыть слайд** исключает текущий слайд из показа. Команда **Репетиция времени показа** запускает показ и записывает, сколько времени вы тратите на каждый слайд. Флажок **Использовать время показа** делает так, что показ переходит к следующему слайду сам, по истечении времени, заданного для слайда.
- В группе **Мониторы** есть флажок **Использовать режим докладчика** для случая, когда у вас два экрана, и команда **Режим докладчика** (Alt+F5), которая открывает показ в небольшом окне, а режим докладчика — рядом с ним, так что репетицию можно провести на одном экране.

Во время показа нажмите Ctrl+P для пера, Ctrl+I для маркера, Ctrl+L для лазерной указки и Ctrl+E для ластика. Чтобы вернуть стрелку, нажмите Ctrl+A или Esc.

См. также [Воспроизведение показа и использование режима докладчика](show).
