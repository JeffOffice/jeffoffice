# Вкладка «Показ слайдов»

На вкладке **Показ слайдов** запускается показ и настраивается его работа.

- **Начать показ слайдов** содержит команды **С начала** (F5) и **С текущего слайда** (Shift+F5). **Произвольный показ слайдов** показывает ваши произвольные показы по именам, так что любой из них можно воспроизвести. Команда **Произвольные показы** создаёт, изменяет, копирует и удаляет их.
- **Настройка** содержит команду **Настройка показа слайдов**, в которой выбираются вид показа, какие слайды будут показаны, нужно ли повторять показ по кругу и как происходит переход к следующему слайду. Команда **Скрыть слайд** исключает текущий слайд из показа. **Репетиция времени** воспроизводит показ и записывает, сколько времени вы проводите на каждом слайде. Флажок **Использовать время показа** включает автоматический переход к следующему слайду по истечении заданного для него времени.
- **Мониторы** содержит флажок **Использовать режим докладчика** (на случай, если у вас два экрана), список **Показ презентации на**, в котором выбирается экран для показа слайдов (Авто или экран по его имени и размеру), и команду **Режим докладчика** (Alt+F5), которая открывает показ в небольшом окне с режимом докладчика рядом, чтобы вы могли провести репетицию на одном экране.

Во время показа нажмите Ctrl+P для пера, Ctrl+I для маркера, Ctrl+L для лазерной указки и Ctrl+E для ластика. Чтобы вернуть стрелку, нажмите Ctrl+A или Esc.

См. [Воспроизведение показа слайдов и использование режима докладчика](show).
