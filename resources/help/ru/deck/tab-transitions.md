# Вкладка «Переходы»
<!-- keywords: вкладка переходы, лента, предпросмотр, переход к этому слайду, параметры эффекта, длительность, по щелчку мыши, после, применить ко всем, морфинг, объекты, слова, символы, появление, выталкивание, шторка, разделение, проявление, наложение, открытие, масштаб, вырезание -->

На вкладке **Переходы** задаётся, как показ слайдов переходит на текущий слайд.

- **Предпросмотр** содержит кнопку **Предпросмотр**, которая воспроизводит переход к слайду, чтобы вы могли его увидеть.
- **Переход к этому слайду** — это коллекция эффектов: **Нет**, **Морфинг**, **Появление**, **Выталкивание**, **Шторка**, **Разделение**, **Проявление**, **Наложение**, **Открытие**, **Масштаб** и **Вырезание**. **Параметры эффекта** задают направление или **Наружу** и **Внутрь** для тех эффектов, где они есть. Для **Морфинга** выбирается **Объекты**, **Слова** или **Символы**.
- **Время показа** содержит **Длительность**, **По щелчку мыши**, **Через** с количеством секунд и **Применить ко всем**. Морфинг при выборе длится 2 секунды. Остальные эффекты длятся 0,7 секунды.

См. [Переходы между слайдами](transitions).
