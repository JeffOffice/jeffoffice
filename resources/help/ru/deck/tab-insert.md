# Вкладка «Вставка»
<!-- keywords: вкладка вставка, лента, новый слайд, таблица, рисунки, изображения, изображения из интернета, с этого устройства, фигуры, иллюстрации, значки, штрихкод, QR-код, текстовое поле, художественный текст, колонтитулы, дата и время, ссылка, гиперссылка, символ, мультимедиа, видео, аудио, фильм, звук -->

На вкладке **Вставка** добавляются объекты в вашу презентацию.

- Группа **Слайды** содержит кнопку **Создать слайд**. См. раздел [Добавление, изменение и удаление слайдов](slides).
- Группа **Таблицы** содержит кнопку **Таблица**, которая открывает сетку для выбора числа строк и столбцов, и команду **Вставить таблицу…**. См. раздел [Фигуры, рисунки, таблицы и художественный текст](objects).
- Группа **Изображения** содержит кнопку **Рисунок**. Щёлкните её основную часть, чтобы добавить файлы рисунков с компьютера. Щёлкните её стрелку, чтобы выбрать **С этого устройства…** (то же самое) или **Изображения из Интернета…**, которая находит бесплатные рисунки в сети. См. раздел [Фигуры, рисунки, таблицы и художественный текст](objects).
- Группа **Иллюстрации** содержит **Фигуры**, галерею линий, стрелок и фигур для рисования, **Значки**, набор простых рисунков для поиска и вставки, и **Штрихкод**, который создаёт QR-код или штрихкод другого типа. См. раздел [Фигуры, рисунки, таблицы и художественный текст](objects).
- Группа **Текст** содержит **Текстовое поле**, **Колонтитулы**, **Художественный текст**, то есть галерею стилей для оформленных надписей, и **Дата и время**. Художественный текст описан в разделе «Фигуры, рисунки, таблицы и художественный текст», который указан ниже в разделе «Связанные темы». См. также разделы [Форматирование текста](text) и [Размер слайда, фон и колонтитулы](design).
- Группа **Связи** содержит **Ссылка** (Ctrl+K), которая связывает текст или объект с веб-страницей, местом в презентации или адресом эл. почты. См. раздел [Форматирование текста](text).
- Группа **Символы** содержит **Символ** для знаков, которых нет на клавиатуре. См. раздел [Форматирование текста](text).
- Группа **Мультимедиа** содержит **Видео** и **Аудио**. Каждая кнопка открывает меню с командами **Видео с этого устройства…** или **Аудио с этого устройства…**, которые помещают фильм или звук из файла на слайд. После выбора объекта вкладка **Воспроизведение** задаёт способ его воспроизведения.
