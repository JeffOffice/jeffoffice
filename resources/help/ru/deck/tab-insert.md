# Вкладка «Вставка»
<!-- keywords: вставка, вкладка вставка, лента, новый слайд, таблица, рисунки, изображения, изображения из интернета, с этого устройства, фигуры, иллюстрации, значки, штрихкод, QR-код, уравнение, формула, математика, текстовое поле, художественный текст, колонтитулы, дата и время, ссылка, гиперссылка, символ, мультимедиа, видео, аудио, фильм, звук -->

Вкладка **«Вставка»** добавляет в презентацию различные объекты.

- В группе **«Слайды»** есть кнопка **«Создать слайд»**. См. раздел [Добавление, изменение и удаление слайдов](slides).
- В группе **«Таблицы»** есть кнопка **«Таблица»**, которая открывает сетку для выбора числа строк и столбцов, и пункт **«Вставить таблицу…»**. См. раздел [Фигуры, рисунки, таблицы и художественный текст](objects).
- В группе **«Изображения»** есть кнопка **«Рисунки»**. Щелкните её основную часть, чтобы добавить файлы рисунков с вашего компьютера. Щелкните её стрелку, чтобы выбрать пункт **«С этого устройства…»** (то же самое) или **«Изображения из Интернета…»**, с помощью которого можно найти бесплатные рисунки в сети. См. раздел [Фигуры, рисунки, таблицы и художественный текст](objects).
- В группе **«Иллюстрации»** есть коллекция **«Фигуры»** с линиями, стрелками и фигурами для рисования, кнопка **«Значки»** с набором простых рисунков для поиска и вставки и кнопка **«Штрихкод»**, которая создаёт QR-код или штрихкод другого типа. См. раздел [Фигуры, рисунки, таблицы и художественный текст](objects).
- В группе **«Текст»** есть **«Текстовое поле»**, **«Колонтитулы»**, **«Художественный текст»** (коллекция стилей для необычного оформления слов), **«Номер слайда»** и **«Дата и время»**. Художественный текст описан в разделе «Фигуры, рисунки, таблицы и художественный текст», который указан ниже в разделе «См. также». См. разделы [Форматирование текста](text) и [Размер слайда, фон и колонтитулы](design).
- В группе **«Ссылки»** есть кнопка **«Ссылка»** (Ctrl+K), которая связывает текст или объект с веб-страницей, адресом эл. почты, местом в презентации, файлом, другой презентацией или новой презентацией, которую JeffDeck создаст для вас. См. раздел [Форматирование текста](text).
- В группе **«Символы»** есть **«Уравнение»**, которое оформляет математические выражения, введённые в строку, **«Встроенные уравнения»**, список известных формул для начала работы, и **«Символ»** для знаков, которых нет на клавиатуре. См. разделы [Формулы](equations) и [Форматирование текста](text).
- В группе **«Мультимедиа»** есть кнопки **«Видео»** и **«Аудио»**. Каждая открывает меню с пунктом **«Видео с этого устройства…»** или **«Аудио с этого устройства…»**, который помещает на слайд фильм или звук из файла. После выбора объекта вкладка **«Воспроизведение»** задаёт, как он будет воспроизводиться.
