# Работа с файлами .pub

<!-- keywords: pub, .pub, файл pub, открыть pub, сохранить pub, преобразование, совместимость, импорт, старые публикации, другие программы, jpub, формат, отсутствующие шрифты, резервная копия оригинала, формат файла -->

Файл .pub — это публикация, созданная в других программах для настольной издательской системы. JeffPub открывает файлы .pub, созданные начиная с 1998 года. Он также может сохранять вашу работу в файл .pub. Собственный формат JeffPub — .jpub.

## Открытие файла .pub

1. Нажмите Ctrl+O или выберите **Файл > Открыть**.
2. Нажмите **Обзор**, выберите файл .pub и нажмите **Открыть**.

Файл можно также перетащить на страницу. Текст, рисунки, фигуры и таблицы переносятся вместе со связанными текстовыми полями. Большинство страниц выглядит близко к оригиналу, но не каждая деталь пока совпадает. Некоторые текстовые поля могут заканчивать слово на одно-два слова раньше или позже, чем раньше.

Если какого-либо шрифта из файла нет на вашем компьютере, JeffPub использует похожий открытый шрифт. Шрифты, внедрённые в файл .pub, не переносятся. Если JeffPub нужно сообщить вам что-то после открытия, в строке состояния в нижней части окна появляется примечание.

Если файл не открывается, JeffPub сообщит, что он может быть повреждён или использует возможности, которые программа пока не может прочитать.

## Проверка результата

Открытие — это преобразование, поэтому просмотрите каждую страницу. Проверьте переносы строк, шрифты и рисунки. Используйте [Проверку дизайна](design-checker), чтобы найти текст, который не помещается.

## Сохранение в файл .pub

- Щелкните **Файл > Экспорт**, затем **Сохранить как файл .pub**.
- Или выберите **Файл > Сохранить как** и в поле **Тип файла** укажите **Файлы публикаций .pub (*.pub)**.

При сохранении в файл .pub JeffPub может записать страницы, текстовые поля и связанные текстовые поля, форматирование текста, фигуры, линии, рисунки, таблицы, заливки, тени, художественный текст, стили, буклеты, складные открытки, конверты, номера страниц и связи. Если какой-то объект не имеет формы в формате .pub, JeffPub сообщит, сколько объектов он пропустил. Эти объекты остаются в вашей публикации и сохраняются при сохранении в файл .jpub. Примечания тоже не имеют формы в формате .pub: JeffPub сообщит, что их пропустил, и они сохраняются только в файлах .jpub. Подробнее об этом рассказано в разделе справки «Примечания».

## Сохранение оригинала

Когда вы открываете файл .pub и нажимаете Ctrl+S, JeffPub записывает изменения в тот же файл .pub. Чтобы сохранить оригинал:

- Включите **Всегда создавать резервную копию** в **Файл > Параметры** на вкладке **Сохранение**. Тогда JeffPub будет сохранять прежний файл с названием «Резервная копия» и именем файла.
- Или выберите **Файл > Сохранить как** и сохраните файл .jpub. Файл .jpub сохраняет всё.

Храните исходные файлы, пока не убедитесь, что новые файлы правильные.
