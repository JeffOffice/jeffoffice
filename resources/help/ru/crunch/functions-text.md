# Текстовые функции
<!-- keywords: функции, ASC, BAHTTEXT, CHAR, CLEAN, CODE, CONCAT, CONCATENATE, DBCS, DOLLAR, ENCODEURL, EXACT, FILTERXML, FIND, FINDB, FIXED, LEFT, LEFTB, LEN, LENB, LOWER, MID, MIDB, NUMBERVALUE, PHONETIC, PROPER, REPLACE, REPLACEB, REPT, RIGHT, RIGHTB, SEARCH, SEARCHB, SUBSTITUTE, T, TEXT, TEXTJOIN, TRIM, UNICHAR, UNICODE, UPPER, VALUE, текстовые функции, функции для текста, функции работы с текстом -->

Это текстовые функции, которые может вычислять JeffCrunch. Каждая из них показывает, как она записывается, что делает и что означает каждый её аргумент. Аргумент в квадратных скобках необязателен, а «...» означает, что можно добавить сколько угодно таких же аргументов после последнего. Чтобы попробовать функцию, см. раздел [Выбор функции](insert-function). Пока вы вводите функцию в ячейке, под ячейкой появляется небольшая подсказка с её аргументами; щелчок по имени функции в подсказке открывает её описание на этой странице.

## ASC

`ASC(текст)`

Заменяет полноширинные буквы и цифры в тексте на обычные (полуширинные).

- `текст`: Текст для обработки или ячейка, которая его содержит.

## BAHTTEXT

`BAHTTEXT(число)`

Записывает число тайскими словами с обозначением бата.

- `число`: Число для обработки.

## CHAR

`CHAR(число)`

Возвращает знак, которому соответствует код.

- `число`: Число для обработки.

## CLEAN

`CLEAN(текст)`

Удаляет из текста знаки, которые не печатаются.

- `текст`: Текст для обработки или ячейка, которая его содержит.

## CODE

`CODE(текст)`

Возвращает код первого знака текста.

- `текст`: Текст для обработки или ячейка, которая его содержит.

## CONCAT

`CONCAT(текст1, ...)`

Объединяет тексты и тексты из блоков ячеек в один.

- `текст1`: Первый текст или блок ячеек с текстом.
- `...`: Сколько угодно дополнительных аргументов того же вида, что и предыдущий.

## CONCATENATE

`CONCATENATE(текст1, ...)`

Объединяет тексты в один.

- `текст1`: Первый текст или блок ячеек с текстом.
- `...`: Сколько угодно дополнительных аргументов того же вида, что и предыдущий.

## DBCS

`DBCS(текст)`

Заменяет полуширинные буквы и цифры в тексте на полноширинные.

- `текст`: Текст для обработки или ячейка, которая его содержит.

## DOLLAR

`DOLLAR(число, [знаки])`

Преобразует число в текст в виде денежной суммы.

- `число`: Число для обработки.
- `знаки` (необязательный): Сколько знаков оставить после десятичного разделителя.

## ENCODEURL

`ENCODEURL(текст)`

Преобразует текст так, чтобы его можно было использовать в веб-адресе.

- `текст`: Текст для обработки или ячейка, которая его содержит.

## EXACT

`EXACT(текст1, текст2)`

ИСТИНА, если два текста полностью совпадают, включая заглавные буквы.

- `текст1`: Первый текст или блок ячеек с текстом.
- `текст2`: Второй текст.

## FILTERXML

`FILTERXML(xml, xpath)`

Извлекает значения из текста, содержащего XML, с помощью выражения XPath.

- `xml`: Текст, содержащий XML.
- `xpath`: Выражение XPath, которое указывает, какие части нужно вернуть, например //item/price.

## FIND

`FIND(искомый_текст, текст_для_поиска, [начальная_позиция])`

Возвращает место, с которого один текст начинается внутри другого, различая заглавные и строчные буквы.

- `искомый_текст`: Текст для поиска.
- `текст_для_поиска`: Текст, в котором выполняется поиск.
- `начальная_позиция` (необязательный): Место в тексте, с которого начать поиск; первый знак считается как 1.

## FINDB

`FINDB(искомый_текст, текст_для_поиска, [начальная_позиция])`

Возвращает место, где текст впервые появляется в другом тексте, различая заглавные и строчные буквы.

- `искомый_текст`: Текст для поиска.
- `текст_для_поиска`: Текст, в котором выполняется поиск.
- `начальная_позиция` (необязательный): Место в тексте, с которого начать поиск; первый знак считается как 1.

## FIXED

`FIXED(число, [знаки], [без_разделителей])`

Преобразует число в текст с заданным количеством знаков после запятой.

- `число`: Число для обработки.
- `знаки` (необязательный): Сколько знаков оставить после десятичного разделителя.
- `без_разделителей` (необязательный): ИСТИНА, чтобы не выводить запятые, отделяющие разряды тысяч.

## LEFT

`LEFT(текст, [количество_знаков])`

Возвращает первые знаки текста.

- `текст`: Текст для обработки или ячейка, которая его содержит.
- `количество_знаков` (необязательный): Сколько знаков взять (если не указано, то 1).

## LEFTB

`LEFTB(текст, [количество_знаков])`

Возвращает первые знаки текста.

- `текст`: Текст для обработки или ячейка, которая его содержит.
- `количество_знаков` (необязательный): Сколько знаков взять (если не указано, то 1).

## LEN

`LEN(текст)`

Подсчитывает знаки в тексте.

- `текст`: Текст для обработки или ячейка, которая его содержит.

## LENB

`LENB(текст)`

Возвращает количество знаков в тексте.

- `текст`: Текст для обработки или ячейка, которая его содержит.

## LOWER

`LOWER(текст)`

Преобразует текст в строчные буквы.

- `текст`: Текст для обработки или ячейка, которая его содержит.

## MID

`MID(текст, начальная_позиция, количество_знаков)`

Возвращает знаки из середины текста.

- `текст`: Текст для обработки или ячейка, которая его содержит.
- `начальная_позиция`: Место в тексте, с которого начать; первый знак считается как 1.
- `количество_знаков`: Сколько знаков взять (если не указано, то 1).

## MIDB

`MIDB(текст, начальная_позиция, количество_знаков)`

Возвращает знаки из середины текста.

- `текст`: Текст для обработки или ячейка, которая его содержит.
- `начальная_позиция`: Место в тексте, с которого начать; первый знак считается как 1.
- `количество_знаков`: Сколько знаков взять (если не указано, то 1).

## NUMBERVALUE

`NUMBERVALUE(текст, [десятичный_разделитель], [разделитель_групп])`

Читает текст как число с указанными разделителями.

- `текст`: Текст для обработки или ячейка, которая его содержит.
- `десятичный_разделитель` (необязательный): Знак, который отделяет дробную часть в тексте (если не указано, то точка).
- `разделитель_групп` (необязательный): Знак, который группирует цифры в тексте (если не указано, то запятая).

## PHONETIC

`PHONETIC(ссылка)`

Возвращает текст ячейки для чтений японского текста.

- `ссылка`: Ячейка или блок ячеек.

## PROPER

`PROPER(текст)`

Делает первую букву каждого слова текста заглавной.

- `текст`: Текст для обработки или ячейка, которая его содержит.

## REPLACE

`REPLACE(старый_текст, начальная_позиция, количество_знаков, новый_текст)`

Заменяет знаки текста новым текстом.

- `старый_текст`: Текст для изменения.
- `начальная_позиция`: Место в тексте, с которого начать; первый знак считается как 1.
- `количество_знаков`: Сколько знаков взять (если не указано, то 1).
- `новый_текст`: Текст для вставки.

## REPLACEB

`REPLACEB(старый_текст, начальная_позиция, количество_знаков, новый_текст)`

Заменяет часть текста другим текстом.

- `старый_текст`: Текст для изменения.
- `начальная_позиция`: Место в тексте, с которого начать; первый знак считается как 1.
- `количество_знаков`: Сколько знаков взять (если не указано, то 1).
- `новый_текст`: Текст для вставки.

## REPT

`REPT(текст, количество_повторов)`

Повторяет текст заданное количество раз.

- `текст`: Текст для обработки или ячейка, которая его содержит.
- `количество_повторов`: Сколько раз повторить текст.

## RIGHT

`RIGHT(текст, [количество_знаков])`

Возвращает последние знаки текста.

- `текст`: Текст для обработки или ячейка, которая его содержит.
- `количество_знаков` (необязательный): Сколько знаков взять (если не указано, то 1).

## RIGHTB

`RIGHTB(текст, [количество_знаков])`

Возвращает последние знаки текста.

- `текст`: Текст для обработки или ячейка, которая его содержит.
- `количество_знаков` (необязательный): Сколько знаков взять (если не указано, то 1).

## SEARCH

`SEARCH(искомый_текст, текст_для_поиска, [начальная_позиция])`

Возвращает место, с которого один текст начинается внутри другого, не учитывая регистр и допуская ? и * в искомом тексте.

- `искомый_текст`: Текст для поиска.
- `текст_для_поиска`: Текст, в котором выполняется поиск.
- `начальная_позиция` (необязательный): Место в тексте, с которого начать поиск; первый знак считается как 1.

## SEARCHB

`SEARCHB(искомый_текст, текст_для_поиска, [начальная_позиция])`

Возвращает место, где текст впервые появляется в другом тексте, не учитывая регистр.

- `искомый_текст`: Текст для поиска.
- `текст_для_поиска`: Текст, в котором выполняется поиск.
- `начальная_позиция` (необязательный): Место в тексте, с которого начать поиск; первый знак считается как 1.

## SUBSTITUTE

`SUBSTITUTE(текст, старый_текст, новый_текст, [номер_вхождения])`

Заменяет один фрагмент текста другим везде, где он встречается.

- `текст`: Текст для обработки или ячейка, которая его содержит.
- `старый_текст`: Текст для поиска.
- `новый_текст`: Текст для вставки.
- `номер_вхождения` (необязательный): Какое совпадение заменить (если не указано, то все).

## T

`T(значение)`

Возвращает сам текст и пустое значение для всего, что текстом не является.

- `значение`: Значение для обработки или ячейка, которая его содержит.

## TEXT

`TEXT(значение, текст_формата)`

Преобразует число в текст в заданном формате.

- `значение`: Значение для обработки или ячейка, которая его содержит.
- `текст_формата`: Числовой формат, в котором показать значение, например «0,00» или «дд.мм.гггг».

## TEXTJOIN

`TEXTJOIN(разделитель, пропускать_пустые, текст1, ...)`

Объединяет тексты, помещая между ними разделитель.

- `разделитель`: Текст, который нужно поместить между частями.
- `пропускать_пустые`: ИСТИНА, чтобы пропускать пустые части; ЛОЖЬ, чтобы сохранять их.
- `текст1`: Первый текст или блок ячеек с текстом.
- `...`: Сколько угодно дополнительных аргументов того же вида, что и предыдущий.

## TRIM

`TRIM(текст)`

Удаляет лишние пробелы из текста, оставляя один пробел между словами.

- `текст`: Текст для обработки или ячейка, которая его содержит.

## UNICHAR

- `число`: Число для обработки.

## UNICODE

- `текст`: Текст для обработки или ячейка, которая его содержит.

## UPPER

`UPPER(текст)`

Преобразует текст в прописные буквы.

- `текст`: Текст для обработки или ячейка, которая его содержит.

## VALUE

`VALUE(текст)`

Преобразует текст, похожий на число, в число.

- `текст`: Текст для обработки или ячейка, которая его содержит.
