# Функции поиска и ссылок
<!-- keywords: функции, ADDRESS, AREAS, COLUMN, COLUMNS, FILTER, FORMULATEXT, GETPIVOTDATA, HLOOKUP, HYPERLINK, INDEX, INDIRECT, LOOKUP, MATCH, OFFSET, ROW, ROWS, SORT, SORTBY, TRANSPOSE, UNIQUE, VLOOKUP, XLOOKUP, XMATCH -->

Это функции поиска и ссылок, которые может вычислять JeffCrunch. Для каждой показано, как она записывается, что делает и каков смысл каждого её аргумента. Аргумент в квадратных скобках необязателен, а «...» означает, что последнего аргумента можно указать сколько нужно раз. Чтобы попробовать одну из них, см. [Выбор функции](insert-function). Пока вы вводите функцию в ячейке, под ячейкой появляется небольшая подсказка с её аргументами, и щелчок по имени функции в подсказке открывает её описание здесь.

## ADDRESS

`ADDRESS(row_num, column_num, [abs_num], [a1], [sheet_text])`

Записывает адрес ячейки в виде текста по её номерам строки и столбца.

- `row_num`: Номер строки в блоке, при этом первая строка считается как 1.
- `column_num`: Номер столбца в блоке, при этом первый столбец считается как 1.
- `abs_num` (необязательный): Насколько адрес закреплён: 1 — полностью, 2 — только строка, 3 — только столбец, 4 — ничего не закреплено.
- `a1` (необязательный): «Истина» или не указано — читать адрес как букву столбца и номер строки; «ложь» — читать как номера строки и столбца.
- `sheet_text` (необязательный): Имя листа, которое нужно поставить перед адресом.

## AREAS

`AREAS(reference)`

Даёт количество отдельных блоков ячеек в ссылке.

- `reference`: Ячейка или блок ячеек.

## COLUMN

`COLUMN([reference])`

Возвращает номер столбца ячейки.

- `reference` (необязательный): Ячейка или блок ячеек.

## COLUMNS

`COLUMNS(array)`

Подсчитывает количество столбцов в блоке ячеек.

- `array`: Блок ячеек или список значений, записанный в фигурных скобках.

## FILTER

`FILTER(array, include, [if_empty])`

Возвращает строки или столбцы блока, которые проходят проверку.

- `array`: Блок ячеек или список значений, записанный в фигурных скобках.
- `include`: Столбец или строка значений «истина» и «ложь», по одному для каждой строки или столбца блока: «истина» оставляет его.
- `if_empty` (необязательный): Что вывести, если ни одна строка или столбец не прошли проверку (ошибка #ВЫЧИСЛ!, если не указано).

## FORMULATEXT

`FORMULATEXT(reference)`

Возвращает формулу ячейки в виде текста.

- `reference`: Ячейка или блок ячеек.

## GETPIVOTDATA

`GETPIVOTDATA(data_field, pivot_table, [field1], [item1], ...)`

Возвращает значение, которое сводная таблица показывает для значения и элементов её строк и столбцов. Ячейка таблицы указывается вторым аргументом; названные поля должны быть первыми полями строк или столбцов.

- `data_field`: Имя значения, которое нужно получить, в кавычках, как его показывает сводная таблица («Sum of Amount»).
- `pivot_table`: Любая ячейка сводной таблицы.
- `field1` (необязательный): Имя поля строк или столбцов в кавычках (можно не указывать вместе с элементом).
- `item1` (необязательный): Элемент этого поля, для которого нужно получить значение, в кавычках.
- `...`: Сколько угодно дополнительных аргументов того же вида, что и предыдущий.

## HLOOKUP

`HLOOKUP(lookup_value, table_array, row_index_num, [range_lookup])`

Ищет значение в первой строке таблицы и возвращает значение из того же столбца.

- `lookup_value`: Значение для поиска.
- `table_array`: Блок ячеек, в котором выполняется поиск; искомое значение должно находиться в первой строке блока.
- `row_index_num`: Номер строки таблицы, из которой нужно взять значение, при этом первая строка считается как 1.
- `range_lookup` (необязательный): «Ложь» находит точное совпадение; «истина» или не указано — ближайшее меньшее значение (первая строка должна быть отсортирована по возрастанию).

## HYPERLINK

`HYPERLINK(link_location, [friendly_name])`

Создаёт ячейку, которая открывает ссылку при щелчке.

- `link_location`: Куда ведёт ссылка: веб-адрес, файл или место в этой книге.
- `friendly_name` (необязательный): Текст, который показывается в ячейке (сама ссылка, если не указано).

## INDEX

`INDEX(array, row_num, [column_num], [area_num])`

Возвращает значение на пересечении строки и столбца блока ячеек.

- `array`: Блок ячеек или список значений, записанный в фигурных скобках.
- `row_num`: Номер строки в блоке, при этом первая строка считается как 1.
- `column_num` (необязательный): Номер столбца в блоке, при этом первый столбец считается как 1.
- `area_num` (необязательный): Какой блок использовать, если первый аргумент задаёт несколько блоков (1 — для первого).

## INDIRECT

`INDIRECT(ref_text, [a1])`

Возвращает ячейку, на которую указывает адрес, записанный в виде текста.

- `ref_text`: Адрес, записанный в виде текста, например «B5».
- `a1` (необязательный): «Истина» или не указано — читать адрес как букву столбца и номер строки; «ложь» — читать как номера строки и столбца.

## LOOKUP

`LOOKUP(lookup_value, lookup_vector, [result_vector])`

Ищет значение в одной строке или одном столбце и возвращает значение с того же места в другом.

- `lookup_value`: Значение для поиска.
- `lookup_vector`: Одна строка или один столбец ячеек, в котором выполняется поиск.
- `result_vector` (необязательный): Одна строка или один столбец ячеек, из которого берётся результат.

## MATCH

`MATCH(lookup_value, lookup_array, [match_type])`

Возвращает место значения в списке.

- `lookup_value`: Значение для поиска.
- `lookup_array`: Блок ячеек, одна строка или один столбец, в котором выполняется поиск.
- `match_type` (необязательный): 1 или не указано — находит наибольшее значение, не превышающее искомое (список должен быть отсортирован по возрастанию); 0 — находит точное совпадение; -1 — находит наименьшее значение, не меньшее искомого (список должен быть отсортирован по убыванию).

## OFFSET

`OFFSET(reference, rows, cols, [height], [width])`

Возвращает ячейки, отстоящие на заданное количество строк и столбцов от начальной ячейки.

- `reference`: Ячейка или блок ячеек.
- `rows`: На сколько строк сместиться: положительное число — вниз, отрицательное — вверх.
- `cols`: На сколько столбцов сместиться: положительное число — вправо, отрицательное — влево.
- `height` (необязательный): Высота результата в строках.
- `width` (необязательный): Ширина результата в столбцах.

## ROW

`ROW([reference])`

Возвращает номер строки ячейки.

- `reference` (необязательный): Ячейка или блок ячеек.

## ROWS

`ROWS(array)`

Подсчитывает количество строк в блоке ячеек.

- `array`: Блок ячеек или список значений, записанный в фигурных скобках.

## SORT

`SORT(array, [sort_index], [sort_order], [by_col])`

Возвращает блок с отсортированными строками или столбцами.

- `array`: Блок ячеек или список значений, записанный в фигурных скобках.
- `sort_index` (необязательный): Номер столбца (или строки), по которому выполняется сортировка (1, если не указано).
- `sort_order` (необязательный): 1 или не указано — по возрастанию; -1 — по убыванию.
- `by_col` (необязательный): «Истина» — сортировать столбцы; «ложь» или не указано — сортировать строки.

## SORTBY

`SORTBY(array, by_array1, [sort_order1], ...)`

Возвращает блок, упорядоченный по одному или нескольким другим блокам.

- `array`: Блок ячеек или список значений, записанный в фигурных скобках.
- `by_array1`: Блок ячеек, по порядку которого нужно упорядочить первый блок; его длина должна совпадать с длиной первого блока.
- `sort_order1` (необязательный): 1 или не указано — по возрастанию; -1 — по убыванию.
- `...`: Сколько угодно дополнительных аргументов того же вида, что и предыдущий.

## TRANSPOSE

`TRANSPOSE(array)`

Меняет строки на столбцы, а столбцы на строки.

- `array`: Блок ячеек или список значений, записанный в фигурных скобках.

## UNIQUE

`UNIQUE(array, [by_col], [exactly_once])`

Возвращает различные строки или столбцы блока.

- `array`: Блок ячеек или список значений, записанный в фигурных скобках.
- `by_col` (необязательный): «Истина» — работать со столбцами; «ложь» или не указано — работать со строками.
- `exactly_once` (необязательный): «Истина» — вывести только те элементы, которые встречаются один раз; «ложь» или не указано — вывести каждый различный элемент.

## VLOOKUP

`VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])`

Ищет значение в первом столбце таблицы и возвращает значение из той же строки.

- `lookup_value`: Значение для поиска.
- `table_array`: Блок ячеек, в котором выполняется поиск; искомое значение должно находиться в первом столбце блока.
- `col_index_num`: Номер столбца таблицы, из которого нужно взять значение, при этом первый столбец считается как 1.
- `range_lookup` (необязательный): «Ложь» находит точное совпадение; «истина» или не указано — ближайшее меньшее значение (первый столбец должен быть отсортирован по возрастанию).

## XLOOKUP

`XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])`

Ищет значение в списке и возвращает соответствующий элемент другого списка.

- `lookup_value`: Значение для поиска.
- `lookup_array`: Блок ячеек, одна строка или один столбец, в котором выполняется поиск.
- `return_array`: Блок ячеек, из которого берётся результат совпадения.
- `if_not_found` (необязательный): Что вывести, если совпадения нет (ошибка #Н/Д, если не указано).
- `match_mode` (необязательный): 0 или не указано — точное совпадение; -1 — следующее меньшее значение; 1 — следующее большее значение; 2 — поиск с использованием подстановочных знаков.
- `search_mode` (необязательный): 1 или не указано — поиск с первого элемента; -1 — с последнего; 2 или -2 — двоичный поиск по отсортированному списку.

## XMATCH

`XMATCH(lookup_value, lookup_array, [match_mode], [search_mode])`

Возвращает место значения в списке с возможностью выбрать способ сопоставления и направление поиска.

- `lookup_value`: Значение для поиска.
- `lookup_array`: Блок ячеек, одна строка или один столбец, в котором выполняется поиск.
- `match_mode` (необязательный): 0 или не указано — точное совпадение; -1 — следующее меньшее значение; 1 — следующее большее значение; 2 — поиск с использованием подстановочных знаков.
- `search_mode` (необязательный): 1 или не указано — поиск с первого элемента; -1 — с последнего; 2 или -2 — двоичный поиск по отсортированному списку.
