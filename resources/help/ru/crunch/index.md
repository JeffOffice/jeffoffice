# Справка JeffCrunch
<!-- keywords: содержание, справка, разделы, начало, помощь, оглавление -->

Введите текст в поле поиска вверху, чтобы найти раздел или команду для выполнения. В любой момент нажмите **F1**, чтобы получить справку по тому, что вы делаете: по вкладке ленты или по странице экрана «Файл», на которой вы находитесь.
