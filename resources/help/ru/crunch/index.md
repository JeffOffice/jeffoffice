# JeffCrunch: справка
<!-- keywords: содержание, справка, разделы, начало, оглавление, помощь -->

Введите текст в поле поиска вверху, чтобы найти раздел или команду для выполнения. В любой момент нажмите **F1**, чтобы получить справку по тому, что вы делаете: по вкладке ленты, на которой вы находитесь, или по странице «Файл», которую вы открыли.
