# Функции баз данных
<!-- keywords: functions, DAVERAGE, DCOUNT, DCOUNTA, DGET, DMAX, DMIN, DPRODUCT, DSTDEV, DSTDEVP, DSUM, DVAR, DVARP -->

Это функции баз данных, которые может вычислять JeffCrunch. Для каждой показано, как она записывается, что она делает и что означает каждый её аргумент. Аргумент в квадратных скобках необязательный, а «...» означает, что можно указать сколько угодно дополнительных аргументов последнего типа. Чтобы попробовать функцию, см. раздел [Выбрать функцию](insert-function). Пока вы вводите функцию в ячейку, под ячейкой появляется небольшая подсказка с её аргументами; щелчок по имени функции в подсказке открывает её описание на этой странице.

## DAVERAGE

`DAVERAGE(database, field, criteria)`

Вычисляет среднее значение чисел в столбце списка для строк, которые удовлетворяют условиям.

- `database`: Блок ячеек, в котором находится список, с именами столбцов в первой строке.
- `field`: Столбец, который нужно использовать: его имя в кавычках или его номер, при этом первый столбец имеет номер 1.
- `criteria`: Что искать: число, текст или условие, например «>5».
