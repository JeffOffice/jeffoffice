На вкладке **Справка** есть **Справка** (F1), **Сочетания клавиш**, которое открывает эту страницу, **Что нового** и **Обратная связь**, которые открывают свои веб-страницы.

На Mac клавиша **Command** (⌘) выполняет то же действие, что и **Ctrl** в таблицах ниже, если в таблице не указано иное.

## Перемещение и выделение

| Клавиши | Что они делают |
| --- | --- |
| Клавиши со стрелками | Перемещают активную ячейку на одну ячейку, пропуская скрытые строки и столбцы |
| Shift+стрелка | Расширяют выделение на одну ячейку |
| Ctrl+стрелка | Переходят к границе данных (Esc останавливает длительный поиск) |
| Ctrl+Shift+стрелка | Расширяют выделение до границы данных |
| Home | Переходит к первому столбцу строки |
| Ctrl+Home | Переходит к первой ячейке (A1 или к первой ячейке, которая прокручивается при закреплённых строках или столбцах) |
| Ctrl+End | Переходит к последней ячейке, которая содержит данные или оформление |
| Page Down, Page Up | Перемещают вниз или вверх на один экран |
| Tab, Shift+Tab | Перемещают вправо или влево (по выделенным ячейкам, если их несколько) |
| Enter, Shift+Enter | Перемещают вниз или вверх (по выделенным ячейкам, если их несколько) |
| Ctrl+пробел | Выделяет весь столбец |
| Shift+пробел | Выделяет всю строку |
| {key:SelectAll} | Выделяет всё |

## Изменение ячеек

| Клавиши | Что они делают |
| --- | --- |
| Любой символ | Начинает ввод в активной ячейке вместо её содержимого |
| F2 | Редактирует содержимое активной ячейки в самой ячейке; при вводе формулы переключает между указанием ячеек и редактированием текста |
| F4 | При вводе формулы ставит знак $ в адресе у курсора (A1, $A$1, A$1, $A1) |
| Enter, Shift+Enter | Сохраняют ввод и перемещают вниз или вверх |
| Tab, Shift+Tab | Сохраняют ввод и перемещают вправо или влево |
| Esc | Отменяет ввод |
| Alt+Enter | Начинает новую строку в ячейке |
| Delete | Очищает выделенные ячейки |
| {key:Undo}, {key:Redo} | Отменяют и повторяют действие |
| {key:Save} | Сохраняют файл |
| {key:Cut}, {key:Copy}, {key:Paste} | Вырезают, копируют, вставляют (Esc убирает рамку вокруг скопированных ячеек) |
| Ctrl+Alt+V | Специальная вставка |
| Ctrl и клавиша плюс, Ctrl и клавиша минус | Вставляют и удаляют (строки или столбцы, если выделены целые строки или столбцы) |
| Ctrl+D, Ctrl+R | Заполняют вниз, заполняют вправо |
| Ctrl+E | Мгновенное заполнение |
| Alt и знак равенства | Сумма |
| Ctrl+0, Ctrl+9 | Скрывают столбцы, скрывают строки |
| Alt+Вниз | Открывает список ячейки, если он есть |
| {key:Find} | Найти |
| Ctrl+H (на Mac Option+Command+F) | Найти и заменить |
| F5, Ctrl+G | Переход к ячейке, диапазону или имени |
| Ctrl+Shift+L | Включает или выключает фильтр |
| Shift+F3 | Выбор функции |
| Ctrl+F3 | Список имён |
| F9, Shift+F9 | Пересчитывают всё, пересчитывают этот лист |
| Tab, Enter | Во время ввода формулы: выбирают функцию или имя, отмеченное в списке |
| Esc | Останавливает поиск, сортировку или фильтрацию, которые выполняются |

## Назначение собственных сочетаний клавиш

Вы можете изменить клавиши любой команды или назначить клавиши команде, у которой их нет. Нажмите **Файл > Параметры**, затем вкладку **Настройка**.

1. Введите в поле **Поиск** название команды или её клавиши. Список сгруппирован по вкладкам ленты, и у каждой команды показаны её клавиши. Команды, которых нет на ленте, перечислены в группе **Другие**.
2. Щёлкните команду. Её клавиши перечислены в разделе **Клавиши для этой команды**.
3. Щёлкните поле **Нажмите новые клавиши** и нажмите нужные клавиши, например **Ctrl+Shift+B**. Затем нажмите **Назначить**. Команде можно назначить до четырёх клавиш.
4. Чтобы убрать клавишу, выберите её в списке и нажмите **Удалить**.

Если эти клавиши уже назначены другой команде, JeffCrunch сообщит, какой именно. Нажмите **Перенести**, чтобы передать клавиши этой команде; другая команда их потеряет. Ничего не меняется, пока вы не нажмёте **ОК**. После этого все открытые окна JeffCrunch и все окна, которые вы откроете позже, используют ваши клавиши. Всплывающие подсказки, меню и таблица сочетаний клавиш ниже показывают ваши клавиши.

Клавиши можно назначить и символу. См. раздел **Вставка символа** в статье [Ввод текста в ячейки](edit-cells): нажмите **Клавиша быстрого вызова** в окне «Символ». После этого символ появится в этом списке, как любая команда.

**Сбросить одну** возвращает обычные клавиши выбранной команды. **Сбросить все** возвращает обычные клавиши всех команд. JeffCrunch сохраняет только те команды, клавиши которых вы изменили, поэтому команда, которую вы не меняли, получит более удачные клавиши, если их добавит более поздняя версия.

Некоторые клавиши нельзя назначить команде, потому что они нужны системе или вводу текста. JeffCrunch сообщает **зарезервировано**, когда вы нажимаете такую клавишу. Зарезервированы клавиши **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z**, **Ctrl+A**, **Tab**, **Shift+Tab**, **Enter**, **Esc**, **Backspace**, **Delete**, **Alt+F4**, клавиши-стрелки, **Home**, **End**, **Page Up**, **Page Down** и **Пробел**, **F1**, **F6**, **Shift+F6**, **Ctrl+Y**, **Ctrl+Shift+Z**, **Ctrl** со стрелкой, **Home**, **End**, **Backspace** или **Delete** (с **Shift** или без него там, где это имеет смысл в текстовом поле), а также буквенная, цифровая или символьная клавиша, нажатая одна или с **Shift**. Клавиша, которую уже использует другая часть окна, тоже зарезервирована. **Сохранить**, **Отменить** и **Повторить** всегда сохраняют хотя бы одну клавишу. На Mac **Ctrl** здесь означает клавишу **Command**.

## Клавиши доступа

Нажмите **Alt», чтобы увидеть букву на каждой вкладке ленты и на каждой команде, затем нажмите эти буквы. Нажмите **Alt**, затем **F**, чтобы открыть экран «Файл». Нажмите **Esc**, чтобы вернуться назад.
