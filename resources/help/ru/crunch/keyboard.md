На вкладке **Справка** есть **Справка** (F1), **Сочетания клавиш**, которое открывает эту страницу, **Что нового** и **Обратная связь**, которые открывают свои веб-страницы.

На компьютере Mac клавиша **Command** (⌘) выполняет то же действие, что и **Ctrl** в таблицах ниже, если в таблице не указано иное.

## Перемещение и выделение

| Клавиши | Действие |
| --- | --- |
| Клавиши со стрелками | Перемещают активную ячейку на одну ячейку, пропуская скрытые строки и столбцы |
| Shift+стрелка | Расширяет выделение на одну ячейку |
| Ctrl+стрелка | Переходит к краю данных (Esc останавливает долгий поиск) |
| Ctrl+Shift+стрелка | Расширяет выделение до края данных |
| End, затем стрелка | Переходит к краю данных (в строке состояния отображается End) |
| Ctrl+A | Выделяет блок вокруг активной ячейки, затем весь лист (весь лист сразу, если выделение уже больше блока) |
| Ctrl+Shift+* | Выделяет блок вокруг активной ячейки |
| Ctrl+щелчок или Ctrl+перетаскивание | Добавляет диапазон к выделению |
| Ctrl+Shift+Enter | Вводит формулу как формулу массива для выделенных ячеек |
| Home | Переходит к первому столбцу строки |
| Ctrl+Home | Переходит к первой ячейке (A1 или первой ячейке, которая прокручивается при закреплении строк или столбцов) |
| Ctrl+End | Переходит к последней ячейке, которая содержит данные или формат |
| Page Down, Page Up | Перемещают вниз или вверх на один экран |
| Tab, Shift+Tab | Перемещают вправо или влево (по выделенным ячейкам, если их несколько) |
| Enter, Shift+Enter | Перемещают вниз или вверх (по выделенным ячейкам, если их несколько) |
| Ctrl+пробел | Выделяет весь столбец |
| Shift+пробел | Выделяет всю строку |
| {key:SelectAll} | Выделяет всё |

## Изменение ячеек

| Клавиши | Действие |
| --- | --- |
| Любой символ | Начинает ввод в активной ячейке вместо того, что в ней находится |
| F2 | Редактирует содержимое активной ячейки прямо в ячейке; при вводе формулы переключает между указанием ячеек и редактированием текста |
| F4 | При вводе формулы ставит знаки $ в адрес у курсора (A1, $A$1, A$1, $A1) |
| Enter, Shift+Enter | Сохраняет ввод и перемещает вниз или вверх |
| Tab, Shift+Tab | Сохраняет ввод и перемещает вправо или влево |
| Esc | Отменяет ввод |
| Alt+Enter | Начинает новую строку в ячейке |
| Delete | Очищает выделенные ячейки |
| Ctrl+Q (Control+Q на Mac) | Открывает быстрый анализ для выделенных ячеек |
| {key:Undo}, {key:Redo} | Отменяет или повторяет действие |
| F4 | Повторяет последнюю команду для выделенных ячеек (Ctrl+Y делает то же, когда нечего повторять) |
| {key:Save} | Сохраняет файл |
| {key:Cut}, {key:Copy}, {key:Paste} | Вырезает, копирует, вставляет (Esc убирает рамку у скопированных ячеек) |
| Ctrl+Alt+V | Специальная вставка |
| Ctrl и клавиша плюс, Ctrl+Shift и клавиша плюс, Ctrl и клавиша минус | Вставляют или удаляют (строки или столбцы, если выделены целые строки или столбцы; клавиши плюс вставляют вырезанные ячейки или скопированные без изменений после копирования, а в остальных случаях пустые ячейки) |
| Клавиши со стрелками, Shift+стрелка, Ctrl+стрелка (Option+стрелка на Mac), Enter, Esc | После команды «Переместить или изменить размер примечания»: перемещают рамку примечания, изменяют её размер, задают шаг 1 пиксель, сохраняют или отменяют изменения |
| Ctrl+D, Ctrl+R | Заполняют вниз, заполняют вправо |
| Ctrl+E | Мгновенное заполнение |
| Alt и знак равенства | Сумма |
| Ctrl+0, Ctrl+9 | Скрывают столбцы, скрывают строки |
| Alt+Вниз | Открывает список ячейки, если он есть |
| {key:Find} | Найти |
| Ctrl+H (на Mac Option+Command+F) | Найти и заменить |
| F5, Ctrl+G | Переход к ячейке, диапазону или имени |
| Ctrl+Shift+L | Включает или выключает фильтр |
| Shift+F3 | Выбор функции |
| Ctrl+F3 | Список имён |
| F9, Shift+F9 | Пересчитать всё, пересчитать этот лист |
| Tab, Enter | Во время ввода формулы: выбрать отмеченную в списке функцию или имя |
| Esc | Останавливает выполняющийся поиск, сортировку или фильтрацию |

## Назначение собственных сочетаний клавиш

Можно изменить клавиши любой команды или назначить клавишу команде, у которой её нет. Нажмите **Файл > Параметры**, затем вкладку **Настройка**.

1. Введите текст в поле **Поиск**, чтобы найти команду по её названию или клавишам. Список сгруппирован по вкладкам ленты, и у каждой команды указаны её клавиши. Команды, которых нет на ленте, перечислены в разделе **Другие**.
2. Щёлкните команду. Её клавиши перечислены в разделе **Клавиши для этой команды**.
3. Щёлкните поле **Нажмите новые клавиши** и нажмите нужные клавиши, например **Ctrl+Shift+B**. Затем нажмите **Назначить**. Команде можно назначить до четырёх клавиш.
4. Чтобы удалить клавишу, выделите её в списке и нажмите **Удалить**.

Если эти клавиши уже назначены другой команде, JeffCrunch сообщит, какой именно. Нажмите **Перенести**, чтобы передать клавиши этой команде; другая команда их потеряет. Ничего не меняется, пока вы не нажмёте **ОК**. После этого все открытые окна JeffCrunch, а также все окна, которые вы откроете позже, используют ваши клавиши. Подсказки, меню и таблица сочетаний клавиш ниже показывают ваши клавиши.

Клавиши можно назначить и символу. См. раздел **Вставка символа** в статье [Ввод текста в ячейки](edit-cells): нажмите **Клавиша быстрого вызова** в окне «Символ». Затем символ будет показан в этом списке так же, как команда.

**Сбросить одну** возвращает обычные клавиши выбранной команды. **Сбросить все** возвращает обычные клавиши всех команд. JeffCrunch сохраняет только команды, клавиши которых вы изменили, поэтому команда, которую вы не меняли, получит лучшие клавиши, если их добавит более поздняя версия.

Некоторые клавиши нельзя назначить команде, потому что они нужны системе или вводу текста. JeffCrunch сообщает **зарезервировано**, когда вы нажимаете такую клавишу. Зарезервированы клавиши **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z**, **Ctrl+A**, **Tab**, **Shift+Tab**, **Enter**, **Esc**, **Backspace**, **Delete**, **Alt+F4**, клавиши со стрелками, **Home**, **End**, **Page Up**, **Page Down** и **пробел**, **F1**, **F6**, **Shift+F6**, **Ctrl+Y**, **Ctrl+Shift+Z**, **Ctrl** со стрелкой, **Home**, **End**, **Backspace** или **Delete** (с **Shift** или без него там, где это имеет смысл в текстовом поле), а также буквенные, цифровые и символьные клавиши, нажатые отдельно или с **Shift**. Клавиши, которые уже использует другая часть окна, тоже зарезервированы. **Сохранить**, **Отменить** и **Повторить** всегда сохраняют хотя бы одну клавишу. На Mac **Ctrl** здесь означает клавишу **Command**.

## Клавиши доступа

Нажмите **Alt**, чтобы увидеть букву у каждой вкладки ленты и каждой команды, затем нажмите эти буквы. Нажмите **Alt**, затем **F**, чтобы открыть экран «Файл». Нажмите **Esc**, чтобы вернуться назад.
