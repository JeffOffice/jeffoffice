На вкладке **Справка** есть **Справка** (F1), **Клавиатурные сочетания**, которые открывают эту страницу, **Что нового** и **Обратная связь**, которые открывают свои веб-страницы.

На Mac клавиша **Command** (⌘) выполняет то же, что **Ctrl** в таблицах ниже, если в таблице не указано иное.

## Перемещение и выделение

| Клавиши | Что делают |
| --- | --- |
| Клавиши со стрелками | Перемещают активную ячейку на одну ячейку, пропуская скрытые строки и столбцы |
| Shift+стрелка | Расширяют выделение на одну ячейку |
| Ctrl+стрелка | Переходят к краю данных (Esc останавливает долгий поиск) |
| Ctrl+Shift+стрелка | Расширяют выделение до края данных |
| End, затем стрелка | Переходят к краю данных (в строке состояния отображается End) |
| Ctrl+A | Выделяют блок вокруг активной ячейки, затем весь лист (сразу весь лист, если выделение уже больше блока) |
| Ctrl+Shift+* | Выделяют блок вокруг активной ячейки |
| Ctrl+щелчок или Ctrl+перетаскивание | Добавляют диапазон к выделению |
| Ctrl+Shift+Enter | Вводят формулу как формулу массива для выделенных ячеек |
| Home | Переходит к первому столбцу строки |
| Ctrl+Home | Переходит к первой ячейке (A1 или к первой ячейке, которая прокручивается, если закреплены строки или столбцы) |
| Ctrl+End | Переходит к последней ячейке, которая содержит данные или формат |
| Page Down, Page Up | Перемещают вниз или вверх на экран |
| Tab, Shift+Tab | Перемещают вправо или влево (по выделенным ячейкам, если их несколько) |
| Enter, Shift+Enter | Перемещают вниз или вверх (по выделенным ячейкам, если их несколько) |
| Ctrl+Пробел | Выделяет весь столбец |
| Shift+Пробел | Выделяет всю строку |
| {key:SelectAll} | Выделяет всё |

## Изменение ячеек

| Клавиши | Что делают |
| --- | --- |
| Любой символ | Начинает ввод в активной ячейке вместо её содержимого |
| F2 | Редактирует содержимое активной ячейки в самой ячейке; при вводе формулы переключает между указанием ячеек и редактированием текста |
| F4 | При вводе формулы ставит знак $ в адрес у курсора (A1, $A$1, A$1, $A1) |
| Enter, Shift+Enter | Сохраняют ввод и перемещают вниз или вверх |
| Tab, Shift+Tab | Сохраняют ввод и перемещают вправо или влево |
| Esc | Отменяет ввод |
| Alt+Enter | Начинает новую строку в ячейке |
| Delete | Очищает выделенные ячейки |
| {key:Undo}, {key:Redo} | Отменяют, повторяют |
| F4 | Повторяет последнюю команду для выделенных ячеек (Ctrl+Y делает то же, когда нечего повторять) |
| {key:Save} | Сохраняет |
| {key:Cut}, {key:Copy}, {key:Paste} | Вырезают, копируют, вставляют (Esc убирает рамку скопированных ячеек) |
| Ctrl+Alt+V | Специальная вставка |
| Ctrl и клавиша плюс, Ctrl+Shift и клавиша плюс, Ctrl и клавиша минус | Вставляют и удаляют (строки или столбцы, если выделены целые строки или столбцы; клавиши плюс добавляют ячейки, которые вырезаны или скопированы без изменений после этого, а в остальных случаях пустые ячейки) |
| Клавиши со стрелками, Shift+стрелка, Ctrl+стрелка (Option+стрелка на Mac), Enter, Esc | После команды «Переместить или изменить размер примечания»: перемещают рамку примечания, изменяют её размер, задают шаг 1 пиксель, сохраняют или отменяют изменения |
| Ctrl+D, Ctrl+R | Заполняют вниз, заполняют вправо |
| Ctrl+E | Мгновенное заполнение |
| Alt и знак равенства | Сумма |
| Ctrl+0, Ctrl+9 | Скрывают столбцы, скрывают строки |
| Alt+Вниз | Открывает список ячейки, если он есть |
| {key:Find} | Найти |
| Ctrl+H (на Mac Option+Command+F) | Найти и заменить |
| F5, Ctrl+G | Переход к ячейке, диапазону или имени |
| Ctrl+Shift+L | Включает или выключает фильтр |
| Shift+F3 | Выбор функции |
| Ctrl+F3 | Список имён |
| F9, Shift+F9 | Пересчитывают всё, пересчитывают этот лист |
| Tab, Enter | Во время ввода формулы: выбирают отмеченную в списке функцию или имя |
| Esc | Останавливает начатый поиск, сортировку или фильтрацию |

## Выбор собственных клавиш быстрого вызова

Можно изменить клавиши любой команды или назначить клавиши команде, у которой их нет. Нажмите **Файл > Параметры**, затем вкладку **Настройка**.

1. Введите текст в поле **Поиск**, чтобы найти команду по её имени или клавишам. Список сгруппирован по вкладкам ленты, у каждой команды показаны её клавиши. Команды, которых нет на ленте, перечислены в разделе **Другие**.
2. Щёлкните команду. Её клавиши перечислены в разделе **Клавиши этой команды**.
3. Щёлкните поле **Нажмите новые клавиши** и нажмите нужные клавиши, например **Ctrl+Shift+B**. Затем нажмите **Назначить**. Команде можно назначить до четырёх клавиш.
4. Чтобы убрать клавишу, выберите её в списке и нажмите **Удалить**.

Если эти клавиши уже назначены другой команде, JeffCrunch сообщит, какой именно. Нажмите **Перенести**, чтобы передать клавиши этой команде; другая команда их потеряет. Ничего не меняется, пока вы не нажмёте **ОК**. После этого все открытые окна JeffCrunch и все окна, которые вы откроете позже, используют ваши клавиши. Подсказки, меню и таблица сочетаний клавиш ниже показывают ваши клавиши.

Клавиши может иметь и символ. См. раздел **Вставка символа** в статье [Ввод текста в ячейки](edit-cells): нажмите **Клавиша быстрого вызова** в окне «Символ». Затем он появится в этом списке, как любая команда.

**Сбросить одну** возвращает обычные клавиши выбранной команды. **Сбросить все** возвращает обычные клавиши всех команд. JeffCrunch сохраняет только команды, клавиши которых вы изменили, поэтому команда, которую вы не меняли, получит лучшие клавиши, если их добавит более поздняя версия.

Некоторые клавиши нельзя назначить команде, потому что они нужны системе или вводу текста. JeffCrunch сообщает **зарезервировано**, когда вы нажимаете такую клавишу. Зарезервированы клавиши **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z**, **Ctrl+A**, **Tab**, **Shift+Tab**, **Enter**, **Esc**, **Backspace**, **Delete**, **Alt+F4**, клавиши-стрелки, **Home**, **End**, **Page Up**, **Page Down** и **Пробел**, **F1**, **F6**, **Shift+F6**, **Ctrl+Y**, **Ctrl+Shift+Z**, **Ctrl** со стрелкой, **Home**, **End**, **Backspace** или **Delete** (с **Shift** или без него, где это имеет смысл в текстовом поле), а также буквенная, цифровая или символьная клавиша, нажатая отдельно или с **Shift**. Клавиши, которые уже используются другой частью окна, тоже зарезервированы. **Сохранить**, **Отменить** и **Повторить** всегда сохраняют по крайней мере одну клавишу. На Mac **Ctrl** здесь означает клавишу **Command**.

## Клавиши доступа

Нажмите **Alt**, чтобы увидеть букву на каждой вкладке ленты и у каждой команды, затем нажмите эти буквы. Нажмите **Alt**, затем **F**, чтобы открыть экран «Файл». Нажмите **Esc**, чтобы вернуться назад.
