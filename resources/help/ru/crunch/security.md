# Безопасность: к чему может обращаться файл
<!-- keywords: центр управления безопасностью, безопасность, макросы, связанные файлы, связи, связанные рисунки, связанные мультимедиа, интернет, загруженные, только для чтения, защищённые, внешние связи, программы, безопасно -->

Файл может указывать на другие объекты: файлы, веб-страницы, видео и даже программы. На странице **Безопасность** вы решаете, что JeffCrunch будет делать с такими ссылками. Нажмите **Файл > Параметры**, затем вкладку **Безопасность**. Нажмите **ОК**, чтобы сохранить изменения, или **Отмена**, чтобы отказаться от них.

Эти параметры общие для всех приложений JeffOffice: если изменить один из них в одном приложении, он изменится во всех. Строка для того, чего в приложении нет, имеет надпись **Не применяется** и выделена серым.

## Макросы

Макросы — это небольшие программы, которые хранятся внутри файла. JeffCrunch сохраняет их в файле, поэтому они остаются на месте при сохранении, и она **никогда их не запускает**. Нет параметра, который запускал бы их.

## Связанные файлы и связи книг

Речь о других книгах, из которых книга получает числа; такие ссылки называются **связями**. Выбор определяет, что JeffCrunch делает при открытии книги, в которой есть связи.

- **Спрашивать перед запуском** — обычный выбор. JeffCrunch спрашивает, обновлять ли числа из других книг.
- **Обновлять их** обновляет их без вопроса.
- **Никогда не обновлять их** сохраняет числа, которые были записаны в файле.

Выбор, сделанный для одной книги в **Данные > Изменить связи** (**Запрос при запуске**), действует для этой книги. Книга, для которой выбрано «никогда», всегда остаётся без изменений. Книга, расположенная на другом компьютере, не читается при открытии файла, что бы вы ни выбрали. Вы по-прежнему можете в любое время использовать **Обновить значения** в окне **Изменить связи**.

## Связанные видео и звуки

В JeffCrunch это не применяется: здесь нет связанных видео или звуков для воспроизведения. Строка выделена серым.

## Файлы из интернета или с других компьютеров

Загруженный файл или файл, находящийся на другом компьютере в вашей сети, может быть небезопасным. Этот параметр определяет, как JeffCrunch его открывает.

- **Сначала открывать только для чтения** — обычный выбор. Файл открывается для чтения, но изменить его нельзя. Под файлом появляется полоса с этим предупреждением. Нажмите **Включить редактирование** на полосе, чтобы изменить только этот файл (до закрытия программы). Если после этого сохранить файл на прежнем месте, отметка о загрузке с него снимается. Или используйте **Сохранить как**, чтобы сделать копию, либо переключите этот параметр на следующий вариант.
- **Открывать обычным образом** открывает каждый файл одинаково.

Файл, открытый через **Открыть как копию**, **Открыть и восстановить** или **Открыть только для чтения** на экране **Файл**, открывается так, как указано в этой команде, независимо от настройки.

## Связи, которые запускают программу

Связь, которая запустила бы программу или сценарий (файл с расширением .exe, .bat, .sh и т. п.), **всегда отклоняется**. JeffCrunch сообщает об этом, и ничего не запускается. Связь с файлом на другом компьютере никогда не открывается без вашего подтверждения. Никакой параметр этого не меняет.
