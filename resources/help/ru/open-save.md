JeffPub сохраняет вашу работу в файлах .jpub. Он также открывает и сохраняет файлы .pub. См. [Работа с файлами .pub](pub-files).

## Сохранение

Нажмите Ctrl+S, щёлкните кнопку **Сохранить** на панели быстрого доступа или выберите **Файл > Сохранить**. При первом сохранении JeffPub попросит указать имя и место. После этого команда «Сохранить» заменяет файл вашей последней версией.

Звёздочка (*) после имени в строке заголовка означает, что есть несохранённые изменения. Сохраняйте работу часто. Если JeffPub неожиданно закроется, см. [Восстановление несохранённой работы](recover).

Чтобы сохранить последнюю сохранённую копию файла, включите **Всегда создавать резервную копию**. При каждом сохранении JeffPub сначала копирует старый файл в файл с названием «Копия» и именем исходного файла в той же папке. Если копию создать не удалось, программа спросит, сохранять ли без неё. По умолчанию ответ «Нет», и файл остаётся без изменений. Этот параметр находится в **Файл > Параметры** на вкладке **Общие**. Он есть во всех приложениях JeffOffice.

## Сохранение под новым именем

Выберите **Файл > Сохранить как** или нажмите F12. Введите имя, выберите **Тип файла** и нажмите **Сохранить**. Доступны варианты:

- **Публикация JeffPub (*.jpub)** — обычный выбор.
- **Файлы публикаций .pub (*.pub)** создают файл .pub.
- **PDF (*.pdf)** создаёт PDF, а публикация остаётся без изменений.
- **Шаблон JeffPub (*.jpub)** добавляет публикацию в **Мои шаблоны**.

После сохранения в .jpub или .pub строка заголовка показывает новое имя, и вы продолжаете работать в новом файле.

## Сохранение копии

Выберите **Файл > Сохранить копию** и укажите имя. JeffPub запишет публикацию в этот файл, а вы продолжите работу в прежнем. Имя текущего файла и несохранённые изменения остаются прежними.

## Открытие

1. Нажмите Ctrl+O или выберите **Файл > Открыть**.
2. Нажмите **Обзор**, чтобы выбрать файл, или щёлкните имя в разделе **Закреплённые** или **Недавние публикации**.

Можно также перетащить файл .jpub или .pub на страницу. Если в текущей публикации есть несохранённые изменения, JeffPub сначала спросит о них.

Щёлкните имя в списке правой кнопкой мыши, чтобы выбрать **Закрепить в списке** (имя останется вверху) или **Удалить из списка**. Имя серым цветом означает, что JeffPub сейчас не может найти файл. Чтобы изменить количество недавних имён в списке, см. [Настройка JeffPub](options).

## Другие способы открытия файла

На странице **Открыть** нажмите **Другие способы открытия**. Также можно щёлкнуть имя в списке недавних файлов правой кнопкой мыши.

- **Открыть только для чтения** открывает публикацию только для просмотра. Её можно читать и прокручивать, но нельзя изменить. В строке заголовка написано «Только чтение». Если нажать **Сохранить**, JeffPub попросит новое имя, поэтому открытый файл не меняется.
- **Открыть как копию** открывает публикацию без собственного файла. При **Сохранении** программа спросит, куда её записать.
- **Открыть в новом окне** открывает файл в отдельном окне.
- **Открыть и восстановить** предназначен для повреждённого файла .jpub, например обрезанного при копировании. JeffPub читает все части файла, которые может прочитать, и пропускает часть, которую не может открыть. Публикация открывается как копия с названием «Восстановлено» и именем файла, а сообщение указывает, что было пропущено. Повреждённый файл не изменяется.

## Закрытие

Выберите **Файл > Закрыть** или нажмите Ctrl+F4. JeffPub спросит, сохранять ли изменения, и затем откроет пустую страницу.

## Сведения: свойства, пометка как окончательной, проверка и версии

**Файл > Сведения** показывает, где находится файл, с кнопками **Показать в папке** и **Копировать путь**. Здесь приведены сведения о публикации: страницы, размер страницы, рисунки, слова и даты. Введите значения в поля **Название**, **Автор**, **Тема**, **Ключевые слова**, **Категории**, **Примечания**, **Компания** и **Руководитель**, а для собственных свойств нажмите **Настраиваемые свойства**. Изменение сохраняется вместе с публикацией, и **Ctrl+Z** его отменяет. На этой странице также открываются сведения о компании, **Параметры типографской печати** (см. [Файлы PDF и типография](pdf)) и [Проверка дизайна](design-checker).

- **Проверить совместимость** показывает, что файл .pub не может сохранить из вашей публикации: скрытые объекты, некоторые стили списков и всё остальное, что не записывает модуль .pub. Ничего при этом не сохраняется. При сохранении в файл .pub JeffPub показывает тот же список **до** записи. Выберите **Всё равно сохранить**, **Сохранить как .jpub** (файл .jpub создаётся рядом, и ничего не теряется) или **Отмена**. Установите флажок **Больше не спрашивать для этого файла**, и JeffPub не будет задавать этот вопрос о данном файле до закрытия программы.
- **Пометить как окончательный** сохраняет публикацию и затем открывает её только для чтения. При открытии строка заголовка сообщает, что файл только для чтения, а примечание указывает, что он помечен как окончательный. Это не блокировка: чтобы редактировать, выберите **Помечено как окончательный** ещё раз. Файл .pub не может хранить эту метку, поэтому сначала сохраните файл в формате .jpub.
- **Проверить публикацию** показывает, что файл содержит и чем вы, возможно, не хотите делиться, и удаляет это: примечания и имена их авторов, автора и другие имена в свойствах, сведения о компании, список для слияния почты и объекты на рабочей области рядом со страницами.
- **Удалить личные сведения из этого файла при сохранении** под карточками убирает при каждом сохранении автора, того, кто сохранил файл последним, компанию и руководителя — для файлов .jpub и .pub. Это тот же флажок, что и в **Параметрах**, и он одинаков во всех приложениях JeffOffice.
- **История версий** хранит именованные копии публикации на вашем компьютере. Сначала сохраните публикацию. Нажмите **Сохранить версию…**, а затем выберите версию, чтобы **Открыть копию** (ещё раз), **Вернуться к ней** (текущая публикация сначала сохраняется как версия) или **Удалить**.

Формат .jpub не предусматривает пароль, поэтому в JeffPub нет карточки пароля. Проверки специальных возможностей в JeffPub пока нет, поэтому на странице нет карточки для неё.

## Если Windows не разрешает JeffPub сохранять файлы

Безопасность Windows может блокировать сохранение программами в папках, например «Документы». Тогда JeffPub покажет сообщение с шагами, как разрешить сохранение. Можно также сохранить файл в другой папке.
