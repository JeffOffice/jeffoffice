JeffPub сохраняет вашу работу в файлах .jpub. Он также открывает и сохраняет файлы .pub. См. [Работа с файлами .pub](pub-files).

## Сохранение

Нажмите Ctrl+S, щёлкните кнопку **Сохранить** на панели быстрого доступа или выберите **Файл > Сохранить**. При первом сохранении JeffPub попросит ввести имя и выбрать место. После этого команда «Сохранить» заменяет файл вашей последней версией работы.

Звёздочка (*) после имени в строке заголовка означает, что есть несохранённые изменения. Сохраняйте работу часто. Если JeffPub неожиданно закроется, см. [Восстановление несохранённой работы](recover).

Чтобы сохранить последнюю сохранённую копию файла, включите параметр **Всегда создавать резервную копию**. При каждом сохранении JeffPub сначала копирует старый файл в файл с именем «Копия» и исходным именем в той же папке. Если копию создать не удалось, программа спросит, сохранять ли без неё. По умолчанию ответ «Нет», если вы не выберете «Да», и файл остаётся без изменений. Этот параметр находится в **Файл > Параметры** на вкладке **Общие**. Он есть во всех приложениях JeffOffice.

## Сохранение с новым именем

Выберите **Файл > Сохранить как** или нажмите F12. Введите имя, выберите **Тип файла** и нажмите **Сохранить**. Доступны такие варианты:

- **Публикация JeffPub (*.jpub)** — обычный выбор.
- **Файлы публикаций .pub (*.pub)** создаёт файл .pub.
- **PDF (*.pdf)** создаёт PDF и оставляет публикацию без изменений.
- **Шаблон JeffPub (*.jpub)** добавляет публикацию в **Мои шаблоны**.

После сохранения в .jpub или .pub в строке заголовка появляется новое имя, и вы продолжаете работу в новом файле.

## Сохранение копии

Выберите **Файл > Сохранить копию** и укажите имя. JeffPub записывает публикацию в этот файл, а вы продолжаете работать в прежнем. Имя и несохранённые изменения исходной публикации остаются прежними.

## Открытие

1. Нажмите Ctrl+O или выберите **Файл > Открыть**.
2. Нажмите **Обзор**, чтобы выбрать файл. Или щёлкните имя в разделе **Закреплённые** или **Недавние публикации**.

Файл .jpub или .pub можно также перетащить на страницу. Если в текущей публикации есть несохранённые изменения, JeffPub сначала спросит о них.

Щёлкните имя в списке правой кнопкой, чтобы **Закрепить в списке** (оно останется вверху) или **Удалить из списка**. Имя серым цветом означает, что JeffPub сейчас не может найти этот файл. Чтобы изменить количество недавних имён, см. [Настройка JeffPub](options).

## Другие способы открытия файла

На странице **Открыть** нажмите **Другие способы открытия**. Также можно щёлкнуть имя в списке недавних правой кнопкой.

- **Открыть только для чтения** открывает публикацию только для просмотра. Её можно смотреть и прокручивать, но нельзя ничего изменить. В строке заголовка написано «Только чтение». Если нажать **Сохранить**, JeffPub попросит новое имя, поэтому открытый файл не изменится.
- **Открыть как копию** открывает публикацию без собственного файла. При **Сохранить** программа спросит, куда её поместить.
- **Открыть в новом окне** открывает файл в отдельном окне.
- **Открыть и восстановить** предназначена для повреждённого файла .jpub, например обрезанного при копировании. JeffPub читает все части файла, которые может прочитать, и пропускает те, что не может. Публикация открывается как копия с именем «Восстановлено» и исходным именем, а сообщение сообщает, что было пропущено. Повреждённый файл не изменяется.

## Закрытие

Выберите **Файл > Закрыть** или нажмите Ctrl+F4. JeffPub спросит, сохранять ли изменения, и затем покажет пустую страницу.

## Сведения: свойства, пометка как окончательного, проверка и версии

**Файл > Сведения** показывает, где находится файл, и содержит кнопки **Показать в папке** и **Копировать путь**. Здесь же приводятся сведения о публикации: страницы, размер страницы, рисунки, слова и даты. Введите значения в полях **Название**, **Автор**, **Тема**, **Ключевые слова**, **Категории**, **Примечания**, **Компания** и **Руководитель», а для собственных свойств нажмите **Пользовательские свойства**. Изменение сохраняется вместе с публикацией, а **Ctrl+Z** его отменяет. На этой странице также открываются сведения о компании, **Параметры типографской печати** (см. [Файлы PDF и типография](pdf)) и [Проверка дизайна](design-checker).

- **Проверка совместимости** показывает, что файл .pub не может сохранить из вашей публикации: скрытые объекты, некоторые виды списков и всё остальное, что не записывает модуль .pub. Ничего при этом не сохраняется. При сохранении в файл .pub JeffPub показывает тот же список **до** записи. Выберите **Всё равно сохранить**, **Сохранить как .jpub** (файл .jpub создаётся рядом, и ничего не теряется) или **Отмена**. Установите флажок **Не спрашивать для этого файла**, и JeffPub перестанет спрашивать о нём до закрытия программы.
- **Всегда открывать только для чтения** открывает публикацию только для просмотра при каждом запуске. Параметр сохраняется в файле .jpub, а строка состояния сообщает об этом при открытии. Чтобы разрешить редактирование, выберите **Всегда открывается только для чтения** на той же странице. Это напоминание, а не блокировка. Файл .pub не может хранить этот параметр (модуль .pub не сохраняет такие свойства, а JeffPub не читает их из файла .pub), поэтому сначала сохраните файл как .jpub. Проверка совместимости показывает этот параметр для файла .pub.
- **Пометить как окончательный** сохраняет публикацию и затем открывает её только для чтения. При открытии в строке заголовка указано, что файл только для чтения, а примечание сообщает, что он помечен как окончательный. Это не блокировка: чтобы редактировать публикацию, снова выберите **Помечено как окончательный**. Файл .pub не может хранить эту метку, поэтому сначала сохраните файл как .jpub.
- **Проверить публикацию** показывает, что файл содержит такого, чем вы, возможно, не хотите делиться, и удаляет это: примечания и имена их авторов, автора и другие имена в свойствах, сведения о компании, список рассылки слияния и объекты на рабочей области рядом со страницами.
- **Удалить личные сведения из этого файла при сохранении**, под карточками, при каждом сохранении файла .jpub или .pub удаляет из него автора, того, кто сохранил файл последним, компанию и руководителя. Это тот же флажок, что и в **Параметрах**, и он одинаков во всех приложениях JeffOffice.
- **История версий** хранит именованные копии публикации на вашем компьютере. Сначала сохраните публикацию. Нажмите **Сохранить версию…**, а затем выберите версию, чтобы **Открыть копию**, **Вернуться к ней** (текущая публикация сначала сохраняется как версия) или **Удалить** её.

Файл .jpub не имеет формы для пароля, поэтому в JeffPub нет карточки пароля. В JeffPub пока нет проверки специальных возможностей, поэтому на странице нет для неё карточки.

## Если Windows не разрешает JeffPub сохранять файлы

Безопасность Windows может запретить программам сохранять файлы в папках, например в «Документах». Тогда JeffPub показывает сообщение с шагами для разрешения. Можно также сохранить файл в другой папке.
