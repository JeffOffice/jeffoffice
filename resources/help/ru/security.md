# Безопасность: к чему файл может обращаться

<!-- keywords: центр управления безопасностью, безопасность, макросы, связанные файлы, связи, связанные рисунки, связанные мультимедиа, интернет, загруженные, только для чтения, защищённые, внешние связи, программы, безопасно -->

Файл может ссылаться на другие объекты: файлы, веб-страницы, видео и даже программы. На странице **Безопасность** вы решаете, что JeffPub делает в таких случаях. Нажмите **Файл > Параметры**, затем вкладку **Безопасность**. Нажмите **ОК**, чтобы сохранить изменения, или **Отмена**, чтобы отказаться от них.

Эти параметры общие для всех приложений JeffOffice: если изменить один из них в одном приложении, он изменится во всех. Строка для того, чего в приложении нет, содержит текст **Не применяется** и выделена серым.

## Макросы

Макросы — это небольшие программы, которые хранятся внутри файла. JeffPub **никогда их не запускает**, и никакого параметра, который бы их запускал, нет. JeffPub также не сохраняет макросы публикации: при сохранении открытого вами файла `.pub` в копии их не будет, поэтому, если они вам ещё нужны, сохраните исходный файл.

## Связанные файлы и связи с книгами

Речь идёт о рисунках, которые **связаны** с файлом, а не хранятся внутри публикации. Параметр определяет, что JeffPub делает при открытии публикации, в которой такие рисунки есть.

- **Обновлять** — обычный выбор. При открытии публикации JeffPub заново читает файл каждого связанного рисунка, если этот файл находится в папке самой публикации, поэтому рисунок всегда актуален. Программа при этом не спрашивает.
- **Никогда не обновлять** оставляет каждый рисунок таким, каким он был сохранён. Каждый из них показывает **Не обновлён**, пока вы не нажмёте на нём **Обновить связь**. Тогда **Экспорт в PDF** и **Печать** сообщают в строке состояния, что для рисунков, у которых в публикации нет полной копии, использовались предварительные изображения.

JeffPub читает только файлы, которые находятся в папке публикации (или в папке, которую вы разрешили). Любой другой связанный файл ожидает, пока вы его не запросите.

## Связанные видео и звуки

В JeffPub это не применяется: у программы нет связанных видео или звуков для воспроизведения. Строка выделена серым.

## Файлы из интернета или с других компьютеров

Загруженный файл или файл, который находится на другом компьютере в вашей сети, может быть небезопасным. Этот параметр определяет, как JeffPub его открывает.

- **Сначала открывать только для чтения** — обычный выбор. Файл открывается для чтения, но изменить его нельзя. Под файлом появляется полоса с этим предупреждением. Нажмите на ней **Включить редактирование**, чтобы изменить именно этот файл (до закрытия программы). Если после этого вы сохраните файл в том же месте, JeffPub снимет с него метку загрузки. Можно также использовать **Сохранить как**, чтобы создать копию, или переключить этот параметр на следующий вариант.
- **Открывать обычным образом** открывает все файлы одинаково.

Файл, открытый через **Открыть как копию**, **Открыть и восстановить** или **Открыть только для чтения** на экране **Файл**, открывается именно так, независимо от этого параметра.

## Связи, которые запускают программы

Связь, которая запустила бы программу или сценарий (файл с расширением .exe, .bat, .sh и т. п.), **всегда отклоняется**. JeffPub сообщает об этом, и ничего не запускается. Связь с файлом на другом компьютере никогда не открывается без вашего запроса. Этого не меняет ни один параметр.
