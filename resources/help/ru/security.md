# Безопасность: к чему может обращаться файл
<!-- keywords: центр управления безопасностью, безопасность, макросы, связанные файлы, связи, связанные рисунки, связанные мультимедиа, интернет, загруженные, только для чтения, защищённые, внешние связи, программы, безопасно, доверие -->

Файл может ссылаться на другие объекты: файлы, веб-страницы, видео, даже программы. На странице **Безопасность** вы решаете, как JeffPub поступает с такими ссылками. Нажмите **Файл > Параметры**, затем вкладку **Безопасность**. Нажмите **ОК**, чтобы сохранить изменения, или **Отмена**, чтобы отказаться от них.

Эти параметры общие для всех приложений JeffOffice: если изменить один из них в одном приложении, он изменится во всех остальных. Строка для того, чего в приложении нет, содержит текст **Не применяется** и выделена серым.

## Макросы

Макросы — это небольшие программы, которые хранятся внутри файла. JeffPub сохраняет их в файле, поэтому они остаются на месте при сохранении, но JeffPub **никогда их не запускает**. Нет параметра, который бы их запускал.

## Связанные файлы и связи с книгами

Речь идёт о рисунках, которые **связаны** с файлом, а не хранятся внутри публикации. Выбор определяет, что JeffPub делает при открытии публикации, в которой такие рисунки есть.

- **Обновлять** — обычный выбор. При открытии публикации JeffPub заново читает файл каждого связанного рисунка, если этот файл находится в папке публикации, поэтому рисунок всегда актуален. JeffPub никогда не спрашивает об этом.
- **Никогда не обновлять** оставляет каждый рисунок таким, каким он был сохранён. Каждый из них показывает **Не обновлён**, пока вы не нажмёте на нём **Обновить связь**. Тогда при **Экспорте в PDF** и **Печати** строка состояния сообщит, что для рисунков, у которых в публикации нет полной копии, использованы предварительные изображения.

JeffPub читает только файлы, находящиеся в папке публикации (или в папке, которую вы разрешили). Любой другой связанный файл ожидает, пока вы его не запросите.

## Связанные видео и звуки

В JeffPub это не применяется: здесь нет связанных видео или звуков для воспроизведения. Строка выделена серым.

## Файлы из интернета или с других компьютеров

Загруженный файл или файл, находящийся на другом компьютере в вашей сети, может быть небезопасным. Этот выбор определяет, как JeffPub его открывает.

- **Сначала открывать только для чтения** — обычный выбор. Файл открывается для просмотра, но изменить его нельзя. Под файлом появляется полоса с соответствующим сообщением. Нажмите на полосе **Включить редактирование**, чтобы изменить только этот файл (до закрытия программы). Если после этого вы сохраните файл на прежнем месте, JeffPub снимет с него метку загрузки. Или используйте **Сохранить как**, чтобы создать копию, либо выберите следующий вариант этого параметра.
- **Открывать обычным образом** открывает все файлы одинаково.

Файл, открытый командами **Открыть как копию**, **Открыть и восстановить** или **Открыть только для чтения** на экране **Файл**, открывается указанным способом независимо от этой настройки.

## Ссылки, которые запускают программы

Ссылка, которая запустила бы программу или сценарий (файл с расширением .exe, .bat, .sh и т. п.), **всегда отклоняется**. JeffPub сообщает вам об этом, и ничего не запускается. Ссылка на файл на другом компьютере никогда не открывается без вашего подтверждения. Никакой параметр это не меняет.
