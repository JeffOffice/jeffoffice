# Слияние почты и слияние каталога

<!-- keywords: слияние почты, слияние, получатели, список адресов, наклейки, письма, форма письма, csv, xlsx, vcard, поле слияния, блок адреса, каталог, список товаров, слияние по эл. почте, просмотр -->

Слияние почты заполняет одну публикацию данными из списка. Вы пишете письмо один раз, а JeffPub создаёт копию для каждого человека, подставляя его имя и адрес. Слияние каталога повторяет один макет для каждого товара из списка.

Инструменты находятся на вкладке **Рассылки**. Чтобы пройти по шагам, нажмите **Рассылки > Начать слияние > Пошаговый мастер слияния почты**, чтобы открыть область **Слияние почты**.

## Выбор получателей

Нажмите **Рассылки > Начать слияние > Выбрать получателей**:

- **Использовать существующий список…**: выберите файл CSV, текстовый файл с разделителями-табуляциями, электронную таблицу .xlsx (первый лист) или файл контактов .vcf. В файлах CSV, текстовых и электронных таблицах первая строка должна содержать имена столбцов.
- **Выбрать из контактов…**: выберите файл контактов (.vcf или .vcard). Большинство адресных книг и телефонов могут сохранить контакты в таком файле; каждый контакт становится получателем, со столбцами имени, адреса, телефона и эл. почты.
- **Ввести новый список…**: заполните окно **Новый список адресов**, используя **Новая запись** для каждого человека. Затем JeffPub предложит сохранить список в файл CSV.

Чтобы проверить список, нажмите **Рассылки > Начать слияние > Изменить список получателей**. В окне **Получатели слияния почты** снимите отметку со строки, чтобы пропустить человека, щёлкните заголовок, чтобы отсортировать список, и введите текст в поле **Фильтр получателей**, чтобы сузить список. **Различать получателей по** выбирает столбец, по которому отличаются люди; список сохраняется в вашей публикации вместе со снятыми отметками, и при повторном выборе того же файла списка эти люди снова будут пропущены, даже если перед этим вы отсортировали строки. **Найти дубликаты** снимает отметки с повторов, а **Проверить адреса** выделяет строки с пропущенным адресом или необычным почтовым индексом.

## Добавление полей слияния

Поле слияния — это заполнитель, например «Имя», который для каждого человека становится реальным значением. Щёлкните в текстовом поле (если его нет, JeffPub добавит его), затем используйте **Рассылки > Написание и вставка полей**:

- **Блок адреса**: почтовый адрес, собранный из столбцов с именами вроде «Имя», «Фамилия» и «Адрес, строка 1».
- **Строка приветствия**: «Уважаемый(ая)» и имя человека или «Дорогой друг,», если имени нет.
- **Вставить поле слияния**: выберите любой столбец.
- **Поле рисунка**: выберите столбец с именами файлов рисунков. JeffPub добавит пустую рамку и будет искать файлы рядом с вашим списком. После сохранения публикации и её повторного открытия рисунок, файл которого находится вне папки публикации, не отображается, пока вы снова не выберете список получателей (**Рассылки > Выбрать получателей > Использовать существующий список…**). Затем рисунки из папки списка и из вложенных в неё папок отображаются, пока публикация не закрыта. JeffPub не запоминает это для следующего раза. Также можно хранить файлы рисунков в папке публикации или во вложенной в неё папке: они отобразятся сразу после её открытия. Это не даёт публикации, которую вам прислал кто-то другой, самостоятельно читать рисунки с вашего компьютера. Рисунок каждой записи отображается при просмотре результатов, печати, сохранении PDF или слиянии в новую публикацию или каталог.

## Показ числа, цены, даты или времени в нужном виде

Поле слияния показывает значение так, как оно записано в списке. Чтобы это изменить, щёлкните рядом с полем (или выделите его или несколько полей) и нажмите **Рассылки > Написание и вставка полей > Формат поля слияния…**. В разделе **Показывать значение как** выберите:

- **Число** с **Число десятичных знаков** от 0 до 4. Например, 1234,5 с одним десятичным знаком выглядит как 1 234,5.
- **Денежный** — с денежным знаком вашего региона: 1234,5 выглядит как 1 234,50 в тех регионах, где это принятый знак.
- **Процентный**: 0,256 выглядит как 25,6 % с одним десятичным знаком.
- **Дата** в **Стиле**, например «Краткий», «Полный», «Год, месяц, день», «Месяц и день» или «Месяц и год».
- **Время** в стиле «Краткий», «12-часовой» или «24-часовой».

Строка **Образец** показывает, что получится при вашем выборе. Значения читаются и выводятся на языке текста в месте поля (американский английский, если язык не задан), а не на языке вашего компьютера. В американском английском 03/04/2026 — это 4 марта, а в языках с порядком «день, месяц» (например, немецком или британском английском) — 3 апреля; в немецком 1.234,5 — число с десятичной запятой. Год из двух цифр читается как 2000–2029 для 00–29 и как 1930–1999 для 30–99. Число в скобках, например (500), считается отрицательным. Значение, которое не является числом, датой или временем выбранного вида, выводится так, как оно есть в списке: слово, «nan» или «inf» (человека может звать Нэн), пустое значение, время с форматом даты или дата с форматом времени. Просмотр и готовое слияние показывают отформатированное значение. Выбор занимает один шаг отмены и сохраняется вместе с публикацией.

## Просмотр результатов

Нажмите **Рассылки > Просмотр результатов > Просмотр результатов**, чтобы вместо полей увидеть реальные данные. Используйте **Первая запись**, **Предыдущая запись**, **Следующая запись** и **Последняя запись**, чтобы просматривать людей по порядку, или **Найти получателя**, чтобы перейти к совпадению.

## Завершение слияния

Нажмите **Рассылки > Завершение > Завершение и слияние**:

- **Вывести слияние на принтер…** открывает страницу **Печать**. Установите флажок **Печатать все записи слияния почты**, затем печатайте.
- **Объединить в новую публикацию** создаёт новую публикацию с копией ваших страниц для каждого человека.
- **Объединить в PDF…** сохраняет один файл PDF со страницами для всех людей.
- **Слияние по эл. почте…** создаёт отдельный файл письма .eml для каждого человека, в котором первая страница показана как рисунок. Выберите столбец с адресами эл. почты, введите тему и выберите папку. JeffPub не отправляет письма: откройте файлы в своей почтовой программе.
- **Сохранить каждый как файл…** создаёт отдельную публикацию .jpub для каждого человека в выбранной вами папке. Называйте файлы, указывая столбцы в фигурных скобках, например {Фамилия}, {Имя}. Программа запросит подтверждение перед созданием более 200 файлов и один раз, если файлы с такими же именами уже есть. Чтобы остановить процесс между файлами, нажмите **Отмена**.
- **Экспортировать список получателей…** сохраняет список в файл CSV.

## Слияние каталога

Нажмите **Вставка > Страницы > Страницы каталога**, чтобы открыть область **Слияние каталога**.

1. Выберите список товаров, как описано выше.
2. Нажмите **Вставить область каталога**. Появится рамка с пометкой «Область каталога». Задайте её **Строки** и **Столбцы**, а также положение и размер. Поместите поля одного товара в первую ячейку, дважды щёлкнув их в списке. Они повторятся в остальных ячейках. Для рисунка выберите вариант поля «(рисунок)».
3. Просмотрите результат стрелками. На каждой странице выводится столько товаров, сколько ячеек в области. Затем выполните слияние в новую публикацию, в PDF или отправьте на принтер.

**Удалить область каталога** убирает область.
