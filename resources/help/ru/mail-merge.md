# Слияние почты и каталога

<!-- keywords: слияние почты, слияние, получатели, список адресов, наклейки, form letters, csv, xlsx, vcard, поле слияния, блок адреса, каталог, список товаров, слияние по эл. почте, предварительный просмотр -->

Слияние почты заполняет одну публикацию сведениями из списка. Вы пишете письмо один раз, а JeffPub создаёт копию для каждого человека, с его именем и адресом на нужных местах. Слияние каталога повторяет один макет для каждого элемента списка.

Инструменты находятся на вкладке **Рассылки**. Для пошагового режима нажмите **Рассылки > Начать слияние > Пошаговый мастер слияния почты**, чтобы открыть область **Слияние почты**.

## Выбор получателей

Нажмите **Рассылки > Начать слияние > Выбрать получателей**:

- **Использовать существующий список…**: выберите файл CSV, текстовый файл с разделением табуляцией, электронную таблицу .xlsx (первый лист) или файл контактов .vcf. В файлах CSV, текстовых файлах и электронных таблицах первая строка должна содержать имена столбцов.
- **Выбрать из контактов…**: выберите файл контактов (.vcf или .vcard). Большинство адресных книг и телефонов могут сохранить контакты в таком файле; каждый контакт становится получателем, а имя, адрес, телефон и адрес эл. почты — столбцами.
- **Ввести новый список…**: заполните окно **Новый список адресов**, нажимая **Новая запись** для каждого человека. Затем JeffPub предложит сохранить список в файл CSV.

Чтобы проверить список, нажмите **Рассылки > Начать слияние > Изменить список получателей**. В окне **Получатели слияния почты** снимите отметку со строки, чтобы пропустить человека, щёлкните заголовок, чтобы отсортировать список, и введите текст в поле **Фильтр получателей**, чтобы сузить список. Кнопка **Найти дубликаты** снимает отметки с повторов, а **Проверить адреса** выделяет строки с пропущенным адресом или странным почтовым индексом.

## Добавление полей слияния

Поле слияния — это заполнитель, например «Имя», который для каждого человека заменяется реальным значением. Щёлкните в текстовом поле (если его нет, JeffPub добавит его), затем используйте **Рассылки > Написание и вставка полей**:

- **Блок адреса**: почтовый адрес, составленный из столбцов с именами вроде «Имя», «Фамилия» и «Адрес, строка 1».
- **Строка приветствия**: «Уважаемый» и имя человека или «Дорогой друг,», если имени нет.
- **Вставить поле слияния**: выберите любой столбец.
- **Поле рисунка**: выберите столбец с именами файлов рисунков. JeffPub добавит пустую рамку и будет искать файлы рядом с вашим списком. После сохранения публикации и повторного открытия рисунок, файл которого находится вне папки публикации, не отображается, пока вы снова не выберете список получателей (**Рассылки > Выбрать получателей > Использовать существующий список…**). Тогда рисунки из папки списка и из вложенных в неё папок будут отображаться до закрытия публикации. JeffPub не запоминает это для следующего раза. Либо храните файлы рисунков в папке публикации или в папке внутри неё — тогда они будут показаны сразу после открытия. Так публикация, которую вам прислал кто-то другой, не будет сама читать рисунки с вашего компьютера. Рисунок каждой записи показывается при предварительном просмотре результатов, печати, сохранении PDF или слиянии в новую публикацию или каталог.

## Предварительный просмотр результатов

Нажмите **Рассылки > Просмотр > Просмотр результатов**, чтобы вместо полей увидеть реальные данные. Используйте **Первая запись**, **Предыдущая запись**, **Следующая запись** и **Последняя запись**, чтобы листать людей, или **Найти получателя**, чтобы перейти к совпадению.

## Завершение слияния

Нажмите **Рассылки > Завершение > Завершение и слияние**:

- **Вывести слияние на принтер…** открывает страницу **Печать**. Установите флажок **Печатать все записи слияния почты**, затем печатайте.
- **Объединить в новую публикацию** создаёт новую публикацию с копией ваших страниц для каждого человека.
- **Объединить в PDF…** сохраняет один файл PDF со страницами для всех людей.
- **Слияние по эл. почте…** создаёт отдельный файл эл. письма .eml для каждого человека, с первой страницей в виде рисунка. Выберите столбец с адресами эл. почты, введите тему и выберите папку. JeffPub не отправляет письма: откройте файлы в своей почтовой программе.
- **Экспорт списка получателей…** сохраняет список в файл CSV.

## Слияние каталога

Нажмите **Вставка > Страницы > Страницы каталога**, чтобы открыть область **Слияние каталога**.

1. Выберите список товаров, как описано выше.
2. Нажмите **Вставить область каталога**. Появится рамка с подписью «Область каталога». Задайте её **Строки** и **Столбцы**, а также положение и размер. Поместите поля одного элемента в первую ячейку, дважды щёлкнув их в списке. Они будут повторяться в остальных ячейках. Для рисунка выберите вариант поля с пометкой «(рисунок)».
3. Просматривайте результат стрелками. Каждая страница показывает столько элементов, сколько ячеек в области. Затем выполните слияние в новую публикацию, в PDF или на принтер.

**Удалить область каталога** убирает область.
