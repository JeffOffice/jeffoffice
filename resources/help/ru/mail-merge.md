# Слияние почты и слияние каталога
<!-- keywords: слияние почты, слияние, получатели, список адресов, наклейки, форм письма, csv, xlsx, vcard, поле слияния, блок адреса, каталог, список товаров, слияние по эл. почте, просмотр -->

Слияние почты заполняет одну публикацию сведениями из списка. Вы пишете письмо один раз, а JeffPub создаёт копию для каждого человека, с его именем и адресом на нужных местах. Слияние каталога повторяет один макет для каждого элемента списка.

Инструменты находятся на вкладке **Рассылки**. Для пошагового режима нажмите **Рассылки > Начать > Слияние почты > Пошаговый мастер слияния почты**, чтобы открыть область **Слияние почты**.

## Выбор получателей

Нажмите **Рассылки > Начать > Выбрать получателей**:

- **Использовать существующий список…**: выберите файл CSV, текстовый файл с разделением табуляцией, электронную таблицу .xlsx (первый лист) или файл контактов .vcf. В файлах CSV, текстовых файлах и электронных таблицах первая строка должна содержать имена столбцов.
- **Выбрать из контактов…**: выберите файл контактов (.vcf или .vcard). Большинство адресных книг и телефонов могут сохранить контакты в таком файле; каждый контакт становится получателем, со столбцами имени, адреса, телефона и адреса эл. почты.
- **Создать новый список…**: заполните окно **Новый список адресов**, используя **Новая запись** для каждого человека. Затем JeffPub предложит сохранить список в файл CSV.

Чтобы проверить список, нажмите **Рассылки > Начать > Изменить список получателей**. В окне **Получатели слияния почты** снимите отметку со строки, чтобы пропустить человека, щёлкните заголовок, чтобы отсортировать список, и введите текст в поле **Фильтр получателей**, чтобы сузить список. Команда **Найти дубликаты** снимает отметки с повторов, а **Проверить адреса** выделяет строки с пропущенным адресом или необычным почтовым индексом.

## Добавление полей слияния

Поле слияния — это заполнитель, например «Имя», который для каждого человека заменяется реальным значением. Щёлкните в текстовом поле (если его нет, JeffPub его добавит), затем используйте **Рассылки > Написание и вставка полей**:

- **Блок адреса**: почтовый адрес, собранный из столбцов с именами вроде «Имя», «Фамилия» и «Адрес, строка 1».
- **Строка приветствия**: «Уважаемый» и имя человека или «Дорогой друг,», если имени нет.
- **Вставить поле слияния**: выберите любой столбец.
- **Поле рисунка**: выберите столбец с именами файлов рисунков. JeffPub добавит пустую рамку и будет искать файлы рядом с вашим списком. После сохранения публикации и её повторного открытия рисунок, файл которого находится вне папки публикации, не отображается, пока вы снова не выберете список получателей (**Рассылки > Выбрать получателей > Использовать существующий список…**). Затем рисунки из папки списка и вложенных в неё папок отображаются до закрытия публикации. JeffPub не запоминает это для следующего раза. Можно также хранить файлы рисунков в папке публикации или в папке внутри неё: тогда они отображаются сразу после открытия. Так публикация, которую вам прислали, не будет сама по себе читать рисунки с вашего компьютера. Рисунок каждой записи появляется при просмотре результатов, печати, сохранении PDF или слиянии в новую публикацию или каталог.

## Вывод числа, цены, даты или времени в нужном виде

Поле слияния показывает значение так, как оно хранится в списке. Чтобы это изменить, щёлкните рядом с полем (или выделите его, или несколько полей) и нажмите **Рассылки > Написание и вставка полей > Формат поля слияния…**. В группе **Показывать значение как** выберите:

- **Число** с **Числом знаков после запятой** от 0 до 4. Например, 1234,5 при одном знаке после запятой отображается как 1 234,5.
- **Денежный**, с денежным знаком вашего региона: 1234,5 отображается как 1 234,50 ₽, если это принятый знак.
- **Процент**: 0,256 отображается как 25,6 % при одном знаке после запятой.
- **Дата** в **Стиле** Краткий, Полный, Год, Месяц, день, День и месяц или Месяц и год.
- **Время** в стиле Краткий, 12-часовой или 24-часовой.

Строка **Образец** показывает, что получится при вашем выборе. Значения читаются и отображаются на языке текста в месте поля (американский английский, если язык не задан), а не на языке вашего компьютера. В американском английском 03/04/2026 — это 4 марта, а в языках с днём впереди, например в немецком или британском английском, — 3 апреля; в немецком 1.234,5 — число с десятичной запятой. Двузначный год читается как 2000–2029 для 00–29 и как 1930–1999 для 30–99. Число в скобках, например (500), считается отрицательным. Значение, которое не является числом, датой или временем выбранного вида, показывается так, как оно есть в вашем списке: слово, «nan» или «inf» (человека может звать Нан), пустое значение, время в формате даты или дата в формате времени. Просмотр и готовое слияние показывают отформатированное значение. Выбор формата является одним шагом отмены и сохраняется вместе с публикацией.

## Просмотр результатов

Нажмите **Рассылки > Просмотр результатов > Просмотр результатов**, чтобы вместо полей увидеть реальные данные. Используйте **Первая запись**, **Предыдущая запись**, **Следующая запись** и **Последняя запись**, чтобы перелистывать людей, или **Найти получателя**, чтобы перейти к совпадению.

## Завершение слияния

Нажмите **Рассылки > Завершение > Завершение и слияние**:

- **Вывести слияние на принтер…** открывает страницу **Печать**. Установите флажок **Печатать все записи слияния почты**, затем печатайте.
- **Объединить в новую публикацию** создаёт новую публикацию с копией ваших страниц для каждого человека.
- **Объединить в PDF…** сохраняет один файл PDF со страницами для каждого человека.
- **Слияние по эл. почте…** создаёт отдельный файл эл. письма .eml для каждого человека, с первой страницей в виде рисунка. Выберите столбец эл. почты, введите тему и выберите папку. JeffPub не отправляет письма: откройте файлы в своей почтовой программе.
- **Экспорт списка получателей…** сохраняет список в файл CSV.

## Слияние каталога

Нажмите **Вставка > Страницы > Страницы каталога**, чтобы открыть область **Слияние каталога**.

1. Выберите список товаров, как описано выше.
2. Нажмите **Вставить область каталога**. Появится рамка с надписью «Область каталога». Задайте её **Строки** и **Столбцы**, а также положение и размер. Поместите поля для одного элемента в первую ячейку, дважды щёлкнув их в списке. Они повторятся в остальных ячейках. Для рисунка выберите вариант поля «(рисунок)».
3. Просмотрите результат стрелками. Каждая страница показывает столько элементов, сколько ячеек в области. Затем выполните слияние в новую публикацию, в PDF или на принтер.

**Удалить область каталога** убирает область.
