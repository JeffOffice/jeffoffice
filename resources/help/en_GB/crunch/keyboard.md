# Use JeffCrunch with the keyboard
<!-- keywords: keyboard, shortcuts, keys, hotkeys, arrow, ctrl, shift, home, end, page up, page down, tab, enter, select all, copy, F9, F1, zoom, access keys, key tips, customize keyboard, change shortcut keys, reassign keys, reset keys, customise keyboard -->

The **Help** tab has **Help** (F1), **Keyboard Shortcuts**, which opens this page, **What's New**, and **Feedback**, which open their web pages.

On a Mac, the **Command** key (⌘) does what **Ctrl** does in the tables below, except where a table says otherwise.

## Moving and selecting

| Keys | What they do |
| --- | --- |
| Arrow keys | Move the active cell one cell, skipping hidden rows and columns |
| Shift+arrow | Extend the selection one cell |
| Ctrl+arrow | Go to the edge of the data (Esc stops a long search) |
| Ctrl+Shift+arrow | Extend the selection to the edge of the data |
| Home | Go to the first column of the row |
| Ctrl+Home | Go to the first cell (A1, or the first cell that scrolls when rows or columns are frozen) |
| Ctrl+End | Go to the last cell that holds something or has a format |
| Page Down, Page Up | Move down or up by a screen |
| Tab, Shift+Tab | Move right or left (through the selected cells, if there are several) |
| Enter, Shift+Enter | Move down or up (through the selected cells, if there are several) |
| Ctrl+Space | Select the whole column |
| Shift+Space | Select the whole row |
| {key:SelectAll} | Select everything |

## Changing cells

| Keys | What they do |
| --- | --- |
| Any character | Start an entry in the active cell, in place of what it holds |
| F2 | Edit what the active cell holds, in the cell; while typing a formula, switch between pointing at cells and editing the text |
| F4 | While typing a formula, fix parts of the address at the cursor with $ (A1, $A$1, A$1, $A1) |
| Enter, Shift+Enter | Keep the entry, and move down or up |
| Tab, Shift+Tab | Keep the entry, and move right or left |
| Esc | Give the entry up |
| Alt+Enter | Start a new line in the cell |
| Delete | Clear the selected cells |
| {key:Undo}, {key:Redo} | Undo, redo |
| {key:Save} | Save |
| {key:Cut}, {key:Copy}, {key:Paste} | Cut, copy, paste (Esc takes away the border of the cells copied) |
| Ctrl+Alt+V | Paste Special |
| Ctrl and the plus key, Ctrl and the minus key | Insert, delete (rows or columns if whole ones are selected) |
| Ctrl+D, Ctrl+R | Fill down, fill right |
| Ctrl+E | Flash Fill |
| Alt and the equals sign | Sum |
| Ctrl+0, Ctrl+9 | Hide the columns, hide the rows |
| Alt+Down | Open the list of a cell that has one |
| {key:Find} | Find |
| Ctrl+H (on a Mac, Option+Command+F) | Find and Replace |
| F5, Ctrl+G | Go to a cell, a range, or a name |
| Ctrl+Shift+L | Turn the filter on or off |
| Shift+F3 | Pick a function |
| Ctrl+F3 | The list of names |
| F9, Shift+F9 | Recalculate all, recalculate this sheet |
| Tab, Enter | While a formula is typed: take the function or name marked in the list |
| Esc | Stop a search, a sort, or a filter that is going on |

## Choose your own shortcut keys

You can change the keys of any command, or give a key to a command that has none. Click **File > Options**, then the **Customise** tab.

1. Type in the **Search** box to find a command by its name or by its keys. The list is grouped by the ribbon's tabs, and each command shows its keys. Commands that are not on the ribbon are listed under **Other**.
2. Click the command. Its keys are listed under **Keys for this command**.
3. Click the **Press the new keys** box and press the keys you want, such as **Ctrl+Shift+B**. Then click **Assign**. A command can have up to four keys.
4. To take a key off, click it in the list and click **Remove**.

If another command already has the keys you pressed, JeffCrunch says which one. Click **Take Over** to give the keys to this command, and the other command loses them. Nothing changes until you click **OK**. Then every open JeffCrunch window uses your keys, and so does every window you open later. Tooltips, menus, and the table of shortcuts below show your keys.

A symbol can have keys too. See **Put in a symbol** in [Type in cells](edit-cells): click **Shortcut Key** in the Symbol box. It then shows in this list like any command.

**Reset One** puts back the usual keys of the chosen command. **Reset All** puts back the usual keys of every command. JeffCrunch keeps only the commands whose keys you changed, so a command you never changed gets any better keys a later version gives it.

Some keys cannot be given to a command, because the system or typing needs them. JeffCrunch says **reserved** when you press one. The reserved keys are **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z**, **Ctrl+A**, **Tab**, **Shift+Tab**, **Enter**, **Esc**, **Backspace**, **Delete**, **Alt+F4**, the arrow, **Home**, **End**, **Page Up**, **Page Down**, and **Space** keys, **F1**, **F6**, **Shift+F6**, **Ctrl+Y**, **Ctrl+Shift+Z**, **Ctrl** with an arrow, **Home**, **End**, **Backspace**, or **Delete** (with or without **Shift**, where that makes sense in a text box), and a letter, digit, or symbol key pressed alone or with **Shift**. A key that another part of the window already uses is reserved too. **Save**, **Undo**, and **Redo** always keep at least one key. On a Mac, **Ctrl** here means the **Command** key.

## Access keys

Press **Alt** to see a letter on every ribbon tab and command, then press the letters. Press **Alt**, then **F**, for the File screen. Press **Esc** to back out.
