# Tab Desain
<!-- keywords: tab desain, pita, tema, varian, warna, font, gaya latar belakang, telusuri tema, sesuaikan, ukuran slaid, standar, layar lebar, format latar belakang, warna latar belakang -->

Tab **Desain** mengubah tampilan semua slaid.

- **Tema** menampilkan sembilan tema sebagai gambar kecil dari slaid judulnya. Klik salah satu untuk menggunakannya pada semua slaid. Klik kanan salah satu untuk menerapkannya hanya pada slaid yang dipilih, menelusuri tema dari berkas lain, atau menyimpan tema Anda sebagai berkas tema.
- **Varian** menampilkan empat tampilan lain dari tema tersebut. Klik salah satu untuk menggunakannya. Panah di sebelahnya membuka menu **Warna**, **Font**, dan **Gaya Latar Belakang**. Di **Warna** dan **Font**, Anda dapat membuat set sendiri dan mengatur ulang ke tema templat.
- **Sesuaikan** berisi **Ukuran Slaid**, untuk memilih **Standar (4:3)** atau **Layar Lebar (16:9)**, serta **Format Latar Belakang**, yang mengatur warna solid di belakang slaid atau di belakang semua slaid.

Lihat [Ukuran slaid, latar belakang, dan footer](design).
