# Tab Bantuan
<!-- keywords: tab bantuan, bantuan, dukungan, hubungi dukungan, masukan, yang baru, catatan rilis, pintasan keyboard, F1, laporkan masalah, usulkan ide -->

Tab **Bantuan** selalu tampil di pita, setelah tab **Tampilan**. Gunakan tab ini untuk mendapatkan bantuan, melaporkan masalah, atau mengusulkan ide.

- Grup **Bantuan**: empat tombol. Lihat [Selamat Datang di JeffPub](start) dan [Dapatkan bantuan dan laporkan masalah](support).

| Tombol | Fungsinya | KeyTip |
|---|---|---|
| **Bantuan** | Membuka panel Bantuan di sisi kanan. Anda juga dapat menekan F1 atau mengklik tombol **?** di ujung kanan baris tab. | Alt, Y, H |
| **Masukan** | Membuka halaman GitHub tempat Anda melaporkan masalah atau mengusulkan ide. Anda memerlukan akun GitHub gratis. | Alt, Y, K |
| **Pintasan Keyboard** | Membuka topik bantuan tentang penggunaan JeffPub dengan keyboard, berisi daftar tombol setiap perintah. | Alt, Y, S |
| **Yang Baru** | Membuka catatan untuk versi JeffPub Anda di GitHub, di peramban web Anda. | Alt, Y, W |
