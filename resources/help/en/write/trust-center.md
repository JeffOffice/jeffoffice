# Trust Center: what a file may reach out to
<!-- keywords: trust center, security, macros, linked files, links, linked pictures, linked media, internet, downloaded, read-only, protected, external links, programs, safe -->

A file can point to other things: files, web pages, movies, even programs. The **Trust Center** is where you decide what JeffWrite does about that. Click **File > Options**, then the **Trust Center** tab. Click **OK** to keep your changes, or **Cancel** to throw them away.

These choices belong to all the JeffOffice apps: change one in one app and it changes in all of them. A row for something an app does not have says **This doesn't apply** and is grayed out.

## Macros

Macros are small programs kept inside a file. JeffWrite keeps them in the file, so they are still there when you save, and it **never runs them**. There is no setting that runs them.

## Linked files and workbook links

This does not apply in JeffWrite: it has no linked files to update. The row is grayed out.

## Linked movies and sounds

This does not apply in JeffWrite: it has no linked movies or sounds to play. The row is grayed out.

## Files from the internet or other computers

A file you downloaded, or that sits on another computer in your network, may not be safe. This choice says how JeffWrite opens it.

- **Open as read-only first** is the usual choice. The file opens so you can read it, but you can't change it. The status bar says so. To change it, use **Save As** to make a copy, or switch this setting to the next choice.
- **Open normally** opens every file the same way.

A file you open with **Open as Copy**, **Open and Repair**, or **Open Read-Only** from the **File** screen opens that way whatever this says.

## Links that start a program

A link that would start a program or a script (a file ending in .exe, .bat, .sh, and so on) is **always refused**. JeffWrite tells you, and nothing runs. A link to a file on another computer is never followed without asking you first. No setting changes this.
