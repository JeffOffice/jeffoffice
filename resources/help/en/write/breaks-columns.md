# Breaks, columns, hyphenation, and line numbers
<!-- keywords: break, breaks, page break, column break, section break, continuous, next page, even page, odd page, columns, column, two columns, three columns, left, right, line between, more columns, hyphenation, hyphenate, automatic hyphenation, line numbers, line numbering, mirrored margins, mirror margins, inside, outside, facing pages, custom margins -->

All of these are on the **Layout** tab, in the **Page Setup** group.

## Breaks

Choose **Layout > Breaks**.

- **Page** (Ctrl+Enter) ends the page. What follows goes to the top of the next page.
- **Column** (Ctrl+Shift+Enter) ends the column. What follows goes to the top of the next column. In the last column of a page, it goes to the next page.
- **Next Page** starts a new section on a new page.
- **Continuous** starts a new section on the same page. Use it to change the number of columns in the middle of a page.
- **Even Page** and **Odd Page** start a new section on the next even or odd numbered page. If the page would have the wrong number, one blank page is left before it.

A **section** is a part of the document with its own page setup, so it can have its own margins, columns, and line numbers. A header or footer is not given a break.

## Margins

**Layout > Margins** has the **Normal**, **Narrow**, **Moderate**, and **Wide** margins. **Mirrored** is for pages that face each other, like a book. It makes the inside margin (the one by the binding) wider than the outside one. **Mirror Margins** turns the same setting on or off. **Custom Margins** opens the Page Setup window.

## Columns

**Layout > Columns** has **One**, **Two**, and **Three** columns of equal width. **Left** has a narrow column on the left and a wide one on the right. **Right** is the other way round.

**More Columns** opens a window. Set the **number of columns** (up to 12). Turn off **Equal column width** to set the width of each column and the space after it. Turn on **Line between** to draw a thin line between the columns. Choose **This section** or **Whole document**.

## Hyphenation

**Layout > Hyphenation > Automatic** splits long words at the end of a line, with a hyphen, so the right edge looks smoother. **None** turns it off. It uses the word lists for the language of the text. It applies to the whole document.

## Line numbers

**Layout > Line Numbers** puts a number beside each line, in the margin. **Continuous** counts on from page to page. **Restart Each Page** and **Restart Each Section** start again at 1. **None** takes them away. **Line Numbering Options** opens a window where you can count by a number other than 1 (every 5th line, for example), pick the first number, and set the space between the numbers and the text.
