# Footnotes and endnotes
<!-- keywords: footnote, endnote, note, notes, reference, citation, source, insert footnote, insert endnote, References tab, number, foot of the page, end of the document, caption, Ctrl+Alt+F, Ctrl+Alt+D -->

A **note** tells the reader more about some words without breaking up the sentence. A small raised number in the text, called the **reference**, points to the note that goes with it. A **footnote** is set at the bottom of the page that has its reference. An **endnote** is set after the last text of the document, or at the end of a section when the file asks for that.

## Add a footnote

1. Click where the reference should go, just after the words the note is about.
2. Click **References > Insert Footnote**, or press **Ctrl+Alt+F**.

JeffWrite puts the reference in the text and a new note at the foot of the page with the same number. The caret moves into the note, so you can type it at once.

Notes are numbered in the order of their references in the text. If you add a footnote before others, each later note goes up by one, and the reference in the text shows the new number too.

## Add an endnote

Click where the reference should go, then click **References > Insert Endnote**, or press **Ctrl+Alt+D**. JeffWrite puts the reference in the text and a new endnote after the last text, with its number, and the caret moves into it. Endnotes have their own numbers, in the style the file asks for.

## Edit a note

Click in the words of a note at the foot of the page, or after the last text for an endnote. The caret goes there. Type, select, cut, copy, paste, and change how the words look, as you do in the text. A note can have more than one paragraph.

Two parts of a note are not text, and no edit can change them: the number that begins the note, and the short line above the notes. If you press **Backspace** just after the number, nothing happens. A selection that would run from one note into another stops at the end of the note you began in.

To leave a note, press **Esc**, press **Up** at its first line or **Down** at its last line, or click in the text of the page. The caret goes back to the text, just after the note's reference.

## Remove or move a note

- Delete a reference, and its note goes with it. The notes after it are numbered again. **Undo** brings back both.
- Cut a reference and paste it somewhere else, and its note moves with it.
- Copy a reference and paste it, and you get a second note with the same words, which you can change on its own.
- Some files have two references to one note. Delete one, and the note stays. Delete the last, and the note goes.

## What JeffWrite keeps

- A part of the file that you did not change is saved exactly as it was. When you change a note, only the notes you changed are written again, and anything in them that JeffWrite can't edit (a picture, a bookmark, a link, a field) stays where it was.
- The line above the notes, and the line that goes above a note that carries on from the page before, are kept as the file has them.
- If the file has no notes, the first one you add also adds what a notes part needs, so that other programs open the file without a message.
- **Find and Replace** and the **Spelling** pane (F7) look through the text of the document, not in its notes.

## Undo

**Undo** (Ctrl+Z) takes back the last change you made, wherever it was: in the text, in a header or footer, or in a note. If it was in a footnote, JeffWrite puts the caret there to show you. **Redo** does it again.
