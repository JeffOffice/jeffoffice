# Open, save, print, and export
<!-- keywords: open, save, save as, docx, template, dotx, recent, pin, new, close, print, pdf, export, recover, autorecover, unsaved, crash, file screen, file formats -->

Click **File** at the top left to see the File screen. It has pages for New, Open, Print, and Export, and commands for Save and Save As. Press **Esc** to go back to your document.

## Start a new document

Press **Ctrl+N**, or click **File > New** and then **Blank Document**. A new document opens in its own window. If the window you are in is empty and was never saved, the new document takes its place.

## Open a document

Press **Ctrl+O**, or click **File > Open**. Click **Browse** to pick a file. JeffWrite opens these kinds of file:

- **.docx** is a document.
- **.dotx** is a template. A template opens as a new document made from it, so the template stays as it is.
- **.docm** and **.dotm** open too. JeffWrite does not keep their macros. It tells you so the first time you save such a document, and it saves a .docx file.

The **Open** page also lists the documents you opened or saved lately. Click one to open it. Right-click one to pin it to the top of the list, or take it off the list.

If a file has parts that JeffWrite can't show yet, it keeps them. See [Welcome to JeffWrite](start). If part of a file can't be read at all, JeffWrite tells you what it left out. It then does not save over that file: Save asks for a new name, so that the original keeps what the copy lost.

## Save a document

Press **Ctrl+S** to save. The first time, JeffWrite asks for a name. **Save As** (F12) saves a copy under a new name. Choose **Template (*.dotx)** to save a template. A file that came from an older kind of file is always saved under a new name, so the old file is never written over.

## Get back unsaved work

JeffWrite saves a spare copy of unsaved work every few minutes, as a file in its own folder. If the program closes unexpectedly, it offers those copies the next time you start it. Click **File > Open > Recover Unsaved Work** to see them later. You can choose which to open, and you can save each one where you like.

## Print

Press **Ctrl+P**, or click **File > Print**. Choose a printer, the copies, and the pages, look at each page in the preview, and click **Print**. See [Print](print).

## Make a PDF

Click **File > Export > Export to PDF**. Choose a name. The PDF looks the same on every computer, because the fonts go inside it.
