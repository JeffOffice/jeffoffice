## Moving and selecting

| Keys | What they do |
| --- | --- |
| Arrow keys | Move the active cell one cell, skipping hidden rows and columns |
| Shift+arrow | Extend the selection one cell |
| Ctrl+arrow | Go to the edge of the data (Esc stops a long search) |
| Ctrl+Shift+arrow | Extend the selection to the edge of the data |
| Home | Go to the first column of the row |
| Ctrl+Home | Go to the first cell (A1, or the first cell that scrolls when rows or columns are frozen) |
| Ctrl+End | Go to the last cell that holds something or has a format |
| Page Down, Page Up | Move down or up by a screen |
| Tab, Shift+Tab | Move right or left (through the selected cells, if there are several) |
| Enter, Shift+Enter | Move down or up (through the selected cells, if there are several) |
| Ctrl+Space | Select the whole column |
| Shift+Space | Select the whole row |
| Ctrl+A | Select everything |

## Access keys

Press **Alt** to see a letter on every ribbon tab and command, then press the letters. Press **Alt**, then **F**, for the File screen. Press **Esc** to back out.
