# Slide Show tab
<!-- keywords: slide show tab, ribbon, from beginning, from current slide, hide slide, set up, monitors, use presenter view, presenter view, rehearse, play, present, f5 -->

The **Slide Show** tab starts the show and sets it up.

- **Start Slide Show** has **From Beginning** (F5) and **From Current Slide** (Shift+F5).
- **Set Up** has **Hide Slide**, which keeps the slide you are on out of the show.
- **Monitors** has the **Use Presenter View** check box, for when you have two screens, and **Presenter View** (Alt+F5), which opens the show in a small window with Presenter View beside it, so you can rehearse on one screen.

See [Play the slide show and use Presenter View](show).
