# Slide Show tab
<!-- keywords: slide show tab, ribbon, from beginning, from current slide, custom slide show, custom shows, hide slide, set up, set up slide show, rehearse timings, use timings, monitors, use presenter view, presenter view, rehearse, play, present, f5 -->

The **Slide Show** tab starts the show and sets it up.

- **Start Slide Show** has **From Beginning** (F5) and **From Current Slide** (Shift+F5). **Custom Slide Show** lists your custom shows by name, so you can play one. Its **Custom Shows** command makes, changes, copies, and deletes them.
- **Set Up** has **Set Up Slide Show**, which chooses the kind of show, which slides play, whether it loops, and how it moves on. **Hide Slide** keeps the slide you are on out of the show. **Rehearse Timings** plays the show and records how long you spend on each slide. The **Use Timings** check box makes the show move on by itself after each slide's time.
- **Monitors** has the **Use Presenter View** check box, for when you have two screens, and **Presenter View** (Alt+F5), which opens the show in a small window with Presenter View beside it, so you can rehearse on one screen.

While the show plays, press Ctrl+P for the pen, Ctrl+I for the highlighter, Ctrl+L for the laser pointer, and Ctrl+E for the eraser. Press Ctrl+A or Esc for the arrow again.
