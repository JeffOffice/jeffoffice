# The File screen
<!-- keywords: file, file screen, backstage, new, open, save, save as, print, export, close, options, about, version, license, report a problem, source code, downloads, back to presentation -->

The **File** button, left of the tabs, opens the File screen. It covers the window and holds everything that works on the whole file: starting, opening, saving, printing, and exporting. Press Esc, or click **Back to presentation**, to return to your slides. **Alt+F** also opens it.

On the left is a list. Some entries open a page, and some do their job at once.

## Start

- **New** shows a **Blank Presentation** to click. See [Open and save presentations](open-save).
- **Open** has **Browse** to pick a file, **Recover Unsaved Work** to bring back copies that AutoRecover kept, and lists of **Pinned** and **Recent Presentations**. See [Open and save presentations](open-save) and [Get back unsaved work](recover).

## This presentation

- **Save** and **Save As** save the file, and the screen closes when they are done. See [Open and save presentations](open-save).
- **Print** is the Print page, with a preview. See [Print, PDF, and slide pictures](printing).
- **Export** has **Export to PDF** and **Export Slide as Picture**. See [Print, PDF, and slide pictures](printing).
- **Close** closes the presentation's window. JeffDeck asks first whether to save changes.

## JeffDeck

- **Options** opens the **JeffDeck Options** window. See [Change JeffDeck's settings](options).
- **About** shows the version of JeffDeck and of Qt, which JeffDeck is built with. It also lists the JeffOffice apps, with links to the **Source code**, the **Downloads**, and **Report a problem**. Each link opens the project's page in your browser. At the bottom are the license and notices: JeffDeck is free software under the GNU General Public License, version 3, and it comes with no warranty.
