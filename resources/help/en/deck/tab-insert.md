# Insert tab
<!-- keywords: insert tab, ribbon, new slide, table, pictures, images, shapes, illustrations, text box, header and footer, date and time, link, hyperlink, symbol, media, video, audio, movie, sound -->

The **Insert** tab adds things to your presentation.

- **Slides** has **New Slide**. See [Add, change, and delete slides](slides).
- **Tables** has **Table**, which opens a grid to pick the rows and columns, and **Insert Table…**. See [Shapes, pictures, tables, and Text Art](objects).
- **Images** has **Pictures**, which adds picture files to the slide. See [Shapes, pictures, tables, and Text Art](objects).
- **Illustrations** has **Shapes**, a gallery of lines, arrows, and shapes to draw. See [Shapes, pictures, tables, and Text Art](objects).
- **Text** has **Text Box**, **Header and Footer**, and **Date and Time**. See [Type and format text](text) and [Slide size, background, and footers](design).
- **Links** has **Link** (Ctrl+K), which links text or an object to a web page, to a place in the presentation, or to an email address. See [Type and format text](text).
- **Symbols** has **Symbol**, for characters that aren't on the keyboard. See [Type and format text](text).
- **Media** has **Video** and **Audio**. Each opens a menu with **Video on This Device…** or **Audio on This Device…**, which puts a movie or a sound from a file on the slide. Once one is selected, the **Playback** tab sets how it plays.
