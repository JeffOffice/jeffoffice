# Open and save publications
<!-- keywords: open, save, save as, save a copy, close, recent files, pinned, file types, jpub, rename, backup, properties, info, mark as final, inspect, version history, new name, copy, Ctrl+S, read-only, read only, open as copy, new window, my templates, save as template, repair, open and repair, damaged -->

JeffPub saves your work in .jpub files. It also opens and saves .pub files. See [Work with .pub files](pub-files).

## Save

Press Ctrl+S, click the **Save** button in the quick toolbar, or click **File > Save**. The first time, JeffPub asks for a name and a place. After that, Save replaces the file with your latest work.

A star (*) after the name in the title bar means you have changes you have not saved. Save often. If JeffPub stops by surprise, see [Get back unsaved work](recover).

To keep the last saved copy of a file, turn on **Always create backup copy**. Each time you save, JeffPub first copies the old file to one called "Backup of" plus its name, in the same folder. If the copy can't be made, the app asks whether to save without it. The answer is No unless you say Yes, and the file stays as it was. You find this option in **File > Options**, on the **General** tab. Every JeffOffice app has it.

## Save with a new name

Click **File > Save As**, or press F12. Type a name, pick **Save as type**, and click **Save**. The choices are:

- **JeffPub Publication (*.jpub)** is the normal choice.
- **.pub Publication Files (*.pub)** makes a .pub file.
- **PDF (*.pdf)** makes a PDF and leaves your publication as it was.
- **JeffPub Template (*.jpub)** adds the publication to **My Templates**.

After a .jpub or .pub save, the title bar shows the new name, and you keep working in the new file.

## Save a copy

Click **File > Save a Copy** and choose a name. JeffPub writes the publication to that file, and you keep working in the one you had. Its name and its unsaved changes stay as they were.

## Open

1. Press Ctrl+O, or click **File > Open**.
2. Click **Browse** to pick a file. Or click a name under **Pinned** or **Recent Publications**.

You can also drag a .jpub or .pub file onto the page. If your current publication has unsaved changes, JeffPub asks about them first.

Right-click a name in the list to **Pin to list** (it stays at the top) or **Remove from list**. A name in gray means JeffPub can't find that file now. To change how many recent names show, see [Change JeffPub's settings](options).

## Other ways to open a file

On the **Open** page, click **More Ways to Open**. You can also right-click a name in the Recent list.

- **Open Read-Only** opens the publication for reading only. You can look and scroll, but you can't change anything. The title bar says "Read-Only". If you press **Save**, JeffPub asks for a new name, so the file you opened is not changed.
- **Open as Copy** opens the publication with no file of its own. **Save** asks where to put it.
- **Open in New Window** opens the file in a window of its own.
- **Open and Repair** is for a .jpub file that is damaged, for example one that was cut short when it was copied. JeffPub reads every part of the file that it can, and leaves out a part it can't read. The publication opens as a copy called "Repaired" plus the name, and a message tells you what was left out. The damaged file is not changed.

## Close

Click **File > Close**, or press Ctrl+F4. JeffPub asks whether to save changes, then gives you a blank page.

## Info: properties, Mark as Final, Inspect, and versions

**File > Info** shows where the file is, with **Show in Folder** and **Copy Path**. It shows facts about your publication: pages, page size, pictures, words, and dates. Type in the boxes to set its **Title**, **Author**, **Subject**, **Keywords**, **Categories**, **Comments**, **Company**, and **Manager**, and click **Custom Properties** for properties of your own. The change is saved with the publication, and **Ctrl+Z** takes it back. The page also opens your business information, the **Commercial Print Settings** (see [PDF files and print shops](pdf)), and the [Design Checker](design-checker).

- **Mark as Final** saves the publication and then holds it for reading only. When someone opens it, the title bar says it is read-only, and a note tells them it was marked as final. It is not a lock: choose **Marked as Final** again to edit it. A .pub file can't hold the mark, so save as a .jpub file first.
- **Inspect Publication** lists what the file holds that you may not want to share, and removes it: the comments and the names of the people who wrote them, the author and other names in the properties, the business information, the mail merge list, and the objects parked on the scratch area beside the pages.
- **Remove personal information from this file when saving**, under the cards, takes the author, the person who saved the file last, the company, and the manager out of the file each time you save, for a .jpub or a .pub file. It is the same box as in **Options**, and the same in every JeffOffice app.
- **Version History** keeps named copies of the publication on your computer. Save the publication first. Click **Keep a Version…**, and later choose one to **Open a Copy** of it, **Go Back to It** (the publication as it is now is kept as a version first), or **Delete** it.

A .jpub file has no form for a password, so JeffPub has no password card. JeffPub has no accessibility check yet, so the page has no card for one.

## If Windows won't let JeffPub save

Windows Security can block programs from saving in folders such as Documents. JeffPub then shows a message with steps to allow it. Or save in a different folder.
