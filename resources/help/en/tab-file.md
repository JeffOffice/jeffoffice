# File tab
<!-- keywords: file, file menu, backstage, file page, new, open, save, print, export, share, info, properties, close, settings, options, about -->

The **File** button is at the left of the tabs, and it is always there. It opens the File page, which fills the window. The page has a list of choices down the left side. Press Esc, or click **Back to publication**, to return to your work. You can also press Alt, then F. The version number is at the bottom of the list.

- **New** starts a publication from a template or a blank page. See [Start a new publication](create).
- **Open** opens a publication, and lists recent and pinned ones. It also has **Recover Unsaved Work**. See [Open and save publications](open-save) and [Get back unsaved work](recover).
- **Save** saves the publication you are working on. See [Open and save publications](open-save).
- **Save As** saves the publication under a new name or as another kind of file. See [Open and save publications](open-save).
- **Print** sets up and prints your pages, with a preview. See [Print a publication](printing).
- **Export** makes PDFs, pictures, a web page, an e-book, a .pub file, and packages for printers. See [PDF files and print shops](pdf) and [Save as a picture, web page, or e-book](export).
- **Share** saves an email message that holds your page, your publication, or a PDF. See [Save as a picture, web page, or e-book](export).
- **Info** shows where the file is, the publication's properties to read and edit (title, author, subject, keywords, categories, comments, company, and manager), its pages, size, pictures, words, and dates, and a picture of the page. It has cards for **Mark as Final**, **Inspect Publication**, **Version History**, **Business Information**, **Commercial Print Settings**, and **Run Design Checker**. See [Open and save publications](open-save) and [Check your design](design-checker).
- **Close** closes the publication and gives you a blank page. It asks to save changes first.
- **Options** opens the **JeffPub Options** window. See [Change JeffPub's settings](options).
- **About** shows the version, update and statistics choices, and the license. See [Get help and report problems](support).
