# Hilfe erhalten und Probleme melden

Wenn sich JeffPub merkwürdig verhält oder Sie eine Idee haben, wie es besser werden kann, teilen Sie dies den Entwicklern mit. Das geschieht auf GitHub, einer Website, auf der Probleme und Ideen gesammelt und verfolgt werden.

## Zuerst nach einer Antwort suchen

- Drücken Sie **F1**, oder klicken Sie auf **Hilfe > Hilfe > Hilfe**, und geben Sie einige Wörter in das Suchfeld ein. Siehe [Willkommen bei JeffPub](start).
- Klicken Sie auf **Hilfe > Hilfe > Tastenkombinationen**, um die Tasten anzuzeigen. Siehe [JeffPub mit der Tastatur verwenden](keyboard).
- Klicken Sie auf **Hilfe > Hilfe > Neuigkeiten**, um die Anmerkungen zu Ihrer Version zu lesen.
- Wenn Sie nach dem Schließen von JeffPub Arbeit verloren haben, lesen Sie [Nicht gespeicherte Arbeit wiederherstellen](recover).
- Prüfen Sie, ob Sie die neueste Version haben. Klicken Sie auf **Datei > Info** und dann auf **Nach Updates suchen**. Möglicherweise ist das Problem bereits behoben.

## Ein Problem melden oder eine Idee vorschlagen

1. Klicken Sie auf **Hilfe > Hilfe > Feedback**. In Ihrem Webbrowser wird eine Seite auf GitHub geöffnet. Um dort etwas zu veröffentlichen, benötigen Sie ein kostenloses GitHub-Konto.
2. Geben Sie einen kurzen Titel ein, zum Beispiel „Text verschwindet beim Drucken“ oder „Idee: mehr Rahmenarten“.
3. Beschreiben Sie unter **What would you like to tell us?**, was schiefgelaufen ist oder was Sie sich wünschen. Notieren Sie dabei jede Meldung, die Sie gesehen haben.
4. Führen Sie bei einem Problem unter **What did you do just before it happened?** Ihre Schritte der Reihe nach auf, damit jemand anderes sie nachvollziehen kann.
5. Lassen Sie die letzte Zeile stehen. Sie nennt Ihre JeffPub-Version und Ihr Betriebssystem. Falls sie fehlt, fügen Sie die Versionsnummer aus **Datei > Info** hinzu.
6. Senden Sie den Beitrag mit der Schaltfläche auf der GitHub-Seite ab.

Ein Bild des Problems ist hilfreich. Veröffentlichen Sie keine Publikation, die private Informationen enthält.

## Info zu JeffPub

Klicken Sie auf **Datei > Info**, um Ihre Versionsnummer anzuzeigen, nach Updates zu suchen und die Lizenz und die Danksagungen zu lesen. Die Seite enthält außerdem Links zum Quellcode, zu den Downloads und zu **Problem melden**. Informationen zu den Einstellungen für Updates und Statistiken finden Sie unter [Einstellungen von JeffPub ändern](options).
