# Farb- und Schriftartenschemas
<!-- keywords: Farbschema, Design, Farbpalette, Palette, Schriftartenschema, Schriftarten, Schriften, Hintergrund, Seitenhintergrund, Farbverlauf, Textur, Muster, Vorlage ändern, Akzentfarben, Überschriftenschriftart, Textkörperschriftart, Umgestalten, neu formatieren -->

Ein Farbschema ist ein Satz von Farben, den Ihre gesamte Publikation gemeinsam verwendet. Ein Schriftartenschema ist ein Paar von Schriftarten, eine für Überschriften und eine für den Textkörper. Wenn Sie ein Schema wechseln, wird die Publikation in einem Schritt umgestaltet. Die Tools finden Sie auf der Registerkarte **Seitenentwurf**.

## Ein Farbschema auswählen

Klicken Sie im Katalog unter **Seitenentwurf > Schemas** auf ein Schema. Es stehen mehr als 90 zur Auswahl.

Jedes Schema hat acht Farben: Hauptfarbe, Akzent 1 bis Akzent 5, Link und Besuchter Link. Wenn Sie ein Objekt mit einer dieser Farben einfärben, folgt das Objekt dem Schema. Ein Banner mit der Füllung Akzent 1 ändert zum Beispiel seine Farbe, wenn Sie ein neues Schema auswählen. Eine selbst gemischte Farbe bleibt unverändert.

## Ein eigenes Farbschema erstellen

1. Klicken Sie unten im Katalog auf **Neues Farbschema erstellen…**.
2. Klicken Sie im Fenster **Neues Farbschema erstellen** auf die einzelnen Farbschaltflächen, und wählen Sie jeweils eine Farbe aus.
3. Geben Sie unter **Name des Farbschemas** einen Namen ein, und klicken Sie auf **OK**.

Die neuen Farben werden sofort auf Ihre Publikation angewendet.

## Ein Schriftartenschema auswählen

Klicken Sie auf **Seitenentwurf > Schemas > Schriftarten**. Jeder Eintrag zeigt den Namen des Schemas und seine beiden Schriftarten an, zum Beispiel „Modern — Montserrat / Open Sans“. Text, der die Schemaschriftarten verwendet, ändert sich. Text, dem eine bestimmte Schriftart zugewiesen ist, ändert sich nicht.

- **Neues Schriftartenschema erstellen…**: Wählen Sie eine **Überschriftenschriftart**, eine **Textkörperschriftart** und einen Namen aus.
- **Schriftartenschema aktualisieren**: Entfernt fest zugewiesene Schriftarten aus Ihren Formatvorlagen, sodass Text mit diesen Formatvorlagen die Schemaschriftarten verwendet.

## Einen Seitenhintergrund festlegen

1. Wechseln Sie zu der Seite.
2. Klicken Sie auf **Seitenentwurf > Seitenhintergrund > Hintergrund**.
3. Wählen Sie **Kein Hintergrund**, eine einfarbige Füllung oder einen Farbverlauf (eine Farbe, die in eine andere übergeht). Die Farben stammen aus Ihrem Farbschema.

Unten im Katalog öffnet **Weitere Hintergründe…** das Fenster **Hintergrund formatieren** mit Registerkarten für Farbverlauf, Textur, Bild, Muster und Farbton. **Hintergrund auf alle Seiten anwenden** überträgt diesen Hintergrund auf jede Seite.

Um ein Bild zu verwenden, markieren Sie es, und klicken Sie auf **Seitenentwurf > Seitenhintergrund > Bild als Hintergrund verwenden**. Das Bild wird zum Hintergrund, und das Bildobjekt wird entfernt.

Ein Hintergrund gehört zu einer Seite. Ein Hintergrund auf einer Masterseite wird auf jeder Seite angezeigt, die diese Masterseite verwendet, sofern die Seite keinen eigenen Hintergrund hat. Eine Masterseite ist eine Hintergrundseite, deren Inhalt sich auf anderen Seiten wiederholt.

## Die Vorlage ändern

**Seitenentwurf > Vorlage > Vorlage ändern** öffnet einen Katalog mit Entwürfen. Wählen Sie einen aus, und JeffPub überträgt Text und Bilder der geöffneten Publikation in diesen Entwurf. Sie können ihn auf die geöffnete Publikation anwenden oder eine neue Publikation erstellen und die aktuelle unverändert lassen. Ihr Farbschema und Ihr Schriftartenschema ändern sich nur, wenn Sie im Katalog andere auswählen. Um eine Publikation umzugestalten, ohne ihren Entwurf zu ändern, ändern Sie stattdessen hier ihre Schemas und Hintergründe. Siehe [Vorlage einer Publikation ändern](change-template).
