# Bilder hinzufügen und anpassen

Ein Bild liegt in einem Rahmen. Sie können das Bild zuschneiden sowie den Rahmen verschieben und in der Größe ändern.

## Ein Bild aus einer Datei einfügen

1. Klicken Sie auf **Einfügen > Illustrationen > Bilder**.
2. Wählen Sie im Fenster **Bild einfügen** eine Datei aus. JeffPub öffnet PNG-, JPEG-, GIF-, BMP-, TIFF-, WebP-, SVG-, WMF-, EMF-, ICO- und PDF-Dateien.
3. Wählen Sie im Feld **Einfügen als**, das neben der Dateiliste steht und mit der Tabulatortaste erreicht werden kann, **Einfügen**, **Mit Datei verknüpfen** oder **Einfügen und verknüpfen**. Beim Öffnen des Fensters ist immer **Einfügen** ausgewählt. Siehe „Ein Bild mit seiner Datei verknüpfen“ weiter unten.
4. Klicken Sie auf **Öffnen**.

Das Bild wird in der Seitenmitte eingefügt. Sie können eine Bilddatei auch auf die Seite ziehen; dabei wird immer **Einfügen** verwendet.

JeffPub liest Bilddateien mit einer Größe von bis zu 256 MB. Eine größere Datei wird abgelehnt, ebenso eine leere Datei oder alles, was keine gewöhnliche Datei auf dem Datenträger ist, etwa ein Gerät oder eine Pipe. Die Meldung besagt, dass JeffPub die Datei nicht als Bild lesen kann.

Wenn Sie mehrere Bilder gleichzeitig auswählen, werden sie als Miniaturansichten auf dem Arbeitsbereich angeordnet, dem grauen Bereich neben der Seite. Ziehen Sie die gewünschten Bilder auf die Seite.

Hat eine PDF-Datei mehr als eine Seite, zeigt das Fenster **PDF-Seite einfügen** jede Seite an. Wählen Sie eine aus und klicken Sie auf **OK**.

## Ein Bild mit seiner Datei verknüpfen

**Einfügen** legt eine Kopie des Bilds in der Publikation ab. Diese Kopie wandert mit der Publikation mit, aber eine Publikation mit vielen großen Fotos wird dadurch ebenfalls groß. Eine Verknüpfung hält die Fotos stattdessen in ihren eigenen Dateien.

- **Einfügen** legt eine Kopie des Bilds in der Publikation ab. Das ist die übliche Wahl.
- **Mit Datei verknüpfen** speichert nur den Speicherort der Datei und eine kleine Vorschau mit höchstens 512 Pixeln an der längsten Seite. Das Bild auf der Seite sowie im Ausdruck, in einer PDF-Datei oder in einem E-Book stammt in voller Qualität aus der Datei. Wird die Datei verschoben oder gelöscht, zeigt die Seite stattdessen die kleine Vorschau.
- **Einfügen und verknüpfen** tut beides. Die Publikation enthält das vollständige Bild und die Verknüpfung. Öffnen Sie die Publikation und hat sich die Datei geändert, liest JeffPub sie erneut ein und ersetzt die Kopie.

JeffPub merkt sich den vollständigen Speicherort der Datei sowie die Lage im Verhältnis zur Publikation, etwa „der Ordner Fotos neben ihr“. Verschieben Sie die Publikation zusammen mit ihren Bildern, gilt die relative Lage, sodass die Bilder wieder gefunden werden. Behalten Sie die Ordnerstruktur bei.

JeffPub öffnet die Datei eines verknüpften Bilds nur dann selbstständig, wenn sie im Ordner der Publikation oder in einem Unterordner liegt. Ein Bild, dessen Datei woanders liegt, zeigt seine gespeicherte, unscharfe Vorschau und wird mit **Nicht aktualisiert** gekennzeichnet, bis Sie es auswählen und im Grafik-Manager auf **Verknüpfung aktualisieren** klicken. So kann eine Publikation, die Ihnen jemand schickt, nicht auf Ihren Computer zugreifen. Damit Bilder von selbst geladen werden, legen Sie sie in den Ordner der Publikation.

Der **Grafik-Manager** zeigt für jedes Bild, ob es **Eingebettet**, **Verknüpft**, **Fehlt**, **Geändert** oder **Nicht aktualisiert** ist, und bietet Schaltflächen, um eine Verknüpfung zu aktualisieren, auf eine andere Datei zu zeigen oder in eine Kopie umzuwandeln. Siehe [Grafik-Manager](graphics-manager).

Wenn Sie eine Publikation als `.pub`-Datei speichern, eine Pack-and-Go-Datei erstellen oder per E-Mail senden, legt JeffPub jedes verknüpfte Bild vollständig in der Datei ab, damit sie nicht von Dateien abhängt, die zurückbleiben. Fehlt eine verknüpfte Datei dann oder ist das Bild **Nicht aktualisiert**, wird stattdessen die kleine Vorschau eingefügt. Eine geöffnete `.pub`-Datei enthält nie Verknüpfungen: Ihre Bilder werden als Kopien eingelesen.

## Einen Bildplatzhalter hinzufügen

Ein Platzhalter ist ein leerer Rahmen, der einen Platz für ein Bild freihält. Klicken Sie auf **Einfügen > Illustrationen > Bildplatzhalter**, doppelklicken Sie dann auf den Rahmen und wählen Sie eine Datei aus. Das Bild füllt den Rahmen aus, überstehende Kanten werden ausgeblendet. Ein leerer Platzhalter wird nicht gedruckt.

## Kostenlose Bilder im Internet finden

Klicken Sie auf **Einfügen > Illustrationen > Onlinebilder**. Der Bereich **Onlinebilder** durchsucht zwei kostenlose Bibliotheken mit Bildern unter offenen Lizenzen: Openverse, das viele Sammlungen umfasst, und Wikimedia Commons, die Bildbibliothek von Wikipedia.

1. Wählen Sie eine Bibliothek, geben Sie ein, wonach Sie suchen, etwa „roter Stall“, und drücken Sie die Eingabetaste.
2. Klicken Sie auf ein Bild, um zu sehen, wer es gemacht hat und unter welcher Lizenz es steht. Eine Lizenz ist die Gesamtheit der Regeln für die Nutzung des Bilds. Die meisten verlangen, dass Sie den Urheber nennen.
3. Klicken Sie auf **Einfügen**. JeffPub setzt das Bild auf die Seite und verwendet seinen Titel als Alternativtext. Ist **Quellenangabe unter dem Bild hinzufügen** aktiviert, erscheint darunter eine Zeile wie „Roter Stall“ von Pat Lee, CC BY 2.0.

Ihre Suchbegriffe gehen an die gewählte Bibliothek. Prüfen Sie, ob die Lizenz jedes Bilds zu Ihrer Verwendung passt.

Eine Suche zeigt bis zu 24 Bilder an. JeffPub verwendet nur sichere (https-)Webadressen einer Bibliothek und lässt jedes Bild weg, dessen Adresse keine solche ist. Bei Wikimedia Commons kommt ein Bild, das breiter als 1.920 Pixel ist, als Kopie in dieser Breite und nicht als Originalupload. Ein Download über 50 MB oder einer, der zu lange dauert, wird abgebrochen; der Bereich meldet dann, dass das Bild nicht heruntergeladen oder geladen werden konnte.

## Ein Bild zuschneiden

Beim Zuschneiden werden die Ränder eines Bilds ausgeblendet.

1. Klicken Sie auf das Bild und dann auf **Bildformat > Zuschneiden > Zuschneiden**.
2. Ziehen Sie an einem Ziehpunkt, um einen Teil des Bilds auszublenden. Ziehen Sie am Bild, um es im Rahmen zu verschieben.
3. Klicken Sie erneut auf **Zuschneiden** oder drücken Sie **Esc**.

Ebenfalls in der Gruppe **Zuschneiden**: **Seitenverhältnis** schneidet den Rahmen um seine Mitte auf eine Form wie ein Quadrat, 4 breit zu 3 hoch oder 16 zu 9 zu (das Bild bleibt an seiner Stelle auf der Seite). **Einpassen** zeigt das ganze Bild im Rahmen, **Ausfüllen** füllt den Rahmen aus, **In Form zuschneiden** schneidet auf eine Form wie eine Ellipse zu, und **Zuschnitt entfernen** zeigt das ganze Bild wieder an.

## Aussehen eines Bilds ändern

Verwenden Sie auf der Registerkarte **Bildformat** die Gruppe **Anpassen**:

- **Korrekturen**: Wählen Sie ein Paar aus Helligkeit und Kontrast, von minus 40 bis plus 40 Prozent. **Objekt formatieren…** unten im Menü bietet Schieberegler.
- **Farbe**: Stellen Sie das Bild als Graustufen, Sepia, Ausgewaschen, Schwarzweiß oder mit einem Akzentfarbton dar. **Transparente Farbe festlegen** macht die Farbe in der oberen linken Ecke des Bilds transparent.
- **Transparenz…**: Blenden Sie das ganze Bild aus.
- **Bild zurücksetzen**: Entfernt alle Änderungen aus dieser Liste sowie Rahmen, Form und Effekte des Bilds. Auch der Zuschnitt geht verloren, sodass der Rahmen das ganze Bild zeigt. Klicken Sie auf den Pfeil daneben für **Bild und Größe zurücksetzen**; das setzt zusätzlich die Größe zurück, die das Bild in seiner Datei hat.
- **Bilder komprimieren…**: Verkleinert die Datei, indem die Detailgenauigkeit auf 300, 220 oder 96 ppi (Pixel pro Zoll) gesenkt wird. Standardmäßig werden alle Bilder geändert und zugeschnittene Bereiche gelöscht.
- **In Formen konvertieren**: Wandelt ein SVG-Bild (eine Zeichnung aus Linien und Formen) in bearbeitbare Formen um; dabei werden Teile entfernt, die die Zeichnung abschneidet. Text und Bilder darin fallen weg.

## Bildformatvorlagen, Rahmen und Effekte

Verwenden Sie die Gruppe **Bildformatvorlagen** auf der Registerkarte **Bildformat**:

- Die **Galerie** zeigt etwa zwei Dutzend fertige Looks: Rahmen, Schatten, Spiegelungen, weiche Kanten, abgerundete und ovale Formen, eine Drehung im Raum, ein Leuchten und Abschrägungen. Eine Abschrägung ist eine schräge Kante, die das Bild erhaben wirken lässt. Jede Kachel zeigt Ihre Farben. Klicken Sie auf eine, um dem Bild diesen Look zu geben. Eine Formatvorlage legt Form, Rahmen und Effekte gemeinsam fest und ersetzt die vorhandenen. Zuschnitt, Größe und Farben bleiben erhalten.
- **Bildrahmen** legt Farbe, **Stärke** (wie dick die Linie ist) und **Striche** (eine durchgehende, punktierte oder gestrichelte Linie) fest. **Keine Kontur** entfernt den Rahmen.
- **Bildeffekte** öffnet **Schatten**, **Spiegelung**, **Leuchten**, **Weiche Kanten**, **Abschrägung** und **3D-Drehung**. Jede Gruppe hat fertige Auswahlmöglichkeiten. Wählen Sie eine aus, um sie hinzuzufügen. Die übrigen Effekte bleiben erhalten. Wählen Sie den ersten Eintrag, etwa **Kein Schatten**, um einen Effekt zu entfernen. **Weitere Effektoptionen…** öffnet **Objekt formatieren**.

Jeder Schritt lässt sich mit einem Schritt rückgängig machen.

## Beschriftung, Alternativtext und Austausch

- **Bildformat > Bildformatvorlagen > Beschriftung** fügt ein Textfeld unter dem Bild hinzu.
- Der Alternativtext ist eine kurze Beschreibung für Menschen, die das Bild nicht sehen können, etwa für Nutzer von Bildschirmleseprogrammen. Klicken Sie mit der rechten Maustaste auf das Bild, wählen Sie **Objekt formatieren…**, öffnen Sie die Registerkarte **Alternativtext** und geben Sie im Feld **Alternativtext** ein.
- **Bildformat > Einfügen > Bild ändern** setzt eine andere Datei in denselben Rahmen. Der Rahmen behält Größe, Position und Aussehen bei: Rahmen, Form, Effekte und Farbänderungen. Hat das neue Bild dieselbe Form wie das alte, bleibt auch der Zuschnitt erhalten. Hat es eine andere Form, füllt es den Rahmen aus.
- Um zwei Bilder zu tauschen, ziehen Sie eines auf das andere. Erscheint der Hinweis **Loslassen, um die Bilder zu tauschen**, lassen Sie los: Die Bilder wechseln die Rahmen, und der Rahmen, den Sie gezogen haben, kehrt an seine Stelle zurück. Oder halten Sie die Umschalttaste gedrückt, klicken beide Bilder an und klicken auf **Tauschen**. Halten Sie beim Ziehen die Strg-Taste gedrückt, um stattdessen ein Bild zu kopieren. Eine Kopie, die Sie über einem anderen Bild loslassen, bleibt dort, wo Sie sie abgelegt haben, und es wird nichts getauscht.

## Alle Bilder anzeigen

Klicken Sie auf **Ansicht > Anzeigen > Grafik-Manager**, um alle Bilder im Bereich **Grafik-Manager** aufzulisten. Wählen Sie ein Bild aus und klicken Sie dann auf **Gehe zu**, um dorthin zu springen, auf **Speichern unter…**, um eine Kopie zu speichern, oder auf **Ersetzen…**, um eine andere Datei zu wählen. Bei verknüpften Bildern gibt es außerdem **Verknüpfung aktualisieren**, **Verknüpfung ändern…** und **Bild einbetten**. Siehe [Grafik-Manager](graphics-manager).
