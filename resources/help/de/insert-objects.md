# Symbole, Barcodes und andere Objekte
<!-- keywords: Symbol, Icon, Sonderzeichen, Barcode, ISBN, UPC, Baustein, Kalender, Rahmen, Anzeige, Unternehmensinformationen, Datum und Uhrzeit, Hyperlink, Link, Datei einfügen, Zeichen einfügen, Grafik -->

Dieser Abschnitt beschreibt weitere Elemente, die Sie über die Registerkarte **Einfügen** hinzufügen können. Bilder, Formen, Tabellen, Textkunst und Fußnoten haben eigene Abschnitte.

## Symbole

1. Klicken Sie auf **Einfügen > Illustrationen > Symbole**.
2. Geben Sie im Fenster **Symbole einfügen** ein Wort ein, etwa Pfeil, Brief oder Stern.
3. Klicken Sie auf ein Symbol. Halten Sie **Strg** oder **Umschalt** gedrückt, während Sie klicken, um mehrere auszuwählen.
4. Klicken Sie auf **Einfügen**.

JeffPub enthält mehr als 1.500 Symbole aus der Lucide-Sammlung. Jedes Symbol wird in der Mitte der Seite eingefügt, 2,5 cm hoch, und in der Hauptfarbe Ihres Farbschemas gefärbt. Ein Symbol ist eine Form. Sie können seine Farbe deshalb über **Formkontur** auf der Registerkarte **Formformat** ändern.

## Barcodes

1. Klicken Sie auf **Einfügen > Illustrationen > Barcode**.
2. Wählen Sie im Fenster **Barcode einfügen** einen **Typ**: Buch (ISBN), EAN-13, UPC-A, EAN-8, Code 128, Code 39 oder QR-Code. Ein QR-Code kann beliebigen Text enthalten, etwa eine Webadresse. Er hat die Einstellung **Fehlerkorrektur**: Eine höhere Stufe lässt den Code auch dann noch lesen, wenn ein größerer Teil beschädigt oder verdeckt ist, und macht den Code größer.
3. Geben Sie die Nummer oder den Text ein. Bei einem Buch geben Sie die ISBN ein. JeffPub setzt die Bindestriche selbst.
4. Bei einem Buch wählen Sie einen Preiszusatzcode oder **Kein Zusatzcode**. Bei EAN- und UPC-Codes können Sie einen Zusatzcode mit 2 oder 5 Ziffern eingeben.
5. Prüfen Sie die Vorschau und klicken Sie dann auf **Einfügen**.

Ist etwas nicht in Ordnung, weist das Fenster rot darauf hin, und **Einfügen** bleibt ausgegraut. Außerdem können Sie **Vergrößerung** und **Balkenhöhe** einstellen. Lassen Sie **Weißer Hintergrund** eingeschaltet, denn Scanner brauchen den freien Rand. Um einen Barcode später zu ändern, doppelklicken Sie darauf. Damit die Bindestriche für jedes Land richtig gesetzt werden, lädt JeffPub die Bereichsliste der Internationalen ISBN-Agentur herunter und behält eine Kopie.

## Bausteine

Ein Baustein ist eine fertige Gruppe von Objekten, etwa eine Überschrift oder ein Gutschein. Öffnen Sie eine Galerie unter **Einfügen > Bausteine**:

- **Seitenelemente**: Überschriften, hervorgehobene Zitate, Randleisten, zwei- und dreispaltige Artikel sowie ein Inhaltsverzeichnis. Ein hervorgehobenes Zitat ist ein kurzes Zitat aus dem Artikel, groß gesetzt.
- **Kalender**: dieser Monat oder nächster Monat. Für einen anderen Monat klicken Sie auf **Weitere Kalender…** und wählen im Fenster **Kalender** Monat, Jahr und Entwurf.
- **Rahmen und Akzente**: Balken, Linien, Rahmen und Eckelemente.
- **Anzeigen**: Gutschein, Verkaufsanzeige, Veranstaltungsanzeige, Explosionsform, Preisschild und mehr.

Klicken Sie auf einen Baustein, um ihn einzufügen. Er verwendet Ihr Farbschema und Ihre Schriftarten. Er besteht aus gewöhnlichen Textfeldern und Formen und lässt sich deshalb wie alles andere bearbeiten.

## Unternehmensinformationen

Klicken Sie auf **Einfügen > Text > Unternehmensinformationen** und wählen Sie eine Angabe, etwa Firmenname, Adresse, Telefon, Website oder Logo. Steht der Cursor in einem Textfeld, wird die Angabe dort eingefügt. Andernfalls legt JeffPub ein neues Textfeld an. Wählen Sie **Unternehmensinformationen bearbeiten…**, um Ihre Angaben einzutragen oder zu ändern. Eingefügte Angaben werden aktualisiert, wenn Sie sie ändern.

## Text, Links und weitere Elemente

- **Einfügen > Text > Text aus Datei** übernimmt Text aus einer Datei mit der Endung .txt, .rtf, .html, .docx, .doc, .odt oder .md, bis zu 64 MB groß. Der Text wird an der Cursorposition eingefügt oder, wenn gerade kein Text bearbeitet wird, in einem neuen Textfeld. Das geschieht in einem Schritt, den Sie rückgängig machen können. Eine Datei, die zu groß ist, sich nicht öffnen lässt, nicht dem Dokumenttyp entspricht, den ihr Name angibt, oder mit einem Kennwort geschützt ist, wird nicht eingefügt. JeffPub teilt Ihnen das mit, und die Publikation bleibt unverändert. Dasselbe gilt, wenn Sie Textdateien auf die Seite ziehen. Die anderen abgelegten Dateien werden trotzdem übernommen. Der Text übernimmt Fett, Kursiv, Unterstreichung und Ausrichtung. Bei einer .docx-, .doc- oder .odt-Datei werden Bilder, Tabellen, Listen, Kommentare und Notizen als einfacher Text übernommen oder weggelassen, und JeffPub gibt die Anzahl an. Text in einem Textfeld wird als normale Zeilen übernommen. Die Nummern und Aufzählungszeichen einer Liste bleiben nicht erhalten. Kopf- und Fußzeilen werden nicht gelesen, und JeffPub weist nicht darauf hin. Eine Datei ohne Text wird nicht eingefügt, und JeffPub teilt Ihnen das mit. Enthält eine Datei mehr als 600.000 Absätze, Tabellenzellen oder Textabschnitte, wird nur bis zu dieser Grenze gelesen, und JeffPub meldet, dass das Ende fehlt.
- **Symbol** fügt ein Sonderzeichen ein, etwa © oder é. Klicken Sie zuerst in ein Textfeld.
- **Datum und Uhrzeit**: Klicken Sie zuerst in ein Textfeld, wählen Sie eine **Sprache** für die Namen der Wochentage und Monate, wählen Sie ein Format und aktivieren Sie **Automatisch aktualisieren**, damit das Datum stets aktuell bleibt. Das Feld behält seine Sprache. Eine .pub-Datei speichert das Format, aber nicht die Sprache. Ein dort gespeichertes Datum wird deshalb beim erneuten Öffnen in der Sprache des Computers angezeigt.
- **Einfügen > Links > Link** (Strg+K) erstellt einen Hyperlink auf eine Webseite, eine Seite Ihrer Publikation oder eine E-Mail-Adresse. Markieren Sie zuerst Text oder ein Objekt. Wählen Sie **Link entfernen**, um ihn wieder zu löschen.
- **Textmarke** vergibt einen Namen für den markierten Text oder das markierte Objekt.
- **Objekt** lässt Sie eine Datei auswählen und fügt sie als Bild ein.
