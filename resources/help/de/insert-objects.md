# Symbole, Barcodes und andere Objekte
<!-- keywords: Symbol, Sonderzeichen, Barcode, ISBN, UPC, Bausteine, Kalender, Rahmen, Anzeige, Unternehmensinformationen, Datum und Uhrzeit, Hyperlink, Link, Datei einfügen, Icon -->

Dieses Thema behandelt die übrigen Objekte, die Sie über die Registerkarte **Einfügen** hinzufügen können. Bilder, Formen, Tabellen, Textkunst und Fußnoten haben eigene Themen.

## Symbole

1. Klicken Sie auf **Einfügen > Illustrationen > Symbole**.
2. Geben Sie im Fenster **Symbole einfügen** ein Wort ein, etwa Pfeil, E-Mail oder Stern.
3. Klicken Sie auf ein Symbol. Halten Sie **Strg** oder **Umschalt** gedrückt, während Sie klicken, um mehrere auszuwählen.
4. Klicken Sie auf **Einfügen**.

JeffPub enthält mehr als 1.500 Symbole aus dem Lucide-Set. Jedes Symbol wird in der Mitte der Seite eingefügt, 2,54 cm (1 Zoll) hoch, in der Hauptfarbe Ihres Farbschemas. Ein Symbol ist eine Form, daher können Sie die Farbe mit **Formkontur** auf der Registerkarte **Formformat** ändern.

## Barcodes

1. Klicken Sie auf **Einfügen > Illustrationen > Barcode**.
2. Wählen Sie im Fenster **Barcode einfügen** unter **Typ** einen Eintrag: Buch (ISBN), EAN-13, UPC-A, EAN-8, Code 128, Code 39 oder QR-Code. Ein QR-Code kann beliebigen Text enthalten, etwa eine Webadresse, und hat die Einstellung **Fehlerkorrektur**. Eine höhere Stufe lässt den Code auch dann noch lesen, wenn mehr davon beschädigt oder verdeckt ist, und macht den Code größer.
3. Geben Sie die Nummer oder den Text ein. Bei einem Buch geben Sie die ISBN ein. JeffPub setzt die Bindestriche selbst.
4. Bei einem Buch wählen Sie einen Preiszusatzcode oder **Kein Zusatzcode**. Bei EAN- und UPC-Codes können Sie einen 2- oder 5-stelligen Zusatzcode eingeben.
5. Prüfen Sie die Vorschau und klicken Sie dann auf **Einfügen**.

Wenn etwas nicht stimmt, zeigt das Fenster eine rote Meldung an, und **Einfügen** bleibt abgeblendet. Außerdem können Sie **Vergrößerung** und **Balkenhöhe** einstellen. Lassen Sie **Weißer Hintergrund** eingeschaltet, weil Scanner den freien Rand benötigen. Um einen Barcode später zu ändern, doppelklicken Sie darauf. Damit die Bindestriche für jedes Land richtig gesetzt werden, lädt JeffPub die Bereichsliste der Internationalen ISBN-Agentur herunter und speichert eine Kopie.

## Bausteine

Ein Baustein ist eine fertige Gruppe von Objekten, etwa eine Überschrift oder ein Gutschein. Öffnen Sie eine Galerie unter **Einfügen > Bausteine**:

- **Seitenelemente**: Überschriften, hervorgehobene Zitate, Randleisten, zwei- und dreispaltige Artikel sowie ein Inhaltsverzeichnis. Ein hervorgehobenes Zitat ist ein kurzes Zitat aus dem Artikel in großer Schrift.
- **Kalender**: diesen Monat oder nächsten Monat. Für einen anderen Monat klicken Sie auf **Weitere Kalender…** und wählen dann im Fenster **Kalender** Monat, Jahr und Entwurf.
- **Rahmen und Akzente**: Balken, Linien, Rahmen und Eckelemente.
- **Anzeigen**: ein Gutschein, eine Verkaufsanzeige, eine Veranstaltungsanzeige, ein Explosionsstern, ein Preisschild und mehr.

Klicken Sie auf einen Baustein, um ihn einzufügen. Er verwendet Ihr Farbschema und Ihre Schriftarten. Er besteht aus gewöhnlichen Textfeldern und Formen, daher lässt er sich wie jedes andere Objekt bearbeiten.

## Unternehmensinformationen

Klicken Sie auf **Einfügen > Text > Unternehmensinformationen** und wählen Sie einen Eintrag, etwa Name der Organisation, Adresse, Telefon, Website oder Logo. Befindet sich der Cursor in einem Textfeld, wird der Eintrag dort eingefügt. Andernfalls legt JeffPub ein neues Textfeld an. Wählen Sie **Unternehmensinformationen bearbeiten…**, um Ihre Angaben einzutragen oder zu ändern. Eingefügte Angaben werden aktualisiert, wenn Sie sie ändern.

## Text, Links und weitere Elemente

- **Einfügen > Text > Datei einfügen** übernimmt Text aus einer Datei mit der Endung .txt, .rtf, .html, .docx oder .md, bis zu 64 MB groß. Der Text wird an der Position des Cursors eingefügt oder in einem neuen Textfeld, wenn gerade kein Text bearbeitet wird. Das geschieht in einem Schritt, den Sie rückgängig machen können. Eine Datei, die zu groß ist, sich nicht öffnen lässt oder nicht dem Dokumenttyp entspricht, den ihr Name angibt, wird nicht eingefügt. JeffPub zeigt eine Meldung an, und die Publikation bleibt unverändert. Wenn Sie Textdateien auf die Seite ziehen, funktioniert das genauso, und die übrigen abgelegten Dateien werden trotzdem übernommen.
- **Sonderzeichen** fügt ein Sonderzeichen ein, etwa © oder é. Klicken Sie vorher in ein Textfeld.
- **Datum und Uhrzeit**: Klicken Sie vorher in ein Textfeld, wählen Sie unter **Sprache** die Sprache für die Namen der Wochentage und Monate, wählen Sie ein Format und aktivieren Sie **Automatisch aktualisieren**, damit das Datum immer aktuell bleibt. Das Feld behält seine Sprache. Eine .pub-Datei speichert das Format, aber nicht die Sprache. Ein dort gespeichertes Datum wird daher beim erneuten Öffnen in der Sprache des Computers angezeigt.
- **Einfügen > Verknüpfungen > Link (Strg+K)** erstellt einen Hyperlink zu einer Webseite, einer Seite Ihrer Publikation oder einer E-Mail-Adresse. Markieren Sie vorher Text oder ein Objekt. Wählen Sie **Link entfernen**, um ihn wieder zu entfernen.
- **Textmarke** vergibt einen Namen für den markierten Text oder das markierte Objekt.
- **Objekt** lässt Sie eine Datei auswählen und sie als Bild einfügen.
