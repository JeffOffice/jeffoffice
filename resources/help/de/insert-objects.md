# Symbole, Barcodes und andere Objekte
<!-- keywords: Symbol, Icon, Sonderzeichen, Barcode, ISBN, UPC, Bausteine, Kalender, Rahmen, Anzeige, Unternehmensinformationen, Datum und Uhrzeit, Hyperlink, Link, Datei einfügen, Textmarke, Objekt -->

Dieses Thema beschreibt weitere Elemente, die Sie über die Registerkarte **Einfügen** hinzufügen können. Bilder, Formen, Tabellen, Textkunst und Fußnoten haben eigene Themen.

## Symbole

1. Klicken Sie auf **Einfügen > Illustrationen > Symbole**.
2. Geben Sie im Fenster **Symbole einfügen** ein Wort wie Pfeil, E-Mail oder Stern ein.
3. Klicken Sie auf ein Symbol. Halten Sie **Strg** oder **Umschalt** gedrückt, während Sie klicken, um mehrere auszuwählen.
4. Klicken Sie auf **Einfügen**.

JeffPub enthält mehr als 1.500 Symbole aus dem Lucide-Satz. Jedes Symbol wird in der Mitte der Seite eingefügt, 2,5 cm hoch, in der Hauptfarbe Ihres Farbschemas. Ein Symbol ist eine Form. Deshalb können Sie seine Farbe mit **Formkontur** auf der Registerkarte **Formformat** ändern.

## Barcodes

1. Klicken Sie auf **Einfügen > Illustrationen > Barcode**.
2. Wählen Sie im Fenster **Barcode einfügen** unter **Typ** einen Eintrag: Buch (ISBN), EAN-13, UPC-A, EAN-8, Code 128, Code 39 oder QR-Code. Ein QR-Code kann beliebigen Text enthalten, etwa eine Webadresse. Er hat außerdem die Einstellung **Fehlerkorrektur**: Eine höhere Stufe lässt den Code auch dann noch lesen, wenn ein größerer Teil beschädigt oder verdeckt ist, macht den Code aber größer.
3. Geben Sie die Nummer oder den Text ein. Bei einem Buch geben Sie die ISBN ein. JeffPub setzt die Bindestriche selbst.
4. Wählen Sie bei einem Buch einen Preiszusatz oder **Kein Zusatzcode**. Bei EAN- und UPC-Codes können Sie einen Zusatzcode mit 2 oder 5 Ziffern eingeben.
5. Prüfen Sie die Vorschau und klicken Sie dann auf **Einfügen**.

Wenn etwas nicht stimmt, zeigt das Fenster das rot an, und **Einfügen** bleibt abgeblendet. Außerdem können Sie **Vergrößerung** und **Balkenhöhe** einstellen. Lassen Sie **Weißer Hintergrund** eingeschaltet, weil Scanner den freien Rand benötigen. Um einen Barcode später zu ändern, doppelklicken Sie darauf. Damit die Bindestriche für jedes Land richtig gesetzt werden, lädt JeffPub die Bereichsliste der Internationalen ISBN-Agentur herunter und behält eine Kopie.

## Bausteine

Ein Baustein ist ein fertiger Satz von Objekten, etwa eine Überschrift oder ein Gutschein. Öffnen Sie eine Galerie unter **Einfügen > Bausteine**:

- **Seitenelemente**: Überschriften, hervorgehobene Zitate, Randleisten sowie Artikel mit zwei oder drei Spalten und ein Inhaltsverzeichnis. Ein hervorgehobenes Zitat ist ein kurzes Zitat aus dem Artikel, groß gesetzt.
- **Kalender**: dieser Monat oder nächster Monat. Für einen anderen Monat klicken Sie auf **Weitere Kalender…** und wählen im Fenster **Kalender** Monat, Jahr und Entwurf aus.
- **Rahmen und Akzente**: Balken, Linien, Rahmen und Eckstücke.
- **Anzeigen**: ein Gutschein, eine Verkaufsanzeige, eine Veranstaltungsanzeige, ein Explosionsstern, ein Preisschild und mehr.

Klicken Sie auf einen Baustein, um ihn einzufügen. Er verwendet Ihr Farbschema und Ihre Schriftarten. Er besteht aus gewöhnlichen Textfeldern und Formen, Sie können ihn also wie jedes andere Objekt bearbeiten.

## Unternehmensinformationen

Klicken Sie auf **Einfügen > Text > Unternehmensinformationen** und wählen Sie eine Angabe, etwa Name der Organisation, Adresse, Telefon, Website oder Logo. Wenn sich der Cursor in einem Textfeld befindet, wird die Angabe dort eingefügt. Ist das nicht der Fall, fügt JeffPub ein neues Textfeld hinzu. Wählen Sie **Unternehmensinformationen bearbeiten…**, um Ihre Angaben einzutragen oder zu ändern. Eingefügte Angaben werden aktualisiert, wenn Sie sie ändern.

## Text, Links und weitere Elemente

- **Einfügen > Text > Text aus Datei** übernimmt Text aus einer Datei mit der Endung .txt, .rtf, .html, .docx oder .md.
- **Symbol** fügt ein Sonderzeichen ein, etwa © oder é. Klicken Sie zuvor in ein Textfeld.
- **Datum und Uhrzeit**: Klicken Sie zuerst in ein Textfeld, wählen Sie ein Format und aktivieren Sie **Automatisch aktualisieren**, damit es immer aktuell bleibt.
- **Einfügen > Links > Link** (Strg+K) erstellt einen Hyperlink zu einer Webseite, einer Seite Ihrer Publikation oder einer E-Mail-Adresse. Markieren Sie zuvor Text oder ein Objekt. Wählen Sie **Link entfernen**, um ihn wieder zu löschen.
- **Textmarke** gibt dem markierten Text oder Objekt einen Namen.
- **Objekt** lässt Sie eine Datei auswählen und fügt sie als Bild ein.
