# Symbole, Barcodes und andere Objekte
<!-- keywords: Symbol, Icon, Sonderzeichen, Barcode, Strichcode, ISBN, UPC, EAN, Baustein, Kalender, Rahmen, Anzeige, Unternehmensinformationen, Datum und Uhrzeit, Link, Hyperlink, Datei einfügen -->

Dieses Thema behandelt die weiteren Elemente, die Sie über die Registerkarte **Einfügen** hinzufügen können. Für Bilder, Formen, Tabellen, Textkunst und Fußnoten gibt es eigene Themen.

## Symbole

1. Klicken Sie auf **Einfügen > Illustrationen > Symbole**.
2. Geben Sie im Fenster **Symbole einfügen** einen Begriff ein, zum Beispiel Pfeil, E-Mail oder Stern.
3. Klicken Sie auf ein Symbol. Halten Sie beim Klicken **Strg** oder **Umschalt** gedrückt, um mehrere auszuwählen.
4. Klicken Sie auf **Einfügen**.

JeffPub bietet mehr als 1.500 Symbole aus dem Lucide-Satz. Jedes Symbol wird in der Mitte der Seite eingefügt, 2,5 cm hoch, in der Hauptfarbe Ihres Farbschemas. Ein Symbol ist eine Form, daher können Sie es mit **Formkontur** auf der Registerkarte **Formformat** neu einfärben.

## Barcodes

1. Klicken Sie auf **Einfügen > Illustrationen > Barcode**.
2. Wählen Sie im Fenster **Barcode einfügen** unter **Typ** eine Option aus: Buch (ISBN), EAN-13, UPC-A, EAN-8, Code 128 oder Code 39.
3. Geben Sie die Nummer oder den Text ein. Geben Sie für ein Buch die ISBN ein. JeffPub fügt die Bindestriche ein.
4. Wählen Sie für ein Buch einen Preis-Zusatzcode oder **Kein Zusatzcode** aus. Für EAN- und UPC-Codes können Sie einen 2- oder 5-stelligen Zusatzcode eingeben.
5. Prüfen Sie die Vorschau, und klicken Sie dann auf **Einfügen**.

Ist etwas fehlerhaft, zeigt das Fenster dies in Rot an, und **Einfügen** bleibt abgeblendet. Sie können außerdem **Vergrößerung** und **Balkenhöhe** festlegen. Lassen Sie **Weißer Hintergrund** aktiviert, da Scanner die Ruhezone benötigen. Um einen Barcode später zu ändern, doppelklicken Sie darauf. Damit die Bindestriche für jedes Land richtig gesetzt werden, lädt JeffPub die Bereichsliste der Internationalen ISBN-Agentur herunter und speichert eine Kopie.

## Bausteine

Ein Baustein ist eine vorgefertigte Gruppe von Objekten, zum Beispiel eine Überschrift oder ein Gutschein. Öffnen Sie einen Katalog unter **Einfügen > Bausteine**:

- **Seitenelemente**: Überschriften, Zitate, Randleisten, zwei- und dreispaltige Artikel und ein Inhaltsverzeichnis. Ein Zitat ist ein kurzer, groß gesetzter Auszug aus dem Artikel.
- **Kalender**: dieser oder nächster Monat. Für einen anderen Monat klicken Sie auf **Weitere Kalender…** und wählen dann im Fenster **Kalender** Monat, Jahr und Entwurf aus.
- **Rahmen und Akzente**: Balken, Linien, Rahmen und Eckelemente.
- **Anzeigen**: ein Gutschein, eine Verkaufsanzeige, eine Veranstaltungsanzeige, eine Explosion, ein Preisschild und mehr.

Klicken Sie auf einen Baustein, um ihn hinzuzufügen. Er verwendet Ihr Farbschema und Ihre Schriftarten. Er besteht aus normalen Textfeldern und Formen, sodass Sie ihn wie jedes andere Objekt ändern können.

## Unternehmensinformationen

Klicken Sie auf **Einfügen > Text > Unternehmensinformationen**, und wählen Sie eine Angabe aus, zum Beispiel Name der Organisation, Adresse, Telefon, Website oder Logo. Steht der Cursor in einem Textfeld, wird die Angabe dort eingefügt. Andernfalls fügt JeffPub ein neues Textfeld hinzu. Wählen Sie **Unternehmensinformationen bearbeiten…**, um Ihre Angaben einzutragen oder zu ändern. Eingefügte Angaben werden aktualisiert, wenn Sie sie ändern.

## Text, Links und weitere Elemente

- **Einfügen > Text > Datei einfügen** übernimmt Text aus einer TXT-, RTF-, HTML-, DOCX- oder MD-Datei.
- **Sonderzeichen** fügt ein Sonderzeichen ein, zum Beispiel © oder é. Klicken Sie zuerst in ein Textfeld.
- **Datum und Uhrzeit**: Klicken Sie zuerst in ein Textfeld, wählen Sie ein Format aus, und aktivieren Sie **Automatisch aktualisieren**, damit die Angabe aktuell bleibt.
- **Einfügen > Links > Link** (Strg+K) erstellt einen Link zu einer Webseite, einer Seite in Ihrer Publikation oder einer E-Mail-Adresse. Markieren Sie zuerst Text oder ein Objekt. Wählen Sie **Link entfernen**, um ihn wieder zu entfernen.
- **Textmarke** gibt dem markierten Text oder Objekt einen Namen.
- **Objekt** lässt Sie eine Datei auswählen und fügt sie als Bild ein.
