# Symbole, Barcodes und andere Objekte
<!-- keywords: Symbol, Icon, Sonderzeichen, Barcode, ISBN, UPC, Bausteine, Kalender, Rahmen, Anzeige, Unternehmensinformationen, Datum und Uhrzeit, Hyperlink, Link, Datei einfügen -->

Dieses Thema behandelt die weiteren Elemente, die Sie auf der Registerkarte **Einfügen** hinzufügen können. Bilder, Formen, Tabellen, Textkunst und Fußnoten haben eigene Themen.

## Symbole

1. Klicken Sie auf **Einfügen > Illustrationen > Symbole**.
2. Geben Sie im Fenster **Symbole einfügen** ein Wort ein, etwa Pfeil, E-Mail oder Stern.
3. Klicken Sie auf ein Symbol. Halten Sie **Strg** oder **Umschalt** gedrückt, während Sie klicken, um mehrere auszuwählen.
4. Klicken Sie auf **Einfügen**.

JeffPub enthält mehr als 1.500 Symbole aus dem Lucide-Satz. Jedes Symbol wird in der Mitte der Seite eingefügt, 2,5 cm hoch, und in der Hauptfarbe Ihres Farbschemas gefärbt. Ein Symbol ist eine Form. Deshalb können Sie seine Farbe mit **Formkontur** auf der Registerkarte **Formformat** ändern.

## Barcodes

1. Klicken Sie auf **Einfügen > Illustrationen > Barcode**.
2. Wählen Sie im Fenster **Barcode einfügen** einen **Typ**: Buch (ISBN), EAN-13, UPC-A, EAN-8, Code 128, Code 39 oder QR-Code. Ein QR-Code kann beliebigen Text enthalten, etwa eine Webadresse, und hat die Einstellung **Fehlerkorrektur**: Eine höhere Stufe lässt den Code auch dann noch lesen, wenn mehr davon beschädigt oder verdeckt ist, und macht den Code dafür größer.
3. Geben Sie die Nummer oder den Text ein. Bei einem Buch geben Sie die ISBN ein. JeffPub setzt die Bindestriche selbst.
4. Bei einem Buch wählen Sie einen Preis-Zusatzcode oder **Ohne Zusatzcode**. Bei EAN- und UPC-Codes können Sie einen 2- oder 5-stelligen Zusatzcode eingeben.
5. Prüfen Sie die Vorschau und klicken Sie dann auf **Einfügen**.

Wenn etwas nicht stimmt, zeigt das Fenster dies rot an, und **Einfügen** bleibt ausgegraut. Außerdem können Sie **Vergrößerung** und **Balkenhöhe** einstellen. Lassen Sie **Weißer Hintergrund** aktiviert, weil Scanner den freien Rand benötigen. Um einen Barcode später zu ändern, doppelklicken Sie darauf. Damit die Bindestriche für jedes Land richtig gesetzt werden, lädt JeffPub die Bereichsliste der Internationalen ISBN-Agentur herunter und speichert eine Kopie.

## Bausteine

Ein Baustein ist eine fertige Gruppe von Objekten, etwa eine Überschrift oder ein Gutschein. Öffnen Sie eine Galerie unter **Einfügen > Bausteine**:

- **Seitenelemente**: Überschriften, hervorgehobene Zitate, Randleisten, zwei- und dreispaltige Artikel sowie ein Inhaltsverzeichnis. Ein hervorgehobenes Zitat ist ein kurzes Zitat aus dem Artikel, groß gesetzt.
- **Kalender**: dieser Monat oder nächster Monat. Für einen anderen Monat klicken Sie auf **Weitere Kalender…** und wählen dann im Fenster **Kalender** Monat, Jahr und Entwurf.
- **Rahmen und Akzente**: Balken, Linien, Rahmen und Eckelemente.
- **Anzeigen**: Gutschein, Verkaufsanzeige, Veranstaltungsanzeige, Explosionsform, Preisschild und mehr.

Klicken Sie auf einen Baustein, um ihn einzufügen. Er verwendet Ihr Farbschema und Ihre Schriftarten. Er besteht aus gewöhnlichen Textfeldern und Formen, Sie können ihn also wie jedes andere Objekt bearbeiten.

## Unternehmensinformationen

Klicken Sie auf **Einfügen > Text > Unternehmensinformationen** und wählen Sie eine Angabe, etwa Name der Organisation, Adresse, Telefon, Website oder Logo. Befindet sich die Einfügemarke in einem Textfeld, wird die Angabe dort eingefügt. Andernfalls fügt JeffPub ein neues Textfeld hinzu. Wählen Sie **Unternehmensinformationen bearbeiten…**, um Ihre Angaben einzutragen oder zu ändern. Eingefügte Angaben werden aktualisiert, wenn Sie sie ändern.

## Text, Links und weitere Elemente

- **Einfügen > Text > Text aus Datei** übernimmt Text aus einer .txt-, .rtf-, .html-, .docx- oder .md-Datei.
- **Symbol** fügt ein Sonderzeichen ein, etwa © oder é. Klicken Sie zuvor in ein Textfeld.
- **Datum und Uhrzeit**: Klicken Sie zuvor in ein Textfeld, wählen Sie unter **Sprache** die Sprache für die Namen der Wochentage und Monate, wählen Sie ein Format und aktivieren Sie **Automatisch aktualisieren**, damit das Datum immer aktuell bleibt. Das Feld behält seine Sprache. Eine .pub-Datei behält das Format, aber nicht die Sprache. Ein dort gespeichertes Datum wird daher beim erneuten Öffnen in der Sprache des Computers angezeigt.
- **Einfügen > Links > Link** (Strg+K) erstellt einen Hyperlink zu einer Webseite, zu einer Seite Ihrer Publikation oder zu einer E-Mail-Adresse. Markieren Sie zuvor Text oder ein Objekt. Wählen Sie **Link entfernen**, um ihn wieder zu entfernen.
- **Textmarke** vergibt einen Namen für den markierten Text oder das markierte Objekt.
- **Objekt** lässt Sie eine Datei auswählen und sie als Bild einfügen.
