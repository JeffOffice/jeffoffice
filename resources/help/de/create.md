# Neue Publikation erstellen
<!-- keywords: neu, neue Publikation, Vorlage, Vorlagen, leere Seite, Seitengröße, Flyer, Newsletter, Karte, Prospekt, Broschüre, Katalog, benutzerdefinierte Größe, Meine Vorlagen, erstellen, anlegen, Entwurf, Design -->

Sie können mit einer **Vorlage** beginnen, also einem fertigen Entwurf mit Beispieltext und Bildern, oder mit einer leeren Seite. Dazu verwenden Sie die Seite **Neu**. JeffPub zeigt diese Seite beim Start an.

## Mit einer Vorlage beginnen

1. Klicken Sie auf **Datei** und dann auf **Neu**. Oder drücken Sie Strg+N.
2. Wählen Sie links in der Liste **Kategorien** eine Gruppe aus. **Empfohlen** zeigt eine Auswahl. Zu den weiteren Gruppen gehören Flyer, Newsletter, Prospekte, Visitenkarten, Grußkarten, Kalender, Einladungskarten und Lebensläufe. Die Zahl neben einer Gruppe gibt an, wie viele Entwürfe sie enthält.
3. Oder geben Sie ein Wort in das Feld **Vorlagen durchsuchen** ein.
4. Klicken Sie auf einen Entwurf. Rechts wird eine Vorschau mit einer kurzen Beschreibung angezeigt.
5. Klicken Sie auf **Erstellen**. Sie können auch auf den Entwurf doppelklicken.

Wenn die aktuelle Publikation nicht gespeicherte Änderungen enthält, fragt JeffPub zuerst, ob Sie diese speichern möchten. Die neue Publikation ersetzt sie dann im Fenster.

## Zuerst das Aussehen wählen

Im Bereich rechts können Sie einige Einstellungen ändern, bevor Sie auf **Erstellen** klicken:

- **Farbschema** und **Schriftartenschema** legen die Farben und Schriftarten fest. Lassen Sie **(Vorlagenstandard)** eingestellt, um die Farben und Schriftarten des Entwurfs beizubehalten. Siehe [Farb- und Schriftartenschemas](color-schemes).
- **Unternehmensinformationen** wählt den Satz Kontaktdaten aus, den der Entwurf einfügt. Klicken Sie auf **Bearbeiten…**, um ihn zu ändern.
- **Logo einbeziehen** und **Postanschrift einbeziehen** werden nur bei Entwürfen angezeigt, die diese verwenden.

Farben und Schriftarten können Sie später auf der Registerkarte **Seitenentwurf** in der Gruppe **Schemas** ändern.

## Mit einer leeren Seite beginnen

1. Klicken Sie auf der Seite **Neu** auf **Empfohlen** oder **Leere Formate**.
2. Klicken Sie auf eine Größe. **Empfohlen** beginnt mit einer leeren Letter-Seite im Hoch- oder Querformat. **Leere Formate** enthält Papierformate (wie Letter, Legal und A4), Karten, Umschläge, Poster, ein Banner und Formate für das Web.
3. Klicken Sie auf **Erstellen**.

## Eigene Seitengröße erstellen

1. Klicken Sie auf der Seite **Neu** auf **Leere Formate**.
2. Klicken Sie am Ende der Liste auf **Neue Seitengröße erstellen…** und dann auf **Erstellen**.
3. Geben Sie im geöffneten Fenster einen Namen ein, legen Sie die Größe fest, und klicken Sie auf **OK**.

Ihre Größe wird jetzt in der Liste **Leere Formate** angezeigt. Wählen Sie sie aus, und klicken Sie auf **Erstellen**, um sie zu verwenden. Um die Größe einer vorhandenen Publikation zu ändern, verwenden Sie **Seitenentwurf > Seite einrichten**. Siehe [Seite einrichten](page-setup).

## Eigene Vorlage speichern

Machen Sie aus einer fertigen Publikation eine Vorlage, die Sie wiederverwenden können. Klicken Sie auf **Datei > Exportieren > Als Vorlage speichern**, geben Sie einen Namen ein, und klicken Sie auf **OK**. Die Vorlage wird auf der Seite **Neu** unter **Meine Vorlagen** angezeigt.
