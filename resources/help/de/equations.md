# Eine Gleichung einfügen

Eine **Gleichung** ist eine mathematische Zeile, zum Beispiel ein Bruch oder eine Quadratwurzel. In JeffPub ist eine Gleichung ein Objekt auf der Seite, ähnlich wie ein Bild: Sie können sie verschieben, in der Größe ändern, drehen und einfärben.

## Eine Gleichung auf die Seite setzen

1. Klicken Sie auf **Einfügen > Text > Gleichung**, oder drücken Sie **Alt+=**.
2. Geben Sie die Gleichung in einer Zeile ein. Unter dem Feld sehen Sie, wie sie aussehen wird. Klicken Sie auf **OK**.

Die Gleichung wird in die Mitte der Seite gesetzt und ist markiert. Wenn Sie mit einer bekannten Formel beginnen möchten, klicken Sie auf den Pfeil neben **Gleichung** und wählen Sie eine integrierte Gleichung aus, zum Beispiel die quadratische Formel oder die Fläche eines Kreises.

## So geben Sie Gleichungen ein

- **Brüche:** Geben Sie einen Schrägstrich ein. `a/b` ergibt a über b. `(x+1)/(x-1)` fasst jede Gruppe in Klammern als einen Teil auf.
- **Hoch- und Tiefstellungen:** `x^2` ist x hoch 2, und `x_i` ist x mit einem kleinen i darunter. Sie können beides kombinieren, wie in `x_i^2`.
- **Wurzeln:** Geben Sie `sqrt(x+1)` für eine Quadratwurzel oder `sqrt[3]{x}` für eine dritte Wurzel ein.
- **Summen, Integrale und Produkte:** Geben Sie `\sum_(i=1)^n i`, `\int_0^1 x` oder `\prod_(k=1)^n k` ein. Der Teil nach dem Unterstrich steht unten, der Teil nach dem Dach-Zeichen steht oben.
- **Symbole:** Geben Sie einen umgekehrten Schrägstrich und einen Namen ein. `\alpha` ergibt α, `\pi` ergibt π, `\infty` ergibt ∞, `\leq` ergibt ≤ und `\times` ergibt ×. Etwa 70 Namen funktionieren.
- **Akzente:** `\hat{x}`, `\vec{v}` und `\bar{x}` setzen ein Zeichen über den Buchstaben.
- **Klammern, die mitwachsen:** Geben Sie `\left( ... \right)` ein, dann wachsen die Klammern auf die Höhe des Inhalts zwischen ihnen.
- **Matrizen:** Eine **Matrix** ist ein Raster aus Zahlen. Geben Sie `\pmatrix{a & b \\ c & d}` ein. Setzen Sie ein `&` zwischen die Zellen einer Zeile und zwei umgekehrte Schrägstriche zwischen die Zeilen.

## Eine Gleichung ändern

Markieren Sie die Gleichung und drücken Sie die Eingabetaste, oder doppelklicken Sie darauf, oder klicken Sie auf **Einfügen > Text > Gleichung**. Das Feld öffnet sich mit der Gleichung in einer Zeile. Ändern Sie sie und klicken Sie auf **OK**. Rückgängig machen können Sie das mit einem Schritt.

Eine Gleichung, die eine Datei mit Teilen mitbringt, die das Feld nicht schreiben kann, wird so angezeigt, wie sie ist. Um sie zu ändern, geben Sie eine neue ein.

## Verschieben, Größe und Farbe

Ziehen Sie die Gleichung, um sie zu verschieben. Ziehen Sie an einer Ecke, um sie zu vergrößern oder zu verkleinern; die Gleichung behält dabei ihre Proportionen. Mit **Formfüllung** ändern Sie die Farbe der Buchstaben.

## Speichern

- **.jpub** behält die Gleichung, sodass Sie sie später wieder bearbeiten können.
- **PDF und Drucken** zeichnen die Gleichung als Formen, sodass sie bei jeder Größe scharf bleibt.
- **.pub** kennt keine Gleichungen. JeffPub speichert jede Gleichung als Bild davon, an derselben Stelle und in derselben Größe, und weist Sie beim Speichern darauf hin.
- **EPUB** und **HTML** übernehmen die Gleichung als die Zeile, die Sie eingegeben haben.
