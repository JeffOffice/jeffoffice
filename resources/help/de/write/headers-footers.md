# Kopf- und Fußzeilen

Eine **Kopfzeile** ist Text am oberen Rand jeder Seite. Eine **Fußzeile** ist Text am unteren Rand. Sie werden zum Beispiel für Seitenzahlen, einen Titel, ein Datum oder einen Firmennamen verwendet. In diesem Thema erfahren Sie, wie Sie Kopf- und Fußzeilen hinzufügen, bearbeiten und schließen.

## Kopf- oder Fußzeile zum Bearbeiten öffnen

- Doppelklicken Sie in den oberen Rand einer Seite, um ihre Kopfzeile zu bearbeiten. Doppelklicken Sie in den unteren Rand, um ihre Fußzeile zu bearbeiten.
- Oder klicken Sie auf **Einfügen > Kopfzeile** bzw. **Einfügen > Fußzeile**.

Hat der Teil des Dokuments, zu dem die Seite gehört, noch keine Kopfzeile (bzw. Fußzeile), öffnet JeffWrite eine leere. Eine leere Kopf- oder Fußzeile, die Sie per Doppelklick geöffnet haben, wird erst Teil der Datei, wenn Sie etwas eingeben. Wenn Sie sie schließen, ohne etwas einzugeben, bleibt das Dokument also unverändert. Mit **Einfügen > Kopfzeile** und **Einfügen > Fußzeile** wird sie sofort zur Datei hinzugefügt. Eine leere Seite, etwa die Seite, die entsteht, wenn ein Abschnitt auf einer ungeraden Seite beginnen muss, zeigt keine Kopf- oder Fußzeile an. Dort gibt es also keine, die Sie öffnen könnten.

Wenn eine Kopf- oder Fußzeile zum Bearbeiten geöffnet ist:

- Der Text der Seite wird abgeblendet, damit Sie sehen, was Sie bearbeiten. Eine gestrichelte Linie und ein kleiner Name kennzeichnen ihren Rand.
- Links im Menüband erscheint eine neue Registerkarte namens **Kopf- und Fußzeile**.
- Die Einfügemarke steht in der Kopf- oder Fußzeile. Sie können Text wie auf der Seite eingeben, markieren, ausschneiden, kopieren, einfügen und formatieren. Mit **Tab** springen Sie zum nächsten Tabstopp. Eine Kopf- oder Fußzeile enthält keine Seiten-, Spalten- oder Abschnittsumbrüche und keine Fußnoten oder Kommentare. Deshalb sind **Seitenumbruch** und **Abschnittsumbruch** abgeblendet, solange eine Kopf- oder Fußzeile geöffnet ist, und beim Einfügen von Text werden diese Elemente weggelassen. Eine Kopfzeile hat meist einen **zentrierten Tabstopp** in der Mitte der Zeile und einen **rechtsbündigen Tabstopp** am Ende. Ein Tabulator zentriert also den nachfolgenden Text, zwei Tabulatoren setzen Text an den rechten Rand.

Dieselbe Kopfzeile erscheint auf jeder Seite, die sie verwendet. Wenn Sie sie auf einer Seite ändern, ändern sich alle diese Seiten. Seiten, die eine andere Kopfzeile verwenden, etwa eine abweichende erste Seite, bleiben unverändert.

## Kopf- oder Fußzeile schließen

Drücken Sie **Esc**, doppelklicken Sie in den Text der Seite, oder klicken Sie auf der Registerkarte **Kopf- und Fußzeile** auf **Kopf- und Fußzeile schließen**.

## Seitenzahl hinzufügen

Klicken Sie auf **Kopf- und Fußzeile > Einfügen > Seitenzahl**. JeffWrite fügt an der Einfügemarke ein **Feld** ein. Ein Feld ist Text, den JeffWrite selbst ausfüllt. Das Seitenzahlfeld zeigt die Nummer der Seite an, auf der es steht, und ist daher auf jeder Seite anders.

Ein Feld ist eine Einheit. Die Einfügemarke kann nicht hineingesetzt werden. Wenn Sie direkt daneben **Rücktaste** oder **Entf** drücken, wird das ganze Feld gelöscht. Sie können es verschieben, kopieren und formatieren, zum Beispiel fett oder in einem größeren Schriftgrad. Felder, die bereits in einer Datei enthalten sind, etwa die Seitenanzahl, das Datum oder der Titel einer Überschrift, verhalten sich genauso. Ihre Feldcodes können Sie nicht ändern. Wenn Sie Text mit einem Feld als unformatierten Text kopieren, wird das Feld so kopiert, wie es auf dieser Seite angezeigt wird, zum Beispiel als Zahl 3. Beim Kopieren und Einfügen innerhalb von JeffWrite bleibt es ein Feld.

## Seiten mit unterschiedlichen Kopfzeilen

- **Erste Seite anders** gibt der ersten Seite des Abschnitts eine eigene Kopf- und Fußzeile. Ein **Abschnitt** ist ein Teil des Dokuments mit eigener Seiteneinrichtung. Ein neues Dokument hat einen Abschnitt.
- **Gerade und ungerade Seiten unterschiedlich** gibt den ungeraden Seiten eine Kopfzeile und den geraden Seiten eine andere. Diese Einstellung gilt für das ganze Dokument.
- **Mit vorheriger verknüpfen** ist aktiviert, wenn ein Abschnitt dieselbe Kopfzeile wie der vorherige Abschnitt anzeigt. Ändern Sie die eine, ändert sich auch die andere. Deaktivieren Sie die Option, um dem Abschnitt eine eigene Kopie zum Bearbeiten zu geben. Aktivieren Sie sie wieder, zeigt der Abschnitt die Kopfzeile des vorherigen Abschnitts an, und seine eigene Kopie wird verworfen. Der erste Abschnitt hat keinen vorherigen Abschnitt, daher ist die Schaltfläche für ihn deaktiviert.

Wenn Sie eine abweichende erste Seite oder unterschiedliche gerade und ungerade Seiten aktivieren, ist die neue Kopfzeile zunächst leer. Geben Sie Text ein, um sie zu füllen. Bis dahin ist sie nicht Teil der Datei.

## Was JeffWrite beibehält

- Bilder, Formen, Textfelder und Tabellen in einer Kopf- oder Fußzeile bleiben an ihrer Position. Sie können sie noch nicht bearbeiten, sie gehen aber nicht verloren.
- Beim Speichern wird eine Kopf- oder Fußzeile, die Sie nicht geändert haben, genau so zurückgeschrieben, wie sie in der Datei stand. Eine geänderte wird neu geschrieben, wobei alles, was JeffWrite nicht bearbeiten kann, an seiner Stelle erhalten bleibt.

## Suchen und Rechtschreibung

- **Suchen und Ersetzen** und der Bereich **Rechtschreibung** (F7) durchsuchen den Text des Dokuments, nicht seine Kopf- und Fußzeilen. Wenn Sie sie öffnen, während eine Kopfzeile geöffnet ist, schließt JeffWrite zuerst die Kopfzeile.
- Während Sie eine Kopf- oder Fußzeile bearbeiten, werden falsch geschriebene Wörter wie auf der Seite rot gewellt unterstrichen.

## Rückgängig

**Rückgängig** (Strg+Z) macht die letzte Änderung rückgängig, egal wo sie vorgenommen wurde: im Text oder in einer Kopf- oder Fußzeile. War sie in einer Kopfzeile, öffnet JeffWrite diese Kopfzeile, um sie Ihnen zu zeigen. **Wiederholen** stellt die Änderung wieder her. Eine zusammenhängende Eingabe an einer Stelle gilt als ein Schritt.
