# OpenDocument-Dateien öffnen und speichern
<!-- keywords: odt, fodt, ott, opendocument, open document, öffnen, speichern, speichern unter, Format, Dateityp, andere Programme, Dokumente austauschen, weitergeben, Kompatibilität, Änderungen nachverfolgen, ausgelassen, Vorlage -->

JeffWrite öffnet und speichert OpenDocument-Text, also Dateien, deren Name auf **.odt** endet. Viele kostenlose Programme lesen und schreiben dieses Format. Damit lässt sich ein Dokument gut mit jemandem austauschen, der JeffWrite nicht verwendet.

## OpenDocument-Datei öffnen

Drücken Sie **Strg+O**, oder klicken Sie auf **Datei > Öffnen**, und wählen Sie eine Datei aus:

- **.odt** ist ein Dokument.
- **.ott** ist eine Vorlage. Sie wird als neues Dokument geöffnet, das auf ihr basiert, sodass die Vorlage selbst unverändert bleibt.
- **.fodt** ist dieselbe Art von Dokument, gespeichert in einer einzigen einfachen XML-Datei.

JeffWrite erkennt den Dateityp an ihrem Inhalt und nicht an ihrem Namen. Eine Datei mit einer falschen Endung lässt sich daher ebenfalls öffnen. Sie können den Namen einer Datei auch beim Start von JeffWrite angeben oder die Datei aus Ihrem Dateimanager auf das Programm ziehen, so wie bei einer .docx-Datei.

JeffWrite liest den Text und sein Aussehen, Überschriften, Formatvorlagen samt den Vorlagen, auf denen sie beruhen, Aufzählungen und nummerierte Listen, Tabellen (mit verbundenen Zellen, Spaltenbreiten, Rahmen, Schattierung und Tabellen in Tabellen), Abschnitte und Spalten, Größe, Ränder und Ausrichtung der Seite, Kopf- und Fußzeilen (erste Seite, linke und rechte Seiten), Fuß- und Endnoten, Felder (Seitenzahlen, Seitenanzahl, Titel, Autor, Dateiname, Querverweise und gezählte Nummern), Textmarken, Links, ein Inhaltsverzeichnis, Bilder, Textfelder, Tabstopps, Kommentare und nachverfolgte Änderungen, die als Markierungen erscheinen, die Sie annehmen oder ablehnen können.

Einiges kann JeffWrite noch nicht anzeigen: gezeichnete Formen ohne Text, Formeln, Diagramme und andere Objekte im Text. Enthält eine Datei so etwas, teilt JeffWrite Ihnen beim Öffnen mit, was. Die Datei wird dann nicht überschrieben: Bei **Speichern** werden Sie nach einem neuen Namen gefragt, damit das Original behält, was in der Kopie fehlt. Ein Dokument, das mit einem Kennwort geschützt ist, wird nicht geöffnet. Öffnen Sie es im Programm, mit dem es erstellt wurde, und speichern Sie eine Kopie ohne Kennwort.

## OpenDocument-Datei speichern

Klicken Sie auf **Datei > Speichern unter**, und wählen Sie in der Liste der Dateitypen **OpenDocument Text (*.odt)** aus. Danach speichert **Strg+S** wieder in derselben Art.

Die Datei enthält alles, was oben aufgeführt ist. Für einige wenige Dinge hat das Format keinen Platz. JeffWrite sagt Ihnen nach dem ersten Speichern einmal, welche das sind: Sie werden so gespeichert, wie sie jetzt aussehen, oder ausgelassen. Nachverfolgte Änderungen in einer Kopf- oder Fußzeile werden angenommen gespeichert.

Andere Programme, die OpenDocument lesen, öffnen die Datei, ohne eine Reparatur anzubieten.
