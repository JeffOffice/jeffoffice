# Öffnen, Speichern, Drucken und Exportieren
<!-- keywords: öffnen, speichern, speichern unter, docx, doc, dot, ältere Dateien, Vorlage, dotx, zuletzt verwendet, anheften, neu, schließen, drucken, pdf, exportieren, wiederherstellen, AutoWiederherstellen, nicht gespeichert, Absturz, Dateiansicht, Backstage, Dateiformate -->

Klicken Sie oben links auf **Datei**, um die Dateiansicht anzuzeigen. Sie enthält Seiten für „Neu“, „Öffnen“, „Drucken“ und „Exportieren“ sowie die Befehle „Speichern“ und „Speichern unter“. Drücken Sie **Esc**, um zu Ihrem Dokument zurückzukehren.

## Neues Dokument beginnen

Drücken Sie **Strg+N**, oder klicken Sie auf **Datei > Neu** und dann auf **Leeres Dokument**. Ein neues Dokument wird in einem eigenen Fenster geöffnet. Wenn das aktuelle Fenster leer ist und nie gespeichert wurde, tritt das neue Dokument an seine Stelle.

## Dokument öffnen

Drücken Sie **Strg+O**, oder klicken Sie auf **Datei > Öffnen**. Klicken Sie auf **Durchsuchen**, um eine Datei auszuwählen. JeffWrite öffnet die folgenden Dateitypen:

- **.docx** ist ein Dokument.
- **.dotx** ist eine Vorlage. Eine Vorlage wird als neues Dokument geöffnet, das auf ihr basiert, sodass die Vorlage selbst unverändert bleibt.
- **.docm** und **.dotm** lassen sich ebenfalls öffnen. JeffWrite übernimmt ihre Makros nicht. Darauf werden Sie beim ersten Speichern eines solchen Dokuments hingewiesen, und JeffWrite speichert eine .docx-Datei.
- **.doc** und **.dot** sind die älteren Dokument- und Vorlagenformate. JeffWrite kann sie lesen und speichert Ihre Änderungen als neue .docx-Datei.

Auf der Seite **Öffnen** werden außerdem die Dokumente aufgeführt, die Sie zuletzt geöffnet oder gespeichert haben. Klicken Sie auf ein Dokument, um es zu öffnen. Klicken Sie mit der rechten Maustaste darauf, um es oben in der Liste anzuheften oder aus der Liste zu entfernen.

Wenn eine Datei Elemente enthält, die JeffWrite noch nicht bearbeiten kann, etwa das Layout einer Tabelle oder eine Kopfzeile, bleiben diese erhalten. Siehe [Willkommen bei JeffWrite](start). Kann ein Teil einer Datei überhaupt nicht gelesen werden, teilt JeffWrite Ihnen mit, was ausgelassen wurde. Die Datei wird dann nicht überschrieben: Beim Speichern werden Sie nach einem neuen Namen gefragt, damit das Original behält, was in der Kopie fehlt.

## Dokument speichern

Drücken Sie **Strg+S**, um zu speichern. Beim ersten Mal fragt JeffWrite nach einem Namen. **Speichern unter** (F12) speichert eine Kopie unter einem neuen Namen. Wählen Sie **Vorlage (*.dotx)**, um eine Vorlage zu speichern. Eine Datei, die aus einem älteren Dateiformat stammt, wird immer unter einem neuen Namen gespeichert, sodass die alte Datei nie überschrieben wird.

## Nicht gespeicherte Arbeit wiederherstellen

JeffWrite speichert alle paar Minuten eine Sicherungskopie nicht gespeicherter Arbeit als Datei in einem eigenen Ordner. Wird das Programm unerwartet beendet, bietet es Ihnen diese Kopien beim nächsten Start an. Klicken Sie auf **Datei > Öffnen > Nicht gespeicherte Arbeit wiederherstellen**, um sie später anzuzeigen. Sie können auswählen, welche Kopien Sie öffnen, und jede an einem beliebigen Ort speichern.

## Drucken

Drücken Sie **Strg+P**, oder klicken Sie auf **Datei > Drucken**. Wählen Sie einen Drucker, die Anzahl der Exemplare und die Seiten aus, sehen Sie sich jede Seite in der Vorschau an, und klicken Sie auf **Drucken**. Siehe [Drucken](print).

## PDF erstellen

Klicken Sie auf **Datei > Exportieren > Als PDF exportieren**. Wählen Sie einen Namen. Die PDF-Datei sieht auf jedem Computer gleich aus, weil die Schriftarten darin eingebettet werden.
