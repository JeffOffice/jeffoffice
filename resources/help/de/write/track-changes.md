# Änderungen nachverfolgen, annehmen oder ablehnen

**Änderungen nachverfolgen** zeichnet jede Bearbeitung auf, die Sie vornehmen. So können Sie (oder andere) sehen, was sich geändert hat, und entscheiden, ob die Änderung bleiben soll. Verwenden Sie diese Funktion, wenn Sie ein Dokument bearbeiten, das jemand anderem gehört oder das nach Ihnen noch jemand überprüft.

## Änderungen nachverfolgen ein- und ausschalten

Klicken Sie auf **Überprüfen > Änderungen nachverfolgen**, oder drücken Sie **Strg+Umschalt+E**. Die Statusleiste unten im Fenster zeigt an, ob die Funktion eingeschaltet ist. Ein Klick auf diesen Text schaltet sie um. Die Einstellung wird im Dokument gespeichert. Sie ist also noch eingeschaltet, wenn das Dokument von jemand anderem zurückkommt.

Solange die Funktion eingeschaltet ist, gilt:

- **Was Sie eingeben**, wird als Einfügung markiert.
- **Was Sie löschen**, wird nicht entfernt. Es bleibt durchgestrichen im Text stehen, damit es wiederhergestellt werden kann. Die einzige Ausnahme ist Text, den Sie selbst bei eingeschalteter Nachverfolgung eingegeben haben: Wenn Sie ihn löschen, wird er einfach entfernt, da ihn noch niemand sonst gesehen hat.
- **Ein Absatzumbruch, den Sie einfügen** (Eingabetaste), wird als eingefügt markiert. Ein Absatzumbruch, den Sie löschen (Rücktaste am Anfang eines Absatzes), wird als gelöscht markiert.
- **Eine Formatierungsänderung** (Fett, Schriftart, Schriftgrad, Farbe, Ausrichtung, Einzüge oder Formatvorlage) wird zusammen mit dem vorherigen Aussehen des Texts aufgezeichnet.

Zu jeder Änderung wird gespeichert, wer sie wann vorgenommen hat. Als Name wird der unter **Datei > Optionen** im Feld **Benutzername** angegebene Name verwendet. Ändern Sie ihn dort, falls er nicht stimmt.

Jede Bearbeitung ist ein Schritt. Mit **Strg+Z** machen Sie sie wie jede andere Bearbeitung rückgängig.

## So sehen Änderungen aus

Die Änderungen jeder Person haben eine eigene Farbe. Eingefügter Text ist in der Farbe der Person unterstrichen, gelöschter Text ist durchgestrichen. Ein Balken am linken Seitenrand kennzeichnet jede Zeile, die eine Änderung enthält.

## Ansicht auswählen: Zur Überprüfung anzeigen

Klicken Sie auf **Überprüfen > Zur Überprüfung anzeigen**, und wählen Sie eine Option aus:

- **Markup: alle** zeigt alle Änderungen im Text an, mit den Balken am Seitenrand.
- **Einfaches Markup** zeigt das Dokument so an, wie es mit angenommenen Änderungen aussieht, und neben jeder Zeile mit einer Änderung einen Balken am Seitenrand.
- **Kein Markup** zeigt das Dokument so an, wie es aussieht, wenn alle Änderungen angenommen sind, und sonst nichts.
- **Original** zeigt das Dokument so an, wie es vor allen Änderungen war: Gelöschter Text ist wieder da, eingefügter Text fehlt.

Diese Optionen ändern nur die Anzeige. Sie ändern nie das Dokument und werden nicht mit ihm gespeichert. Ein Dokument, das Änderungen enthält, wird mit **Markup: alle** geöffnet.

Unter **Überprüfen > Markups anzeigen** legen Sie fest, welche Arten von Änderungen angezeigt werden: **Einfügungen und Löschungen**, **Formatierung** und **Kommentare**. Darunter wählen Sie aus, wie gelöschter Text angezeigt wird. **Alle Überarbeitungen inline anzeigen** lässt ihn durchgestrichen im Text stehen. **Überarbeitungen in Sprechblasen anzeigen** nimmt gelöschten Text aus der Zeile heraus und zeigt ihn in einer Sprechblase am Seitenrand an. **Nur Kommentare und Formatierungen in Sprechblasen anzeigen** lässt Einfügungen und Löschungen im Text stehen.

## Änderungen annehmen oder ablehnen

Wenn Sie eine Änderung annehmen, wird sie endgültig übernommen. Wenn Sie sie ablehnen, wird sie rückgängig gemacht.

- **Überprüfen > Annehmen** nimmt die Änderung an, in der sich die Einfügemarke befindet (oder alle Änderungen im markierten Text), und springt dann zur nächsten. **Überprüfen > Ablehnen** funktioniert genauso, macht die Änderung aber rückgängig.
- Klicken Sie auf den Pfeil unter **Annehmen** oder **Ablehnen**, um weitere Befehle anzuzeigen: **Alle angezeigten Änderungen annehmen**, **Alle Änderungen annehmen** und **Alle Änderungen annehmen und Nachverfolgung beenden** sowie **Alle angezeigten Änderungen ablehnen** und **Alle Änderungen ablehnen**. „Angezeigt“ bezieht sich auf die Änderungen der Arten, die unter **Markups anzeigen** eingeschaltet sind (und im **Überarbeitungsbereich** auf den ausgewählten Bearbeiter).
- Mit **Zurück** und **Weiter** in der Gruppe **Änderungen** springen Sie von einer Änderung zur nächsten, ohne etwas zu ändern.

Jeder dieser Befehle ist ein Schritt. Mit **Strg+Z** stellen Sie das Dokument genau so wieder her, wie es war.

Wenn Sie eine Löschung annehmen, wird der Text endgültig entfernt. Wenn Sie eine Einfügung ablehnen, wird der Text ebenfalls entfernt. Wenn Sie eine Einfügung annehmen, bleibt der Text erhalten, und die Markierung als neu wird entfernt. Wenn Sie eine Löschung ablehnen, bleibt der Text erhalten, und die Durchstreichung wird entfernt. Wenn Sie eine Formatierungsänderung ablehnen, erhält der Text wieder sein vorheriges Aussehen.

## Der Überarbeitungsbereich

Klicken Sie auf **Überprüfen > Überarbeitungsbereich**, um eine Liste der Änderungen im Dokument zu öffnen: Art der Änderung, wer sie wann vorgenommen hat und der betroffene Text. Wenn Sie auf einen Eintrag klicken, wird die Änderung im Text angezeigt. Verwenden Sie **Annehmen**, **Ablehnen**, **Zurück** und **Weiter** unter der Liste, oder wählen Sie im Feld darüber einen Bearbeiter aus, um nur dessen Änderungen anzuzeigen.

## Was noch nicht nachverfolgt wird

Änderungen an Tabellen (Zeilen, Zellen, Verbinden), an Nummerierungen und Listen, an Abschnitten und der Seiteneinrichtung sowie an Text in Kopfzeilen, Fußzeilen und Notizen werden wie gewohnt ausgeführt, ohne aufgezeichnet zu werden. Änderungen, die andere Programme an diesen Stellen aufgezeichnet haben, bleiben erhalten und werden unverändert gespeichert.
