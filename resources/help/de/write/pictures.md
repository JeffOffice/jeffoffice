Ein **Bild** kann in einer Textzeile stehen, wie ein Buchstabe, oder frei auf der Seite schweben, während der Text es umfließt. Dieses Thema zeigt, wie Sie ein Bild in ein Dokument einfügen, wie Sie seine Größe und Position ändern, wie der Text es umfließt und wie Sie es für Menschen beschreiben, die es nicht sehen können.

## Ein Bild einfügen

- Klicken Sie auf **Einfügen > Bilder**, dann auf **Bild**, wählen Sie eine Datei aus und klicken Sie auf **Öffnen**. JeffWrite liest die Dateiformate PNG, JPEG, GIF, BMP, TIFF, WebP und SVG. Ein Bild aus einer Datei wird im Dokument in dem Format gespeichert, in dem es vorliegt (ein WebP- oder SVG-Bild wird als PNG gespeichert).
- Oder klicken Sie auf **Einfügen > Bilder > Bild aus Zwischenablage** bzw. drücken Sie **Strg+V**, wenn Sie ein Bild kopiert haben (zum Beispiel einen Screenshot). Das Bild wird im Dokument gespeichert, es ist also auch dann noch vorhanden, wenn Sie die Datei speichern und später wieder öffnen.
- Oder ziehen Sie eine Bilddatei aus dem Dateimanager Ihres Computers auf eine Seite. Das Bild wird an der Stelle eingefügt, an der Sie es ablegen.
- Oder klicken Sie auf **Einfügen > Symbole**. Ein Fenster zeigt kleine Zeichnungen von Dingen, etwa Pfeilen, Personen und Werkzeugen. Geben Sie ein Wort ein, um eines zu finden, wählen Sie ein oder mehrere aus und klicken Sie auf **OK**. Jedes Symbol wird an der Einfügemarke als Bild von etwa 1,7 cm im Quadrat eingefügt.
- Oder klicken Sie auf **Einfügen > Barcode**, um einen Barcode einzufügen (siehe unten).

Das Bild wird an der Einfügemarke eingefügt und ersetzt dabei alles, was Sie markiert haben. Es wird so groß eingefügt, wie es verlangt, aber nicht breiter als die Spalte und nicht höher als der Textbereich der Seite, und die Proportionen bleiben erhalten. Anschließend ist das Bild markiert, und die Registerkarte **Bildformat** erscheint rechts im Menüband.

Ein Bild, das zu groß ist (mehr als 40 Millionen Pixel, eine Seite länger als 30.000 Pixel oder eine Datei mit mehr als 48 MB), wird nicht eingefügt, und die Statusleiste zeigt dies an. Das Gleiche gilt für eine Datei, die kein Bild ist.

## Kostenlose Bilder im Internet finden

**Onlinebilder** findet kostenlose Bilder. Sie stammen aus zwei offenen Bibliotheken: Openverse, das viele Sammlungen durchsucht, und Wikimedia Commons, die Bildbibliothek von Wikipedia.

1. Klicken Sie auf **Einfügen > Bilder** und dann auf **Onlinebilder…**. Rechts öffnet sich ein Bereich.
2. Wählen Sie eine Bibliothek, geben Sie ein, wonach Sie suchen, und klicken Sie auf **Suchen** (oder drücken Sie die Eingabetaste).
3. Klicken Sie auf ein Bild, um zu sehen, von wem es stammt und welche Lizenz es hat. Eine **Lizenz** legt fest, wie Sie ein Bild verwenden dürfen. Klicken Sie auf den Namen der Lizenz, um sie zu lesen.
4. Klicken Sie auf **Einfügen** (oder doppelklicken Sie auf das Bild).

**Was JeffWrite sendet.** Ihre Suchbegriffe gehen an die von Ihnen gewählte Bibliothek, und zwar erst, wenn Sie auf **Suchen** klicken oder die Eingabetaste drücken. JeffWrite fordert danach von der Bibliothek die kleinen Vorschaubilder der Treffer an und das eine Bild, das Sie einfügen. Wie jede Webseite kann die Bibliothek die Internetadresse Ihres Computers sehen, und sie erfährt, dass JeffWrite diese Anfrage stellt. Inhalte Ihres Dokuments werden nicht gesendet.

Das Bild wird an der Einfügemarke in der Textzeile eingefügt und im Dokument gespeichert. Sein Titel wird als **Alternativtext** gespeichert. Die meisten Lizenzen verlangen, dass Sie den Urheber nennen. Wenn **Quellenangabe unter dem Bild hinzufügen** aktiviert ist, fügt JeffWrite unter dem Bild eine kleine Textzeile mit Titel, Urheber und Lizenz ein. Sie ist ein Absatz, den Sie ändern oder löschen können. Das Einfügen ist ein einziger Schritt, und **Rückgängig** nimmt Bild und Quellenangabe gemeinsam zurück. Prüfen Sie, ob die Lizenz zu Ihrer Verwendung des Bildes passt.

## Die Größe ändern

Klicken Sie auf das Bild, um es auszuwählen. Acht kleine Quadrate, die **Ziehpunkte**, erscheinen an den Ecken und Seiten.

- Ziehen Sie an einem **Eckpunkt**, um das Bild in gleichen Proportionen größer oder kleiner zu machen.
- Ziehen Sie an einem **Seitenpunkt**, um nur eine Seite zu ändern.
- Oder geben Sie unter **Bildformat > Höhe** oder **Breite** eine Zahl ein. Ist **Seitenverhältnis sperren** aktiviert, passt sich die andere Zahl an. Bilder bleiben auf einer Seite zwischen 2 und 2.000 Punkt.

Jede Änderung ist ein Schritt, den Sie rückgängig machen können.

## Ein Bild zuschneiden

Ein Bild **zuschneiden** heißt, Teile seiner Ränder abzuschneiden. Wählen Sie das Bild aus und klicken Sie auf **Bildformat > Zuschneiden**. Geben Sie in Prozent des gesamten Bildes an, wie viel links, oben, rechts und unten abgeschnitten werden soll. Klicken Sie auf **OK**.

Der Bildrahmen wird um denselben Betrag kleiner, sodass der verbleibende Teil seine Größe behält. Schneiden Sie später erneut zu, beginnen Sie vom ganzen Bild, sodass Sie das Abgeschnittene jederzeit zurückholen können. Ein Wert unter null lässt einen leeren Raum um das Bild entstehen. Der Zuschnitt zweier gegenüberliegender Seiten darf zusammen höchstens 98 Prozent ergeben.

## Ein Bild auf eine Form zuschneiden

Wählen Sie das Bild aus und klicken Sie auf **Bildformat > Auf Form zuschneiden**. Wählen Sie eine Form, etwa eine Ellipse, einen Stern oder ein abgerundetes Rechteck. Das Bild wird nur innerhalb dieser Form angezeigt. Wählen Sie das einfache Rechteck, um die Ecken wiederherzustellen. Die Bilddatei selbst wird nicht verändert.

## Ein Bild drehen

Wählen Sie das Bild aus und klicken Sie auf **Bildformat > Drehen**. Drehen Sie es um eine Viertelumdrehung nach rechts oder links oder zurück auf keine Drehung.

## Bilder ausrichten

Klicken Sie auf der Registerkarte **Bildformat** auf **Ausrichten**. Wählen Sie **Linksbündig**, **Zentriert ausrichten** oder **Rechtsbündig**, um das Bild quer über die Seite auszurichten, und **Oben ausrichten**, **Mittig ausrichten** oder **Unten ausrichten**, um es senkrecht auf der Seite auszurichten. Standardmäßig richtet sich das Bild an den Seitenrändern aus. Aktivieren Sie **Auf Seite ausrichten**, um es stattdessen an den Seitenkanten auszurichten. Ein Bild, das in der Textzeile steht, wird dadurch zu einem schwebenden Bild vor dem Text.

## Das Aussehen eines Bildes ändern

Diese Befehle befinden sich auf der Registerkarte **Bildformat**. Jeder ist ein einzelner Schritt, den Sie rückgängig machen können, und keiner verändert die Bilddatei im Dokument.

- **Korrekturen** macht das Bild heller oder dunkler und verleiht ihm mehr oder weniger Kontrast. **Helligkeit** beschreibt, wie hell das Bild ist. **Kontrast** beschreibt, wie stark sich die hellen Teile von den dunklen unterscheiden.
- **Farbe** stellt das Bild in Graustufen (**Graustufen**), in reines Schwarzweiß (**Schwarzweiß**) oder in einen blassen, verblassten Look (**Ausgeblichen**) um. **Nicht neu einfärben** stellt die Farben wieder her.
- **Bildformatvorlagen** und **Bildrahmen** setzen einen Rahmen um das Bild. Wählen Sie eine Vorlage oder eine Farbe, dann eine **Stärke** (wie dick die Linie ist) und **Striche** (eine durchgezogene, gepunktete oder gestrichelte Linie). Wählen Sie **Kein Rahmen**, um den Rahmen zu entfernen.
- **Bild ändern** setzt an derselben Stelle ein anderes Bild ein. Das neue Bild behält die Breite des alten, seine Position auf der Seite, die Art des Textumbruchs und den Alternativtext. Seine Höhe richtet sich nach seiner eigenen Form.
- **Bild zurücksetzen** entfernt den Zuschnitt, die Korrekturen, die Farbänderung und den Rahmen. Das Bild erhält die Skalierung zurück, die es jetzt hat.

## Bilder verkleinern

Ein Foto aus einer Kamera kann viel größer sein, als es auf einer Seite angezeigt wird, und es macht die Datei groß. Klicken Sie auf ein Bild und dann auf **Bilder komprimieren…** in der Gruppe **Anpassen** der Registerkarte **Bildformat**. Wählen Sie, wo das Dokument verwendet wird: **Professioneller Druck (300 ppi)**, **Desktop-Druck (220 ppi)** oder **Web (96 ppi)**. Lassen Sie **Auf alle Bilder im Textteil des Dokuments anwenden** aktiviert, um alle Bilder zu verkleinern, oder deaktivieren Sie es, um nur das ausgewählte Bild zu verkleinern. **Zugeschnittene Bereiche von Bildern löschen** entfernt außerdem die verborgenen Teile, die Sie zugeschnitten haben; der Zuschnitt ist dann weg. Ein Bild wird nur ersetzt, wenn das neue kleiner ist. Seine Größe, Position, der Textumbruch und der Alternativtext bleiben unverändert. Mit **Rückgängig** (Strg+Z) erhalten Sie die Bilder zurück, und die Datei enthält beim Speichern nur die kleineren.

Nur Bilder im Textteil des Dokuments werden verkleinert. Bilder in einer Kopfzeile, einer Fußzeile, einem Textfeld oder einer Form bleiben unverändert, ebenso ein Bild, das eine Zeichnung (SVG, EMF oder WMF) oder eine Animation ist.

## Text um ein Bild umbrechen

**Bildformat > Textumbruch** legt fest, wie der Text um das Bild läuft. Sie können auch mit der rechten Maustaste auf das Bild klicken und **Textumbruch** wählen.

- **Mit Text in Zeile**: Das Bild ist ein Zeichen seiner Zeile und bewegt sich mit den Wörtern um sich herum.
- **Quadratisch**: Der Text läuft um ein Rechteck, das das Bild aufnimmt.
- **Eng**: Der Text läuft so nah am Bild, wie ein Rechteck es zulässt (JeffWrite behandelt dies wie **Quadratisch**).
- **Oben und unten**: Der Text endet über dem Bild und beginnt darunter wieder.
- **Hinter den Text**: Das Bild liegt unter dem Text, und die Wörter laufen direkt darüber.
- **Vor den Text**: Das Bild liegt über dem Text, und die Wörter laufen direkt darunter.

## Ein Bild über ein anderes legen

Schwebende Bilder (jeder Umbruch außer **Mit Text in Zeile**) liegen in Ebenen wie Papierblätter übereinander. **Eine Ebene nach vorne** bringt das ausgewählte Bild eine Ebene nach oben. **Eine Ebene nach hinten** bringt es eine Ebene nach unten. Jede Schaltfläche hat ein kleines Menü mit **In den Vordergrund** und **In den Hintergrund**, die das Bild über oder unter alle anderen verschieben. Dieselben vier Befehle stehen im Kontextmenü unter **Anordnen**.

Ein Bild ganz unten in den Ebenen vor dem Text geht bei einem weiteren Klick auf **Eine Ebene nach hinten** hinter den Text. Ein Bild hinter dem Text kommt bei einem weiteren Klick auf **Eine Ebene nach vorne** davor. Ein Befehl ist abgeblendet, wenn das Bild sich in diese Richtung nicht bewegen kann. Jeder Befehl ist ein Schritt, den **Rückgängig** zurücknimmt.

## Ein Bild verschieben

Ziehen Sie das Bild. Ein Bild **in Zeile mit Text** wird an die Stelle im Text verschoben, an der Sie loslassen. Ein Bild mit einem anderen Umbruch wird an die Stelle auf der Seite verschoben, an der Sie loslassen, und bleibt dort, während sich der Text um es herum ändert (es bleibt bei dem Absatz, zu dem es gehört, auf der Seite dieses Absatzes).

Wenn Sie ein Bild, das in Zeile mit Text steht, ziehen, ändert sich sein Umbruch nicht. Um es schweben zu lassen, wählen Sie einen Umbruch wie **Quadratisch**.

## Ein Bild beschreiben

Ein Bild, das die Seite nur verziert, etwa eine Linie oder ein Rahmen, braucht keine Beschreibung. Wählen Sie es aus und klicken Sie auf **Bildformat > Als dekorativ markieren** (oder klicken Sie mit der rechten Maustaste darauf). Bildschirmleseprogramme überspringen es dann. Klicken Sie erneut darauf, um die Markierung zu entfernen.

Der **Alternativtext** ist eine kurze Beschreibung, die Bildschirmleseprogramme vorlesen und die angezeigt wird, wenn ein Bild nicht dargestellt werden kann. Wählen Sie das Bild aus, klicken Sie auf **Bildformat > Alternativtext** (oder klicken Sie mit der rechten Maustaste auf das Bild und wählen Sie **Alternativtext**), geben Sie die Beschreibung ein und klicken Sie auf **OK**.

## Bilder aus anderen Dokumenten

JeffWrite zeigt die Bilder der Dokumente, die es öffnet, und behält sie bei. Es kann Größe, Umbruch, Position und Alternativtext eines Bildes ändern, das das Dokument als einfaches Bild speichert. Ein Bild, das in einer Form gespeichert ist, die JeffWrite nicht ändert (zum Beispiel eine Gruppe von Zeichnungen), wird ausgewählt und so beibehalten, wie es war; seine Befehle sind deaktiviert.

## Einen Barcode einfügen

Ein **Barcode** ist ein Muster aus Strichen, das ein Scanner liest. JeffWrite erstellt ISBN-Barcodes für Bücher (mit oder ohne Preis), EAN-13, UPC-A, EAN-8, Code 128, Code 39 und QR-Codes. Ein QR-Code kann beliebigen Text enthalten, etwa eine Internetadresse.

1. Setzen Sie die Einfügemarke an die Stelle, an der der Barcode stehen soll, und klicken Sie auf **Einfügen > Barcode**.
2. Wählen Sie einen **Typ** und geben Sie den Text oder die Ziffern ein. Das Fenster zeigt den Barcode während der Eingabe an und nennt in Rot, was nicht stimmt, falls er nicht erstellt werden kann.
3. Klicken Sie auf **Einfügen**.

Der Barcode wird als schwebendes Bild eingefügt, und der Text umläuft ihn. Ziehen Sie ihn, um ihn zu verschieben, ziehen Sie an einer Ecke, um die Größe zu ändern, und verwenden Sie die Registerkarte **Bildformat**, um den Textumbruch zu ändern. Lassen Sie **Weißer Hintergrund** aktiviert, denn ein Scanner benötigt den freien Raum um die Striche. Um den Barcode zu ändern, doppelklicken Sie darauf (oder wählen Sie ihn aus und klicken Sie erneut auf **Einfügen > Barcode**), ändern Sie den Text und klicken Sie auf **Aktualisieren**. Er behält seine Position und seine Breite. Jede Änderung ist ein Schritt, den Sie rückgängig machen können.

Beim Speichern wird der Barcode als Bild gespeichert, und zwar als SVG, das scharf bleibt, sodass ihn jedes Programm anzeigen kann. JeffWrite speichert außerdem die Einstellungen des Barcodes in der Datei, sodass er sich beim erneuten Öffnen in JeffWrite weiterhin bearbeiten lässt. In anderen Programmen ist er ein gewöhnliches Bild. Sein Alternativtext nennt, was er enthält.
