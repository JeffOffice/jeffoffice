# Bilder hinzufügen und ändern

Ein **Bild** kann wie ein Buchstabe in einer Textzeile stehen oder frei auf der Seite liegen, während der Text um das Bild herumfließt. In diesem Thema erfahren Sie, wie Sie ein Bild in ein Dokument einfügen, wie Sie seine Größe, seine Position und den Textumbruch ändern und wie Sie das Bild für Menschen beschreiben, die es nicht sehen können.

## Bild einfügen

- Klicken Sie auf **Einfügen > Bilder** und dann auf **Bild**, wählen Sie eine Datei aus, und klicken Sie auf **Öffnen**. JeffWrite liest PNG-, JPEG-, GIF-, BMP-, TIFF-, WebP- und SVG-Dateien. Ein Bild aus einer Datei wird unverändert im Dokument gespeichert (ein WebP- oder SVG-Bild wird als PNG gespeichert).
- Alternativ klicken Sie auf **Einfügen > Bilder > Bild aus Zwischenablage** oder drücken **Strg+V**, wenn Sie ein Bild kopiert haben (zum Beispiel einen Screenshot). Das Bild wird im Dokument gespeichert und ist also auch nach dem Speichern und erneuten Öffnen der Datei noch vorhanden.
- Sie können auch eine Bilddatei aus dem Dateimanager Ihres Computers auf eine Seite ziehen. Das Bild wird dort eingefügt, wo Sie es ablegen.

Das Bild wird an der Einfügemarke eingefügt und ersetzt einen eventuell markierten Inhalt. Es wird in seiner eigenen Größe eingefügt, jedoch nicht breiter als die Spalte und nicht höher als der Textbereich der Seite; das Seitenverhältnis bleibt dabei erhalten. Anschließend ist das Bild markiert, und rechts im Menüband wird die Registerkarte **Bildformat** angezeigt.

Ein zu großes Bild (mehr als 40 Millionen Pixel, eine Seite länger als 30.000 Pixel oder eine Datei größer als 48 MB) wird nicht eingefügt, und die Statusleiste weist darauf hin. Dasselbe gilt für eine Datei, die kein Bild ist.

## Größe ändern

Klicken Sie auf das Bild, um es zu markieren. An den Ecken und Seiten erscheinen acht kleine Quadrate, die **Ziehpunkte**.

- Ziehen Sie an einem **Eckziehpunkt**, um das Bild proportional zu vergrößern oder zu verkleinern.
- Ziehen Sie an einem **seitlichen** Ziehpunkt, um nur eine Seite zu ändern.
- Oder geben Sie unter **Bildformat > Höhe** bzw. **Breite** einen Wert ein. Ist **Seitenverhältnis sperren** aktiviert, wird der andere Wert automatisch angepasst. Jede Seite eines Bilds ist mindestens 2 Punkt und höchstens 2.000 Punkt lang.

Jede Änderung lässt sich in einem Schritt rückgängig machen.

## Text um ein Bild umbrechen

Unter **Bildformat > Textumbruch** legen Sie fest, wie der Text um das Bild fließt. Sie können auch mit der rechten Maustaste auf das Bild klicken und **Textumbruch** wählen.

- **Mit Text in Zeile**: Das Bild ist ein Zeichen seiner Zeile und verschiebt sich mit dem umgebenden Text.
- **Quadrat**: Der Text fließt um ein Rechteck, das das Bild umschließt.
- **Passend**: Der Text fließt so nah an das Bild heran, wie es ein Rechteck zulässt (JeffWrite behandelt diese Option wie „Quadrat“).
- **Oben und unten**: Der Text endet über dem Bild und wird darunter fortgesetzt.
- **Hinter den Text**: Das Bild liegt unter dem Text, der ungehindert darüber verläuft.
- **Vor den Text**: Das Bild liegt über dem Text, der ungehindert darunter verläuft.

## Bild verschieben

Ziehen Sie das Bild an die gewünschte Stelle. Ein Bild **mit Text in Zeile** wird an der Stelle im Text eingefügt, an der Sie die Maustaste loslassen. Ein Bild mit einem anderen Textumbruch wird an die Stelle auf der Seite verschoben, an der Sie loslassen, und bleibt dort, auch wenn sich der umgebende Text ändert (es bleibt mit seinem Absatz verbunden, auf der Seite dieses Absatzes).

Wenn Sie ein Bild mit Text in Zeile ziehen, ändert sich sein Textumbruch nicht. Damit es frei auf der Seite liegt, wählen Sie einen Textumbruch wie **Quadrat**.

## Bild beschreiben

Der **Alternativtext** ist eine kurze Beschreibung, die Sprachausgaben vorlesen und die angezeigt wird, wenn das Bild nicht angezeigt werden kann. Markieren Sie das Bild, und klicken Sie auf **Bildformat > Alternativtext** (oder klicken Sie mit der rechten Maustaste auf das Bild und wählen **Alternativtext**). Geben Sie die Beschreibung ein, und klicken Sie auf **OK**.

## Bilder aus anderen Dokumenten

JeffWrite zeigt die Bilder der geöffneten Dokumente an und behält sie bei. Bei einem Bild, das im Dokument als einfaches Bild gespeichert ist, können Sie Größe, Textumbruch, Position und Alternativtext ändern. Ein Bild, das in einer Form gespeichert ist, die JeffWrite nicht ändert (zum Beispiel eine Gruppe von Zeichnungen), lässt sich markieren und bleibt unverändert erhalten; die zugehörigen Befehle sind dann nicht verfügbar.
