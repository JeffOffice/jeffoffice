# Dokument schützen und Änderungsnachverfolgung sperren

Mit dem Schutz legen Sie fest, was andere in einem Dokument tun dürfen. Diese Werkzeuge finden Sie auf der Registerkarte **Überprüfen**.

## Bearbeitung einschränken

1. Klicken Sie in der Gruppe **Schützen** auf **Bearbeitung einschränken**.
2. Wählen Sie aus, was andere tun dürfen:
   - **Keine Änderungen (schreibgeschützt)**: Der Text kann nicht geändert werden.
   - **Nachverfolgte Änderungen**: Andere dürfen bearbeiten, jede Bearbeitung wird aber nachverfolgt, und „Änderungen nachverfolgen“ kann nicht ausgeschaltet werden.
   - **Kommentare**: Andere dürfen Kommentare hinzufügen, aber den Text nicht ändern.
   - **Formulare ausfüllen**: Der Text ist schreibgeschützt.
3. Geben Sie zweimal ein Kennwort ein. Sie können das Kennwortfeld leer lassen. Dann kann jeder den Schutz aufheben.
4. Klicken Sie auf **Schutz aktivieren**.

Die Titelleiste zeigt danach „Geschützt“ an. Um den Schutz aufzuheben, klicken Sie erneut auf **Bearbeitung einschränken** und dann auf **Schutz beenden**. Geben Sie das Kennwort ein, falls eines festgelegt ist.

Ein Kennwort verhindert, dass Personen das Dokument versehentlich ändern. Es ist keine starke Sicherheitsmaßnahme. Verwenden Sie den Schutz nicht, um private Informationen zu verbergen.

Das Kennwort wird in der Datei als verschlüsselte Zahlenfolge gespeichert, einem sogenannten Hashwert. Das Kennwort selbst wird nie gespeichert. Wenn Sie es vergessen, kann JeffWrite es nicht wiederherstellen.

## Änderungsnachverfolgung sperren

Klicken Sie auf **Optionen für Änderungsnachverfolgung** und dann auf **Änderungsnachverfolgung sperren**. Ab diesem Zeitpunkt werden alle Änderungen nachverfolgt. Ohne Kennwort kann niemand die Änderungsnachverfolgung ausschalten oder Änderungen annehmen bzw. ablehnen. Das entspricht dem Schutz des Dokuments für nachverfolgte Änderungen.

## Ihren Namen für Änderungen festlegen

Klicken Sie auf **Optionen für Änderungsnachverfolgung** und dann auf **Optionen für Änderungsnachverfolgung…**. Geben Sie Ihren Namen und Ihre Initialen ein. Sie werden ab diesem Zeitpunkt bei den Änderungen und Kommentaren angezeigt, die Sie vornehmen.
