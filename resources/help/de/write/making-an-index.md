# Ein Stichwortverzeichnis erstellen
<!-- keywords: Stichwortverzeichnis, Index, Eintrag markieren, alle markieren, Untereintrag, Querverweis, siehe, XE, INDEX, Seitenbereich, Seitenzahl fett, Spalten, Mit Text in Zeile, Buchstabenüberschriften, Alt+Umschalt+X, Stichwortverzeichnis aktualisieren, Index erstellen, Verweis -->

Ein **Stichwortverzeichnis** ist eine alphabetische Liste von Wörtern und Begriffen mit den Seiten, auf denen sie vorkommen. Sie **markieren** zuerst die Wörter, die hineingehören, und **fügen** dann das Stichwortverzeichnis **ein**.

## Einen Eintrag markieren

1. Markieren Sie das Wort oder die Wörter, die aufgeführt werden sollen, oder klicken Sie an die Stelle, auf die der Eintrag verweisen soll.
2. Klicken Sie auf **Verweise > Eintrag markieren**, oder drücken Sie **Alt+Umschalt+X**.
3. Prüfen Sie den **Haupteintrag**. Geben Sie einen **Untereintrag** ein, wenn der Eintrag einen Teil darunter hat. Zum Beispiel der Haupteintrag `Äpfel` mit dem Untereintrag `Fuji`.
4. Wählen Sie, was die Seitenzahl anzeigen soll:
   - **Aktuelle Seite** führt die Seite auf, auf der die Markierung steht.
   - **Seitenbereich** führt die Seiten auf, die eine Textmarke umfasst, zum Beispiel 5–7.
   - **Querverweis** führt statt einer Seite Wörter auf, zum Beispiel „Siehe Obst“.
5. Aktivieren Sie **Seitenzahl fett** oder **Seitenzahl kursiv**, wenn die Zahl hervorstechen soll.
6. Klicken Sie auf **Markieren**, um diese Stelle zu markieren, oder auf **Alle markieren**, um jede Stelle zu markieren, an der dieselben Wörter (mit denselben Groß- und Kleinbuchstaben) vorkommen.

Eine Markierung ist ein ausgeblendetes **Indexeintragsfeld** (ein XE-Feld). Es wird auf der Seite nicht angezeigt.

## Das Stichwortverzeichnis einfügen

1. Klicken Sie an die Stelle, an der das Stichwortverzeichnis stehen soll.
2. Klicken Sie auf **Verweise > Stichwortverzeichnis einfügen**.
3. Wählen Sie das Aussehen: **Eingerückt** setzt jeden Untereintrag in eine eigene Zeile, und **Mit Text in Zeile** setzt die Untereinträge nach dem Eintrag in eine gemeinsame Zeile. Legen Sie fest, ob die Seitenzahlen **rechtsbündig** stehen, welches Füllzeichen verwendet wird und ob jeder Gruppe ein Buchstabe als Überschrift vorangestellt wird.
4. Klicken Sie auf **OK**.

Das Stichwortverzeichnis listet die Einträge in alphabetischer Reihenfolge auf. Die Seitenzahlen eines Eintrags werden jeweils einmal in Seitenreihenfolge aufgeführt und durch Kommas getrennt.

## Das Stichwortverzeichnis aktuell halten

Klicken Sie im Stichwortverzeichnis auf **Verweise > Stichwortverzeichnis aktualisieren**, oder drücken Sie **F9**. Die Markierungen, die Sie hinzugefügt haben, werden aufgeführt, gelöschte Markierungen verschwinden, und die Seitenzahlen werden neu berechnet.
