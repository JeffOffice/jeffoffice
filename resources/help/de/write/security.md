# Sicherheit: worauf eine Datei zugreifen darf
<!-- keywords: Vertrauensstellen, Sicherheit, Makros, verknüpfte Dateien, Verknüpfungen, Links, verknüpfte Bilder, verknüpfte Medien, Internet, heruntergeladen, schreibgeschützt, geschützt, externe Verknüpfungen, Programme, sicher, Vertrauensstellungscenter, Datenschutz -->

Eine Datei kann auf andere Dinge verweisen: auf Dateien, Webseiten, Filme und sogar Programme. Auf der Seite **Sicherheit** legen Sie fest, wie JeffWrite damit umgeht. Klicken Sie auf **Datei > Optionen** und dann auf die Registerkarte **Sicherheit**. Klicken Sie auf **OK**, um Ihre Änderungen zu übernehmen, oder auf **Abbrechen**, um sie zu verwerfen.

Diese Einstellungen gelten für alle JeffOffice-Apps: Ändern Sie eine Einstellung in einer App, wird sie in allen anderen ebenfalls geändert. Eine Zeile für etwas, das eine App nicht besitzt, zeigt **Trifft nicht zu** und ist ausgegraut.

## Makros

Makros sind kleine Programme, die in einer Datei gespeichert sind. JeffWrite bewahrt sie in der Datei auf, sodass sie beim Speichern erhalten bleiben, und **führt sie niemals aus**. Es gibt keine Einstellung, die sie ausführt.

## Verknüpfte Dateien und Arbeitsmappenverknüpfungen

Dies trifft in JeffWrite nicht zu: Das Programm hat keine verknüpften Dateien, die aktualisiert werden könnten. Die Zeile ist ausgegraut.

## Verknüpfte Filme und Töne

Dies trifft in JeffWrite nicht zu: Das Programm hat keine verknüpften Filme oder Töne, die wiedergegeben werden könnten. Die Zeile ist ausgegraut.

## Dateien aus dem Internet oder von anderen Computern

Eine Datei, die Sie heruntergeladen haben oder die auf einem anderen Computer in Ihrem Netzwerk liegt, ist möglicherweise nicht sicher. Diese Einstellung legt fest, wie JeffWrite sie öffnet.

- **Zuerst schreibgeschützt öffnen** ist die übliche Wahl. Die Datei wird so geöffnet, dass Sie sie lesen, aber nicht ändern können. Eine Leiste unter der Datei weist darauf hin. Klicken Sie auf der Leiste auf **Bearbeitung aktivieren**, um diese eine Datei zu bearbeiten (bis Sie das Programm schließen). Wenn Sie sie danach am selben Ort speichern, wird die Download-Markierung von der Datei entfernt. Oder verwenden Sie **Speichern unter**, um eine Kopie zu erstellen, oder wechseln Sie in dieser Einstellung zur nächsten Wahl.
- **Normal öffnen** öffnet jede Datei auf die gleiche Weise.

Eine Datei, die Sie über den Bereich **Datei** mit **Als Kopie öffnen**, **Öffnen und reparieren** oder **Schreibgeschützt öffnen** öffnen, wird unabhängig von dieser Einstellung auf diese Weise geöffnet.

## Verknüpfungen, die ein Programm starten

Eine Verknüpfung, die ein Programm oder ein Skript startet (eine Datei mit der Endung .exe, .bat, .sh und ähnlichen), wird **immer abgelehnt**. JeffWrite teilt Ihnen das mit, und nichts wird ausgeführt. Eine Verknüpfung zu einer Datei auf einem anderen Computer wird nie ohne Rückfrage verfolgt. Keine Einstellung ändert das.
