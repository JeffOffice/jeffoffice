# Format mit „Format übertragen“ kopieren
<!-- keywords: Format übertragen, Format kopieren, Format einfügen, Formatierung kopieren, Formatierung übertragen, Pinsel, Formatpinsel, gleiches Aussehen, Strg+Umschalt+C, Strg+Umschalt+V, Doppelklick -->

Mit **Format übertragen** kopieren Sie das Aussehen eines Textes und übertragen es auf anderen Text. Verwenden Sie diese Funktion, wenn ein Wort oder Absatz genauso aussehen soll wie ein anderes bzw. ein anderer.

## Format auf eine Stelle übertragen

1. Markieren Sie die Wörter, deren Aussehen Sie übernehmen möchten. Oder klicken Sie in den Absatz.
2. Klicken Sie auf der Registerkarte **Start** auf **Format übertragen**. Die Schaltfläche bleibt gedrückt, und die Statusleiste zeigt an, was zu tun ist.
3. Markieren Sie mit der Maus die Wörter, die Sie ändern möchten. Sobald Sie die Maustaste loslassen, übernehmen sie das Aussehen, und „Format übertragen“ wird ausgeschaltet.

Wenn Sie in ein Wort klicken, ohne etwas zu markieren, übernimmt das Wort das Aussehen.

## Format auf mehrere Stellen übertragen

Doppelklicken Sie auf **Format übertragen**. Die Funktion bleibt eingeschaltet. Jedes Mal, wenn Sie Text mit der Maus markieren, übernimmt dieser Text das Aussehen. Drücken Sie **Esc**, oder klicken Sie erneut auf die Schaltfläche, um die Funktion zu beenden.

## Was kopiert wird

- Das Aussehen der Zeichen: Schriftart, Schriftgrad, Fett, Kursiv, Unterstreichung, Farbe und mehr.
- Das Aussehen des Absatzes, wenn Sie von einer Absatzmarke kopiert haben. Um von einer Absatzmarke zu kopieren, markieren Sie den ganzen Absatz bis zum Beginn des nächsten, oder klicken Sie in den Absatz, ohne etwas zu markieren. Ausrichtung, Einzüge, Abstände und Formatvorlage des Absatzes werden mitkopiert. Sie werden auf die Absätze übertragen, bei denen Ihre Markierung das Absatzende einschließt.
- Wenn Sie nur Wörter markieren, wird nur das Aussehen der Zeichen kopiert.

Die Liste, zu der ein Absatz gehört, und seine Position im Dokument werden nicht geändert.

Jede Übertragung ist ein einzelner Schritt. Mit **Rückgängig** (Strg+Z) machen Sie ihn rückgängig.

## Tastatur verwenden

- **Strg+Umschalt+C** kopiert das Aussehen Ihrer Markierung.
- **Strg+Umschalt+V** überträgt dieses Aussehen auf Ihre Markierung.
