# Drucken

Drücken Sie **Strg+P**, oder klicken Sie auf **Datei > Drucken**, um die Seite „Drucken“ zu öffnen. Die Optionen stehen links. Rechts sehen Sie für jede Seite eine Abbildung, so wie sie gedruckt wird. Mit den Pfeilen darunter blättern Sie zu den anderen Seiten.

## So drucken Sie

- **Drucker** listet die Drucker auf, die Ihr Computer kennt. **Als PDF speichern** erstellt statt eines Ausdrucks eine PDF-Datei. JeffWrite fragt nach einem Namen, wenn Sie auf **Drucken** klicken.
- **Exemplare** ist die Anzahl der Exemplare, die gedruckt werden.
- **Sortiert** ist wichtig, wenn Sie mehr als ein Exemplar drucken. Ist die Option aktiviert, werden die Seiten als 1, 2, 3, dann wieder 1, 2, 3 ausgegeben. Ist sie deaktiviert, erscheinen sie als 1, 1, 2, 2, 3, 3.
- **Alle Seiten**, **Aktuelle Seite** oder **Seiten** legt fest, was gedruckt wird. Geben Sie bei **Seiten** Seitenzahlen und Bereiche ein, durch Kommas getrennt, z. B. 1-3, 5. Ein Bereich kann auch rückwärts angegeben werden (5-3). Ein Bereich ohne Endangabe reicht bis zur letzten Seite (8-), ein Bereich ohne Anfangsangabe beginnt auf der ersten Seite (-2).
- Die Liste unter den Seitenzahlen kann das Drucken auf **Nur ungerade Seiten** oder **Nur gerade Seiten** beschränken. Sie zählt die Seiten der Reihe nach ab der ersten Seite des Dokuments: Die erste Seite ist Seite 1 (ungerade), die zweite Seite 2 (gerade) und so weiter. Dabei werden die auf den Seiten gedruckten Nummern nicht berücksichtigt. Beginnt die Nummerierung eines Dokuments neu oder bei 5, wird die erste Seite trotzdem als ungerade gezählt. Die Einschränkung wirkt auf die Seiten, die der Bereich ausgewählt hat.
- **Letzte Seite zuerst** druckt die Seiten in umgekehrter Reihenfolge, sodass der Stapel anschließend in der richtigen Reihenfolge liegt. Zusammen mit den Optionen für ungerade und gerade Seiten druckt es die beiden Seiten eines Blatts von Hand: Drucken Sie zuerst die ungeraden Seiten, drehen Sie den Stapel um, und drucken Sie dann die geraden Seiten. Stellen Sie **Letzte Seite zuerst** je nach Drucker ein oder aus, damit es passt.
- **Papier** zeigt an, auf welchem Papier die Seite in der Vorschau gedruckt wird.

Seiten werden in der Reihenfolge gedruckt, in der Sie sie eingeben, und jede nur einmal. Eine Zahl, die keine Seite des Dokuments ist, wird übersprungen. Wenn keine der eingegebenen Zahlen eine Seite ist, erhält das Feld einen roten Rand, und die Schaltfläche **Drucken** bleibt inaktiv.

Klicken Sie auf **Drucken**, um die Seiten zu senden. Die Seite „Drucken“ schließt sich, sobald der Drucker die Seiten übernommen hat.

## Seitenbereiche zählen Stellen, nicht gedruckte Nummern

Die Zahlen, die Sie bei **Seiten** eingeben, sind Stellen im Dokument: 1 ist die erste Seite, 2 die zweite und so weiter, unabhängig davon, welche Nummer auf der Seite steht. Beginnt ein Abschnitt seine Nummerierung neu, etwa mit Seite 1 eines neuen Kapitels, oder bei einer anderen Zahl, kann die auf einer Seite angezeigte Nummer von ihrer Stelle abweichen. Geben Sie dann die Stelle ein. Die Zeile unter der Vorschau, z. B. **Seite 5 von 12**, nennt die Stelle der gerade angezeigten Seite, sodass Sie die einzugebende Zahl finden.

## Das Papier kommt aus dem Dokument

Jeder Abschnitt eines Dokuments hat ein eigenes Papierformat und eine eigene Ausrichtung, die Sie auf der Registerkarte **Layout** festlegen. JeffWrite druckt jede Seite auf dem Papier ihres Abschnitts und dreht eine Querformatseite auf die Seite. Verwenden die ausgewählten Seiten mehr als eine Papiersorte, weist die Zeile **Papier** darauf hin. Legen Sie das Papier ein, das jede Seite benötigt.

## Papier und PDF sehen gleich aus

JeffWrite zeichnet eine Seite für den Drucker und für eine PDF-Datei gleich: dieselben Linien, dieselben Umbrüche und dieselben Schriftarten. Die roten Linien der Rechtschreibprüfung und die Absatzmarken werden nicht gedruckt.

Um eine PDF-Datei ohne die Seite „Drucken“ zu erstellen, siehe [Öffnen, Speichern, Drucken und Exportieren](open-save).
