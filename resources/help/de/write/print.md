# Drucken

Drücken Sie **Strg+P**, oder klicken Sie auf **Datei > Drucken**, um die Seite „Drucken“ zu öffnen. Links finden Sie die Einstellungen. Rechts sehen Sie eine Vorschau jeder Seite, wie sie gedruckt wird. Mit den Pfeilen darunter blättern Sie zu den anderen Seiten.

## Druckeinstellungen wählen

- **Drucker** listet die Drucker auf, die Ihrem Computer bekannt sind. **Als PDF speichern** erstellt statt eines Ausdrucks eine PDF-Datei. JeffWrite fragt nach einem Dateinamen, wenn Sie auf **Drucken** klicken.
- **Exemplare** gibt an, wie viele Exemplare gedruckt werden.
- **Sortiert** ist wichtig, wenn Sie mehr als ein Exemplar drucken. Ist die Option aktiviert, werden die Seiten in der Reihenfolge 1, 2, 3 und dann wieder 1, 2, 3 ausgegeben. Ist sie deaktiviert, kommen sie in der Reihenfolge 1, 1, 2, 2, 3, 3.
- Mit **Alle Seiten**, **Aktuelle Seite** oder **Seiten** legen Sie fest, was gedruckt wird. Geben Sie bei **Seiten** Seitenzahlen und Seitenbereiche durch Kommas getrennt ein, z. B. 1-3, 5. Ein Bereich kann auch rückwärts verlaufen (5-3). Ein Bereich mit offenem Ende reicht bis zur letzten Seite (8-) oder beginnt bei der ersten (-2).
- **Papier** gibt an, auf welchem Papier die Seite in der Vorschau gedruckt wird.

Die Seiten werden in der eingegebenen Reihenfolge gedruckt, jede einmal. Eine Zahl, die keiner Seite des Dokuments entspricht, wird übersprungen. Entspricht keine der eingegebenen Zahlen einer Seite, erhält das Feld einen roten Rand, und die Schaltfläche **Drucken** bleibt deaktiviert.

Klicken Sie auf **Drucken**, um die Seiten zu senden. Die Seite „Drucken“ wird geschlossen, sobald der Drucker die Seiten erhalten hat.

## Seitenbereiche zählen Positionen, nicht gedruckte Seitenzahlen

Die Zahlen, die Sie bei **Seiten** eingeben, sind Positionen im Dokument: 1 ist die erste Seite, 2 die zweite usw., unabhängig davon, welche Seitenzahl auf der Seite steht. Beginnt ein Abschnitt seine Nummerierung neu, etwa mit Seite 1 eines neuen Kapitels, oder beginnt er bei einer anderen Zahl, kann die angezeigte Seitenzahl von der Position abweichen. Geben Sie die Position ein. Die Zeile unter der Vorschau, z. B. **Seite 5 von 12**, nennt die Position der angezeigten Seite, sodass Sie die einzugebende Zahl ermitteln können.

## Das Papier richtet sich nach dem Dokument

Jeder Abschnitt eines Dokuments hat eine eigene Papiergröße und eine eigene Ausrichtung, die Sie auf der Registerkarte **Layout** festlegen. JeffWrite druckt jede Seite auf dem Papier ihres Abschnitts und dreht Seiten im Querformat entsprechend. Verwenden die ausgewählten Seiten mehr als eine Papiersorte, weist die Zeile **Papier** darauf hin. Legen Sie das Papier ein, das die jeweilige Seite benötigt.

## Ausdruck und PDF sehen gleich aus

JeffWrite stellt eine Seite für den Drucker und für eine PDF-Datei auf dieselbe Weise dar: mit denselben Zeilen, denselben Umbrüchen und denselben Schriftarten. Die roten Wellenlinien der Rechtschreibprüfung und die Absatzmarken werden nie gedruckt.

Wie Sie eine PDF-Datei ohne die Seite „Drucken“ erstellen, erfahren Sie unter [Öffnen, speichern, drucken und exportieren](open-save).
