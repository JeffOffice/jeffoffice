# Quellenangaben und Literaturverzeichnis
<!-- keywords: Zitat, Quelle, Quellenangabe, Literaturverzeichnis, works cited, Verweise, references, APA, MLA, Chicago, Harvard, IEEE, Quellen verwalten, Quellenangabe einfügen, Zitierformat, Autor, Buch, Zeitschrift -->

Eine **Quelle** ist ein Buch, ein Artikel, eine Webseite oder etwas anderes, das Sie zitieren oder woraus Sie etwas lernen. Eine **Quellenangabe** ist die kurze Erwähnung einer Quelle in Ihrem Text, zum Beispiel (Schmidt, 2020). Ein **Literaturverzeichnis** ist die Liste der Quellen am Ende. JeffWrite speichert Ihre Quellen in einer einzigen Liste, erstellt für Sie jede Quellenangabe und jeden Eintrag im Literaturverzeichnis und aktualisiert alle, wenn Sie das Zitierformat ändern.

## Quellenangabe einfügen

1. Klicken Sie an die Stelle, an der die Quellenangabe stehen soll.
2. Klicken Sie auf **Verweise > Quellenangabe einfügen**.
3. Wählen Sie eine Quelle aus der Liste, oder klicken Sie auf **Neue Quelle**, um eine zu erstellen.
4. Geben Sie unter **Seiten** die Seitenzahlen ein, wenn die Quellenangabe sie nennen soll. Aktivieren Sie **Autor weglassen** oder **Jahr weglassen**, wenn der Satz diese bereits enthält, oder **Titel anzeigen**.
5. Klicken Sie auf **Einfügen**.

## Quelle erstellen

Wählen Sie im Feld „Quelle“ den **Quellentyp** aus. Das Feld fragt dann nach den Angaben, die dieser Typ braucht: Ein Buch verlangt Titel, Jahr, Ort und Verlag, ein Artikel Name der Zeitschrift, Band, Heft und Seiten. Geben Sie jeden Autor in einer eigenen Zeile im Format `Nachname, Vorname Zweitname` ein. Ein Unternehmen oder eine Gruppe kann unter **Organisation als Autor** als Autor angegeben werden. Der **Kurzname** ist der kurze Name, den eine Quellenangabe verwendet; JeffWrite erstellt ihn aus Autor und Jahr, zum Beispiel Sch20.

## Quellen verwalten

Klicken Sie auf **Verweise > Quellen verwalten**. Das Feld zeigt zwei Listen:

- Die **Hauptliste** gehört Ihnen. Jedes Dokument, das Sie schreiben, kann Quellen daraus übernehmen.
- Die **Aktuelle Liste** enthält die Quellen in diesem Dokument.

Mit **Kopieren** verschieben Sie eine Quelle von einer Liste in die andere, mit **Neu** erstellen Sie eine Quelle, mit **Bearbeiten** ändern Sie eine, und mit **Löschen** entfernen Sie eine. Eine Vorschau zeigt, wie die Quelle im Literaturverzeichnis aussieht. Quellen, die Sie im Feld „Quellenangabe einfügen“ erstellen, werden ebenfalls in die Hauptliste aufgenommen.

## Zitierformat wählen

Klicken Sie auf **Verweise > Zitierformat** und wählen Sie **APA (6. Auflage)**, **MLA (7. Auflage)**, **Chicago (15. Auflage)**, **Harvard** oder **IEEE**. Die Auflagen sind angegeben, weil es von diesen Leitfäden neuere Auflagen gibt; sie sind nicht fest eingebaut. Jede Quellenangabe und jedes Literaturverzeichnis im Dokument wird in dieses Format umgestellt. Bei IEEE ist eine Quellenangabe eine Zahl in eckigen Klammern, zum Beispiel [1], in der Reihenfolge, in der die Quellen zum ersten Mal zitiert werden.

## Literaturverzeichnis einfügen

Klicken Sie an die Stelle, an der die Liste stehen soll, klicken Sie auf **Verweise > Literaturverzeichnis** und wählen Sie **Literaturverzeichnis**, **Referenzen** oder **Works Cited**. JeffWrite fügt eine Überschrift und eine Liste der Quellen ein, die Sie zitiert haben, in der Reihenfolge ihres Auftretens. Eine Quelle, die Sie nicht zitiert haben, ist nicht in der Liste enthalten. Wenn Sie später weitere Quellen zitieren, klicken Sie in die Liste und drücken Sie **F9**, um sie neu zu erstellen.

## Was gespeichert wird

Ihre Quellen werden in der Datei in einer Form gespeichert, die auch andere Textverarbeitungsprogramme lesen. Eine geöffnete Datei behält ihre Quellen genau so, wie sie waren, bis Sie sie ändern.
