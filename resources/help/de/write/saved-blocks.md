# Einen Baustein speichern und wieder einfügen
<!-- keywords: Bausteine, Textbausteine, Vorlagentext, Signatur, Briefkopf, Textkürzel, Textkürzel verwenden, Text wiederverwenden, Auswahl speichern, erneut einfügen, F3, Bibliothek, gespeicherte Bausteine -->

Ein **Baustein** ist ein Teil eines Dokuments, den Sie speichern, damit Sie ihn wieder einfügen können: eine Unterschrift, einen Absatz, den Sie in jedem Brief verwenden, einen Briefkopf oder ein Bild mit Bildunterschrift. Ein Baustein behält seinen Text mit Schriftarten, Farben, Formatvorlagen, Aufzählungszeichen und Nummerierungen, Bildern, Links, Feldern und Tabellen (Zeilen, Spalten, Breiten, Rahmen, Schattierungen, verbundene Zellen, eine Kopfzeile, die sich wiederholt, und das Tabellenformat). Kommentare, Fußnoten, Endnoten und Abschnittswechsel werden nicht übernommen (siehe Wissenswertes).

## Baustein speichern

1. Markieren Sie den Inhalt, den Sie speichern möchten.
2. Wählen Sie **Einfügen > Gespeicherte Bausteine > Auswahl als Baustein speichern**.
3. Geben Sie unter **Name** einen Namen ein. Sie können auch eine **Kategorie** und eine **Beschreibung** angeben, die Ihnen helfen, den Baustein später wiederzufinden.
4. Wählen Sie unter **Katalog** entweder **Gespeicherte Bausteine** (ein Baustein, den Sie aus einem Katalog auswählen) oder **Textkürzel** (ein Baustein, den Sie durch Eingabe seines Namens einfügen).
5. Wählen Sie unter **Einfügen als**, wie der Baustein in ein Dokument eingefügt wird: **Wie er ist, an der Einfügemarke**, **In einem eigenen Absatz** oder **Auf einer eigenen Seite**.
6. Klicken Sie auf **Speichern**.

Ist bereits ein Baustein mit diesem Namen gespeichert, fragt JeffWrite, ob er ersetzt werden soll.

## Baustein einfügen

1. Setzen Sie die Einfügemarke an die Stelle, an die der Baustein soll. Wenn Sie vorher Wörter markieren, nimmt der Baustein deren Platz ein.
2. Wählen Sie **Einfügen > Gespeicherte Bausteine** und klicken Sie dann auf den Baustein. Geben Sie im Suchfeld den Namen, die Kategorie oder die Beschreibung ein, um einen Baustein zu finden.

Das Einfügen eines Bausteins lässt sich mit einem Schritt rückgängig machen. Eine Formatvorlage, die der Baustein verwendet und die Ihr Dokument nicht hat, wird hinzugefügt. Eine Formatvorlage, die Ihr Dokument bereits unter demselben Namen hat, wird nie verändert. Ein Feld im Baustein, etwa die Seitenzahl, wird für das Dokument aktualisiert, in das es eingefügt wird. Der erste und der letzte Absatz eines Bausteins übernehmen das Aussehen der Absätze, an die sie angrenzen, wie beim Einfügen.

## Textkürzel

Ein Textkürzel ist ein Baustein mit einem kurzen Namen. Geben Sie den Namen ein und drücken Sie dann **F3** (oder wählen Sie **Einfügen > Gespeicherte Bausteine > Textkürzel erweitern**). Der Name wird durch den Baustein ersetzt. Der Name muss am Anfang eines Wortes stehen: „sig“ funktioniert nach einem Leerzeichen, aber nicht innerhalb von „Design“.

## Gespeicherte Bausteine verwalten

Wählen Sie **Einfügen > Gespeicherte Bausteine > Gespeicherte Bausteine verwalten**. Dort sehen Sie jeden Baustein und können seinen Namen, seine Kategorie, seine Beschreibung oder die Art, wie er eingefügt wird, über **Eigenschaften bearbeiten** ändern sowie ihn mit **Löschen** entfernen. **Löschen rückgängig machen** stellt das Gelöschte wieder her, solange das Fenster geöffnet ist. Mit **Exportieren** speichern Sie Ihre Bausteine in einer Datei, und mit **Importieren** fügen Sie die Bausteine einer solchen Datei hinzu. Ein Baustein, dessen Name bereits vorhanden ist, bleibt unverändert.

## Wissenswertes

- Ihre gespeicherten Bausteine liegen in einer einzigen Datei auf diesem Computer, nur für Ihr eigenes Konto: Sie stehen nicht in Ihren Dokumenten und werden nirgendwohin gesendet. Die Datei heißt `library.jblocks` und liegt im Ordner `Saved Blocks` innerhalb Ihres Datenordners: `AppData\Local\JeffOffice` unter Windows, `Library/Application Support/JeffOffice` auf dem Mac und `.local/share/JeffOffice` unter Linux. Alle JeffOffice-Programme auf Ihrem Computer nutzen diese Datei gemeinsam, und zwei Fenster können gleichzeitig Bausteine hinzufügen, ohne dass einer den anderen verliert.
- Ein Baustein darf bis zu 8 Megabyte groß sein, und die Bibliothek enthält bis zu 5.000 Bausteine.
- Eine Tabelle wird als Tabelle gespeichert, wenn die Auswahl die ganze Tabelle umfasst. Enthält die Auswahl nur einen Teil einer Tabelle, wird dieser Teil als Text gespeichert, mit einem Absatz für jede Zelle; JeffWrite weist Sie vor dem Speichern darauf hin.
- Eine Textmarke in einem Baustein erhält beim Einfügen einen eigenen Namen: Hat Ihr Dokument bereits eine Textmarke mit diesem Namen, wird die neue mit „_2“, „_3“ usw. benannt.
- Kommentare, Fußnoten und Endnoten werden nicht übernommen. Abschnittswechsel werden nicht gespeichert. Formen und Textfelder bleiben erhalten und werden zusammen mit dem Baustein wieder eingefügt.
- Nachverfolgte Änderungen werden beim Speichern des Bausteins angenommen: Die eingefügten Wörter bleiben, die gelöschten Wörter sind nicht im Baustein enthalten. Ein Baustein enthält daher nie nachverfolgte Wörter einer anderen Person.
- Ein Dokument fügt nie Bausteine zu Ihrer Bibliothek hinzu. Das tun nur Sie.
