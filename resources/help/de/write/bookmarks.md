# Textmarken
<!-- keywords: Textmarke, Textmarken, Lesezeichen, gehe zu, Stelle markieren, Textmarke löschen, ausgeblendete Textmarken, Sprungmarke, Strg+Umschalt+F5 -->

Eine **Textmarke** gibt einer Stelle oder einem Textabschnitt einen Namen. So können Sie direkt dorthin springen oder in einem Querverweis darauf verweisen.

## Textmarke hinzufügen

1. Markieren Sie den Text, oder klicken Sie an die Stelle, an der die Textmarke stehen soll.
2. Klicken Sie auf **Einfügen > Textmarke**, oder drücken Sie **Strg+Umschalt+F5**.
3. Geben Sie einen Namen ein. Er muss mit einem Buchstaben beginnen und darf Buchstaben, Ziffern und Unterstriche enthalten, aber keine Leerzeichen. Er darf bis zu 40 Zeichen lang sein.
4. Klicken Sie auf **Hinzufügen**.

Wenn Sie einen Namen hinzufügen, der bereits verwendet wird, wird die Textmarke an die neue Stelle verschoben.

## Zu einer Textmarke wechseln oder sie löschen

Öffnen Sie das Dialogfeld **Textmarke**, wählen Sie den Namen in der Liste aus, und klicken Sie auf **Gehe zu**, oder doppelklicken Sie auf den Namen. Klicken Sie auf **Löschen**, um die Textmarke zu entfernen. Der Text bleibt erhalten.

Mit **Sortieren nach** listen Sie die Namen alphabetisch oder in der Reihenfolge auf, in der sie im Text stehen. Aktivieren Sie **Ausgeblendete Textmarken**, um die Textmarken anzuzeigen, die JeffWrite und andere Programme für den eigenen Gebrauch anlegen. Ihre Namen beginnen mit einem Unterstrich.

## Beispiel

Markieren Sie die Wörter `Quarterly results`, drücken Sie **Strg+Umschalt+F5**, geben Sie `results` ein, und klicken Sie auf **Hinzufügen**. Öffnen Sie später **Verweise > Querverweis**, wählen Sie **Textmarke** aus, und fügen Sie **Seitenzahl** für `results` ein. Im Text wird dann die Seite angezeigt, auf der sich die Textmarke befindet.
