# Formulare mit Inhaltssteuerelementen erstellen

Ein **Inhaltssteuerelement** ist ein Feld in Ihrem Text, das eine Person ausfüllt: eine Zeile Text, formatierte Absätze, ein Bild, eine Auswahl aus einer Liste, ein Datum aus einem Kalender, ein Kontrollkästchen oder ein Abschnitt, der wiederholt werden kann. Damit erstellen Sie ein Formular, das andere ausfüllen können, ohne den übrigen Text des Dokuments zu verändern.

## Ein Steuerelement einfügen

1. Setzen Sie die Einfügemarke an die Stelle, an der das Steuerelement stehen soll.
2. Wählen Sie **Einfügen > Inhaltssteuerelement** und dann die gewünschte Art:
   - **Formatierter Text:** ein Feld für formatierte Wörter. Sind Absätze markiert oder befindet sich die Einfügemarke in einem leeren Absatz, enthält das Steuerelement ganze Absätze, auch Listen und Tabellen, und die Eingabetaste erzeugt darin einen neuen Absatz. Wird es in einem Absatz mit anderem Text erstellt, enthält es nur Wörter dieses Absatzes, und die Eingabetaste teilt es dort in zwei Steuerelemente.
   - **Nur-Text:** ein Feld für Wörter. Es zeigt den Platzhalter „Text eingeben“, bis jemand etwas eingibt. Sind Wörter markiert, wird das Steuerelement um sie herum erstellt.
   - **Bild:** eine Stelle für ein Bild. Sie zeigt „Bild hinzufügen“, bis ein Bild eingefügt wird.
   - **Kombinationsfeld:** eine Liste mit Auswahlmöglichkeiten, in die Sie auch selbst etwas eingeben können. Es zeigt „Element auswählen oder eingeben“, bis etwas ausgewählt oder eingegeben wird.
   - **Dropdown-Liste:** eine Liste mit Auswahlmöglichkeiten. Sie zeigt „Element auswählen“, bis eines ausgewählt wird.
   - **Datumsauswahl:** ein Datum aus einem Kalender. Sie zeigt „Datum auswählen“, bis ein Datum gewählt wird.
   - **Kontrollkästchen:** ein kleines Kästchen, das aktiviert oder deaktiviert ist.
   - **Wiederholungsabschnitt:** Der Absatz, in dem sich die Einfügemarke befindet (oder die markierten Absätze), wird zum ersten Element eines Abschnitts, der weitere Elemente haben kann.

Ein Steuerelement erhält eine helle Hinterlegung, damit Sie sehen, wo es beginnt und endet. Befindet sich die Einfügemarke darin, erscheint ein Rahmen, und sein Titel steht auf einer Registerkarte darüber. Das Einfügen eines Steuerelements lässt sich mit einem einzigen Schritt rückgängig machen.

## Ein Steuerelement ausfüllen

- **Formatierter Text:** Klicken Sie auf den Platzhalter, und geben Sie den Text ein. Alles, was im Text möglich ist, etwa Fettschrift, Listen und Tabellen, funktioniert auch in einem Steuerelement, das Absätze enthält.
- **Bild:** Klicken Sie auf das Steuerelement oder drücken Sie die Eingabetaste, während sich die Einfügemarke darin befindet, und wählen Sie eine Bilddatei aus. Sie können eine Bilddatei auch auf das Steuerelement ziehen. Ein Bild, das an die Stelle eines anderen gesetzt wird, übernimmt dessen Größe, wobei das Seitenverhältnis erhalten bleibt. Ein Bildsteuerelement beginnt mit einer Kantenlänge von 5,1 cm (2 Zoll). Mit **Bild leeren** (im Menü „Inhaltssteuerelement“) erscheint wieder der Platzhalter.
- **Kombinationsfeld:** Klicken Sie auf den Platzhalter, und geben Sie den Text ein. Sie können auch das Steuerelement doppelklicken (oder bei Einfügemarke darin Alt+Pfeil nach unten drücken) und dann ein Element anklicken.
- **Wiederholungsabschnitt:** Klicken Sie auf die Schaltfläche **+** am Ende des Abschnitts oder wählen Sie **Element hinzufügen**, um nach dem letzten Element ein neues anzuhängen. Jedes neue Element ist eine Kopie des letzten, bei der alle Steuerelemente wieder leer sind. **Element entfernen** löscht das Element, in dem sich die Einfügemarke befindet. Ein Abschnitt behält mindestens ein Element und hat höchstens 1.000. Bei eingeschalteter Änderungsnachverfolgung ist ein hinzugefügtes Element eine nachverfolgte Einfügung und ein entferntes Element eine nachverfolgte Löschung, sodass ein Prüfer sie sehen kann. Mit „Alle Änderungen ablehnen“ wird alles wiederhergestellt. Bei eingeschalteter Änderungsnachverfolgung können Sie einem Abschnitt, der das Dokumentende bildet, kein Element hinzufügen und kein Element daraus entfernen. Schalten Sie in diesem Fall die Änderungsnachverfolgung aus oder fügen Sie nach dem Abschnitt einen Absatz ein.
- **Nur-Text:** Klicken Sie auf den Platzhalter, und geben Sie den Text ein. Ihre Eingabe ersetzt den Platzhalter. Drücken Sie Umschalt+Eingabetaste für einen Zeilenumbruch; die Eingabetaste erzeugt in einem Steuerelement keinen neuen Absatz.
- **Dropdown-Liste:** Klicken Sie auf das Steuerelement (oder drücken Sie bei Einfügemarke darin die Eingabetaste oder Alt+Pfeil nach unten) und dann auf ein Element. Das ausgewählte Element wird beim nächsten Öffnen der Liste markiert.
- **Datumsauswahl:** Klicken Sie auf das Steuerelement und dann auf einen Tag im Kalender. **Heute** fügt das heutige Datum ein. **Leeren** bringt den Platzhalter zurück.
- **Kontrollkästchen:** Klicken Sie darauf oder drücken Sie die Leertaste, während sich die Einfügemarke darin befindet, um es zu aktivieren oder zu deaktivieren.

Eine Dropdown-Liste, eine Datumsauswahl, ein Kontrollkästchen und ein Bildsteuerelement enthalten nur das, was dafür ausgewählt wird; hineinschreiben können Sie darin nicht.

## Die Eigenschaften eines Steuerelements ändern

Setzen Sie die Einfügemarke in das Steuerelement, und wählen Sie **Einfügen > Inhaltssteuerelement > Eigenschaften**. Sie können festlegen:

- **Titel** und **Tag:** Der Titel erscheint auf der Registerkarte über dem Steuerelement. Das Tag ist ein kurzer Name, mit dem andere Programme das Steuerelement finden können.
- **Elemente in der Liste** (Dropdown-Liste und Kombinationsfeld): Hinzufügen, umbenennen (doppelklicken Sie auf ein Element), Entfernen, Nach oben und Nach unten. Eine Liste enthält höchstens 1.000 Elemente.
- **Datumsformat** (Datumsauswahl): Wählen Sie ein Format aus oder geben Sie ein eigenes ein, zum Beispiel MMMM d, yyyy. Das Feld zeigt, wie das heutige Datum in diesem Format aussieht.
- **Das Steuerelement kann nicht gelöscht werden:** Das Steuerelement bleibt erhalten, der Inhalt darin lässt sich aber ändern.
- **Der Inhalt kann nicht bearbeitet werden:** Das Steuerelement lässt sich löschen, der Inhalt darin aber nicht ändern. Dazu zählen Eingeben, Einfügen, Ziehen, Suchen und Ersetzen, eine Rechtschreibkorrektur, eine neue Darstellung der Wörter, Formatierung übertragen, Tabellenbefehle sowie das Annehmen oder Ablehnen einer nachverfolgten Änderung darin. Eine Änderung darin, die vor der Sperre nachverfolgt wurde, bleibt zur späteren Klärung bestehen.
- **Elemente können nicht hinzugefügt oder entfernt werden** (Wiederholungsabschnitt): „Element hinzufügen“ und „Element entfernen“ tun nichts und teilen mit, warum. Setzen Sie die Einfügemarke in ein beliebiges Element, um dieses Feld für den gesamten Abschnitt zu sehen.

Wählen Sie **OK**, um die Änderungen anzuwenden. Sie lassen sich gemeinsam mit einem einzigen Schritt rückgängig machen.

## Gut zu wissen

- Ein Steuerelement, das ganze Absätze enthält, hält seinen Text von den umgebenden Absätzen getrennt. Lässt es sich nicht löschen oder sein Inhalt nicht bearbeiten, bewirken Rücktaste und Entf am Rand ohne Wirkung, da sonst Wörter hinein- oder herausgeschoben würden. Ist es nicht gesperrt, übernimmt ein über seinen Rand hinweg zusammengeführter Absatz die Seite, auf der die Einfügemarke steht, und das Steuerelement behält seine übrigen Absätze. Ein Steuerelement mit nur einem Absatz bleibt immer mit mindestens einem Absatz bestehen, sodass der zusammengeführte Absatz darin bleibt.
- Eine Sperre bei einem Steuerelement, das ganze Tabellenzeilen oder Zellen umfasst, wird in der Datei gespeichert, JeffWrite kann sie jedoch nicht anwenden. Dasselbe gilt für ein Steuerelement, das mit einer Tabelle beginnt.
- Ein Dokument, das zum Ausfüllen von Formularen geschützt ist, ist durchgehend schreibgeschützt. Daher lässt sich darin kein Steuerelement ausfüllen, und die Tab-Taste springt nicht zwischen Steuerelementen.
- Ein Dokument kann bis zu 10.000 Steuerelemente enthalten; Steuerelemente lassen sich bis zu 8 Ebenen ineinander verschachteln. Ein Wiederholungsabschnitt und seine Elemente zählen als Steuerelemente.
- Steuerelemente in Dateien anderer Programme werden so angezeigt und beibehalten, wie sie waren. Eine Art, die JeffWrite nicht erstellen kann (etwa eine Bausteingalerie, eine Formel oder eine Gruppe), bleibt an ihrer Stelle erhalten; Sie können deren Titel, Tag und Sperren ändern, aber nicht den Inhalt.
- Steuerelemente werden in `.docx`-Dateien gespeichert. In anderen Dateiformaten bleiben die Wörter erhalten, das Steuerelement jedoch nicht. Die **Kompatibilitätsprüfung** weist darauf hin und nennt die Arten ohne Entsprechung: Wiederholungsabschnitte, Bildsteuerelemente und Kombinationsfelder.
