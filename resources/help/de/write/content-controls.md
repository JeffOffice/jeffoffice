# Formulare mit Inhaltssteuerelementen erstellen
<!-- keywords: Inhaltssteuerelement, Inhaltssteuerelemente, Steuerelement, Formular, Formulare, ausfüllen, Nur-Text, Textfeld, Dropdown-Liste, Dropdown, Datumsauswahl, Kalender, Kontrollkästchen, Checkbox, Titel, Tag, Platzhalter, sperren, nicht löschen, Eigenschaften -->

Ein **Inhaltssteuerelement** ist ein Feld in Ihrem Text, das eine Person ausfüllt: eine Textzeile, eine Auswahl aus einer Liste, ein Datum aus einem Kalender oder ein Kontrollkästchen. Damit erstellen Sie ein Formular, das andere ausfüllen können, ohne den übrigen Inhalt des Dokuments zu verändern.

## Ein Steuerelement einfügen

1. Setzen Sie die Einfügemarke an die Stelle, an der das Steuerelement stehen soll.
2. Wählen Sie **Einfügen > Inhaltssteuerelement** und dann die gewünschte Art:
   - **Nur-Text:** ein Feld für Wörter. Es zeigt den Platzhalter „Text eingeben“, bis jemand etwas schreibt. Sind Wörter markiert, wird das Steuerelement um sie herum erstellt.
   - **Dropdown-Liste:** eine Liste mit Auswahlmöglichkeiten. Sie zeigt „Element auswählen“, bis ein Eintrag gewählt wird.
   - **Datumsauswahl:** ein Datum aus einem Kalender. Sie zeigt „Datum auswählen“, bis ein Datum gewählt wird.
   - **Kontrollkästchen:** ein kleines Feld, das angekreuzt oder leer sein kann.

Ein Steuerelement erhält einen hellen Hintergrund, damit Sie sehen, wo es beginnt und endet. Wenn die Einfügemarke darin steht, erscheint um das Steuerelement ein Rahmen, und sein Titel steht auf einer Registerkarte darüber. Das Einfügen eines Steuerelements lässt sich mit einem einzigen Schritt rückgängig machen.

## Ein Steuerelement ausfüllen

- **Nur-Text:** Klicken Sie auf den Platzhalter, und geben Sie Ihren Text ein. Der Text ersetzt den Platzhalter. Drücken Sie Umschalt+Enter für einen Zeilenumbruch; mit Enter wird innerhalb eines Steuerelements kein neuer Absatz begonnen.
- **Dropdown-Liste:** Klicken Sie auf das Steuerelement (oder drücken Sie bei gesetzter Einfügemarke Enter oder Alt+Pfeil nach unten), und klicken Sie dann auf einen Eintrag. Der gewählte Eintrag ist beim nächsten Öffnen der Liste markiert.
- **Datumsauswahl:** Klicken Sie auf das Steuerelement und danach auf einen Tag im Kalender. **Heute** fügt das heutige Datum ein. **Platzhalter wiederherstellen** stellt den Platzhalter wieder her.
- **Kontrollkästchen:** Klicken Sie darauf, oder drücken Sie bei gesetzter Einfügemarke die Leertaste, um es anzukreuzen oder die Markierung zu entfernen.

Eine Dropdown-Liste, eine Datumsauswahl und ein Kontrollkästchen enthalten nur das, was dafür ausgewählt wird: In sie können Sie nicht schreiben.

## Eigenschaften eines Steuerelements ändern

Setzen Sie die Einfügemarke in das Steuerelement, und wählen Sie **Einfügen > Inhaltssteuerelement > Eigenschaften**. Sie können Folgendes festlegen:

- **Titel** und **Tag:** Der Titel wird auf der Registerkarte über dem Steuerelement angezeigt. Das Tag ist ein kurzer Name, mit dem andere Programme das Steuerelement finden können.
- **Einträge in der Liste** (Dropdown-Liste): Hinzufügen, Umbenennen (Doppelklick auf einen Eintrag), Entfernen, Nach oben und Nach unten. Eine Liste enthält bis zu 1.000 Einträge.
- **Datumsformat** (Datumsauswahl): Wählen Sie ein Format, oder geben Sie ein eigenes ein, etwa MMMM d, yyyy. Das Feld zeigt, wie das heutige Datum in diesem Format aussieht.
- **Das Steuerelement kann nicht gelöscht werden:** Das Steuerelement bleibt bestehen, der Inhalt darin kann aber geändert werden.
- **Der Inhalt kann nicht bearbeitet werden:** Das Steuerelement kann gelöscht werden, der Inhalt darin kann aber nicht geändert werden.

Wählen Sie **OK**, um die Änderungen zu übernehmen. Sie lassen sich mit einem einzigen Schritt rückgängig machen.

## Gut zu wissen

- Ein Dokument kann bis zu 10.000 Steuerelemente enthalten, und Steuerelemente können bis zu 8 Ebenen tief ineinander liegen.
- Steuerelemente aus Dateien anderer Programme werden so angezeigt und beibehalten, wie sie waren. Eine Art, die JeffWrite nicht erstellen kann (etwa Rich Text, ein Bild, ein Kombinationsfeld oder einen sich wiederholenden Abschnitt), bleibt an ihrer Stelle erhalten; Sie können ihren Titel, das Tag und die Sperren ändern, aber nicht ihre Liste mit Inhalten.
- Steuerelemente werden in `.docx`-Dateien gespeichert. In anderen Dateiformaten bleiben die Wörter erhalten, das Steuerelement jedoch nicht.
