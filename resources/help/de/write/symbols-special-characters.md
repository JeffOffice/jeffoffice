# Sonderzeichen und Symbole einfügen

Ein **Symbol** ist ein Zeichen, das nicht auf Ihrer Tastatur liegt, etwa der griechische Buchstabe Omega oder ein Pfeil. Ein **Sonderzeichen** ist ein Zeichen, das die Seite auf eine bestimmte Weise behandelt, etwa ein Leerzeichen, an dem nie ein Zeilenumbruch erfolgt.

## Symbole

1. Setzen Sie die Einfügemarke an die Stelle, an der das Symbol stehen soll.
2. Wählen Sie **Einfügen > Symbol**. Ein kleines Feld zeigt die Symbole, die Sie zuletzt verwendet haben. Klicken Sie auf eines, um es einzufügen.
3. Für jedes andere Symbol wählen Sie **Weitere Sonderzeichen**. Wählen Sie eine **Schriftart** und einen **Subset** (einen Block zusammengehöriger Zeichen, etwa Pfeile). Doppelklicken Sie auf ein Symbol, oder klicken Sie es an und wählen Sie **Einfügen**.

Das Fenster bleibt geöffnet, damit Sie mehrere Symbole einfügen können. Das Feld zeigt den **Zeichencode** des Symbols, auf das Sie klicken. Das Symbol wird in der Schriftart eingefügt, die Sie gewählt haben. Die Auswahl **(normaler Text)** behält die eigene Schriftart des Textes bei.

## Sonderzeichen

Wählen Sie **Einfügen > Sonderzeichen** und danach eines der folgenden Zeichen.

- **Geschütztes Leerzeichen** (Strg+Umschalt+Leertaste) ist ein Leerzeichen, das zwei Wörter in derselben Zeile hält.
- **Geschützter Bindestrich** (Strg+Umschalt+Minus) ist ein Bindestrich, an dem ein Wort nie getrennt wird.
- **Bedingter Trennstrich** (Strg+Minus) ist ein Bindestrich, der nur dann erscheint, wenn das Wort am Zeilenende an dieser Stelle getrennt wird.
- **Halbgeviertstrich** und **Geviertstrich** sind Gedankenstriche. Ein Halbgeviertstrich ist so breit wie der Buchstabe n. Ein Geviertstrich ist so breit wie der Buchstabe m.
- **Halbgeviertabstand** und **Geviertabstand** sind Leerzeichen in der Breite dieser Buchstaben.
- Die vier **Anführungszeichen** sind typografische Zeichen, öffnend und schließend, doppelt und einfach.
- **Zeilenumbruch** (Umschalt+Eingabe) beginnt eine neue Zeile, ohne einen neuen Absatz zu beginnen.
- **Breitenloser bedingter Umbruch** ist eine Stelle, an der eine Zeile umbrechen darf, ohne dass ein Zeichen sichtbar wird.
- **Breitenloser geschützter Umbruch** ist ein unsichtbares Zeichen, das verhindert, dass die beiden Seiten getrennt in zwei Zeilen stehen.

Schalten Sie **Start > Alle anzeigen** ein, um die Markierungen für diese Zeichen in Ihrem Text zu sehen.

## Eine leere Seite

**Einfügen > Leere Seite** setzt an die Stelle der Einfügemarke eine komplett leere Seite. Der Text davor bleibt auf seiner Seite, und der Text danach rückt auf die Seite nach der leeren Seite. Mit **Rückgängig** wird sie in einem Schritt wieder entfernt.

## Ein Deckblatt

**Einfügen > Deckblatt** setzt ein Deckblatt auf eine eigene Seite vor Ihren Text. Wählen Sie einen Entwurf: **Klassisch**, **Band** oder **Schlicht**. Klicken Sie auf jede Zeile (den Titel, den Untertitel, den Autor und das Datum) und überschreiben Sie sie. Ein Dokument hat ein Deckblatt: Wenn Sie einen anderen Entwurf wählen, ersetzt er das erste. Mit **Aktuelles Deckblatt entfernen** wird es entfernt. Mit **Rückgängig** kommt es zurück.

## Datum und Uhrzeit

**Einfügen > Datum und Uhrzeit** zeigt verschiedene Schreibweisen für das heutige Datum und die Uhrzeit. Wählen Sie eine aus. Ist **Automatisch aktualisieren** aktiviert, wird sie als Feld eingefügt, das bei jedem Drücken von F9 und beim Öffnen des Dokuments das aktuelle Datum anzeigt. Ist das Kontrollkästchen deaktiviert, wird die Angabe als normaler Text eingefügt, der unverändert bleibt.
