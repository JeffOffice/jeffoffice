# Sonderzeichen und Symbole einfügen

Ein **Symbol** ist ein Zeichen, das nicht auf Ihrer Tastatur liegt, zum Beispiel der griechische Buchstabe Omega oder ein Pfeil. Ein **Sonderzeichen** ist ein Zeichen, das die Seite auf eine bestimmte Weise behandelt, zum Beispiel ein Leerzeichen, das nie über zwei Zeilen getrennt wird.

## Symbole

1. Setzen Sie die Einfügemarke an die Stelle, an die das Symbol soll.
2. Wählen Sie **Einfügen > Symbol**. Ein kleines Feld zeigt die Symbole, die Sie zuletzt verwendet haben. Klicken Sie auf eines, um es einzufügen.
3. Für jedes andere Symbol wählen Sie **Weitere Sonderzeichen**. Wählen Sie eine **Schriftart** und einen **Subset** (einen Block zusammengehöriger Zeichen, z. B. Pfeile). Doppelklicken Sie auf ein Symbol, oder klicken Sie es an und wählen Sie **Einfügen**.

Das Fenster bleibt geöffnet, sodass Sie mehrere Symbole einfügen können. Das Feld zeigt den **Zeichencode** des Symbols, auf das Sie klicken. Das Symbol wird in der Schriftart eingefügt, die Sie wählen. Die Auswahl **(normaler Text)** behält die eigene Schriftart des Textes bei.

## Sonderzeichen

Wählen Sie **Einfügen > Sonderzeichen** und dann eines der folgenden Zeichen.

- **Geschütztes Leerzeichen** (Strg+Umschalt+Leertaste) ist ein Leerzeichen, das zwei Wörter in derselben Zeile hält.
- **Geschützter Bindestrich** (Strg+Umschalt+Minus) ist ein Bindestrich, an dem ein Wort nie getrennt wird.
- **Bedingter Trennstrich** (Strg+Minus) ist ein Bindestrich, der nur dann erscheint, wenn das Wort am Zeilenende an dieser Stelle getrennt wird.
- **Halbgeviertstrich** und **Geviertstrich** sind Gedankenstriche. Ein Halbgeviertstrich ist so breit wie der Buchstabe n. Ein Geviertstrich ist so breit wie der Buchstabe m.
- **Halbgeviertabstand** und **Geviertabstand** sind Leerzeichen in der Breite dieser Buchstaben.
- Die vier **Anführungszeichen** sind die typografischen Zeichen, öffnend und schließend, doppelt und einfach.
- **Zeilenumbruch** (Umschalt+Eingabe) beginnt eine neue Zeile, ohne einen neuen Absatz zu beginnen.
- **Bedingter Umbruch ohne Breite** ist eine Stelle, an der eine Zeile umbrechen darf, ohne dass etwas sichtbar ist.
- **Geschützter Umbruch ohne Breite** ist ein unsichtbares Zeichen, das die beiden Seiten in derselben Zeile hält.

Schalten Sie **Start > Alle anzeigen ¶** ein, um die Markierungen dieser Zeichen in Ihrem Text zu sehen.

## Eine leere Seite

**Einfügen > Leere Seite** fügt an der Einfügemarke eine ganz leere Seite ein. Der Text vor der Stelle bleibt auf seiner Seite, und der Text danach rückt auf die Seite nach der leeren. Mit **Rückgängig** entfernen Sie sie in einem Schritt.

## Ein Deckblatt

**Einfügen > Deckblatt** setzt vor Ihren Text ein Deckblatt auf eine eigene Seite. Wählen Sie ein Design: **Klassisch**, **Band** oder **Schlicht**. Klicken Sie auf jede Zeile (Titel, Untertitel, Autor und Datum) und überschreiben Sie sie. Ein Dokument hat nur ein Deckblatt: Wenn Sie ein anderes Design wählen, ersetzt es das erste. **Aktuelle Titelseite entfernen** nimmt es wieder weg. Mit **Rückgängig** holen Sie es zurück.

## Datum und Uhrzeit

**Einfügen > Datum und Uhrzeit** listet Arten auf, das heutige Datum und die Uhrzeit zu schreiben. Wählen Sie eine aus. Ist **Automatisch aktualisieren** aktiviert, wird sie als Feld eingefügt, das bei jedem Drücken von F9 und beim Öffnen des Dokuments das neue Datum anzeigt. Ist die Option ausgeschaltet, wird sie als normaler Text eingefügt, der so bleibt, wie er ist.

## Initiale

Eine Initiale ist ein großer Anfangsbuchstabe, der in die Zeilen daneben hineinragt, wie am Anfang eines Artikels.

1. Klicken Sie in den Absatz.
2. Wählen Sie **Einfügen > Initiale > Im Text**. Der erste Buchstabe reicht über drei Zeilen.
3. Für andere Optionen wählen Sie **Initialoptionen**. **Zeilen für Initiale** gibt an, wie viele Zeilen hoch der Buchstabe ist. **Buchstaben** gibt an, wie viele der ersten Buchstaben groß sind. Für sie können Sie eine eigene **Schriftart** wählen.

**Keine Initiale** entfernt die Initiale. Auch **Rückgängig** entfernt sie. Ein Absatz in einer Liste oder einer Tabelle oder ein Absatz, der mit einem Leerzeichen beginnt, kann keine Initiale haben. Beim Speichern werden die großen Buchstaben in einen eigenen kleinen Absatz gesetzt, der als Initiale formatiert ist und vor dem restlichen Text steht. So speichern andere Programme sie ebenfalls.
