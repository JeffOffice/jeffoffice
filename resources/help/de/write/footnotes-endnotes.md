# Fußnoten und Endnoten
<!-- keywords: Fußnote, Endnote, Anmerkung, Notiz, Verweis, Fußnotenzeichen, Zitat, Quellenangabe, Quelle, Fußnote einfügen, Endnote einfügen, Registerkarte Verweise, Nummer, Nummerierung, Seitenende, Dokumentende, Beschriftung, Strg+Alt+F, Strg+Alt+D -->

Eine **Anmerkung** gibt dem Leser zusätzliche Informationen zu einigen Wörtern, ohne den Satz zu unterbrechen. Eine kleine hochgestellte Zahl im Text, das **Notenzeichen**, verweist auf die zugehörige Anmerkung. Eine **Fußnote** steht unten auf der Seite, auf der sich ihr Notenzeichen befindet. Eine **Endnote** steht nach dem letzten Text des Dokuments oder am Ende eines Abschnitts, wenn die Datei dies vorsieht.

## Fußnote hinzufügen

1. Klicken Sie an die Stelle, an der das Notenzeichen stehen soll, direkt hinter die Wörter, auf die sich die Anmerkung bezieht.
2. Klicken Sie auf **Verweise > Fußnote einfügen**, oder drücken Sie **Strg+Alt+F**.

JeffWrite fügt das Notenzeichen in den Text und eine neue Anmerkung mit derselben Nummer am Seitenende ein. Die Einfügemarke springt in die Anmerkung, sodass Sie sofort schreiben können.

Anmerkungen werden in der Reihenfolge ihrer Notenzeichen im Text nummeriert. Wenn Sie eine Fußnote vor anderen einfügen, erhöht sich die Nummer jeder folgenden Anmerkung um eins, und auch das Notenzeichen im Text zeigt die neue Nummer an.

## Endnote hinzufügen

Klicken Sie an die Stelle, an der das Notenzeichen stehen soll, und klicken Sie dann auf **Verweise > Endnote einfügen**, oder drücken Sie **Strg+Alt+D**. JeffWrite fügt das Notenzeichen in den Text und eine neue Endnote mit ihrer Nummer nach dem letzten Text ein, und die Einfügemarke springt hinein. Endnoten haben eine eigene Nummerierung im Format, das die Datei vorgibt.

## Anmerkung bearbeiten

Klicken Sie in den Text einer Anmerkung am Seitenende oder, bei einer Endnote, nach dem letzten Text. Die Einfügemarke wird dorthin gesetzt. Sie können wie im übrigen Text schreiben, markieren, ausschneiden, kopieren, einfügen und die Formatierung ändern sowie eine Formatvorlage für den Absatz wählen: Der Absatz bleibt Teil der Anmerkung. Eine Anmerkung kann mehrere Absätze haben.

Zwei Teile einer Anmerkung sind kein Text und lassen sich nicht bearbeiten: die Nummer am Anfang der Anmerkung und die kurze Linie über den Anmerkungen. Wenn Sie direkt hinter der Nummer die **Rücktaste** drücken, geschieht nichts. Eine Markierung, die von einer Anmerkung in eine andere reichen würde, endet am Ende der Anmerkung, in der Sie begonnen haben.

Um eine Anmerkung zu verlassen, drücken Sie **Esc**, drücken Sie in der ersten Zeile **Nach-oben** bzw. in der letzten Zeile **Nach-unten**, oder klicken Sie in den Text der Seite. Die Einfügemarke kehrt in den Text zurück, direkt hinter das Notenzeichen der Anmerkung. Eine lange Anmerkung kann am Ende der nächsten Seite fortgesetzt werden; die Pfeiltasten gehen von einem Teil zum nächsten, und die Anmerkung wird nur in ihrer allerersten und allerletzten Zeile verlassen. Eine Anmerkung mit zwei Notenzeichen steht auf beiden Seiten, und Sie bearbeiten sie auf der Seite, auf die Sie geklickt haben.

## Anmerkung entfernen oder verschieben

- Wenn Sie ein Notenzeichen löschen, wird auch die zugehörige Anmerkung gelöscht. Die folgenden Anmerkungen werden neu nummeriert. **Rückgängig** stellt beides wieder her.
- Wenn Sie ein Notenzeichen ausschneiden und an anderer Stelle einfügen, wird die Anmerkung mit verschoben.
- Wenn Sie ein Notenzeichen kopieren und einfügen, erhalten Sie eine zweite Anmerkung mit demselben Text, die Sie unabhängig ändern können.
- Manche Dateien enthalten zwei Notenzeichen für eine Anmerkung. Wenn Sie eines löschen, bleibt die Anmerkung erhalten. Wenn Sie das letzte löschen, wird die Anmerkung entfernt.

## Was JeffWrite beibehält

- Teile der Datei, die Sie nicht geändert haben, werden genau so gespeichert, wie sie waren. Wenn Sie eine Anmerkung ändern, werden nur die geänderten Anmerkungen neu geschrieben, und alles darin, was JeffWrite nicht bearbeiten kann (ein Bild, eine Textmarke, ein Link, ein Feld), bleibt an seiner Stelle.
- Die Linie über den Anmerkungen und die Linie über einer Anmerkung, die von der vorherigen Seite fortgesetzt wird, bleiben so erhalten, wie die Datei sie enthält.
- Enthält die Datei noch keine Anmerkungen, fügt die erste neue Anmerkung auch alles hinzu, was ein Anmerkungsteil benötigt, damit andere Programme die Datei ohne Meldung öffnen.
- Eine Anmerkung bleibt in der Datei, solange etwas auf sie verweist: der Text, eine Kopf- oder Fußzeile, ein Textfeld oder eine andere Anmerkung. Wenn der letzte Verweis entfällt, wird die Anmerkung entfernt.
- Ein Dokument kann bis zu 5.000 Anmerkungen jeder Art enthalten, auf die der Text verweist. Ist diese Zahl erreicht, sind **Fußnote einfügen** und **Endnote einfügen** deaktiviert, und die Statusleiste nennt den Grund. Anmerkungen, die Sie einfügen und dann rückgängig machen, zählen nicht.
- **Suchen und Ersetzen** und der Bereich **Rechtschreibung** (F7) durchsuchen den Text des Dokuments, nicht die Anmerkungen.

## Rückgängig

**Rückgängig** (Strg+Z) nimmt die letzte Änderung zurück, wo auch immer sie war: im Text, in einer Kopf- oder Fußzeile oder in einer Anmerkung. War sie in einer Fußnote, setzt JeffWrite die Einfügemarke dorthin, um sie Ihnen zu zeigen. **Wiederholen** führt sie erneut aus.
