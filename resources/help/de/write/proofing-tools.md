Diese Werkzeuge finden Sie auf der Registerkarte **Überprüfen**.

## Wörter zählen

1. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Wörter zählen**.
2. Das Feld zeigt die Seiten, Wörter, Zeichen ohne Leerzeichen, Zeichen mit Leerzeichen und Absätze an.

Wenn Sie zuerst einen Text markieren, zählt das Feld nur diesen Text. Die Statusleiste am unteren Rand des Fensters zeigt dann ebenfalls an, wie viele Wörter markiert sind, zum Beispiel „12 von 340 Wörtern“.

Aktivieren Sie **Fußnoten und Endnoten einbeziehen**, um sie ebenfalls mitzuzählen. Ausgeblendeter Text wird nie gezählt. Text, den eine nachverfolgte Änderung gelöscht hat, wird ebenfalls nicht gezählt.

## Sprache von Text festlegen

JeffWrite prüft die Rechtschreibung mit dem Wörterbuch der Sprache, in der der Text geschrieben ist. Wenn Sie ein französisches Zitat als Französisch markieren, werden seine Wörter auf Französisch geprüft.

1. Markieren Sie den Text.
2. Klicken Sie in der Gruppe **Sprache** auf **Sprache der Dokumentprüfung festlegen**. Sie können auch auf den Namen der Sprache in der Statusleiste klicken.
3. Wählen Sie eine Sprache aus, und klicken Sie auf **OK**.

Die Sprache wird in der Datei gespeichert, sodass auch andere Programme sie kennen. Die Statusleiste zeigt die Sprache des Texts an der Einfügemarke an.

## Bestimmten Text nicht prüfen

Manche Texte sollen nicht geprüft werden, etwa ein Code, ein Name oder eine Zeile in einer erfundenen Sprache. Markieren Sie einen solchen Text, und klicken Sie in der Gruppe **Sprache** auf **Rechtschreibung nicht prüfen**. Die roten Wellenlinien verschwinden. Klicken Sie erneut darauf, um den Text wieder zu prüfen.

## Ein Wort im Thesaurus nachschlagen

Ein Thesaurus enthält Wörter, die fast dasselbe bedeuten.

1. Klicken Sie auf ein Wort, oder markieren Sie es.
2. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Thesaurus**, oder drücken Sie **Umschalt+F7**.
3. Wählen Sie in der Liste ein Wort aus, und klicken Sie auf **Ersetzen**. Um stattdessen eines der Wörter nachzuschlagen, klicken Sie auf **Nachschlagen**. Sie können auch ein anderes Wort in das Feld eingeben und **Eingabe** drücken.

Die Liste stammt aus einer Datei auf Ihrem Computer. Es wird keine Internetverbindung benötigt.

## Text übersetzen

1. Markieren Sie den Text. Ist nichts markiert, wird das gesamte Dokument verwendet.
2. Klicken Sie in der Gruppe **Sprache** auf **Übersetzen**.
3. Wählen Sie die Sprache aus, in die übersetzt werden soll.
4. Klicken Sie auf **OK**.

Ihr Webbrowser öffnet dann einen Übersetzungsdienst namens LibreTranslate, in dem Ihr Text bereits eingefügt ist. Erst wenn Sie auf **OK** klicken, wird etwas gesendet. Im Feld können Sie die Adresse des Dienstes ändern, zum Beispiel auf einen Dienst, den Sie selbst betreiben. Es werden nur Webadressen (http oder https) verwendet. Es werden höchstens 5.000 Buchstaben gesendet.

## Barrierefreiheit prüfen

Manche Menschen lesen mit einem Bildschirmleser, der das Dokument laut vorliest. Andere können blassen Text schlecht sehen. Die Prüfung auf Barrierefreiheit findet, was ein Dokument für sie schwer lesbar macht.

1. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Barrierefreiheit prüfen**.
2. Rechts öffnet sich eine Liste. Jede Zeile beschreibt ein Problem. Klicken Sie auf eine Zeile, um zu der Stelle zu springen.
3. Beheben Sie das Problem, und klicken Sie auf **Erneut prüfen**.

Die Prüfung sucht nach folgenden Punkten:

- **Ein Bild ohne Alternativtext.** Der Alternativtext ist eine kurze Beschreibung des Bilds. Um ihn hinzuzufügen, klicken Sie das Bild mit der rechten Maustaste an und wählen **Alternativtext…**.
- **Eine Tabelle ohne Kopfzeile.** Die Kopfzeile enthält die Namen der Spalten.
- **Eine leere Tabellenzelle.**
- **Eine Überschrift, die eine Ebene überspringt**, zum Beispiel Überschrift 3 direkt nach Überschrift 1.
- **Schwer lesbarer Text**, weil seine Farbe der Farbe dahinter zu ähnlich ist.
- **Ein Bild, das frei auf der Seite schwebt**, statt mit dem Text in einer Zeile zu stehen.
- **Eine Tabelle mit verbundenen Zellen.** Eine verbundene Zelle ist eine einzelne Zelle, die zwei oder mehr Spalten oder Zeilen überdeckt. Ein Bildschirmleser kann in einer solchen Tabelle die Orientierung verlieren. Dieser Hinweis erscheint einmal für jede Tabelle.
- **Ein Link, dessen Text nichts über das Ziel aussagt**, etwa „hier klicken“ oder „weiterlesen“, oder eine Webadresse, die so angezeigt wird, wie sie ist. Wer sich auf einer Seite die Linkliste vorlesen lässt, braucht Wörter, die die Seite benennen.

Sie können die Prüfung auch über **Datei > Info** starten: Klicken Sie dort auf **Barrierefreiheit prüfen**.
