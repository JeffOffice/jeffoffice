# Wörter zählen, prüfen und Wörter nachschlagen

Diese Werkzeuge finden Sie auf der Registerkarte **Überprüfen**.

## Wörter zählen

1. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Wortanzahl**.
2. Das Feld zeigt die Seiten, Wörter, Zeichen ohne Leerzeichen, Zeichen mit Leerzeichen und Absätze an.

Wenn Sie vorher Text markieren, zählt das Feld nur diesen Text. Die Statusleiste unten im Fenster zeigt ihn ebenfalls an, zum Beispiel als „12 von 340 Wörtern“.

Aktivieren Sie **Fußnoten und Endnoten einbeziehen**, um sie ebenfalls zu zählen. Ausgeblendeter Text wird nie gezählt. Ebenso wenig wird Text gezählt, den eine nachverfolgte Änderung gelöscht hat.

## Sprache von Text festlegen

JeffWrite prüft die Rechtschreibung mit dem Wörterbuch der Sprache, in der der Text steht. Markieren Sie ein französisches Zitat als Französisch, dann werden seine Wörter auf Französisch geprüft.

1. Markieren Sie den Text.
2. Klicken Sie in der Gruppe **Sprache** auf **Dokumentprüfungssprache festlegen**. Sie können auch auf den Sprachnamen in der Statusleiste klicken.
3. Wählen Sie eine Sprache aus, und klicken Sie auf **OK**.

Die Sprache wird in der Datei gespeichert, sodass auch andere Programme sie kennen. Die Statusleiste zeigt die Sprache des Textes an der Einfügemarke an.

## Bestimmten Text nicht prüfen

Manche Texte sollen nicht geprüft werden, etwa Code, ein Name oder eine Zeile in einer erfundenen Sprache. Markieren Sie ihn, und klicken Sie in der Gruppe **Sprache** auf **Rechtschreibung nicht prüfen**. Die roten Wellenlinien verschwinden. Klicken Sie erneut darauf, um den Text wieder zu prüfen.

## Ein Wort im Thesaurus nachschlagen

Ein Thesaurus listet Wörter auf, die nahezu dasselbe bedeuten.

1. Klicken Sie auf ein Wort, oder markieren Sie es.
2. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Thesaurus**, oder drücken Sie **Umschalt+F7**.
3. Wählen Sie in der Liste ein Wort aus, und klicken Sie auf **Ersetzen**. Um stattdessen eines der Wörter nachzuschlagen, klicken Sie auf **Nachschlagen**. Sie können auch ein anderes Wort in das Feld eintippen und **Eingabe** drücken.

Die Liste stammt aus einer Datei auf Ihrem Computer. Es wird keine Internetverbindung benötigt.

## Text übersetzen

Markieren Sie Text, und klicken Sie in der Gruppe **Sprache** auf **Übersetzen**. Der Bereich „Übersetzen“ rechts übersetzt ihn auf Ihrem Computer und kann den Text ersetzen oder die Übersetzung darunter einfügen. Siehe [Text übersetzen](translate).

## Barrierefreiheit prüfen

Manche Menschen lesen mit einem Bildschirmleser, der das Dokument vorliest. Andere haben Mühe, blassen Text zu erkennen. Die Barrierefreiheitsprüfung findet, was ein Dokument für sie schwer lesbar macht.

1. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Barrierefreiheit prüfen**.
2. Rechts öffnet sich eine Liste. Jede Zeile beschreibt ein Problem. Klicken Sie auf eine Zeile, um zur Stelle zu springen.
3. Beheben Sie das Problem. Klicken Sie auf **Erneut prüfen**.

Die Prüfung sucht nach Folgendem:

- **Ein Bild ohne Alternativtext.** Der Alternativtext ist eine kurze Beschreibung des Bildes. Um ihn hinzuzufügen, klicken Sie mit der rechten Maustaste auf das Bild und wählen Sie den Alternativtext aus.
- **Eine Tabelle ohne Kopfzeile.** Die Kopfzeile enthält die Namen der Spalten.
- **Eine leere Tabellenzelle.**
- **Eine Überschrift, die eine Ebene überspringt**, etwa Überschrift 3 direkt nach Überschrift 1.
- **Text, der schwer lesbar ist**, weil seine Farbe der Hintergrundfarbe zu ähnlich ist.
- **Ein Bild, das frei auf der Seite schwebt**, statt mit dem Text in einer Zeile zu stehen.
- **Eine Tabelle mit verbundenen Zellen.** Eine verbundene Zelle ist eine einzelne Zelle, die zwei oder mehr Spalten oder Zeilen umfasst. Ein Bildschirmleser kann in einer solchen Tabelle die Orientierung verlieren. Dieser Hinweis erscheint einmal für jede Tabelle.
- **Ein Link, dessen Wortlaut nichts über das Ziel aussagt**, etwa „Hier klicken“ oder „Weiterlesen“, oder eine Webadresse in der Form, wie sie angezeigt wird. Wer sich die Linkliste einer Seite vorlesen lässt, braucht Wörter, die die Seite benennen.

Sie können die Prüfung auch über **Datei > Info** starten: Klicken Sie dort auf **Barrierefreiheit prüfen**.
