# Wörter zählen, prüfen und Wörter nachschlagen

Diese Werkzeuge finden Sie auf der Registerkarte **Überprüfen**.

## Wörter zählen

1. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Wörter zählen**.
2. Das Feld zeigt die Seiten, Wörter, Zeichen ohne Leerzeichen, Zeichen mit Leerzeichen und Absätze an.

Wenn Sie vorher einen Text markieren, zählt das Feld nur diesen Text. Die Statusleiste am unteren Rand des Fensters zeigt das ebenfalls an, zum Beispiel als „12 von 340 Wörtern“.

Aktivieren Sie **Fußnoten und Endnoten einbeziehen**, um sie mitzuzählen. Ausgeblendeter Text wird nie gezählt. Ebenso wenig wird Text gezählt, den eine nachverfolgte Änderung gelöscht hat.

## Sprache eines Textes festlegen

JeffWrite prüft die Rechtschreibung mit dem Wörterbuch der Sprache, in der der Text geschrieben ist. Wenn Sie ein französisches Zitat als Französisch kennzeichnen, werden seine Wörter auf Französisch geprüft.

1. Markieren Sie den Text.
2. Klicken Sie in der Gruppe **Sprache** auf **Dokumentprüfungssprache festlegen**. Sie können auch auf den Sprachnamen in der Statusleiste klicken.
3. Wählen Sie eine Sprache aus, und klicken Sie auf **OK**.

Die Sprache wird in der Datei gespeichert, damit auch andere Programme sie kennen. Die Statusleiste zeigt die Sprache des Textes an der Einfügemarke an.

## Einen Text nicht prüfen

Manche Texte sollen nicht geprüft werden, etwa ein Code, ein Name oder eine Zeile in einer erfundenen Sprache. Markieren Sie einen solchen Text, und klicken Sie in der Gruppe **Sprache** auf **Rechtschreibung nicht prüfen**. Die roten Wellenlinien verschwinden. Klicken Sie erneut darauf, um den Text wieder zu prüfen.

## Ein Wort im Thesaurus nachschlagen

Ein Thesaurus enthält Wörter mit nahezu gleicher Bedeutung.

1. Klicken Sie auf ein Wort, oder markieren Sie es.
2. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Thesaurus**, oder drücken Sie **Umschalt+F7**.
3. Wählen Sie in der Liste ein Wort aus, und klicken Sie auf **Ersetzen**. Um eines der Wörter stattdessen nachzuschlagen, klicken Sie auf **Nachschlagen**. Sie können auch ein anderes Wort in das Feld eingeben und **Eingabe** drücken.

Die Liste stammt aus einer Datei auf Ihrem Computer. Es wird keine Internetverbindung benötigt.

## Text übersetzen

1. Markieren Sie den Text. Ist nichts markiert, wird das gesamte Dokument verwendet.
2. Klicken Sie in der Gruppe **Sprache** auf **Übersetzen**.
3. Wählen Sie die Sprache aus, in die übersetzt werden soll.
4. Klicken Sie auf **OK**.

Ihr Webbrowser öffnet dann einen Übersetzungsdienst namens LibreTranslate, in dem Ihr Text bereits eingefügt ist. Gesendet wird erst, wenn Sie auf **OK** klicken. Sie können die Adresse des Dienstes im Feld ändern, zum Beispiel auf einen Dienst, den Sie selbst betreiben. Es werden nur Webadressen (http oder https) verwendet. Es werden höchstens 5.000 Buchstaben gesendet.

## Barrierefreiheit prüfen

Manche Menschen lesen mit einem Bildschirmleser, der das Dokument vorliest. Andere haben Mühe, blasse Schrift zu erkennen. Die Prüfung auf Barrierefreiheit findet, was ein Dokument für sie schwer lesbar macht.

1. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Barrierefreiheit prüfen**.
2. Rechts öffnet sich eine Liste. Jede Zeile beschreibt ein Problem. Klicken Sie auf eine Zeile, um zur Stelle zu springen.
3. Beheben Sie das Problem. Klicken Sie dann auf **Erneut prüfen**.

Die Prüfung sucht nach Folgendem:

- **Ein Bild ohne Alternativtext.** Der Alternativtext ist eine kurze Beschreibung des Bildes. Um ihn hinzuzufügen, klicken Sie mit der rechten Maustaste auf das Bild und wählen Sie den Alternativtext aus.
- **Eine Tabelle ohne Kopfzeile.** Die Kopfzeile enthält die Namen der Spalten.
- **Eine leere Tabellenzelle.**
- **Eine Überschrift, die eine Ebene überspringt**, etwa Überschrift 3 direkt nach Überschrift 1.
- **Text, der schwer lesbar ist**, weil seine Farbe der Farbe dahinter zu ähnlich ist.
- **Ein Bild, das frei auf der Seite schwebt**, statt mit dem Text in einer Zeile zu stehen.

Der Text von Links wird noch nicht geprüft.
