# Wörter zählen, prüfen und nachschlagen

Diese Werkzeuge finden Sie auf der Registerkarte **Überprüfen**.

## Wörter zählen

1. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Wortanzahl**.
2. Das Feld zeigt die Seiten, Wörter, Zeichen ohne Leerzeichen, Zeichen mit Leerzeichen und Absätze an.

Wenn Sie vorher einen Text markieren, zählt das Feld nur diesen Text. Die Statusleiste unten im Fenster zeigt das ebenfalls an, zum Beispiel als „12 von 340 Wörtern“.

Aktivieren Sie **Fußnoten und Endnoten einbeziehen**, um sie mitzuzählen. Aktivieren Sie **Textfelder einschließen**, um die Wörter in Textfeldern und Formen zu zählen (es wird das gesamte Dokument gezählt, nicht nur eine Auswahl). Ein Textfeld innerhalb eines anderen Textfelds wird ebenfalls gezählt, und ebenso ein Textfeld in einer Fußnote oder Endnote, wenn **Fußnoten und Endnoten einbeziehen** aktiviert ist. Textfelder in Kopf- und Fußzeilen werden nicht gezählt. Ausgeblendeter Text wird nie gezählt. Auch Text, der durch eine nachverfolgte Änderung gelöscht wurde, wird nicht gezählt.

## Sprache eines Textes festlegen

JeffWrite prüft die Rechtschreibung mit dem Wörterbuch der Sprache, in der der Text geschrieben ist. Wenn Sie ein Zitat auf Französisch als französisch markieren, werden seine Wörter auf Französisch geprüft.

1. Markieren Sie den Text.
2. Klicken Sie in der Gruppe **Sprache** auf **Dokumentprüfungssprache festlegen**. Sie können auch in der Statusleiste auf den Namen der Sprache klicken.
3. Wählen Sie eine Sprache aus, und klicken Sie auf **OK**.

Die Sprache wird in der Datei gespeichert, sodass auch andere Programme sie kennen. Die Statusleiste zeigt die Sprache des Textes an der Einfügemarke an.

## Einen Text nicht prüfen

Manche Texte sollen nicht geprüft werden, etwa ein Code, ein Name oder eine Zeile in einer erfundenen Sprache. Markieren Sie einen solchen Text, und klicken Sie in der Gruppe **Sprache** auf **Rechtschreibung nicht prüfen**. Die roten Wellenlinien verschwinden. Klicken Sie erneut darauf, um den Text wieder zu prüfen.

## Ein Wort im Thesaurus nachschlagen

Ein Thesaurus enthält Wörter mit nahezu gleicher Bedeutung.

1. Klicken Sie auf ein Wort, oder markieren Sie es.
2. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Thesaurus**, oder drücken Sie **Umschalt+F7**.
3. Wählen Sie in der Liste ein Wort aus, und klicken Sie auf **Ersetzen**. Um stattdessen eines der Wörter nachzuschlagen, klicken Sie auf **Nachschlagen**. Sie können auch ein anderes Wort in das Feld eingeben und **Eingabe** drücken.

Die Liste stammt aus einer Datei auf Ihrem Computer. Es wird keine Internetverbindung benötigt.

## Text übersetzen

Markieren Sie einen Text, und klicken Sie in der Gruppe **Sprache** auf **Übersetzen**. Der Bereich „Übersetzen“ rechts übersetzt den Text auf Ihrem Computer und kann den Text ersetzen oder die Übersetzung darunter einfügen. Siehe [Text übersetzen](translate).

## Barrierefreiheit prüfen

Manche Menschen lesen mit einem Bildschirmleseprogramm, das das Dokument vorliest. Manche haben Mühe, blasse Schrift zu erkennen. Die Prüfung auf Barrierefreiheit findet, was ein Dokument für sie schwer lesbar macht.

1. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Barrierefreiheit prüfen**.
2. Rechts öffnet sich eine Liste. Jede Zeile beschreibt ein Problem. Klicken Sie auf eine Zeile, um zur Stelle zu springen.
3. Beheben Sie das Problem. Klicken Sie anschließend auf **Erneut prüfen**.

Die Prüfung sucht nach Folgendem:

- **Ein Bild ohne Alternativtext.** Der Alternativtext ist eine kurze Beschreibung eines Bildes. Um ihn hinzuzufügen, klicken Sie das Bild mit der rechten Maustaste an und wählen Sie Alternativtext.
- **Eine Tabelle ohne Kopfzeile.** Die Kopfzeile enthält die Namen der Spalten.
- **Eine leere Tabellenzelle.**
- **Eine Überschrift, die eine Ebene überspringt**, etwa Überschrift 3 direkt nach Überschrift 1.
- **Text, der schwer lesbar ist**, weil seine Farbe der Hintergrundfarbe zu ähnlich ist.
- **Ein Bild, das frei auf der Seite schwebt**, statt mit dem Text in einer Zeile zu stehen.
- **Eine Tabelle mit verbundenen Zellen.** Eine verbundene Zelle ist eine einzelne Zelle, die zwei oder mehr Spalten oder Zeilen überdeckt. Ein Bildschirmleseprogramm kann in einer solchen Tabelle die Orientierung verlieren. Dieser Hinweis erscheint einmal für jede Tabelle.
- **Ein Link, dessen Wortlaut nichts über das Ziel aussagt**, etwa „hier klicken“ oder „weiterlesen“, oder eine als Webadresse angezeigte Adresse. Wer sich die Linkliste einer Seite vorlesen lässt, braucht Wörter, die die Seite benennen.

Sie können die Prüfung auch über **Datei > Info** starten: Klicken Sie dort auf **Barrierefreiheit prüfen**.
