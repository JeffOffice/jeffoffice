Diese Werkzeuge finden Sie auf der Registerkarte **Überprüfen**.

## Wörter zählen

1. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Wörter zählen**.
2. Das Feld zeigt die Seiten, Wörter, Zeichen ohne Leerzeichen, Zeichen mit Leerzeichen und Absätze an.

Wenn Sie vorher einen Text markieren, zählt das Feld nur diesen Text. Die Statusleiste unten im Fenster zeigt ihn ebenfalls an, zum Beispiel als „12 von 340 Wörtern“.

Aktivieren Sie **Fußnoten und Endnoten einbeziehen**, um sie mitzuzählen. Ausgeblendeter Text wird nie mitgezählt. Auch Text, den eine nachverfolgte Änderung gelöscht hat, wird nicht mitgezählt.

## Sprache eines Textes festlegen

JeffWrite prüft die Rechtschreibung mit dem Wörterbuch der Sprache, in der der Text steht. Wenn Sie ein französisches Zitat als Französisch markieren, werden seine Wörter auf Französisch geprüft.

1. Markieren Sie den Text.
2. Klicken Sie in der Gruppe **Sprache** auf **Sprache für Dokumentprüfung festlegen**. Sie können auch in der Statusleiste auf den Namen der Sprache klicken.
3. Wählen Sie eine Sprache aus, und klicken Sie auf **OK**.

Die Sprache wird in der Datei gespeichert, damit andere Programme sie ebenfalls kennen. Die Statusleiste zeigt die Sprache des Textes an der Einfügemarke an.

## Einen Text nicht prüfen

Manche Texte sollen nicht geprüft werden, zum Beispiel ein Code, ein Name oder eine Zeile in einer erfundenen Sprache. Markieren Sie einen solchen Text, und klicken Sie in der Gruppe **Sprache** auf **Rechtschreibung nicht prüfen**. Die roten Wellenlinien verschwinden. Klicken Sie erneut darauf, um den Text wieder zu prüfen.

## Ein Wort im Thesaurus nachschlagen

Ein Thesaurus listet Wörter auf, die fast dasselbe bedeuten.

1. Klicken Sie auf ein Wort, oder markieren Sie es.
2. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Thesaurus**, oder drücken Sie **Umschalt+F7**.
3. Wählen Sie in der Liste ein Wort aus, und klicken Sie auf **Ersetzen**. Um stattdessen eines der Wörter nachzuschlagen, klicken Sie auf **Nachschlagen**. Sie können auch ein anderes Wort in das Feld eingeben und die **Eingabetaste** drücken.

Die Liste stammt aus einer Datei auf Ihrem Computer. Es wird keine Internetverbindung benutzt.

## Text übersetzen

1. Markieren Sie den Text. Ist nichts markiert, wird das ganze Dokument verwendet.
2. Klicken Sie in der Gruppe **Sprache** auf **Übersetzen**.
3. Wählen Sie die Sprache aus, in die übersetzt werden soll.
4. Klicken Sie auf **OK**.

Ihr Webbrowser öffnet dann einen Übersetzungsdienst namens LibreTranslate, in dem Ihr Text bereits steht. Gesendet wird erst, wenn Sie auf **OK** klicken. Sie können die Adresse des Dienstes im Feld ändern, zum Beispiel auf einen Dienst, den Sie selbst betreiben. Es werden nur Webadressen (http oder https) verwendet. Es werden höchstens 5.000 Buchstaben gesendet.

## Barrierefreiheit prüfen

Manche Menschen lesen mit einem Bildschirmleser, der das Dokument vorliest. Andere können blasse Schrift schlecht erkennen. Die Prüfung auf Barrierefreiheit findet, was ein Dokument für sie schwer lesbar macht.

1. Klicken Sie in der Gruppe **Dokumentprüfung** auf **Barrierefreiheit prüfen**.
2. Rechts öffnet sich eine Liste. Jede Zeile beschreibt ein Problem. Klicken Sie auf eine Zeile, um zu der Stelle zu springen.
3. Beheben Sie das Problem. Klicken Sie anschließend auf **Erneut prüfen**.

Die Prüfung sucht nach diesen Punkten:

- **Ein Bild ohne Alternativtext.** Der Alternativtext ist eine kurze Beschreibung des Bildes. Um ihn hinzuzufügen, klicken Sie mit der rechten Maustaste auf das Bild und wählen Sie Alternativtext.
- **Eine Tabelle ohne Kopfzeile.** Die Kopfzeile enthält die Namen der Spalten.
- **Eine leere Tabellenzelle.**
- **Eine Überschrift, die eine Ebene überspringt**, etwa Überschrift 3 direkt nach Überschrift 1.
- **Text, der schwer lesbar ist**, weil seine Farbe der Farbe dahinter zu ähnlich ist.
- **Ein Bild, das auf der Seite schwebt**, statt mit dem Text in einer Zeile zu stehen.
- **Eine Tabelle mit verbundenen Zellen.** Eine verbundene Zelle ist eine einzelne Zelle, die zwei oder mehr Spalten oder Zeilen überdeckt. Ein Bildschirmleser kann in einer solchen Tabelle die Orientierung verlieren. Dieser Hinweis erscheint einmal für jede Tabelle.
- **Ein Link, dessen Wörter nichts über das Ziel sagen**, etwa „hier klicken“ oder „weiterlesen“, oder eine Webadresse, die so angezeigt wird, wie sie ist. Wer sich die Liste der Links auf einer Seite vorlesen lässt, braucht Wörter, die die Seite benennen.

Sie können die Prüfung auch über **Datei > Info** starten: Klicken Sie dort auf **Barrierefreiheit prüfen**.
