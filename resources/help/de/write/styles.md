# Formatvorlagen verwenden
<!-- keywords: Formatvorlagen, Formatvorlage, Vorlage, Stil, Bereich Formatvorlagen, Überschrift, Standard, Formatvorlage erstellen, neue Formatvorlage, Formatvorlage ändern, basiert auf, Formatvorlage für Folgeabsatz, automatisch aktualisieren, Katalog, Zeichenformatvorlage, Absatzformatvorlage, Strg+Alt+Umschalt+S -->

Eine **Formatvorlage** ist eine gespeicherte Zusammenstellung von Formatierungen: Schriftart, Schriftgrad, Abstände und mehr. Wenn Sie einem Absatz eine Formatvorlage zuweisen, übernimmt der Absatz alle diese Formatierungen auf einmal. Wenn Sie die Formatvorlage ändern, ändern sich auch alle Absätze, die sie verwenden. Deshalb sorgen Formatvorlagen in langen Dokumenten für Ordnung.

JeffWrite kennt zwei Arten:

- Eine **Absatzformatvorlage** legt das Aussehen ganzer Absätze fest. **Überschrift 1** und **Standard** sind Absatzformatvorlagen.
- Eine **Zeichenformatvorlage** legt das Aussehen der markierten Wörter fest. **Fett** ist eine Zeichenformatvorlage.

## Text eine Formatvorlage zuweisen

1. Klicken Sie in einen Absatz, oder markieren Sie die Wörter, die Sie ändern möchten.
2. Klicken Sie auf der Registerkarte **Start** im Katalog **Formatvorlagen** auf eine Formatvorlage. Oder drücken Sie **Strg+Umschalt+N** für Standard bzw. **Strg+Alt+1**, **Strg+Alt+2** oder **Strg+Alt+3** für Überschrift 1, 2 oder 3.

Eine Absatzformatvorlage wird jedem Absatz zugewiesen, den die Markierung berührt. Eine Zeichenformatvorlage wird den markierten Wörtern zugewiesen.

## Bereich „Formatvorlagen“ öffnen

Klicken Sie auf den kleinen Pfeil in der Ecke der Gruppe **Formatvorlagen**, oder drücken Sie **Strg+Alt+Umschalt+S**. Rechts wird der Bereich **Formatvorlagen** geöffnet. Er listet die Formatvorlagen Ihres Dokuments auf, jede in ihrem eigenen Aussehen.

- Die Formatvorlage an der Cursorposition ist fett dargestellt, mit einem Pfeil vor ihrem Namen.
- Klicken Sie auf eine Formatvorlage, um sie Ihrer Markierung zuzuweisen.
- In der Liste unter den Formatvorlagen wählen Sie aus, welche angezeigt werden:
  - **In Verwendung** zeigt nur die Formatvorlagen, die Ihr Text verwendet.
  - **Alle Formatvorlagen** zeigt alle Formatvorlagen, auch solche, die Ihr Dokument noch nicht enthält. Eine Formatvorlage wird dem Dokument hinzugefügt, wenn Sie sie zum ersten Mal verwenden.
  - **Empfohlen** zeigt die Formatvorlagen, die sichtbar sein sollen. Eine Formatvorlage, die bis zu ihrer Verwendung ausgeblendet ist, erscheint hier, sobald Sie sie verwenden.

## Formatvorlage aus Ihrem Text erstellen

1. Formatieren Sie einen Absatz so, wie Sie ihn haben möchten. Formatieren Sie ihn zum Beispiel fett, zentrieren Sie ihn, und legen Sie den Schriftgrad fest.
2. Klicken Sie unten im Bereich auf **Neue Formatvorlage** oder auf der Registerkarte **Start** auf **Formatvorlage erstellen**.
3. Geben Sie einen **Namen** ein. Ein Name darf bis zu 255 Zeichen haben und nicht der Name einer anderen Formatvorlage sein.
4. Prüfen Sie die übrigen Optionen, und klicken Sie auf **OK**.

Die neue Formatvorlage wird mit Ihrem Dokument gespeichert, und Ihr Absatz erhält sie. Ein einziges **Rückgängig** (Strg+Z) nimmt die Formatvorlage wieder zurück.

## Formatvorlage ändern

1. Klicken Sie in einen Absatz, der die Formatvorlage hat. Oder klicken Sie im Bereich auf die Formatvorlage.
2. Klicken Sie unten im Bereich auf **Ändern** oder auf der Registerkarte **Start** auf **Formatvorlage ändern**.
3. Ändern Sie, was Sie möchten, und klicken Sie auf **OK**.

Das Dialogfeld bietet diese Optionen:

- **Name** ist der Name der Formatvorlage. Eine mit JeffWrite gelieferte Formatvorlage behält ihren Namen.
- **Basiert auf** ist die Formatvorlage, von der diese ausgeht. Die neue Formatvorlage sieht aus wie diese Formatvorlage, abgesehen von Ihren Änderungen. Wenn Sie die zugrunde liegende Formatvorlage später ändern, übernimmt diese Formatvorlage die Änderung.
- **Formatvorlage für Folgeabsatz** ist die Formatvorlage, die der nächste Absatz erhält, wenn Sie am Ende dieses Absatzes die **Eingabetaste** drücken. Auf eine Überschrift folgt meist Standard.
- **Schriftart**, **Schriftgrad**, **Fett**, **Kursiv**, **Unterstrichen** und **Farbe** legen das Aussehen der Wörter fest.
- **Ausrichtung**, **Einzug**, **Abstand** und **Zeilenabstand** legen das Aussehen der Absätze fest.
- **Zum Formatvorlagenkatalog hinzufügen** nimmt die Formatvorlage in den Katalog auf der Registerkarte **Start** auf.
- **Automatisch aktualisieren** sorgt dafür, dass die Formatvorlage Ihrer Formatierung folgt. Wenn Sie einen Absatz mit dieser Formatvorlage ändern, wird die Formatvorlage entsprechend angepasst, ebenso alle anderen Absätze, die sie haben.

Wenn Sie eine Formatvorlage ändern, ändern sich die Absätze, die sie haben. Wenn Sie einem Absatz eine eigene Formatierung gegeben haben, etwa ein rotes Wort, bleibt diese erhalten.

Wenn Sie auf **OK** klicken, ohne etwas zu ändern, bleibt das Dokument unverändert.

## Formatvorlage an Ihren Text anpassen

Formatieren Sie einen Absatz so, wie Sie es möchten. Klicken Sie dann auf der Registerkarte **Start** auf **Formatvorlage entsprechend Auswahl aktualisieren**. Die Formatvorlage dieses Absatzes übernimmt Ihre Änderungen, und alle Absätze mit dieser Formatvorlage folgen.
