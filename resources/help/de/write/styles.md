# Formatvorlagen verwenden

Eine **Formatvorlage** ist eine gespeicherte Zusammenstellung von Formatierungen: eine Schriftart, eine Schriftgröße, Abstände und mehr. Wenn Sie einem Absatz eine Formatvorlage zuweisen, übernimmt der Absatz alle diese Merkmale auf einmal. Ändern Sie die Formatvorlage, ändern sich alle Absätze, die sie verwenden. Deshalb bleiben lange Dokumente mit Formatvorlagen übersichtlich.

JeffWrite kennt zwei Arten:

- Eine **Absatzformatvorlage** legt das Aussehen ganzer Absätze fest. **Überschrift 1** und **Standard** sind Absatzformatvorlagen.
- Eine **Zeichenformatvorlage** legt das Aussehen der markierten Wörter fest. **Fett** ist eine Zeichenformatvorlage.

## Formatvorlage auf Text anwenden

1. Klicken Sie in einen Absatz, oder markieren Sie die Wörter, die Sie ändern möchten.
2. Klicken Sie auf der Registerkarte **Start** in der Galerie **Formatvorlagen** auf eine Formatvorlage. Alternativ drücken Sie **Strg+Umschalt+N** für Standard oder **Strg+Alt+1**, **Strg+Alt+2** oder **Strg+Alt+3** für Überschrift 1, 2 oder 3.

Eine Absatzformatvorlage wird auf jeden Absatz angewendet, den Sie berühren. Eine Zeichenformatvorlage wird auf die markierten Wörter angewendet.

## Den Bereich „Formatvorlagen“ öffnen

Klicken Sie auf den kleinen Pfeil in der Ecke der Gruppe **Formatvorlagen**, oder drücken Sie **Strg+Alt+Umschalt+S**. Der Bereich **Formatvorlagen** öffnet sich rechts. Er listet die Formatvorlagen Ihres Dokuments auf, jede in ihrem eigenen Aussehen.

- Die Formatvorlage an Ihrer Einfügemarke ist fett, und vor ihrem Namen steht ein Pfeil.
- Klicken Sie auf eine Formatvorlage, um sie auf Ihre Markierung anzuwenden.
- Verwenden Sie die Liste unter den Formatvorlagen, um festzulegen, welche angezeigt werden:
  - **Verwendet** zeigt nur die Formatvorlagen, die Ihr Text verwendet.
  - **Alle Formatvorlagen** zeigt alle Formatvorlagen, auch solche, die Ihr Dokument noch nicht hat. Eine Formatvorlage wird beim ersten Gebrauch zum Dokument hinzugefügt.
  - **Empfohlen** zeigt die Formatvorlagen, die gesehen werden sollen. Eine Formatvorlage, die bis zu ihrer Verwendung ausgeblendet ist, erscheint hier, sobald Sie sie verwenden.
- Klicken Sie unter der Liste auf **Verwalten…**, um für jede Formatvorlage festzulegen, ob sie **Empfohlen** ist (in der Galerie angezeigt), ob sie **Ausgeblendet** ist (in keiner Liste aufgeführt) und welche **Reihenfolge in den Listen** sie hat. Eine niedrigere Zahl steht weiter vorne. Klicken Sie auf **OK**; alle Änderungen werden in einem Schritt übernommen, sodass ein einziges **Rückgängig** sie alle zurücknimmt.
- Klicken Sie im Dialog **Verwalten** auf **Löschen**, um eine Formatvorlage zu entfernen, die Sie selbst erstellt haben. Absätze, die sie hatten, fallen auf Standard zurück, und Formatvorlagen, die auf ihr basierten, basieren künftig auf dem, worauf sie selbst basierte. Mit JeffWrite gelieferte Formatvorlagen können nicht gelöscht werden. Das Löschen ist ein Schritt, daher bringt **Rückgängig** die Formatvorlage zurück.
- Klicken Sie im Dialog **Verwalten** auf **Aus Datei importieren…**, um Formatvorlagen aus einem anderen Dokument zu kopieren. Wählen Sie die Datei, aktivieren Sie die gewünschten Formatvorlagen, und klicken Sie auf **OK**. Eine Formatvorlage, die eine andere benötigt, bringt diese mit. Vorhandene Formatvorlagen bleiben unverändert, sofern Sie nicht **Formatvorlagen mit demselben Namen ersetzen** aktivieren. Der Import lässt sich mit einem Schritt rückgängig machen.
- Klicken Sie im Dialog **Verwalten** auf **In Datei exportieren…**, um einige Ihrer Formatvorlagen in einer Vorlagendatei (eine **.dotx**-Datei) zu speichern. Aktivieren Sie die gewünschten Formatvorlagen, klicken Sie auf **OK**, und wählen Sie den Speicherort. Ein anderes Dokument kann sie aus dieser Datei mit **Aus Datei importieren…** übernehmen. Eine Formatvorlage, die eine andere benötigt, bringt diese mit.
- Aktivieren Sie **Gesperrt** bei einer Formatvorlage, um sie zu sperren. Aktivieren Sie dann **Formatierung auf die nicht gesperrten Formatvorlagen beschränken**, um die Beschränkung einzuschalten. Solange sie aktiv ist, kann niemand Text von Hand formatieren, etwa mit **Fett** oder **Zentriert**, und niemand kann eine gesperrte Formatvorlage verwenden. Alle anderen Formatvorlagen bleiben nutzbar. Die Statusleiste zeigt an, wenn ein Befehl abgelehnt wird. Deaktivieren Sie das Kästchen, um die Beschränkung auszuschalten. Ist das Dokument mit einem Kennwort geschützt, heben Sie zuerst diesen Schutz auf, unter **Überprüfen > Bearbeitung einschränken**. Die Beschränkung und die Sperren werden in der Datei gespeichert.
- Unter der Liste sortiert das Feld **Sortieren** die Formatvorlagen. **Alphabetisch** sortiert nach Namen. **Wie empfohlen** stellt die nützlichsten Formatvorlagen nach vorn. **Nach Typ** listet zuerst die Absatzformatvorlagen, dann die verknüpften und zuletzt die Zeichenformatvorlagen. **Basierend auf** gruppiert jede Formatvorlage mit der Formatvorlage, auf der sie aufbaut.

## Formatvorlage aus Ihrem Text erstellen

1. Formatieren Sie einen Absatz so, wie Sie es möchten. Machen Sie ihn zum Beispiel fett, zentrieren Sie ihn, und legen Sie die Schriftgröße fest.
2. Klicken Sie unten im Bereich auf **Neue Formatvorlage**, oder klicken Sie auf der Registerkarte **Start** auf **Formatvorlage erstellen**.
3. Geben Sie einen **Namen** ein. Ein Name darf bis zu 255 Zeichen lang sein, und er darf nicht der Name einer anderen Formatvorlage sein.
4. Prüfen Sie die übrigen Optionen, und klicken Sie auf **OK**.

Die neue Formatvorlage wird mit Ihrem Dokument gespeichert, und Ihr Absatz übernimmt sie. Ein **Rückgängig** (Strg+Z) nimmt die Formatvorlage wieder zurück.

## Formatvorlage ändern

1. Klicken Sie in einen Absatz mit der Formatvorlage. Oder klicken Sie im Bereich auf die Formatvorlage.
2. Klicken Sie unten im Bereich auf **Ändern**, oder klicken Sie auf der Registerkarte **Start** auf **Formatvorlage ändern**.
3. Nehmen Sie die gewünschten Änderungen vor, und klicken Sie auf **OK**.

Der Dialog bietet diese Optionen:

- **Name** ist der Name der Formatvorlage. Eine mit JeffWrite gelieferte Formatvorlage behält ihren Namen.
- **Basiert auf** ist die Formatvorlage, von der diese ausgeht. Die neue Formatvorlage sieht wie diese aus, außer bei den Dingen, die Sie ändern. Ändern Sie die Basisformatvorlage später, folgt diese Formatvorlage ihr.
- **Formatvorlage für den folgenden Absatz** ist die Formatvorlage, die der nächste Absatz erhält, wenn Sie am Ende dieses Absatzes die **Eingabetaste** drücken. Auf eine Überschrift folgt meist Standard.
- **Schriftart**, **Schriftgrad**, **Fett**, **Kursiv**, **Unterstrichen** und **Farbe** legen fest, wie die Wörter aussehen.
- **Ausrichtung**, **Einzüge**, **Abstand** und **Zeilenabstand** legen fest, wie die Absätze aussehen.
- **Zur Formatvorlagengalerie hinzufügen** legt die Formatvorlage in die Galerie auf der Registerkarte **Start**.
- **Automatisch aktualisieren** sorgt dafür, dass die Formatvorlage Ihren Formatierungen folgt. Ändern Sie einen Absatz mit dieser Formatvorlage, passt sich die Formatvorlage an, und alle anderen Absätze mit ihr folgen.

Ändern Sie eine Formatvorlage, ändern sich die Absätze, die sie haben. Haben Sie einem Absatz ein eigenes Aussehen gegeben, etwa ein rot markiertes Wort, behält er es.

Klicken Sie auf **OK**, ohne etwas zu ändern, wird das Dokument nicht verändert.

## Formatvorlage an Ihren Text anpassen

Formatieren Sie einen Absatz, wie Sie ihn möchten. Klicken Sie dann auf der Registerkarte **Start** auf **Formatvorlage entsprechend Auswahl aktualisieren**. Die Formatvorlage dieses Absatzes übernimmt die Änderungen, und jeder Absatz mit dieser Formatvorlage folgt.
