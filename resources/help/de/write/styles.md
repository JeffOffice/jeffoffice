# Formatvorlagen verwenden

Eine **Formatvorlage** ist eine gespeicherte Sammlung von Formatierungen: eine Schriftart, eine Schriftgröße, Abstände und mehr. Wenn Sie einem Absatz eine Formatvorlage zuweisen, übernimmt der Absatz alle diese Formatierungen auf einmal. Wenn Sie die Formatvorlage ändern, ändern sich auch alle Absätze, die sie verwenden. Deshalb bleiben Formatvorlagen in langen Dokumenten übersichtlich.

JeffWrite kennt zwei Arten:

- Eine **Absatzformatvorlage** legt das Aussehen ganzer Absätze fest. **Überschrift 1** und **Normal** sind Absatzformatvorlagen.
- Eine **Zeichenformatvorlage** legt das Aussehen der markierten Wörter fest. **Stark** ist eine Zeichenformatvorlage.

## Formatvorlage auf Text anwenden

1. Klicken Sie in einen Absatz, oder markieren Sie die Wörter, die Sie ändern möchten.
2. Klicken Sie auf der Registerkarte **Start** in der Gruppe **Formatvorlagen** auf eine Formatvorlage. Alternativ drücken Sie **Strg+Umschalt+N** für Normal oder **Strg+Alt+1**, **Strg+Alt+2** bzw. **Strg+Alt+3** für Überschrift 1, 2 oder 3.

Eine Absatzformatvorlage wird auf jeden Absatz angewendet, den Sie berühren. Eine Zeichenformatvorlage wird auf die markierten Wörter angewendet.

## Bereich „Formatvorlagen“ öffnen

Klicken Sie auf den kleinen Pfeil in der Ecke der Gruppe **Formatvorlagen**, oder drücken Sie **Strg+Alt+Umschalt+S**. Der Bereich **Formatvorlagen** öffnet sich rechts. Er listet die Formatvorlagen Ihres Dokuments auf, jede in ihrem eigenen Aussehen.

- Die Formatvorlage an Ihrer Cursorposition ist fett dargestellt und hat einen Pfeil vor dem Namen.
- Klicken Sie auf eine Formatvorlage, um sie auf Ihre Markierung anzuwenden.
- Verwenden Sie die Liste unter den Formatvorlagen, um auszuwählen, welche angezeigt werden:
  - **Verwendet** zeigt nur die Formatvorlagen, die Ihr Text verwendet.
  - **Alle Formatvorlagen** zeigt alle Formatvorlagen, auch solche, die Ihr Dokument noch nicht hat. Eine Formatvorlage wird beim ersten Gebrauch dem Dokument hinzugefügt.
  - **Empfohlen** zeigt die Formatvorlagen, die gesehen werden sollen. Eine Formatvorlage, die so lange ausgeblendet ist, bis sie verwendet wird, erscheint hier, sobald Sie sie verwenden.
- Klicken Sie unter der Liste auf **Verwalten…**, um für jede Formatvorlage festzulegen, ob sie **Empfohlen** ist (im Katalog angezeigt), ob sie **Ausgeblendet** ist (in keiner Liste aufgeführt) und wie hoch ihre **Reihenfolge in den Listen** ist. Eine niedrigere Zahl steht weiter oben. Klicken Sie auf **OK**; alle Änderungen erfolgen in einem Schritt, sodass ein **Rückgängig** sie alle zurücknimmt.
- Klicken Sie in **Verwalten…** auf **Löschen**, um eine Formatvorlage zu entfernen, die Sie selbst erstellt haben. Absätze, die sie hatten, fallen auf Normal zurück, und Formatvorlagen, die auf ihr basierten, basieren nun auf deren Grundlage. Mit JeffWrite gelieferte Formatvorlagen können nicht gelöscht werden. Das Löschen ist ein Schritt, daher bringt **Rückgängig** die Formatvorlage zurück.
- Klicken Sie in **Verwalten…** auf **Aus Datei importieren…**, um Formatvorlagen aus einem anderen Dokument zu kopieren. Wählen Sie die Datei, aktivieren Sie die gewünschten Formatvorlagen, und klicken Sie auf **OK**. Eine Formatvorlage, die eine andere benötigt, bringt diese mit. Vorhandene Formatvorlagen bleiben unverändert, es sei denn, Sie aktivieren **Formatvorlagen mit demselben Namen ersetzen**. Das Importieren lässt sich in einem Schritt rückgängig machen.
- Klicken Sie in **Verwalten…** auf **In Datei exportieren…**, um einige Ihrer Formatvorlagen in einer Vorlagendatei (eine **.dotx**-Datei) zu speichern. Aktivieren Sie die gewünschten Formatvorlagen, klicken Sie auf **OK**, und wählen Sie den Speicherort. Ein anderes Dokument kann sie mit **Aus Datei importieren…** aus dieser Datei übernehmen. Eine Formatvorlage, die eine andere benötigt, bringt diese mit.
- Aktivieren Sie **Gesperrt** für eine Formatvorlage, um sie zu sperren. Aktivieren Sie anschließend **Formatierung auf die nicht gesperrten Formatvorlagen beschränken**, um die Beschränkung einzuschalten. Solange die Beschränkung aktiv ist, kann niemand Text von Hand formatieren, etwa mit **Fett** oder **Zentriert**, und niemand kann eine gesperrte Formatvorlage verwenden. Alle anderen Formatvorlagen bleiben nutzbar. Die Statusleiste zeigt an, wenn ein Befehl abgelehnt wird. Deaktivieren Sie das Kästchen, um die Beschränkung auszuschalten. Ist das Dokument mit einem Kennwort geschützt, heben Sie zuerst diesen Schutz auf, und zwar unter **Überprüfen > Bearbeiten einschränken**. Die Beschränkung und die Sperren werden in der Datei gespeichert.
- Unter der Liste sortiert das Feld **Sortieren** die Formatvorlagen. **Alphabetisch** sortiert nach Name. **Wie empfohlen** stellt die nützlichsten Formatvorlagen nach vorne. **Nach Typ** listet zuerst die Absatzformatvorlagen, dann die verknüpften und dann die Zeichenformatvorlagen auf. **Basierend auf** gruppiert jede Formatvorlage mit der Formatvorlage, auf der sie aufbaut.

## Formatvorlage aus Ihrem Text erstellen

1. Formatieren Sie einen Absatz so, wie Sie ihn haben möchten, zum Beispiel fett, zentriert und mit der gewünschten Schriftgröße.
2. Klicken Sie unten im Bereich auf **Neue Formatvorlage**, oder klicken Sie auf der Registerkarte **Start** auf **Formatvorlage erstellen**.
3. Geben Sie einen **Namen** ein. Ein Name darf höchstens 255 Zeichen lang sein und darf nicht der Name einer anderen Formatvorlage sein.
4. Prüfen Sie die übrigen Optionen, und klicken Sie auf **OK**.

Der **Formatvorlagentyp** kann **Absatz**, **Zeichen** oder **Verknüpft** sein. Eine verknüpfte Formatvorlage ist eine Absatzformatvorlage mit einer Zeichenformatvorlage mit demselben Aussehen daneben (benannt wie die Absatzformatvorlage, mit dem Zusatz „Zchn“). So lässt sich das Aussehen einem ganzen Absatz oder nur einzelnen Wörtern zuweisen. Wenn Sie die Absatzformatvorlage später ändern, übernimmt auch ihre Zeichenformatvorlage das neue Aussehen.

**Verfügbar in** wählt **Nur in diesem Dokument** oder **Neue Dokumente auf Basis dieser Vorlage**. Mit der zweiten Option wird die Formatvorlage auch in der Vorlage gespeichert, mit der neue Dokumente beginnen.

Die neue Formatvorlage wird mit Ihrem Dokument gespeichert, und Ihr Absatz übernimmt sie. Ein **Rückgängig** (Strg+Z) nimmt die Formatvorlage wieder zurück.

## Formatvorlage ändern

1. Klicken Sie in einen Absatz mit der Formatvorlage, oder klicken Sie im Bereich auf die Formatvorlage.
2. Klicken Sie unten im Bereich auf **Ändern**, oder klicken Sie auf der Registerkarte **Start** auf **Formatvorlage ändern**.
3. Nehmen Sie die gewünschten Änderungen vor, und klicken Sie auf **OK**.

Der Dialog bietet diese Optionen:

- **Name** ist der Name der Formatvorlage. Eine mit JeffWrite gelieferte Formatvorlage behält ihren Namen.
- **Basierend auf** ist die Formatvorlage, von der diese ausgeht. Die neue Formatvorlage sieht wie diese aus, außer bei den Dingen, die Sie ändern. Ändern Sie die Basisformatvorlage später, folgt diese Formatvorlage.
- **Formatvorlage für den folgenden Absatz** ist die Formatvorlage, die der nächste Absatz erhält, wenn Sie am Ende dieses Absatzes **Eingabe** drücken. Auf eine Überschrift folgt meist Normal.
- **Schriftart**, **Schriftgrad**, **Fett**, **Kursiv**, **Unterstreichung** und **Farbe** legen fest, wie die Wörter aussehen.
- **Ausrichtung**, **Einzüge**, **Abstand** und **Zeilenabstand** legen fest, wie Absätze aussehen.
- **Zum Formatvorlagenkatalog hinzufügen** stellt die Formatvorlage im Katalog der Registerkarte **Start** bereit.
- **Automatisch aktualisieren** sorgt dafür, dass die Formatvorlage Ihrer Formatierung folgt. Wenn Sie einen Absatz mit dieser Formatvorlage ändern, passt sich die Formatvorlage an, und alle anderen Absätze mit ihr ebenfalls.

Wenn Sie eine Formatvorlage ändern, ändern sich die Absätze, die sie verwenden. Hat ein Absatz eine eigene Formatierung, etwa ein rot markiertes Wort, behält er diese bei.

Klicken Sie auf **OK**, ohne etwas zu ändern, bleibt das Dokument unverändert.

## Formatvorlage an Ihren Text anpassen

Formatieren Sie einen Absatz so, wie Sie ihn haben möchten. Klicken Sie dann auf der Registerkarte **Start** auf **Formatvorlage entsprechend Auswahl aktualisieren**. Die Formatvorlage dieses Absatzes übernimmt die Änderungen, und jeder Absatz mit dieser Formatvorlage folgt.

## Liste als Listenformatvorlage speichern

Eine **Listenformatvorlage** ist eine nummerierte oder aufgezählte Liste mit einem Namen. Sie behält alle neun Ebenen: die Nummer oder das Aufzählungszeichen jeder Ebene, deren Text, den Startwert und die Position des Textes.

1. Klicken Sie auf der Registerkarte **Start** auf **Mehrstufige Liste** und dann auf **Neue mehrstufige Liste definieren…**.
2. Richten Sie die Ebenen nach Wunsch ein.
3. Aktivieren Sie **Als Listenformatvorlage speichern**, und geben Sie einen Namen ein. Ist der Name leer oder bereits vergeben, meldet das Feld dies und bleibt geöffnet.
4. Klicken Sie auf **OK**. Die markierten Absätze übernehmen die Listenformatvorlage.

Die Listenformatvorlage erscheint jetzt an zwei Stellen: unter **Listenformatvorlagen** im Katalog **Mehrstufige Liste** (die ersten 100) und im Bereich **Formatvorlagen** (alle). Markieren Sie Absätze, und klicken Sie auf ihren Namen, um sie der Listenformatvorlage zuzuweisen.

- **Ändern.** Klicken Sie auf **Mehrstufige Liste**, **Listenformatvorlage ändern** und den Namen, oder wählen Sie die Listenformatvorlage im Bereich **Formatvorlagen** und klicken Sie auf **Ändern…**. Jeder Absatz mit der Listenformatvorlage ändert sich mit, im Text sowie in Kopf- und Fußzeilen und in Notizen. Im Text ist dies ein Schritt, sodass ein **Rückgängig** es zurücknimmt.
- **Löschen.** Klicken Sie auf **Mehrstufige Liste**, **Listenformatvorlage löschen** und den Namen. Die Absätze behalten ihre Nummern und Aufzählungszeichen genau so, wie sie aussehen. Sie folgen nur nicht mehr einer Formatvorlage.
- **In einer Datei speichern.** Eine Listenformatvorlage wird in einer `.docx`-Datei als Nummerierungsformatvorlage und in einer `.odt`-Datei als Listenformatvorlage gespeichert. Beim erneuten Öffnen der Datei steht sie wieder als Listenformatvorlage zur Verfügung. Eine Datei kann bis zu 1.000 Listenformatvorlagen enthalten; die übrigen werden als einfache Listen verwendet.

Eine Ebene kann weiterhin mit einer Absatzformatvorlage verknüpft sein, wie in jeder mehrstufigen Liste. Die Absatzformatvorlage wird dann von der Listenformatvorlage nummeriert, und **Listenformatvorlage ändern** zeigt die Verknüpfung an, damit Sie sie ändern können.

Hat das Feld keine Liste, der die Formatvorlage zugewiesen werden kann (etwa weil der markierte Text gesperrt ist), wird keine Listenformatvorlage gespeichert, und eine Meldung weist darauf hin.
