# Formatvorlagen verwenden

Eine **Formatvorlage** ist eine gespeicherte Zusammenstellung von Erscheinungsbildern: eine Schriftart, eine Schriftgröße, Abstände und mehr. Wenn Sie einem Absatz eine Formatvorlage zuweisen, übernimmt der Absatz alle diese Merkmale auf einmal. Wenn Sie die Formatvorlage ändern, ändern sich auch alle Absätze, die sie verwenden. Deshalb halten Formatvorlagen lange Dokumente übersichtlich.

JeffWrite kennt zwei Arten:

- Eine **Absatzformatvorlage** legt das Aussehen ganzer Absätze fest. **Überschrift 1** und **Normal** sind Absatzformatvorlagen.
- Eine **Zeichenformatvorlage** legt das Aussehen der markierten Wörter fest. **Stark** ist eine Zeichenformatvorlage.

## Formatvorlage auf Text anwenden

1. Klicken Sie in einen Absatz, oder markieren Sie die Wörter, die Sie ändern möchten.
2. Klicken Sie auf der Registerkarte **Start** in der Galerie **Formatvorlagen** auf eine Formatvorlage. Oder drücken Sie **Strg+Umschalt+N** für Normal oder **Strg+Alt+1**, **Strg+Alt+2** bzw. **Strg+Alt+3** für Überschrift 1, 2 oder 3.

Eine Absatzformatvorlage gilt für jeden Absatz, den Sie berühren. Eine Zeichenformatvorlage gilt für die markierten Wörter.

## Bereich „Formatvorlagen“ öffnen

Klicken Sie auf den kleinen Pfeil in der Ecke der Gruppe **Formatvorlagen**, oder drücken Sie **Strg+Alt+Umschalt+S**. Der Bereich **Formatvorlagen** öffnet sich rechts. Er listet die Formatvorlagen Ihres Dokuments auf, jede in ihrem eigenen Erscheinungsbild.

- Die Formatvorlage an Ihrer Cursorposition ist fett dargestellt und hat einen Pfeil vor dem Namen.
- Klicken Sie auf eine Formatvorlage, um sie der Auswahl zuzuweisen.
- Verwenden Sie die Liste unter den Formatvorlagen, um festzulegen, welche angezeigt werden:
  - **Verwendet** zeigt nur die Formatvorlagen, die Ihr Text verwendet.
  - **Alle Formatvorlagen** zeigt alle Formatvorlagen an, auch solche, die Ihr Dokument noch nicht hat. Eine Formatvorlage wird beim ersten Verwenden zum Dokument hinzugefügt.
  - **Empfohlen** zeigt die Formatvorlagen, die sichtbar sein sollen. Eine Formatvorlage, die ausgeblendet ist, bis sie verwendet wird, erscheint hier, sobald Sie sie verwenden.
- Klicken Sie unter der Liste auf **Verwalten…**, um für jede Formatvorlage festzulegen, ob sie **Empfohlen** ist (in der Galerie angezeigt), ob sie **Ausgeblendet** ist (in keiner Liste aufgeführt) und ihre **Reihenfolge in den Listen**. Eine niedrigere Zahl steht weiter vorne. Klicken Sie auf **OK**, dann werden alle Änderungen in einem Schritt übernommen, sodass ein einziges **Rückgängig** sie alle zurücknimmt.
- Klicken Sie in **Verwalten…** auf **Löschen**, um eine Formatvorlage zu entfernen, die Sie erstellt haben. Absätze, die sie hatten, kehren zu Normal zurück, und Formatvorlagen, die auf ihr basierten, basieren nun auf dem, worauf sie selbst basierte. Mit JeffWrite gelieferte Formatvorlagen können nicht gelöscht werden. Das Löschen ist ein Schritt, daher bringt **Rückgängig** die Formatvorlage zurück.
- Klicken Sie in **Verwalten…** auf **Aus Datei importieren…**, um Formatvorlagen aus einem anderen Dokument zu übernehmen. Wählen Sie die Datei aus, aktivieren Sie die gewünschten Formatvorlagen, und klicken Sie auf **OK**. Eine Formatvorlage, die eine andere benötigt, bringt diese mit. Vorhandene Formatvorlagen bleiben unverändert, es sei denn, Sie aktivieren **Formatvorlagen mit demselben Namen ersetzen**. Das Importieren lässt sich mit einem Schritt rückgängig machen.
- Klicken Sie in **Verwalten…** auf **In Datei exportieren…**, um einige Ihrer Formatvorlagen in einer Vorlagendatei (eine **.dotx**-Datei) zu speichern. Aktivieren Sie die gewünschten Formatvorlagen, klicken Sie auf **OK**, und wählen Sie den Speicherort. Ein anderes Dokument kann sie mit **Aus Datei importieren…** aus dieser Datei übernehmen. Eine Formatvorlage, die eine andere benötigt, bringt diese mit.
- Aktivieren Sie **Gesperrt** für eine Formatvorlage, um sie zu sperren. Aktivieren Sie danach **Formatierung auf die nicht gesperrten Formatvorlagen beschränken**, um die Beschränkung einzuschalten. Solange die Beschränkung aktiv ist, kann niemand Text von Hand formatieren, etwa mit **Fett** oder **Zentriert**, und niemand kann eine gesperrte Formatvorlage verwenden. Alle anderen Formatvorlagen bleiben nutzbar. Die Statusleiste zeigt an, wenn ein Befehl abgelehnt wird. Deaktivieren Sie das Kontrollkästchen, um die Beschränkung auszuschalten. Ist das Dokument mit einem Kennwort geschützt, heben Sie diesen Schutz zuerst auf, und zwar unter **Überprüfen > Bearbeitung einschränken**. Die Beschränkung und die Sperren werden in der Datei gespeichert.
- Unter der Liste sortiert das Feld **Sortieren** die Formatvorlagen. **Alphabetisch** sortiert nach Namen. **Wie empfohlen** stellt die nützlichsten Formatvorlagen nach vorne. **Nach Typ** listet zuerst die Absatzformatvorlagen, dann die verknüpften und dann die Zeichenformatvorlagen auf. **Basierend auf** gruppiert jede Formatvorlage mit der Formatvorlage, auf der sie aufbaut.

## Formatvorlage aus Ihrem Text erstellen

1. Formatieren Sie einen Absatz so, wie Sie ihn haben möchten. Machen Sie ihn zum Beispiel fett, zentrieren Sie ihn, und legen Sie die Schriftgröße fest.
2. Klicken Sie unten im Bereich auf **Neue Formatvorlage**, oder klicken Sie auf der Registerkarte **Start** auf **Formatvorlage erstellen**.
3. Geben Sie einen **Namen** ein. Ein Name darf bis zu 255 Zeichen lang sein und darf nicht der Name einer anderen Formatvorlage sein.
4. Prüfen Sie die übrigen Optionen, und klicken Sie auf **OK**.

Der **Formatvorlagentyp** kann **Absatz**, **Zeichen** oder **Verknüpft** sein. Eine verknüpfte Formatvorlage ist eine Absatzformatvorlage mit einer Zeichenformatvorlage mit demselben Erscheinungsbild daneben (benannt wie die Absatzformatvorlage, mit angehängtem „Zeichen“). So lässt sich das Erscheinungsbild auf einen ganzen Absatz oder nur auf einige Wörter anwenden. Ändern Sie später die Absatzformatvorlage, übernimmt auch deren Zeichenformatvorlage das neue Erscheinungsbild.

Eine **Tabellenformatvorlage** bestimmt die Linien, die Kopfzeile und die gebänderten Zeilen einer Tabelle, und eine **Listenformatvorlage** bestimmt die Nummern oder Aufzählungszeichen einer Liste. Geben Sie bei diesen beiden den **Namen** ein, und klicken Sie auf **OK**. Das Feld für diese Art öffnet sich mit dem bereits eingetragenen Namen. Eine so erstellte Liste wird immer als Listenformatvorlage gespeichert. Eine Tabellen- oder Listenformatvorlage wird nicht beibehalten, wenn Sie das Dokument als .odt-Datei (Tabellenformatvorlagen) oder als .rtf-Datei (beide) speichern. Die Funktion **Kompatibilität prüfen** (Datei > Info) zeigt Ihnen dies an.

**Verfügbar in** wählt **Nur in diesem Dokument** oder **Neue Dokumente auf Basis dieser Vorlage**. Bei der zweiten Option wird die Formatvorlage auch in der Vorlage gespeichert, mit der neue Dokumente beginnen.

Die neue Formatvorlage wird mit Ihrem Dokument gespeichert, und Ihr Absatz übernimmt sie. Ein **Rückgängig** (Strg+Z) nimmt die Formatvorlage wieder zurück.

## Formatvorlage ändern

1. Klicken Sie in einen Absatz mit dieser Formatvorlage. Oder klicken Sie im Bereich auf die Formatvorlage.
2. Klicken Sie unten im Bereich auf **Ändern**, oder klicken Sie auf der Registerkarte **Start** auf **Formatvorlage ändern**.
3. Nehmen Sie die gewünschten Änderungen vor, und klicken Sie auf **OK**.

Das Dialogfeld bietet diese Optionen:

- **Name** ist der Name der Formatvorlage. Eine Formatvorlage, die mit JeffWrite geliefert wird, behält ihren Namen.
- **Basiert auf** ist die Formatvorlage, von der diese ausgeht. Die neue Formatvorlage sieht wie jene aus, abgesehen von dem, was Sie ändern. Ändern Sie die Basisformatvorlage später, folgt diese Formatvorlage der Änderung.
- **Formatvorlage für den folgenden Absatz** ist die Formatvorlage, die der nächste Absatz erhält, wenn Sie am Ende dieses Absatzes die **Eingabetaste** drücken. Auf eine Überschrift folgt meist Normal.
- **Schriftart**, **Schriftgrad**, **Fett**, **Kursiv**, **Unterstrichen** und **Farbe** legen fest, wie die Wörter aussehen.
- **Ausrichtung**, **Einzug**, **Abstand** und **Zeilenabstand** legen fest, wie die Absätze aussehen.
- **Zum Formatvorlagenkatalog hinzufügen** stellt die Formatvorlage in den Katalog auf der Registerkarte **Start**.
- **Automatisch aktualisieren** lässt die Formatvorlage Ihrer Formatierung folgen. Ändern Sie einen Absatz mit dieser Formatvorlage, ändert sich die Formatvorlage entsprechend, und alle anderen Absätze mit ihr ebenso.

Ändern Sie eine Formatvorlage, ändern sich die Absätze, die sie verwenden. Hat ein Absatz ein eigenes Erscheinungsbild, etwa ein rot markiertes Wort, behält er es.

Klicken Sie auf **OK**, ohne etwas zu ändern, wird das Dokument nicht verändert.

## Herkunft des Erscheinungsbilds Ihres Textes anzeigen

Klicken Sie unten im Bereich Formatvorlagen auf **Formatvorlagen-Inspektor**. Der Bereich folgt Ihrem Cursor im Text, in einer Kopfzeile, einer Fußzeile oder einer Notiz und zeigt drei Dinge:

- Die **Absatzformatvorlage** des Absatzes. Steht der Absatz in einer Tabelle, wird darunter die Formatvorlage der Tabelle genannt. Unter dem Namen listet „Plus“ auf, was der Absatz selbst zusätzlich zu seiner Formatvorlage festlegt, etwa Ausrichtung, Einzüge, Abstände, Zeilen, Tabstopps, Rahmen, Schattierung, Seitenwechsel davor, Gliederungsebene, Nummerierung oder Aufzählungszeichen und Textrichtung. **Absatzformatierung entfernen** nimmt diese Angaben weg, sodass der Absatz so aussieht, wie seine Formatvorlage es vorsieht. Was die Tabellenformatvorlage ihren Absätzen gibt, wird nicht aufgeführt, weil es nicht zum Absatz selbst gehört.
- Die **Zeichenformatvorlage** des Textes, falls er eine hat. **Zeichenformatvorlage entfernen** nimmt sie weg.
- Die **Textformatierung**, die die Buchstaben selbst haben, etwa eine Schriftart, eine Schriftgröße, Fettdruck, eine Farbe, ausgeblendeten Text oder einen Rahmen. **Zeichenformatierung entfernen** nimmt sie weg, sodass die Buchstaben so aussehen, wie es ihre Formatvorlagen vorsehen. Die Sprache des Textes und seine Zeichenformatvorlage bleiben erhalten.

Markieren Sie zuerst den Text, um nur diesen zu bereinigen. Ohne Markierung beschreibt der Bereich den Buchstaben vor dem Cursor, und **Zeichenformatvorlage entfernen** und **Zeichenformatierung entfernen** wirken auf den gesamten Abschnitt um den Cursor, dessen Buchstaben genauso aussehen wie dieser Buchstabe. Markieren Sie mehrere Absätze oder Buchstaben, die sich unterscheiden, zeigt der Bereich „Mehrere Formatvorlagen in der Auswahl“ oder „Mehrere Erscheinungsbilder in der Auswahl“ an, listet auf, was die Auswahl enthält, und die Schaltflächen wirken auf alles.

Jede Schaltfläche ist ein Schritt, daher bringt **Rückgängig** (Strg+Z) das Erscheinungsbild zurück, und der Cursor bleibt an seiner Position. Eine Änderung an einer Formatvorlage lässt ihre Absätze nie das Erscheinungsbild selbst angeben. Ein Absatz, der seiner Formatvorlage folgt, zeigt daher unter „Plus“ nichts an. Mit Umschalt+F1 öffnen Sie weiterhin **Formatierung anzeigen**, das das Aussehen selbst zeigt.

## Formatvorlage an Ihren Text anpassen

Formatieren Sie einen Absatz, wie Sie möchten. Klicken Sie dann auf der Registerkarte **Start** auf **Formatvorlage entsprechend Auswahl aktualisieren**. Die Formatvorlage dieses Absatzes übernimmt die vorgenommenen Änderungen, und jeder Absatz mit dieser Formatvorlage folgt.

## Eine Liste als Listenformatvorlage speichern

Eine **Listenformatvorlage** ist eine nummerierte oder mit Aufzählungszeichen versehene Liste mit einem Namen. Sie behält alle neun Ebenen: die Nummer oder das Aufzählungszeichen jeder Ebene, ihren Text, wo sie beginnt und wo der Text steht.

1. Klicken Sie auf der Registerkarte **Start** auf **Mehrstufige Liste** und dann auf **Neue mehrstufige Liste definieren…**.
2. Richten Sie die Ebenen so ein, wie Sie möchten.
3. Aktivieren Sie **Als Listenformatvorlage speichern**, und geben Sie einen Namen ein. Ist der Name leer oder bereits vergeben, zeigt das Feld dies an und bleibt geöffnet.
4. Klicken Sie auf **OK**. Die markierten Absätze erhalten die Listenformatvorlage.

Die Listenformatvorlage erscheint nun an zwei Stellen: unter **Listenformatvorlagen** in der Galerie **Mehrstufige Liste** (die ersten 100) und im Bereich **Formatvorlagen** (alle). Markieren Sie Absätze, und klicken Sie auf ihren Namen, um ihnen die Listenformatvorlage zu geben.

- **Ändern.** Klicken Sie auf **Mehrstufige Liste**, dann auf **Listenformatvorlage ändern** und den Namen. Alternativ wählen Sie die Listenformatvorlage im Bereich **Formatvorlagen** und klicken auf **Ändern…**. Jeder Absatz mit der Listenformatvorlage ändert sich mit ihr, im Text ebenso wie in Kopf- und Fußzeilen und Notizen. Im Text ist dies ein Schritt, daher nimmt ein einziges **Rückgängig** die Änderung zurück.
- **Löschen.** Klicken Sie auf **Mehrstufige Liste**, dann auf **Listenformatvorlage löschen** und den Namen. Die Absätze behalten ihre Nummern und Aufzählungszeichen genau so, wie sie aussehen. Sie folgen nur nicht mehr einer Formatvorlage.
- **In einer Datei speichern.** Eine Listenformatvorlage wird in einer `.docx`-Datei als Nummerierungsformatvorlage und in einer `.odt`-Datei als Listenformatvorlage gespeichert. Beim erneuten Öffnen der Datei ist sie wieder eine Listenformatvorlage. Eine Datei kann bis zu 1.000 Listenformatvorlagen enthalten. Die übrigen werden als einfache Listen verwendet.

Eine Ebene kann weiterhin mit einer Absatzformatvorlage verknüpft sein, wie bei jeder mehrstufigen Liste. Die Absatzformatvorlage wird dann durch die Listenformatvorlage nummeriert, und **Listenformatvorlage ändern** zeigt die Verknüpfung, damit Sie sie ändern können.

Hat das Feld keine Liste, der die Formatvorlage zugewiesen werden kann (etwa weil der markierte Text gesperrt ist), wird keine Listenformatvorlage gespeichert, und eine Meldung weist darauf hin.
