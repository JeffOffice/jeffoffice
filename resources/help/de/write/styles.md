# Formatvorlagen verwenden
<!-- keywords: Formatvorlagen, Formatvorlage, Formatvorlagenbereich, Überschrift, Standard, Formatvorlage erstellen, neue Formatvorlage, Formatvorlage ändern, Formatvorlage bearbeiten, basierend auf, nächste Formatvorlage, automatisch aktualisieren, Katalog, Zeichenformatvorlage, Absatzformatvorlage, strg+alt+umschalt+s -->

Eine **Formatvorlage** ist eine gespeicherte Zusammenstellung von Formaten: eine Schriftart, eine Schriftgröße, Abstände und mehr. Wenn Sie einem Absatz eine Formatvorlage zuweisen, übernimmt der Absatz alle diese Formate auf einmal. Ändern Sie die Formatvorlage, ändern sich auch alle Absätze, die sie verwenden. Deshalb bleiben lange Dokumente mit Formatvorlagen übersichtlich.

JeffWrite kennt zwei Arten:

- Eine **Absatzformatvorlage** legt das Aussehen ganzer Absätze fest. **Überschrift 1** und **Standard** sind Absatzformatvorlagen.
- Eine **Zeichenformatvorlage** legt das Aussehen der markierten Wörter fest. **Fett** ist eine Zeichenformatvorlage.

## Einem Text eine Formatvorlage zuweisen

1. Klicken Sie in einen Absatz, oder markieren Sie die Wörter, die Sie ändern möchten.
2. Klicken Sie auf der Registerkarte **Start** im Katalog **Formatvorlagen** auf eine Formatvorlage. Oder drücken Sie **Strg+Umschalt+N** für Standard bzw. **Strg+Alt+1**, **Strg+Alt+2** oder **Strg+Alt+3** für Überschrift 1, 2 oder 3.

Eine Absatzformatvorlage gilt für jeden Absatz, den Sie berühren. Eine Zeichenformatvorlage gilt für die markierten Wörter.

## Den Bereich „Formatvorlagen“ öffnen

Klicken Sie auf den kleinen Pfeil in der Ecke der Gruppe **Formatvorlagen**, oder drücken Sie **Strg+Alt+Umschalt+S**. Der Bereich **Formatvorlagen** öffnet sich rechts. Er listet die Formatvorlagen Ihres Dokuments auf, jede in ihrem eigenen Aussehen.

- Die Formatvorlage an Ihrer Cursorposition ist fett dargestellt und hat einen Pfeil vor dem Namen.
- Klicken Sie auf eine Formatvorlage, um sie der Markierung zuzuweisen.
- Verwenden Sie die Liste unter den Formatvorlagen, um auszuwählen, welche angezeigt werden:
  - **Verwendet** zeigt nur die Formatvorlagen, die Ihr Text verwendet.
  - **Alle Formatvorlagen** zeigt alle Formatvorlagen, auch solche, die Ihr Dokument noch nicht hat. Eine Formatvorlage wird beim ersten Gebrauch in das Dokument aufgenommen.
  - **Empfohlen** zeigt die Formatvorlagen, die sichtbar sein sollen. Eine Formatvorlage, die erst nach dem Gebrauch sichtbar wird, erscheint hier, sobald Sie sie verwenden.
- Unter der Liste sortiert das Feld **Sortierung** die Formatvorlagen. **Alphabetisch** sortiert nach dem Namen. **Wie empfohlen** stellt die nützlichsten Formatvorlagen nach vorn. **Nach Typ** listet zuerst die Absatzformatvorlagen, dann die verknüpften und zuletzt die Zeichenformatvorlagen auf. **Basierend auf** gruppiert jede Formatvorlage mit der Formatvorlage, auf der sie aufbaut.

## Aus Ihrem Text eine Formatvorlage machen

1. Formatieren Sie einen Absatz so, wie Sie ihn haben möchten. Machen Sie ihn zum Beispiel fett, zentrieren Sie ihn, und legen Sie die Schriftgröße fest.
2. Klicken Sie unten im Bereich auf **Neue Formatvorlage**, oder klicken Sie auf der Registerkarte **Start** auf **Formatvorlage erstellen**.
3. Geben Sie unter **Name** einen Namen ein. Ein Name darf bis zu 255 Buchstaben haben und darf nicht der Name einer anderen Formatvorlage sein.
4. Prüfen Sie die übrigen Optionen, und klicken Sie auf **OK**.

Die neue Formatvorlage wird mit Ihrem Dokument gespeichert, und Ihr Absatz übernimmt sie. Ein Schritt mit **Rückgängig** (Strg+Z) nimmt die Formatvorlage wieder zurück.

## Eine Formatvorlage ändern

1. Klicken Sie in einen Absatz mit der Formatvorlage. Oder klicken Sie im Bereich auf die Formatvorlage.
2. Klicken Sie unten im Bereich auf **Ändern**, oder klicken Sie auf der Registerkarte **Start** auf **Formatvorlage ändern**.
3. Nehmen Sie die gewünschten Änderungen vor, und klicken Sie auf **OK**.

Das Dialogfeld bietet diese Optionen:

- **Name** ist der Name der Formatvorlage. Eine Formatvorlage, die mit JeffWrite geliefert wird, behält ihren Namen.
- **Basierend auf** ist die Formatvorlage, von der diese ausgeht. Die neue Formatvorlage sieht wie diese aus, außer bei den Änderungen, die Sie vornehmen. Ändern Sie später die Grundformatvorlage, folgt diese Formatvorlage der Änderung.
- **Formatvorlage für den folgenden Absatz** ist die Formatvorlage, die der nächste Absatz erhält, wenn Sie am Ende dieses Absatzes die Taste **Eingabe** drücken. Auf eine Überschrift folgt meist Standard.
- **Schriftart**, **Schriftgrad**, **Fett**, **Kursiv**, **Unterstreichung** und **Farbe** legen fest, wie die Wörter aussehen.
- **Ausrichtung**, **Einzüge**, **Abstand** und **Zeilenabstand** legen fest, wie Absätze aussehen.
- **Zum Formatvorlagenkatalog hinzufügen** nimmt die Formatvorlage in den Katalog auf der Registerkarte **Start** auf.
- **Automatisch aktualisieren** sorgt dafür, dass die Formatvorlage Ihren Formatierungen folgt. Wenn Sie einen Absatz mit dieser Formatvorlage ändern, passt sich die Formatvorlage an, und alle anderen Absätze mit ihr ebenso.

Wenn Sie eine Formatvorlage ändern, ändern sich die Absätze, die sie verwenden. Haben Sie einem Absatz ein eigenes Aussehen gegeben, etwa ein rot formatiertes Wort, behält er dieses Aussehen.

Klicken Sie auf **OK**, ohne etwas zu ändern, bleibt das Dokument unverändert.

## Eine Formatvorlage an Ihren Text anpassen

Formatieren Sie einen Absatz so, wie Sie ihn haben möchten. Klicken Sie dann auf der Registerkarte **Start** auf **Formatvorlage entsprechend Auswahl aktualisieren**. Die Formatvorlage des Absatzes übernimmt die Änderungen, und jeder Absatz mit dieser Formatvorlage folgt.
