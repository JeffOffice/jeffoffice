Eine **Formatvorlage** ist eine gespeicherte Gruppe von Formaten: eine Schriftart, eine Schriftgröße, Abstände und mehr. Wenn Sie einem Absatz eine Formatvorlage zuweisen, übernimmt der Absatz alle diese Formate auf einmal. Wenn Sie die Formatvorlage ändern, ändern sich auch alle Absätze, die sie verwenden. Deshalb bleiben lange Dokumente mit Formatvorlagen übersichtlich.

JeffWrite kennt zwei Arten:

- Eine **Absatzformatvorlage** legt das Aussehen ganzer Absätze fest. **Überschrift 1** und **Normal** sind Absatzformatvorlagen.
- Eine **Zeichenformatvorlage** legt das Aussehen der markierten Wörter fest. **Stark** ist eine Zeichenformatvorlage.

## Formatvorlage auf Ihren Text anwenden

1. Klicken Sie in einen Absatz, oder markieren Sie die Wörter, die Sie ändern möchten.
2. Klicken Sie auf der Registerkarte **Start** in der Galerie **Formatvorlagen** auf eine Formatvorlage. Alternativ drücken Sie **Strg+Umschalt+N** für Normal oder **Strg+Alt+1**, **Strg+Alt+2** bzw. **Strg+Alt+3** für Überschrift 1, 2 oder 3.

Eine Absatzformatvorlage wird auf jeden Absatz angewendet, den Sie berühren. Eine Zeichenformatvorlage wird auf die markierten Wörter angewendet.

## Den Bereich „Formatvorlagen“ öffnen

Klicken Sie auf den kleinen Pfeil in der Ecke der Gruppe **Formatvorlagen**, oder drücken Sie **Strg+Alt+Umschalt+S**. Der Bereich **Formatvorlagen** öffnet sich rechts. Er listet die Formatvorlagen Ihres Dokuments auf, jede in ihrem eigenen Aussehen.

- Die Formatvorlage an Ihrer Einfügemarke ist fett, und vor ihrem Namen steht ein Pfeil.
- Klicken Sie auf eine Formatvorlage, um sie der Markierung zuzuweisen.
- Verwenden Sie die Liste unter den Formatvorlagen, um festzulegen, welche angezeigt werden:
  - **Verwendet** zeigt nur die Formatvorlagen, die Ihr Text verwendet.
  - **Alle Formatvorlagen** zeigt alle Formatvorlagen, auch solche, die Ihr Dokument noch nicht hat. Eine Formatvorlage wird beim ersten Verwenden dem Dokument hinzugefügt.
  - **Empfohlen** zeigt die Formatvorlagen, die sichtbar sein sollen. Eine Formatvorlage, die bis zu ihrer Verwendung ausgeblendet ist, erscheint hier, sobald Sie sie verwenden.
- Klicken Sie unter der Liste auf **Verwalten…**, um für jede Formatvorlage festzulegen, ob sie **Empfohlen** ist (in der Galerie angezeigt), ob sie **Ausgeblendet** ist (in keiner Liste aufgeführt) und welche **Reihenfolge in den Listen** sie hat. Eine niedrigere Zahl steht weiter vorn. Klicken Sie auf **OK**; alle Änderungen werden auf einmal übernommen, sodass ein einziges **Rückgängig** sie alle zurücknimmt.
- Klicken Sie in **Verwalten…** auf **Löschen**, um eine selbst erstellte Formatvorlage zu entfernen. Absätze mit dieser Formatvorlage werden auf Normal zurückgesetzt, und die Formatvorlagen, die auf ihr basierten, beruhen nun auf deren Grundlage. Mit JeffWrite gelieferte Formatvorlagen lassen sich nicht löschen. Das Löschen ist ein einzelner Schritt, daher bringt **Rückgängig** die Formatvorlage zurück.
- Klicken Sie in **Verwalten…** auf **Aus Datei importieren…**, um Formatvorlagen aus einem anderen Dokument zu kopieren. Wählen Sie die Datei, aktivieren Sie die gewünschten Formatvorlagen, und klicken Sie auf **OK**. Eine Formatvorlage, die eine andere benötigt, bringt diese mit. Vorhandene Formatvorlagen bleiben unverändert, sofern Sie nicht **Formatvorlagen mit demselben Namen ersetzen** aktivieren. Das Importieren lässt sich in einem Schritt rückgängig machen.
- Klicken Sie in **Verwalten…** auf **In Datei exportieren…**, um einige Formatvorlagen in einer Vorlagendatei (eine **.dotx**-Datei) zu speichern. Aktivieren Sie die gewünschten Formatvorlagen, klicken Sie auf **OK**, und wählen Sie den Speicherort. Ein anderes Dokument kann sie mit **Aus Datei importieren…** aus dieser Datei übernehmen. Eine Formatvorlage, die eine andere benötigt, bringt diese mit.
- Aktivieren Sie **Gesperrt** für eine Formatvorlage, um sie zu sperren. Aktivieren Sie anschließend **Formatierung auf die nicht gesperrten Formatvorlagen beschränken**, um die Beschränkung einzuschalten. Solange sie eingeschaltet ist, kann niemand Text von Hand formatieren, etwa mit **Fett** oder **Zentriert**, und niemand kann eine gesperrte Formatvorlage verwenden. Alle anderen Formatvorlagen bleiben verfügbar. Die Statusleiste zeigt an, wenn ein Befehl abgelehnt wird. Deaktivieren Sie das Kästchen, um die Beschränkung auszuschalten. Ist das Dokument mit einem Kennwort geschützt, heben Sie zuerst diesen Schutz auf, und zwar unter **Überprüfen > Bearbeitung einschränken**. Die Beschränkung und die Sperren werden in der Datei gespeichert.
- Unter der Liste sortiert das Feld **Sortieren** die Formatvorlagen. **Alphabetisch** sortiert nach Namen. **Nach Empfehlung** stellt die nützlichsten Formatvorlagen nach vorn. **Nach Typ** listet zuerst die Absatzformatvorlagen, dann die verknüpften und dann die Zeichenformatvorlagen auf. **Basiert auf** gruppiert jede Formatvorlage mit der Formatvorlage, auf der sie aufbaut.

## Aus Ihrem Text eine Formatvorlage erstellen

1. Formatieren Sie einen Absatz so, wie Sie ihn haben möchten, zum Beispiel fett, zentriert und mit der gewünschten Größe.
2. Klicken Sie unten im Bereich auf **Neue Formatvorlage**, oder klicken Sie auf der Registerkarte **Start** auf **Formatvorlage erstellen**.
3. Geben Sie unter **Name** einen Namen ein. Ein Name darf bis zu 255 Buchstaben haben und darf nicht der Name einer anderen Formatvorlage sein.
4. Prüfen Sie die übrigen Optionen, und klicken Sie auf **OK**.

Die neue Formatvorlage wird mit Ihrem Dokument gespeichert, und Ihr Absatz übernimmt sie. Ein einziges **Rückgängig** (Strg+Z) nimmt die Formatvorlage wieder zurück.

## Eine Formatvorlage ändern

1. Klicken Sie in einen Absatz mit dieser Formatvorlage. Oder klicken Sie im Bereich auf die Formatvorlage.
2. Klicken Sie unten im Bereich auf **Ändern**, oder klicken Sie auf der Registerkarte **Start** auf **Formatvorlage ändern**.
3. Ändern Sie, was Sie möchten, und klicken Sie auf **OK**.

Das Dialogfeld bietet diese Optionen:

- **Name** ist der Name der Formatvorlage. Eine mit JeffWrite gelieferte Formatvorlage behält ihren Namen.
- **Basiert auf** ist die Formatvorlage, von der diese ausgeht. Die neue Formatvorlage sieht wie diese aus, außer bei den Änderungen, die Sie vornehmen. Ändern Sie die Grundformatvorlage später, folgt ihr diese Formatvorlage.
- **Formatvorlage für den folgenden Absatz** ist die Formatvorlage, die der nächste Absatz erhält, wenn Sie am Ende dieses Absatzes **Eingabe** drücken. Auf eine Überschrift folgt meist Normal.
- **Schriftart**, **Größe**, **Fett**, **Kursiv**, **Unterstrichen** und **Farbe** legen fest, wie die Wörter aussehen.
- **Ausrichtung**, **Einzug**, **Abstand** und **Zeilenabstand** legen fest, wie Absätze aussehen.
- **Zum Formatvorlagenkatalog hinzufügen** stellt die Formatvorlage in den Katalog auf der Registerkarte **Start**.
- **Automatisch aktualisieren** sorgt dafür, dass die Formatvorlage Ihren Formaten folgt. Wenn Sie einen Absatz mit dieser Formatvorlage ändern, passt sich die Formatvorlage an, und ebenso alle anderen Absätze, die sie verwenden.

Wenn Sie eine Formatvorlage ändern, ändern sich die Absätze, die sie verwenden. Hat ein Absatz eine eigene Formatierung, etwa ein rot markiertes Wort, behält er diese bei.

Klicken Sie auf **OK**, ohne etwas zu ändern, bleibt das Dokument unverändert.

## Eine Formatvorlage an Ihren Text anpassen

Formatieren Sie einen Absatz so, wie Sie ihn haben möchten. Klicken Sie dann auf der Registerkarte **Start** auf **Formatvorlage entsprechend Auswahl aktualisieren**. Die Formatvorlage dieses Absatzes übernimmt die Änderungen, die Sie vorgenommen haben, und jeder Absatz mit dieser Formatvorlage folgt.

## Eine Liste als Listenformatvorlage speichern

Eine **Listenformatvorlage** ist eine nummerierte oder mit Aufzählungszeichen versehene Liste mit einem Namen. Sie behält alle neun Ebenen: die Nummer oder das Aufzählungszeichen jeder Ebene, deren Text, wo sie beginnt und wo der Text steht.

1. Klicken Sie auf der Registerkarte **Start** auf **Mehrstufige Liste** und dann auf **Neue mehrstufige Liste definieren…**.
2. Richten Sie die Ebenen so ein, wie Sie möchten.
3. Aktivieren Sie **Als Listenformatvorlage speichern**, und geben Sie einen Namen ein. Ist der Name leer oder bereits vergeben, zeigt das Feld dies an und bleibt geöffnet.
4. Klicken Sie auf **OK**. Die markierten Absätze übernehmen die Listenformatvorlage.

Die Listenformatvorlage erscheint nun an zwei Stellen: unter **Listenformatvorlagen** in der Galerie **Mehrstufige Liste** (die ersten 100) und im Bereich **Formatvorlagen** (alle). Markieren Sie Absätze, und klicken Sie auf ihren Namen, um sie der Listenformatvorlage zuzuweisen.

- **Ändern.** Klicken Sie auf **Mehrstufige Liste**, **Listenformatvorlage ändern** und den Namen, oder wählen Sie die Listenformatvorlage im Bereich **Formatvorlagen** und klicken Sie auf **Ändern…**. Jeder Absatz mit der Listenformatvorlage ändert sich mit, im Text sowie in Kopf- und Fußzeilen und Notizen. Im Text ist das ein einzelner Schritt, daher nimmt ein **Rückgängig** es zurück.
- **Löschen.** Klicken Sie auf **Mehrstufige Liste**, **Listenformatvorlage löschen** und den Namen. Die Absätze behalten ihre Nummern und Aufzählungszeichen genau so, wie sie aussehen. Sie folgen nur nicht mehr einer Formatvorlage.
- **In einer Datei speichern.** Eine Listenformatvorlage wird in einer `.docx`-Datei als Nummerierungsformatvorlage und in einer `.odt`-Datei als Listenformatvorlage gespeichert. Beim erneuten Öffnen der Datei ist sie wieder eine Listenformatvorlage. Eine Datei kann bis zu 1.000 Listenformatvorlagen enthalten; die übrigen werden als einfache Listen verwendet.

Eine Ebene kann weiterhin mit einer Absatzformatvorlage verknüpft sein, wie bei jeder mehrstufigen Liste. Die Absatzformatvorlage wird dann von der Listenformatvorlage nummeriert, und **Listenformatvorlage ändern** zeigt die Verknüpfung, damit Sie sie ändern können.

Gibt es für die Formatvorlage keine Liste, der sie zugewiesen werden kann (etwa weil der markierte Text gesperrt ist), wird keine Listenformatvorlage gespeichert, und eine Meldung weist darauf hin.
