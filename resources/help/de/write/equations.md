# Gleichungen
<!-- keywords: Gleichung, Gleichungen, Mathematik, Formel, Bruch, Quadratwurzel, Wurzel, hochgestellt, tiefgestellt, Exponent, Summe, Integral, griechisch, Symbol, Gleichung einfügen, Alt+= -->

Eine **Gleichung** ist eine mathematische Formel, etwa ein Bruch oder eine Quadratwurzel. Dieses Thema zeigt, wie Sie eine Gleichung eingeben und in ein Dokument einfügen.

## Gleichung einfügen

1. Setzen Sie die Einfügemarke an die Stelle, an der die Gleichung stehen soll.
2. Klicken Sie auf **Einfügen > Gleichung**, oder drücken Sie **Alt+=**.
3. Geben Sie die Gleichung in einer Zeile ein. Unter dem Feld sehen Sie, wie sie aussehen wird. Klicken Sie auf **OK**.

Die Gleichung wird im Dokument in der Standardform für Mathematik gespeichert, damit andere Programme sie öffnen können.

## So geben Sie Gleichungen ein

- **Brüche:** Geben Sie einen Schrägstrich ein. `a/b` ist a über b. `(x+1)/(x-1)` fasst jede Gruppe in Klammern als einen Teil auf. Auch `\frac{1}{2}` funktioniert.
- **Potenzen:** Geben Sie ein Dach-Zeichen (^) ein. `x^2` ist x hoch 2. `e^(i*pi)` fasst die Gruppe in Klammern zusammen.
- **Indizes:** Geben Sie einen Unterstrich ein. `x_i` ist x mit einem kleinen i darunter. Sie können beides kombinieren, etwa `x_i^2`.
- **Wurzeln:** Geben Sie `sqrt(x+1)` für eine Quadratwurzel ein. Geben Sie `sqrt[3]{x}` für eine Kubikwurzel ein.
- **Summen, Integrale und Produkte:** Geben Sie `\sum_(i=1)^n i`, `\int_0^1 x` oder `\prod_(k=1)^n k` ein. Der Teil nach dem Unterstrich steht darunter (bei einem Integralzeichen unten am Zeichen), der Teil nach dem Dach-Zeichen steht darüber.
- **Symbole:** Geben Sie einen Backslash und einen Namen ein. `\alpha` ist α, `\pi` ist π, `\infty` ist ∞, `\leq` ist ≤, `\neq` ist ≠, `\times` ist ×, `\pm` ist ±, und `\to` ist →. Etwa 70 Namen sind möglich.
- **Funktionen:** `sin`, `cos`, `tan`, `log`, `ln`, `exp`, `lim`, `min` und `max` bleiben als ganze Namen erhalten.

Auf der Seite zeigt JeffWrite eine Gleichung als eine Zeile Text an. Die Gleichung in der Datei behält ihre Brüche und Wurzeln, und andere Programme stellen sie entsprechend dar.

## Gleichungen in anderen Dokumenten

JeffWrite zeigt die Gleichungen an, die ein Dokument enthält, und behält sie unverändert bei. Eine bereits vorhandene Gleichung in einem Dokument ändert JeffWrite nicht. Löschen Sie sie, und fügen Sie sie erneut ein.
