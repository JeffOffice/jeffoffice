# Gleichungen

Eine **Gleichung** ist eine Zeile mit Mathematik, zum Beispiel ein Bruch oder eine Quadratwurzel. Dieses Thema zeigt, wie Sie eine Gleichung eingeben und in ein Dokument einfügen.

## Gleichung einfügen

1. Setzen Sie die Einfügemarke an die Stelle, an der die Gleichung stehen soll.
2. Klicken Sie auf **Einfügen > Gleichung**, oder drücken Sie **Alt+=**.
3. Geben Sie die Gleichung in einer Zeile ein. Unter dem Feld sehen Sie, wie sie aussehen wird. Klicken Sie auf **OK**.

Die Gleichung wird im Dokument in der Standardform für Mathematik gespeichert, sodass andere Programme sie öffnen können.

## So geben Sie Gleichungen ein

- **Brüche:** Geben Sie einen Schrägstrich ein. `a/b` ergibt a über b. `(x+1)/(x-1)` fasst jede Gruppe in Klammern als einen Teil auf. `\frac{1}{2}` funktioniert ebenfalls.
- **Potenzen:** Geben Sie ein Dach-Zeichen ein. `x^2` ergibt x hoch 2. `e^(i*pi)` übernimmt die Gruppe in Klammern.
- **Indizes:** Geben Sie einen Unterstrich ein. `x_i` ergibt x mit einem kleinen i unten. Beides können Sie kombinieren, wie in `x_i^2`.
- **Wurzeln:** Geben Sie `sqrt(x+1)` für eine Quadratwurzel ein. Geben Sie `sqrt[3]{x}` für eine dritte Wurzel ein.
- **Summen, Integrale und Produkte:** Geben Sie `\sum_(i=1)^n i`, `\int_0^1 x` oder `\prod_(k=1)^n k` ein. Der Teil nach dem Unterstrich steht unten (bzw. unten am Integralzeichen), der Teil nach dem Dach-Zeichen steht oben.
- **Symbole:** Geben Sie einen Backslash und einen Namen ein. `\alpha` ergibt α, `\pi` ergibt π, `\infty` ergibt ∞, `\leq` ergibt ≤, `\neq` ergibt ≠, `\times` ergibt ×, `\pm` ergibt ± und `\to` ergibt →. Etwa 70 Namen funktionieren.
- **Akzente:** `\hat{x}`, `\check{x}`, `\tilde{x}`, `\acute{x}`, `\grave{x}`, `\breve{x}`, `\dot{x}`, `\ddot{x}`, `\bar{x}` und `\vec{v}` setzen eine Markierung über den Buchstaben. `\overline{ab}` zieht eine Linie über die Gruppe, und `\underline{ab}` zieht eine Linie darunter.
- **Klammern, die mitwachsen:** Geben Sie `\left( ... \right)` ein, dann wachsen die Klammern auf die Höhe des Inhalts dazwischen. Verwenden Sie nach `\left` und `\right` eine beliebige Klammer, oder einen Punkt, um eine Seite wegzulassen, wie in `\left[ x \right.`.
- **Matrizen:** Eine **Matrix** ist ein Raster aus Zahlen. Geben Sie `\matrix{a & b \\ c & d}` ein. Setzen Sie ein `&` zwischen die Zellen einer Zeile und zwei Backslashes zwischen die Zeilen. Verwenden Sie `\pmatrix` für runde Klammern um das Raster, `\bmatrix` für eckige und `\vmatrix` für senkrechte Striche.
- **Funktionen:** `sin`, `cos`, `tan`, `log`, `ln`, `exp`, `lim`, `min` und `max` behalten ihre Namen ganz.

Auf der Seite zeigt JeffWrite eine Gleichung als eine Textzeile. Die Gleichung in der Datei behält ihre Brüche und Wurzeln, sodass andere Programme sie korrekt darstellen.

## Integrierte Gleichungen

Klicken Sie auf **Einfügen > Integrierte Gleichungen**, um eine Liste bekannter Gleichungen zu sehen, zum Beispiel die quadratische Formel und die Fläche eines Kreises. Klicken Sie auf eine davon, um sie an der Einfügemarke einzufügen.

## Gleichung ändern

Setzen Sie die Einfügemarke neben eine Gleichung, oder markieren Sie sie, und klicken Sie auf **Einfügen > Gleichung**. Das Feld öffnet sich mit der Gleichung in einer Zeile. Ändern Sie sie und klicken Sie auf **OK**. Mit einem Schritt können Sie die Änderung rückgängig machen.

## Gleichungen in anderen Dokumenten

JeffWrite zeigt die Gleichungen an, die ein Dokument enthält, und behält sie unverändert bei. Eine Gleichung, die aus den oben aufgeführten Teilen besteht, kann JeffWrite ändern. Eine Gleichung mit anderen Teilen, etwa Gruppierungszeichen, bleibt unverändert erhalten. In diesem Fall fügt **Einfügen > Gleichung** eine neue Gleichung ein, statt die vorhandene zu ändern.
