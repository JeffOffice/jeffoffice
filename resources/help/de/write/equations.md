# Gleichungen

Eine **Gleichung** ist eine Zeile mit Mathematik, zum Beispiel ein Bruch oder eine Quadratwurzel. Dieses Thema zeigt, wie Sie eine Gleichung eingeben und in ein Dokument einfügen.

## Gleichung einfügen

1. Setzen Sie die Einfügemarke an die Stelle, an der die Gleichung stehen soll.
2. Klicken Sie auf **Einfügen > Gleichung**, oder drücken Sie **Alt+=**.
3. Geben Sie die Gleichung in einer Zeile ein. Unter dem Feld sehen Sie die Gleichung so gezeichnet, wie sie aussehen wird, und die Textzeile, die die Seite anzeigt. Um von einer bekannten Gleichung auszugehen, wählen Sie im Feld eine Gleichung aus der Liste **Integrierte Gleichungen**. Klicken Sie auf **OK**.

Die Gleichung wird im Dokument in der Standardform für Mathematik gespeichert, damit andere Programme sie öffnen können.

## So geben Sie sie ein

- **Brüche:** Geben Sie einen Schrägstrich ein. `a/b` ist a über b. `(x+1)/(x-1)` fasst jede Gruppe in Klammern als einen Teil auf. `\frac{1}{2}` funktioniert ebenfalls.
- **Potenzen:** Geben Sie ein Dach-Zeichen (^) ein. `x^2` ist x hoch 2. `e^(i*pi)` fasst die Gruppe in Klammern zusammen.
- **Indizes:** Geben Sie einen Unterstrich ein. `x_i` ist x mit einem kleinen i darunter. Sie können beides kombinieren, wie in `x_i^2`.
- **Wurzeln:** Geben Sie `sqrt(x+1)` für eine Quadratwurzel ein. Geben Sie `sqrt[3]{x}` für eine dritte Wurzel ein.
- **Summen, Integrale und Produkte:** Geben Sie `\sum_(i=1)^n i`, `\int_0^1 x` oder `\prod_(k=1)^n k` ein. Der Teil nach dem Unterstrich steht darunter (bei einem Integralzeichen am unteren Ende), der Teil nach dem Dach-Zeichen darüber.
- **Symbole:** Geben Sie einen Backslash und einen Namen ein. `\alpha` ist α, `\pi` ist π, `\infty` ist ∞, `\leq` ist ≤, `\neq` ist ≠, `\times` ist ×, `\pm` ist ±, und `\to` ist →. Etwa 70 Namen funktionieren.
- **Akzente:** `\hat{x}`, `\check{x}`, `\tilde{x}`, `\acute{x}`, `\grave{x}`, `\breve{x}`, `\dot{x}`, `\ddot{x}`, `\bar{x}` und `\vec{v}` setzen ein Zeichen über den Buchstaben. `\overline{ab}` zieht eine Linie über die Gruppe, und `\underline{ab}` zieht eine darunter.
- **Klammern, die mitwachsen:** Geben Sie `\left( ... \right)` ein, dann wachsen die Klammern auf die Höhe des Inhalts zwischen ihnen. Verwenden Sie nach `\left` und `\right` eine beliebige Klammer oder einen Punkt, um eine Seite wegzulassen, wie in `\left[ x \right.`.
- **Matrizen:** Eine **Matrix** ist ein Raster aus Zahlen. Geben Sie `\matrix{a & b \\ c & d}` ein. Setzen Sie ein `&` zwischen die Felder einer Zeile und zwei Backslashes zwischen die Zeilen. Verwenden Sie `\pmatrix` für runde Klammern um das Raster, `\bmatrix` für eckige und `\vmatrix` für gerade Striche.
- **Funktionen:** `sin`, `cos`, `tan`, `log`, `ln`, `exp`, `lim`, `min` und `max` behalten ihre Namen vollständig.

In der Seite zeigt JeffWrite eine Gleichung als eine Textzeile. Die Gleichung in der Datei behält ihre Brüche und Wurzeln, damit andere Programme sie richtig darstellen.

## Integrierte Gleichungen

Klicken Sie auf **Einfügen > Integrierte Gleichungen**, um eine Liste bekannter Gleichungen zu sehen, etwa die quadratische Formel und die Fläche eines Kreises. Klicken Sie auf eine, um sie an der Einfügemarke einzufügen.

## Gleichung ändern

Setzen Sie die Einfügemarke neben eine Gleichung, oder markieren Sie sie, und klicken Sie auf **Einfügen > Gleichung**. Das Feld öffnet sich mit der Gleichung in einer Zeile. Ändern Sie sie, und klicken Sie auf **OK**. Mit einem Schritt können Sie das rückgängig machen.

## Gleichungen in anderen Dokumenten

JeffWrite zeigt die Gleichungen an, die ein Dokument enthält, und behält sie so, wie sie sind. Eine Gleichung, die aus den oben aufgeführten Teilen besteht, kann JeffWrite ändern. Eine Gleichung mit anderen Teilen, etwa Gruppierungszeichen, bleibt unverändert. Wenn Sie in diesem Fall **Einfügen > Gleichung** verwenden, wird eine neue Gleichung eingefügt, statt die vorhandene zu ändern.
