# Inhaltsverzeichnis

Ein **Inhaltsverzeichnis** listet Ihre Überschriften mit der Seite auf, auf der sich jede befindet. JeffWrite erstellt es aus den Absätzen, die die Überschriftenformatvorlagen verwenden.

## Inhaltsverzeichnis einfügen

1. Geben Sie Ihren Überschriften die Formatvorlagen **Überschrift 1**, **Überschrift 2** usw.
2. Klicken Sie an die Stelle, an der das Verzeichnis stehen soll.
3. Klicken Sie auf **Verweise > Inhaltsverzeichnis**.
4. Wählen Sie, wie viele Ebenen angezeigt werden, ob Seitenzahlen erscheinen und rechtsbündig ausgerichtet werden, welche Punkte oder Linien davor stehen (das **Füllzeichen**) und ob jede Zeile ein Link ist. Klicken Sie auf **OK**.

Wenn Sie zum Beispiel 2 Ebenen festlegen und ein Dokument die Überschriften `Einleitung` (Überschrift 1) und `Hintergrund` (Überschrift 2) enthält, erhalten Sie zwei Zeilen mit jeweils einer Seitenzahl, wobei die zweite etwas weiter eingerückt ist.

## Ein fertiges Verzeichnis wählen

Klicken Sie auf den kleinen Pfeil bei **Verweise > Inhaltsverzeichnis**, um den Katalog zu öffnen:

- **Inhalt** zeigt über dem Verzeichnis, das aus Ihren Überschriften erstellt wird, den Titel „Inhalt“.
- **Inhaltsverzeichnis mit vollständigem Titel** zeigt über dem Verzeichnis, das aus Ihren Überschriften erstellt wird, den Titel „Inhaltsverzeichnis“.
- **Inhalt zum Ausfüllen** enthält Zeilen mit Beispieltext, den Sie überschreiben. Es wird nicht automatisch aktualisiert.
- **Inhaltsverzeichnis…** öffnet das oben beschriebene Dialogfeld, damit Sie die Optionen selbst festlegen können.
- **Inhaltsverzeichnis entfernen** löscht das Verzeichnis.

## Eine Zeile für Wörter hinzufügen, die keine Überschrift sind

1. Markieren Sie die Wörter, oder klicken Sie an die Stelle, auf die die Zeile verweisen soll.
2. Klicken Sie auf **Verweise > Eintrag markieren**, oder drücken Sie **Alt+Umschalt+O**.
3. Geben Sie den Text der Zeile ein, wählen Sie ihre Ebene (1 bis 9), und klicken Sie auf **OK**.
4. Wenn Sie das Verzeichnis einfügen, aktivieren Sie **Mit „Eintrag markieren“ markierte Einträge einschließen**.

Mit „Eintrag markieren“ wird ein ausgeblendetes **Verzeichniseintragsfeld** (ein TC-Feld) in Ihren Text eingefügt. Ein Verzeichnis, das Einträge einschließt, listet den Text jedes Feldes auf der Ebene des Feldes, in der Reihenfolge des Textes, mit seiner Seite. Ein Buchstabe im Feld **Verzeichniskennung** erlaubt es, zwei Verzeichnisse getrennt zu halten: Ein Verzeichnis, das den Buchstaben C verlangt, listet nur Einträge auf, die mit C markiert sind. Aktivieren Sie **Seitenzahl weglassen** für eine Zeile, die keine Seitenzahl zeigen soll.

## Einen Absatz in eine Überschrift umwandeln

Klicken Sie in den Absatz, klicken Sie dann auf **Verweise > Text hinzufügen**, und wählen Sie **Ebene 1**, **Ebene 2** oder **Ebene 3**. Der Absatz erhält die Formatvorlage Überschrift 1, 2 oder 3, sodass das Verzeichnis ihn aufführt. **Nicht im Inhaltsverzeichnis anzeigen** weist dem Absatz wieder die übliche Formatvorlage für Fließtext zu.

## Verzeichnis aktualisieren

Klicken Sie in das Verzeichnis, und drücken Sie **F9**, oder klicken Sie auf **Verweise > Verzeichnis aktualisieren**. Wählen Sie:

- **Nur Seitenzahlen aktualisieren**, wenn Sie keine Überschrift geändert haben.
- **Gesamtes Verzeichnis aktualisieren**, wenn Sie Überschriften hinzugefügt, entfernt oder umbenannt haben.

Das Aktualisieren ist ein einziger Schritt, den Sie mit **Rückgängig** zurücknehmen können.

## Ein sehr langes Verzeichnis

Ein Verzeichnis umfasst höchstens 20.000 Zeilen. Wenn Ihr Dokument mehr Überschriften enthält, bricht das Verzeichnis dort ab, und JeffWrite weist Sie beim Erstellen oder Aktualisieren des Verzeichnisses darauf hin.

## Verzeichnis entfernen

Klicken Sie in das Verzeichnis, und klicken Sie auf **Verweise > Inhaltsverzeichnis entfernen**.

## Einer Zeile folgen

Wenn die Zeilen Links sind, halten Sie **Strg** gedrückt und klicken Sie auf eine Zeile, um zu ihrer Überschrift zu gelangen.

## Das Aussehen der Zeilen ändern

Die Zeilen verwenden die Formatvorlagen **Verzeichnis 1** bis **Verzeichnis 9**. Ändern Sie eine davon im Bereich „Formatvorlagen“, und aktualisieren Sie danach das gesamte Verzeichnis.
