## Links

Ein **Link** (auch Hyperlink genannt) ist ein Text, der Sie an eine andere Stelle bringt, wenn Sie ihn mit Strg+Klick anklicken. Er kann auf eine Webadresse, auf eine E-Mail-Adresse, auf eine Überschrift oder eine **Textmarke** im selben Dokument, auf eine Datei auf Ihrem Computer oder auf ein neues Dokument verweisen, das JeffWrite für Sie erstellt.

1. Markieren Sie die Wörter, die der Link werden sollen. Oder markieren Sie nichts, und geben Sie die Wörter im Feld **Anzuzeigender Text** ein.
2. Drücken Sie **Strg+K**, oder wählen Sie **Einfügen > Link**.
3. Wählen Sie unter **Link zu** aus, wohin der Link führen soll:
   - **Webadresse:** Geben Sie die Adresse ein. „https://“ können Sie weglassen: JeffWrite ergänzt es.
   - **E-Mail-Adresse:** Geben Sie die Adresse ein. „mailto:“ wird für Sie ergänzt.
   - **Position in diesem Dokument:** Wählen Sie in der Liste eine Überschrift oder eine Textmarke aus. Eine Überschrift erhält eine eigene, ausgeblendete Textmarke, sodass der Link auch nach dem Speichern und erneuten Öffnen des Dokuments funktioniert, bei jedem Dateityp. Die Liste zeigt Ihre Textmarken und Überschriften. (Um eine Textmarke zu setzen, verwenden Sie **Einfügen > Textmarke**.)
   - **Vorhandene Datei:** Geben Sie den vollständigen Pfad einer Datei auf Ihrem Computer ein, oder klicken Sie auf **Durchsuchen**.
   - **Neues Dokument:** Geben Sie den vollständigen Pfad für ein neues, leeres Dokument ein, das auf .docx oder .odt endet, oder klicken Sie auf **Durchsuchen**. JeffWrite erstellt das Dokument dort und verknüpft es. Eine bereits vorhandene Datei wird niemals überschrieben.
4. Geben Sie bei Bedarf eine **QuickInfo** ein. Sie erscheint als kleiner Hinweis, wenn der Mauszeiger auf dem Link ruht.
5. Klicken Sie auf **OK**. Ist die Adresse für JeffWrite nicht verwendbar, bleibt das Fenster geöffnet und zeigt den Grund an.

Die Wörter erhalten das Linkformat (blau und unterstrichen). Rückgängig machen können Sie das mit einem Schritt.

Um einen Link zu **ändern**, setzen Sie die Einfügemarke in den Link und drücken erneut Strg+K. **Link entfernen** in diesem Fenster oder **Einfügen > Link entfernen** hebt den Link auf und behält die Wörter.

Mit **Strg+Klick** auf einen Link folgen Sie ihm. Ein Link zu einer Textmarke setzt die Einfügemarke dorthin. Ein Link zu einer Webadresse oder E-Mail-Adresse öffnet Ihren Browser bzw. Ihr E-Mail-Programm. Bei einem Link zu einer Datei fragt JeffWrite zuerst nach und öffnet die Datei dann mit dem zugehörigen Programm. Zu Ihrer Sicherheit folgt JeffWrite nur Web-, E-Mail-, FTP-, Telefon- und Dateilinks. Ein Dateilink muss den vollständigen Pfad einer Datei auf Ihrem Computer angeben, und die Datei muss ein Dokument oder ein Bild sein (etwa .docx, .odt, .pdf, .txt, .xlsx, .pptx, .png oder .jpg). Ein Link zu einem Programm, zu einem Skript, zu einer Datei auf einem anderen Computer oder zu einem unvollständigen Pfad wird niemals geöffnet. JeffWrite sucht die Datei auch nicht, bevor nachgefragt wird.

## Text aus einer Datei

**Einfügen > Text aus Datei** fügt den Text einer anderen Datei an der Stelle ein, an der sich die Einfügemarke befindet. Es kann sich um ein Dokument (.docx, .doc, .rtf oder .odt) oder um eine Nur-Text-Datei handeln. Ein Dokument behält seine Schriftarten, Formatvorlagen, Bilder und Links. In einer Nur-Text-Datei wird jede Zeile zu einem Absatz. Eine Datei darf bis zu 64 Megabyte groß sein. Rückgängig machen können Sie das mit einem Schritt.
