## Links

Ein **Link** (auch Hyperlink genannt) ist Text, der Sie an eine andere Stelle bringt, wenn Sie ihn mit Strg+Klick anklicken. Er kann auf eine Webadresse, auf eine E-Mail-Adresse oder auf eine **Textmarke** im selben Dokument verweisen.

1. Markieren Sie die Wörter, die der Link werden sollen. Oder markieren Sie nichts, und geben Sie die Wörter im Feld **Anzuzeigender Text** ein.
2. Drücken Sie **Strg+K**, oder wählen Sie **Einfügen > Link**.
3. Wählen Sie **Web- oder E-Mail-Adresse**, und geben Sie die Adresse ein. Sie können „https://“ weglassen: JeffWrite ergänzt es. Vor einer E-Mail-Adresse wird „mailto:“ ergänzt. Oder wählen Sie **Aktuelles Dokument**, und wählen Sie eine Textmarke aus. (Um eine Textmarke zu setzen, verwenden Sie **Einfügen > Textmarke**.)
4. Geben Sie bei Bedarf eine **QuickInfo** ein. Das ist der kleine Hinweis, der angezeigt wird, wenn der Zeiger auf dem Link verweilt.
5. Klicken Sie auf **OK**. Wenn die Adresse von JeffWrite nicht verwendet werden kann, bleibt das Fenster geöffnet und zeigt den Grund an.

Die Wörter erhalten das Linkformat (blau und unterstrichen). Das Einfügen lässt sich mit einem Schritt rückgängig machen.

Um einen Link zu **ändern**, setzen Sie die Einfügemarke in den Link, und drücken Sie erneut Strg+K. **Link entfernen** in diesem Fenster oder **Einfügen > Link entfernen** nimmt den Link weg und behält die Wörter bei.

**Strg+Klick** auf einen Link folgt ihm. Ein Link auf eine Textmarke setzt die Einfügemarke dorthin. Ein Link auf eine Web- oder E-Mail-Adresse öffnet Ihren Browser oder Ihr E-Mail-Programm. Aus Sicherheitsgründen folgt JeffWrite nur Web-, E-Mail-, FTP- und Telefonlinks. Ein Link startet nie ein Programm und öffnet nie eine Datei.

## Text aus einer Datei

**Einfügen > Text aus Datei** fügt den Text einer anderen Datei an der Stelle der Einfügemarke in Ihr Dokument ein. Es kann sich um ein Dokument (.docx, .doc, .rtf oder .odt) oder um eine Textdatei ohne Formatierung handeln. Ein Dokument behält seine Schriftarten, Formatvorlagen, Bilder und Links. Bei einer Textdatei ohne Formatierung wird jede Zeile zu einem Absatz. Eine Datei darf bis zu 64 MB groß sein. Das Einfügen lässt sich mit einem Schritt rückgängig machen.
