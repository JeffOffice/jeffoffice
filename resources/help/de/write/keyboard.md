# Mit der Tastatur in JeffWrite arbeiten
<!-- keywords: Tastatur, Tastenkombinationen, Tastenkürzel, Tasten, Hotkeys, Zugriffstasten, Strg, Alt, navigieren, bewegen, auswählen, Einfügemarke, Cursor, Tastatur anpassen, Tastenkürzel ändern, Tasten neu zuweisen, Tasten zurücksetzen, Taste für eine Formatvorlage, Taste für ein Sonderzeichen -->

Sie können in JeffWrite alles mit der Tastatur erledigen. Diese Seite listet die Tasten auf.

## Bewegen und auswählen

- **Pfeiltasten** bewegen die Einfügemarke. Die **Einfügemarke** ist der blinkende Strich, der zeigt, wohin die Eingabe geht.
- **Strg+Links** und **Strg+Rechts** bewegen um ein Wort.
- **Pos1** und **Ende** bewegen zum Anfang und Ende einer Zeile. **Strg+Pos1** und **Strg+Ende** bewegen zum Anfang und Ende des Dokuments.
- **Bild auf** und **Bild ab** bewegen um einen Fensterausschnitt Text.
- Halten Sie **Umschalt** gedrückt, während Sie eine dieser Tasten verwenden, um Text beim Bewegen auszuwählen.
- **Strg+A** wählt alles aus.

## Eingeben und löschen

- **Eingabe** beginnt einen neuen Absatz. **Umschalt+Eingabe** beginnt eine neue Zeile im selben Absatz.
- **Strg+Eingabe** beginnt eine neue Seite.
- **Esc** schließt eine Kopf- oder Fußzeile, die Sie bearbeiten, und verlässt eine Fußnote, die Sie bearbeiten, zurück zum Text.
- **Tab** fügt einen Tabstopp ein. In einer Liste rückt er das Element um eine Ebene tiefer ein. **Umschalt+Tab** rückt es um eine Ebene weniger tief ein.
- **Rücktaste** und **Entf** löschen Text. Halten Sie **Strg** gedrückt, um ein Wort zu löschen.

## Zum Menüband wechseln

Drücken Sie **Alt**, um auf jeder Registerkarte einen Buchstaben anzuzeigen. Drücken Sie den Buchstaben, um die Registerkarte zu öffnen, und dann die Buchstaben, die erscheinen, um eine Schaltfläche zu erreichen. Drücken Sie **Esc**, um einen Schritt zurückzugehen. Mit **F6** wechselt die Tastatur zwischen dem Menüband und der Seite.

## Eigene Tastenkombinationen festlegen

Sie können die Tasten jedes Befehls ändern oder einem Befehl, der keine hat, eine Taste zuweisen. Klicken Sie auf **Datei > Optionen** und dann auf die Registerkarte **Anpassen**.

1. Geben Sie im Feld **Suchen** den Namen oder die Tasten eines Befehls ein. Die Liste ist nach den Registerkarten des Menübands gruppiert, und jeder Befehl zeigt seine Tasten an. Befehle, die nicht im Menüband stehen, sind unter **Sonstige** aufgeführt.
2. Klicken Sie auf den Befehl. Seine Tasten werden unter **Tasten für diesen Befehl** aufgelistet.
3. Klicken Sie in das Feld **Neue Tasten drücken** und drücken Sie die gewünschten Tasten, zum Beispiel **Strg+Umschalt+B**. Klicken Sie dann auf **Zuweisen**. Ein Befehl kann bis zu vier Tasten haben.
4. Um eine Taste zu entfernen, klicken Sie sie in der Liste an und klicken Sie auf **Entfernen**.

Wenn ein anderer Befehl bereits die gedrückten Tasten hat, zeigt JeffWrite an, welcher es ist. Klicken Sie auf **Übernehmen**, um die Tasten diesem Befehl zu geben; der andere Befehl verliert sie dann. Erst wenn Sie auf **OK** klicken, ändert sich etwas. Danach verwenden alle geöffneten JeffWrite-Fenster Ihre Tasten, ebenso jedes Fenster, das Sie später öffnen. QuickInfos, Menüs und die Tabelle der Tastenkombinationen unten zeigen Ihre Tasten an.

**Einzeln zurücksetzen** stellt die üblichen Tasten des gewählten Befehls wieder her. **Alle zurücksetzen** stellt die üblichen Tasten aller Befehle wieder her. JeffWrite speichert nur die Befehle, deren Tasten Sie geändert haben. Ein Befehl, den Sie nie geändert haben, erhält daher bessere Tasten, die eine spätere Version ihm zuweist.

### Tasten für Formatvorlagen und Sonderzeichen

Sie können einer Formatvorlage eine Taste geben, sodass das Drücken sie dem Absatz oder den markierten Zeichen zuweist, und einem Sonderzeichen, sodass das Drücken es einfügt. Unter der Liste auf der Seite **Tastatur** finden Sie drei Schaltflächen.

- **Formatvorlage hinzufügen** listet die Formatvorlagen Ihres Dokuments und die integrierten Formatvorlagen auf. Wählen Sie eine aus, und sie wird der Gruppe **Formatvorlagen** hinzugefügt.
- **Sonderzeichen hinzufügen** öffnet das Dialogfeld **Symbol**. Wählen Sie ein Zeichen, klicken Sie auf **Einfügen** und dann auf **Schließen**. Das Zeichen wird der Gruppe **Sonderzeichen** hinzugefügt, mit der Schriftart, die Sie im Dialogfeld gewählt haben, sofern es sich nicht um normalen Text handelt.
- **Sonderzeichen per Code hinzufügen** dient für ein Zeichen, das das Dialogfeld nicht anzeigt. Geben Sie seinen Unicode-Code in Hexadezimal ein, zum Beispiel **1F600**.

Klicken Sie dann auf den neuen Eintrag und weisen Sie ihm Tasten zu wie bei jedem anderen Befehl. Diese Einträge stehen in eigenen Gruppen am Ende der Liste. Für eine Formatvorlage oder ein Sonderzeichen gelten dieselben Regeln wie für jede andere Taste: Sie können übernommen, entfernt und mit **Einzeln zurücksetzen** und **Alle zurücksetzen** wiederhergestellt werden.

Eine Formatvorlagentaste sucht ihre Formatvorlage bei jedem Drücken anhand des Namens, und es spielt keine Rolle, ob der Name in Großbuchstaben geschrieben ist. Wenn Ihr Dokument keine Formatvorlage dieses Namens hat, diese aber eine der integrierten Formatvorlagen ist, wird die Formatvorlage dem Dokument hinzugefügt, genau wie beim Klicken im Bereich **Formatvorlagen**. Gibt es keine solche Formatvorlage, meldet JeffWrite dies in der Statusleiste und ändert nichts. Wenn Sie eine Formatvorlage umbenennen, funktioniert eine Taste, die Sie ihr unter dem alten Namen gegeben haben, nicht mehr, und die Seite **Tastatur** zeigt hinter dem Namen „(keine solche Formatvorlage)“ an. Fügen Sie die Formatvorlage unter ihrem neuen Namen erneut hinzu und weisen Sie ihr die Taste zu. Tasten für Bausteine sind noch nicht verfügbar.

Einige Tasten können keinem Befehl zugewiesen werden, weil das System oder die Texteingabe sie benötigt. JeffWrite meldet **reserviert**, wenn Sie eine davon drücken. Reserviert sind **Strg+C**, **Strg+X**, **Strg+V**, **Strg+Z**, **Strg+A**, **Tab**, **Umschalt+Tab**, **Eingabe**, **Esc**, **Rücktaste**, **Entf**, **Alt+F4**, die Pfeiltasten, **Pos1**, **Ende**, **Bild auf**, **Bild ab** und die **Leertaste**, **F1**, **F6**, **Umschalt+F6**, **Strg+Y**, **Strg+Umschalt+Z**, **Strg** mit einer Pfeiltaste, **Pos1**, **Ende**, **Rücktaste** oder **Entf** (mit oder ohne **Umschalt**, wo das in einem Textfeld sinnvoll ist) sowie eine Buchstaben-, Ziffern- oder Symboltaste allein oder mit **Umschalt**. Eine Taste, die ein anderer Teil des Fensters bereits verwendet, ist ebenfalls reserviert. **Speichern**, **Rückgängig** und **Wiederholen** behalten immer mindestens eine Taste. Auf dem Mac bezeichnet **Strg** hier die Taste **Befehl**.
