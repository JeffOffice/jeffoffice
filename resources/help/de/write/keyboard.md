# JeffWrite mit der Tastatur bedienen
<!-- keywords: Tastatur, Tastenkombinationen, Tastenkürzel, Shortcuts, Tasten, Hotkeys, Zugriffstasteninfos, Strg, Alt, navigieren, bewegen, verschieben, markieren, auswählen, Einfügemarke, Cursor -->

Sie können in JeffWrite alles mit der Tastatur erledigen. Auf dieser Seite sind die Tasten aufgeführt.

## Bewegen und markieren

- Die **Pfeiltasten** bewegen die Einfügemarke. Die **Einfügemarke** ist die blinkende Linie, die anzeigt, wo der eingegebene Text erscheint.
- **Strg+Nach-links** und **Strg+Nach-rechts** springen um ein Wort weiter.
- **Pos1** und **Ende** springen an den Anfang bzw. das Ende einer Zeile. **Strg+Pos1** und **Strg+Ende** springen an den Anfang bzw. das Ende des Dokuments.
- **Bild-auf** und **Bild-ab** blättern um eine Fensterhöhe weiter.
- Halten Sie bei einer dieser Tasten zusätzlich die **Umschalttaste** gedrückt, um beim Bewegen Text zu markieren.
- **Strg+A** markiert alles.

## Eingeben und löschen

- Die **Eingabetaste** beginnt einen neuen Absatz. **Umschalt+Eingabe** beginnt eine neue Zeile im selben Absatz.
- **Strg+Eingabe** beginnt eine neue Seite.
- **Esc** schließt eine Kopf- oder Fußzeile, die Sie gerade bearbeiten, und kehrt von einer Fußnote, die Sie gerade bearbeiten, zum Text zurück.
- Die **Tabulatortaste** fügt ein Tabulatorzeichen ein. In einer Liste stuft sie das Element um eine Ebene tiefer. **Umschalt+Tab** stuft es um eine Ebene höher.
- Die **Rücktaste** und **Entf** löschen Text. Halten Sie zusätzlich **Strg** gedrückt, um ein ganzes Wort zu löschen.

## Das Menüband erreichen

Drücken Sie **Alt**, um auf jeder Registerkarte einen Buchstaben anzuzeigen. Drücken Sie den Buchstaben, um die Registerkarte zu öffnen, und dann die angezeigten Buchstaben, um eine Schaltfläche zu erreichen. Mit **Esc** gehen Sie einen Schritt zurück. **F6** wechselt mit der Tastatur zwischen dem Menüband und der Seite.
