Diese Werkzeuge finden Sie auf der Registerkarte **Start**. Sie wirken auf den markierten Text.

## Groß-/Kleinschreibung von Buchstaben ändern

Die **Schreibweise** eines Buchstabens gibt an, ob er ein Großbuchstabe (A) oder ein Kleinbuchstabe (a) ist.

1. Markieren Sie den Text. Ohne Markierung ändert JeffWrite das Wort, in dem sich der Cursor befindet.
2. Klicken Sie in der Gruppe **Schriftart** auf **Groß-/Kleinschreibung**.
3. Wählen Sie eine Option:
   - **Satzbeginn groß** schreibt den ersten Buchstaben jedes Satzes groß. Der Rest bleibt klein.
   - **kleinbuchstaben** schreibt alle Buchstaben klein.
   - **GROSSBUCHSTABEN** schreibt alle Buchstaben groß.
   - **Wörter groß schreiben** schreibt den ersten Buchstaben jedes Wortes groß.
   - **gROSS-/kLEINSCHREIBUNG uMKEHREN** wandelt jeden Großbuchstaben in einen Kleinbuchstaben um und jeden Kleinbuchstaben in einen Großbuchstaben.

Mit **Umschalt+F3** wechseln Sie nacheinander durch drei dieser Optionen: **Wörter groß schreiben**, dann **GROSSBUCHSTABEN**, dann **kleinbuchstaben**.

Die Gestaltung der Buchstaben bleibt gleich. Fett bleibt fett. Mit **Strg+Z** machen Sie die Änderung in einem Schritt rückgängig. Ist **Änderungen nachverfolgen** aktiv, erscheint die Änderung als Löschung und Einfügung.

## Absätze sortieren

Sortieren bringt Absätze in eine Reihenfolge, etwa von A bis Z. Verwenden Sie es für eine Liste von Namen oder für Zeilen einer Tabelle, die mit Tabulatoren oder Kommas aufgebaut ist.

1. Markieren Sie zwei oder mehr Absätze.
2. Klicken Sie in der Gruppe **Absatz** auf **Sortieren**.
3. Wählen Sie, wonach sortiert werden soll. Jede Auswahl hat ein **Feld**, einen **Typ** und eine **Reihenfolge**.
   - Das **Feld** ist ein Teil des Absatzes. Feld 1 ist der erste Teil. Sind die Teile durch Kommas oder Tabulatoren getrennt, legen Sie das im Feld unter den Schlüsseln fest. Belassen Sie es bei **Absätze**, ist der ganze Absatz das eine Feld.
   - Der **Typ** ist **Text**, **Zahl** oder **Datum**. Eine Zahl wird nach ihrem Wert sortiert, also kommt 9 vor 10.
   - Die **Reihenfolge** ist **Aufsteigend** (A bis Z, klein bis groß, alt bis neu) oder **Absteigend**.
4. Verwenden Sie **Dann nach**, um Gleichstände aufzulösen.
5. Aktivieren Sie **Der erste Absatz ist eine Überschrift**, damit er an seiner Stelle bleibt.
6. Klicken Sie auf **OK**.

Jede Stelle behält ihr eigenes Absatzformat. Sortieren ist nicht möglich, solange **Änderungen nachverfolgen** aktiv ist, weil eine Sortierung nicht als Änderung angezeigt werden kann. Schalten Sie die Änderungsnachverfolgung aus, sortieren Sie und schalten Sie sie danach wieder ein.

## Auf andere Weise einfügen

Klicken Sie auf den kleinen Pfeil unter **Einfügen**, um weitere Möglichkeiten zu sehen:

- Stammt der Text aus einem anderen Programm, das formatierten Text (RTF) in die Zwischenablage legt, bleibt beim Drücken von **Strg+V** sein Aussehen erhalten: Schriftarten, Größen, Farben, Fett, Listen, Tabellen, Links und Bilder. Hat das Programm keinen formatierten Text geliefert, verwendet JeffWrite die Webseitenform (HTML) und danach den reinen Text. Formatierter Text über 16 MB wird nicht gelesen; das Einfügen verwendet dann die nächste Form. Ziehen Sie formatierten Text aus einem anderen Programm auf die Seite, geschieht dasselbe.
- **Formatierung zusammenführen** fügt den Text im Aussehen der Stelle ein, an die er kommt. Nur Fett, Kursiv, Unterstreichung und Durchstreichung bleiben erhalten.
- **Nur Text beibehalten** fügt die Wörter ohne jede Formatierung ein.
- **Bild** fügt ein Bild aus der Zwischenablage ein. Die Schaltfläche ist abgeblendet, wenn die Zwischenablage kein Bild enthält.
- **Inhalte einfügen** (**Strg+Alt+V**) listet alle Arten auf, in denen die Zwischenablage jetzt eingefügt werden kann, und lässt Sie eine auswählen, etwa **Formatierter Text (RTF)**, **Unformatierter Text** oder **HTML**.

Eine Auswahl ist abgeblendet, wenn die Zwischenablage nichts enthält, was sie verwenden kann.

Direkt nach dem Einfügen erscheint neben dem Cursor eine kleine Schaltfläche **Einfügeoptionen**. Klicken Sie darauf, um **Quellformatierung beibehalten**, **Formatierung zusammenführen** oder **Nur Text beibehalten** zu wählen. JeffWrite nimmt das Einfügen zurück und führt es erneut auf diese Weise aus. Die Änderung ist ein Schritt: Ein einziges **Rückgängig** nimmt das gesamte Einfügen zurück, egal wie oft Sie Ihre Meinung geändert haben. Über die Tastatur tippen Sie nach einem Einfügen auf die Taste **Strg** (auf dem Mac die Taste **Control**), um das Menü der Schaltfläche zu öffnen. Dann wählen Sie mit den Pfeiltasten und **Eingabe**. Die Schaltfläche verschwindet, sobald Sie etwas eingeben, den Cursor bewegen oder **Esc** drücken. Sie wird in einem Dokument, das Sie nicht ändern dürfen, nicht angeboten.

**Standardeinfügen festlegen** finden Sie auf der Seite **Erweitert** unter **Optionen**. Dort gibt es ein Feld für das Einfügen innerhalb desselben Dokuments, eines für das Einfügen zwischen Dokumenten und eines für das Einfügen aus anderen Programmen. Jedes kann auf **Quellformatierung beibehalten** (wie bisher), **Formatierung zusammenführen** oder **Nur Text beibehalten** gesetzt werden. **Einfügen** (**{key:Paste}**) tut dann, was für den Ort festgelegt ist, von dem der Inhalt stammt. Beispiel: Stellen Sie das Einfügen aus anderen Programmen auf **Nur Text beibehalten**, dann übernehmen Wörter, die von einer Webseite kopiert wurden, die Formatierung der Stelle, an die sie kommen. Mit der Schaltfläche **Einfügeoptionen** können Sie für jedes einzelne Einfügen trotzdem eine andere Form wählen.

Bringt das Einfügen Listenabsätze neben eine Liste, bietet die Schaltfläche außerdem **Liste fortsetzen** (die Nummern laufen weiter von der Liste daneben), **Neue Liste** (die Nummerierung beginnt wieder bei 1) und **Liste zusammenführen** (die Elemente werden in die Liste daneben aufgenommen und übernehmen deren Aussehen). Ein einfaches **Strg+V** fügt die Elemente so ein, wie sie kopiert wurden, und eine Auswahl ändert das. Dieselben Auswahlmöglichkeiten gibt es als Befehle im Menü **Einfügen** auf der Registerkarte **Start** und unter **Inhalte einfügen**, sodass Sie sie auch über die Tastatur erreichen.

Enthält die Zwischenablage Tabellenkalkulationszellen (aus JeffCrunch oder einem anderen Programm als Tabelle oder als Zeilen mit Tabulatoren zwischen den Zellen kopiert), fügt ein einfaches **Strg+V** sie als Wörter ein, wie sie sind. Um sie als Zellen einzufügen, wählen Sie **Tabelle** über die Schaltfläche, das Menü **Einfügen** oder **Inhalte einfügen**. Steht der Cursor in einer Tabelle, bietet die Schaltfläche **Tabelle verschachteln** (eine Tabelle in der Zelle), **Tabelle zusammenführen** (die Zellen werden Teil der Tabelle, die dafür die nötigen Spalten erhält), **Als neue Zeilen einfügen**, **Als neue Spalten einfügen** (die Zellen kommen in neue Spalten nach der Zelle des Cursors, ab dessen Zeile nach unten; eine Tabelle kann höchstens 256 Spalten und 50.000 Zellen haben, und das Einfügen wird mit einer Meldung abgelehnt, wenn eine verbundene Zelle über den Platz für die Spalten hinausreicht) und **Zellen überschreiben** (die Zellen ersetzen die Zellen der Tabelle ab der Zelle des Cursors). Eine eingefügte Tabelle hat höchstens 500 Zeilen und 63 Spalten, und eine Zelle enthält höchstens 4.000 Zeichen. Was darüber hinausgeht, wird weggelassen, und eine Meldung weist darauf hin. Eine Tabelle in einer Tabelle darf höchstens 8 Ebenen tief sein, und eine verschachtelte Tabelle, deren Spalten in der Zelle zu schmal würden, wird abgelehnt. Jedes Einfügen ist ein Schritt: **Rückgängig** nimmt alles zurück, und **Wiederholen** stellt es wieder her.

**Intelligentes Ausschneiden und Einfügen** sorgt beim Verschieben von Wörtern für die richtigen Leerzeichen. Schneiden Sie ganze Wörter zwischen zwei Leerzeichen aus, nimmt JeffWrite eines der Leerzeichen mit, sodass kein doppeltes Leerzeichen bleibt. Fügen Sie ein Wort direkt an ein anderes Wort an, setzt JeffWrite ein Leerzeichen dazwischen. Die Mitte eines Wortes bleibt unverändert. Zum Ausschalten klicken Sie auf **Datei > Optionen > Erweitert** und deaktivieren **Intelligentes Ausschneiden und Einfügen**.

## Zeilen- und Seitenumbrüche sowie Tabulatoren

Klicken Sie auf die kleine Schaltfläche in der Ecke der Gruppe **Absatz**, um das Feld **Absatz** zu öffnen. Unter den Abstandsoptionen finden Sie diese:

- **Hurenkinder und Schusterjungen verhindern** verhindert, dass eine einzelne Zeile eines Absatzes allein oben oder unten auf einer Seite steht.
- **Mit nächstem Absatz** hält den Absatz auf derselben Seite wie den folgenden. Verwenden Sie es für eine Überschrift.
- **Zeilen zusammenhalten** hält alle Zeilen des Absatzes auf einer Seite.
- **Zeilennummern unterdrücken** nimmt diesen Absatz von der Zeilennummerierung aus, wenn die Zeilen einer Seite nummeriert werden (siehe Layout > Zeilennummern).
- **Seitenwechsel davor** beginnt den Absatz auf einer neuen Seite.
- **Nicht silbentrennen** verhindert, dass die Wörter des Absatzes am Zeilenende mit einem Bindestrich getrennt werden.
- **Kein Abstand zwischen Absätzen derselben Formatvorlage** entfernt den Abstand zwischen zwei Absätzen mit derselben Formatvorlage.
- **Gliederungsebene** legt fest, wo der Absatz in der Gliederung des Dokuments steht: **Fließtext** oder eine Ebene von 1 bis 9.

Klicken Sie im Feld auf **Tabstopps**, um Tabstopps festzulegen. Ein Tabstopp ist die Stelle, zu der der Text springt, wenn Sie **Tab** drücken. Geben Sie seine Position ein, wählen Sie, wie der Text dort ausgerichtet wird (links, zentriert, rechts oder dezimal), und wählen Sie ein Füllzeichen. Ein Füllzeichen ist die Reihe aus Punkten, Strichen oder eine Linie, die den Platz vor dem Tabstopp füllt. Klicken Sie auf **Festlegen**, um ihn hinzuzufügen. Zum Entfernen wählen Sie ihn in der Liste und klicken auf **Löschen**. **Alle löschen** entfernt alle.

Wählen Sie **Balken**, um einen Balkentabstopp zu setzen. Ein Balkentabstopp hält den Text nicht an. Er zeichnet an dieser Stelle in jeder Zeile des Absatzes einen dünnen senkrechten Strich. So setzen Sie eine Trennlinie zwischen Textspalten. Ein Balken hat kein Füllzeichen. Das Lineal zeigt Balken nicht an. Ein Absatz kann bis zu 64 davon haben. Noch nicht unterstützt: In einem Absatz, der von rechts nach links gelesen wird, werden Balken weiterhin vom linken Rand aus gemessen. Festlegen und Löschen tun Sie im Feld **Tabstopps**.

**Standardtabstopps** ist der Abstand zwischen den Tabstopps, den ein Absatz erhält, wenn er keine eigenen hat, und der nach dem letzten eigenen Tabstopp gilt. Üblich sind 1,3 cm. Diese Einstellung gilt für das gesamte Dokument, nicht nur für den Absatz, in dem Sie sich befinden. Der neue Abstand gilt für jeden Absatz, sobald Sie auf **OK** klicken.

## Rahmen und Schattierung für Absätze

Markieren Sie einen oder mehrere Absätze. In der Gruppe **Absatz** bietet die Schaltfläche **Rahmen** die schnellen Auswahlen: **Unterer Rahmen**, **Oberer Rahmen**, **Linker Rahmen**, **Rechter Rahmen**, **Alle Rahmenlinien** und **Kein Rahmen**. Eine schnelle Auswahl zeichnet eine einzelne Linie mit 0,018 cm Stärke, etwa 0,035 cm vom Text entfernt. Eine Auswahl für eine Seite lässt die übrigen Seiten, wie sie waren.

**Rahmen und Schattierung** am Ende dieser Liste öffnet ein Feld. Aktivieren Sie die Seiten, die eine Linie erhalten, oder klicken Sie auf **Box** oder **Keine**. Aktivieren Sie **Zwischen**, um zwischen den markierten Absätzen mit denselben Rahmen eine Linie einzufügen. Dann wählen Sie die **Art** (einfach, doppelt, dick, punktiert, gestrichelt, kurze Striche, Strich-Punkt oder Strich-Punkt-Punkt), die **Breite**, die **Farbe** und den **Abstand zum Text**. **Schattierung** füllt die Absätze mit einer Farbe. Die Schaltfläche **Schattierung** neben **Rahmen** legt nur die Füllung fest, und zwar mit denselben Farben wie **Schriftfarbe**.

Linien und Füllung bilden einen Schritt, den **Rückgängig** zurücknimmt. Beim Speichern als .docx- oder .odt-Datei bleiben sie erhalten. Stammt ein Absatz aus einer Datei mit eigenem Rahmen oder eigener Füllung, ersetzt Ihre Auswahl diese.

## Horizontale Linie einfügen

Klicken Sie in der Gruppe **Absatz** auf **Horizontale Linie**. JeffWrite fügt nach dem Absatz, in dem der Cursor steht, einen eigenen Absatz mit einer dünnen Linie darunter ein. Der Cursor springt zu einem einfachen Absatz unter der Linie. Zum Entfernen der Linie markieren Sie ihren Absatz und löschen ihn.

## Festlegungen an der Cursorposition anzeigen

Drücken Sie **Umschalt+F1** oder verwenden Sie **Formatierung anzeigen**. Ein Feld listet an der Cursorposition die Formatvorlagen, die Schriftart, die Schriftgröße, die Gestaltung der Buchstaben, die Farbe sowie die Ausrichtung, Einzüge und Abstände des Absatzes auf. Es zeigt die Formatierung nur an. Zum Ändern verwenden Sie die Felder **Schriftart** und **Absatz**.

## Der Bereich Zwischenablage

Der Bereich **Zwischenablage** merkt sich die letzten 24 Elemente, die Sie in diesem Programmfenster kopiert oder ausgeschnitten haben. So können Sie ein älteres Element einfügen, ohne es erneut zu kopieren. Klicken Sie auf den kleinen Pfeil in der Ecke der Gruppe **Zwischenablage** auf der Registerkarte **Start** (oder drücken Sie **Alt**, dann **H**, dann **FO**), um ihn zu öffnen. Neben der Seite erscheint ein Bereich.

Jedes Element zeigt eine kleine Vorschau und die Art des Inhalts: Text, formatierter Text, Zellen, ein Bild, Formen oder Folien. Das neueste steht oben. Klicken Sie auf ein Element, um es dort einzufügen, wo der Cursor oder die Markierung steht. Es wird wie jedes andere Einfügen eingefügt: Ein Schritt von **Rückgängig** nimmt es zurück, und die Schaltfläche **Einfügeoptionen** erscheint wie üblich.

- **Alle einfügen** fügt alle Elemente ein, das älteste zuerst, damit sie in der Reihenfolge stehen, in der Sie sie kopiert haben.
- **Löschen** entfernt das gewählte Element. **Alle löschen** entfernt alle.
- Der Bereich sammelt nur, solange er geöffnet ist. Damit er auch nach dem Schließen weiter sammelt, aktivieren Sie **Auch nach dem Schließen dieses Bereichs weiter sammeln**. Die Einstellung wird gespeichert, und das Sammeln beginnt beim Start des Programms, noch bevor Sie den Bereich öffnen.
- Um auch Kopiertes aus anderen Programmen zu sammeln, aktivieren Sie **Auch Inhalte sammeln, die in anderen Programmen kopiert werden**. Es werden nur reiner Text und Bilder gespeichert, und die Einstellung ist bei jedem Start des Programms wieder aus. Ist sie aktiv, wird eine Kopie aus einem anderen Programm vollständig gelesen, bevor dieses Programm entscheidet, ob es sie behält. Eine sehr große Kopie kann das Programm daher kurz anhalten und so viel Arbeitsspeicher belegen, wie die Kopie groß ist. Gelesen wird nur eine Form: ihr Text, wenn sie Text enthält, andernfalls ein Bild. Ist die Einstellung aus, wird nichts gelesen, was in anderen Programmen kopiert wurde.

Die Elemente werden nur im Arbeitsspeicher des Programms gehalten. Nichts wird in einer Datei gespeichert, und die Liste wird geleert, wenn Sie das letzte Fenster des Programms schließen. Ein Element bleibt in der Liste, auch nachdem das Dokument, aus dem es stammt, geschlossen wurde. Ein Element, das größer als 8 MB ist, wird nicht behalten. Der Bereich teilt Ihnen das mit. Ein Bild zählt 4 Byte je Bildpunkt (Pixel), daher ist ein Bild mit mehr als etwa 2 Millionen Pixeln zu groß. Alle Elemente zusammen sind auf 64 MB begrenzt, und die ältesten fliegen zuerst hinaus. Was ein Kennwortmanager als geheim kennzeichnet, wird nie behalten.
