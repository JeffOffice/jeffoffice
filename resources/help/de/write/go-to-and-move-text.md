# Zu einer Stelle springen und Text verschieben

## Zu einer Stelle springen

Drücken Sie **Strg+G**, oder klicken Sie auf **Start > Bearbeiten > Gehe zu**. Das Dialogfeld **Gehe zu** wird geöffnet.

1. Wählen Sie unter **Gehe zu** die Option **Seite**, **Abschnitt**, **Zeile**, **Textmarke**, **Fußnote** oder **Überschrift** aus.
2. Geben Sie eine Nummer oder einen Namen ein. Bei einer Textmarke, einer Fußnote oder einer Überschrift können Sie stattdessen auch einen Eintrag aus der Liste unter dem Feld auswählen.
3. Klicken Sie auf **Gehe zu**. Der Cursor springt an diese Stelle, und die Ansicht wird so verschoben, dass die Stelle sichtbar ist.

Hinweise zu den einzelnen Arten:

- **Seite**, **Abschnitt**, **Fußnote** und **Überschrift** erwarten eine Nummer: 3 springt zum dritten Element. Stellen Sie ein **+** oder **-** voran, um ab der Cursorposition zu zählen: **+1** springt zum nächsten Element, **-1** zum vorherigen.
- **Zeile** erwartet eine Nummer, gezählt vom Anfang des Dokuments.
- **Textmarke** erwartet den Namen einer Textmarke. Die Groß-/Kleinschreibung spielt dabei keine Rolle. Textmarken, die ein Programm für den eigenen Gebrauch angelegt hat und deren Namen mit einem Unterstrich beginnen, werden nicht aufgeführt.
- **Überschrift** erwartet eine Nummer oder einen beliebigen Teil des Überschriftentexts. Überschriften sind Absätze mit einer Gliederungsebene, etwa Absätze mit den Überschrift-Formatvorlagen.

Ist die Stelle im Dokument nicht vorhanden, wird im Dialogfeld ein entsprechender Hinweis angezeigt, und es bleibt geöffnet, sodass Sie eine andere Angabe eingeben können.

## Text durch Ziehen verschieben oder kopieren

1. Markieren Sie den Text, den Sie verschieben möchten.
2. Drücken Sie mit der Maus auf den markierten Text, und bewegen Sie den Zeiger bei gedrückter Maustaste ein wenig. Ziehen Sie den Text dann an die gewünschte Stelle.
3. Lassen Sie die Maustaste los. Der Text wird dorthin verschoben und bleibt markiert.

Wenn Sie den Text kopieren statt verschieben möchten, halten Sie beim Loslassen die **Strg**-Taste gedrückt. Das Original bleibt dann an seiner Stelle.

Das Ziehen von Text erfolgt in einem einzigen Schritt, daher stellt ein einziges **Rückgängig** (Strg+Z) den ursprünglichen Zustand wieder her. Wenn Sie den Text auf der Markierung selbst ablegen, geschieht nichts. Sie können auch Text aus einem anderen Programm in Ihr Dokument ziehen und dort ablegen.
