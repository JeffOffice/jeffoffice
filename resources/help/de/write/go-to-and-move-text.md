# Zu einer Stelle springen und Text verschieben

## Zu einer Stelle springen

Drücken Sie **Strg+G**, oder klicken Sie auf **Start > Bearbeiten > Gehe zu**. Das Feld **Gehe zu** wird geöffnet.

1. Wählen Sie unter **Gehe zu was** die Option **Seite**, **Abschnitt**, **Zeile**, **Textmarke**, **Fußnote**, **Endnote**, **Kommentar**, **Feld**, **Tabelle**, **Grafik**, **Gleichung** oder **Überschrift**.
2. Geben Sie eine Zahl oder einen Namen ein. Bei einer Textmarke, einer Fußnote oder einer Überschrift können Sie stattdessen einen Eintrag aus der Liste unter dem Feld auswählen.
3. Klicken Sie auf **Gehe zu**. Ihre Einfügemarke springt zu dieser Stelle, und die Seiten werden so verschoben, dass sie sichtbar ist.

Einige Hinweise zu den einzelnen Arten:

- **Seite**, **Abschnitt**, **Fußnote**, **Endnote**, **Kommentar**, **Feld**, **Tabelle**, **Grafik**, **Gleichung** und **Überschrift** erwarten eine Zahl: 3 springt zum dritten Eintrag. Setzen Sie ein **+** oder ein **-** davor, um ab der Position der Einfügemarke zu zählen: **+1** springt zum nächsten Eintrag, **-1** zum vorherigen.
- **Zeile** erwartet eine Zahl, die vom Anfang des Dokuments aus gezählt wird.
- **Textmarke** erwartet den Namen einer Textmarke. Groß- und Kleinschreibung spielen keine Rolle. Textmarken, die ein Programm für eigene Zwecke angelegt hat und deren Namen mit einem Unterstrich beginnen, werden nicht aufgelistet.
- **Kommentar**, **Feld**, **Tabelle**, **Grafik** und **Gleichung** werden in der Reihenfolge gezählt, in der sie im Text vorkommen. Eine Grafik ist ein Bild, eine Form oder ein Textfeld. Ein Feld ist ein Textteil, den das Programm für Sie berechnet, zum Beispiel ein Datum oder eine Seitenzahl. Antworten auf einen Kommentar werden nicht einzeln gezählt.
- **Überschrift** erwartet eine Zahl oder einen beliebigen Teil des Überschriftentextes. Überschriften sind die Absätze, die eine Gliederungsebene haben, etwa die Absätze in den Formatvorlagen für Überschriften.

Wenn die Stelle nicht im Dokument vorhanden ist, zeigt das Feld eine Meldung an und bleibt geöffnet, sodass Sie einen anderen Wert eingeben können.

## Text per Ziehen verschieben oder kopieren

1. Markieren Sie den Text, den Sie verschieben möchten.
2. Drücken Sie mit der Maus auf den markierten Text, halten Sie die Maustaste gedrückt, und bewegen Sie den Zeiger ein Stück. Ziehen Sie dann den Text an die gewünschte Stelle.
3. Lassen Sie die Maustaste los. Der Text wird an die neue Stelle verschoben und bleibt markiert.

Um den Text stattdessen zu kopieren, halten Sie beim Loslassen die Taste **Strg** gedrückt. Das Original bleibt an seiner Stelle.

Das Verschieben per Ziehen erfolgt in einem einzigen Schritt, daher stellt ein einmaliges **Rückgängig** (Strg+Z) den Text wieder her. Wenn Sie den Text auf der eigenen Markierung ablegen, geschieht nichts. Sie können außerdem Text aus einem anderen Programm in Ihr Dokument ziehen.
