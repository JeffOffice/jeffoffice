# Verzeichnis der Rechtsquellen erstellen
<!-- keywords: Verzeichnis der Rechtsquellen, Rechtsquellen, Zitat, Zitat markieren, Urteil, Gesetz, Vorschrift, Verordnung, Fachliteratur, passim, Schriftsatz, Verzeichnis, Verzeichnis der Rechtsquellen einfügen, Alt+Umschalt+I, Kategorie -->

Ein **Verzeichnis der Rechtsquellen** ist eine Liste, die ein Schriftsatz enthält: die Urteile, Gesetze und anderen Werke, die im Schriftsatz zitiert werden, mit den Seiten, auf denen sie zitiert werden. Sie **markieren** zuerst jedes Zitat und **fügen** dann das Verzeichnis **ein**.

## Ein Zitat markieren

1. Markieren Sie das Zitat im Text, zum Beispiel den Namen eines Urteils mit seinen Nummern.
2. Klicken Sie auf **Verweise > Zitat markieren**, oder drücken Sie **Alt+Umschalt+I**.
3. Aktivieren Sie **Langzitat**. Dieses wird im Verzeichnis angezeigt. Geben Sie unter **Kurzzitat** eine Kurzform ein, wenn Sie später im Text eine kürzere Form verwenden.
4. Wählen Sie unter **Kategorie** eine aus: Urteile, Gesetze, Sonstige Rechtsquellen, Vorschriften, Fachliteratur, Verordnungen oder Verfassungsbestimmungen. Für eigene Zwecke stehen außerdem neun weitere nummerierte Kategorien zur Verfügung.
5. Klicken Sie auf **OK**.

Markieren Sie jede Stelle, an der die Rechtsquelle zitiert wird. Das Verzeichnis führt die Rechtsquelle nur einmal auf, mit allen Seiten.

## Das Verzeichnis einfügen

1. Klicken Sie an die Stelle, an der das Verzeichnis stehen soll.
2. Klicken Sie auf **Verweise > Verzeichnis der Rechtsquellen**.
3. Wählen Sie eine Kategorie aus, oder **Alle**, um alle Kategorien mit Markierungen aufzulisten. Legen Sie das Füllzeichen fest, ob **passim** verwendet werden soll und ob der Kategoriename über seinen Zitaten stehen soll.
4. Klicken Sie auf **OK**.

**Passim** ist ein lateinisches Wort und bedeutet „hier und da“. Wird eine Rechtsquelle auf fünf oder mehr Seiten zitiert, zeigt das Verzeichnis statt einer langen Seitenliste dieses Wort an.

## Das Verzeichnis aktuell halten

Klicken Sie in das Verzeichnis, und klicken Sie auf **Verzeichnis aktualisieren** (in der Gruppe **Verzeichnis der Rechtsquellen** auf der Registerkarte **Verweise**), oder drücken Sie **F9**.
