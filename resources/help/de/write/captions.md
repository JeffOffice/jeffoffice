# Beschriftungen und Abbildungsverzeichnisse
<!-- keywords: Abbildungsverzeichnis aus einer Formatvorlage, Liste der Absätze einer Formatvorlage, Beschriftung, Abbildung, Abbildungsverzeichnis, Bezeichnung, Nummer, SEQ, Beschriftung einfügen, Abbildungsliste, Kapitelnummer, Verzeichnis aktualisieren -->

Eine **Beschriftung** ist eine kurze Textzeile unter oder über einem Bild oder einer Tabelle, zum Beispiel „Abbildung 1: Sonnenaufgang“. JeffWrite nummeriert Beschriftungen für Sie. Wenn Sie eine Beschriftung in der Mitte einfügen, werden die Nummern danach erhöht.

## Beschriftung hinzufügen

1. Klicken Sie in das Bild, die Tabelle oder den Absatz, zu dem die Beschriftung gehört.
2. Klicken Sie auf **Verweise > Beschriftung einfügen**.
3. Wählen Sie eine **Bezeichnung**. **Abbildung**, **Tabelle** und **Gleichung** stehen Ihnen zur Verfügung. Sie können auch eine eigene Bezeichnung eingeben, zum Beispiel Diagramm. Jede Bezeichnung wird separat gezählt.
4. Geben Sie Wörter ein, die nach der Nummer stehen sollen, zum Beispiel `: Sonnenaufgang`.
5. Wählen Sie **Oberhalb** oder **Unterhalb** und klicken Sie auf **OK**.

Die Beschriftung ist ein neuer Absatz in der Formatvorlage **Beschriftung**. Wenn Sie eine Tabelle gewählt haben, steht die Beschriftung oberhalb oder unterhalb der gesamten Tabelle, nicht innerhalb davon.

Aktivieren Sie **Bezeichnung nicht anzeigen**, um nur die Nummer anzuzeigen. Aktivieren Sie **Kapitelnummer einschließen**, um Beschriftungen nach Kapiteln zu nummerieren, zum Beispiel 2-1 und 2-2: Wählen Sie die Überschriftenebene, die ein Kapitel beginnt, sowie ein Trennzeichen. Die Zählung beginnt dann unter jeder Überschrift dieser Ebene wieder bei 1.

## Abbildungsverzeichnis erstellen

Ein **Abbildungsverzeichnis** listet Ihre Beschriftungen mit ihren Seiten auf, ähnlich wie ein Inhaltsverzeichnis.

1. Klicken Sie an die Stelle, an die das Verzeichnis soll.
2. Klicken Sie auf **Verweise > Abbildungsverzeichnis**.
3. Wählen Sie die Beschriftungsbezeichnung, das Füllzeichen (die Punkte vor den Seitenzahlen) und ob die Zeilen Links sein sollen.
4. Klicken Sie auf **OK**.

Deaktivieren Sie **Bezeichnung und Nummer einschließen**, um nur die Wörter nach der Nummer aufzulisten.

Sie können das Verzeichnis auch aus einer Absatzformatvorlage erstellen. Wählen Sie unter **Oder die Absätze der Formatvorlage** eine Formatvorlage aus. Jeder Absatz in dieser Formatvorlage, zum Beispiel eine Überschriftenformatvorlage, wird dann zu einer Zeile des Verzeichnisses. Die Beschriftungsbezeichnung wird in diesem Fall nicht verwendet.

## Nummern und Verzeichnis aktualisieren

Drücken Sie **F9**, um die Felder in der Auswahl zu aktualisieren, oder markieren Sie zuvor mit **Strg+A** alles. Die Nummern der Beschriftungen und die Zeilen eines Abbildungsverzeichnisses werden dann neu erstellt. Das Aktualisieren ist ein Schritt, den **Rückgängig** wieder zurücknimmt.

## Auf eine Beschriftung verweisen

Verwenden Sie **Verweise > Querverweis**, um „siehe Abbildung 2“ so zu schreiben, dass der Verweis der Nummer folgt, wenn sie sich ändert.
