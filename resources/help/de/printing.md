# Eine Publikation drucken
<!-- keywords: drucken, Drucker, Druck, Kopien, Seitenbereich, Broschüre, Plakat, Banner, gekachelt, Schnittmarken, Anschnitt, Farbauszüge, beidseitig, Druckvorschau, Graustufen, Seriendruck, PDF -->

Das Drucken erfolgt auf der Seite **Drucken**. Links wählen Sie die Einstellungen, rechts sehen Sie eine Vorschau jeder Seite.

## Eine Publikation drucken

1. Drücken Sie Strg+P, oder klicken Sie auf **Datei > Drucken**. Auch die **Schnellsymbolleiste** enthält eine Schaltfläche **Drucken**.
2. Legen Sie neben der Schaltfläche **Drucken** die **Anzahl der Exemplare** fest.
3. Wählen Sie einen **Drucker**. Die Liste endet mit **Als PDF speichern**. Damit erstellen Sie eine PDF-Datei statt eines Papierausdrucks.
4. Wählen Sie unter **Einstellungen** die Option **Alle Seiten drucken**, **Aktuelle Seite drucken** oder **Benutzerdefinierter Druck**. Bei einem benutzerdefinierten Druck geben Sie die Seiten im Feld **Seiten** ein: Seitenzahlen und Bereiche, durch Kommas getrennt, z. B. 1-3, 5.
5. Wählen Sie die weiteren benötigten Einstellungen. Sie sind unten aufgeführt.
6. Klicken Sie auf **Drucken**.

Klicken Sie auf **Druckereigenschaften…**, um das Druckfenster des Systems mit den eigenen Optionen Ihres Druckers zu öffnen.

Die Vorschau rechts hat Pfeile, mit denen Sie von Seite zu Seite blättern. Aktivieren Sie **Lineale anzeigen** oder **Seitenzahlen anzeigen**, um diese in der Vorschau einzublenden.

## Layout wählen

Die Liste **Layout** legt fest, wie die Seiten auf dem Papier angeordnet werden:

- **Eine Seite pro Blatt** druckt jede Seite für sich. Eine Seite, die zu groß für das Papier ist, wird in Teilen gedruckt. Eine Seite, die etwas zu groß ist, wird verkleinert, bis sie passt.
- **Mehrere Seiten pro Blatt** setzt verschiedene Seiten auf ein Blatt.
- **Mehrere Exemplare pro Blatt** wiederholt eine Seite über das ganze Blatt. Verwenden Sie diese Option für Visitenkarten und Etiketten.
- **Broschüre, seitlich gefalzt** und **Broschüre, oben gefalzt** setzen zwei Seiten in der richtigen Reihenfolge auf jedes Blatt, sodass sich ein gefalzter Stapel in der richtigen Reihenfolge lesen lässt. Seitlich gefalzt setzt die beiden Seiten nebeneinander. Oben gefalzt setzt eine Seite über die andere.
- **Gekachelt (Poster und Banner)** druckt eine große Seite in Teilen auf mehrere Blätter, mit einer kleinen Überlappung, damit Sie die Blätter ausrichten können.

## Weitere Einstellungen

- **Papier**: Letter, Legal, Tabloid, A4, A3 oder **Wie Publikation**.
- **Seiten**: **Einseitig drucken** oder **Beidseitig drucken** mit Wenden an der langen Kante oder an der kurzen Kante. **Beidseitig manuell drucken** ist für einen Drucker gedacht, der nicht beidseitig drucken kann. JeffPub druckt zuerst die erste, dritte, fünfte usw. Seite (bei einer Broschüre die Blattseiten), danach erscheint eine Meldung, die Sie auffordert, den Stapel zu wenden und wieder in den Drucker zu legen. Wenn Sie auf **OK** klicken, druckt das Programm die übrigen Seiten, die letzte zuerst. Ein Auftrag mit nur einer Seite muss nicht gewendet werden. Beim Speichern als PDF ist die Auswahl abgeblendet, da eine Datei keine Seiten hat. Die Vorschau zeigt dann, auf welchem Blatt und auf welcher Seite sich jede Seite befindet.
- **Farbe**: **Composite RGB** für Vollfarbe oder **Composite-Graustufen** für Graustufen.
- **Alle Seriendruckdatensätze drucken**: Verfügbar, wenn Ihre Publikation eine Empfängerliste hat. Siehe [Seriendruck](mail-merge).

## Druckmarken und Farbauszüge

Diese Optionen sind für Arbeiten gedacht, die an eine Druckerei gehen. Fragen Sie die Druckerei, was sie benötigt.

- **Schnittmarken** zeigen, wo beschnitten wird. **Anschnittmarken** zeigen den zusätzlichen Rand. **Passermarken** helfen beim Ausrichten der Farben. **Dichtebalken** und **Farbbalken** erlauben es der Druckerei, die Farbe zu prüfen. **Auftragsinformationen** drucken Name, Seite und Datum.
- **Anschnitt zulassen** druckt Objekte, die über die Seite hinausragen, sodass nach dem Beschneiden kein weißer Rand entsteht. Dieser zusätzliche Rand heißt **Anschnitt**.
- Die Markierungen werden außerhalb der Seite gedruckt. Verwenden Sie deshalb Papier, das größer ist als Ihre Seite.
- **Farbauszüge (CMYK-Platten)** unter **Farbe** druckt ein Blatt für jede Farbe: **Cyan**, **Magenta**, **Gelb** und **Schwarz** sowie alle Schmuckfarben (Volltonfarben), die Ihre Publikation verwendet. Eine Volltonfarbe ist eine speziell vorgemischte Druckfarbe. Aktivieren oder deaktivieren Sie die gewünschten Platten.

Eine PDF-Datei für die Druckerei erstellen Sie unter [PDF-Dateien und Druckereien](pdf).
