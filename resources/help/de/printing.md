# Eine Publikation drucken

Gedruckt wird auf der Seite **Drucken**. Links wählen Sie die Einstellungen, rechts prüfen Sie eine Vorschau jeder Seite.

## Eine Publikation drucken

1. Drücken Sie Strg+P, oder klicken Sie auf **Datei > Drucken**. Auch die **Symbolleiste für den Schnellzugriff** enthält eine Schaltfläche **Drucken**.
2. Legen Sie neben der Schaltfläche **Drucken** die Anzahl der **Exemplare** fest.
3. Wählen Sie einen **Drucker** aus. Am Ende der Liste steht **Als PDF speichern**. Damit erstellen Sie statt eines Ausdrucks eine PDF-Datei.
4. Wählen Sie unter **Einstellungen** die Option **Alle Seiten drucken**, **Aktuelle Seite drucken** oder **Benutzerdefinierter Druck**. Geben Sie für einen benutzerdefinierten Druck die Seiten in das Feld **Seiten** ein: Seitenzahlen und Seitenbereiche, durch Kommas getrennt, zum Beispiel 1-3, 5.
5. Wählen Sie die weiteren benötigten Einstellungen aus. Sie sind unten beschrieben.
6. Klicken Sie auf **Drucken**.

Klicken Sie auf **Druckereigenschaften…**, um das Druckfenster des Systems mit den Optionen Ihres Druckers zu öffnen.

Mit den Pfeilen in der Vorschau rechts blättern Sie von Seite zu Seite. Aktivieren Sie **Lineale anzeigen** oder **Seitenzahlen anzeigen**, um diese in der Vorschau einzublenden.

## Ein Layout auswählen

Die Liste **Layout** legt fest, wie die Seiten auf das Papier kommen:

- **Eine Seite pro Blatt** druckt jede Seite einzeln. Eine Seite, die zu groß für das Papier ist, wird in Teilen gedruckt. Eine Seite, die nur wenig zu groß ist, wird passend verkleinert.
- **Mehrere Seiten pro Blatt** druckt verschiedene Seiten auf ein Blatt.
- **Mehrere Exemplare pro Blatt** wiederholt eine Seite auf dem ganzen Blatt. Verwenden Sie diese Option für Visitenkarten und Etiketten.
- **Broschüre, seitlich gefalzt** und **Broschüre, oben gefalzt** drucken zwei Seiten in der richtigen Reihenfolge auf jedes Blatt, sodass sich ein gefalteter Stapel der Reihe nach lesen lässt. Bei seitlicher Falzung stehen die beiden Seiten nebeneinander, bei Falzung oben übereinander.
- **Gekachelt (Poster und Banner)** druckt eine große Seite in Teilen auf mehrere Blätter, mit einer kleinen Überlappung, damit Sie die Blätter aneinander ausrichten können.

## Weitere Einstellungen

- **Papier**: Letter, Legal, Tabloid, A4, A3 oder **Wie Publikation**.
- **Seiten (Duplex)**: **Einseitig** oder beidseitig mit Wenden an der langen oder kurzen Kante. Die Vorschau zeigt dann, auf welchem Blatt und welcher Seite jede Seite steht.
- **Farbe**: **Composite RGB** für vollfarbigen Druck oder **Composite Graustufen** für Grautöne.
- **Alle Seriendruckdatensätze drucken**: verfügbar, wenn Ihre Publikation eine Empfängerliste hat. Siehe [Seriendruck](mail-merge).

## Druckmarken und Farbauszüge

Diese Optionen sind für Aufträge an eine Druckerei gedacht. Fragen Sie die Druckerei, was sie benötigt.

- **Schnittmarken** zeigen, wo geschnitten wird. **Anschnittmarken** zeigen den zusätzlichen Rand. **Passermarken** helfen, die Farben genau übereinanderzulegen. Mit **Dichtebalken** und **Farbbalken** kann die Druckerei die Druckfarbe prüfen. **Auftragsinformationen** druckt Name, Seite und Datum.
- **Anschnitt zulassen** druckt Objekte, die über den Seitenrand hinausragen, sodass nach dem Beschneiden kein weißer Rand bleibt. Dieser zusätzliche Rand heißt **Anschnitt**.
- Die Marken werden außerhalb der Seite gedruckt. Verwenden Sie daher Papier, das größer ist als Ihre Seite.
- **Farbauszüge (CMYK-Platten)** unter **Farbe** druckt für jede Druckfarbe ein eigenes Blatt: **Cyan**, **Magenta**, **Gelb** und **Schwarz** sowie alle Volltonfarben Ihrer Publikation (eine Volltonfarbe ist eine spezielle, vorgemischte Druckfarbe). Aktivieren oder deaktivieren Sie die gewünschten Platten.

Wie Sie eine PDF-Datei für eine Druckerei erstellen, erfahren Sie unter [PDF-Dateien und Druckereien](pdf).
