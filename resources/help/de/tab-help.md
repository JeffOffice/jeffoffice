# Registerkarte „Hilfe“
<!-- keywords: Registerkarte Hilfe, Hilfe, Support, Support kontaktieren, Feedback, Neuigkeiten, Versionshinweise, Tastenkombinationen, Tastenkürzel, F1, Problem melden, Idee vorschlagen, Verbesserungsvorschlag -->

Die Registerkarte **Hilfe** ist immer im Menüband vorhanden, nach der Registerkarte **Ansicht**. Hier erhalten Sie Hilfe, melden ein Problem oder schlagen eine Idee vor.

- Gruppe **Hilfe**: vier Schaltflächen. Siehe [Willkommen bei JeffPub](start) und [Hilfe erhalten und Probleme melden](support).

| Schaltfläche | Funktion | Zugriffstasteninfo |
|---|---|---|
| **Hilfe** | Öffnet den Hilfebereich auf der rechten Seite. Sie können auch F1 drücken oder auf die Schaltfläche **?** am rechten Ende der Registerkartenzeile klicken. | Alt, Y, H |
| **Feedback** | Öffnet eine GitHub-Seite, auf der Sie ein Problem melden oder eine Idee vorschlagen können. Dazu benötigen Sie ein kostenloses GitHub-Konto. | Alt, Y, K |
| **Tastenkombinationen** | Öffnet das Hilfethema zur Verwendung von JeffPub mit der Tastatur, mit einer Liste der Tasten für alle Befehle. | Alt, Y, S |
| **Neuigkeiten** | Öffnet die Anmerkungen zu Ihrer Version von JeffPub auf GitHub in Ihrem Webbrowser. | Alt, Y, W |
