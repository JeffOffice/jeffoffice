# Formatvorlagen verwenden
<!-- keywords: Formatvorlage, Formatvorlagen, Formatvorlagenkatalog, Absatzformatvorlage, Zeichenformatvorlage, Überschrift 1, Überschrift 2, Überschrift 3, Titel, neue Formatvorlage, Formatvorlage ändern, Formatvorlagen importieren, Standard, Textkörper, Untertitel, Stil, Vorlage -->

Eine Formatvorlage ist eine gespeicherte Gruppe von Formatierungen mit einem Namen. Wenn Sie die Formatvorlage **Überschrift 1** anwenden, erhält der Text auf einmal die Schriftart, den Schriftgrad, die Farbe und die Abstände dieser Formatvorlage. Wenn Sie die Formatvorlage später ändern, ändern sich auch alle Absätze, die sie verwenden.

Es gibt zwei Arten von Formatvorlagen:

- Eine **Absatzformatvorlage** formatiert ganze Absätze.
- Eine **Zeichenformatvorlage** formatiert nur die markierten Buchstaben. **Hervorhebung** (kursiv) und **Fett** (fett) sind Zeichenformatvorlagen.

## Formatvorlage anwenden

1. Klicken Sie in einen Absatz, oder markieren Sie den Text. Markieren Sie für eine Zeichenformatvorlage die gewünschten Wörter.
2. Klicken Sie unter **Start > Formatvorlagen** im Katalog auf eine Formatvorlage.

Wenn stattdessen ein Textfeld markiert ist, gilt die Formatvorlage für alle Absätze darin. Der Katalog zeigt einige Formatvorlagen an. Mit den Pfeilen **Vorherige Zeile** und **Nächste Zeile** sehen Sie weitere, mit der Schaltfläche **Alle anzeigen** alle.

Eine neue Publikation enthält zu Beginn diese Formatvorlagen: Standard, Textkörper, Titel, Untertitel, Überschrift 1 bis Überschrift 4, Zitat, Beschriftung, Aufzählungszeichen, Adresse, Name der Organisation, Slogan, Telefon Fax E-Mail, Hervorhebung und Fett. Die Überschriftenformatvorlagen verwenden die Überschriftenschriftart der Publikation. Wenn Sie ein anderes Schriftartenschema wählen, ändern sie sich deshalb. Weitere Informationen finden Sie unter [Farb- und Schriftartenschemas](color-schemes).

Verwenden Sie **Überschrift 1**, **Überschrift 2** und **Überschrift 3** für Ihre Überschriften. JeffPub erstellt daraus ein Inhaltsverzeichnis. Weitere Informationen finden Sie unter [Inhaltsverzeichnis, Fußnoten und Endnoten](references).

## Neue Formatvorlage erstellen

1. Formatieren Sie Text so, wie die Formatvorlage aussehen soll. Lassen Sie die Einfügemarke darin stehen.
2. Klicken Sie im Katalog **Formatvorlagen** auf **Alle anzeigen** und dann auf **Neue Formatvorlage…**.
3. Geben Sie einen **Namen der Formatvorlage** ein. Prüfen oder ändern Sie die übrigen Einstellungen.
4. Klicken Sie auf **OK**.

Die neue Formatvorlage wird im Katalog angezeigt. Sie ist noch nicht auf Ihren Text angewendet. Klicken Sie deshalb im Katalog darauf.

Schneller geht es mit **Neue Formatvorlage aus Beispiel**. Geben Sie einen Namen für die Formatvorlage ein, die auf dem markierten Text basiert. JeffPub erstellt die Formatvorlage und wendet sie sofort an.

## Formatvorlage ändern

1. Klicken Sie in einen Absatz, der die Formatvorlage verwendet.
2. Klicken Sie im Katalog **Formatvorlagen** auf **Alle anzeigen** und dann auf **Formatvorlage ändern…**.
3. Ändern Sie Schriftart, Schriftgrad, Fett, Kursiv, Farbe, Ausrichtung oder Abstände. Klicken Sie auf **OK**.

Alle Absätze mit dieser Formatvorlage ändern sich sofort.

Das Dialogfeld bietet außerdem diese Möglichkeiten:

- **Formatvorlage für nächsten Absatz:** Die Formatvorlage, die Sie erhalten, wenn Sie am Ende eines Absatzes die Eingabetaste drücken. Nach einer Überschrift ist das meist **Standard**.
- **Zeichenformatvorlage:** Aktivieren Sie diese Option, um eine Formatvorlage zu erstellen, die nur markierten Text formatiert.
- **Basiert auf:** JeffPub speichert diese Auswahl, aber eine Formatvorlage ändert sich nicht, wenn sich die Formatvorlage ändert, auf der sie basiert.

## Formatvorlagen aus einer anderen Publikation übernehmen

1. Klicken Sie im Katalog **Formatvorlagen** auf **Alle anzeigen** und dann auf **Formatvorlagen importieren…**.
2. Wählen Sie eine JeffPub-Publikation oder eine .pub-Datei aus.

Formatvorlagen mit gleichem Namen werden ersetzt. Andere Formatvorlagen werden hinzugefügt. Bereits geschriebener Text behält sein Aussehen, bis Sie die Formatvorlage erneut anwenden.
