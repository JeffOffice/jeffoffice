# Formatvorlagen verwenden
<!-- keywords: Formatvorlage, Formatvorlagenkatalog, Absatzformatvorlage, Zeichenformatvorlage, Überschrift 1, Überschrift 2, Überschrift 3, Titel, neue Formatvorlage, Formatvorlage ändern, Formatvorlagen importieren, Normal, Fließtext, Untertitel, Formatvorlage erstellen -->

Eine Formatvorlage ist eine gespeicherte Formatierung mit einem Namen. Wenn Sie die Formatvorlage **Überschrift 1** anwenden, erhält der Text auf einmal die Schriftart, Schriftgröße, Farbe und Abstände dieser Formatvorlage. Ändern Sie die Formatvorlage später, ändern sich auch alle Absätze, die sie verwenden.

Es gibt zwei Arten von Formatvorlagen:

- Eine **Absatzformatvorlage** formatiert ganze Absätze.
- Eine **Zeichenformatvorlage** formatiert nur die Buchstaben, die Sie markieren. **Betonung** (kursiv) und **Stark** (fett) sind Zeichenformatvorlagen.

## Formatvorlage anwenden

1. Klicken Sie in einen Absatz, oder markieren Sie den Text. Bei einer Zeichenformatvorlage markieren Sie die Wörter.
2. Klicken Sie unter **Start > Formatvorlagen** auf eine Formatvorlage im Katalog.

Wenn Sie stattdessen ein Textfeld markiert haben, gilt die Formatvorlage für alle seine Absätze. Der Katalog zeigt einige Formatvorlagen. Mit den Pfeilen **Vorherige Zeile** und **Nächste Zeile** sehen Sie weitere, mit der Schaltfläche **Alle anzeigen** sehen Sie alle.

Eine neue Publikation beginnt mit diesen Formatvorlagen: Normal, Fließtext, Titel, Untertitel, Überschrift 1 bis Überschrift 4, Zitat, Beschriftung, Aufzählung, Adresse, Name der Organisation, Slogan, Telefon Fax E-Mail, Betonung und Stark. Die Überschriften-Formatvorlagen verwenden die Überschriftenschriftart der Publikation, deshalb ändert sich bei einem neuen Schriftartenschema auch ihre Schrift. Siehe [Farb- und Schriftartenschemas](color-schemes).

Verwenden Sie **Überschrift 1**, **Überschrift 2** und **Überschrift 3** für Ihre Überschriften. JeffPub erstellt daraus ein Inhaltsverzeichnis. Siehe [Inhaltsverzeichnis, Fußnoten und Endnoten](references).

## Neue Formatvorlage erstellen

1. Formatieren Sie einen Text so, wie die Formatvorlage aussehen soll. Lassen Sie die Einfügemarke darin stehen.
2. Klicken Sie im Katalog **Formatvorlagen** auf **Alle anzeigen**, und klicken Sie dann auf **Neue Formatvorlage…**.
3. Geben Sie unter **Name der Formatvorlage** einen Namen ein. Prüfen oder ändern Sie die übrigen Einstellungen.
4. Klicken Sie auf **OK**.

Die neue Formatvorlage erscheint im Katalog. Sie ist noch nicht auf Ihren Text angewendet, klicken Sie sie dort also an.

Schneller geht es mit **Neue Formatvorlage aus Beispiel**. Geben Sie einen Namen für die Formatvorlage ein. Sie basiert auf dem markierten Text. JeffPub erstellt die Formatvorlage und wendet sie sofort an.

## Formatvorlage ändern

1. Klicken Sie in einen Absatz, der die Formatvorlage verwendet.
2. Klicken Sie im Katalog **Formatvorlagen** auf **Alle anzeigen**, und klicken Sie dann auf **Formatvorlage ändern…**.
3. Ändern Sie Schriftart, Schriftgrad, Fett, Kursiv, Farbe, Ausrichtung, Einzüge oder Abstände. Klicken Sie auf **OK**.

Jeder Absatz mit dieser Formatvorlage ändert sich sofort.

Das Dialogfeld bietet außerdem diese Optionen:

- **Formatvorlage für den nächsten Absatz:** Die Formatvorlage, die Sie erhalten, wenn Sie am Ende eines Absatzes die Eingabetaste drücken. Nach einer Überschrift möchten Sie meist **Normal**.
- **Zeichenformatvorlage:** Aktivieren Sie das Kontrollkästchen, um eine Formatvorlage zu erstellen, die nur markierten Text formatiert.
- **Basiert auf:** Die Formatvorlage, von der diese ausgeht. Eine Formatvorlage speichert nur, was Sie darin ändern. Ändern Sie die Basisformatvorlage, ändern sich deshalb auch alle darauf basierenden Formatvorlagen und der Text in ihnen. Eine Einstellung steht bei **von Basis**, wenn sie von der Basisformatvorlage stammt, und bei **hier festlegen**, wenn diese Formatvorlage sie festlegt. Mit **Auf Basis zurücksetzen** erhält eine Einstellung wieder den Wert der Basis. Text, den Sie selbst formatiert haben, behält sein Aussehen.
- **Formatvorlage löschen:** Entfernt die Formatvorlage. Darauf basierende Formatvorlagen basieren stattdessen auf deren eigener Basis und sehen gleich aus.

## Formatvorlagen aus einer anderen Publikation übernehmen

1. Klicken Sie im Katalog **Formatvorlagen** auf **Alle anzeigen**, und klicken Sie dann auf **Formatvorlagen importieren…**.
2. Wählen Sie eine JeffPub-Publikation oder eine .pub-Datei.

Formatvorlagen mit gleichem Namen werden ersetzt. Andere Formatvorlagen werden hinzugefügt. Text in einer ersetzten Formatvorlage erhält deren neues Aussehen, außer was Sie am Text selbst eingestellt haben.
