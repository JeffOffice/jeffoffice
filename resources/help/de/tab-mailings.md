# Registerkarte „Sendungen“
<!-- keywords: Registerkarte Sendungen, Seriendruck, Serienbrief, Empfänger, Seriendruckfelder, Etiketten, Serienbriefe, Menüband -->

Die Registerkarte **Sendungen** ist immer im Menüband vorhanden. Sie enthält die Tools für den Seriendruck, der eine Publikation mit Angaben aus einer Personenliste füllt. Um sie über die Tastatur zu öffnen, drücken Sie **Alt** und dann **M**.

- **Seriendruck starten**: Starten Sie den Seriendruck-Assistenten oder einen Seriendruck an E-Mail, wählen Sie eine Empfängerliste aus oder geben Sie eine ein, und bearbeiten Sie sie. Siehe [Seriendruck und Katalogseriendruck](mail-merge).
- **Felder schreiben und einfügen**: Fügen Sie einen Adressblock, eine Grußzeile, ein Seriendruckfeld oder ein Bildfeld hinzu. Siehe [Seriendruck und Katalogseriendruck](mail-merge).
- **Vorschau Ergebnisse**: Zeigen Sie anstelle der Felder die tatsächlichen Angaben an, und blättern Sie durch die Datensätze. Siehe [Seriendruck und Katalogseriendruck](mail-merge).
- **Fertig stellen**: Führen Sie den Seriendruck auf dem Drucker, in einer neuen Publikation, in einer PDF-Datei oder per E-Mail aus, oder exportieren Sie die Liste. Siehe [Seriendruck und Katalogseriendruck](mail-merge).
