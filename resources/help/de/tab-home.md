# Registerkarte „Start“
<!-- keywords: Registerkarte Start, Start, Menüband, Zwischenablage, Gruppe Schriftart, Gruppe Absatz, Formatvorlagenkatalog, Formatvorlagen, Objekte, Gruppe Bearbeiten, Formatierungstools, Formatierung -->

Die Registerkarte **Start** ist immer im Menüband vorhanden. Sie enthält die Tools, die Sie beim Schreiben und Gestalten einer Seite am häufigsten verwenden.

- **Zwischenablage** enthält **Einfügen**, **Ausschneiden**, **Kopieren** und **Format übertragen**. Mit **Format übertragen** übertragen Sie das Aussehen von Text auf ein anderes Feld. Weitere Informationen finden Sie unter [Text formatieren](formatting-text).
- **Schriftart** ändert Schriftart, Schriftgrad, Farbe und Schriftschnitt von Buchstaben. Weitere Informationen finden Sie unter [Text formatieren](formatting-text).
- **Absatz** enthält Aufzählungszeichen, Nummerierung, Einzüge, Ausrichtung und Abstände für ganze Absätze. Weitere Informationen finden Sie unter [Aufzählungszeichen, Nummerierung und Tabstopps](lists-tabs).
- **Formatvorlagen** ist ein Katalog benannter Formatierungen, die Sie mit einem Klick anwenden können. Hier können Sie auch eigene Formatvorlagen erstellen. Weitere Informationen finden Sie unter [Formatvorlagen verwenden](styles).
- **Objekte** zeichnet ein Textfeld, fügt eine Tabelle ein, fügt Bilder hinzu und zeichnet Formen. Weitere Informationen finden Sie unter [Textfelder hinzufügen und formatieren](text-boxes).
- **Anordnen** legt fest, wie Objekte von Text umflossen, übereinander angeordnet, gruppiert, ausgerichtet und gedreht werden. Weitere Informationen finden Sie unter [Objekte verschieben, ausrichten, gruppieren und anordnen](arrange).
- **Bearbeiten** enthält **Suchen**, **Ersetzen** und **Auswählen**. Mit **Auswählen** markieren Sie den gesamten Text in einem Feld, alle Objekte oder alle Objekte einer Art. Weitere Informationen finden Sie unter [Text suchen und ersetzen](find-replace).
