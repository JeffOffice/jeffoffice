# Inhaltsverzeichnis, Fußnoten und Endnoten
<!-- keywords: Inhaltsverzeichnis, Verzeichnis, Inhaltsseite, Fußnote, Endnote, Anmerkungen, Notizen, Verweise, Quellenangaben, Zitate, Verzeichnis aktualisieren, Seitenzahlen, Füllzeichen, Punkte, Überschriftenformatvorlagen -->

Die Gruppe **Verweise** auf der Registerkarte **Einfügen** enthält Tools für lange Publikationen: ein Inhaltsverzeichnis, Fußnoten und Endnoten.

## Inhaltsverzeichnis hinzufügen

Ein Inhaltsverzeichnis listet Ihre Überschriften mit ihren Seitenzahlen auf, damit Leser schnell finden, was sie suchen.

1. Weisen Sie jeder Überschrift eine der Formatvorlagen **Überschrift 1**, **Überschrift 2** oder **Überschrift 3** zu. Siehe [Formatvorlagen verwenden](styles).
2. Klicken Sie an die Stelle im Text, an der das Verzeichnis stehen soll, oder klicken Sie auf eine leere Seite.
3. Klicken Sie auf **Einfügen > Verweise > Inhaltsverzeichnis**.

JeffPub fügt einen Titel, **Inhalt**, und eine Zeile für jede Überschrift ein. Jede Zeile endet mit einer Punktreihe und einer Seitenzahl. Zeilen für **Überschrift 1** sind fett, und die unteren Ebenen werden jeweils um 0,6 cm eingezogen.

Wenn Sie in Text geklickt haben, wird das Verzeichnis genau dort eingefügt. Andernfalls wird es, sofern die Seite leer ist, in einem neuen Textfeld auf dieser Seite eingefügt. Ist die Seite nicht leer, fügt JeffPub dafür nach dieser Seite eine neue Seite ein.

Wenn es noch keine Überschriften gibt, weist das Verzeichnis darauf hin. Fügen Sie Überschriften hinzu, und aktualisieren Sie das Verzeichnis dann.

### Verzeichnis aktuell halten

Das Verzeichnis ändert sich nicht von selbst. Nachdem Sie Überschriften bearbeitet oder Seiten verschoben haben, klicken Sie auf **Einfügen > Verweise > Verzeichnis aktualisieren**. Alle Seitenzahlen werden aktualisiert, und jedes Verzeichnis in der Publikation wird auf den neuesten Stand gebracht. JeffPub schreibt das gesamte Verzeichnis neu. Nehmen Sie daher keine Änderungen direkt darin vor, sondern ändern Sie stattdessen die Überschriften.

## Fußnote hinzufügen

Eine Fußnote ist eine kurze Anmerkung unten auf der Seite. Eine kleine hochgestellte Zahl im Text verweist darauf.

1. Klicken Sie an die Stelle im Text, an der die Zahl stehen soll.
2. Klicken Sie auf **Einfügen > Verweise > Fußnote**, oder drücken Sie Strg+Alt+F.
3. Geben Sie die Anmerkung im Dialogfeld **Fußnote einfügen** ein.
4. Klicken Sie auf **OK**.

JeffPub nummeriert Fußnoten fortlaufend mit 1, 2, 3 usw. Jede Anmerkung wird unten in der Spalte platziert, die ihre Zahl enthält, unter einer kurzen Linie. Der Text der Anmerkung ist etwas kleiner als Ihr Text. Wenn eine Anmerkung und die Zeile mit ihrer Zahl nicht in den verbleibenden Platz einer Spalte passen, werden beide in die nächste Spalte verschoben.

Eine Fußnote, die höher als eine ganze Spalte ist, wird geteilt. Der erste Teil bleibt unten in der Spalte mit ihrer Zahl, und die Zeile mit der Zahl bleibt darüber. Der Rest wird unten in der nächsten Spalte oder im nächsten verknüpften Textfeld fortgesetzt, auch auf einer anderen Seite. Dort steht er über den eigenen Fußnoten dieser Spalte, unter einer Linie, die so breit ist wie die Spalte. Eine lange Anmerkung wird über so viele Spalten fortgesetzt wie nötig.

Wenn keine Spalte für den Rest übrig ist, ist der Textabschnitt zu lang für seine Textfelder. Dann wird die rote Überlaufanzeige angezeigt, wie bei jedem Text, der nicht passt. [Verknüpfen Sie ein weiteres Textfeld](linked-text), oder schaffen Sie Platz, dann wird der Rest der Anmerkung angezeigt.

## Endnote hinzufügen

Eine Endnote ist wie eine Fußnote, aber alle Anmerkungen werden gesammelt am Ende des Textabschnitts unter der Überschrift **Anmerkungen** aufgeführt.

1. Klicken Sie an die Stelle im Text, an der die Zahl stehen soll.
2. Klicken Sie auf **Einfügen > Verweise > Endnote**, oder drücken Sie Strg+Alt+D.
3. Geben Sie die Anmerkung im Dialogfeld **Endnote einfügen** ein, und klicken Sie auf **OK**.

## Anmerkung ändern

Klicken Sie im Text direkt neben die Zahl einer Anmerkung, und klicken Sie erneut auf **Fußnote** bzw. **Endnote**. Das Dialogfeld **Fußnote bearbeiten** bzw. **Endnote bearbeiten** wird mit dem Text der Anmerkung geöffnet. Um eine Anmerkung zu entfernen, löschen Sie ihre Zahl im Text.

Anmerkungen funktionieren in Textfeldern, nicht jedoch in Tabellenzellen.
