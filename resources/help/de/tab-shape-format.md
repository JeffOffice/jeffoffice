# Registerkarte „Formformat“
<!-- keywords: Registerkarte Formformat, Zeichentools, Formfüllung, Formkontur, Formeffekte, Linien, Pfeile, Menüband, kontextbezogene Registerkarte, Form formatieren -->

Die Registerkarte **Formformat** wird angezeigt, wenn Sie eine Form, eine Linie, eine Gruppe oder mehrere Objekte gleichzeitig markieren. Damit können Sie diese zeichnen, einfärben und anordnen.

- **Formen einfügen**: Zeichnen Sie eine Form, ändern Sie eine Form in eine andere, bearbeiten Sie ihre Punkte, oder zeichnen Sie ein Textfeld. Siehe [Formen und Linien zeichnen](shapes).
- **Formenarten**: Wählen Sie eine Formenart, eine Füllung, eine Kontur und Effekte wie Schatten und Leuchten aus. Siehe [Formen und Linien zeichnen](shapes).
- **Linien**: Zeichnen Sie eine Linie, einen Pfeil oder einen Doppelpfeil. Siehe [Formen und Linien zeichnen](shapes).
- **Anordnen**: Legen Sie den Textumbruch fest, ändern Sie die Stapelreihenfolge, gruppieren, richten Sie aus, und drehen Sie Objekte. Siehe [Objekte verschieben, ausrichten, gruppieren und anordnen](arrange) und [Text um Objekte umbrechen](wrap).
- **Größe**: Geben Sie eine genaue Höhe und Breite ein. Siehe [Objekte verschieben, ausrichten, gruppieren und anordnen](arrange).
