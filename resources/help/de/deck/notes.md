# Sprechernotizen
<!-- keywords: Notizen, Sprechernotizen, Notizenbereich, Notizenfeld, Referentennotizen, Notizenseite, Stichpunkte, Notizen drucken, Notizen ausblenden, Notizen einblenden, Redemanuskript -->

**Sprechernotizen** sind die Stichpunkte, die Sie sich während der Präsentation merken möchten. Das Publikum sieht sie nicht. Jede Folie hat ihre eigenen.

## Notizen schreiben

Das Notizenfeld befindet sich unter der Folie. Klicken Sie hinein, und geben Sie Ihren Text ein. Solange es leer ist, steht darin **Klicken, um Notizen hinzuzufügen**. Die Notizen gehören zu der Folie, auf der Sie sich gerade befinden. Um die Notizen einer anderen Folie zu sehen oder zu schreiben, klicken Sie auf diese Folie.

Sie können die Notizen genauso formatieren wie den Text auf einer Folie. Markieren Sie Wörter im Notizenfeld, und klicken Sie dann auf **Fett**, **Kursiv** oder **Unterstrichen**, erstellen Sie eine Liste mit Aufzählungszeichen oder Nummerierung, oder drücken Sie am Anfang eines Eintrags die Tabulatortaste, um ihn eine Ebene tiefer zu setzen. Über **Einfügen > Link** fügen Sie außerdem einen Link hinzu. Eine Leiste mit den gängigen Optionen erscheint außerdem bei Wörtern, die Sie mit der Maus markieren. Rechtschreibprüfung und AutoKorrektur funktionieren hier ebenfalls. Befehle, die Objekte auf die Folie setzen, etwa Bilder, Formen und Tabellen, sind während der Eingabe im Notizenfeld deaktiviert, und ein Bild, das in die Notizen eingefügt wird, wird weggelassen. Eine nummerierte Liste, die Sie direkt nach einem Eintrag einfügen, wird mit der Nummer dieses Eintrags fortgesetzt. Beginnt sie nach einem leeren Absatz, fängt sie wieder bei 1 an. Eine gespeicherte Datei zeigt dieselben Nummern.

Was Sie eingeben, wird zu einem Schritt, den Sie mit Strg+Z rückgängig machen können, sobald Sie eine Pause machen oder an einer anderen Stelle klicken. Jede Formatänderung ist ein eigener Schritt.

Um auf einer Seite zu schreiben, die wie die gedruckte Notizenseite aussieht, klicken Sie auf **Ansicht > Präsentationsansichten > Notizenseite**. Das Notizenfeld auf dieser Seite ist derselbe Editor mit derselben Formatierung, und seine Schrift wird beim Zoomen der Seite größer oder kleiner. Das Zoomen verändert die Notizen nie. Sind die Notizen länger als das Feld, werden sie kleiner dargestellt, damit sie hineinpassen, so wie die gedruckte Seite es vorgibt, und Sie sehen alle. Eine sehr lange Notiz wird auf der gedruckten Seite am unteren Rand des Feldes abgeschnitten. Eine Seite wird dafür nie hinzugefügt.

Um die Höhe des Feldes zu ändern, ziehen Sie die Linie zwischen Feld und Folie. Um es auszublenden und mehr Platz für die Folie zu haben, klicken Sie auf **Ansicht > Anzeigen > Notizen** oder auf die Schaltfläche **Notizen** in der Statusleiste. Ein erneuter Klick blendet es wieder ein.

## Notizen während der Präsentation verwenden

Die Referentenansicht zeigt die Notizen der Folie mit ihrer Formatierung auf dem Bildschirm, in einer Größe, die Sie wählen. Dort können Sie auch Text eingeben. Das Feld **Sprechernotizen** der Bildschirmpräsentation zeigt sie ebenfalls formatiert an. Siehe [Bildschirmpräsentation abspielen und die Referentenansicht verwenden](show).

## Notizen drucken

Um die Folien mit ihren Notizen darunter zu drucken, wählen Sie auf der Seite Drucken die Option **Notizenseiten**. Die Notizen können auch in eine PDF-Datei aufgenommen werden. Siehe [Drucken, PDF und Folienbilder](printing).

Um festzulegen, wo Notizen, Folienbild, Kopfzeile und Seitenzahl auf der gedruckten Seite stehen, öffnen Sie **Ansicht > Masteransichten > Notizenmaster**.

## Notizen in Kopien

Eine Folie, die Sie duplizieren oder aus einer anderen Präsentation wiederverwenden, nimmt ihre Notizen mit. Siehe [Folien hinzufügen, ändern und löschen](slides) und [Folien aus einer anderen Präsentation wiederverwenden](reuse).
