# Formen, Bilder, Tabellen und Textkunst

Neben Text kann eine Folie Formen, Bilder und Tabellen enthalten. In diesem Thema erfahren Sie, wie Sie diese hinzufügen und wie JeffDeck mit anderen Arten von Objekten umgeht.

## Eine Form oder Linie zeichnen

1. Klicken Sie auf **Start > Zeichnen > Formen** (oder **Einfügen > Illustrationen > Formen**). Ein Katalog wird geöffnet. Oben finden Sie Linien, Pfeile, gewinkelte und gekrümmte Verbinder, Kurven und Freihandzeichnungen. Darunter folgen die Formen, nach Art sortiert.
2. Klicken Sie auf ein Element, und ziehen Sie dann auf der Folie, um es zu zeichnen.
3. Um Text in eine Form einzugeben, markieren Sie sie und drücken die Eingabetaste, oder beginnen Sie einfach zu tippen.

Markieren Sie eine Form oder Linie, und färben Sie mit **Formfüllung** und **Formkontur** auf der Registerkarte **Start** das Innere und den Rand ein. Beide zeigen die Farben des Designs der Präsentation an und bieten **Keine Füllung** bzw. **Keine Kontur**.

## Ein Bild hinzufügen

Klicken Sie auf **Einfügen > Bilder > Bilder**, wählen Sie eine oder mehrere Dateien aus, und klicken Sie auf **Öffnen**. JeffDeck platziert jedes Bild in der Mitte der Folie. Es wird nicht größer als der Großteil der Folie. Die Bilddaten werden in der Präsentation gespeichert, die Datei ist also vollständig, wenn Sie sie weitergeben.

Sie können Bilddateien auch aus Ihrem Dateimanager auf eine Folie ziehen. Das Bild landet dort, wo Sie es ablegen.

JeffDeck liest Bilder im Format PNG, JPEG, GIF, BMP, TIFF, WebP, SVG, WMF, EMF, ICO und PDF.

## Ein Bild aus dem Web hinzufügen

**Onlinebilder** findet kostenlose Bilder. Sie stammen aus zwei offenen Bibliotheken: Openverse, das viele Sammlungen durchsucht, und Wikimedia Commons, der Bildbibliothek der Wikipedia.

1. Klicken Sie auf den Pfeil unter **Einfügen > Bilder > Bilder**, und wählen Sie **Onlinebilder…**. Rechts wird ein Bereich geöffnet.
2. Wählen Sie eine Bibliothek, geben Sie ein, wonach Sie suchen, und klicken Sie auf **Suchen** (oder drücken Sie die Eingabetaste).
3. Klicken Sie auf ein Bild, um zu sehen, wer es erstellt hat und unter welcher Lizenz es steht. Eine **Lizenz** legt fest, wie Sie ein Bild verwenden dürfen. Klicken Sie auf den Namen der Lizenz, um sie zu lesen.
4. Klicken Sie auf **Einfügen** (oder doppelklicken Sie auf das Bild).

**Was JeffDeck sendet.** Ihre Suchbegriffe gehen an die von Ihnen gewählte Bibliothek, und zwar nur, wenn Sie auf **Suchen** klicken oder die Eingabetaste drücken. JeffDeck fordert dann bei der Bibliothek die kleinen Vorschaubilder der Treffer an sowie das eine Bild, das Sie einfügen. Wie jede Webseite kann die Bibliothek die Internetadresse Ihres Computers sehen, und sie erfährt, dass JeffDeck die Anfrage stellt. Aus Ihrer Präsentation wird nichts gesendet.

Das Bild wird in der Mitte der Folie platziert. Es wird nicht größer als der Großteil der Folie. Der Titel des Bilds wird als **Alternativtext** gespeichert, also als Text, den eine Sprachausgabe für Menschen vorliest, die das Bild nicht sehen können. Die meisten Lizenzen verlangen, dass Sie den Urheber nennen. Wenn **Quellenangabe unter dem Bild hinzufügen** aktiviert ist, fügt JeffDeck unter dem Bild eine kleine Textzeile mit Titel, Urheber und Lizenz hinzu. Es handelt sich um ein Textfeld, das Sie verschieben oder ändern können. Prüfen Sie, ob die Lizenz zu Ihrer geplanten Verwendung des Bilds passt.

## Ein Symbol hinzufügen

Ein **Symbol** ist ein einfaches Bild, etwa ein Herz, ein Pfeil oder ein Briefumschlag. JeffDeck bietet mehr als 1.500 davon.

1. Klicken Sie auf **Einfügen > Illustrationen > Symbole**.
2. Geben Sie ein Wort in das Suchfeld ein, etwa **Pfeil** oder **E-Mail**. Nur die passenden Symbole bleiben sichtbar.
3. Klicken Sie auf ein Symbol. Um mehrere auszuwählen, halten Sie beim Klicken **Strg** oder **Umschalt** gedrückt.
4. Klicken Sie auf **Einfügen** (oder doppelklicken Sie auf ein Symbol).

Jedes Symbol wird als Bild von 2,5 × 2,5 cm in der Mitte der Folie eingefügt. Mehrere Symbole werden nebeneinander platziert. Sie werden in der Textfarbe des Designs gezeichnet. Symbole sind SVG-Bilder. Sie bleiben also scharf, wenn Sie sie vergrößern. Sie können sie wie jedes Bild verschieben, in der Größe ändern und drehen. Beim Speichern wird jedes Symbol als Bild und als SVG gespeichert, sodass auch andere Programme, die SVG darstellen können, es scharf anzeigen.

## Textkunst hinzufügen

**Textkunst** ist dekorativer Text: Buchstaben mit Farbe, Kontur, Schatten oder einer geschwungenen Form.

1. Klicken Sie auf **Einfügen > Text > Textkunst**. Ein Katalog mit Formatvorlagen wird geöffnet.
2. Klicken Sie auf eine Formatvorlage. Die Textkunst wird in der Mitte der Folie eingefügt, und ein Dialogfeld wird geöffnet, in dem ihr Text bereits markiert ist.
3. Geben Sie Ihren Text ein. Er ersetzt den bisherigen. Wählen Sie bei Bedarf eine Schriftart, einen Schriftgrad, **Fett** oder **Kursiv**. Klicken Sie auf **OK**.

Um den Text später zu ändern, doppelklicken Sie auf die Textkunst, oder markieren Sie sie und drücken die Eingabetaste. Sie können sie wie jedes Objekt verschieben, in der Größe ändern, drehen und löschen. Die Buchstaben werden gestreckt, um das Feld auszufüllen. Ziehen Sie also an den Ziehpunkten, um sie breiter oder höher zu machen.

## Eine Tabelle hinzufügen

Eine **Tabelle** ist ein Raster aus Zeilen und Spalten. Jedes Feld im Raster ist eine Zelle, und jede Zelle enthält ihren eigenen Text.

1. Klicken Sie auf **Einfügen > Tabellen > Tabelle**. Fahren Sie über das Raster, um die Anzahl der Zeilen und Spalten festzulegen, und klicken Sie dann. Oder wählen Sie **Tabelle einfügen…**, und geben Sie die **Anzahl der Spalten** und die **Anzahl der Zeilen** ein.
2. Die Tabelle erscheint in der Mitte der Folie, und Sie können sofort in die erste Zelle schreiben. Geben Sie Text ein, und drücken Sie die Tabulatortaste, um zur nächsten Zelle zu wechseln. Mit Umschalt+Tab gelangen Sie zurück. Wenn Sie in der letzten Zelle die Tabulatortaste drücken, wird eine Zeile hinzugefügt.

Während Sie in einer Zelle schreiben, wirken die Schaltflächen für Schriftart, Schriftgrad, Farbe und Ausrichtung auf der Registerkarte **Start** auf ihren Text. JeffDeck bietet noch keine Tabellentools zum Verbinden von Zellen, für Rahmen oder Tabellenformatvorlagen, aber Tabellen aus anderen Programmen werden so angezeigt, wie sie erstellt wurden.

## Einen Film oder Sound hinzufügen

Ein **Film** oder ein **Sound** wird direkt auf der Folie wiedergegeben. JeffDeck speichert die Datei in der Präsentation, sodass der Film oder Sound mit ihr weitergegeben wird.

1. Klicken Sie auf **Einfügen > Medien > Video**, und wählen Sie **Video auf diesem Gerät…**. Oder klicken Sie auf **Einfügen > Medien > Audio**, und wählen Sie **Audio auf diesem Gerät…**.
2. Wählen Sie eine Datei aus, und klicken Sie auf **Öffnen**. JeffDeck liest die Datei einen Moment lang ein. Dann platziert es den Film oder Sound auf der Folie.

Ein Film zeigt sein **Posterbild** an, also sein erstes Bild. Ein Sound zeigt das Bild eines Lautsprechers. Sie können beide wie jedes Bild verschieben, in der Größe ändern, drehen und löschen. Beide werden in die **Klickreihenfolge** aufgenommen. Das ist die Liste der Schritte, die die Bildschirmpräsentation abspielt, einen pro Klick. Der Film oder Sound wird in der Bildschirmpräsentation also per Klick wiedergegeben.

JeffDeck gibt die Dateiarten wieder, die der Computer abspielen kann, zum Beispiel .mp4, .mov, .avi, .wmv, .mkv, .webm, .mp3, .wav, .m4a, .wma, .ogg und .flac. Bei einer Datei, die der Computer nicht abspielen kann, wird an ihrer Stelle eine Meldung angezeigt. Der Rest von JeffDeck funktioniert weiter. Ein Film, auf den eine Datei nur verweist, im Web oder auf einem Datenträger, wird nicht wiedergegeben. Die Datei muss in der Präsentation enthalten sein.

JeffDeck gibt eine Datei erst wieder, wenn Sie es verlangen. Beim Öffnen, Speichern und Drucken einer Präsentation wird nur das Posterbild verwendet.

### Einen Film oder Sound beim Bearbeiten wiedergeben

Klicken Sie auf den Film oder Sound, oder zeigen Sie mit der Maus darauf. Darunter erscheint eine **Steuerleiste**:

- Die Schaltfläche **Wiedergeben** startet die Wiedergabe. Während der Wiedergabe hält dieselbe Schaltfläche sie an.
- Die **Suchleiste** zeigt, wie weit die Wiedergabe fortgeschritten ist, und die Zeit. Klicken Sie darauf, um zu dieser Stelle zu springen.
- Die Schaltfläche **Lautsprecher** schaltet den Ton stumm, und der kleine Schieberegler daneben legt die Lautstärke fest.

Der Film wird direkt auf der Folie wiedergegeben und beim Zoomen mit vergrößert oder verkleinert. Es wird immer nur einer gleichzeitig wiedergegeben. Die Wiedergabe endet, wenn Sie zu einer anderen Folie wechseln.

### Festlegen, wie die Wiedergabe erfolgt

Markieren Sie einen Film oder Sound. Die Registerkarte **Wiedergabe** wird angezeigt. Dort legen Sie fest, wie der Film oder Sound in der Bildschirmpräsentation wiedergegeben wird: wann er startet, wie laut er ist, wo er beginnt und endet und mehr. Drücken Sie auf dieser Registerkarte **F1**, um das zugehörige Thema anzuzeigen.

### Filme und Sounds in der Bildschirmpräsentation

In der Bildschirmpräsentation wird ein Film oder Sound so wiedergegeben, wie es in der Datei festgelegt ist:

- **In Klickreihenfolge**: Er wird per Klick zusammen mit den Animationen der Folie wiedergegeben. Der Klick, der ihn startet, schaltet die Präsentation nicht weiter.
- **Automatisch**: Er wird von selbst wiedergegeben, sobald er an der Reihe ist. Ein erster startet, wenn die Folie erscheint.
- **Beim Daraufklicken**: Er wird wiedergegeben, wenn Sie darauf klicken.

Zeigen Sie auf einen Film, um seine Steuerleiste einzublenden. Klicken Sie auf den Film, um ihn wiederzugeben oder anzuhalten. Der Film wird an seiner Stelle auf der Folie wiedergegeben oder füllt den Bildschirm, wenn **Im Vollbildmodus wiedergeben** aktiviert ist. Er endet beim Folienwechsel, sofern er nicht folienübergreifend wiedergegeben werden soll.

## Objekte markieren, verschieben und anordnen

- Klicken Sie auf ein Objekt, um es zu markieren. Halten Sie **Umschalt** gedrückt, und klicken Sie, um weitere hinzuzufügen. Oder ziehen Sie auf einem leeren Bereich der Folie einen Rahmen um Objekte. Mit der **Tabulatortaste** wechseln Sie von einem Objekt zum nächsten.
- Ziehen Sie ein Objekt, um es zu verschieben. Halten Sie **Umschalt** gedrückt, um es nur waagerecht oder senkrecht zu verschieben. Halten Sie beim Ziehen **Strg** gedrückt, um eine Kopie zu erstellen.
- Legen Sie ein Bild auf einem anderen ab, tauschen die beiden Bilder ihre Plätze. Halten Sie beim Ziehen **Strg** gedrückt, um stattdessen eine Kopie zu erstellen.
- Drücken Sie die Pfeiltasten, um das markierte Objekt zu verschieben. Halten Sie **Alt** gedrückt für den kleinsten Schritt.
- Ziehen Sie an einem Ziehpunkt, um die Größe zu ändern. Bilder behalten an einer Ecke ihre Proportionen. Halten Sie Umschalt gedrückt, um sie frei zu strecken. Bei anderen Objekten halten Sie Umschalt gedrückt, um die Proportionen beizubehalten.
- Ziehen Sie am runden Ziehpunkt über einem Objekt, um es zu drehen.
- Drücken Sie **Entf**, um das markierte Objekt zu entfernen.

**Start > Zeichnen > Anordnen** enthält **In den Vordergrund**, **Eine Ebene nach vorne**, **Eine Ebene nach hinten** und **In den Hintergrund**, um festzulegen, welches Objekt oben liegt. Außerdem gibt es **Gruppieren** (Strg+Umschalt+G) und **Gruppierung aufheben**, mit denen sich mehrere Objekte gemeinsam verschieben und skalieren lassen, sowie **90° nach rechts drehen**, **90° nach links drehen**, **Horizontal spiegeln** und **Vertikal spiegeln**.

Aktivieren Sie **Ansicht > Anzeigen > Lineal**, **Gitternetzlinien** oder **Führungslinien** als Hilfe beim Platzieren von Objekten. Unter **Datei > Optionen > Ansicht** finden Sie **Objekte an anderen Objekten ausrichten**. Siehe [Registerkarte „Ansicht“](tab-view) und [Einstellungen von JeffDeck ändern](options).

## Objekte, die JeffDeck anzeigt, aber noch nicht erstellen kann

Eine in einem anderen Programm erstellte Präsentation kann Elemente enthalten, für die JeffDeck noch keine Tools bietet. JeffDeck zeigt sie so gut wie möglich an und behält sie beim Speichern bei.

- **Textkunst** aus einer älteren Datei wird angezeigt und gespeichert, und Sie können ihren Text ändern, genau wie bei Textkunst, die Sie selbst hinzufügen. JeffDeck bietet noch keine Tools, um ihre Formatvorlage oder Form nachträglich zu ändern. Um eine andere Formatvorlage auszuprobieren, fügen Sie neue Textkunst hinzu.
- **Diagramme** werden anhand der in der Datei gespeicherten Werte gezeichnet und vollständig gespeichert. Bearbeiten können Sie sie noch nicht.
- **SmartArt-Grafiken** werden so gezeichnet, wie sie gespeichert wurden. Eine SmartArt-Grafik ist eine Gruppe zusammengehöriger Formen, etwa eine Reihe von Kästen oder eine Abfolge von Schritten. JeffDeck behandelt die gesamte Grafik als ein Objekt. Sie können sie markieren, verschieben, in der Größe ändern, kopieren und löschen. Die Zeichnung wird dabei mit vergrößert oder verkleinert. Ihren Text können Sie noch nicht ändern. Beim Speichern wird die Grafik vollständig in die Datei zurückgeschrieben, sodass das Programm, mit dem sie erstellt wurde, sie weiterhin bearbeiten kann. Eine eingefügte Kopie ist nur ein Bild der Grafik. Eine duplizierte Folie behält die vollständige Grafik.
- **Formeln** werden als das Bild angezeigt, das die Datei von ihnen speichert. Eine Formel ist mathematischer Inhalt in besonderem Satz, etwa ein Bruch oder eine Quadratwurzel. Sie können das Bild verschieben, in der Größe ändern, drehen, kopieren und löschen, die Formel selbst aber noch nicht ändern. Beim Speichern wird die Formel unverändert in die Datei zurückgeschrieben. Das funktioniert auch bei einem Textfeld, in dem eine Formel von weiterem Text umgeben ist.
