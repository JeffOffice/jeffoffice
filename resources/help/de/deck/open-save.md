# Präsentationen öffnen und speichern

JeffDeck speichert Ihre Arbeit in PPTX-Dateien und öffnet verschiedene Arten von Präsentationsdateien.

## Eine neue Präsentation beginnen

Drücken Sie Strg+N. Ein neues Fenster mit einer leeren Präsentation wird geöffnet. Sie können auch auf **Datei > Neu** und dann auf **Leere Präsentation** klicken. Enthält das aktuelle Fenster eine neue Präsentation, die noch niemand bearbeitet hat, tritt die leere Präsentation an ihre Stelle. Andernfalls wird sie in einem eigenen Fenster geöffnet.

## Speichern

Drücken Sie Strg+S, oder klicken Sie auf **Datei > Speichern**. Beim ersten Mal fragt JeffDeck nach einem Namen und einem Speicherort. Danach ersetzt **Speichern** die Datei durch Ihren aktuellen Stand. Unten erscheint eine Meldung mit „Gespeichert“ und dem Dateinamen.

Ein Sternchen (*) hinter dem Namen in der Titelleiste bedeutet, dass Sie nicht gespeicherte Änderungen haben. Speichern Sie häufig. Falls JeffDeck unerwartet beendet wird, lesen Sie [Nicht gespeicherte Arbeit wiederherstellen](recover).

Meldet JeffDeck, dass einige Objekte „in dieser Art von Datei noch nicht gespeichert werden können“, ist die Datei zwar gespeichert, JeffDeck konnte diese Objekte aber nicht schreiben. Bewahren Sie auch die Originaldatei auf.

## Unter einem neuen Namen oder Dateityp speichern

Klicken Sie auf **Datei > Speichern unter**, oder drücken Sie F12. Geben Sie einen Namen ein, wählen Sie den Dateityp aus, und klicken Sie auf **Speichern**. Zur Auswahl stehen:

- **Präsentation (*.pptx)** ist die übliche Wahl.
- **Vorlage (*.potx)** speichert die Folien als Muster, aus dem Sie neue Präsentationen erstellen.
- **Bildschirmpräsentation (*.ppsx)** speichert eine Präsentation zum Vorführen.

Wenn Sie keine Dateiendung angeben, fügt JeffDeck die zum Dateityp passende hinzu. Nach dem Speichern zeigt die Titelleiste den neuen Namen, und Sie arbeiten in der neuen Datei weiter.

Eine Präsentation, die Sie aus einer Vorlage geöffnet haben, wird als neue Präsentation gespeichert: **Speichern** fragt nach einem Namen, sodass die Vorlage unverändert bleibt. Dasselbe gilt für Präsentationen, die Sie aus einer älteren PPT-, PPS- oder POT-Datei oder aus einer ODP- oder OTP-Datei geöffnet haben.

## Öffnen

Drücken Sie Strg+O, um direkt eine Datei auszuwählen. Sie können auch auf **Datei > Öffnen** und dann auf **Durchsuchen** oder auf einen Namen unter **Angeheftet** oder **Zuletzt verwendete Präsentationen** klicken.

Die Datei wird in diesem Fenster geöffnet, wenn es eine neue Präsentation enthält, die noch niemand bearbeitet hat. Andernfalls wird sie in einem eigenen Fenster geöffnet.

Klicken Sie mit der rechten Maustaste auf einen Namen in der Liste, um **An Liste anheften** (er bleibt dann oben), **Von Liste lösen** oder **Aus Liste entfernen** zu wählen. Ein grau dargestellter Name bedeutet, dass JeffDeck die Datei zurzeit nicht finden kann.

## Dateitypen, die JeffDeck liest

- **.pptx, .potx und .ppsx** sind ein Format in drei Formen: Präsentation, Vorlage und Bildschirmpräsentation. JeffDeck liest und schreibt alle drei.
- **.ppt, .pps und .pot** sind die älteren Dateitypen. JeffDeck kann sie lesen, aber nicht schreiben. **Speichern** fragt daher nach einem neuen Namen und speichert eine PPTX-Datei (bei einer PPS-Datei eine PPSX-Datei). Das Original wird nie überschrieben.
- **.odp und .otp** sind OpenDocument-Präsentationen und deren Vorlagen. JeffDeck liest sie und speichert sie als neue PPTX-Datei. Das Original wird nie überschrieben.

Kann ein Teil einer Datei nicht gelesen werden, öffnet JeffDeck den Rest und listet auf, was ausgelassen wurde. Kann die gesamte Datei nicht gelesen werden, nennt JeffDeck den Grund.

## Was erhalten bleibt, aber nicht angezeigt wird

Manche Teile einer Datei kann JeffDeck noch nicht anzeigen oder ändern. JeffDeck behält sie bei ihren Folien und schreibt sie beim Speichern zurück, sodass sie nicht verloren gehen. Dazu gehören Animationen, die in der Bildschirmpräsentation abgespielt werden, Filme und Sounds, die noch nicht abgespielt werden, sowie Übergangseffekte, für die JeffDeck keine Entsprechung hat und die als Verblassen abgespielt werden. Diagramme und SmartArt-Grafiken werden so angezeigt, wie sie gespeichert wurden. Siehe [Willkommen bei JeffDeck](start).
