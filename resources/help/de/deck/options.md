# JeffDeck-Einstellungen ändern

Ihre Einstellungen finden Sie im Fenster **JeffDeck-Optionen**. Klicken Sie auf **Datei > Optionen**, um es zu öffnen. Es hat vier Registerkarten. Klicken Sie auf **OK**, um Ihre Änderungen zu übernehmen, oder auf **Abbrechen**, um sie zu verwerfen.

## Allgemein

- **Benutzername** und **Initialen** werden bei den Kommentaren angezeigt, die Sie schreiben. Siehe [Kommentare](comments).
- **Design** ist **Systemeinstellung verwenden**, **Hell** oder **Dunkel**. Die Änderung wird sofort sichtbar.
- **Anzeigesprache** ist die Sprache, in der JeffDeck selbst angezeigt wird. **Systemsprache verwenden** richtet sich nach Ihrem Computer. Weitere Sprachen erscheinen in dieser Liste, sobald Übersetzungen verfügbar sind. Eine neue Sprache wird beim nächsten Öffnen von JeffDeck wirksam.
- **Beim Start von JeffDeck nach Updates suchen** lässt JeffDeck bei jedem Start nach einer neueren Version suchen. Gibt es eine, zeigt das Fenster **Update verfügbar**, was neu ist. Wählen Sie **Jetzt aktualisieren**, **Später** oder **Diese Version überspringen**. Unter Windows lädt **Jetzt aktualisieren** das Installationsprogramm herunter. Es installiert die neue Version aller JeffOffice-Apps und fordert Sie auf, geöffnete Apps zu schließen. Auf anderen Computern heißt die Schaltfläche **Downloadseite öffnen**. Sie öffnet die Seite, auf der Sie die neue Version erhalten. Ist auch JeffPub geöffnet, weist pro Tag nur eines der beiden Programme auf eine neue Version hin.
- **Betaversionen erhalten (frühe Builds zum Testen)** lässt JeffDeck auch Betaversionen anbieten. Diese erscheinen vor den regulären Versionen. Sie können noch kleine Mängel haben.
- **Anonyme Nutzungsstatistiken senden** lässt Sie Angaben dazu teilen, wie JeffDeck verwendet wird. Anonym bedeutet, dass diese Angaben nichts darüber verraten, wer Sie sind. Ist die Option aktiviert, sendet JeffDeck diese Angaben einmal täglich und am Tag eines Updates: dass es sich um JeffDeck handelt, die Version, Ihr Betriebssystem und Ihre Sprache, wie oft das Programm gestartet wurde, wie oft jeder Befehl verwendet wird und welche Art von Datei Sie geöffnet oder gespeichert haben (zum Beispiel .pptx). Wird JeffDeck einmal unerwartet beendet, sendet es beim nächsten Start außerdem einen Absturzbericht. Der Bericht gibt an, an welcher Stelle im Programm es angehalten hat, damit das Problem gefunden und behoben werden kann. JeffDeck sendet niemals Ihre Dateien, deren Namen oder Inhalte und nichts, was Sie eingegeben haben. Ist die Option deaktiviert, wird auch kein Absturzbericht gesendet. JeffDeck fragt beim ersten Start in einem Fenster namens **Helfen Sie, JeffDeck zu verbessern** danach. Es fragt nicht, wenn Sie bereits in JeffPub oder bei der Installation eine Wahl getroffen haben.

**Benutzername**, **Initialen**, **Design** und **Anzeigesprache** sowie die Einstellungen zu Updates und Statistiken gelten für alle JeffOffice-Apps: Ändern Sie eine davon hier, ändert sie sich in jeder App.

## Dokumentprüfung

Diese Kontrollkästchen steuern die Hilfe bei Rechtschreibung und Eingabe. Siehe [Text eingeben und formatieren](text).

- **Rechtschreibung während der Eingabe prüfen**
- **Wörter in GROSSBUCHSTABEN ignorieren**
- **Wörter mit Zahlen ignorieren**
- **Text während der Eingabe ersetzen (AutoKorrektur)** korrigiert häufige Tippfehler.
- **Gerade Anführungszeichen durch typografische ersetzen** wandelt " und ' in typografische Anführungszeichen um.
- **Während der Eingabe automatisch formatieren (Striche, Brüche, Ordnungszahlen, automatische Listen)**

## Ansicht

- **Lineal anzeigen** blendet die Lineale an den Rändern der Folie ein. Dies entspricht **Ansicht > Anzeigen > Lineal** und gilt für jedes Fenster, jetzt und für neu geöffnete Fenster.
- **Objekte an anderen Objekten ausrichten** richtet ein Objekt, das Sie ziehen, an den anderen Objekten auf der Folie aus.

## Speichern

- **Schriftarten in der Datei einbetten** speichert die in Ihren Folien verwendeten Schriftarten beim Speichern in der Datei, damit die Folien auch auf einem Computer ohne diese Schriftarten gleich aussehen. Die Option ist aktiviert, bis Sie sie deaktivieren. Sie bettet nur die Schriftarten ein, die mit JeffDeck geliefert werden, und vergrößert die Datei. Einzelheiten finden Sie im Thema „Präsentationen öffnen und speichern“ unter „Schriftarten in der Datei“.
