# Text formatieren und gestalten

Die meisten Folien bestehen hauptsächlich aus Text. Dieses Thema zeigt, wo Text auf einer Folie steht und wie Sie ihn formatieren.

## Text in einen Platzhalter eingeben

Ein **Platzhalter** ist ein Feld auf einem Layout, das den Titel, den Untertitel, den Text oder ein Bild einer Folie aufnimmt. Eine neue Folie erhält eine Kopie jedes Platzhalters, den ihr Layout hat. Ein leerer Platzhalter zeigt einen gepunkteten Rahmen und einen Hinweis, zum Beispiel **Klicken, um Titel hinzuzufügen**, **Klicken, um Untertitel hinzuzufügen** oder **Klicken, um Text hinzuzufügen**. Rahmen und Hinweis erscheinen nur im Bearbeitungsfenster. Sie werden nie gedruckt und nie in der Bildschirmpräsentation angezeigt.

Klicken Sie in einen Platzhalter, und geben Sie dann Text ein. Drücken Sie Esc, um die Texteingabe zu beenden. Das Feld bleibt markiert. Drücken Sie Esc noch einmal, um die Markierung aufzuheben. Sie können auch ein Feld markieren und sofort mit dem Schreiben beginnen.

Text, der für seinen Platzhalter zu lang ist, wird so weit verkleinert, dass er hineinpasst. Ziehen Sie an einem Platzhalter, um ihn zu verschieben, oder an einem Ziehpunkt, um seine Größe zu ändern. Um die Platzhalter wieder dorthin zu setzen, wo das Layout sie vorsieht, klicken Sie auf **Start > Folien > Zurücksetzen**. Siehe [Folien hinzufügen, ändern und löschen](slides).

## Textfeld hinzufügen

Für Text, der nicht in einem Platzhalter steht, klicken Sie auf **Einfügen > Text > Textfeld**, ziehen dann auf der Folie ein Feld auf und geben Text ein. Ein Textfeld lässt sich wie jedes andere Objekt verschieben und in der Größe ändern. Siehe [Formen, Bilder, Tabellen und Textkunst](objects).

## Schrift formatieren

Markieren Sie den Text, den Sie ändern möchten: Ziehen Sie darüber, oder doppelklicken Sie auf ein Wort. Um den gesamten Text eines Felds zu ändern, markieren Sie das ganze Feld. Verwenden Sie dann die Gruppe **Start > Schriftart**:

- Das Feld **Schriftart** und das Feld **Schriftgrad**. **Schriftgrad vergrößern** und **Schriftgrad verkleinern** ändern die Größe schrittweise (Strg+Umschalt+> und Strg+Umschalt+<).
- **Fett** (Strg+B), **Kursiv** (Strg+I), **Unterstreichen** (Strg+U), **Durchgestrichen** und **Schatten**.
- **Zeichenabstand** legt fest, wie eng oder weit die Buchstaben stehen, von **Sehr eng** bis **Sehr weit**. **Weitere Abstände…** öffnet ein Fenster für einen eigenen Wert.
- **Groß-/Kleinschreibung** bietet **Satzbeginn groß**, **kleinbuchstaben**, **GROSSBUCHSTABEN**, **Jedes Wort groß schreiben** und **gROSS-/kLEINSCHREIBUNG uMKEHREN**.
- **Schriftfarbe** öffnet die Farben des Designs der Präsentation und weitere Farben.
- **Formatierung löschen** (Strg+Leertaste) entfernt die Formatierung, die Sie hinzugefügt haben.

Die kleine Schaltfläche mit drei Punkten in der Ecke der Gruppe öffnet das Fenster **Schriftart** (Strg+T), in dem alle diese Optionen an einer Stelle stehen.

Wörter können **Effekte** haben. Ein Effekt ist eine Optik, die den Buchstaben hinzugefügt wird, etwa ein Schatten, ein Leuchten oder eine Spiegelung. Ein **Schatten** ist eine weiche, dunkle Kopie der Wörter, die ein wenig nach unten und nach rechts versetzt ist. Ein **Leuchten** ist ein weicher Farbrand um die Buchstaben. Eine **Spiegelung** ist eine verblasste, auf dem Kopf stehende Kopie der Wörter unter ihnen. Ein **Innenschatten** verdunkelt die Buchstaben entlang einer inneren Kante. JeffDeck zeigt die Effekte, die eine Präsentation bereits hat, und behält sie beim Speichern bei. Mit der Schaltfläche **Schatten** erhalten die markierten Wörter einen Schatten, ein zweiter Klick entfernt ihn wieder. Ein Schatten wird direkt unter seinen Buchstaben gezeichnet, sodass er nie andere Wörter überdeckt. In einer Präsentation, die auf Format verkleinert wurde, schrumpfen die Schatten mit den Wörtern.

**Formatierung übertragen** kopiert, wie Text oder ein Objekt aussieht. Markieren Sie, was Sie kopieren möchten, klicken Sie auf **Formatierung übertragen**, und klicken Sie dann auf oder ziehen Sie über das, was gleich aussehen soll. Halten Sie beim Klicken auf die Schaltfläche die Umschalttaste gedrückt, um die Formatierung mehrfach zu übertragen. Klicken Sie erneut auf die Schaltfläche oder drücken Sie Esc, um aufzuhören.

## Die Minisymbolleiste

Wenn Sie Wörter mit der Maus markieren, schwebt über ihnen eine kleine Leiste. Sie enthält die Schaltflächen, die Sie am häufigsten brauchen: **Fett**, **Kursiv**, **Unterstreichen**, Text verkleinern oder vergrößern, linksbündige, zentrierte und rechtsbündige Ausrichtung, Aufzählungszeichen und Nummerierung. Über ihnen steht ein Feld **Schriftart**, und am Ende befindet sich die Schaltfläche **Schriftfarbe**. Es sind dieselben Schaltflächen wie im Menüband, und jede davon ist ein einzelner Schritt, den Sie rückgängig machen können. Die Leiste nimmt Ihnen die Tastatur für den Text nie weg. Sie verschwindet, wenn Sie etwas eingeben, Esc drücken, die Folie verschieben oder so klicken, dass keine Wörter mehr markiert sind.

## Absätze formatieren

Klicken Sie in einen Absatz, oder markieren Sie mehrere. Verwenden Sie dann die Gruppe **Start > Absatz**:

- **Aufzählungen** und **Nummerierung** schalten eine Liste ein oder aus. Der Pfeil neben jeder Schaltfläche öffnet eine Auswahl an Formaten. Aufzählungszeichen können ein Kreis, ein Ring, ein Quadrat, eine Raute, ein Pfeil, ein Häkchen, ein Stern oder ein Strich sein. Nummerierungen können 1. 2. 3., a. b. c., A. B. C., i. ii. iii., I. II. III., 1) 2) 3) oder (1) (2) (3) sein. **Aufzählungszeichen und Nummerierung…** öffnet ein Fenster mit weiteren Auswahlmöglichkeiten.
- **Listenebene verringern** und **Listenebene erhöhen** rücken eine Zeile um eine Ebene nach außen oder innen. Jede Ebene ist weiter eingerückt. In einem Textplatzhalter einer Folie übernimmt eine verschobene Zeile das Aufzählungszeichen, den Einzug und die Schriftgröße, die das Layout der Folie für die neue Ebene vorsieht, sodass sie wie die Beispielzeilen auf dem Layout aussieht.
- **Zeilenabstand** bietet 1, 1,15, 1,5, 2, 2,5 und 3, und **Absatz…** für weitere Einstellungen.
- **Linksbündig** (Strg+L), **Zentriert** (Strg+E), **Rechtsbündig** (Strg+R) und **Blocksatz** (Strg+J).

Ein Textplatzhalter auf einer neuen Folie hat bereits die Aufzählungszeichen seines Layouts. Was Sie dort eingeben, ist also von Anfang an mit Aufzählungszeichen versehen. Das erste Design, JeffOffice, hat keine, und ein Layout ohne Aufzählungszeichen zeigt auch keine an.

Drei Schaltflächen ändern das ganze Feld und nicht nur einen Absatz. **Textrichtung** legt **Horizontal** oder **Gesamten Text um 90° drehen** fest. **Text ausrichten** setzt den Text an den **Oberen**, **Mittleren** oder **Unteren** Rand seines Felds. **Spalten** legt in einem Textfeld eine, zwei oder drei Spalten fest.

## Wörter suchen und ersetzen

Um nach Wörtern zu suchen, drücken Sie **Strg+F**, oder klicken Sie auf **Start > Bearbeiten > Suchen**. Der Bereich **Suchen und Ersetzen** öffnet sich rechts. Geben Sie die Wörter bei **Suchen nach** ein. Drücken Sie dann die Eingabetaste, oder klicken Sie auf **Weitersuchen**.

JeffDeck beginnt auf der Folie, auf der Sie gerade sind. Es durchsucht Titel, Textfelder, Formen, Tabellen, Textkunst und Sprechernotizen. Auch ausgeblendete Folien werden durchsucht. Wenn es die Wörter findet, zeigt es die Folie und markiert die Wörter. Bei Textkunst markiert es die gesamte Textkunst. Ein Treffer in den Sprechernotizen wird im Notizenfeld unter der Folie markiert. Klicken Sie erneut auf **Weitersuchen**, um zum nächsten Treffer zu gelangen. Nach der letzten Folie beginnt die Suche wieder bei der ersten.

- **Groß-/Kleinschreibung beachten** findet nur Wörter mit denselben Großbuchstaben. „Plan“ findet nicht „plan“.
- **Nur ganze Wörter suchen** überspringt längere Wörter, die Ihr Suchbegriff enthalten. „plan“ findet nicht „planet“.
- **Sprechernotizen durchsuchen** ist zu Beginn aktiviert. Deaktivieren Sie es, um nur die Folien zu durchsuchen.

Um Wörter zu ändern, drücken Sie **Strg+H**, oder klicken Sie auf **Start > Bearbeiten > Ersetzen**. Geben Sie die neuen Wörter bei **Ersetzen durch** ein. Klicken Sie auf **Ersetzen**, um den angezeigten Treffer zu ändern und zum nächsten zu wechseln. Klicken Sie auf **Alle ersetzen**, um jeden Treffer zu ändern. Der Bereich zeigt an, wie viele Treffer geändert wurden. „Alle ersetzen“ ist ein einziger Schritt, daher stellt ein einziges **Rückgängig** (Strg+Z) alle Wörter wieder her.

## Das Kontextmenü

Klicken Sie mit der rechten Maustaste auf die Folie, um die Befehle zu sehen, die zu Ihrer Tätigkeit passen. Sie können auch **Umschalt+F10** drücken oder die **Menütaste** Ihrer Tastatur verwenden. Das Menü öffnet sich an der Textmarke oder am markierten Objekt.

- **Bei Wörtern, die Sie gerade eingeben:** Ist ein Wort als falsch geschrieben markiert, beginnt das Menü mit Rechtschreibvorschlägen. Klicken Sie auf einen Vorschlag, um das Wort zu korrigieren. **Alle ignorieren** lässt das Wort vorerst unverändert, und **Zum Wörterbuch hinzufügen** behält es bei. Danach folgen **Ausschneiden**, **Kopieren**, **Einfügen**, **Schriftart…**, **Absatz…**, **Aufzählungszeichen**, **Nummerierung**, **Link**, **Thesaurus** und **Neuer Kommentar**.
- **Bei einem Objekt:** **Ausschneiden**, **Kopieren**, **Einfügen**, **Einfügeoptionen**, **Löschen**, **Text bearbeiten**, **Gruppieren** oder **Gruppierung aufheben**, **Anordnen** (In den Vordergrund, Eine Ebene nach vorne, Eine Ebene nach hinten und In den Hintergrund), **Ausrichten**, **Als Bild speichern**, **Größe und Position**, **Form formatieren** (bei einem Bild **Bild formatieren**), **Alternativtext**, **Link** und **Neuer Kommentar**. **Einfügeoptionen** erlaubt es, mit der Formatierung einzufügen, die die Wörter hatten, nur mit den Wörtern oder über **Inhalte einfügen…**, wobei gefragt wird, welche Form Sie möchten. **Als Bild speichern** speichert das Objekt als Datei im Format .png oder .jpg. **Größe und Position** öffnet den Bereich „Format“ bei den Feldern für Größe und Position. **Form formatieren** öffnet den Bereich „Format“ für dieses Objekt. **Alternativtext** öffnet den Bereich „Format“, in dem Sie das Objekt für Menschen beschreiben können, die es nicht sehen. **Text bearbeiten** setzt die Einfügemarke in das Feld, die Form oder die Tabelle, damit Sie schreiben können. **Ausrichten** ist verfügbar, wenn das Objekt Wörter enthält. Es richtet die Wörter links, zentriert oder rechts aus oder verteilt sie auf die ganze Zeile.
- **Auf einer leeren Stelle der Folie:** **Einfügen**, **Layout**, **Folie zurücksetzen**, **Hintergrund formatieren**, **Raster und Führungslinien**, **Lineal** und **Neuer Kommentar**.

Jeder Befehl ist derselbe wie im Menüband und funktioniert deshalb auch genauso.

## Weitere Inhalte für Text

- **Einfügen > Symbole > Symbol** fügt ein Zeichen ein, das nicht auf der Tastatur liegt.
- **Einfügen > Text > Datum und Uhrzeit** fügt das Datum oder die Uhrzeit in den Text ein, den Sie gerade schreiben. Wählen Sie eine **Sprache**, um die Namen der Wochentage und Monate in dieser Sprache zu sehen, etwa Deutsch oder Japanisch. Wählen Sie ein Format. Aktivieren Sie **Automatisch aktualisieren**, wenn Sie ein Feld möchten, das sich selbst aktuell hält. Das Feld merkt sich seine Sprache. Eine `.pptx`-Datei speichert die Art des Datums (eine von dreizehn) und die Sprache, aber kein eigenes Format. Ein Datum in einem anderen Format wird deshalb auf die nächstliegende Art zurückgesetzt. Eine `.odp`-Datei speichert Format und Sprache genau. Lassen Sie das Kästchen leer, um reinen Text einzufügen, der sich nie ändert. Siehe [Folienformat, Hintergrund und Fußzeilen](design) für ein Datum auf jeder Folie.
- **Einfügen > Text > Foliennummer > Foliennummer im Text** fügt die Nummer der Folie in den Text ein, den Sie gerade schreiben. Sie ist ein Feld, zeigt auf jeder Folie, auf der sie steht, die richtige Nummer an und ändert sich von selbst, wenn Sie die Folie verschieben. Der Befehl ist grau, wenn Sie nicht gerade in einem Textfeld schreiben. Um auf jeder Folie eine Nummer anzuzeigen, verwenden Sie stattdessen die anderen Optionen in diesem Menü.
- **Einfügen > Links > Link** (Strg+K) macht den markierten Text oder das markierte Objekt zu einem Link. Wählen Sie unter **Verknüpfen mit** eine Webadresse, eine E-Mail-Adresse, eine Stelle in der Präsentation (eine Folie, die nächste oder vorherige Folie oder das Ende der Show), eine vorhandene Datei, eine andere Präsentation oder eine neue Präsentation. Bei einer neuen Präsentation geben Sie den vollständigen Pfad dafür ein oder klicken auf **Durchsuchen**. JeffDeck legt dort eine leere Präsentation an und verknüpft sie. Eine vorhandene Datei wird nie überschrieben. In der Bildschirmpräsentation öffnet ein Klick auf einen Link Webseiten und E-Mail-Adressen. Andere Links haben derzeit keine Funktion.
- **Überprüfen > Dokumentprüfung > Rechtschreibung** (F7) prüft die Rechtschreibung. **Thesaurus** (Umschalt+F7) sucht andere Wörter. **Wortanzahl** zählt die Wörter auf den Folien, beim Schreiben auch in der Auswahl. Um die Rechtschreibung während der Eingabe zu prüfen, siehe [JeffDeck-Einstellungen ändern](options).

## Schriftmerkmale

Im Feld **Schriftart** enthält die Registerkarte **Erweitert** Ligaturen, Zahlenabstände, Zahlzeichen, stilistische Sätze und kontextabhängige Alternativen. Der Folientext hat keine Ligaturen, es sei denn, Sie wählen sie hier aus. Eine gespeicherte Präsentationsdatei kann diese Einstellungen nicht speichern. Sie werden deshalb nur während der Arbeit beibehalten.
