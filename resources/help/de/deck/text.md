Die meisten Folien bestehen hauptsächlich aus Wörtern. Dieses Thema zeigt, wo Text auf einer Folie steht und wie Sie ihn formatieren.

## In einen Platzhalter schreiben

Ein **Platzhalter** ist ein Feld auf einem Layout, das den Titel, den Untertitel, Text oder ein Bild einer Folie aufnimmt. Eine neue Folie erhält eine Kopie jedes Platzhalters, den ihr Layout hat. Ein leerer Platzhalter zeigt einen gepunkteten Rahmen und einen Hinweis, etwa **Klicken, um Titel hinzuzufügen**, **Klicken, um Untertitel hinzuzufügen** oder **Klicken, um Text hinzuzufügen**. Rahmen und Hinweis werden nur im Bearbeitungsfenster angezeigt. Sie werden nie gedruckt und nie in der Bildschirmpräsentation gezeigt.

Klicken Sie in einen Platzhalter, und schreiben Sie dann. Drücken Sie Esc, um das Schreiben zu beenden. Das Feld bleibt markiert. Drücken Sie Esc noch einmal, um die Markierung aufzuheben. Sie können auch ein Feld markieren und sofort losschreiben.

Text, der zu lang für seinen Platzhalter ist, wird kleiner, damit er passt. Ziehen Sie an einem Platzhalter, um ihn zu verschieben, oder an einem Griff, um seine Größe zu ändern. Um die Platzhalter wieder an die Stelle zu setzen, die das Layout vorsieht, klicken Sie auf **Start > Folien > Zurücksetzen**. Siehe [Folien hinzufügen, ändern und löschen](slides).

## Textfeld hinzufügen

Für Wörter, die nicht in einem Platzhalter stehen, klicken Sie auf **Einfügen > Text > Textfeld**, ziehen dann auf der Folie ein Feld auf und schreiben. Durch Ziehen entsteht ein Feld in der Größe, die Sie ziehen, jede Seite ist aber mindestens 0,6 cm lang. Ein Klick ohne nennenswertes Ziehen erzeugt ein Feld von 5 cm Breite und 2,5 cm Höhe. Halten Sie **Umschalt** gedrückt, damit das Feld quadratisch bleibt. Drücken Sie **Esc** oder wählen Sie ein anderes Werkzeug, um das Textfeldwerkzeug zu deaktivieren. Ein Textfeld lässt sich wie jedes andere Objekt verschieben und in der Größe ändern. Siehe [Formen, Bilder, Tabellen und Textkunst](objects).

## Schrift formatieren

Markieren Sie den Text, den Sie ändern möchten: Ziehen Sie darüber, oder doppelklicken Sie auf ein Wort. Markieren Sie das ganze Feld, um seinen gesamten Text zu ändern. Verwenden Sie dann die Gruppe **Start > Schriftart**:

- Die Felder **Schriftart** und **Schriftgrad**. **Schriftgrad vergrößern** und **Schriftgrad verkleinern** ändern die Größe schrittweise (Strg+Umschalt+> und Strg+Umschalt+<).
- **Fett** (Strg+B), **Kursiv** (Strg+I), **Unterstreichung** (Strg+U), **Durchgestrichen** und **Schatten**.
- **Zeichenabstand** legt fest, wie eng oder weit die Buchstaben stehen, von **Sehr eng** bis **Sehr weit**. **Weitere Abstände…** öffnet ein Fenster für einen eigenen Wert.
- **Groß-/Kleinschreibung** bietet **Satzbeginn groß.**, **kleinbuchstaben**, **GROSSBUCHSTABEN**, **Jedes Wort groß schreiben** und **gROSS-/kLEINSCHREIBUNG uMKEHREN**.
- **Schriftfarbe** öffnet die Farben des Designs der Präsentation und weitere Farben.
- **Alle Formatierungen löschen** (Strg+Leertaste) entfernt die Formatierung, die Sie hinzugefügt haben.

Die kleine Schaltfläche mit drei Punkten in der Ecke der Gruppe öffnet das Fenster **Schriftart** (Strg+T), in dem alle diese Optionen an einer Stelle stehen.

Wörter können **Effekte** haben. Ein Effekt ist eine Optik, die den Buchstaben hinzugefügt wird, etwa ein Schatten, ein Leuchten oder eine Spiegelung. Ein **Schatten** ist eine weiche, dunkle Kopie der Wörter, die leicht nach unten und rechts versetzt ist. Ein **Leuchten** ist ein weicher Farbring um die Buchstaben. Eine **Spiegelung** ist eine verblasste, auf den Kopf gestellte Kopie der Wörter unter ihnen. Ein **Innenschatten** verdunkelt die Buchstaben entlang einer inneren Kante. JeffDeck zeigt die Effekte, die eine Präsentation bereits hat, und behält sie beim Speichern bei. Die Schaltfläche **Schatten** gibt den markierten Wörtern einen Schatten, ein zweiter Klick entfernt ihn. Ein Schatten wird direkt unter seinen Buchstaben gezeichnet, sodass er nie andere Wörter überdeckt. In einer Präsentation, die auf die Folienbreite verkleinert wurde, werden die Schatten zusammen mit den Wörtern verkleinert.

**Formatierung übertragen** kopiert, wie Text oder ein Objekt aussieht. Markieren Sie, was Sie kopieren möchten, klicken Sie auf **Formatierung übertragen**, und klicken Sie dann auf oder ziehen Sie über das, was gleich aussehen soll. Halten Sie beim Klick auf die Schaltfläche **Umschalt** gedrückt, um die Formatierung mehrmals zu übertragen. Klicken Sie erneut auf die Schaltfläche oder drücken Sie Esc, um aufzuhören.

## Die Minisymbolleiste

Wenn Sie Wörter mit der Maus markieren, schwebt über ihnen eine kleine Leiste. Sie enthält die Schaltflächen, die Sie am häufigsten brauchen: **Fett**, **Kursiv**, **Unterstreichung**, Text verkleinern oder vergrößern, linksbündige, zentrierte und rechtsbündige Ausrichtung, Aufzählungszeichen und Nummerierung. Über ihnen steht ein Feld **Schriftart**, und am Ende der Leiste liegt die Schaltfläche **Schriftfarbe**. Es sind dieselben Schaltflächen wie im Menüband, und jede davon ist ein einzelner Schritt, den Sie rückgängig machen können. Die Leiste nimmt Ihnen nie den Fokus vom Text. Sie verschwindet, wenn Sie schreiben, Esc drücken, die Folie scrollen oder so klicken, dass keine Wörter mehr markiert sind.

## Absätze formatieren

Klicken Sie in einen Absatz, oder markieren Sie mehrere. Verwenden Sie dann die Gruppe **Start > Absatz**:

- **Aufzählungszeichen** und **Nummerierung** schalten eine Liste ein oder aus. Der Pfeil daneben öffnet eine Auswahl an Formaten. Aufzählungszeichen können ein Punkt, ein Kreis, ein Quadrat, eine Raute, ein Pfeil, ein Häkchen, ein Stern oder ein Strich sein. Nummerierungen können 1. 2. 3., a. b. c., A. B. C., i. ii. iii., I. II. III., 1) 2) 3) oder (1) (2) (3) sein. **Aufzählungszeichen und Nummerierung…** öffnet ein Fenster mit weiteren Auswahlmöglichkeiten.
- **Listenebene verringern** und **Listenebene erhöhen** rücken eine Zeile um eine Ebene nach außen oder innen. Jede Ebene ist weiter eingerückt. Im Textplatzhalter einer Folie übernimmt eine verschobene Zeile das Aufzählungszeichen, den Einzug und die Schriftgröße, die das Layout der Folie für die neue Ebene vorsieht, sodass sie wie die Beispielzeilen auf dem Layout aussieht.
- **Zeilenabstand** bietet 1, 1,15, 1,5, 2, 2,5 und 3, und **Absatz…** für weitere Optionen.
- **Linksbündig** (Strg+L), **Zentriert** (Strg+E), **Rechtsbündig** (Strg+R) und **Blocksatz** (Strg+J).

Ein Textplatzhalter auf einer neuen Folie hat bereits die Aufzählungszeichen seines Layouts, sodass alles, was Sie dort schreiben, von Anfang an mit Aufzählungszeichen versehen ist. Das erste Design, JeffOffice, hat keine, und ein Layout ohne Aufzählungszeichen zeigt auch keine.

Drei Schaltflächen ändern das ganze Feld und nicht nur einen Absatz. **Textrichtung** legt **Horizontal**, **Gesamten Text um 90° drehen** oder **Gesamten Text um 270° drehen** fest. Die Wörter werden gedreht eingegeben, so wie sie angezeigt werden, und eine als .pptx- oder .odp-Datei gespeicherte Präsentation behält die Richtung bei. **Text ausrichten** setzt den Text oben, in der Mitte oder unten in sein Feld. **Spalten** legt in einem Textfeld eine, zwei oder drei Spalten fest.

## Wörter suchen und ersetzen

Um nach Wörtern zu suchen, drücken Sie **Strg+F** oder klicken Sie auf **Start > Bearbeiten > Suchen**. Der Bereich **Suchen und Ersetzen** öffnet sich rechts. Geben Sie die Wörter in **Suchen nach** ein. Drücken Sie dann die Eingabetaste oder klicken Sie auf **Weitersuchen**.

JeffDeck beginnt auf der Folie, die Sie gerade anzeigen. Es durchsucht Titel, Textfelder, Formen, Tabellen, Textkunst und Sprechernotizen. Auch ausgeblendete Folien werden durchsucht. Wenn es die Wörter findet, zeigt es diese Folie und markiert die Wörter. Bei Textkunst wird die gesamte Textkunst markiert. Ein Treffer in den Sprechernotizen wird im Notizenfeld unter der Folie markiert. Klicken Sie erneut auf **Weitersuchen**, um zum nächsten Treffer zu gelangen. Nach der letzten Folie beginnt die Suche wieder bei der ersten.

- **Groß-/Kleinschreibung beachten** findet nur Wörter mit denselben Großbuchstaben. „Plan“ findet „plan“ nicht.
- **Nur ganze Wörter suchen** überspringt längere Wörter, die Ihres enthalten. „plan“ findet „planet“ nicht.
- **Sprechernotizen durchsuchen** ist zunächst aktiviert. Deaktivieren Sie die Option, um nur die Folien zu durchsuchen.

Um Wörter zu ändern, drücken Sie **Strg+H** oder klicken Sie auf **Start > Bearbeiten > Ersetzen**. Geben Sie die neuen Wörter in **Ersetzen durch** ein. Klicken Sie auf **Ersetzen**, um den angezeigten Treffer zu ändern und zum nächsten zu wechseln. Klicken Sie auf **Alle ersetzen**, um jeden Treffer zu ändern. Der Bereich zeigt an, wie viele Treffer geändert wurden. Alle ersetzen ist ein einzelner Schritt, sodass ein Klick auf **Rückgängig** (Strg+Z) alle Wörter wiederherstellt.

## Das Kontextmenü

Klicken Sie mit der rechten Maustaste auf die Folie, um die Befehle zu sehen, die zu Ihrer Tätigkeit passen. Sie können auch **Umschalt+F10** oder die **Menütaste** auf Ihrer Tastatur drücken. Das Menü öffnet sich an der Textmarke oder am markierten Objekt.

- **Bei Wörtern, die Sie schreiben:** Ist ein Wort als falsch geschrieben markiert, beginnt das Menü mit Rechtschreibvorschlägen. Klicken Sie auf einen, um das Wort zu korrigieren. **Alle ignorieren** lässt das Wort vorerst unverändert, und **Zum Wörterbuch hinzufügen** behält es bei. Danach folgen **Ausschneiden**, **Kopieren**, **Einfügen**, **Schriftart…**, **Absatz…**, **Aufzählungszeichen**, **Nummerierung**, **Link**, **Thesaurus** und **Neuer Kommentar**.
- **Bei einem Objekt:** **Ausschneiden**, **Kopieren**, **Einfügen**, **Einfügeoptionen**, **Löschen**, **Text bearbeiten**, **Gruppieren** oder **Gruppierung aufheben**, **Anordnen** (In den Vordergrund, Eine Ebene nach vorne, Eine Ebene nach hinten und In den Hintergrund), **Ausrichten**, **Als Bild speichern**, **Größe und Position**, **Form formatieren** (bei einem Bild **Bild formatieren**), **Alternativtext**, **Link** und **Neuer Kommentar**. **Einfügeoptionen** erlaubt das Einfügen mit der Formatierung, die die Wörter hatten, nur mit den Wörtern oder mit **Inhalte einfügen…**, wobei gefragt wird, welche Form Sie möchten. **Als Bild speichern** speichert das Objekt als .png- oder .jpg-Datei. **Größe und Position** öffnet den Bereich **Format** bei den Feldern für Größe und Position. **Form formatieren** öffnet den Bereich **Format** für dieses Objekt. **Alternativtext** öffnet den Bereich **Format**, in dem Sie das Objekt für Menschen beschreiben können, die es nicht sehen. **Text bearbeiten** setzt die Einfügemarke in das Feld, die Form oder die Tabelle, damit Sie schreiben können. **Ausrichten** steht zur Verfügung, wenn das Objekt Wörter enthält. Es richtet die Wörter links, zentriert oder rechts aus oder verteilt sie, sodass sie die Zeile füllen.
- **Auf einer leeren Stelle der Folie:** **Einfügen**, **Layout**, **Folie zurücksetzen**, **Hintergrund formatieren**, **Raster und Führungslinien**, **Lineal** und **Neuer Kommentar**.

Jeder Befehl ist derselbe wie im Menüband und funktioniert genauso.

## Weiteres in Text einfügen

- **Einfügen > Symbole > Symbol** fügt ein Zeichen ein, das nicht auf der Tastatur steht.
- **Einfügen > Text > Datum und Uhrzeit** fügt das Datum oder die Uhrzeit in den Text ein, den Sie gerade schreiben. Wählen Sie eine **Sprache**, um die Namen der Wochentage und Monate in dieser Sprache zu sehen, etwa Deutsch oder Japanisch. Wählen Sie ein Format. Aktivieren Sie **Automatisch aktualisieren**, wenn Sie ein Feld wünschen, das sich selbst auf dem neuesten Stand hält. Das Feld merkt sich seine Sprache. Eine .pptx-Datei speichert die Art des Datums (eine von dreizehn) und die Sprache, aber kein eigenes Format. Ein Datum in einem anderen Format wird daher in der nächstliegenden Art wiederhergestellt. Eine .odp-Datei speichert Format und Sprache genau. Lassen Sie das Kästchen leer, um einfachen Text einzufügen, der sich nie ändert. Ein Datum auf jeder Folie finden Sie unter [Foliengröße, Hintergrund und Fußzeilen](design).
- **Einfügen > Text > Foliennummer > Foliennummer im Text** fügt die Nummer der Folie in den Text ein, den Sie schreiben. Es handelt sich um ein Feld, das auf jeder Folie, auf der es steht, die richtige Nummer zeigt und sich von selbst ändert, wenn Sie die Folie verschieben. Der Befehl ist grau, wenn Sie nicht in einem Textfeld schreiben. Um stattdessen auf jeder Folie eine Nummer anzuzeigen, verwenden Sie die anderen Auswahlmöglichkeiten in diesem Menü.
- **Einfügen > Links > Link** (Strg+K) macht den markierten Text oder das markierte Objekt zu einem Link. Wählen Sie unter **Verknüpfen mit** eine Webadresse, eine E-Mail-Adresse, eine Stelle in der Präsentation (eine Folie, die nächste oder vorherige Folie oder das Ende der Show), eine vorhandene Datei, eine andere Präsentation oder eine neue Präsentation. Bei einer neuen Präsentation geben Sie den vollständigen Pfad dafür ein oder klicken auf **Durchsuchen**. JeffDeck erstellt dort eine leere Präsentation und verlinkt sie. Eine Datei, die bereits existiert, wird nie überschrieben. In der Bildschirmpräsentation öffnet ein Klick auf einen Link Webseiten und E-Mail-Adressen. Andere Links haben vorerst keine Wirkung.
- **Überprüfen > Dokumentprüfung > Rechtschreibung** (F7) prüft die Rechtschreibung. **Thesaurus** (Umschalt+F7) sucht nach anderen Wörtern. **Wortanzahl** zählt die Wörter auf den Folien und, wenn Sie gerade schreiben, in der Markierung. Informationen zur Rechtschreibprüfung während der Eingabe finden Sie unter [JeffDeck-Einstellungen ändern](options).

## Schriftfunktionen

Im Feld **Schriftart** bietet die Registerkarte **Erweitert** Ligaturen, Zahlenabstand, Zahlzeichen, stilistische Sätze und kontextabhängige Alternativen. Folientext hat keine Ligaturen, sofern Sie sie hier nicht ausdrücklich anfordern. Eine gespeicherte Präsentationsdatei kann diese Einstellungen nicht speichern, daher bleiben sie nur während der Arbeit erhalten.
