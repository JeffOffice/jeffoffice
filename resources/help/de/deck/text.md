# Text eingeben und formatieren

Die meisten Folien bestehen vor allem aus Wörtern. In diesem Thema erfahren Sie, wo Text auf einer Folie steht und wie Sie ihn formatieren.

## In einen Platzhalter schreiben

Ein **Platzhalter** ist ein Feld in einem Layout, das den Titel, Untertitel, Text oder ein Bild einer Folie aufnimmt. Eine neue Folie erhält eine Kopie jedes Platzhalters ihres Layouts. Ein leerer Platzhalter zeigt eine gepunktete Kontur und einen Hinweis wie **Titel durch Klicken hinzufügen**, **Untertitel durch Klicken hinzufügen** oder **Text durch Klicken hinzufügen**. Kontur und Hinweis erscheinen nur im Bearbeitungsfenster. Sie werden nie gedruckt und nie in der Bildschirmpräsentation angezeigt.

Klicken Sie in einen Platzhalter, und geben Sie den Text ein. Drücken Sie Esc, um die Eingabe zu beenden. Das Feld bleibt markiert. Drücken Sie erneut Esc, um die Markierung aufzuheben. Sie können auch ein Feld markieren und einfach lostippen.

Text, der für seinen Platzhalter zu lang ist, wird verkleinert, damit er hineinpasst. Ziehen Sie einen Platzhalter, um ihn zu verschieben, oder ziehen Sie einen Ziehpunkt, um seine Größe zu ändern. Um die Platzhalter wieder an die Stellen des Layouts zu setzen, klicken Sie auf **Start > Folien > Zurücksetzen**. Siehe [Folien hinzufügen, ändern und löschen](slides).

## Ein Textfeld hinzufügen

Für Text außerhalb eines Platzhalters klicken Sie auf **Einfügen > Text > Textfeld**, ziehen ein Feld auf der Folie auf und geben den Text ein. Ein Textfeld lässt sich wie jedes Objekt verschieben und in der Größe ändern. Siehe [Formen, Bilder, Tabellen und Textkunst](objects).

## Zeichen formatieren

Markieren Sie den Text, den Sie ändern möchten: Ziehen Sie darüber, oder doppelklicken Sie auf ein Wort. Markieren Sie das ganze Feld, um seinen gesamten Text zu ändern. Verwenden Sie dann die Gruppe **Start > Schriftart**:

- Die Felder **Schriftart** und **Schriftgrad**. **Schriftgrad vergrößern** und **Schriftgrad verkleinern** ändern die Größe schrittweise (Strg+Umschalt+> und Strg+Umschalt+<).
- **Fett** (Strg+B), **Kursiv** (Strg+I), **Unterstrichen** (Strg+U), **Durchgestrichen** und **Schatten**.
- **Zeichenabstand** legt fest, wie eng oder locker die Buchstaben stehen, von **Sehr eng** bis **Sehr weit**. **Weitere Abstände…** öffnet ein Fenster für einen eigenen Wert.
- **Groß-/Kleinschreibung** bietet **Ersten Buchstaben im Satz großschreiben.**, **kleinbuchstaben**, **GROSSBUCHSTABEN**, **Ersten Buchstaben Jedes Wortes Großschreiben** und **gROSS-/kLEINSCHREIBUNG uMKEHREN**.
- **Schriftfarbe** öffnet die Farben des Designs der Präsentation und weitere Farben.
- **Alle Formatierungen löschen** (Strg+Leertaste) entfernt die von Ihnen hinzugefügte Formatierung.

Die kleine Schaltfläche mit drei Punkten in der Ecke der Gruppe öffnet das Fenster **Schriftart** (Strg+T), das alle diese Einstellungen an einer Stelle vereint.

**Format übertragen** kopiert das Aussehen von Text oder einem Objekt. Markieren Sie, was Sie kopieren möchten, klicken Sie auf **Format übertragen**, und klicken oder ziehen Sie dann über das, was genauso aussehen soll. Halten Sie beim Klicken auf die Schaltfläche die Umschalttaste gedrückt, um das Format mehrmals zu übertragen. Klicken Sie erneut auf die Schaltfläche, oder drücken Sie Esc, um aufzuhören.

## Absätze formatieren

Klicken Sie in einen Absatz, oder markieren Sie mehrere. Verwenden Sie dann die Gruppe **Start > Absatz**:

- **Aufzählungszeichen** und **Nummerierung** schalten eine Liste ein oder aus. Der Pfeil daneben öffnet eine Auswahl an Formaten. Aufzählungszeichen können ein Punkt, Kreis, Quadrat, eine Raute, ein Pfeil, Häkchen, Stern oder Strich sein. Die Nummerierung kann 1. 2. 3., a. b. c., A. B. C., i. ii. iii., I. II. III., 1) 2) 3) oder (1) (2) (3) sein. **Aufzählungszeichen und Nummerierung…** öffnet ein Fenster mit weiteren Möglichkeiten.
- **Listenebene verringern** und **Listenebene erhöhen** rücken eine Zeile um eine Ebene nach außen oder innen. Jede Ebene ist weiter eingezogen. Im Textplatzhalter einer Folie übernimmt eine verschobene Zeile das Aufzählungszeichen, den Einzug und die Größe, die das Folienlayout für die neue Ebene vorsieht, sodass sie wie die Beispielzeilen im Layout aussieht.
- **Zeilenabstand** bietet 1,0, 1,15, 1,5, 2,0, 2,5 und 3,0 sowie **Absatz…** für weitere Einstellungen.
- **Linksbündig** (Strg+L), **Zentriert** (Strg+E), **Rechtsbündig** (Strg+R) und **Blocksatz** (Strg+J).

Ein Textplatzhalter auf einer neuen Folie hat bereits die Aufzählungszeichen seines Layouts, sodass Ihr Text dort von Anfang an eine Aufzählung ist. Das erste Design, JeffOffice, hat keine, und ein Layout ohne Aufzählungszeichen vergibt auch keine.

Drei Schaltflächen ändern das ganze Feld und nicht nur einen Absatz. **Textrichtung** legt **Horizontal** oder **Gesamten Text um 90° drehen** fest. **Text ausrichten** setzt den Text **Oben**, in die **Mitte** oder **Unten** in sein Feld. **Spalten** legt eine, zwei oder drei Spalten in einem Textfeld fest.

## Weitere Inhalte im Text

- **Einfügen > Symbole > Sonderzeichen** fügt ein Zeichen ein, das nicht auf der Tastatur ist.
- **Einfügen > Text > Datum und Uhrzeit** fügt das Datum oder die Uhrzeit ein. Ein Datum auf jeder Folie wird unter [Foliengröße, Hintergrund und Fußzeilen](design) beschrieben.
- **Einfügen > Links > Link** (Strg+K) macht den markierten Text oder das markierte Objekt zu einem Link auf eine Webseite, eine Stelle in der Präsentation oder eine E-Mail-Adresse. In der Bildschirmpräsentation öffnet ein Klick auf einen Link Webseiten und E-Mail-Adressen. Andere Links bewirken noch nichts.
- **Überprüfen > Dokumentprüfung > Rechtschreibung** (F7) prüft die Rechtschreibung. **Thesaurus** (Umschalt+F7) schlägt andere Wörter nach. **Wörter zählen** zählt die Wörter auf den Folien und, während Sie schreiben, in der Markierung. Wie Sie die Rechtschreibung während der Eingabe prüfen, erfahren Sie unter [Die Einstellungen von JeffDeck ändern](options).
