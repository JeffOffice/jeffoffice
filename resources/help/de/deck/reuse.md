# Folien aus einer anderen Präsentation wiederverwenden

Sie können Folien aus einer anderen Präsentation in die Präsentation kopieren, an der Sie gerade arbeiten. Der Bereich **Folien wiederverwenden** zeigt die Folien der anderen Präsentation an, und mit einem Klick fügen Sie eine Folie in Ihre Präsentation ein.

## Folien aus einer Datei hinzufügen

1. Klicken Sie auf **Start > Folien**, dann auf den kleinen Pfeil unter **Neue Folie**, und wählen Sie unten im Katalog **Folien wiederverwenden…**. Rechts wird der Bereich **Folien wiederverwenden** geöffnet.
2. Klicken Sie auf **Durchsuchen…**, und wählen Sie eine Präsentation aus. Das kann eine .pptx-, .potx-, .ppsx-, .ppt-, .pps- oder .pot-Datei sein.
3. Der Bereich zeigt ein Bild jeder Folie mit Nummer und Titel. Klicken Sie auf die gewünschte Folie. JeffDeck fügt eine Kopie hinter der aktuellen Folie im selben Abschnitt ein. Sie können auch eine Folie im Bereich auswählen und die Eingabetaste drücken.
4. Klicken Sie auf weitere Folien, um weitere hinzuzufügen. Jede Folie ist ein eigener Schritt, den Sie mit Strg+Z rückgängig machen können.

Die andere Datei wird nicht geändert.

## Was mit einer Folie übernommen wird

Eine Kopie enthält alles, was zur Folie gehört: Text, Formen, Bilder, Diagramme, Sprechernotizen, Übergang und Animationen. Danach besteht keine Verbindung zur anderen Datei mehr. Eine Änderung in der einen Datei wirkt sich nie auf die andere aus.

Haben die Folien der anderen Präsentation eine andere Größe, wird die Kopie an die Foliengröße Ihrer Präsentation angepasst.

## Altes Aussehen beibehalten oder neues übernehmen

Das Kontrollkästchen **Ursprüngliche Formatierung beibehalten** unter den Folien bestimmt, wie eine kopierte Folie aussieht.

- **Deaktiviert** (die übliche Wahl): Die Folie übernimmt den Entwurf der Präsentation, an der Sie arbeiten. Sie verwendet Ihr Layout derselben Art. Ihre Platzhalter werden an die Positionen dieses Layouts verschoben und übernehmen dessen Textformat. Sie hat keinen eigenen Hintergrund, und ihre Fußzeile richtet sich nach der Ihrer Präsentation.
- **Aktiviert**: Die Folie behält ihr eigenes Aussehen. Ihr Layout und ihr Folienmaster werden mit ihrem Design übernommen, sodass die Folie so aussieht wie vorher. Ein Layout, das genauso aussieht wie ein bereits vorhandenes, wird nicht doppelt hinzugefügt.
