# Registerkarte „Bildschirmpräsentation“
<!-- keywords: Registerkarte Bildschirmpräsentation, Menüband, von Beginn an, ab aktueller Folie, Folie ausblenden, einrichten, Bildschirme, Monitore, Referentenansicht verwenden, Referentenansicht, Moderatoransicht, proben, üben, abspielen, vorführen, präsentieren, F5 -->

Auf der Registerkarte **Bildschirmpräsentation** starten Sie die Präsentation und richten sie ein.

- **Bildschirmpräsentation starten** enthält **Von Beginn an** (F5) und **Ab aktueller Folie** (Umschalt+F5).
- **Einrichten** enthält **Folie ausblenden**. Damit nehmen Sie die aktuelle Folie aus der Präsentation heraus.
- **Bildschirme** enthält das Kontrollkästchen **Referentenansicht verwenden** für den Fall, dass Sie zwei Bildschirme haben, sowie **Referentenansicht** (Alt+F5). Damit wird die Präsentation in einem kleinen Fenster mit der Referentenansicht daneben geöffnet, sodass Sie an einem einzigen Bildschirm proben können.

Siehe [Bildschirmpräsentation vorführen und Referentenansicht verwenden](show).
