# Gleichungen

Eine **Gleichung** ist eine Zeile mit Mathematik, zum Beispiel ein Bruch oder eine Quadratwurzel. Auf einer Folie ist eine Gleichung ein Objekt, so wie ein Bild oder ein Textfeld. Sie können sie verschieben, in der Größe ändern, drehen, kopieren und löschen.

## Gleichung auf der Folie einfügen

1. Klicken Sie auf **Einfügen > Symbole > Gleichung** (oder drücken Sie **Alt+=**).
2. Geben Sie die Gleichung in einer Zeile ein. Unter dem Feld sehen Sie, wie sie aussehen wird. Klicken Sie auf **OK**.

Die Gleichung erscheint in der Mitte der Folie und ist markiert. Ihre Buchstaben sind ungefähr so groß wie eine Überschrift. Eine sehr breite Gleichung wird verkleinert, damit sie auf die Folie passt. Um von einer bekannten Gleichung auszugehen, klicken Sie auf **Integrierte Gleichungen** und wählen Sie eine aus, zum Beispiel die quadratische Formel oder die Fläche eines Kreises.

## So geben Sie sie ein

- **Brüche:** Geben Sie einen Schrägstrich ein. `a/b` ist a über b. `(x+1)/(x-1)` fasst jede Gruppe in Klammern als einen Teil auf.
- **Potenzen und tiefgestellte Zeichen:** `x^2` ist x hoch 2, und `x_i` ist x mit einem kleinen i darunter.
- **Wurzeln:** Geben Sie `sqrt(x+1)` für eine Quadratwurzel ein.
- **Summen, Integrale und Produkte:** Geben Sie `\sum_(i=1)^n i`, `\int_0^1 x` oder `\prod_(k=1)^n k` ein.
- **Symbole:** Geben Sie einen umgekehrten Schrägstrich und einen Namen ein. `\alpha` ist α, `\pi` ist π, `\infty` ist ∞, und `\leq` ist ≤.
- **Akzente, Klammern und Matrizen:** `\hat{x}`, `\left( ... \right)` und `\pmatrix{a & b \\ c & d}`.

## Ändern, verschieben und in der Größe anpassen

Doppelklicken Sie auf die Gleichung oder markieren Sie sie und klicken Sie auf **Einfügen > Symbole > Gleichung**, um das Feld mit ihrer Zeile zu öffnen. Ändern Sie sie und klicken Sie auf **OK**. Sie bleibt an ihrer Stelle und behält ihre Größe, und die Änderung lässt sich mit einem Schritt rückgängig machen. Ziehen Sie die Gleichung, um sie zu verschieben. Ziehen Sie an einem Ziehpunkt, um die Größe zu ändern; die Gleichung behält dabei innerhalb ihres Rahmens ihre Proportionen.

Eine Gleichung, die aus einer Datei stammt, können Sie ebenfalls ändern. Solange Sie sie nicht ändern, zeigt JeffDeck das Bild, das die Datei speichert, und schreibt es unverändert zurück. Doppelklicken Sie darauf (oder markieren Sie sie und klicken Sie auf **Gleichung**). Das Feld beginnt mit einer Zeile, die beschreibt, was die Gleichung ist. Wenn Sie diese Zeile ändern, wird das Bild an derselben Stelle zu einer Gleichung, und JeffDeck setzt die Mathematik aus Ihrer Eingabe neu, sodass eventuell besondere Schriftarten der alten Formel verloren gehen. Wenn Sie auf **OK** klicken, ohne die Zeile zu ändern, bleibt alles unverändert.

## Bildschirmpräsentation, Druck und PDF

Bildschirmpräsentation, Druck und PDF-Dateien zeichnen die Gleichung als Formen. Dadurch bleibt sie bei jeder Größe scharf.

## Speichern

- **.pptx** speichert die Gleichung als Gleichung in der Standardform für Mathematik, daneben mit einem Bild davon für Programme, die Mathematik nicht lesen können. Wenn Sie die Datei erneut öffnen, zeigt JeffDeck das Bild und behält die Mathematik bei, und Sie können sie wie oben beschrieben weiterhin ändern. Eine Präsentation enthält insgesamt höchstens 2.000 Gleichungen und 16 MB Mathematik. Darüber hinaus fügt JeffDeck keine weitere hinzu.
- **.odp** enthält in der Kopie von JeffDeck keine Gleichungen. Jede wird als Bild davon an derselben Stelle gespeichert, und die Meldung nach dem Speichern weist darauf hin.
- Ein Textfeld mit Wörtern um die Mathematik ist hier keine Gleichung. Es wird als Bild angezeigt, das die Datei speichert, und ganz unverändert zurückgeschrieben.
