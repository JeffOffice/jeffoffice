# JeffDeck-Hilfe
<!-- keywords: Inhalt, Hilfe, Themen, Start, Hilfethemen, Übersicht -->

Geben Sie oben in das Suchfeld einen Begriff ein, um ein Thema zu finden, oder einen Befehl, den Sie ausführen möchten. Drücken Sie jederzeit **F1**, um Hilfe zu dem zu erhalten, was Sie gerade tun: zur Registerkarte des Menübands, auf der Sie sich befinden, zum Bereich, in dem Sie arbeiten, oder zum ausgewählten Objekt.
