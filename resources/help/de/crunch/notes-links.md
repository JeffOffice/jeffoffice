## Notizen

Eine **Notiz** ist ein kurzer Text, der an einer Zelle hängt. Eine Zelle, die eine Notiz hat, zeigt oben rechts in der Ecke eine kleine rote Markierung. Bewegen Sie den Zeiger über die Zelle, erscheint die Notiz daneben; bewegen Sie den Zeiger weg, verschwindet sie wieder.

Um eine Notiz auf eine Zelle zu setzen, markieren Sie die Zelle und verwenden Sie **Überprüfen > Neue Notiz** (oder drücken Sie **Umschalt+F2**). Geben Sie den Text ein und klicken Sie auf **OK**. Bei einer Zelle, die bereits eine Notiz hat, heißt derselbe Befehl **Notiz bearbeiten**. Wenn Sie den Text löschen, wird die Notiz entfernt.

- **Notiz löschen** entfernt die Notizen der markierten Zellen.
- **Notiz anzeigen oder ausblenden** zeigt die Notiz der markierten Zellen dauerhaft im Blatt, in einem Feld neben jeder Zelle, oder blendet sie wieder aus.
- **Alle Notizen anzeigen** tut dasselbe für alle Notizen im Blatt; die Schaltfläche heißt dann **Alle Notizen ausblenden**.
- **Vorherige Notiz** und **Nächste Notiz** springen von einer Zelle mit Notiz zur nächsten.

Jeder dieser Schritte lässt sich rückgängig machen. Eine Notiz wandert mit ihrer Zelle, wenn Zeilen oder Spalten eingefügt oder gelöscht werden und wenn Zellen sortiert werden. **Alle löschen** entfernt die Notizen und die Kommentare der Zellen, die es leert.

Eine Zelle kann auch eine Unterhaltung aus **Kommentaren** mit Antworten enthalten. Dazu im nächsten Abschnitt mehr.

Notizen können in einer .xlsx-Arbeitsmappe gespeichert werden. Eine Arbeitsmappe, die aus einem älteren Dateityp oder aus einer Textdatei geöffnet wurde, behält ihre Notizen erst, wenn Sie sie als .xlsx-Arbeitsmappe speichern.

## Kommentare

Ein **Kommentar** ist wie eine Notiz, beginnt aber einen **Verlauf**: Andere können darauf antworten, und eine Person kann den Verlauf als **erledigt** markieren, wenn die Frage beantwortet ist. Jeder Kommentar zeigt, wer ihn geschrieben hat und wann. Eine Zelle mit einem Verlauf hat dieselbe rote Markierung wie eine Zelle mit einer Notiz. Bewegen Sie den Zeiger über die Zelle, um den ganzen Verlauf zu lesen; jede Antwort ist unter dem Kommentar eingerückt, auf den sie sich bezieht. Ein erledigter Verlauf beginnt mit dem Wort **Erledigt**.

Auf der Registerkarte **Überprüfen** finden Sie in der Gruppe **Kommentare**:

- **Neuer Kommentar** (**Strg+Umschalt+F2**) beginnt einen Verlauf auf der markierten Zelle. Geben Sie den Text ein und klicken Sie auf **OK**. Das funktioniert auch bei einer Zelle ohne Notiz und ohne Kommentare.
- **Antworten** fügt Ihren Text dem Verlauf auf der markierten Zelle hinzu.
- **Als erledigt markieren** kennzeichnet den Verlauf als erledigt. Dieselbe Schaltfläche heißt dann **Wieder öffnen**; damit wird der Verlauf erneut geöffnet.
- **Kommentar löschen** entfernt die Verläufe der markierten Zellen.
- **Vorheriger Kommentar** und **Nächster Kommentar** springen von einer Zelle mit Verlauf zur nächsten.
- **Kommentare anzeigen** öffnet den Bereich **Kommentare** neben dem Blatt. Er listet jeden Verlauf des Blatts als Karte auf: die Zelle, jeden Kommentar mit Autor und Uhrzeit sowie die Schaltflächen **Antworten**, **Lösen** bzw. **Wieder öffnen** und **Löschen**. Mit **Gehe zu** wechseln Sie zur Zelle. Der Bereich folgt jeder Änderung, auch dem Rückgängigmachen.
- **Notizen in Kommentare umwandeln** macht aus jeder einfachen Notiz im Blatt einen Verlauf mit einem Kommentar. **Kommentare in Notizen umwandeln** macht aus jedem Verlauf wieder eine Notiz. Eine Notiz hat keine Antworten; deshalb werden die Kommentare eines Verlaufs zu einer Notiz mit all ihrem Text zusammengefasst. Bei einem Verlauf mit Antworten fragt JeffCrunch vorher nach.

Jeder dieser Schritte lässt sich rückgängig machen.

Programme, die Verläufe nicht anzeigen können, zeigen an ihrer Stelle eine einfache Notiz. JeffCrunch behält diese Notiz mit dem Text des Verlaufs bei jedem Speichern. Verläufe, Antworten und die Personen, die sie geschrieben haben, bleiben beim Speichern und erneuten Öffnen der Arbeitsmappe so, wie sie waren. Ein Verlauf mit mehr als 500 Kommentaren wird angezeigt und gespeichert, aber JeffCrunch fügt ihm nichts hinzu und ändert ihn nicht.

Kommentare werden in einer .xlsx-Arbeitsmappe gespeichert. Eine Arbeitsmappe, die aus einem älteren Dateityp oder aus einer Textdatei geöffnet wurde, behält ihre Kommentare erst, wenn Sie sie als .xlsx-Arbeitsmappe speichern.

## Links

Ein **Link** bringt Sie beim Anklicken an ein Ziel: auf eine Webseite, zu einer Datei, zu einer E-Mail-Adresse oder zu einer Stelle in dieser Arbeitsmappe (einer Zelle, mehreren Zellen oder einem Namen).

Um einen Link auf eine Zelle zu setzen, markieren Sie die Zelle und verwenden Sie **Einfügen > Link** (oder drücken Sie **Strg+K**). Wählen Sie, wohin der Link führt, geben Sie die Adresse oder die Stelle ein (oder wählen Sie eine der zuletzt geöffneten Dateien unter **Oder eine zuletzt verwendete Datei**) und, falls gewünscht, den Text, den die Zelle anzeigen soll, sowie eine **QuickInfo**. Bei einer Zelle, die bereits einen Link hat, heißt derselbe Befehl **Link bearbeiten**. **Link entfernen** nimmt die Links der markierten Zellen weg.

Bewegen Sie den Zeiger über eine Zelle mit Link, um zu sehen, wohin sie führt. Zum Öffnen halten Sie **Strg** gedrückt und klicken auf die Zelle, oder Sie markieren die Zelle und verwenden **Link öffnen** aus dem Kontextmenü. Ein einfacher Klick markiert nur die Zelle.

JeffCrunch öffnet nie von selbst etwas. Eine Webseite oder eine E-Mail-Adresse öffnet sich in Ihrem üblichen Programm, wenn Sie dem Link folgen. Bei einem Link zu einer Datei oder zu einer anderen Adressart fragt das Programm vorher nach. Ein Link, der ein Skript ausführen würde, wird nie geöffnet.

Ein Link wandert mit seiner Zelle, wenn Zeilen oder Spalten eingefügt oder gelöscht werden und wenn Zellen sortiert werden. Er wird mit der Arbeitsmappe gespeichert.

## Arbeitsmappenstatistik

**Arbeitsmappenstatistik** (Registerkarte **Überprüfen**) zählt, was die Arbeitsmappe enthält: wie viele **Blätter** sie hat, wie viele **Zellen mit Daten** (Zellen, die eine Zahl, einen Text oder eine Formel enthalten), wie viele **Formeln**, wie viele **Diagramme** und wie viele **Pivot-Tabellen**. Gelöschte Blätter werden nicht mitgezählt. Dieselben Zahlen finden Sie auf der Seite **Info** der Registerkarte **Datei**.

## Thesaurus

**Thesaurus** (Registerkarte **Überprüfen** oder **Umschalt+F7**) findet Wörter, die fast dasselbe bedeuten wie ein Wort in einer Zelle. Es sucht das erste Wort des Textes in der Zelle, auf der Sie gerade stehen. Geben Sie unter **Nachschlagen** ein anderes Wort ein und drücken Sie **Eingabe**, um stattdessen dieses Wort nachzuschlagen. Wählen Sie ein Wort in der Liste und klicken Sie auf **Ersetzen** oder doppelklicken Sie darauf. Das Wort in der Zelle wird ersetzt, und ein großer Anfangsbuchstabe bleibt groß. **Nachschlagen** sucht das ausgewählte Wort nach, um einer Kette von Bedeutungen zu folgen. Die Wortliste arbeitet auf Englisch.

## Barrierefreiheit prüfen

**Barrierefreiheit prüfen** (Registerkarte **Überprüfen**) öffnet ein kleines Fenster, das auflistet, was in der Arbeitsmappe für manche Leser schwer zu nutzen ist oder was ein Screenreader (ein Programm, das den Bildschirm vorliest) schwer wiedergeben kann. Jede Zeile beginnt mit **Fehler**, **Warnung** oder **Tipp**. Klicken Sie auf eine Zeile, um zur Zelle zu wechseln.

Es sucht nach:

- Einem Diagramm oder Bild ohne **Alternativtext** (den Worten, die beschreiben, was es zeigt). Das ist ein Fehler.
- Einer Tabelle ohne Kopfzeile, sodass ihre Spalten keine Namen haben. Das ist ein Fehler.
- **Verbundenen Zellen**, durch die sich mit der Tastatur schwer navigieren lässt. Das ist eine Warnung.
- Text, der vor der Hintergrundfarbe schwer zu lesen ist, etwa blassgrauer Text auf Weiß. JeffCrunch misst, wie stark sich der Text von der Füllung abhebt. Kleiner Text braucht ein Verhältnis von mindestens 4,5 zu 1, großer Text (18 Punkt oder fett 14 Punkt) braucht 3 zu 1. Es nennt die erste Zelle mit jeder Kombination aus Schriftart und Füllung. Das ist eine Warnung.
- Einem Blatt, das noch den Namen trägt, den es bekommen hat, etwa Tabelle1. Das ist ein Tipp.

Klicken Sie nach Änderungen auf **Erneut prüfen**.
