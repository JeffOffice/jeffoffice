## Notizen

Eine **Notiz** ist ein kurzer Text, der zu einer Zelle gespeichert wird. Eine Zelle mit Notiz zeigt in der oberen rechten Ecke eine kleine rote Markierung. Wenn Sie den Mauszeiger auf die Zelle setzen, wird die Notiz daneben angezeigt; wenn Sie den Mauszeiger wegbewegen, verschwindet sie wieder.

Um einer Zelle eine Notiz hinzuzufügen, markieren Sie sie und wählen Sie **Überprüfen > Neue Notiz** (oder drücken Sie **Umschalt+F2**). Geben Sie den Text ein und klicken Sie auf **OK**. Bei einer Zelle, die bereits eine Notiz hat, heißt derselbe Befehl **Notiz bearbeiten**. Wenn Sie den Text vollständig löschen, wird die Notiz entfernt.

- **Notiz löschen** entfernt die Notizen der markierten Zellen.
- **Notiz ein-/ausblenden** zeigt die Notiz der markierten Zellen dauerhaft in einem Feld neben jeder Zelle auf dem Blatt an oder blendet sie wieder aus.
- **Alle Notizen anzeigen** macht dasselbe für alle Notizen auf dem Blatt; die Schaltfläche heißt dann **Alle Notizen ausblenden**.
- **Vorherige Notiz** und **Nächste Notiz** springen von einer Zelle mit Notiz zur nächsten.

Jeder dieser Befehle ist ein einzelner Schritt, den Sie rückgängig machen können. Eine Notiz bleibt bei ihrer Zelle, wenn Zeilen oder Spalten eingefügt oder gelöscht werden und wenn Zellen sortiert werden. **Alle löschen** entfernt auch die Notizen der geleerten Zellen.

Eine Arbeitsmappe kann eine Unterhaltung aus Kommentaren mit Antworten enthalten. JeffCrunch zeigt die gesamte Unterhaltung als Notiz an und behält sie beim Speichern bei, ändert sie aber nicht: Die Notiz ist schreibgeschützt.

Notizen können in einer XLSX-Arbeitsmappe gespeichert werden. Eine Arbeitsmappe, die aus einem älteren Dateiformat oder aus einer Textdatei geöffnet wurde, behält ihre Notizen nur, wenn Sie sie als XLSX-Arbeitsmappe speichern.

## Links

Ein **Link** führt Sie an ein Ziel, wenn Sie ihm folgen: zu einer Webseite, zu einer Datei, zu einer E-Mail-Adresse oder zu einer Stelle in dieser Arbeitsmappe (einer Zelle, mehreren Zellen oder einem Namen).

Um einer Zelle einen Link hinzuzufügen, markieren Sie sie und wählen Sie **Einfügen > Link** (oder drücken Sie **Strg+K**). Wählen Sie das Ziel, geben Sie die Adresse oder die Stelle ein und, falls gewünscht, den Text, den die Zelle anzeigen soll, sowie eine **QuickInfo**. Bei einer Zelle, die bereits einen Link hat, heißt derselbe Befehl **Link bearbeiten**. **Link entfernen** entfernt die Links aus den markierten Zellen.

Wenn Sie den Mauszeiger auf eine Zelle mit Link setzen, sehen Sie, wohin er führt. Um dem Link zu folgen, halten Sie **Strg** gedrückt und klicken Sie auf die Zelle, oder markieren Sie die Zelle und wählen Sie im Kontextmenü **Link öffnen**. Ein einfacher Klick markiert nur die Zelle.

JeffCrunch öffnet nie etwas von selbst. Eine Webseite oder eine E-Mail-Adresse wird in Ihrem Standardprogramm geöffnet, wenn Sie dem Link folgen. Bei einem Link zu einer Datei oder zu einer anderen Art von Adresse werden Sie zuerst gefragt. Ein Link, der ein Skript ausführen würde, wird nie geöffnet.

Ein Link bleibt bei seiner Zelle, wenn Zeilen oder Spalten eingefügt oder gelöscht werden und wenn Zellen sortiert werden, und er wird mit der Arbeitsmappe gespeichert.
