# Drucken und PDF erstellen
<!-- keywords: drucken, Drucker, Ausdruck, Vorschau, Druckvorschau, PDF, exportieren, Exemplare, Kopien, sortiert, Seiten, Seitenbereich, Auswahl, Markierung, gesamte Arbeitsmappe, Skalierung, anpassen, Seitenumbrüche, gestrichelte Linien, als PDF speichern -->

Wählen Sie **Datei > Drucken** (oder drücken Sie **Strg+P**). Die Seite wird mit einer Vorschau der Seiten geöffnet, die gedruckt werden, jeweils eine Seite. Mit den Pfeilen darunter blättern Sie von Seite zu Seite, und mit **Seite einpassen** oder den Zoomschaltflächen sehen Sie mehr oder weniger von einer Seite. Die Vorschau wird genauso dargestellt wie im Ausdruck und in der PDF-Datei: Was Sie sehen, ist das, was Sie erhalten.

## Was gedruckt werden soll

- **Was**: das aktuelle Blatt, die gesamte Arbeitsmappe (alle eingeblendeten Blätter) oder die Markierung. Ausgeblendete Blätter werden nicht gedruckt. Ein Diagrammblatt ergibt eine Seite, auf der das Diagramm den gesamten Platz innerhalb der Seitenränder einnimmt.
- **Seiten**: alle oder nur einige, z. B. **1-3, 5**.
- **Exemplare** und **Sortiert** (jeweils ein vollständiger Satz, 1 2 3 1 2 3, statt alle Exemplare einer Seite hintereinander).
- **Ausrichtung**, **Papier** und **Seitenränder**, die für diesen Ausdruck statt der Einstellungen der einzelnen Blätter gelten.
- **Skalierung**: wie im jeweiligen Blatt festgelegt, Originalgröße, gesamtes Blatt auf einer Seite, alle Spalten auf einer Seite oder alle Zeilen auf einer Seite.
- **Druckbereich ignorieren**: Alles drucken, was Inhalt hat.
- **Seite einrichten** öffnet das Dialogfeld für das aktuelle Blatt.

Unter der Vorschau weist JeffCrunch Sie auf Punkte hin, die Ihre Aufmerksamkeit erfordern: ein Blatt, das mehr Seiten benötigt, als erstellt werden können, ein Blatt, das so stark verkleinert wurde, dass die Schrift sehr klein ist, oder ein Blatt ohne Inhalt.

## Der Drucker

Wählen Sie einen Drucker aus der Liste oder **Als PDF speichern**. **Druckereigenschaften** öffnet das Dialogfeld Ihres Systems für die Druckeroptionen, z. B. beidseitiger Druck und Papierfächer. **Drucken** sendet die Seiten an den Drucker.

## Als PDF exportieren

**Datei > Exportieren** erstellt eine PDF-Datei des aktuellen Blatts oder der gesamten Arbeitsmappe, ohne dass Sie einen Drucker auswählen müssen. Der Text bleibt Text (keine Bilder), sodass er durchsucht werden kann und beim Zoomen scharf bleibt.

## Seitenumbrüche auf dem Bildschirm

Nachdem Sie die Druckansicht geöffnet haben, zeigt das Blatt auf dem Bildschirm, wo die Seiten beginnen: eine gestrichelte Linie für einen Umbruch, den JeffCrunch berechnet hat, und eine durchgezogene Linie für einen, den Sie festgelegt haben. Die Linien werden aktualisiert, wenn Sie das Blatt ändern. Sie blenden sie mit **Ansicht > Seitenumbruchlinien** aus. (Die Ansicht **Seitenumbrüche**, beschrieben unter [Seiten einrichten](page-layout), zeigt sie immer an.)

## Was noch nicht gedruckt wird

Notizen (Kommentare) werden nach der letzten Seite des Blatts gedruckt, wenn unter „Seite einrichten“ für das Blatt **Nach der letzten Seite auflisten** eingestellt ist. An ihrer Position auf den Zellen werden sie noch nicht gedruckt. Bedingte Formatierungen werden auf dem Bildschirm noch nicht angezeigt und daher auch nicht gedruckt.
