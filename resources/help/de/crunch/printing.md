Wählen Sie **Datei > Drucken** (oder drücken Sie **Strg+P**). Die Seite öffnet sich mit einer Vorschau der Seiten, die ausgegeben werden, jeweils eine Seite nach der anderen. Verwenden Sie die Pfeile darunter, um von Seite zu Seite zu wechseln, und **Seite anpassen** oder die Zoomschaltflächen, um mehr oder weniger von einer Seite zu sehen. Die Vorschau wird so gezeichnet, wie es der Drucker und das PDF tun. Was Sie sehen, ist also das, was Sie erhalten.

## Was gedruckt wird

- **Was**: das Blatt, auf dem Sie sich befinden (oder alle Blätter, deren Registerkarten Sie mit Strg oder Umschalt gewählt haben, nacheinander), die gesamte Arbeitsmappe (jedes angezeigte Blatt) oder die Auswahl. Ausgeblendete Blätter werden nicht gedruckt. Ein Diagrammblatt ist eine Seite, und sein Diagramm wird so groß dargestellt, wie es innerhalb der Ränder Platz hat.
- **Seiten**: alle oder einige, etwa **1-3, 5**.
- **Welche Seiten**: **Alle Seiten im Bereich**, **Nur ungerade Seiten** oder **Nur gerade Seiten**. Damit können Sie beidseitig drucken, wenn Ihr Drucker das nicht selbst kann. Drucken Sie zuerst die ungeraden Seiten. Wenn sie fertig sind, drehen Sie den Stapel um, legen ihn wieder in das Papierfach und drucken erneut mit **Nur gerade Seiten**.
- **Seitenausgabe**: **Auf einer Seite drucken**, **Beidseitig drucken, an der langen Kante wenden**, **Beidseitig drucken, an der kurzen Kante wenden** oder **Beidseitig manuell drucken**. Die lange Kante eignet sich für Seiten, die wie ein Buch umgeblättert werden. Die kurze Kante eignet sich für Seiten, die wie ein Notizblock umgeblättert werden. Ein Drucker, der nicht beidseitig drucken kann, hat diese beiden Optionen abgeblendet. Zeigen Sie auf eine davon, um den Grund zu sehen. **Manuell** ist für einen solchen Drucker gedacht: JeffCrunch druckt die erste, dritte, fünfte usw. Seite, oder die Blätter, wenn Sie mehrere Seiten auf einem Blatt drucken. Dann fordert eine Meldung Sie auf, den Stapel umzudrehen und wieder in das Papierfach zu legen. Wenn Sie auf **OK** klicken, druckt es die übrigen Seiten, die letzte zuerst, damit sie auf den Rückseiten landen. Wenn Sie nur eine Seite drucken, gibt es nichts umzudrehen. Alle Optionen sind abgeblendet, wenn Sie ein PDF speichern, weil eine Datei keine Seiten hat. JeffCrunch merkt sich Ihre Wahl für das nächste Mal.
- **Seiten pro Blatt**: Drucken Sie 1, 2, 4, 6, 9 oder 16 verkleinerte Seiten auf jedes Blatt Papier. Jede Seite erhält einen dünnen Rahmen. Die Vorschau zeigt eine Seite weiterhin in voller Größe.
- **Kopien** und **Sortiert** (einen ganzen Satz nach dem anderen, 1 2 3 1 2 3, statt die Kopien jeder Seite zusammen).
- **Letzte Seite zuerst** druckt die Seiten in umgekehrter Reihenfolge, damit ein Stapel in der richtigen Reihenfolge herauskommt. Bei mehreren Seiten auf einem Blatt kommen die Blätter in umgekehrter Reihenfolge heraus. Bei beidseitigem Druck bleibt eine Vorderseite mit ihrer Rückseite zusammen. Die Option ist abgeblendet, wenn Sie beidseitig manuell drucken, weil JeffCrunch die Reihenfolge dann selbst festlegt.
- **Graustufen** druckt alle Farben in Grautönen, auf Papier und in einer PDF-Datei. Auch die Vorschau ist grau.
- **Ausrichtung**, **Papier** und **Ränder** für diesen Druck, statt der Einstellungen, die jedes Blatt angibt.
- **Skalierung**: wie im jeweiligen Blatt angegeben, in voller Größe, das ganze Blatt auf einer Seite, alle Spalten auf einer Seite oder alle Zeilen auf einer Seite.
- **Druckbereich ignorieren**: Druckt alles, was Inhalt hat.
- **Seite einrichten** öffnet das Dialogfeld für das aktuelle Blatt.

Unter der Vorschau teilt JeffCrunch mit, wenn etwas Ihre Aufmerksamkeit braucht: ein Blatt, das mehr Seiten bräuchte, als es erzeugen kann, ein Blatt, das so stark verkleinert wurde, dass die Schrift sehr klein ist, oder ein Blatt ohne Inhalt.

## Auf ein Papierformat skalieren

**An Papierformat anpassen** verkleinert oder vergrößert jede Seite, damit sie auf das gewählte Papier passt. Dabei bleibt ihre Form erhalten, und sie wird in die Mitte gesetzt. Verwenden Sie diese Option, um für ein Papierformat zu drucken, das Ihr Drucker nicht hat, etwa eine für A4 eingerichtete Seite auf Letter-Papier. **Keine Skalierung** druckt jede Seite auf ihrem eigenen Papier. Die Vorschau zeigt das Blatt Papier, das herauskommt.

## Mehrere Seiten auf einem Blatt

**Seiten pro Blatt** setzt 2, 4, 6, 9 oder 16 Seiten auf jedes Blatt Papier, jede einzelne verkleinert und mit Rahmen. Die Vorschau zeigt das ganze Blatt. Die Beschriftung darunter nennt das Blatt, das Sie gerade ansehen, etwa **Blatt 1 von 2**. Mit **Weiter** und **Zurück** sehen Sie die anderen Blätter.

## Ränder und Spaltenbreiten in der Vorschau ziehen

Auf einer Seite der Vorschau markieren gestrichelte Linien die vier Ränder, und eine dünne Linie markiert die rechte Kante jeder Spalte, die auf der Seite liegt (die ersten 64). Ziehen Sie eine Randlinie, um diesen Rand zu verschieben, oder ziehen Sie die Linie einer Spalte, um die Spalte breiter oder schmaler zu machen. Das Blatt ändert sich beim Loslassen als ein einziger Schritt, sodass **Rückgängig** es zurücknimmt, und die Vorschau wird neu erstellt. Jede Linie hat einen Namen, den ein Bildschirmleseprogramm vorliest, etwa „Breite von Spalte C, 3 von 12“ oder „Linker Rand, 0,75 Zoll“ (der Wert des Rands in Ihrer Maßeinheit). Klicken Sie auf eine Linie oder wechseln Sie mit Tab zu ihr, und drücken Sie die Pfeiltasten, um sie um einen kleinen Schritt zu verschieben. Der neue Wert wird beim Loslassen der Taste angesagt, nicht bei jeder Wiederholung einer gedrückten Taste. Auf einem Blatt, das von rechts nach links liest, wird die Seite gespiegelt gedruckt, und die Linie einer Spalte liegt an ihrer linken Kante. Diese ziehen Sie von der Spalte weg, um sie zu verbreitern. Auf einem geschützten Blatt kann die Breite einer Spalte hier nicht geändert werden, genauso wenig wie im Blatt selbst. Die Ränder lassen sich dagegen wie unter „Seite einrichten“ ändern.

Um es mit der Tastatur zu tun, drücken Sie **Tab**, bis die gewünschte Linie den Fokus hat, und drücken Sie dann die Pfeiltasten: links und rechts für die seitlichen Ränder und die Spalten, oben und unten für den oberen und unteren Rand. Ein Bildschirmleseprogramm sagt den Namen jeder Linie an, etwa **Linker Rand** oder **Breite von Spalte B**. Jeder Tastendruck verschiebt die Linie ein Stück und ist ein eigener Schritt.

Sie können auch **Seitenlayout > Seitenränder > Benutzerdefinierte Seitenränder** für die Ränder und **Start > Format > Spaltenbreite** für die Spalten verwenden. Für die Ränder werden keine Linien gezeichnet, solange Sie für diesen Druck **Ränder** gewählt haben (Schmal, Standard oder Breit), weil diese nicht die eigenen Ränder des Blatts sind. Auch wenn mehrere Seiten auf einem Blatt Papier liegen, werden keine Linien gezeichnet.

## Der Drucker

Wählen Sie einen Drucker aus der Liste oder **Als PDF speichern**. **Druckereigenschaften** öffnet das Fenster Ihres Systems für den Drucker, etwa für die Papierfächer. Was Sie dort einstellen (Drucker, Kopien, Sortiert und Farbe), wird auf diese Seite übernommen. Die Schaltfläche ist ausgeblendet, wenn **Als PDF speichern** gewählt ist oder wenn Ihr Computer kein solches Fenster hat. **Drucken** sendet die Seiten.

Wenn **Als PDF speichern** gewählt ist, öffnet das Kontrollkästchen **PDF nach dem Speichern öffnen** die Datei sofort nach dem Speichern in dem Programm, das Ihr Computer für PDF-Dateien verwendet. Es ist zunächst deaktiviert, und die Auswahl bleibt für das nächste Mal erhalten.

## Als PDF exportieren

**Datei > Exportieren** erstellt ein PDF des aktuellen Blatts oder der gesamten Arbeitsmappe, ohne dass Sie einen Drucker wählen. Die Buchstaben bleiben Text (keine Bilder), sodass man in ihnen suchen kann und sie beim Vergrößern scharf bleiben.

Jedes Blatt erhält ein **Lesezeichen**, einen Eintrag in der Liste, die ein PDF-Programm neben den Seiten anzeigt. Klicken Sie auf ein Lesezeichen, um zur ersten Seite des Blatts zu springen.

Eine Zelle mit einem Link ist im PDF ein anklickbares Feld, und zwar auf jeder Seite, auf der die Zelle liegt. Eine Zelle in einer Titelzeile, die oben auf jeder Seite wiederholt wird, ist auf jeder dieser Seiten ein Link. Ein Link auf eine Webadresse (http oder https) oder auf eine E-Mail-Adresse öffnet sie. Ein Link auf eine Stelle in der Arbeitsmappe, etwa Tabelle2!A1, führt zu dieser Zelle auf ihrer Seite, oder zur ersten Seite des Blatts, wenn die Seite der Zelle nicht im PDF enthalten ist. Ein Link auf eine Datei, auf eine andere Art von Adresse oder auf ein Blatt ohne Seite im PDF wird weggelassen. Eine Zelle, die ein Seitenumbruch teilt, etwa eine verbundene Zelle, die über mehrere Seiten reicht, ist auf jeder dieser Seiten ein Link, und zwar über dem Teil, den diese Seite zeigt. Links sind begrenzt: Eine Adresse mit mehr als 2048 Zeichen wird weggelassen, und ein PDF enthält höchstens 20000 Links. Die übrigen sind nicht anklickbar. Der Export meldet, wenn das geschieht, und wie viele Adressen weggelassen wurden.

Die Eigenschaften des PDF, die ein PDF-Programm anzeigt, sind Titel, Autor, Betreff und Stichwörter der Arbeitsmappe (siehe **Datei > Info**). Wenn die persönlichen Informationen entfernt werden oder in den Optionen **Persönliche Informationen beim Speichern entfernen** aktiviert ist, hat das PDF keinen Autor und keinen Titel, der aus dem Dateinamen gebildet wurde. Links sind keine Eigenschaften: Ein E-Mail-Link (mailto) wird auch dann ins PDF geschrieben, wenn die persönlichen Informationen entfernt sind, weil er ein Link in einer Zelle ist. Entfernen Sie den Link der Zelle im Blatt, wenn die Adresse nicht ins PDF gehört.

Das Kontrollkästchen **PDF nach dem Speichern öffnen** auf dieser Seite öffnet das PDF nach dem Speichern. Es ist dieselbe Auswahl wie auf der Seite „Drucken“.

Das Kontrollkästchen **Dokumentstrukturtags für Barrierefreiheit zu jedem PDF hinzufügen** ist zunächst aktiviert und bleibt für das nächste Mal erhalten. Es fügt jeder Seite eine Struktur hinzu, damit Menschen, die ein PDF mit einem Bildschirmleseprogramm hören, es verstehen können. Die Struktur sagt, dass die Zellen einer Seite eine Tabelle sind, sodass das Leseprogramm sie zeilenweise von links nach rechts vorlesen kann. Hintergründe, Linien, Überschriften, Kopf- und Fußzeilen sowie Diagramme werden nicht vorgelesen. Deaktivieren Sie das Kontrollkästchen, wenn Sie diese Struktur nicht möchten.

**Gesamte Arbeitsmappe als PDF/A exportieren** erstellt ein PDF in der Form, die für die langfristige Aufbewahrung gedacht ist. Jede Schriftart wird in die Datei eingebettet, sodass sie auch in vielen Jahren gleich aussieht. Programme, die Dokumente archivieren, verlangen diese Form. Es ist die Form PDF/A-1b, und sie kann ebenfalls mit Strukturkennzeichnungen versehen werden.

**E-Mail erstellen** erzeugt eine Nachrichtendatei mit Ihrer Arbeitsmappe im Anhang oder ein PDF davon. Es wird nichts gesendet. Öffnen Sie die Datei in Ihrem E-Mail-Programm, tragen Sie den Empfänger ein und senden Sie sie. Eine Arbeitsmappe mit Kennwort bleibt in der Nachricht gesperrt: Wer sie erhält, braucht das Kennwort zum Öffnen. Das Kennwort selbst wird nie in die Nachricht geschrieben. Ein PDF der Arbeitsmappe hat nur dann ein Kennwort, wenn Sie im Feld auf **Mit Kennwort verschlüsseln…** klicken, genau wie bei einem exportierten PDF. Teilen Sie der Person das Kennwort auf einem anderen Weg mit als in der Nachricht.

## PDF mit einem Kennwort schützen

Klicken Sie unter **Datei > Exportieren** auf **Mit Kennwort verschlüsseln…**, bevor Sie einen PDF-Befehl wählen. Das gilt nur für das nächste PDF. Geben Sie das Kennwort zweimal ein. Wer das PDF öffnet, muss es dann eingeben. Das Kennwort schützt die Datei wirklich: Die Seiten werden mit starker Verschlüsselung (AES-256) verschlüsselt, und niemand kann sie ohne Kennwort lesen.

Sie können auch **Drucken, Kopieren und Bearbeiten einschränken** aktivieren, ein zweites Kennwort vergeben und festlegen, was erlaubt ist. Diese Einschränkungen sind nur eine Bitte. Die meisten PDF-Programme halten sich daran, aber wer sie umgehen will, wird dadurch nicht gehindert. Verlassen Sie sich daher nicht darauf, eine Datei damit vertraulich zu halten.

Ein vergessenes Kennwort lässt sich nicht wiederherstellen. Bewahren Sie es daher an einem sicheren Ort auf. Das Kennwort gilt nur für dieses eine PDF und wird nie gespeichert. Der Befehl **Gesamte Arbeitsmappe als PDF/A exportieren** ist abgeblendet, solange ein Kennwort festgelegt ist, weil eine PDF/A-Datei keines haben kann.

## Seitenumbrüche auf dem Bildschirm

Nachdem Sie die Druckansicht geöffnet haben, zeigt das Blatt auf Ihrem Bildschirm, wo die Seiten beginnen: eine gestrichelte Linie für einen Umbruch, den JeffCrunch ermittelt hat, und eine durchgezogene Linie für einen, den Sie festgelegt haben. Die Linien werden aktualisiert, wenn Sie das Blatt ändern. Schalten Sie sie mit **Ansicht > Seitenumbruchlinien** aus. (Die Ansicht **Seitenumbruchvorschau**, beschrieben unter [Seiten einrichten](page-layout), zeigt sie immer an.)

## Was noch nicht gedruckt wird

Notizen (Kommentare) werden nach der letzten Seite des Blatts gedruckt, wenn in der Seite einrichten des Blatts **Nach der letzten Seite auflisten** festgelegt ist. Sonst werden sie noch nicht dort gedruckt, wo sie bei den Zellen stehen. Bedingte Formatierungen werden auf dem Bildschirm noch nicht angezeigt und deshalb auch nicht gedruckt.
