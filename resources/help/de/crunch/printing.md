# Drucken und PDF erstellen

Wählen Sie **Datei > Drucken** (oder drücken Sie **Strg+P**). Die Seite öffnet sich mit einer Vorschau der Seiten, die ausgegeben werden, jeweils eine Seite auf einmal. Verwenden Sie die Pfeile darunter, um von Seite zu Seite zu blättern, und **Seite anpassen** oder die Zoomschaltflächen, um mehr oder weniger von einer Seite zu sehen. Die Vorschau wird so dargestellt, wie Drucker und PDF sie ausgeben. Was Sie sehen, entspricht daher dem späteren Ergebnis.

## Was gedruckt wird

- **Was**: das aktuelle Blatt (oder alle Blätter, deren Registerkarten Sie mit Strg oder Umschalt nacheinander ausgewählt haben), die gesamte Arbeitsmappe (jedes angezeigte Blatt) oder die Auswahl. Ausgeblendete Blätter werden ausgelassen. Ein Diagrammblatt ist eine Seite, wobei das Diagramm so groß wie möglich innerhalb der Seitenränder dargestellt wird.
- **Seiten**: alle oder einige, zum Beispiel **1-3, 5**.
- **Welche Seiten**: **Alle Seiten**, **Nur ungerade Seiten** oder **Nur gerade Seiten**. Damit können Sie, falls Ihr Drucker das nicht kann, von Hand beidseitig drucken. Drucken Sie zuerst die ungeraden Seiten. Wenn sie fertig sind, drehen Sie den Stapel um, legen ihn wieder in das Papierfach und drucken erneut mit **Nur gerade Seiten**.
- **Seitenausgabe**: **Einseitig drucken**, **Beidseitig drucken, an der langen Kante wenden**, **Beidseitig drucken, an der kurzen Kante wenden** oder **Beidseitig manuell drucken**. Die lange Kante eignet sich für Seiten, die wie ein Buch umgeblättert werden. Die kurze Kante eignet sich für Seiten, die wie ein Notizblock umgeblättert werden. Ein Drucker, der nicht beidseitig drucken kann, hat diese beiden Optionen abgeblendet. Zeigen Sie auf eine Option, um den Grund zu sehen. **Manuell** ist für einen solchen Drucker gedacht: JeffCrunch druckt die erste, dritte, fünfte und so weiter Seite bzw. die Blätter, wenn Sie mehrere Seiten auf einem Blatt drucken. Danach fordert eine Meldung Sie auf, den Stapel umzudrehen und wieder in das Papierfach zu legen. Wenn Sie auf **OK** klicken, druckt es die übrigen Seiten, die letzte zuerst, damit sie auf der Rückseite landen. Wenn Sie nur eine Seite drucken, muss nichts umgedreht werden. Beim Speichern als PDF sind alle Optionen abgeblendet, da eine Datei keine Seiten-Vorder- und -Rückseiten hat. JeffCrunch merkt sich Ihre Auswahl für das nächste Mal.
- **Seiten pro Blatt**: Drucken Sie 1, 2, 4, 6, 9 oder 16 Seiten, verkleinert, auf jedes Blatt Papier. Jede Seite erhält einen dünnen Rahmen. Die Vorschau zeigt weiterhin eine Seite in Originalgröße.
- **Kopien** und **Sortiert** (ein ganzer Satz nach dem anderen, 1 2 3 1 2 3, statt die Kopien jeder Seite zusammen).
- **Ausrichtung**, **Papier** und **Seitenränder** für diesen Druck, statt der Einstellungen, die in jedem Blatt festgelegt sind.
- **Skalierung**: wie im jeweiligen Blatt festgelegt, Originalgröße, das gesamte Blatt auf einer Seite, alle Spalten auf einer Seite oder alle Zeilen auf einer Seite.
- **Druckbereich ignorieren**: alles drucken, was Inhalt hat.
- **Seite einrichten** öffnet das Dialogfeld für das aktuelle Blatt.

Unter der Vorschau zeigt JeffCrunch an, wenn etwas Aufmerksamkeit braucht: ein Blatt, das mehr Seiten bräuchte, als möglich sind, ein Blatt, das so stark verkleinert wird, dass die Schrift sehr klein ist, oder ein leeres Blatt.

## Auf Papierformat skalieren

Mit **Auf Papier skalieren** wird jede Seite verkleinert oder vergrößert, damit sie auf das gewählte Papier passt. Dabei bleibt ihre Form erhalten, und sie wird in die Mitte gesetzt. Verwenden Sie das, wenn Sie für ein Papierformat drucken möchten, das Ihr Drucker nicht hat, etwa eine für A4 eingerichtete Seite auf Letter-Papier. **Keine Skalierung** druckt jede Seite auf ihrem eigenen Papier. Die Vorschau zeigt das Blatt Papier, das ausgegeben wird.

## Mehrere Seiten auf einem Blatt

**Seiten pro Blatt** setzt 2, 4, 6, 9 oder 16 Seiten auf jedes Blatt Papier, jede davon kleiner und mit einem Rahmen. Die Vorschau zeigt das ganze Blatt, und die Beschriftung darunter nennt das angezeigte Blatt, etwa **Blatt 1 von 2**. Mit **Weiter** und **Zurück** sehen Sie die anderen Blätter.

## Der Drucker

Wählen Sie einen Drucker aus der Liste oder **Als PDF speichern**. **Druckereinstellungen** öffnet das Systemdialogfeld für weitere Einstellungen des Druckers, etwa die Papierfächer. **Drucken** sendet die Seiten.

## Als PDF exportieren

**Datei > Exportieren** erstellt eine PDF-Datei des aktuellen Blatts oder der gesamten Arbeitsmappe, ohne dass Sie einen Drucker auswählen müssen. Die Buchstaben bleiben Text und werden nicht als Bild gespeichert. Dadurch lassen sie sich durchsuchen und bleiben beim Vergrößern scharf.

Mit **Gesamte Arbeitsmappe als PDF/A exportieren** erstellen Sie eine PDF-Datei in der Form, die für die langfristige Aufbewahrung gedacht ist. Jede Schriftart wird in die Datei eingebettet, sodass sie auch in Jahren gleich aussieht. Programme, die Dokumente archivieren, verlangen diese Form.

**E-Mail erstellen** erstellt eine Nachrichtendatei mit Ihrer Arbeitsmappe im Anhang oder mit einem PDF davon. Es wird nichts gesendet. Öffnen Sie die Datei in Ihrem E-Mail-Programm, tragen Sie den Empfänger ein und senden Sie die Nachricht. Eine Arbeitsmappe mit Kennwort bleibt in der Nachricht gesperrt: Wer sie erhält, braucht das Kennwort zum Öffnen. Das Kennwort selbst wird nie in die Nachricht geschrieben. Ein PDF der Arbeitsmappe hat nur dann ein Kennwort, wenn Sie im Feld auf **Mit Kennwort verschlüsseln…** klicken, so wie bei einem exportierten PDF. Teilen Sie der Person das Kennwort auf einem anderen Weg mit als in der Nachricht.

## PDF mit Kennwort schützen

Klicken Sie unter **Datei > Exportieren** auf **Mit Kennwort verschlüsseln…**, bevor Sie einen PDF-Befehl wählen. Das Kennwort gilt nur für das nächste PDF. Geben Sie das Kennwort zweimal ein. Wer die PDF-Datei danach öffnet, muss es eingeben. Das Kennwort schützt die Datei tatsächlich: Die Seiten werden mit starker Verschlüsselung (AES-256) verschleiert, und ohne Kennwort kann sie niemand lesen.

Sie können außerdem **Drucken, Kopieren und Bearbeiten einschränken** aktivieren, ein zweites Kennwort vergeben und festlegen, was erlaubt ist. Diese Einschränkungen sind nur eine Bitte. Die meisten PDF-Programme beachten sie, doch sie hindern niemanden daran, sie zu umgehen. Verlassen Sie sich daher nicht darauf, dass eine Datei dadurch privat bleibt.

Ein vergessenes Kennwort kann nicht wiederhergestellt werden. Bewahren Sie es daher sicher auf. Das Kennwort gilt nur für dieses eine PDF und wird nie gespeichert. Der Befehl **Gesamte Arbeitsmappe als PDF/A exportieren** ist abgeblendet, solange ein Kennwort festgelegt ist, da eine PDF/A-Datei keines haben kann.

## Seitenumbrüche auf dem Bildschirm

Nachdem Sie den Bereich Drucken geöffnet haben, zeigt das Blatt auf dem Bildschirm, wo die Seiten beginnen: eine gestrichelte Linie für einen Umbruch, den JeffCrunch berechnet hat, und eine durchgezogene Linie für einen, den Sie festgelegt haben. Die Linien werden aktualisiert, wenn Sie das Blatt ändern. Schalten Sie sie mit **Ansicht > Seitenumbruchlinien** aus. (Die Ansicht **Seitenumbruchvorschau**, beschrieben unter [Seiten einrichten](page-layout), zeigt sie immer an.)

## Was noch nicht gedruckt wird

Notizen (Kommentare) werden nach der letzten Seite des Blatts gedruckt, wenn in der Seiteneinrichtung des Blatts **Nach der letzten Seite auflisten** eingestellt ist. Sie werden noch nicht an der Stelle gedruckt, an der sie in den Zellen stehen. Bedingte Formatierungen werden auf dem Bildschirm noch nicht angezeigt und daher auch nicht gedruckt.
