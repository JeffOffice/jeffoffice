# Drucken und PDF erstellen
<!-- keywords: drucken, Drucker, Druckvorschau, Vorschau, PDF, exportieren, Exemplare, Kopien, sortiert, Seiten, Seitenbereich, Auswahl, Markierung, gesamte Arbeitsmappe, Skalierung, anpassen, Seitenumbrüche, gestrichelte Linien, als PDF speichern -->

Wählen Sie **Datei > Drucken** (oder drücken Sie **Strg+P**). Die Seite wird mit einer Vorschau der Seiten geöffnet, die gedruckt werden, jeweils eine Seite auf einmal. Mit den Pfeilen darunter blättern Sie von Seite zu Seite, mit **Seite einpassen** oder den Zoomschaltflächen sehen Sie mehr oder weniger von einer Seite. Die Vorschau wird genauso dargestellt wie auf dem Drucker und in der PDF-Datei, Sie sehen also genau das, was Sie erhalten.

## Was gedruckt werden soll

- **Drucken**: das aktuelle Blatt, die gesamte Arbeitsmappe (alle eingeblendeten Blätter) oder die Auswahl. Ausgeblendete Blätter werden nicht gedruckt. Ein Diagrammblatt ergibt eine Seite, auf der das Diagramm den gesamten Platz innerhalb der Seitenränder einnimmt.
- **Seiten**: alle Seiten oder nur einige, z. B. **1-3, 5**.
- **Exemplare** und **Sortiert** (jeweils ein vollständiger Satz, 1 2 3 1 2 3, statt aller Exemplare einer Seite nacheinander).
- **Ausrichtung**, **Papier** und **Seitenränder**, die für diesen Druck statt der Einstellungen der einzelnen Blätter verwendet werden.
- **Skalierung**: wie im jeweiligen Blatt festgelegt, Originalgröße, gesamtes Blatt auf einer Seite, alle Spalten auf einer Seite oder alle Zeilen auf einer Seite.
- **Druckbereich ignorieren**: Alles drucken, was Inhalt hat.
- **Seite einrichten** öffnet das Dialogfeld für das aktuelle Blatt.

Unter der Vorschau weist JeffCrunch Sie auf Punkte hin, die Ihre Aufmerksamkeit erfordern: ein Blatt, das mehr Seiten benötigt, als erstellt werden können, ein Blatt, das so stark verkleinert wurde, dass die Schrift sehr klein ist, oder ein Blatt ohne Inhalt.

## Der Drucker

Wählen Sie einen Drucker aus der Liste aus, oder wählen Sie **Als PDF speichern**. **Druckereigenschaften** öffnet das Dialogfeld Ihres Systems mit den Optionen des Druckers, etwa für beidseitigen Druck und Papierfächer. **Drucken** sendet die Seiten an den Drucker.

## Als PDF exportieren

**Datei > Exportieren** erstellt eine PDF-Datei des aktuellen Blatts oder der gesamten Arbeitsmappe, ohne dass Sie einen Drucker auswählen müssen. Text bleibt Text (und wird nicht zu Bildern), sodass er durchsucht werden kann und beim Zoomen scharf bleibt.

## Seitenumbrüche auf dem Bildschirm

Nachdem Sie die Druckansicht geöffnet haben, zeigt das Blatt auf dem Bildschirm, wo die Seiten beginnen: eine gestrichelte Linie für einen von JeffCrunch berechneten Umbruch und eine durchgezogene Linie für einen von Ihnen festgelegten Umbruch. Die Linien werden aktualisiert, während Sie das Blatt ändern. Sie blenden sie mit **Ansicht > Seitenumbruchlinien** aus. (Die Ansicht **Seitenumbrüche**, beschrieben unter [Seiten einrichten](page-layout), zeigt sie immer an.)

## Was noch nicht gedruckt wird

Notizen (Kommentare) werden nicht gelesen und nicht gedruckt. Bedingte Formatierungen werden auf dem Bildschirm noch nicht angezeigt und daher auch nicht gedruckt.
