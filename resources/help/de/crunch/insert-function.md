# Funktion auswählen
<!-- keywords: Funktion, Funktion auswählen, Funktion einfügen, fx, Formel, Argument, Kategorie, Suche, Alle Funktionen, Summe, Funktionsassistent, Umschalt+F3 -->

Wählen Sie auf der Registerkarte **Formeln** den Befehl **Funktion auswählen** (**Umschalt+F3**) oder im Menü **Summe** den Befehl **Alle Funktionen**.

Geben Sie in das Suchfeld einen Namen ein oder das, was Sie tun möchten („abrunden“, „Text verbinden“). Die Liste zeigt dann die passenden Funktionen an, wobei Namen, die mit Ihren Wörtern beginnen, zuerst erscheinen. Mit **Art** beschränken Sie die Liste auf Funktionen der Kategorien Finanzmathematik, Datum und Uhrzeit, Mathematik und Trigonometrie, Statistik, Nachschlagen und Verweisen, Text, Logik, Information oder Datenbank.

Wählen Sie eine Funktion aus, um zu sehen, wie sie geschrieben wird, was sie tut und welche Argumente sie hat. Ein Argument in Klammern ist optional, und „weitere gleichartige“ bedeutet, dass Sie beliebig viele davon angeben können. Klicken Sie auf **OK** (oder doppelklicken Sie auf die Funktion).

Nach **OK** öffnet sich für die Funktion der Dialog **Funktionsargumente**, in dem Sie die Argumente ausfüllen und das Ergebnis schon beim Tippen sehen (siehe [Eine Funktion mit dem Dialog „Funktionsargumente“ eingeben](function-arguments)). **OK** schreibt dort die Formel in die Zelle, zum Beispiel **=SUM(A1:A3)**. Wenn Sie bereits eine Formel eingeben, wird die Funktion an der Cursorposition eingefügt. Es werden nur die Funktionen aufgeführt, die JeffCrunch berechnen kann.

## Meldungen zu Zellen

Eine Zelle mit einer Regel für zulässige Eingaben kann auch eine Meldung haben (einen Titel und einen Satz). Die Meldung wird neben der Zelle angezeigt, solange diese Zelle ausgewählt ist. Listen, die Zellen eines anderen Blatts lesen, funktionieren ebenfalls.
