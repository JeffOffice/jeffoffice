# Funktion auswählen
<!-- keywords: Funktion, Funktion auswählen, fx, Formel, Argument, Kategorie, suchen, alle Funktionen, Summe, Umschalt+F3 -->

Wählen Sie auf der Registerkarte **Formeln** die Option **Funktion auswählen** (**Umschalt+F3**) oder im Menü **Summe** die Option **Alle Funktionen**.

Geben Sie im Suchfeld einen Namen oder eine Beschreibung dessen ein, was Sie tun möchten (z. B. „abrunden“ oder „Text verbinden“). Die Liste zeigt die passenden Funktionen, wobei Namen, die mit Ihren Wörtern beginnen, zuerst erscheinen. Mit **Art** können Sie die Liste auf Finanz-, Datums- und Uhrzeit-, Mathematik- und Trigonometrie-, Statistik-, Nachschlage- und Verweisfunktionen, Textfunktionen, logische Funktionen, Informationsfunktionen, Datenbankfunktionen oder technische Funktionen einschränken.

Wählen Sie eine Funktion aus, um zu sehen, wie sie geschrieben wird, was sie tut und welche Argumente sie hat. Ein Argument in eckigen Klammern ist optional. „Weitere gleiche Argumente“ bedeutet, dass Sie beliebig viele angeben können. Klicken Sie auf **OK** (oder doppelklicken Sie auf die Funktion).

Nach **OK** öffnet sich das Dialogfeld **Funktionsargumente** für die Funktion. Dort füllen Sie die Argumente aus, während das Ergebnis bereits beim Eingeben angezeigt wird (siehe [Funktion mit dem Dialogfeld Funktionsargumente eingeben](function-arguments)). Ein Klick auf **OK** trägt die Formel in die Zelle ein, zum Beispiel **=SUMME(A1:A3)**. Wenn Sie gerade eine Formel eingeben, wird die Funktion an der Einfügemarke eingefügt. Es werden nur Funktionen aufgelistet, die JeffCrunch berechnen kann.

## Meldungen für Zellen

Eine Zelle, für die eine Regel festlegt, was eingegeben werden darf, kann zusätzlich eine Meldung enthalten (einen Titel und einen Satz). Sie wird neben der Zelle angezeigt, solange die Zelle ausgewählt ist. Listen, die Zellen eines anderen Blatts lesen, funktionieren ebenfalls.

## Funktionen nach Art

Die Gruppe **Funktionsbibliothek** der Registerkarte **Formeln** enthält außerdem für jede Funktionsart eine Schaltfläche: **Finanz**, **Logisch**, **Text**, **Datum und Uhrzeit**, **Nachschlagen und Verweisen**, **Mathematik und Trigonometrie** sowie **Weitere Funktionen** (Statistik, Technik, Informationen und Datenbank). Jede öffnet eine Liste ihrer Funktionen. Zeigen Sie mit dem Zeiger auf einen Namen, um zu lesen, was die Funktion tut. Wählen Sie eine aus, dann öffnet sich das Dialogfeld **Funktionsargumente** für diese Funktion.

**Zuletzt verwendet** listet die zuletzt ausgewählten zehn Funktionen auf, die neueste zuerst.
