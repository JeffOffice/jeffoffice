# Mit der Tastatur in JeffCrunch arbeiten

Auf der Registerkarte **Hilfe** finden Sie **Hilfe** (F1), **Tastenkombinationen**, die diese Seite öffnet, **Neuerungen** und **Feedback**, die ihre Webseiten öffnen.

Auf einem Mac übernimmt die Taste **Befehl** (⌘) die Funktion der Taste **Strg** aus den folgenden Tabellen, außer wo eine Tabelle etwas anderes angibt.

## Bewegen und Auswählen

| Tasten | Funktion |
| --- | --- |
| Pfeiltasten | Bewegen die aktive Zelle um eine Zelle; ausgeblendete Zeilen und Spalten werden übersprungen |
| Umschalt+Pfeiltaste | Erweitert die Auswahl um eine Zelle |
| Strg+Pfeiltaste | Springt zum Rand der Daten (Esc bricht eine lange Suche ab) |
| Strg+Umschalt+Pfeiltaste | Erweitert die Auswahl bis zum Rand der Daten |
| Pos1 | Springt zur ersten Spalte der Zeile |
| Strg+Pos1 | Springt zur ersten Zelle (A1 oder zur ersten Zelle, die beim Scrollen sichtbar ist, wenn Zeilen oder Spalten fixiert sind) |
| Strg+Ende | Springt zur letzten Zelle, die einen Inhalt oder eine Formatierung hat |
| Bild ab, Bild auf | Bewegt um einen Bildschirm nach unten bzw. oben |
| Tab, Umschalt+Tab | Bewegt nach rechts bzw. links (innerhalb der markierten Zellen, falls mehrere markiert sind) |
| Eingabe, Umschalt+Eingabe | Bewegt nach unten bzw. oben (innerhalb der markierten Zellen, falls mehrere markiert sind) |
| Strg+Leertaste | Wählt die ganze Spalte aus |
| Umschalt+Leertaste | Wählt die ganze Zeile aus |
| {key:SelectAll} | Wählt alles aus |

## Eigene Tastenkürzel festlegen

Sie können die Tasten jedes Befehls ändern oder einem Befehl, der keine hat, eine Taste zuweisen. Klicken Sie auf **Datei > Optionen** und dann auf die Registerkarte **Anpassen**.

1. Geben Sie im Feld **Suchen** den Namen oder die Tasten eines Befehls ein. Die Liste ist nach den Registerkarten des Menübands gegliedert, und jeder Befehl zeigt seine Tasten an. Befehle, die nicht im Menüband stehen, finden Sie unter **Sonstige**.
2. Klicken Sie auf den Befehl. Seine Tasten werden unter **Tasten für diesen Befehl** aufgelistet.
3. Klicken Sie in das Feld **Neue Tasten drücken**, und drücken Sie die gewünschten Tasten, zum Beispiel **Strg+Umschalt+B**. Klicken Sie dann auf **Zuweisen**. Ein Befehl kann bis zu vier Tastenkombinationen haben.
4. Um eine Taste zu entfernen, klicken Sie in der Liste darauf und dann auf **Entfernen**.

Wenn ein anderer Befehl die gedrückten Tasten bereits verwendet, zeigt JeffCrunch an, welcher es ist. Klicken Sie auf **Übernehmen**, um die Tasten diesem Befehl zuzuweisen; der andere Befehl verliert sie dann. Erst mit einem Klick auf **OK** werden Änderungen wirksam. Danach verwenden alle geöffneten JeffCrunch-Fenster und alle später geöffneten Fenster Ihre Tasten. QuickInfos, Menüs und die unten stehende Tabelle der Tastenkombinationen zeigen Ihre Tasten an.

Auch ein Sonderzeichen kann eine Tastenkombination erhalten. Siehe **Sonderzeichen einfügen** unter [Text in Zellen eingeben](edit-cells): Klicken Sie im Feld **Sonderzeichen** auf **Tastenkürzel**. Es wird dann in dieser Liste wie jeder andere Befehl angezeigt.

Mit **Einzeln zurücksetzen** stellen Sie die üblichen Tasten des gewählten Befehls wieder her. Mit **Alle zurücksetzen** stellen Sie die üblichen Tasten aller Befehle wieder her. JeffCrunch speichert nur die Befehle, deren Tasten Sie geändert haben. Ein Befehl, den Sie nicht geändert haben, erhält daher in einer späteren Version gegebenenfalls bessere Tasten.

Manche Tasten lassen sich keinem Befehl zuweisen, weil das System oder die Texteingabe sie benötigen. JeffCrunch meldet **reserviert**, wenn Sie eine solche Taste drücken. Reserviert sind **Strg+C**, **Strg+X**, **Strg+V**, **Strg+Z**, **Strg+A**, **Tab**, **Umschalt+Tab**, **Eingabe**, **Esc**, **Rücktaste**, **Entf**, **Alt+F4**, die Pfeiltasten, **Pos1**, **Ende**, **Bild auf**, **Bild ab** und die **Leertaste**, **F1**, **F6**, **Umschalt+F6**, **Strg+Y**, **Strg+Umschalt+Z**, **Strg** mit einer Pfeiltaste, **Pos1**, **Ende**, **Rücktaste** oder **Entf** (mit oder ohne **Umschalt**, sofern das in einem Textfeld sinnvoll ist) sowie ein Buchstaben-, Ziffern- oder Sonderzeichen, allein oder mit **Umschalt** gedrückt. Auch eine Taste, die schon ein anderer Teil des Fensters verwendet, ist reserviert. **Speichern**, **Rückgängig** und **Wiederholen** behalten immer mindestens eine Taste. Auf einem Mac bedeutet **Strg** hier die Taste **Befehl**.

## Zugriffstasten

Drücken Sie **Alt**, um auf jeder Registerkarte und bei jedem Befehl des Menübands einen Buchstaben anzuzeigen, und drücken Sie dann die Buchstaben. Drücken Sie **Alt** und danach **F**, um die Ansicht Datei zu öffnen. Mit **Esc** gehen Sie einen Schritt zurück.
