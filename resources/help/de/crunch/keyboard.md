# Verwenden von JeffCrunch mit der Tastatur
<!-- keywords: Tastatur, Tastenkombinationen, Tasten, Tastaturkürzel, Pfeiltasten, Strg, Umschalt, Pos1, Ende, Bild auf, Bild ab, Tab, Eingabe, alles auswählen, kopieren, F9, F1, Zoom, Zugriffstasten, Tastentipps -->

Die Registerkarte **Hilfe** enthält **Hilfe** (F1), **Tastenkombinationen**, wodurch diese Seite geöffnet wird, **Neuerungen** und **Feedback**, wodurch jeweils die entsprechenden Webseiten geöffnet werden.

Auf einem Mac entspricht die Taste **Befehl** (⌘) der Taste **Strg** in den folgenden Tabellen, sofern in einer Tabelle nichts anderes angegeben ist.

## Bewegen und Auswählen

| Tasten | Funktion |
| --- | --- |
| Pfeiltasten | Bewegt die aktive Zelle um eine Zelle und überspringt dabei ausgeblendete Zeilen und Spalten |
| Umschalt+Pfeiltaste | Erweitert die Markierung um eine Zelle |
| Strg+Pfeiltaste | Springt zum Rand der Daten (mit Esc brechen Sie eine lange Suche ab) |
| Strg+Umschalt+Pfeiltaste | Erweitert die Markierung bis zum Rand der Daten |
| Pos1 | Springt zur ersten Spalte der Zeile |
| Strg+Pos1 | Springt zur ersten Zelle (A1 oder zur ersten Zelle, die beim Scrollen sichtbar wird, wenn Zeilen oder Spalten fixiert sind) |
| Strg+Ende | Springt zur letzten Zelle, die einen Inhalt oder eine Formatierung hat |
| Bild ab, Bild auf | Bewegt die Ansicht um einen Bildschirm nach unten bzw. oben |
| Tab, Umschalt+Tab | Bewegt nach rechts bzw. links (durch die markierten Zellen, wenn mehrere markiert sind) |
| Eingabe, Umschalt+Eingabe | Bewegt nach unten bzw. oben (durch die markierten Zellen, wenn mehrere markiert sind) |
| Strg+Leertaste | Markiert die ganze Spalte |
| Umschalt+Leertaste | Markiert die ganze Zeile |
| Strg+A | Markiert alles |

## Zellen ändern

| Tasten | Funktion |
| --- | --- |
| Beliebiges Zeichen | Beginnt eine Eingabe in der aktiven Zelle und ersetzt dabei deren Inhalt |
| F2 | Bearbeitet den Inhalt der aktiven Zelle direkt in der Zelle; beim Eingeben einer Formel wechseln Sie damit zwischen dem Zeigen auf Zellen und dem Bearbeiten des Textes |
| F4 | Fixiert beim Eingeben einer Formel die Adressteile an der Einfügemarke mit $ (A1, $A$1, A$1, $A1) |
| Eingabe, Umschalt+Eingabe | Übernimmt die Eingabe und bewegt nach unten bzw. oben |
| Tab, Umschalt+Tab | Übernimmt die Eingabe und bewegt nach rechts bzw. links |
| Esc | Verwirft die Eingabe |
| Alt+Eingabe | Beginnt eine neue Zeile in der Zelle |
| Entf | Löscht die markierten Zellen |
| Strg+Z, Strg+Y | Rückgängig, Wiederholen |
| Strg+S | Speichert |
| Strg+X, Strg+C, Strg+V | Ausschneiden, kopieren, einfügen (mit Esc entfernen Sie den Rahmen um die kopierten Zellen) |
| Strg+Alt+V | Inhalte einfügen |
| Strg und Plustaste, Strg und Minustaste | Fügt ein bzw. löscht Zeilen oder Spalten, wenn ganze Zeilen oder Spalten markiert sind |
| Strg+D, Strg+R | Nach unten bzw. nach rechts ausfüllen |
| Strg+E | Blitzvorschau |
| Alt und Gleichheitszeichen | Summe |
| Strg+0, Strg+9 | Blendet die Spalten bzw. die Zeilen aus |
| Alt+Pfeil nach unten | Öffnet die Liste einer Zelle, die eine Liste enthält |
| Strg+F | Sucht |
| Strg+H (auf dem Mac Wahl+Befehl+F) | Suchen und Ersetzen |
| F5, Strg+G | Springt zu einer Zelle, einem Bereich oder einem Namen |
| Strg+Umschalt+L | Schaltet den Filter ein oder aus |
| Umschalt+F3 | Wählt eine Funktion aus |
| Strg+F3 | Öffnet die Liste der Namen |
| F9, Umschalt+F9 | Berechnet alles neu, berechnet dieses Blatt neu |
| Tab, Eingabe | Während eine Formel eingegeben wird: übernimmt die in der Liste markierte Funktion oder den markierten Namen |
| Esc | Beendet eine laufende Suche, Sortierung oder Filterung |

## Zugriffstasten

Drücken Sie **Alt**, um auf jeder Registerkarte des Menübands und bei jedem Befehl einen Buchstaben einzublenden, und drücken Sie dann die Buchstaben. Drücken Sie **Alt** und dann **F**, um die Ansicht „Datei“ zu öffnen. Mit **Esc** gehen Sie einen Schritt zurück.
