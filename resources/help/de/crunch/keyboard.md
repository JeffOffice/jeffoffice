# Mit der Tastatur in JeffCrunch arbeiten

Auf der Registerkarte **Hilfe** finden Sie **Hilfe** (F1), **Tastenkombinationen**, die diese Seite öffnet, **Neuerungen** und **Feedback**, die ihre Webseiten öffnen.

Auf dem Mac entspricht die Taste **Command** (⌘) der Taste **Strg** in den folgenden Tabellen, sofern eine Tabelle nichts anderes angibt.

## Bewegen und Auswählen

| Tasten | Funktion |
| --- | --- |
| Pfeiltasten | Bewegt die aktive Zelle um eine Zelle; ausgeblendete Zeilen und Spalten werden übersprungen |
| Umschalt+Pfeiltaste | Erweitert die Auswahl um eine Zelle |
| Strg+Pfeiltaste | Springt zum Rand der Daten (Esc beendet eine lange Suche) |
| Strg+Umschalt+Pfeiltaste | Erweitert die Auswahl bis zum Rand der Daten |
| Ende, dann eine Pfeiltaste | Springt zum Rand der Daten (die Statusleiste zeigt „Ende“ an) |
| Strg+A | Wählt den Block um die aktive Zelle aus, dann das gesamte Blatt (das gesamte Blatt sofort, wenn die Auswahl bereits größer als der Block ist) |
| Strg+Umschalt+* | Wählt den Block um die aktive Zelle aus |
| Strg+Klick oder Strg+Ziehen | Fügt einen Bereich zur Auswahl hinzu |
| Strg+Umschalt+Eingabe | Gibt die Formel als Matrixformel über die ausgewählten Zellen ein |
| Pos1 | Springt zur ersten Spalte der Zeile |
| Strg+Pos1 | Springt zur ersten Zelle (A1 oder zur ersten Zelle, die beim Scrollen sichtbar wird, wenn Zeilen oder Spalten fixiert sind) |
| Strg+Ende | Springt zur letzten Zelle, die einen Inhalt oder eine Formatierung hat |
| Bild ab, Bild auf | Bewegt um eine Bildschirmseite nach unten oder oben |
| Tab, Umschalt+Tab | Bewegt nach rechts oder links (durch die ausgewählten Zellen, falls mehrere ausgewählt sind) |
| Eingabe, Umschalt+Eingabe | Bewegt nach unten oder oben (durch die ausgewählten Zellen, falls mehrere ausgewählt sind) |
| Strg+Leertaste | Wählt die ganze Spalte aus |
| Umschalt+Leertaste | Wählt die ganze Zeile aus |
| {key:SelectAll} | Wählt alles aus |

## Eigene Tastenkürzel festlegen

Sie können die Tasten jedes Befehls ändern oder einem Befehl Tasten zuweisen, der noch keine hat. Klicken Sie auf **Datei > Optionen** und dann auf die Registerkarte **Anpassen**.

1. Geben Sie im Feld **Suchen** den Namen des Befehls oder seine Tasten ein, um ihn zu finden. Die Liste ist nach den Registerkarten des Menübands gruppiert, und bei jedem Befehl stehen seine Tasten. Befehle, die nicht im Menüband stehen, sind unter **Andere** aufgeführt.
2. Klicken Sie auf den Befehl. Seine Tasten werden unter **Tasten für diesen Befehl** angezeigt.
3. Klicken Sie in das Feld **Neue Tasten drücken**, und drücken Sie die gewünschten Tasten, zum Beispiel **Strg+Umschalt+B**. Klicken Sie dann auf **Zuweisen**. Ein Befehl kann bis zu vier Tastenkombinationen haben.
4. Um eine Taste zu entfernen, klicken Sie sie in der Liste an und klicken auf **Entfernen**.

Hat ein anderer Befehl bereits die gedrückten Tasten, zeigt JeffCrunch an, welcher es ist. Klicken Sie auf **Übernehmen**, um die Tasten diesem Befehl zuzuweisen; der andere Befehl verliert sie dann. Erst wenn Sie auf **OK** klicken, wird etwas geändert. Danach verwenden alle geöffneten JeffCrunch-Fenster und alle Fenster, die Sie später öffnen, Ihre Tasten. QuickInfos, Menüs und die folgende Tastenübersicht zeigen Ihre Tasten an.

Auch ein Sonderzeichen kann Tasten haben. Siehe **Sonderzeichen einfügen** unter [Text in Zellen eingeben](edit-cells): Klicken Sie im Feld „Sonderzeichen“ auf **Tastenkürzel**. Es wird dann in dieser Liste wie jeder andere Befehl angezeigt.

Mit **Einzeln zurücksetzen** erhält der gewählte Befehl seine üblichen Tasten zurück. **Alle zurücksetzen** stellt die üblichen Tasten aller Befehle wieder her. JeffCrunch speichert nur die Befehle, deren Tasten Sie geändert haben. Ein Befehl, den Sie nie geändert haben, erhält daher bessere Tasten, die eine spätere Version ihm zuweist.

Einige Tasten können Befehlen nicht zugewiesen werden, weil das System oder die Texteingabe sie benötigt. JeffCrunch zeigt **reserviert** an, wenn Sie eine solche Taste drücken. Reserviert sind **Strg+C**, **Strg+X**, **Strg+V**, **Strg+Z**, **Strg+A**, **Tab**, **Umschalt+Tab**, **Eingabe**, **Esc**, **Rücktaste**, **Entf**, **Alt+F4**, die Pfeiltasten, **Pos1**, **Ende**, **Bild auf**, **Bild ab** und die **Leertaste**, **F1**, **F6**, **Umschalt+F6**, **Strg+Y**, **Strg+Umschalt+Z**, **Strg** mit einer Pfeiltaste, **Pos1**, **Ende**, **Rücktaste** oder **Entf** (mit oder ohne **Umschalt**, sofern das in einem Textfeld sinnvoll ist) sowie ein Buchstaben-, Ziffern- oder Sonderzeichen, allein oder zusammen mit **Umschalt**. Tasten, die ein anderer Teil des Fensters bereits verwendet, sind ebenfalls reserviert. **Speichern**, **Rückgängig** und **Wiederholen** behalten immer mindestens eine Taste. Auf dem Mac bedeutet **Strg** hier die Taste **Command**.

## Zugriffstasten

Drücken Sie **Alt**, um auf jeder Registerkarte und bei jedem Befehl des Menübands einen Buchstaben einzublenden, und drücken Sie dann die Buchstaben. Drücken Sie **Alt** und dann **F**, um die Backstage-Ansicht „Datei“ zu öffnen. Mit **Esc** gehen Sie einen Schritt zurück.
