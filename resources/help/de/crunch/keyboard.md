# Mit der Tastatur in JeffCrunch arbeiten

Die Registerkarte **Hilfe** enthält **Hilfe** (F1), **Tastenkombinationen**, wodurch diese Seite geöffnet wird, **Neuerungen** und **Feedback**. Die beiden letzten öffnen jeweils ihre Webseiten.

Auf einem Mac entspricht die Taste **Command** (⌘) der Taste **Strg** in den folgenden Tabellen, sofern eine Tabelle nichts anderes angibt.

## Bewegen und Auswählen

| Tasten | Funktion |
| --- | --- |
| Pfeiltasten | Bewegt die aktive Zelle um eine Zelle und überspringt dabei ausgeblendete Zeilen und Spalten |
| Umschalt+Pfeiltaste | Erweitert die Auswahl um eine Zelle |
| Strg+Pfeiltaste | Springt zum Rand der Daten (mit Esc brechen Sie eine längere Suche ab) |
| Strg+Umschalt+Pfeiltaste | Erweitert die Auswahl bis zum Rand der Daten |
| Ende, dann eine Pfeiltaste | Springt zum Rand der Daten (die Statusleiste zeigt Ende an) |
| Strg+A | Wählt den Block um die aktive Zelle aus, dann das ganze Blatt (das ganze Blatt sofort, wenn die Auswahl bereits größer als der Block ist) |
| Strg+Umschalt+* | Wählt den Block um die aktive Zelle aus |
| Strg+Klick oder Strg+Ziehen | Fügt einen Bereich zur Auswahl hinzu |
| Strg+Umschalt+Eingabe | Gibt die Formel als Matrixformel über den ausgewählten Zellen ein |
| Pos1 | Springt zur ersten Spalte der Zeile |
| Strg+Pos1 | Springt zur ersten Zelle (A1 oder zur ersten Zelle, die beim Scrollen sichtbar wird, wenn Zeilen oder Spalten fixiert sind) |
| Strg+Ende | Springt zur letzten Zelle, die einen Inhalt oder eine Formatierung hat |
| Bild ab, Bild auf | Bewegt sich um einen Bildschirm nach unten bzw. oben |
| Tab, Umschalt+Tab | Bewegt sich nach rechts bzw. links (durch die ausgewählten Zellen, wenn mehrere ausgewählt sind) |
| Eingabe, Umschalt+Eingabe | Bewegt sich nach unten bzw. oben (durch die ausgewählten Zellen, wenn mehrere ausgewählt sind) |
| Strg+Leertaste | Wählt die gesamte Spalte aus |
| Umschalt+Leertaste | Wählt die gesamte Zeile aus |
| {key:SelectAll} | Wählt alles aus |

## Eigene Tastenkürzel festlegen

Sie können die Tasten jedes Befehls ändern oder einem Befehl eine Taste zuweisen, der bisher keine hat. Klicken Sie auf **Datei > Optionen** und dann auf die Registerkarte **Anpassen**.

1. Geben Sie im Feld **Suchen** den Namen eines Befehls oder seine Tasten ein. Die Liste ist nach den Registerkarten des Menübands gruppiert, und bei jedem Befehl sind seine Tasten angegeben. Befehle, die nicht im Menüband stehen, sind unter **Andere** aufgeführt.
2. Klicken Sie auf den Befehl. Seine Tasten werden unter **Tasten für diesen Befehl** angezeigt.
3. Klicken Sie in das Feld **Neue Tasten drücken**, und drücken Sie die gewünschten Tasten, zum Beispiel **Strg+Umschalt+B**. Klicken Sie danach auf **Zuweisen**. Einem Befehl können bis zu vier Tasten zugewiesen werden.
4. Um eine Taste zu entfernen, klicken Sie in der Liste darauf und dann auf **Entfernen**.

Hat ein anderer Befehl bereits die gedrückten Tasten, meldet JeffCrunch, welcher es ist. Klicken Sie auf **Übernehmen**, um die Tasten diesem Befehl zuzuweisen; der andere Befehl verliert sie dann. Erst wenn Sie auf **OK** klicken, wird etwas geändert. Danach verwenden alle geöffneten JeffCrunch-Fenster Ihre Tasten, ebenso jedes Fenster, das Sie später öffnen. QuickInfos, Menüs und die unten stehende Tabelle der Tastenkürzel zeigen Ihre Tasten an.

Auch ein Symbol kann Tasten haben. Siehe **Sonderzeichen einfügen** unter [Text in Zellen eingeben](edit-cells): Klicken Sie im Feld Symbol auf **Tastenkürzel**. Es wird dann in dieser Liste wie jeder andere Befehl angezeigt.

Mit **Einzeln zurücksetzen** stellen Sie die üblichen Tasten des gewählten Befehls wieder her. Mit **Alle zurücksetzen** stellen Sie die üblichen Tasten aller Befehle wieder her. JeffCrunch speichert nur die Befehle, deren Tasten Sie geändert haben. Ein Befehl, den Sie nie geändert haben, erhält daher in einer späteren Version gegebenenfalls bessere Tasten.

Manche Tasten können keinem Befehl zugewiesen werden, weil das System oder das Schreiben sie benötigt. JeffCrunch meldet **reserviert**, wenn Sie eine solche Taste drücken. Reserviert sind **Strg+C**, **Strg+X**, **Strg+V**, **Strg+Z**, **Strg+A**, **Tab**, **Umschalt+Tab**, **Eingabe**, **Esc**, **Rücktaste**, **Entf**, **Alt+F4**, die Pfeiltasten, **Pos1**, **Ende**, **Bild auf**, **Bild ab** und die **Leertaste**, **F1**, **F6**, **Umschalt+F6**, **Strg+Y**, **Strg+Umschalt+Z**, **Strg** mit einer Pfeiltaste, **Pos1**, **Ende**, **Rücktaste** oder **Entf** (mit oder ohne **Umschalt**, wo das in einem Textfeld sinnvoll ist) sowie eine Buchstaben-, Ziffern- oder Symboltaste allein oder mit **Umschalt**. Auch eine Taste, die ein anderer Teil des Fensters bereits verwendet, ist reserviert. **Speichern**, **Rückgängig** und **Wiederholen** behalten immer mindestens eine Taste. Auf einem Mac bedeutet **Strg** hier die Taste **Command**.

## Zugriffstasten

Drücken Sie **Alt**, um auf jeder Registerkarte des Menübands und bei jedem Befehl einen Buchstaben anzuzeigen, und drücken Sie dann diese Buchstaben. Drücken Sie **Alt** und danach **D**, um die Backstage-Ansicht „Datei“ zu öffnen. Mit **Esc** gehen Sie einen Schritt zurück.
