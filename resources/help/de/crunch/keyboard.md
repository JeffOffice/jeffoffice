# Die Tastatur in JeffCrunch verwenden

Die Registerkarte **Hilfe** enthält **Hilfe** (F1), **Tastenkombinationen**, die diese Seite öffnet, **Neuerungen** und **Feedback**, die ihre Webseiten öffnen.

Auf dem Mac übernimmt die Taste **Befehl** (⌘) die Funktion der Taste **Strg** aus den folgenden Tabellen, sofern in einer Tabelle nichts anderes angegeben ist.

## Bewegen und Auswählen

| Tasten | Funktion |
| --- | --- |
| Pfeiltasten | Bewegt die aktive Zelle um eine Zelle; ausgeblendete Zeilen und Spalten werden übersprungen |
| Umschalt+Pfeiltaste | Erweitert die Auswahl um eine Zelle |
| Strg+Pfeiltaste | Springt zum Rand der Daten (Esc bricht eine lange Suche ab) |
| Strg+Umschalt+Pfeiltaste | Erweitert die Auswahl bis zum Rand der Daten |
| Ende, dann eine Pfeiltaste | Springt zum Rand der Daten (die Statusleiste zeigt Ende an) |
| Strg+A | Wählt den Block um die aktive Zelle aus, dann das ganze Blatt (das ganze Blatt sofort, wenn die Auswahl bereits größer als der Block ist) |
| Strg+Umschalt+* | Wählt den Block um die aktive Zelle aus |
| Strg+Klick oder Strg+Ziehen | Fügt einen Bereich zur Auswahl hinzu |
| Strg+Umschalt+Eingabe | Gibt die Formel als Matrixformel über den ausgewählten Zellen ein |
| Pos1 | Springt zur ersten Spalte der Zeile |
| Strg+Pos1 | Springt zur ersten Zelle (A1 oder zur ersten Zelle, die bei fixierten Zeilen oder Spalten scrollt) |
| Strg+Ende | Springt zur letzten Zelle, die einen Inhalt oder eine Formatierung hat |
| Bild ab, Bild auf | Bewegt sich um einen Bildschirm nach unten oder oben |
| Tab, Umschalt+Tab | Bewegt sich nach rechts oder links (durch die ausgewählten Zellen, falls mehrere ausgewählt sind) |
| Eingabe, Umschalt+Eingabe | Bewegt sich nach unten oder oben (durch die ausgewählten Zellen, falls mehrere ausgewählt sind) |
| Strg+Leertaste | Wählt die ganze Spalte aus |
| Umschalt+Leertaste | Wählt die ganze Zeile aus |
| {key:SelectAll} | Wählt alles aus |

## Eigene Tastenkürzel festlegen

Sie können die Tasten jedes Befehls ändern oder einem Befehl, der keine hat, eine Taste zuweisen. Klicken Sie auf **Datei > Optionen** und dann auf die Registerkarte **Anpassen**.

1. Geben Sie im Feld **Suchen** den Namen oder die Tasten eines Befehls ein. Die Liste ist nach den Registerkarten des Menübands gegliedert, und bei jedem Befehl stehen seine Tasten. Befehle, die nicht im Menüband sind, stehen unter **Andere**.
2. Klicken Sie auf den Befehl. Seine Tasten werden unter **Tasten für diesen Befehl** angezeigt.
3. Klicken Sie in das Feld **Neue Tasten drücken**, und drücken Sie die gewünschten Tasten, etwa **Strg+Umschalt+B**. Klicken Sie danach auf **Zuweisen**. Ein Befehl kann bis zu vier Tastenkombinationen haben.
4. Um eine Taste zu entfernen, klicken Sie sie in der Liste an und dann auf **Entfernen**.

Wenn ein anderer Befehl die gedrückten Tasten bereits verwendet, zeigt JeffCrunch an, welcher es ist. Klicken Sie auf **Übernehmen**, um die Tasten diesem Befehl zuzuweisen; der andere Befehl verliert sie dann. Erst mit **OK** werden Änderungen wirksam. Danach verwenden alle geöffneten JeffCrunch-Fenster und alle später geöffneten Fenster Ihre Tasten. QuickInfos, Menüs und die unten stehende Tabelle der Tastenkombinationen zeigen Ihre Tasten an.

Auch ein Symbol kann Tasten haben. Siehe **Sonderzeichen einfügen** unter [Text in Zellen eingeben](edit-cells): Klicken Sie im Feld Sonderzeichen auf **Tastenkürzel**. Es erscheint dann in dieser Liste wie jeder andere Befehl.

**Einzelne zurücksetzen** stellt die üblichen Tasten des gewählten Befehls wieder her. **Alle zurücksetzen** stellt die üblichen Tasten aller Befehle wieder her. JeffCrunch speichert nur die Befehle, deren Tasten Sie geändert haben. Ein Befehl, den Sie nicht geändert haben, erhält daher in einer späteren Version gegebenenfalls bessere Tasten.

Manche Tasten können einem Befehl nicht zugewiesen werden, weil das System oder die Texteingabe sie benötigt. JeffCrunch zeigt **reserviert** an, wenn Sie eine solche Taste drücken. Reserviert sind **Strg+C**, **Strg+X**, **Strg+V**, **Strg+Z**, **Strg+A**, **Tab**, **Umschalt+Tab**, **Eingabe**, **Esc**, **Rücktaste**, **Entf**, **Alt+F4**, die Pfeiltasten, **Pos1**, **Ende**, **Bild auf**, **Bild ab** und die **Leertaste**, **F1**, **F6**, **Umschalt+F6**, **Strg+Y**, **Strg+Umschalt+Z**, **Strg** mit einer Pfeiltaste, **Pos1**, **Ende**, **Rücktaste** oder **Entf** (mit oder ohne **Umschalt**, wo das in einem Textfeld sinnvoll ist) sowie eine Buchstaben-, Ziffern- oder Symboltaste, allein oder mit **Umschalt** gedrückt. Auch eine Taste, die ein anderer Teil des Fensters bereits verwendet, ist reserviert. **Speichern**, **Rückgängig** und **Wiederholen** behalten immer mindestens eine Taste. Auf dem Mac steht **Strg** hier für die Taste **Befehl**.

## Zugriffstasten

Drücken Sie **Alt**, um auf jeder Registerkarte des Menübands und bei jedem Befehl einen Buchstaben einzublenden, und drücken Sie dann die Buchstaben. Drücken Sie **Alt** und danach **D**, um die Backstage-Ansicht „Datei“ zu öffnen. Mit **Esc** kehren Sie zurück.
