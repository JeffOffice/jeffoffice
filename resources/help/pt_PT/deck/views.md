# Vista de Estrutura de Tópicos e Organização de Diapositivos
<!-- keywords: vista de estrutura de tópicos, estrutura de tópicos, destaques, organização de diapositivos, organizador, vistas, vista normal, miniaturas, grelha, reordenar diapositivos, mover diapositivos, selecionar diapositivos, promover, despromover, tabulação, títulos, só texto, zoom, tamanho das miniaturas -->

A vista Normal é onde edita um diapositivo de cada vez. Duas outras vistas ajudam quando trabalha na apresentação inteira: **Vista de Estrutura de Tópicos** para o texto e **Organização de Diapositivos** para a ordem dos diapositivos. Mude de vista no separador **Ver**, em **Vistas de Apresentação**, ou com os botões da barra de estado.

## Vista de Estrutura de Tópicos

A Vista de Estrutura de Tópicos mostra o texto dos diapositivos como uma estrutura de tópicos, em vez das imagens dos diapositivos. O próprio diapositivo e as respetivas notas continuam ao lado.

- Cada diapositivo é uma linha numerada com o respetivo **título**, a negrito. Por baixo estão as linhas do texto do corpo, com avanço consoante o nível.
- Escreva para alterar um título ou uma linha. O diapositivo é alterado quando faz uma pausa ou quando clica noutro local. Cada alteração é um passo que Ctrl+Z anula.
- Prima **Enter** no fim de um título para iniciar um novo diapositivo logo a seguir. Prima Enter no corpo para iniciar uma nova linha no mesmo nível.
- Prima **Tab** para avançar uma linha um nível. Um título em que prima Tab passa a ser uma linha do diapositivo anterior. Prima **Shift+Tab** para recuar uma linha um nível. Uma linha de primeiro nível em que prima Shift+Tab passa a ser um diapositivo próprio.
- O diapositivo ao lado da estrutura de tópicos acompanha a linha onde está o cursor.

Só o título e o primeiro marcador de posição de corpo de cada diapositivo aparecem na estrutura de tópicos. Os outros objetos dos diapositivos, como imagens e formas, não são mostrados e ficam como estão.

## Organização de Diapositivos

A Organização de Diapositivos mostra cada diapositivo como uma imagem numa grelha, com tantos lado a lado quantos couberem na janela. O número de cada diapositivo aparece por baixo. Um diapositivo oculto tem o número rasurado e a imagem esbatida. Uma estrela junto ao número indica uma transição. Numa apresentação com secções, cada secção começa numa linha própria, por baixo de um título com o respetivo nome e o número de diapositivos.

**Selecionar diapositivos**

- Clique num diapositivo para o selecionar. Mantenha premida a tecla **Shift** e clique para selecionar todos os diapositivos desde o último em que clicou até este. Mantenha premida a tecla **Ctrl** e clique para adicionar ou remover um.
- Prima **Ctrl+A** para selecionar todos os diapositivos.
- As teclas de seta permitem percorrer a grelha. Mantenha premida a tecla Shift com uma tecla de seta para ir selecionando. **Home**, **End**, **Page Up** e **Page Down** avançam mais.

**Trabalhar com eles**

- Arraste os diapositivos selecionados para um novo local. Uma linha mostra onde vão ficar. Prima Esc durante o arrastamento para cancelar.
- Prima **Delete** para eliminar os diapositivos selecionados. Prima **Ctrl+D** para os duplicar. Clique com o botão direito do rato para abrir um menu com **Novo Diapositivo**, **Duplicar Diapositivo**, **Eliminar Diapositivo**, **Ocultar Diapositivo** e **Adicionar secção**. Cada um é um passo que Ctrl+Z anula.
- Faça duplo clique num diapositivo, ou prima **Enter**, para o abrir na vista Normal.
- Um clique no título de uma secção fecha os respetivos diapositivos. Clique com o botão direito do rato num título para abrir o respetivo menu. Consulte [Adicionar, alterar e eliminar diapositivos](slides).

**Alterar o tamanho das imagens.** Mantenha premida a tecla Ctrl e rode a roda do rato, ou utilize os controlos de zoom da barra de estado. O controlo de deslize, **Reduzir**, **Ampliar** e o menu **Zoom** do separador **Ver** alteram todos o tamanho das imagens enquanto a Organização de Diapositivos está aberta.

## Voltar à vista Normal

Clique em **Ver > Vistas de Apresentação > Normal** ou no botão **Normal** da barra de estado.
