# Transições entre diapositivos
<!-- keywords: transição, transições, desvanecer, empurrar, revelar gradualmente, dividir, revelar, cobrir, descobrir, zoom, cortar, opções de efeitos, direção, duração, avançar diapositivo, ao clicar com o rato, após, automático, temporização, aplicar a todos, pré-visualizar, estrela, efeito de passagem -->

Uma **transição** é o efeito reproduzido quando a apresentação de diapositivos passa de um diapositivo para o seguinte. A transição pertence ao diapositivo em que entra. A apresentação de diapositivos reprodu-la quando avança para esse diapositivo.

## Adicionar uma transição

1. Clique no diapositivo no painel de diapositivos.
2. Clique no separador **Transições**. Na galeria **Transição para Este Diapositivo**, clique num efeito: **Nenhum**, **Desvanecer**, **Empurrar**, **Revelar Gradualmente**, **Dividir**, **Revelar**, **Cobrir**, **Descobrir**, **Zoom** ou **Cortar**. A imagem do diapositivo no painel de diapositivos recebe uma pequena estrela para indicar que tem uma transição.
3. Clique em **Transições > Pré-visualizar > Pré-visualizar** para a ver reproduzida na entrada do diapositivo, sobre a área do diapositivo. Prima Esc para a parar.

Escolha **Nenhum** para remover uma transição.

## Escolher como decorre

Clique em **Opções de Efeitos** para ver as opções do efeito:

- **Empurrar**, **Revelar Gradualmente**, **Revelar**, **Cobrir** e **Descobrir** têm uma direção: **Da direita**, **Da esquerda**, **De baixo** ou **De cima**.
- **Dividir** e **Zoom** podem ser **Para fora** ou **Para dentro**.
- **Desvanecer** e **Cortar** não têm opções. Um corte passa por preto.

## Definir a temporização

O grupo **Temporização** define quanto tempo demora e como a apresentação sai do diapositivo.

- **Duração** é o número de segundos que o efeito demora. Uma nova transição demora 0,7 segundos. Pode escrever um valor de 0,01 a 59.
- **Ao Clicar com o Rato** está ativado por predefinição. A apresentação avança a partir deste diapositivo quando o apresentador clica. Desative-o para avançar com uma tecla, como Espaço ou Seta para a Direita. As animações do diapositivo continuam a ser reproduzidas com um clique. Um clique com o botão direito retrocede sempre.
- **Após** faz a apresentação avançar sozinha após o número de segundos que escrever. Pode utilizar **Após** juntamente com **Ao Clicar com o Rato**: a apresentação avança com o que acontecer primeiro.

**Aplicar a Todos** atribui a todos os diapositivos a transição e a temporização do diapositivo em que se encontra.

Cada uma destas ações é um passo que Ctrl+Z anula.

## Transições de outros ficheiros

Uma apresentação criada noutro programa pode ter uma transição para a qual o JeffDeck não tem efeito. É reproduzida como um desvanecimento e é guardada tal como estava, pelo que continua a funcionar no local de origem.
