# Utilizar o JeffDeck com o teclado

<!-- keywords: teclado, atalhos, teclas de atalho, atalhos de teclado, sugestões de teclas, teclas de acesso, tecla Alt, tecla Tab, teclas de seta, sem rato, navegar, teclas de acesso rápido, teclas da apresentação de diapositivos, F5, Esc -->

Pode fazer a maioria das tarefas no JeffDeck sem rato. Existem teclas de atalho para comandos comuns, Sugestões de Teclas para o friso, e teclas que funcionam no diapositivo, no painel de diapositivos, na Organização de Diapositivos, na vista de Destaques e na apresentação de diapositivos.

## Utilizar as Sugestões de Teclas no friso

As Sugestões de Teclas são pequenas letras que aparecem no friso. Permitem-lhe chegar a qualquer botão sem o rato.

1. Prima e solte **Alt**. Aparecem letras no botão **Ficheiro**, em cada separador e na barra de ferramentas rápida. Os botões da barra de ferramentas rápida usam os números de 1 a 3.
2. Prima a letra do separador que pretende. Os separadores usam **H** para **Base**, **N** para **Inserir**, **G** para **Design**, **K** para **Transições**, **S** para **Apresentação de Diapositivos**, **R** para **Rever** e **W** para **Ver**. Aparecem as letras dos botões desse separador.
3. Escreva as letras do botão que pretende. Por exemplo, prima **Alt**, depois **S**, depois **B** para iniciar a **Apresentação de Diapositivos** **Desde o Início**.

Também pode manter Alt premido e premir a letra de um separador de uma só vez. **Alt+H** abre o separador **Base**. **Alt+F** abre o ecrã Ficheiro.

Prima **Esc** para voltar atrás um passo. Prima qualquer outra tecla para ocultar as letras. As letras que aparecem esbatidas pertencem a um botão que não pode utilizar neste momento.

Prima **Ctrl+F1** para ocultar os botões do friso e mostrar apenas os nomes dos separadores, para ter mais espaço no diapositivo. Prima novamente para os repor.

## Trabalhar no diapositivo

Clique no diapositivo. Depois:

- **Ctrl+Page Down** vai para o diapositivo seguinte, e **Ctrl+Page Up** para o anterior.
- **Tab** seleciona o objeto seguinte. **Shift+Tab** seleciona o anterior.
- As **teclas de seta** deslocam o objeto selecionado um pequeno passo. Mantenha **Alt** premido para o passo mais pequeno.
- **Enter** ou **F2** edita o texto da caixa de texto, marcador de posição, forma ou tabela selecionada. Também pode simplesmente começar a escrever.
- **Delete** elimina o objeto selecionado.
- **Ctrl+1** abre o painel Formatar Forma para o objeto selecionado.
- **Shift+F10** ou a tecla **Menu** abre o menu de clique com o botão direito no objeto selecionado ou no cursor de texto.
- **Ctrl+F** localiza palavras nos diapositivos e nas notas. **Ctrl+H** substitui-as. **Ctrl+G** vai para um diapositivo pelo respetivo número.
- **Esc** termina a edição de texto. A caixa continua selecionada. Prima Esc novamente para limpar a seleção.

Ao escrever numa tabela, **Tab** move-se para a célula seguinte. Tab na última célula acrescenta uma linha.

## No painel de diapositivos

Clique no painel e depois:

- **Seta para Cima** e **Seta para Baixo** vão para o diapositivo anterior ou seguinte. **Home** e **End** vão para o primeiro e o último diapositivo.
- **Enter** acrescenta um novo diapositivo depois do que está selecionado.
- **Delete** elimina o diapositivo atual.

## Na Organização de Diapositivos

- As **teclas de seta**, **Home**, **End**, **Page Up** e **Page Down** deslocam-se pela grelha. Mantenha **Shift** premido para selecionar à medida que se desloca.
- **Ctrl+A** seleciona todos os diapositivos. **Ctrl+D** duplica os diapositivos selecionados. **Delete** elimina-os.
- **Enter** abre o diapositivo na vista Normal.

## Na vista de Destaques

- **Enter** no fim de um título inicia um novo diapositivo.
- **Tab** desloca uma linha um nível para dentro. **Shift+Tab** desloca-a um nível para fora.

## Na apresentação de diapositivos

- **Seta para a Direita**, **Seta para Baixo**, **Espaço**, **Enter**, **Page Down** ou **N** avançam.
- **Seta para a Esquerda**, **Seta para Cima**, **Backspace**, **Page Up** ou **P** recuam.
- **Home** e **End** vão para o primeiro e o último diapositivo. O número de um diapositivo seguido de **Enter** vai para esse diapositivo.
- **B** ou a tecla de ponto escurece o ecrã. **W** ou a tecla de vírgula torna-o branco. Prima a mesma tecla novamente para repor o diapositivo.
- **Ctrl+P** é a caneta, **Ctrl+I** o marcador de texto, **Ctrl+L** o ponteiro laser e **Ctrl+E** a borracha. **E** apaga a tinta do diapositivo. **Ctrl+A** repõe a seta.
- **Esc** repõe a seta quando a caneta, o marcador de texto, o ponteiro laser ou a borracha estão escolhidos. Caso contrário, termina a apresentação.

Prima **F1** para obter ajuda sobre o que está a fazer. O separador **Ajuda** tem **Ajuda**, **Atalhos de Teclado**, que abre esta página, **Novidades** e **Feedback**, que abrem as respetivas páginas Web.
