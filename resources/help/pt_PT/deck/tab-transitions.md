# Separador Transições

<!-- keywords: separador transições, friso, pré-visualizar, transição para este diapositivo, opções de efeito, duração, ao clicar com o rato, após, aplicar a todos, transformação, objetos, palavras, carateres, desvanecer, enviar, revelar, cobrir, descobrir, zoom, cortar, dissolver, persianas, xadrez, pente, barras aleatórias, círculo, losango, mais, cunha, roda, forma, relâmpago, notícia relâmpago, tiras, aleatório -->

O separador **Transições** define a forma como a apresentação de diapositivos passa para o diapositivo em que está.

- **Pré-visualizar** tem **Pré-visualizar**, que reproduz a transição no diapositivo para que a possa ver.
- **Transição para Este Diapositivo** é uma galeria de efeitos: **Nenhum**, **Transformação**, **Desvanecer**, **Empurrar**, **Limpar**, **Dividir**, **Revelar**, **Cobrir**, **Descobrir**, **Zoom**, **Cortar**, **Dissolver**, **Persianas**, **Xadrez**, **Pente**, **Barras Aleatórias**, **Círculo**, **Losango**, **Mais**, **Cunha**, **Roda**, **Forma**, **Relâmpago**, **Notícia Relâmpago**, **Tiras** e **Aleatório**. **Opções de Efeito** escolhe a direção, **Para fora** e **Para dentro**, horizontal ou vertical, os raios de uma roda ou a forma de uma forma, nos efeitos que as têm. Para **Transformação**, escolhe **Objetos**, **Palavras** ou **Carateres**.
- **Temporização** tem **Duração**, **Ao Clicar com o Rato**, **Após** com os respetivos segundos, e **Aplicar a Todos**. Uma transformação demora 2 segundos quando a escolhe. Os restantes efeitos demoram 0,7 segundos.

Veja [Transições entre diapositivos](transitions).
