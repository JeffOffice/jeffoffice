# Separador Transições
<!-- keywords: separador transições, friso, pré-visualizar, transição para este diapositivo, opções de efeito, duração, ao clicar com o rato, após, aplicar a todos, transformação, objetos, palavras, carateres, desvanecer, empurrar, revelar gradualmente, dividir, revelar, cobrir, descobrir, zoom, cortar -->

O separador **Transições** define a forma como a apresentação de diapositivos passa para o diapositivo em que se encontra.

- **Pré-visualizar** contém **Pré-visualizar**, que reproduz a transição para o diapositivo para que a possa ver.
- **Transição para Este Diapositivo** é uma galeria de efeitos: **Nenhuma**, **Transformação**, **Desvanecer**, **Empurrar**, **Revelar Gradualmente**, **Dividir**, **Revelar**, **Cobrir**, **Descobrir**, **Zoom** e **Cortar**. **Opções de Efeitos** escolhe a direção, ou **Para fora** e **Para dentro**, nos efeitos que as têm. Para **Transformação**, escolhe **Objetos**, **Palavras** ou **Carateres**.
- **Temporização** contém **Duração**, **Ao Clicar com o Rato**, **Após** com os respetivos segundos, e **Aplicar a Todos**. Uma transformação demora 2 segundos quando a escolhe. Os outros efeitos demoram 0,7 segundos.

Consulte [Transições entre diapositivos](transitions).
