# Separador Base

<!-- keywords: separador base, friso, área de transferência, grupo tipo de letra, grupo parágrafo, galeria de estilos, objetos, grupo edição, ferramentas de formatação -->

O separador **Base** está sempre no friso. Contém as ferramentas que mais utiliza ao escrever e ao compor uma página.

- **Área de transferência** tem **Colar**, **Cortar**, **Copiar** e **Copiar formatação**, que copia o aspeto do texto para outra caixa. Consulte [Formatar texto](formatting-text).
- **Tipo de letra** altera o tipo de letra, o tamanho, a cor e o estilo dos carateres. Consulte [Formatar texto](formatting-text).
- **Parágrafo** tem marcas, numeração, avanços, alinhamento e espaçamento para parágrafos inteiros. Consulte [Marcas, numeração e tabulações](lists-tabs).
- **Estilos** é uma galeria de aspetos com nome que pode aplicar com um clique, e uma forma de criar os seus próprios. Consulte [Utilizar estilos](styles).
- **Objetos** desenha uma caixa de texto, insere uma tabela, adiciona imagens e desenha formas. Consulte [Adicionar e formatar caixas de texto](text-boxes).
- **Organizar** controla a forma como os objetos moldam o texto, se sobrepõem, se agrupam, se alinham e se rodam. Consulte [Mover, alinhar, agrupar e sobrepor objetos](arrange).
- **Edição** tem **Localizar**, **Substituir**, **Ir Para** e **Selecionar**, que escolhe todo o texto de uma caixa, todos os objetos ou todos os objetos de um tipo. **Ir Para** (Ctrl+G) vai para uma página pelo seu número, ou para um comentário pelo seu número ou para o seguinte ou anterior. Consulte [Localizar e substituir texto](find-replace).

## O painel Área de transferência

O painel Área de transferência memoriza as últimas 24 coisas que copiou ou cortou nesta janela do programa, para que possa colar uma mais antiga sem a copiar novamente. Clique na pequena seta no canto do grupo **Área de transferência** no separador **Base** (ou prima **Alt**, depois **H** e depois **FO**) para o abrir. Um painel aparece ao lado da página.

Cada item mostra uma pequena pré-visualização e o tipo de conteúdo: texto, texto formatado, células, uma imagem, formas ou diapositivos. O mais recente fica no topo. Clique num item para o colar onde estiver o cursor ou a seleção. Cola-se como qualquer outra colagem: um passo de **Anular** desfaz-o, e o botão Opções de Colagem aparece como habitualmente.

- **Colar Tudo** cola todos os itens, do mais antigo para o mais recente, para que fiquem na ordem em que os copiou.
- **Eliminar** remove o item escolhido. **Limpar Tudo** remove todos.
- O painel só recolhe itens enquanto estiver aberto. Para continuar a recolher depois de o fechar, marque **Continuar a recolher quando este painel for fechado**. A escolha fica memorizada, e a recolha começa quando o programa é iniciado, antes de abrir o painel.
- Para recolher também o que copia noutros programas, marque **Recolher também o que é copiado noutros programas**. Só são guardados texto simples e imagens, e esta opção fica desativada de novo sempre que abre o programa. Com esta opção ativa, uma cópia feita noutro programa é lida integralmente antes de este programa decidir se a guarda, por isso uma cópia muito grande pode fazer este programa pausar por um momento e utilizar tanta memória quanto o tamanho da cópia. Só é lida uma forma: o seu texto, quando o tem, caso contrário, uma imagem. Com esta opção desativada, nada copiado noutros programas é lido.

Os itens são guardados apenas na memória do programa. Nada é gravado num ficheiro, e a lista é esvaziada quando fecha a última janela do programa. Um item permanece na lista depois de o documento de onde provém ser fechado. Um item com mais de 8 MB não é guardado, e o painel avisa quando isso acontece; uma imagem conta 4 bytes por cada ponto (píxel), pelo que uma imagem com mais de cerca de 2 milhões de píxeis é demasiado grande. Todos os itens em conjunto são limitados a 64 MB, e os mais antigos são removidos primeiro. Qualquer conteúdo que um gestor de palavras-passe marque como secreto nunca é guardado.
