# Obter ajuda e comunicar problemas
<!-- keywords: suporte, contactar o suporte, comunicar um problema, erro, bug, comentários, sugestão, sugerir, pedido de funcionalidade, ideia, github, versão, falha, bloqueio, mensagem de erro, ajuda, acerca de, atualizações -->

Se o JeffPub fizer algo estranho ou se tiver uma ideia para o melhorar, informe as pessoas que o desenvolvem. Pode fazê-lo no GitHub, um site onde estas registam problemas e ideias.

## Procure primeiro uma resposta

- Prima **F1** ou clique em **Ajuda > Ajuda > Ajuda** e escreva algumas palavras na caixa de pesquisa. Consulte [Bem-vindo ao JeffPub](start).
- Clique em **Ajuda > Ajuda > Atalhos de Teclado** para ver as teclas. Consulte [Utilizar o JeffPub com o teclado](keyboard).
- Clique em **Ajuda > Ajuda > Novidades** para ler as notas da sua versão.
- Se perdeu trabalho depois de o JeffPub fechar, consulte [Recuperar trabalho não guardado](recover).
- Verifique se tem a versão mais recente. Clique em **Ficheiro > Acerca de** e, em seguida, em **Procurar Atualizações**. O problema pode já estar corrigido.

## Comunicar um problema ou sugerir uma ideia

1. Clique em **Ajuda > Ajuda > Comentários**. Abre-se uma página do GitHub no browser. Precisa de uma conta gratuita do GitHub para publicar nessa página.
2. Atribua-lhe um título curto, como "O texto desaparece quando imprimo" ou "Ideia: mais estilos de limite".
3. Em **What would you like to tell us?**, descreva o que correu mal ou o que gostaria. Anote qualquer mensagem que tenha visto.
4. No caso de um problema, em **What did you do just before it happened?**, indique os passos pela ordem em que os seguiu, para que outra pessoa os possa experimentar.
5. Mantenha a última linha. Esta indica a versão do JeffPub e o sistema operativo. Se não estiver presente, adicione o número da versão que aparece em **Ficheiro > Acerca de**.
6. Utilize o botão da página do GitHub para a enviar.

Uma imagem do problema ajuda. Não publique uma publicação que contenha informações privadas.

## Acerca do JeffPub

Clique em **Ficheiro > Acerca de** para ver o número da versão, procurar atualizações e ler a licença e os créditos. A página também tem ligações para o código-fonte, para as transferências e para **Comunicar um problema**. Para as opções de atualizações e estatísticas, consulte [Alterar as definições do JeffPub](options).
