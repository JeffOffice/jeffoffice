# Utilizar o JeffPub com o teclado
<!-- keywords: teclado, atalhos, teclas de atalho, atalhos de teclado, sugestões de teclas, keytips, tecla alt, f6, tecla tab, teclas de seta, sem rato, navegar, teclas de acesso, foco, friso com teclado -->

Pode aceder aos comandos do friso, à lista Páginas e aos objetos da página sem utilizar o rato. Existem três formas: teclas de atalho para comandos comuns, Sugestões de Teclas para o friso e navegação com F6, Tab e as teclas de seta.

## Mover entre as partes da janela

Prima **F6** para mover o **foco** do teclado (o local para onde vai a próxima tecla que premir) para a parte seguinte da janela. A ordem é o friso, a lista Páginas, a página e, de novo, o friso. Prima **Shift+F6** para ir no sentido inverso. Se a lista Páginas estiver oculta, é ignorada. Quando utiliza o teclado, um contorno colorido mostra que controlo tem o foco.

Prima **F1** para obter Ajuda sobre o que está a fazer. Prima **Ctrl+F1** para fechar ou expandir o friso.

## Utilizar as Sugestões de Teclas no friso

As Sugestões de Teclas são pequenas letras que aparecem no friso. Permitem aceder a qualquer botão sem o rato.

1. Prima e solte **Alt**. Aparecem letras no botão **Ficheiro**, em cada separador e na barra de ferramentas rápida. Os botões da barra de ferramentas rápida utilizam os números 1 a 4.
2. Prima a letra do separador pretendido, como **H** para **Base**. Aparecem as letras dos botões desse separador.
3. Escreva as letras do botão pretendido. Por exemplo, **T** e depois **B** corresponde a **Desenhar caixa de texto**.

Também pode manter Alt premida e premir a letra de um separador num só gesto. Alt+H abre o separador **Base**. Alt+F abre a página **Ficheiro**. Alt+Y abre o separador **Ajuda**.

Prima **Esc** para recuar um passo. Prima qualquer outra tecla para ocultar as letras. As letras esbatidas pertencem a um botão que não pode utilizar neste momento, como um que necessita de um objeto selecionado.

## Navegar no friso com as teclas de seta

1. Prima F6 para chegar ao separador atual.
2. Prima **Seta para a Esquerda** ou **Seta para a Direita** para mudar de separador.
3. Prima **Seta para Baixo** para entrar nos botões. Utilize as teclas de seta para se deslocar entre eles. **Tab** e **Shift+Tab** também passam para o controlo seguinte ou anterior.
4. Prima **Enter** ou **Espaço** para utilizar um botão. Um botão com menu abre o respetivo menu.
5. Prima **Esc** para voltar à página.

## Trabalhar na página

Clique na área da página ou prima F6 até lá chegar. Em seguida:

- **Tab** seleciona o objeto seguinte. **Shift+Tab** seleciona o anterior.
- As **teclas de seta** deslocam o objeto selecionado um pequeno passo. Mantenha **Alt** premida para o passo mais pequeno. Para definir o tamanho do passo, consulte [Alterar as definições do JeffPub](options).
- **Enter** ou **F2** edita o texto da caixa de texto, forma ou tabela selecionada. Também pode simplesmente começar a escrever.
- **Delete** remove o objeto selecionado. Com células de uma tabela selecionadas, limpa o respetivo texto.
- **Esc** termina a edição de texto. A caixa de texto continua selecionada. Prima Esc novamente para limpar a seleção.

Enquanto escreve numa tabela, **Tab** passa para a célula seguinte. Tab na última célula adiciona uma linha.
