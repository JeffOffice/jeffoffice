# Separador Página Modelo
<!-- keywords: separador página modelo, separador modelo, página modelo, página mestra, cabeçalho, rodapé, mostrar cabeçalho rodapé, inserir data, inserir hora, número de página, numeração de páginas, página modelo de duas páginas, fechar página modelo, friso -->

O separador **Página Modelo** aparece enquanto está a editar uma página modelo. Surge em primeiro lugar, logo a seguir a **Ficheiro**, e é o separador apresentado quando abre uma página modelo. Para lá chegar, clique em **Ver > Vistas > Página Modelo**. Uma página modelo é uma página de fundo cujo conteúdo é apresentado em todas as páginas que a utilizam.

Enquanto edita uma página modelo, o separador **Correspondência** fica oculto.

- **Página Modelo**: adicione uma página modelo ou uma página modelo de duas páginas para páginas opostas, aplique esta página modelo a todas as páginas ou à página atual, e duplique-a, mude-lhe o nome ou elimine-a. Consulte [Páginas modelo, cabeçalhos e números de página](master-pages).
- **Cabeçalho e Rodapé**: **Mostrar Cabeçalho/Rodapé** coloca o cursor no cabeçalho da página modelo (criando um, se necessário); clique novamente para passar ao rodapé. **Inserir Número de Página** (Alt+Shift+P), **Inserir Data** (Alt+Shift+D) e **Inserir Hora** (Alt+Shift+T) adicionam um número de página, a data de hoje ou a hora no local onde está o cursor; a data e a hora mantêm-se atualizadas. Consulte [Páginas modelo, cabeçalhos e números de página](master-pages).
- **Fechar**: saia da página modelo e regresse às suas páginas. Consulte [Páginas modelo, cabeçalhos e números de página](master-pages).
