# Utilizar o JeffCrunch com o teclado
<!-- keywords: teclado, atalhos, atalhos de teclado, teclas, teclas de atalho, seta, ctrl, shift, home, end, page up, page down, tabulação, enter, selecionar tudo, copiar, F9, F1, zoom, teclas de acesso, sugestões de teclas -->

Num Mac, a tecla **Command** (⌘) faz o mesmo que **Ctrl** nas tabelas abaixo, exceto quando a tabela indicar o contrário.

## Mover e selecionar

| Teclas | O que fazem |
| --- | --- |
| Teclas de seta | Movem a célula ativa uma célula, ignorando linhas e colunas ocultas |
| Shift+seta | Expande a seleção uma célula |
| Ctrl+seta | Vai para o limite dos dados (Esc interrompe uma procura demorada) |
| Ctrl+Shift+seta | Expande a seleção até ao limite dos dados |
| Home | Vai para a primeira coluna da linha |
| Ctrl+Home | Vai para a primeira célula (A1, ou a primeira célula que se desloca quando há linhas ou colunas fixadas) |
| Ctrl+End | Vai para a última célula que tem conteúdo ou formato |
| Page Down, Page Up | Desloca para baixo ou para cima um ecrã |
| Tab, Shift+Tab | Move para a direita ou para a esquerda (dentro das células selecionadas, se houver várias) |
| Enter, Shift+Enter | Move para baixo ou para cima (dentro das células selecionadas, se houver várias) |
| Ctrl+Espaço | Seleciona a coluna inteira |
| Shift+Espaço | Seleciona a linha inteira |
| {key:SelectAll} | Seleciona tudo |

## Alterar células

| Teclas | O que fazem |
| --- | --- |
| Qualquer carácter | Inicia uma entrada na célula ativa, substituindo o que esta contém |
| F2 | Edita o conteúdo da célula ativa, na própria célula; ao escrever uma fórmula, alterna entre apontar para células e editar o texto |
| F4 | Ao escrever uma fórmula, fixa partes do endereço onde está o cursor com $ (A1, $A$1, A$1, $A1) |
| Enter, Shift+Enter | Mantém a entrada e move para baixo ou para cima |
| Tab, Shift+Tab | Mantém a entrada e move para a direita ou para a esquerda |
| Esc | Cancela a entrada |
| Alt+Enter | Inicia uma nova linha na célula |
| Delete | Limpa as células selecionadas |
| {key:Undo}, {key:Redo} | Anular, refazer |
| {key:Save} | Guardar |
| {key:Cut}, {key:Copy}, {key:Paste} | Cortar, copiar, colar (Esc remove o limite das células copiadas) |
| Ctrl+Alt+V | Colar Especial |
| Ctrl e a tecla mais, Ctrl e a tecla menos | Inserir, eliminar (linhas ou colunas, se estiverem selecionadas inteiras) |
| Ctrl+D, Ctrl+R | Preencher para baixo, preencher para a direita |
| Alt e o sinal de igual | Soma |
| Ctrl+0, Ctrl+9 | Ocultar as colunas, ocultar as linhas |
| Alt+Seta para baixo | Abre a lista de uma célula que tenha uma |
| {key:Find} | Localizar |
| Ctrl+H (num Mac, Option+Command+F) | Localizar e Substituir |
| F5, Ctrl+G | Ir para uma célula, um intervalo ou um nome |
| Ctrl+Shift+L | Ativa ou desativa o filtro |
| Shift+F3 | Escolher uma função |
| Ctrl+F3 | A lista de nomes |
| F9, Shift+F9 | Recalcular Tudo, Recalcular Esta Folha |
| Tab, Enter | Ao escrever uma fórmula: aceita a função ou o nome assinalado na lista |
| Esc | Interrompe uma procura, ordenação ou filtragem em curso |

## Teclas de acesso

Prima **Alt** para ver uma letra em cada separador do friso e em cada comando e, em seguida, prima as letras. Prima **Alt** e depois **F** para abrir o ecrã Ficheiro. Prima **Esc** para recuar.
