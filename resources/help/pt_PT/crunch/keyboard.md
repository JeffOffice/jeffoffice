# Utilizar o JeffCrunch com o teclado

O separador **Ajuda** tem **Ajuda** (F1), **Atalhos de Teclado**, que abre esta página, **Novidades** e **Feedback**, que abrem as respetivas páginas Web.

Num Mac, a tecla **Command** (⌘) faz o que a tecla **Ctrl** faz nas tabelas abaixo, exceto quando uma tabela indique o contrário.

## Deslocar e selecionar

| Teclas | O que fazem |
| --- | --- |
| Teclas de seta | Deslocam a célula ativa uma célula, ignorando linhas e colunas ocultas |
| Shift+seta | Alarga a seleção uma célula |
| Ctrl+seta | Vai até à extremidade dos dados (Esc interrompe uma pesquisa demorada) |
| Ctrl+Shift+seta | Alarga a seleção até à extremidade dos dados |
| End, depois uma seta | Vai até à extremidade dos dados (a barra de estado mostra End) |
| Ctrl+A | Seleciona o bloco à volta da célula ativa e, depois, a folha inteira (a folha inteira de uma só vez quando a seleção já é maior do que o bloco) |
| Ctrl+Shift+* | Seleciona o bloco à volta da célula ativa |
| Ctrl+clique ou Ctrl+arrastar | Acrescenta um intervalo à seleção |
| Ctrl+Shift+Enter | Introduz a fórmula como fórmula matricial nas células selecionadas |
| Home | Vai para a primeira coluna da linha |
| Ctrl+Home | Vai para a primeira célula (A1, ou a primeira célula que rola quando linhas ou colunas estão fixas) |
| Ctrl+End | Vai para a última célula que contém algo ou tem formatação |
| Page Down, Page Up | Desce ou sobe um ecrã |
| Tab, Shift+Tab | Desloca para a direita ou para a esquerda (pelas células selecionadas, se houver várias) |
| Enter, Shift+Enter | Desloca para baixo ou para cima (pelas células selecionadas, se houver várias) |
| Ctrl+Espaço | Seleciona a coluna inteira |
| Shift+Espaço | Seleciona a linha inteira |
| {key:SelectAll} | Seleciona tudo |

## Alterar células

| Teclas | O que fazem |
| --- | --- |
| Qualquer carácter | Inicia uma entrada na célula ativa, em substituição do que ela contém |
| F2 | Edita o conteúdo da célula ativa, na própria célula; ao escrever uma fórmula, alterna entre apontar para células e editar o texto |
| F4 | Ao escrever uma fórmula, fixa partes do endereço no cursor com $ (A1, $A$1, A$1, $A1) |
| Enter, Shift+Enter | Mantém a entrada e desloca para baixo ou para cima |
| Tab, Shift+Tab | Mantém a entrada e desloca para a direita ou para a esquerda |
| Esc | Cancela a entrada |
| Alt+Enter | Inicia uma nova linha na célula |
| Delete | Limpa as células selecionadas |
| {key:Undo}, {key:Redo} | Anular, refazer |
| F4 | Repete o último comando nas células selecionadas (Ctrl+Y também o faz, quando não há nada para refazer) |
| {key:Save} | Guardar |
| {key:Cut}, {key:Copy}, {key:Paste} | Cortar, copiar, colar (Esc remove o contorno das células copiadas) |
| Ctrl+Alt+V | Colar Especial |
| Ctrl e a tecla de mais, Ctrl+Shift e a tecla de mais, Ctrl e a tecla de menos | Inserir, eliminar (linhas ou colunas, se forem selecionadas linhas ou colunas inteiras; as teclas de mais inserem células recortadas ou copiadas sem alterações desde então, e, caso contrário, células em branco) |
| Teclas de seta, Shift+seta, Ctrl+seta (Option+seta num Mac), Enter, Esc | Depois de Mover ou Redimensionar Nota: move a caixa da nota, redimensiona-a, define os passos como 1 píxel, mantém-na ou cancela-a |
| Ctrl+D, Ctrl+R | Preencher para baixo, preencher para a direita |
| Ctrl+E | Preenchimento Relâmpago |
| Alt e o sinal de igual | Soma |
| Ctrl+0, Ctrl+9 | Ocultar as colunas, ocultar as linhas |
| Alt+Seta para baixo | Abre a lista de uma célula que tenha uma |
| {key:Find} | Localizar |
| Ctrl+H (num Mac, Option+Command+F) | Localizar e Substituir |
| F5, Ctrl+G | Ir para uma célula, um intervalo ou um nome |
| Ctrl+Shift+L | Ativa ou desativa o filtro |
| Shift+F3 | Escolhe uma função |
| Ctrl+F3 | A lista de nomes |
| F9, Shift+F9 | Recalcular tudo, recalcular esta folha |
| Tab, Enter | Ao escrever uma fórmula: escolhe a função ou o nome assinalado na lista |
| Esc | Interrompe uma pesquisa, uma ordenação ou um filtro em curso |

## Escolha as suas próprias teclas de atalho

Pode alterar as teclas de qualquer comando ou atribuir uma tecla a um comando que não tenha nenhuma. Clique em **Ficheiro > Opções** e, depois, no separador **Personalizar**.

1. Escreva na caixa **Pesquisar** para encontrar um comando pelo nome ou pelas teclas. A lista está agrupada pelos separadores do friso, e cada comando mostra as suas teclas. Os comandos que não estão no friso aparecem em **Outros**.
2. Clique no comando. As respetivas teclas aparecem em **Teclas para este comando**.
3. Clique na caixa **Premir as novas teclas** e prima as teclas que pretende, por exemplo **Ctrl+Shift+B**. Depois, clique em **Atribuir**. Um comando pode ter até quatro teclas.
4. Para retirar uma tecla, clique nela na lista e clique em **Remover**.

Se outro comando já tiver as teclas que premiu, o JeffCrunch indica qual. Clique em **Reatribuir** para atribuir as teclas a este comando, e o outro comando deixa de as ter. Nada muda até clicar em **OK**. Depois, todas as janelas abertas do JeffCrunch usam as suas teclas, e também todas as janelas que abrir mais tarde. As sugestões, os menus e a tabela de atalhos abaixo mostram as suas teclas.

Um símbolo também pode ter teclas. Consulte **Inserir um símbolo** em [Escrever nas células](edit-cells): clique em **Tecla de Atalho** na caixa Símbolo. Depois, esse símbolo aparece nesta lista como qualquer outro comando.

**Repor Um** repõe as teclas habituais do comando escolhido. **Repor Tudo** repõe as teclas habituais de todos os comandos. O JeffCrunch guarda apenas os comandos cujas teclas alterou, pelo que um comando que nunca alterou recebe as teclas melhores que uma versão posterior lhe atribua.

Algumas teclas não podem ser atribuídas a um comando, porque o sistema ou a escrita as necessitam. O JeffCrunch indica **reservada** quando prime uma delas. As teclas reservadas são **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z**, **Ctrl+A**, **Tab**, **Shift+Tab**, **Enter**, **Esc**, **Backspace**, **Delete**, **Alt+F4**, as teclas de seta, **Home**, **End**, **Page Up**, **Page Down** e **Espaço**, **F1**, **F6**, **Shift+F6**, **Ctrl+Y**, **Ctrl+Shift+Z**, **Ctrl** com uma seta, **Home**, **End**, **Backspace** ou **Delete** (com ou sem **Shift**, quando isso faça sentido numa caixa de texto), e uma tecla de letra, de algarismo ou de símbolo premida sozinha ou com **Shift**. Uma tecla que outra parte da janela já utiliza também fica reservada. **Guardar**, **Anular** e **Refazer** mantêm sempre pelo menos uma tecla. Num Mac, **Ctrl** aqui significa a tecla **Command**.

## Teclas de acesso

Prima **Alt** para ver uma letra em cada separador e comando do friso e, depois, prima as letras. Prima **Alt** e, depois, **F**, para aceder ao ecrã Ficheiro. Prima **Esc** para voltar atrás.
