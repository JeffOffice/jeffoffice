# Utilizar o JeffCrunch com o teclado
<!-- keywords: teclado, atalhos, teclas, teclas de atalho, seta, ctrl, shift, home, end, page up, page down, tab, enter, selecionar tudo, copiar, F9, F1, zoom, teclas de acesso, sugestões de teclas -->

Num Mac, a tecla **Command** (⌘) faz o que a tecla **Ctrl** faz nas tabelas abaixo, exceto quando uma tabela indicar outra coisa.

## Deslocar-se e selecionar

| Teclas | O que fazem |
| --- | --- |
| Teclas de seta | Deslocam a célula ativa uma célula, saltando as linhas e colunas ocultas |
| Shift+seta | Estendem a seleção em uma célula |
| Ctrl+seta | Vão até à extremidade dos dados (Esc interrompe uma pesquisa longa) |
| Ctrl+Shift+seta | Estendem a seleção até à extremidade dos dados |
| Home | Vai para a primeira coluna da linha |
| Ctrl+Home | Vai para a primeira célula (A1, ou para a primeira célula que se desloca quando as linhas ou colunas estão fixadas) |
| Ctrl+End | Vai para a última célula que contém algo ou tem formatação |
| Page Down, Page Up | Desce ou sobe um ecrã |
| Tab, Shift+Tab | Avançam para a direita ou para a esquerda (pelas células selecionadas, se houver várias) |
| Enter, Shift+Enter | Descem ou sobem (pelas células selecionadas, se houver várias) |
| Ctrl+Espaço | Seleciona a coluna inteira |
| Shift+Espaço | Seleciona a linha inteira |
| {key:SelectAll} | Seleciona tudo |

## Alterar células

| Teclas | O que fazem |
| --- | --- |
| Qualquer carácter | Inicia uma entrada na célula ativa, substituindo o que ela contém |
| F2 | Edita o conteúdo da célula ativa, na própria célula; ao escrever uma fórmula, alterna entre apontar para células e editar o texto |
| F4 | Ao escrever uma fórmula, fixa partes do endereço no cursor com $ (A1, $A$1, A$1, $A1) |
| Enter, Shift+Enter | Confirmam a entrada e descem ou sobem |
| Tab, Shift+Tab | Confirmam a entrada e avançam para a direita ou para a esquerda |
| Esc | Cancela a entrada |
| Alt+Enter | Inicia uma nova linha na célula |
| Delete | Limpa as células selecionadas |
| {key:Undo}, {key:Redo} | Anular, refazer |
| {key:Save} | Guardar |
| {key:Cut}, {key:Copy}, {key:Paste} | Cortar, copiar, colar (Esc remove o contorno das células copiadas) |
| Ctrl+Alt+V | Colar Especial |
| Ctrl e a tecla de adição, Ctrl e a tecla de subtração | Inserem ou eliminam (linhas ou colunas, se estiverem selecionadas inteiras) |
| Ctrl+D, Ctrl+R | Preencher para baixo, preencher para a direita |
| Ctrl+E | Preenchimento Relâmpago |
| Alt e a tecla de igual | Soma |
| Ctrl+0, Ctrl+9 | Ocultam as colunas, ocultam as linhas |
| Alt+Seta para baixo | Abre a lista de uma célula que tenha uma |
| {key:Find} | Localizar |
| Ctrl+H (num Mac, Opção+Comando+F) | Localizar e substituir |
| F5, Ctrl+G | Vai para uma célula, um intervalo ou um nome |
| Ctrl+Shift+L | Ativa ou desativa o filtro |
| Shift+F3 | Escolhe uma função |
| Ctrl+F3 | A lista de nomes |
| F9, Shift+F9 | Recalcula tudo, recalcula esta folha |
| Tab, Enter | Ao escrever uma fórmula: escolhem a função ou o nome marcado na lista |
| Esc | Interrompe uma pesquisa, uma ordenação ou um filtro em curso |

## Teclas de acesso

Prima **Alt** para ver uma letra em cada separador do friso e em cada comando; depois prima as letras. Prima **Alt** e, a seguir, **F**, para abrir o ecrã Ficheiro. Prima **Esc** para voltar atrás.
