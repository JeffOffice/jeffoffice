# Utilizar o JeffCrunch com o teclado
<!-- keywords: teclado, atalhos, teclas, teclas de atalho, seta, ctrl, shift, home, end, page up, page down, tabulação, tab, enter, selecionar tudo, copiar, F9, F1, zoom, teclas de acesso, sugestões de teclas -->

O separador **Ajuda** tem **Ajuda** (F1), **Atalhos de Teclado**, que abre esta página, **Novidades** e **Feedback**, que abrem as respetivas páginas Web.

No Mac, a tecla **Command** (⌘) faz o que o **Ctrl** faz nas tabelas abaixo, exceto quando uma tabela indique o contrário.

## Mover e selecionar

| Teclas | O que fazem |
| --- | --- |
| Teclas de seta | Move a célula ativa uma célula, saltando as linhas e colunas ocultas |
| Shift+seta | Estende a seleção uma célula |
| Ctrl+seta | Vai até à extremidade dos dados (Esc interrompe uma pesquisa longa) |
| Ctrl+Shift+seta | Estende a seleção até à extremidade dos dados |
| Home | Vai para a primeira coluna da linha |
| Ctrl+Home | Vai para a primeira célula (A1, ou para a primeira célula que se desloca quando as linhas ou colunas estão fixas) |
| Ctrl+End | Vai para a última célula que contém algo ou tem formatação |
| Page Down, Page Up | Desloca-se um ecrã para baixo ou para cima |
| Tab, Shift+Tab | Move para a direita ou para a esquerda (pelas células selecionadas, se houver várias) |
| Enter, Shift+Enter | Move para baixo ou para cima (pelas células selecionadas, se houver várias) |
| Ctrl+Espaço | Seleciona a coluna inteira |
| Shift+Espaço | Seleciona a linha inteira |
| {key:SelectAll} | Seleciona tudo |

## Alterar células

| Teclas | O que fazem |
| --- | --- |
| Qualquer carácter | Inicia uma entrada na célula ativa, substituindo o que ela contém |
| F2 | Edita o conteúdo da célula ativa, na própria célula; ao escrever uma fórmula, alterna entre apontar para células e editar o texto |
| F4 | Ao escrever uma fórmula, fixa partes do endereço no cursor com $ (A1, $A$1, A$1, $A1) |
| Enter, Shift+Enter | Confirma a entrada e move para baixo ou para cima |
| Tab, Shift+Tab | Confirma a entrada e move para a direita ou para a esquerda |
| Esc | Cancela a entrada |
| Alt+Enter | Inicia uma nova linha na célula |
| Delete | Limpa as células selecionadas |
| {key:Undo}, {key:Redo} | Anular, refazer |
| {key:Save} | Guardar |
| {key:Cut}, {key:Copy}, {key:Paste} | Cortar, copiar, colar (Esc remove o contorno animado das células copiadas) |
| Ctrl+Alt+V | Colar Especial |
| Ctrl e a tecla de mais, Ctrl e a tecla de menos | Inserir, eliminar (linhas ou colunas, se forem selecionadas inteiras) |
| Ctrl+D, Ctrl+R | Preencher para baixo, preencher para a direita |
| Ctrl+E | Preenchimento Relâmpago |
| Alt e a tecla de igual | Soma |
| Ctrl+0, Ctrl+9 | Oculta as colunas, oculta as linhas |
| Alt+Seta para baixo | Abre a lista de uma célula que tenha uma |
| {key:Find} | Localizar |
| Ctrl+H (no Mac, Option+Command+F) | Localizar e substituir |
| F5, Ctrl+G | Ir para uma célula, um intervalo ou um nome |
| Ctrl+Shift+L | Ativa ou desativa o filtro |
| Shift+F3 | Escolher uma função |
| Ctrl+F3 | A lista de nomes |
| F9, Shift+F9 | Recalcular tudo, recalcular esta folha |
| Tab, Enter | Ao escrever uma fórmula: aceita a função ou o nome assinalado na lista |
| Esc | Interrompe uma pesquisa, uma ordenação ou um filtro em curso |

## Teclas de acesso

Prima **Alt** para ver uma letra em cada separador e comando do friso, e depois prima as letras. Prima **Alt** e depois **F** para abrir o ecrã Ficheiro. Prima **Esc** para voltar atrás.
