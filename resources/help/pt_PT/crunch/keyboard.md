# Utilizar o JeffCrunch com o teclado
<!-- keywords: teclado, atalhos, atalhos de teclado, teclas, teclas de atalho, seta, ctrl, shift, home, end, page up, page down, tab, enter, selecionar tudo, copiar, F9, F1, zoom, teclas de acesso, sugestões de teclas -->

Num Mac, a tecla **Command** (⌘) faz o mesmo que a tecla **Ctrl** nas tabelas abaixo, exceto quando a tabela indicar o contrário.

## Mover e selecionar

| Teclas | O que fazem |
| --- | --- |
| Teclas de seta | Mover a célula ativa uma célula, ignorando as linhas e colunas ocultas |
| Shift+seta | Expandir a seleção uma célula |
| Ctrl+seta | Ir para o limite dos dados (Esc interrompe uma procura demorada) |
| Ctrl+Shift+seta | Expandir a seleção até ao limite dos dados |
| Home | Ir para a primeira coluna da linha |
| Ctrl+Home | Ir para a primeira célula (A1, ou a primeira célula que se desloca quando há linhas ou colunas fixas) |
| Ctrl+End | Ir para a última célula que tem conteúdo ou formatação |
| Page Down, Page Up | Descer ou subir um ecrã |
| Tab, Shift+Tab | Mover para a direita ou para a esquerda (pelas células selecionadas, se houver várias) |
| Enter, Shift+Enter | Mover para baixo ou para cima (pelas células selecionadas, se houver várias) |
| Ctrl+Espaço | Selecionar a coluna inteira |
| Shift+Espaço | Selecionar a linha inteira |
| {key:SelectAll} | Selecionar tudo |

## Alterar células

| Teclas | O que fazem |
| --- | --- |
| Qualquer carácter | Iniciar uma entrada na célula ativa, substituindo o seu conteúdo |
| F2 | Editar o conteúdo da célula ativa, na própria célula |
| Enter, Shift+Enter | Manter a entrada e mover para baixo ou para cima |
| Tab, Shift+Tab | Manter a entrada e mover para a direita ou para a esquerda |
| Esc | Cancelar a entrada |
| Alt+Enter | Iniciar uma nova linha na célula |
| Delete | Limpar as células selecionadas |
| {key:Undo}, {key:Redo} | Anular, refazer |
| {key:Save} | Guardar |
| {key:Cut}, {key:Copy}, {key:Paste} | Cortar, copiar, colar (Esc remove o limite das células copiadas) |
| Ctrl+Alt+V | Colar Especial |
| Ctrl e a tecla de mais, Ctrl e a tecla de menos | Inserir, eliminar (linhas ou colunas, se estiverem selecionadas linhas ou colunas inteiras) |
| Ctrl+D, Ctrl+R | Preencher para baixo, preencher para a direita |
| Alt e o sinal de igual | Soma Automática |
| Ctrl+0, Ctrl+9 | Ocultar as colunas, ocultar as linhas |
| Alt+Seta para baixo | Abrir a lista de uma célula que tenha uma |
| {key:Find} | Localizar |
| Ctrl+H (num Mac, Option+Command+F) | Localizar e Substituir |
| F5, Ctrl+G | Ir para uma célula, um intervalo ou um nome |
| Ctrl+Shift+L | Ativar ou desativar o filtro |
| Shift+F3 | Escolher uma função |
| Ctrl+F3 | A lista de nomes |
| F9, Shift+F9 | Recalcular Tudo, Recalcular Esta Folha |
| Tab, Enter | Ao escrever uma fórmula: aceitar a função ou o nome realçado na lista |
| Esc | Interromper uma procura, uma ordenação ou um filtro em curso |

## Teclas de acesso

Prima **Alt** para ver uma letra em cada separador do friso e em cada comando e, em seguida, prima as letras. Prima **Alt** e, depois, **F** para abrir o ecrã Ficheiro. Prima **Esc** para recuar.
