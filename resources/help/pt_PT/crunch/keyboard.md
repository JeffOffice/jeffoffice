O separador **Base** tem **Ajuda** (F1), **Atalhos de Teclado**, que abre esta página, **Novidades** e **Comentários**, que abrem as respetivas páginas Web.

Num Mac, a tecla **Command** (⌘) faz o que **Ctrl** faz nas tabelas abaixo, exceto quando uma tabela indicar o contrário.

## Deslocar-se e selecionar

| Teclas | O que fazem |
| --- | --- |
| Teclas de seta | Deslocam a célula ativa uma célula, ignorando linhas e colunas ocultas |
| Shift+seta | Alarga a seleção uma célula |
| Ctrl+seta | Vai para a extremidade dos dados (Esc interrompe uma pesquisa longa) |
| Ctrl+Shift+seta | Alarga a seleção até à extremidade dos dados |
| Home | Vai para a primeira coluna da linha |
| Ctrl+Home | Vai para a primeira célula (A1, ou a primeira célula que se desloca quando as linhas ou colunas estão fixas) |
| Ctrl+End | Vai para a última célula que tem conteúdo ou formatação |
| Page Down, Page Up | Desloca para baixo ou para cima um ecrã |
| Tab, Shift+Tab | Desloca para a direita ou para a esquerda (pelas células selecionadas, se houver várias) |
| Enter, Shift+Enter | Desloca para baixo ou para cima (pelas células selecionadas, se houver várias) |
| Ctrl+Espaço | Seleciona a coluna inteira |
| Shift+Espaço | Seleciona a linha inteira |
| {key:SelectAll} | Seleciona tudo |

| Qualquer carácter | Inicia uma entrada na célula ativa, substituindo o que ela contém |

| F4 | Ao escrever uma fórmula, fixa partes do endereço na posição do cursor com $ (A1, $A$1, A$1, $A1) |
| Enter, Shift+Enter | Confirma a entrada e desloca para baixo ou para cima |
| Tab, Shift+Tab | Confirma a entrada e desloca para a direita ou para a esquerda |
| Esc | Cancela a entrada |
| Alt+Enter | Inicia uma nova linha na célula |
| Delete | Elimina o conteúdo das células selecionadas |
| {key:Undo}, {key:Redo} | Anular, refazer |
| {key:Save} | Guardar |
| {key:Cut}, {key:Copy}, {key:Paste} | Cortar, copiar, colar (Esc remove o contorno das células copiadas) |
| Ctrl+Alt+V | Colar Especial |
| Ctrl e a tecla de mais, Ctrl e a tecla de menos | Inserir, eliminar (linhas ou colunas, se estiverem selecionadas inteiras) |
| Ctrl+D, Ctrl+R | Preencher para baixo, preencher para a direita |
| Ctrl+E | Preenchimento Relâmpago |
| Alt e o sinal de igual | Soma |
| Ctrl+0, Ctrl+9 | Oculta as colunas, oculta as linhas |
| Alt+Seta para baixo | Abre a lista de uma célula que tenha uma |
| {key:Find} | Localizar |
| Ctrl+H (num Mac, Option+Command+F) | Localizar e Substituir |
| F5, Ctrl+G | Ir para uma célula, um intervalo ou um nome |
| Ctrl+Shift+L | Ativa ou desativa o filtro |
| Shift+F3 | Escolher uma função |
| Ctrl+F3 | A lista de nomes |
| F9, Shift+F9 | Recalcular tudo, recalcular esta folha |

| Esc | Interrompe uma pesquisa, uma ordenação ou um filtro em curso |

## Escolher as suas próprias teclas de atalho

Pode alterar as teclas de qualquer comando ou atribuir uma tecla a um comando que não tenha nenhuma. Clique em **Ficheiro > Opções** e, depois, no separador **Personalizar**.

1. Escreva na caixa **Pesquisar** para encontrar um comando pelo nome ou pelas teclas. A lista está agrupada pelos separadores do friso, e cada comando mostra as suas teclas. Os comandos que não estão no friso aparecem em **Outros**.
2. Clique no comando. As suas teclas aparecem em **Teclas para este comando**.
3. Clique na caixa **Prima as novas teclas** e prima as teclas que pretende, como **Ctrl+Shift+B**. Depois, clique em **Atribuir**. Um comando pode ter até quatro teclas.
4. Para retirar uma tecla, clique nela na lista e clique em **Remover**.

Se outro comando já tiver as teclas premidas, o JeffCrunch indica qual é. Clique em **Reatribuir** para atribuir as teclas a este comando, e o outro comando deixa de as ter. Nada muda até clicar em **OK**. Depois, todas as janelas abertas do JeffCrunch usam as suas teclas, e também todas as janelas que abrir mais tarde. As sugestões, os menus e a tabela de atalhos abaixo mostram as suas teclas.

Um símbolo também pode ter teclas. Consulte **Inserir um símbolo** em [Escrever nas células](edit-cells): clique em **Tecla de Atalho** na caixa Símbolo. Depois, ele aparece nesta lista como qualquer outro comando.

**Repor Um** repõe as teclas habituais do comando escolhido. **Repor Tudo** repõe as teclas habituais de todos os comandos. O JeffCrunch guarda apenas os comandos cujas teclas alterou, pelo que um comando que não alterou recebe as teclas melhores que uma versão posterior lhe atribua.

Algumas teclas não podem ser atribuídas a um comando, porque o sistema ou a escrita as necessitam. O JeffCrunch indica **reservada** quando prime uma delas. As teclas reservadas são **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z**, **Ctrl+A**, **Tab**, **Shift+Tab**, **Enter**, **Esc**, **Retrocesso**, **Delete**, **Alt+F4**, as teclas de seta, **Home**, **End**, **Page Up**, **Page Down** e **Espaço**, **F1**, **F6**, **Shift+F6**, **Ctrl+Y**, **Ctrl+Shift+Z**, **Ctrl** com uma seta, **Home**, **End**, **Retrocesso** ou **Delete** (com ou sem **Shift**, onde isso faça sentido numa caixa de texto), e uma tecla de letra, algarismo ou símbolo premida sozinha ou com **Shift**. Uma tecla que outra parte da janela já utilize também fica reservada. **Guardar**, **Anular** e **Refazer** mantêm sempre pelo menos uma tecla. Num Mac, **Ctrl** aqui significa a tecla **Command**.

## Teclas de acesso

Prima **Alt** para ver uma letra em cada separador e comando do friso e, depois, prima as letras. Prima **Alt** e, depois, **F**, para aceder ao ecrã Ficheiro. Prima **Esc** para voltar atrás.
