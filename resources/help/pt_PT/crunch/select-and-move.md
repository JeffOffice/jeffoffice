# Selecionar células e deslocar-se
<!-- keywords: selecionar, seleção, célula, intervalo, linha, coluna, clicar, arrastar, shift, ctrl, seta, home, end, page up, page down, tabulação, enter, linha inteira, coluna inteira, caixa de nome, ir para, deslocar, percorrer, barra de estado, soma, média, contagem, contar -->

**Selecionar** células significa escolher aquelas às quais o comando seguinte se aplica. As células selecionadas ficam sombreadas, com um limite verde à volta. A **célula ativa** é a que tem o cursor e mantém-se branca dentro da seleção.

## Com o rato

- **Clique** numa célula para a selecionar. Clique dentro de uma célula unida para selecionar toda a célula unida.
- **Arraste** sobre as células para selecionar um bloco. Se arrastar para além do limite da janela, a folha desloca-se.
- Faça **Shift+clique** noutra célula para selecionar desde a célula ativa até essa.
- Clique numa **letra de coluna** ou num **número de linha** para selecionar a coluna ou a linha inteira. Arraste sobre as letras ou os números, ou faça Shift+clique, para selecionar várias.
- Clique no **canto** onde as letras e os números se encontram para selecionar tudo.
- Rode a **roda do rato** para deslocar três linhas. Mantenha premida a tecla **Shift** para deslocar na horizontal ou a tecla **Ctrl** para fazer zoom.

## Com o teclado

As teclas de seta movem a célula ativa, ignorando as linhas e colunas ocultas. Mantenha premida a tecla **Shift** para expandir a seleção. **Ctrl** com uma seta vai até ao limite dos dados: até ao fim de uma sequência de células com conteúdo ou, a partir do fim de uma sequência, até à célula seguinte com conteúdo. Consulte [Utilizar o JeffCrunch com o teclado](keyboard) para conhecer todas as teclas.

## Ir para uma célula

Escreva um endereço na **Caixa de nome**, como **C5**, **A1:D10**, **B:D** ou **3:7**, e prima **Enter**.

## Os números da seleção

Quando seleciona duas ou mais células, a barra de estado mostra a **média**, a **contagem** e a **soma** das células. A contagem é o número de células com conteúdo; a média e a soma utilizam apenas os números. As linhas e colunas ocultas são excluídas. Para copiar a seleção como texto, prima **Ctrl+C**.
