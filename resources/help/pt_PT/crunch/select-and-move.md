# Seleccionar células e deslocar-se

<!-- keywords: selecionar, seleção, célula, intervalo, linha, coluna, clicar, arrastar, shift, ctrl, seta, home, end, page up, page down, tabulação, enter, linha inteira, coluna inteira, caixa de nome, ir para, mover células, arrastar limite, deslocar, barra de estado, soma, média, contar -->

**Selecionar** células significa escolher as que o comando seguinte vai afetar. As células selecionadas ficam com uma cor de fundo e uma moldura verde à sua volta. A **célula ativa** é aquela onde está o cursor, e mantém-se branca dentro da seleção.

## Com o rato

- **Clique** numa célula para a selecionar. Clique dentro de uma célula unida para selecionar a célula unida inteira.
- **Arraste** sobre células para selecionar um bloco. Se arrastar para além da margem da janela, a folha desloca-se.
- **Shift+clique** noutra célula para selecionar desde a célula ativa até essa.
- Clique numa **letra de coluna** ou num **número de linha** para selecionar a coluna ou a linha inteira. Arraste sobre as letras ou os números, ou use Shift+clique, para selecionar várias.
- Clique no **canto** onde se encontram as letras e os números para selecionar tudo.
- **Arraste o limite** da seleção para mover as células para outro local. Aponte para a margem da moldura verde até o ponteiro mostrar quatro setas. Um contorno tracejado mostra onde as células vão ficar. Tudo o que aponte para as células, como uma fórmula, acompanha-as. Mantenha **Ctrl** premido enquanto arrasta para copiar as células. Se apenas clicar no limite sem mover, a célula é selecionada normalmente.
- Rode a **roda do rato** para deslocar três linhas. Mantenha **Shift** premido para deslocar na horizontal, ou **Ctrl** para aplicar zoom.

## Com o teclado

As teclas de seta movem a célula ativa, ignorando as linhas e colunas ocultas. Mantenha **Shift** premido para alargar a seleção. **Ctrl** com uma seta vai até à extremidade dos dados: até ao fim de uma sequência de células com conteúdo ou, a partir do fim de uma sequência, até à célula seguinte com conteúdo. Consulte [Utilizar o JeffCrunch com o teclado](keyboard) para ver todas as teclas.

## Ir para uma célula

Escreva um endereço na **Caixa de nome**, como **C5**, **A1:D10**, **B:D** ou **3:7**, e prima **Enter**.

## Os números da seleção

Quando seleciona duas ou mais células, a barra de estado mostra a **média**, a **contagem** e a **soma** das células. A contagem é o número de células que têm conteúdo; a média e a soma usam apenas os números. As linhas e colunas ocultas são excluídas. Para copiar a seleção como texto, prima **Ctrl+C**.
