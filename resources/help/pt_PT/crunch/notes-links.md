## Notas

Uma **nota** é um pequeno texto guardado com uma célula. Uma célula que tenha uma nota mostra uma pequena marca vermelha no canto superior direito. Coloque o ponteiro sobre a célula e a nota aparece ao lado; afaste o ponteiro e a nota desaparece.

Para colocar uma nota numa célula, selecione-a e utilize **Rever > Nova Nota** (ou prima **Shift+F2**). Escreva o texto e clique em **OK**. Numa célula que já tenha uma nota, o mesmo comando chama-se **Editar Nota**. Se apagar todo o texto, a nota é removida.

- **Eliminar Nota** remove as notas das células selecionadas.
- **Mostrar ou Ocultar Nota** mantém a nota das células selecionadas sempre visível na folha, numa caixa ao lado de cada célula, ou volta a ocultá-la.
- **Mostrar Todas as Notas** faz o mesmo para todas as notas da folha; o mesmo botão passa então a chamar-se **Ocultar Todas as Notas**.
- **Nota Anterior** e **Nota Seguinte** permitem passar de uma célula com nota para a seguinte.

Cada uma destas ações é um passo que pode anular. Uma nota acompanha a respetiva célula quando são inseridas ou eliminadas linhas ou colunas e quando as células são ordenadas. **Limpar Tudo** remove as notas das células que limpa.

Um livro pode conter uma conversa de comentários, com respostas. O JeffCrunch mostra a conversa completa como uma nota e mantém-na quando guarda o livro, mas não a altera: a nota é só de leitura.

As notas podem ser guardadas num livro .xlsx. Um livro aberto a partir de um tipo de ficheiro mais antigo, ou de um ficheiro de texto, só mantém as notas depois de o guardar como livro .xlsx.

## Ligações

Uma **ligação** leva-o a outro local quando a segue: a uma página web, a um ficheiro, a um endereço de correio eletrónico ou a um local neste livro (uma célula, várias células ou um nome).

Para colocar uma ligação numa célula, selecione-a e utilize **Inserir > Ligação** (ou prima **Ctrl+K**). Escolha o destino, escreva o endereço ou o local e, se quiser, o texto que a célula deve mostrar e uma **descrição**. Numa célula que já tenha uma ligação, o mesmo comando chama-se **Editar Ligação**. **Remover Ligação** remove as ligações das células selecionadas.

Coloque o ponteiro sobre uma célula com uma ligação para ver o respetivo destino. Para seguir a ligação, mantenha premida a tecla **Ctrl** e clique na célula, ou selecione a célula e utilize **Abrir Ligação** no menu de contexto. Um clique simples apenas seleciona a célula.

O JeffCrunch nunca abre nada por iniciativa própria. Uma página web ou um endereço de correio eletrónico abre no programa habitual quando segue a respetiva ligação. Uma ligação para um ficheiro, ou para outro tipo de endereço, pede-lhe confirmação primeiro. Uma ligação que executaria um script nunca é aberta.

Uma ligação acompanha a respetiva célula quando são inseridas ou eliminadas linhas ou colunas e quando as células são ordenadas, e é guardada com o livro.
