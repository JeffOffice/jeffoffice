## Notas

Uma **nota** é um conjunto de palavras associado a uma célula. Uma célula que tenha uma nota mostra uma pequena marca vermelha no canto superior direito. Quando poisa o ponteiro sobre a célula, a nota aparece ao lado; quando afasta o ponteiro, desaparece.

Para colocar uma nota numa célula, selecione-a e utilize **Revisão > Nova Nota** (ou prima **Shift+F2**). Escreva as palavras e clique em **OK**. Numa célula que já tenha uma nota, o mesmo comando aparece como **Editar Nota**. Se apagar as palavras, a nota é removida.

- **Eliminar Nota** remove as notas das células selecionadas.
- **Mostrar ou Ocultar Nota** mantém a nota das células selecionadas sempre visível na folha, numa caixa ao lado de cada célula, ou volta a ocultá-la.
- **Mostrar Todas as Notas** faz o mesmo para todas as notas da folha; o mesmo botão passa a chamar-se **Ocultar Todas as Notas**.
- **Nota Anterior** e **Nota Seguinte** deslocam-se de uma célula com nota para a seguinte.

Cada uma destas ações pode ser anulada com um único passo. Uma nota acompanha a sua célula quando são inseridas ou eliminadas linhas ou colunas, e quando as células são ordenadas. **Limpar Tudo** remove as notas das células que limpa.

Um livro pode conter uma conversa de comentários, com respostas. O JeffCrunch mostra a conversa completa como uma nota e mantém-na ao guardar, mas não a altera: a nota é só de leitura.

As notas podem ser guardadas num livro .xlsx. Um livro aberto a partir de um tipo de ficheiro mais antigo, ou de um ficheiro de texto, só mantém as notas depois de o guardar como livro .xlsx.

## Ligações

Uma **ligação** leva-o a outro local quando a segue: a uma página web, a um ficheiro, a um endereço de correio eletrónico ou a um local neste livro (uma célula, células ou um nome).

Para colocar uma ligação numa célula, selecione-a e utilize **Inserir > Ligação** (ou prima **Ctrl+K**). Escolha o destino, escreva o endereço ou o local e, se quiser, as palavras que a célula deve mostrar e uma **sugestão de ecrã**. Numa célula que já tenha uma ligação, o mesmo comando aparece como **Editar Ligação**. **Remover Ligação** remove as ligações das células selecionadas.

Poise o ponteiro sobre uma célula com ligação para ver para onde leva. Para a seguir, mantenha **Ctrl** premido e clique na célula, ou selecione a célula e utilize **Abrir Ligação** no menu do botão direito. Um clique simples apenas seleciona a célula.

O JeffCrunch nunca abre nada por iniciativa própria. Uma página web ou um endereço de correio eletrónico abre-se no seu programa habitual quando segue a ligação. Uma ligação a um ficheiro, ou a outro tipo de endereço, pede-lhe primeiro confirmação. Uma ligação que executaria um script nunca é aberta.

Uma ligação acompanha a sua célula quando são inseridas ou eliminadas linhas ou colunas, e quando as células são ordenadas, e é guardada com o livro.

## Estatísticas do Livro

**Estatísticas do Livro** (separador **Revisão**) conta o que o livro contém: quantas **Folhas** tem, quantas **Células com dados** (células que contêm um número, texto ou uma fórmula), quantas **Fórmulas**, quantos **Gráficos** e quantas **Tabelas dinâmicas**. As folhas que eliminou não são contadas. Os mesmos números aparecem na página **Informações** do separador Ficheiro.

## Verificar Acessibilidade

**Verificar Acessibilidade** (separador **Revisão**) abre uma pequena janela que lista o que, no livro, é difícil de usar para alguns leitores, ou para um leitor de ecrã (um programa que lê o ecrã em voz alta). Cada linha começa por **Erro**, **Aviso** ou **Sugestão**. Clique numa linha para ir até à célula.

Procura:

- Um gráfico ou uma imagem sem **texto alternativo** (as palavras que descrevem o que mostra). Isto é um erro.
- Uma tabela sem linha de cabeçalho, pelo que as suas colunas não têm nomes. Isto é um erro.
- **Células unidas**, que são difíceis de percorrer com o teclado. Isto é um aviso.
- Uma folha que ainda tem o nome que lhe foi dado, como Folha1. Isto é uma sugestão.

Prima **Verificar Novamente** depois de fazer alterações.
