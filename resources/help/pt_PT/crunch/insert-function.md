# Escolher uma função
<!-- keywords: função, escolher uma função, fx, fórmula, argumento, categoria, pesquisar, todas as funções, Soma, Shift+F3, procurar -->

Escolha **Escolher uma Função** no separador **Fórmulas** (**Shift+F3**), ou **Todas as Funções** no menu **Soma**.

Escreva na caixa de pesquisa um nome ou o que pretende fazer ("arredondar para baixo", "juntar texto"), e a lista mostra as funções correspondentes, com os nomes que começam pelas suas palavras à frente. **Tipo** limita a lista às funções financeiras, de data e hora, de matemática e trigonometria, estatísticas, de pesquisa e referência, de texto, lógicas, de informação, de base de dados ou de engenharia.

Escolha uma função para ver como se escreve, o que faz e quais são os seus argumentos. Um argumento entre parênteses retos é opcional, e "mais do mesmo" significa que pode indicar tantos quantos precisar. Prima **OK** (ou faça duplo clique na função).

Depois de premir **OK**, abre-se a caixa de diálogo **Argumentos de Função** para a função, para preencher os respetivos argumentos com o resultado apresentado à medida que escreve (veja [Introduzir uma função com a caixa de diálogo Argumentos de Função](function-arguments)). Premir **OK** aí escreve a fórmula na célula, por exemplo **=SOMA(A1:A3)**. Se já estiver a escrever uma fórmula, a função é inserida no cursor. Só são listadas as funções que o JeffCrunch consegue calcular.

## Mensagens nas células

Uma célula que tenha uma regra para os dados que podem ser introduzidos também pode ter uma mensagem (um título e uma frase). Esta mensagem aparece ao lado da célula enquanto a célula estiver selecionada. As listas que leem células de outra folha também funcionam.
