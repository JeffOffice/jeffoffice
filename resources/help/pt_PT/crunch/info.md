# Informações: propriedades, palavras-passe e Inspecionar

Clique em **Ficheiro > Informações** para ver os dados do seu livro e para o proteger antes de o partilhar. Prima **Esc** para voltar ao livro.

## Onde está o ficheiro

No topo, a página mostra onde o ficheiro está guardado. Clique em **Mostrar na Pasta** para abrir essa pasta. Clique em **Copiar Caminho** para copiar o caminho, de modo a poder colá-lo num correio eletrónico ou numa conversa.

## Propriedades

As propriedades são dados sobre o livro, como o seu título e quem o escreveu. A página tem uma caixa para cada uma: **Título**, **Autor**, **Assunto**, **Palavras-chave**, **Categorias**, **Comentários**, **Empresa** e **Gestor**. Escreva numa caixa e prima **Tab** ou **Enter**. O JeffCrunch guarda a alteração e grava-a no ficheiro da próxima vez que guardar o livro. A página mostra também quando o livro foi criado, guardado e impresso.

Clique em **Propriedades Personalizadas** para criar propriedades suas, como **Projeto** ou **Cliente**. Clique em **Adicionar**, escreva um nome, escolha o tipo de valor (texto, um número inteiro, um número, sim ou não, ou uma data) e escreva o valor. O JeffCrunch guarda-as tal como as escreveu.

## Marcar como Final

Clique em **Marcar como Final** para indicar aos leitores que o livro está concluído. O JeffCrunch guarda o livro e depois abre-o apenas para leitura. Quando alguém o abrir, a barra de título indica que é só de leitura. Esta é uma forma suave de dizer "por favor, não altere isto". Não é um bloqueio, porque qualquer pessoa pode escolher **Marcado como Final** novamente para o editar.

## Cifrar com Palavra-passe

Clique em **Cifrar com Palavra-passe** para pedir uma palavra-passe sempre que o ficheiro for aberto. Isto é o mesmo que **Proteger com Palavra-passe**. Veja [Abrir livros protegidos por palavra-passe](open-password). Uma palavra-passe protege um ficheiro **.xlsx** com uma proteção forte. Se se esquecer de uma palavra-passe, ela **não pode ser recuperada**.

Para impedir alterações a uma folha ou ao respetivo esquema, veja [Proteger uma folha ou o livro](protect).

## Inspecionar Livro

Clique em **Inspecionar Livro** antes de enviar um livro a alguém. A ferramenta indica o que o ficheiro contém e que poderá não querer partilhar, e quantos itens de cada tipo encontrou:

- **Notas** são notas que as pessoas deixaram nas células. **Remover Tudo** elimina-as.
- **Propriedades do documento e informações pessoais** são o autor, a pessoa que guardou o livro pela última vez, a empresa e o gestor. **Remover Tudo** limpa-os.
- **Folhas ocultas** são folhas que não aparecem como separadores. **Mostrar Tudo** mostra-as, para que veja o que contêm, e pode eliminar as que não quer.
- **Ligações externas** são ligações a valores de outros livros. Esta lista apenas as contabiliza. Para as quebrar, use o separador **Dados**.
- **Dados XML personalizados** são dados que outros programas acrescentaram ao ficheiro. Esta lista apenas os contabiliza.

Guarde o livro depois, para manter a cópia limpa.
