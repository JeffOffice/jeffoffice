# Criar uma tabela de autoridades
<!-- keywords: tabela de autoridades, autoridades, citação, marcar citação, jurisprudência, legislação, regra, regulamento, tratado, passim, peça processual, TA, TOA, Alt+Shift+I, categoria -->

Uma **tabela de autoridades** é uma lista que uma peça processual pode ter: a jurisprudência, as leis e outras obras que a peça cita, com as páginas em que são citadas. Primeiro **marca** cada citação e, depois, **insere** a tabela.

## Marcar uma citação

1. Selecione a citação no texto, como o nome de um processo com os respetivos números.
2. Clique em **Referências > Marcar Citação**, ou prima **Alt+Shift+I**.
3. Marque a **Citação longa**. É isto que a tabela mostra. Escreva uma **Citação curta** se usar uma forma mais curta mais adiante no texto.
4. Escolha uma **Categoria**: Jurisprudência, Legislação, Outras Autoridades, Regras, Tratados, Regulamentos ou Disposições Constitucionais. Existem mais nove categorias numeradas para uso próprio.
5. Clique em **OK**.

Marque cada passagem que cita a autoridade. A tabela indica a autoridade apenas uma vez, com todas as páginas.

## Inserir a tabela

1. Clique no local onde a tabela deve ficar.
2. Clique em **Referências > Tabela de Autoridades**.
3. Escolha uma categoria, ou **Todas** para listar todas as categorias que têm marcas. Escolha o carácter de preenchimento, se quer usar **passim**, e se quer colocar o nome da categoria acima das respetivas citações.
4. Clique em **OK**.

**Passim** é uma palavra latina que significa "aqui e ali". Quando uma autoridade é citada em cinco ou mais páginas, a tabela mostra esta palavra em vez de uma lista longa de números.

## Manter a tabela atualizada

Clique na tabela e clique em **Atualizar Autoridades** (no grupo **Tabela de Autoridades** do separador **Referências**), ou prima **F9**.
