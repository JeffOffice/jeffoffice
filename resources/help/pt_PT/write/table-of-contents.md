# Índice
<!-- keywords: índice, sumário, conteúdo, tabela de conteúdo, títulos, atualizar índice, remover índice, números de página, carácter de preenchimento, hiperligações, F9 -->

Um **índice** lista os títulos com a página em que cada um se encontra. O JeffWrite cria-o a partir dos parágrafos que utilizam os estilos de título.

## Inserir um índice

1. Aplique aos títulos os estilos **Título 1**, **Título 2** e assim sucessivamente.
2. Clique no local onde pretende colocar o índice.
3. Clique em **Referências > Índice**.
4. Escolha quantos níveis pretende mostrar, se os números de página são mostrados e alinhados à direita, os pontos ou linhas antes deles (o **carácter de preenchimento**) e se cada linha é uma ligação. Clique em **OK**.

Por exemplo, com os níveis definidos como 2, um documento com os títulos `Introdução` (Título 1) e `Contexto` (Título 2) obtém duas linhas, cada uma com o respetivo número de página, e a segunda com um avanço um pouco maior.

## Atualizar o índice

Clique dentro do índice e prima **F9** ou clique em **Referências > Atualizar Índice**. Escolha:

- **Atualizar apenas os números de página** se não alterou nenhum título.
- **Atualizar todo o índice** se adicionou, removeu ou mudou o nome de títulos.

A atualização é um único passo que pode ser revertido com **Anular**.

## Um índice muito longo

Um índice pode ter até 20 000 linhas. Se o documento tiver mais títulos do que isso, o índice termina aí e o JeffWrite informa-o quando cria ou atualiza o índice.

## Remover o índice

Clique dentro do índice e clique em **Referências > Remover Índice**.

## Seguir uma linha

Se as linhas forem ligações, mantenha premida a tecla **Ctrl** e clique numa delas para ir para o respetivo título.

## Alterar o aspeto das linhas

As linhas utilizam os estilos **Índice 1** a **Índice 9**. Altere um deles no painel Estilos e, em seguida, atualize todo o índice.
