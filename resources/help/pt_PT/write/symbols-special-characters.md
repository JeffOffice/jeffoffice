# Inserir símbolos e carateres especiais

Um **símbolo** é um carácter que não está no teclado, como a letra grega ómega ou uma seta. Um **carácter especial** é um carácter que a página trata de uma forma particular, como um espaço que nunca se parte entre duas linhas.

## Símbolos

1. Coloque o cursor onde o símbolo deve ficar.
2. Escolha **Inserir > Símbolo**. Uma caixa pequena mostra os símbolos que usou por último. Clique num para o inserir.
3. Para qualquer outro símbolo, escolha **Mais Símbolos**. Escolha um **Tipo de letra** e um **Subconjunto** (um bloco de carateres relacionados, como Setas). Faça duplo clique num símbolo, ou clique nele e escolha **Inserir**.

A janela fica aberta para poder inserir mais do que um. A caixa mostra o **código do carácter** do símbolo em que clicar. O símbolo fica no tipo de letra que escolher. A opção **(texto normal)** mantém o tipo de letra do próprio texto.

## Carateres especiais

Escolha **Inserir > Carateres Especiais** e, em seguida, uma das opções seguintes.

- **Espaço Não Separável** (Ctrl+Shift+Espaço) é um espaço que mantém duas palavras na mesma linha.
- **Hífen Não Separável** (Ctrl+Shift+Hífen) é um hífen que nunca deixa uma palavra dividir-se nesse ponto.
- **Hífen Opcional** (Ctrl+Hífen) é um hífen que só aparece se a palavra for dividida nesse ponto no fim de uma linha.
- **Meia-Risca** e **Travessão** são traços. A meia-risca tem a largura da letra n. O travessão tem a largura da letra m.
- **Espaço Curto** e **Espaço Longo** são espaços com a largura dessas letras.
- As quatro **aspas** são do tipo curvo, de abertura e de fecho, duplas e simples.
- **Quebra de Linha** (Shift+Enter) inicia uma nova linha sem iniciar um novo parágrafo.
- **Quebra Opcional de Largura Zero** é um sítio onde a linha pode partir-se, sem nada visível.
- **Não Quebra de Largura Zero** é algo invisível que mantém os dois lados na mesma linha.

Ative **Base > Mostrar/Ocultar** para ver as marcas destes carateres no texto.

## Uma página em branco

**Inserir > Página em Branco** coloca uma página completamente vazia onde está o cursor. O texto anterior fica na sua página, e o texto seguinte passa para a página a seguir à página em branco. Anular remove-a num único passo.

## Uma página de rosto

**Inserir > Página de Rosto** coloca uma capa numa página própria, antes do texto. Escolha um design: **Clássico**, **Faixa** ou **Simples**. Clique em cada linha (o título, o subtítulo, o autor e a data) e escreva por cima. Um documento tem apenas uma página de rosto: escolher outro design substitui a primeira. **Remover Página de Rosto Atual** elimina-a. Anular repõe-a.

## A data e a hora

**Inserir > Data e Hora** lista formas de escrever a data de hoje e a hora. Escolha uma. Com **Atualizar automaticamente** selecionado, é inserida como campo, que mostra a nova data sempre que premir F9 ou abrir o documento. Com a opção desativada, é inserida como texto simples que se mantém tal como está. Escolha um **Idioma** para ver os nomes dos dias e dos meses nesse idioma, como alemão ou japonês. Uma data que se atualiza mantém esse idioma, também no ficheiro.

## Capitular

Uma capitular é uma letra inicial grande que desce para dentro das linhas ao lado, como no início de uma história.

1. Clique no parágrafo.
2. Escolha **Inserir > Capitular > Rebaixada**. A primeira letra desce três linhas.
3. Para outras opções, escolha **Opções de Capitular**. **Linhas a capitular** indica a altura da letra em linhas. **Letras** indica quantas das primeiras letras são grandes. Pode escolher um **tipo de letra** próprio para elas.

**Nenhuma** remove a capitular. Anular também a remove. Um parágrafo numa lista ou numa tabela, ou um que comece com um espaço, não pode ter capitular. Ao guardar, as letras grandes ficam num parágrafo pequeno próprio, formatado como capitular, à frente do restante texto. É assim que outros programas as guardam.
