# Criar formulários com controlos de conteúdo
<!-- keywords: controlo de conteúdo, controlos de conteúdo, formulário, formulários, preencher, texto simples, lista pendente, lista de seleção, seletor de data, calendário, caixa de verificação, caixa de seleção, título, etiqueta, marcador de posição, bloquear, não pode ser eliminado, propriedades -->

Um **controlo de conteúdo** é uma caixa no texto que uma pessoa preenche: uma linha de texto, uma escolha de uma lista, uma data de um calendário ou uma caixa de verificação. Use-os para criar um formulário que outros possam preencher sem alterar o resto do documento.

## Inserir um controlo

1. Coloque o cursor onde deve ficar o controlo.
2. Escolha **Inserir > Controlo de Conteúdo** e, em seguida, escolha o tipo:
   - **Texto Simples:** uma caixa para palavras. Mostra o marcador de posição "Escreva texto" até alguém escrever. Com palavras selecionadas, o controlo é criado à volta delas.
   - **Lista Pendente:** uma lista de opções. Mostra "Escolha um item" até ser escolhido um.
   - **Seletor de Data:** uma data de um calendário. Mostra "Escolha uma data" até ser escolhida uma.
   - **Caixa de Verificação:** uma pequena caixa que fica marcada ou desmarcada.

Um controlo tem um tom cinzento ligeiramente claro para que veja onde começa e onde termina. Quando o cursor está num controlo, este tem um contorno, e o respetivo título aparece num separador por cima dele. Inserir um controlo é um passo que pode ser anulado.

## Preencher um controlo

- **Texto Simples:** clique no marcador de posição e escreva. O que escrever substitui-o. Prima Shift+Enter para mudar de linha; Enter não cria um novo parágrafo dentro de um controlo.
- **Lista Pendente:** clique no controlo (ou prima Enter ou Alt+Seta para Baixo com o cursor nele) e clique num item. O item escolhido fica assinalado na próxima vez.
- **Seletor de Data:** clique no controlo e, em seguida, clique num dia no calendário. **Hoje** insere a data de hoje. **Limpar** repõe o marcador de posição.
- **Caixa de Verificação:** clique nela, ou prima a barra de espaço com o cursor nela, para a marcar ou desmarcar.

Uma lista pendente, um seletor de data e uma caixa de verificação guardam apenas o que for escolhido para eles: não é possível escrever neles.

## Alterar as propriedades de um controlo

Coloque o cursor no controlo e escolha **Inserir > Controlo de Conteúdo > Propriedades**. Pode definir:

- **Título** e **Etiqueta:** o título aparece no separador por cima do controlo. A etiqueta é um nome curto que outros programas podem usar para encontrar o controlo.
- **Itens da lista** (lista pendente): Adicionar, Renomear (clique duas vezes num item), Remover, Mover para Cima e Mover para Baixo. Uma lista pode ter até 1,000 itens.
- **Formato da data** (seletor de data): escolha um formato ou escreva o seu, como MMMM d, yyyy. A caixa mostra o aspeto da data de hoje nesse formato.
- **O controlo não pode ser eliminado:** o controlo fica, embora o conteúdo que tem dentro possa ser alterado.
- **O conteúdo não pode ser editado:** o controlo pode ser eliminado, mas o conteúdo que tem dentro não pode ser alterado.

Escolha **OK** para aplicar as alterações como um único passo que pode ser anulado.

## Boas to know

- Um documento pode ter até 10 000 controlos, e os controlos podem estar uns dentro dos outros até 8 níveis de profundidade.
- Os controlos de ficheiros de outros programas são apresentados e mantidos como estavam. Um tipo que o JeffWrite não consegue criar (como texto formatado, uma imagem, uma caixa combinada ou uma secção repetida) é mantido no lugar; pode alterar o respetivo título, etiqueta e bloqueios, mas não a lista de conteúdo.
- Os controlos são guardados em ficheiros `.docx`. Noutros tipos de ficheiro, as palavras mantêm-se e o controlo não.
