# Equações

<!-- keywords: equação, equações, matemática, fórmula, fração, raiz quadrada, índice superior, índice inferior, expoente, soma, integral, grego, símbolo, inserir equação, alt+= -->

Uma **equação** é uma linha de matemática, como uma fração ou uma raiz quadrada. Este tópico mostra como escrever uma equação e a inserir num documento.

## Inserir uma equação

1. Coloque o cursor onde deve ficar a equação.
2. Clique em **Inserir > Equação**, ou prima **Alt+=**.
3. Escreva a equação numa única linha. Por baixo da caixa vê o aspeto que terá. Clique em **OK**.

A equação é guardada no documento no formato padrão para matemática, para que outros programas a possam abrir.

## Como escrever

- **Frações:** escreva uma barra. `a/b` é a sobre b. `(x+1)/(x-1)` trata cada grupo entre parênteses como uma única parte. `\frac{1}{2}` também funciona.
- **Potências:** escreva um acento circunflexo. `x^2` é x ao quadrado. `e^(i*pi)` trata o grupo entre parênteses.
- **Índices inferiores:** escreva um underscore. `x_i` é x com um i pequeno em baixo. Pode usar ambos, como em `x_i^2`.
- **Raízes:** escreva `sqrt(x+1)` para uma raiz quadrada. Escreva `sqrt[3]{x}` para uma raiz cúbica.
- **Somas, integrais e produtos:** escreva `\sum_(i=1)^n i`, `\int_0^1 x` ou `\prod_(k=1)^n k`. A parte depois do underscore fica em baixo (ou na base do sinal de integral), e a parte depois do acento circunflexo fica em cima.
- **Símbolos:** escreva uma barra invertida e um nome. `\alpha` é α, `\pi` é π, `\infty` é ∞, `\leq` é ≤, `\neq` é ≠, `\times` é ×, `\pm` é ± e `\to` é →. Funcionam cerca de 70 nomes.
- **Funções:** `sin`, `cos`, `tan`, `log`, `ln`, `exp`, `lim`, `min` e `max` mantêm o nome completo.

Na página, o JeffWrite mostra uma equação como uma linha de texto. A equação no ficheiro mantém as frações e as raízes, para que outros programas a apresentem corretamente.

## Equações noutros documentos

O JeffWrite mostra as equações que um documento contém e mantém-nas tal como estavam. Não altera uma equação que já exista num documento. Elimine-a e volte a inseri-la.
