# Legendas e índices de figuras
<!-- keywords: legenda, figura, índice de figuras, etiqueta, número, SEQ, inserir legenda, lista de figuras, número do capítulo, atualizar tabela -->

Uma **legenda** é uma linha curta de texto por baixo ou por cima de uma imagem ou tabela, como "Figura 1: Nascer do sol". O JeffWrite numera as legendas para si. Se acrescentar uma no meio, os números seguintes são atualizados.

## Adicionar uma legenda

1. Clique na imagem, na tabela ou no parágrafo a que a legenda se refere.
2. Clique em **Referências > Inserir Legenda**.
3. Escolha uma **Etiqueta**. **Figura**, **Tabela** e **Equação** já estão disponíveis. Também pode escrever uma etiqueta própria, como Gráfico. Cada etiqueta é contada separadamente.
4. Escreva as palavras que devem aparecer depois do número, como `: Nascer do sol`.
5. Escolha **Acima** ou **Abaixo** e clique em **OK**.

A legenda fica num novo parágrafo com o estilo **Legenda**. Se escolher uma tabela, a legenda fica acima ou abaixo de toda a tabela, e não dentro dela.

Ative **Não mostrar a etiqueta** para mostrar apenas o número. Ative **Incluir o número do capítulo** para numerar as legendas por capítulo, como 2-1 e 2-2: escolha o nível do título que inicia um capítulo e um separador. A contagem recomeça em 1 abaixo de cada título desse nível.

## Criar um índice de figuras

Um **índice de figuras** lista as suas legendas com as respetivas páginas, à semelhança de um índice.

1. Clique onde deve ficar o índice.
2. Clique em **Referências > Índice de Figuras**.
3. Escolha a etiqueta da legenda, o carácter de preenchimento (os pontos antes dos números de página) e se as linhas são ligações.
4. Clique em **OK**.

Desative **Incluir etiqueta e número** para listar apenas as palavras depois do número.

## Atualizar os números e o índice

Prima **F9** para atualizar os campos do que selecionou, ou selecione tudo com **Ctrl+A** primeiro. Os números das legendas e as linhas de um índice de figuras são calculados de novo. A atualização é um passo que **Anular** pode desfazer.

## Referir uma legenda

Use **Referências > Referência cruzada** para escrever "ver Figura 2" de forma a que acompanhe o número se este mudar.
