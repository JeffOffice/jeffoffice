# Criar um índice remissivo
<!-- keywords: índice remissivo, marcar entrada, marcar tudo, subentrada, referência cruzada, ver, XE, INDEX, intervalo de páginas, número de página a negrito, colunas, em linha, cabeçalhos de letra, Alt+Shift+X, atualizar índice -->

Um **índice remissivo** é uma lista alfabética de palavras e ideias com as páginas onde aparecem. Primeiro **marca** as palavras que devem constar do índice e, depois, **insere** o índice.

## Marcar uma entrada

1. Selecione a palavra ou as palavras a incluir, ou clique no local para onde a entrada deve apontar.
2. Clique em **Referências > Marcar Entrada** ou prima **Alt+Shift+X**.
3. Confirme a **Entrada principal**. Escreva uma **Subentrada** se a entrada tiver uma parte subordinada. Por exemplo, a entrada principal `Maçãs` com a subentrada `Fuji`.
4. Escolha o que o número de página mostra:
   - **Página atual** indica a página onde está a marca.
   - **Intervalo de páginas** indica as páginas abrangidas por um marcador, como 5-7.
   - **Referência cruzada** indica palavras em vez de uma página, como "Ver Fruta".
5. Ative **Número de página a negrito** ou **Número de página em itálico** se quiser que o número se destaque.
6. Clique em **Marcar** para marcar este local, ou em **Marcar Tudo** para marcar todos os locais onde as mesmas palavras (com as mesmas maiúsculas e minúsculas) aparecem.

Uma marca é um **campo de entrada de índice** oculto (um campo XE). Não mostra nada na página.

## Inserir o índice

1. Clique no local onde o índice deve ficar.
2. Clique em **Referências > Inserir Índice Remissivo**.
3. Escolha o aspeto: **Com avanço** coloca cada subentrada numa linha própria, e **Em linha** coloca as subentradas depois da entrada, numa só linha. Escolha se pretende **Alinhar números de página à direita**, o carácter de preenchimento e se uma letra encabeça cada grupo.
4. Clique em **OK**.

O índice lista as entradas por ordem alfabética. Os números de página de uma entrada são listados uma vez cada, por ordem de página, separados por vírgulas.

## Manter o índice atualizado

Clique no índice e clique em **Referências > Atualizar Índice**, ou prima **F9**. As marcas que acrescentou passam a constar do índice, as marcas que eliminou desaparecem e as páginas são calculadas novamente.
