Estas ferramentas encontram-se no separador **Base**. Funcionam sobre o texto que selecionar.

## Alterar as maiúsculas e minúsculas das letras

A **capitalização** de uma letra indica se é uma letra maiúscula (A) ou minúscula (a).

1. Selecione o texto. Se não houver nada selecionado, o JeffWrite altera a palavra onde está o cursor.
2. No grupo **Tipo de Letra**, clique em **Maiúsculas/Minúsculas**.
3. Escolha uma opção:
   - **Maiúscula inicial da frase** coloca em maiúscula a primeira letra de cada frase. As restantes ficam em minúsculas.
   - **minúsculas** coloca todas as letras em minúsculas.
   - **MAIÚSCULAS** coloca todas as letras em maiúsculas.
   - **Maiúscula Inicial das Palavras** coloca em maiúscula a primeira letra de cada palavra.
   - **aLTERNAR mAIÚSCULAS** transforma cada maiúscula em minúscula, e cada minúscula em maiúscula.

Prima **Shift+F3** para percorrer três destas opções por ordem: **Maiúscula Inicial das Palavras**, depois **MAIÚSCULAS** e, por fim, **minúsculas**.

O aspeto das letras mantém-se. O negrito continua negrito. **Ctrl+Z** anula a alteração num único passo. Se o **Controlo de Alterações** estiver ativado, a alteração aparece como uma eliminação e uma inserção.

## Ordenar parágrafos

Ordenar coloca os parágrafos por ordem, como de A a Z. Use esta função para uma lista de nomes ou para linhas de uma tabela feita com tabulações ou vírgulas.

1. Selecione dois ou mais parágrafos.
2. No grupo **Parágrafo**, clique em **Ordenar**.
3. Escolha o critério de ordenação. Cada escolha tem um **campo**, um **tipo** e uma **ordem**.
   - O **campo** é uma parte do parágrafo. O campo 1 é a primeira parte. Se as partes estiverem separadas por vírgulas ou tabulações, indique-o na caixa abaixo das chaves. Se deixar **Parágrafos**, o parágrafo inteiro é o único campo.
   - O **tipo** é **Texto**, **Número** ou **Data**. Um número ordena-se pelo seu valor, pelo que 9 vem antes de 10.
   - A **ordem** é **Crescente** (de A a Z, do menor para o maior, do mais antigo para o mais recente) ou **Decrescente**.
4. Use **Depois por** para desempatar.
5. Marque **O primeiro parágrafo é um cabeçalho** para o deixar no mesmo lugar.
6. Clique em **OK**.

Cada parágrafo mantém a sua própria aparência. Não é possível ordenar com o **Controlo de Alterações** ativado, porque uma ordenação não é uma alteração que se possa mostrar. Desative o **Controlo de Alterações**, ordene e volte a ativá-lo.

## Colar de outras formas

Clique na pequena seta por baixo de **Colar** para ver mais opções:

- **Unir Formatação** cola o texto com a aparência do local para onde vai. Só se mantêm o negrito, o itálico, o sublinhado e o rasurado.
- **Manter Apenas Texto** cola as palavras sem qualquer aparência.
- **Imagem** cola uma imagem da área de transferência. Fica a cinzento quando a área de transferência não tem nenhuma imagem.
- **Colar Especial** (**Ctrl+Alt+V**) apresenta todas as formas como a área de transferência pode ser colada neste momento, e permite escolher uma delas.

Uma opção fica a cinzento quando a área de transferência não tem nada que possa utilizar.

## Quebras de linha e de página, e tabulações

Clique no pequeno botão no canto do grupo **Parágrafo** para abrir a caixa **Parágrafo**. Por baixo das opções de espaçamento encontram-se estas:

- **Controlo de linhas isoladas e órfãs** evita que uma linha solta de um parágrafo fique sozinha no início ou no fim de uma página.
- **Manter com o seguinte** mantém o parágrafo na mesma página que o seguinte. Use esta opção para um título.
- **Manter linhas juntas** mantém todas as linhas do parágrafo numa única página.
- **Quebra de página antes** inicia o parágrafo numa nova página.
- **Não hifenizar** impede que as palavras do parágrafo sejam divididas com um hífen no fim de uma linha.
- **Não adicionar espaço entre parágrafos do mesmo estilo** remove o espaço entre dois parágrafos que têm o mesmo estilo.
- **Nível de contorno** indica a posição do parágrafo no contorno do documento: **Corpo de texto**, ou um nível de 1 a 9.

Clique em **Tabulações** na caixa para definir posições de tabulação. Uma posição de tabulação é um sítio para onde o texto salta quando prime **Tab**. Escreva a posição, escolha o modo como o texto se alinha nesse ponto (à esquerda, ao centro, à direita ou decimal) e escolha um carácter de preenchimento. Um carácter de preenchimento é a fila de pontos, traços ou uma linha que preenche o espaço antes da posição. Clique em **Definir** para a adicionar. Para remover uma, selecione-a na lista e clique em **Limpar**. **Limpar Tudo** remove todas.

## Desenhar uma linha horizontal

Clique em **Linha Horizontal** no grupo **Parágrafo**. O JeffWrite acrescenta um parágrafo próprio com uma linha fina por baixo, depois do parágrafo onde está o cursor. O cursor passa para um parágrafo simples abaixo da linha. Para remover a linha, selecione o respetivo parágrafo e elimine-o.

## Ver o que está definido onde está o cursor

Prima **Shift+F1** ou use **Mostrar Formatação**. Uma caixa indica os estilos, o tipo de letra, o tamanho, o aspeto das letras, a cor e o alinhamento, os avanços e o espaçamento do parágrafo no cursor. Apenas mostra estes dados. Para os alterar, use as caixas **Tipo de Letra** e **Parágrafo**.
