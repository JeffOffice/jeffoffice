# Copiar um aspeto com Copiar formatação
<!-- keywords: copiar formatação, copiar formato, colar formato, pincel, pintar, mesmo aspeto, mesma formatação, ctrl+shift+c, ctrl+shift+v, duplo clique -->

**Copiar formatação** copia o aspeto de um texto e aplica-o a outro texto. Utilize-o quando pretender que uma palavra ou um parágrafo fique com o mesmo aspeto de outro.

## Copiar um aspeto para um local

1. Selecione as palavras que têm o aspeto pretendido. Em alternativa, clique no parágrafo.
2. Clique em **Copiar formatação** no separador **Base**. O botão permanece premido e a barra de estado lembra-lhe o que fazer.
3. Selecione com o rato as palavras que pretende alterar. Quando soltar o botão do rato, estas ficam com o aspeto copiado e Copiar formatação é desativado.

Se clicar numa palavra sem selecionar, é essa palavra que fica com o aspeto.

## Copiar um aspeto para vários locais

Faça duplo clique em **Copiar formatação**. O comando permanece ativo. Sempre que selecionar texto com o rato, esse texto fica com o aspeto copiado. Prima **Esc** ou clique novamente no botão para parar.

## O que é copiado

- O aspeto dos carateres: o tipo de letra, o tamanho, o negrito, o itálico, o sublinhado, a cor, entre outros.
- O aspeto do parágrafo, se tiver copiado a partir de uma marca de parágrafo. Para copiar a partir de uma marca de parágrafo, selecione o parágrafo inteiro até ao início do seguinte ou clique no parágrafo sem selecionar. O alinhamento, os avanços, o espaçamento e o estilo do parágrafo são copiados com ele. São aplicados aos parágrafos que pintar quando a seleção incluir o fim de um parágrafo.
- Se selecionar apenas palavras, só é copiado o aspeto dos carateres.

A lista em que um parágrafo se encontra e a posição que ocupa no documento não são alteradas.

Cada aplicação de Copiar formatação corresponde a um passo. **Anular** (Ctrl+Z) desfá-la.

## Utilizar o teclado

- **Ctrl+Shift+C** copia o aspeto da seleção.
- **Ctrl+Shift+V** aplica esse aspeto à seleção.
