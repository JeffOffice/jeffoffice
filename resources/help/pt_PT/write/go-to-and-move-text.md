## Ir para um local

Prima **Ctrl+G** ou clique em **Base > Edição > Ir Para**. Abre-se a caixa **Ir Para**.

1. Em **Ir para**, escolha **Página**, **Secção**, **Linha**, **Marcador**, **Nota de rodapé**, **Nota de fim**, **Comentário**, **Campo**, **Tabela**, **Gráfico**, **Equação** ou **Título**.
2. Escreva um número ou um nome. Para um marcador, uma nota de rodapé ou um título, pode escolher um item da lista que aparece por baixo da caixa.
3. Clique em **Ir Para**. O cursor move-se para esse local, e as páginas deslocam-se para o mostrar.

Algumas notas sobre cada tipo:

- **Página**, **Secção**, **Nota de rodapé**, **Nota de fim**, **Comentário**, **Campo**, **Tabela**, **Gráfico**, **Equação** e **Título** aceitam um número: 3 vai para o terceiro. Escreva **+** ou **-** antes do número para contar a partir da posição do cursor: **+1** vai para o seguinte, e **-1** vai para o anterior.
- **Linha** aceita um número contado a partir do início do documento.
- **Marcador** aceita o nome de um marcador. Não faz diferença usar maiúsculas ou minúsculas. Os marcadores criados por um programa para uso próprio, cujos nomes começam por um sublinhado, não são listados.
- **Comentário**, **Campo**, **Tabela**, **Gráfico** e **Equação** são contados pela ordem em que surgem no texto. Um gráfico é uma imagem, uma forma ou uma caixa de texto. Um campo é um pedaço de texto que o programa calcula por si, como uma data ou um número de página. As respostas a um comentário não são contadas separadamente.
- **Título** aceita um número ou qualquer parte do texto do título. Os títulos são os parágrafos que têm um nível de contorno, como os dos estilos de Título.

Se o local não existir no documento, a caixa indica-o e continua aberta, para que possa escrever outro.

## Mover ou copiar texto arrastando

1. Selecione o texto que pretende mover.
2. Prima o texto selecionado com o rato e mantenha o botão premido enquanto desloca ligeiramente o ponteiro. Depois arraste o texto para o local pretendido.
3. Largue o botão do rato. O texto move-se para ali e continua selecionado.

Para copiar o texto em vez de o mover, mantenha **Ctrl** premido ao largar o botão. O original fica onde estava.

Arrastar texto é uma ação só, por isso um **Anular** (Ctrl+Z) repõe o texto. Se largar o texto sobre a própria seleção, nada acontece. Também pode largar no documento texto proveniente de outro programa.
