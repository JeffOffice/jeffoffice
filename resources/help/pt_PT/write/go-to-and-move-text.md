## Ir para um local

Prima **Ctrl+G** ou clique em **Base > Edição > Ir Para**. É aberta a caixa **Ir Para**.

1. Em **Ir para**, escolha **Página**, **Secção**, **Linha**, **Marcador**, **Nota de rodapé** ou **Título**.
2. Escreva um número ou um nome. Para um marcador, uma nota de rodapé ou um título, pode, em alternativa, escolher um da lista por baixo da caixa.
3. Clique em **Ir Para**. O cursor move-se para esse local e as páginas deslocam-se para o mostrar.

Algumas notas sobre cada tipo:

- **Página**, **Secção**, **Nota de rodapé** e **Título** aceitam um número: 3 vai para o terceiro. Coloque um **+** ou um **-** antes para contar a partir da posição do cursor: **+1** vai para o seguinte e **-1** vai para o anterior.
- **Linha** aceita um número contado a partir do início do documento.
- **Marcador** aceita o nome de um marcador. Não importa se utiliza maiúsculas ou não. Os marcadores que um programa criou para uso próprio, cujos nomes começam por um carácter de sublinhado, não são listados.
- **Título** aceita um número ou qualquer parte do texto do título. Os títulos são os parágrafos que têm um nível de destaque, como os que utilizam os estilos de Título.

Se o local não existir no documento, a caixa indica-o e permanece aberta, para que possa escrever outro.

## Mover ou copiar texto arrastando

1. Selecione o texto que pretende mover.
2. Prima o botão do rato sobre o texto selecionado e mantenha-o premido enquanto move ligeiramente o ponteiro. Em seguida, arraste o texto para o local pretendido.
3. Solte o botão do rato. O texto é movido para esse local e permanece selecionado.

Para copiar o texto em vez de o mover, mantenha premida a tecla **Ctrl** enquanto solta o botão. O original permanece onde estava.

Arrastar texto é uma única operação, pelo que basta um **Anular** (Ctrl+Z) para repor o texto. Se largar o texto sobre a própria seleção, nada acontece. Também pode largar no documento texto proveniente de outro programa.
