# Utilizar o JeffWrite com o teclado
<!-- keywords: teclado, atalhos, atalhos de teclado, teclas, teclas de atalho, sugestões de teclas, ctrl, alt, navegar, mover, deslocar, selecionar, ponto de inserção, cursor -->

Pode fazer tudo no JeffWrite com o teclado. Esta página indica as teclas.

## Mover e selecionar

- As **teclas de seta** movem o ponto de inserção. O **ponto de inserção** é a linha intermitente que mostra onde aparece o texto que escreve.
- **Ctrl+Seta para a Esquerda** e **Ctrl+Seta para a Direita** movem uma palavra.
- **Home** e **End** movem para o início e o fim de uma linha. **Ctrl+Home** e **Ctrl+End** movem para o início e o fim do documento.
- **Page Up** e **Page Down** movem uma janela de texto.
- Mantenha premida a tecla **Shift** com qualquer uma destas teclas para selecionar texto à medida que se move.
- **Ctrl+A** seleciona tudo.

## Escrever e eliminar

- **Enter** inicia um novo parágrafo. **Shift+Enter** inicia uma nova linha no mesmo parágrafo.
- **Ctrl+Enter** inicia uma nova página.
- **Esc** fecha um cabeçalho ou rodapé que esteja a editar e sai de uma nota de rodapé que esteja a editar, regressando ao texto.
- **Tab** adiciona uma tabulação. Numa lista, desce o item um nível. **Shift+Tab** sobe-o um nível.
- **Backspace** e **Delete** removem texto. Mantenha premida a tecla **Ctrl** para remover uma palavra.

## Aceder ao friso

Prima **Alt** para mostrar uma letra em cada separador. Prima a letra para abrir o separador e, em seguida, as letras que aparecem para aceder a um botão. Prima **Esc** para recuar. **F6** move o teclado entre o friso e a página.
