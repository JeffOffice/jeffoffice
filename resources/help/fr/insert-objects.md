# Icônes, codes-barres et autres objets
<!-- keywords: icône, symbole, caractère spécial, code-barres, ISBN, UPC, bloc de construction, calendrier, bordure, publicité, informations professionnelles, date et heure, lien hypertexte, lien, insérer un fichier, insertion de fichier -->

Cette rubrique présente les autres éléments que vous pouvez ajouter depuis l'onglet **Insertion**. Les images, les formes, les tableaux, le texte artistique et les notes de bas de page ont leurs propres rubriques.

## Icônes

1. Cliquez sur **Insertion > Illustrations > Icônes**.
2. Dans la fenêtre **Insérer des icônes**, saisissez un mot tel que flèche, courrier ou étoile.
3. Cliquez sur une icône. Maintenez **Ctrl** ou **Maj** enfoncé pendant le clic pour en choisir plusieurs.
4. Cliquez sur **Insérer**.

JeffPub propose plus de 1 500 icônes issues de la collection Lucide. Chaque icône est placée au centre de la page, avec une hauteur de 2,5 cm, dans la couleur principale de votre jeu de couleurs. Une icône est une forme : vous pouvez donc changer sa couleur avec **Contour de la forme** dans l'onglet **Format de la forme**.

## Codes-barres

1. Cliquez sur **Insertion > Illustrations > Code-barres**.
2. Dans la fenêtre **Insérer un code-barres**, choisissez un **Type** : Livre (ISBN), EAN-13, UPC-A, EAN-8, Code 128, Code 39 ou code QR. Un code QR peut contenir n'importe quel texte, comme une adresse web. Il dispose d'un réglage **Correction d'erreur** : plus le niveau est élevé, plus le code reste lisible lorsqu'une partie est endommagée ou masquée, mais plus il devient grand.
3. Saisissez le numéro ou le texte. Pour un livre, saisissez l'ISBN. JeffPub ajoute les tirets.
4. Pour un livre, choisissez un code complémentaire de prix ou **Aucun code complémentaire**. Pour les codes EAN et UPC, vous pouvez saisir un complément de 2 ou 5 chiffres.
5. Vérifiez l'aperçu, puis cliquez sur **Insérer**.

Si quelque chose ne va pas, la fenêtre l'indique en rouge et le bouton **Insérer** reste grisé. Vous pouvez aussi régler **Agrandissement** et **Hauteur des barres**. Gardez **Arrière-plan blanc** activé, car les lecteurs ont besoin de la marge claire. Pour modifier un code-barres ultérieurement, double-cliquez dessus. Pour placer correctement les tirets de chaque pays, JeffPub télécharge la liste des plages de l'Agence internationale de l'ISBN et en conserve une copie.

## Blocs de construction

Un bloc de construction est un ensemble d'objets prêts à l'emploi, comme un titre ou un bon de réduction. Ouvrez une galerie dans **Insertion > Blocs de construction** :

- **Composants de page** : titres, citations en exergue, encadrés, articles sur deux et trois colonnes, et une table des matières. Une citation en exergue est une courte citation extraite de l'article, en grand format.
- **Calendriers** : le mois en cours ou le mois suivant. Pour un autre mois, cliquez sur **Autres calendriers…**, puis choisissez un mois, une année et une présentation dans la fenêtre **Calendrier**.
- **Bordures et accents** : barres, filets, cadres et éléments d'angle.
- **Publicités** : un bon de réduction, une publicité de soldes, une publicité d'événement, une explosion, une étiquette de prix, et d'autres.

Cliquez sur un bloc pour l'ajouter. Il utilise les couleurs et les polices de votre jeu. Il est composé de zones de texte et de formes ordinaires : vous pouvez donc le modifier comme n'importe quel autre élément.

## Informations professionnelles

Cliquez sur **Insertion > Texte > Informations professionnelles**, puis choisissez une information, comme Nom de l'organisation, Adresse, Téléphone, Site web ou Logo. Si le curseur se trouve dans une zone de texte, l'information y est insérée. Sinon, JeffPub ajoute une nouvelle zone de texte. Choisissez **Modifier les informations professionnelles…** pour saisir ou modifier vos coordonnées. Les informations que vous avez insérées sont mises à jour lorsque vous modifiez vos coordonnées.

## Texte, liens et autres éléments

- **Insertion > Texte > Insérer un fichier** importe du texte depuis un fichier .txt, .rtf, .html, .docx ou .md, d'une taille maximale de 64 Mo. Le texte est placé à l'endroit du curseur, ou dans une nouvelle zone de texte si aucun texte n'est en cours de modification ; l'opération peut être annulée en une seule fois. Un fichier trop volumineux, impossible à ouvrir ou qui n'est pas du type indiqué par son nom n'est pas importé : JeffPub vous en informe, et la composition reste inchangée. Le dépôt de fichiers texte sur la page fonctionne de la même manière, et les autres fichiers déposés sont tout de même importés.
- **Symbole** insère un caractère spécial, comme © ou é. Cliquez d'abord dans une zone de texte.
- **Date et heure** : cliquez d'abord dans une zone de texte, choisissez une **Langue** pour les noms des jours et des mois, sélectionnez un format, puis cochez **Mettre à jour automatiquement** pour que la date reste à jour. Le champ conserve sa langue. Un fichier `.pub` conserve le format mais pas la langue : une date enregistrée dans ce format s'affiche donc dans la langue de l'ordinateur lorsque le fichier est rouvert.
- **Insertion > Liens > Lien** (Ctrl+K) crée un lien hypertexte vers une page web, une page de votre composition ou une adresse e-mail. Sélectionnez d'abord du texte ou un objet. Choisissez **Supprimer le lien** pour le retirer.
- **Signet** donne un nom au texte ou à l'objet sélectionné.
- **Objet** vous permet de choisir un fichier et de le placer comme une image.
