# Aller à un emplacement et déplacer du texte

## Aller à un emplacement

Appuyez sur **Ctrl+G**, ou cliquez sur **Accueil > Modification > Atteindre**. La boîte de dialogue **Atteindre** s'ouvre.

1. Dans **Atteindre**, choisissez **Page**, **Section**, **Ligne**, **Signet**, **Note de bas de page**, **Note de fin**, **Commentaire**, **Champ**, **Tableau**, **Graphique**, **Équation** ou **Titre**.
2. Saisissez un numéro ou un nom. Pour un signet, une note de bas de page ou un titre, vous pouvez aussi en choisir un dans la liste située sous la boîte.
3. Cliquez sur **Atteindre**. Votre curseur se place à cet emplacement, et les pages défilent pour l'afficher.

Quelques précisions pour chaque type :

- **Page**, **Section**, **Note de bas de page**, **Note de fin**, **Commentaire**, **Champ**, **Tableau**, **Graphique**, **Équation** et **Titre** s'utilisent avec un numéro : 3 vous mène au troisième élément. Placez un **+** ou un **-** devant le numéro pour compter à partir de l'emplacement du curseur : **+1** mène à l'élément suivant, et **-1** à l'élément précédent.
- **Ligne** s'utilise avec un numéro compté depuis le début du document.
- **Signet** s'utilise avec le nom d'un signet. La casse n'a pas d'importance. Les signets créés par le programme pour son propre usage, dont le nom commence par un trait de soulignement, ne sont pas listés.
- **Commentaire**, **Champ**, **Tableau**, **Graphique** et **Équation** sont comptés dans l'ordre où ils apparaissent dans le texte. Un graphique est une image, une forme ou une zone de texte. Un champ est un élément de texte que le programme calcule pour vous, comme une date ou un numéro de page. Les réponses à un commentaire ne sont pas comptées séparément.
- **Titre** s'utilise avec un numéro, ou avec n'importe quelle partie du texte du titre. Les titres sont les paragraphes dotés d'un niveau de plan, comme ceux des styles Titre.

Si l'emplacement ne se trouve pas dans le document, la boîte de dialogue l'indique et reste ouverte, afin que vous puissiez saisir un autre emplacement.

## Déplacer ou copier du texte par glisser-déposer

1. Sélectionnez le texte à déplacer.
2. Appuyez sur le texte sélectionné avec la souris, maintenez le bouton enfoncé et déplacez légèrement le pointeur. Faites ensuite glisser le texte jusqu'à l'emplacement voulu.
3. Relâchez le bouton de la souris. Le texte est déplacé à cet endroit et reste sélectionné.

Pour copier le texte au lieu de le déplacer, maintenez la touche **Ctrl** enfoncée au moment où vous relâchez le bouton. L'original reste à sa place.

Le glisser-déplacer se fait en une seule étape : une seule commande **Annuler** (Ctrl+Z) remet le texte à sa place. Si vous déposez le texte sur la sélection elle-même, rien ne se passe. Vous pouvez également déposer dans votre document du texte provenant d'un autre programme.
