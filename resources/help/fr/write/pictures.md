# Ajouter et modifier des images
<!-- keywords: image, images, photo, illustration, insérer une image, presse-papiers, coller une image, capture d'écran, habillage du texte, habillage, aligné sur le texte, carré, rapproché, haut et bas, derrière le texte, devant le texte, texte de remplacement, description, redimensionner, taille, poignées, déplacer une image, faire glisser une image, déposer, format de l'image, conserver les proportions -->

Une **image** peut se placer dans une ligne de texte, comme une lettre, ou flotter sur la page avec le texte qui l'entoure. Cette rubrique explique comment insérer une image dans un document, modifier sa taille, sa position et la façon dont le texte l'entoure, et comment la décrire pour les personnes qui ne peuvent pas la voir.

## Insérer une image

- Cliquez sur **Insertion > Images**, puis sur **Image**, choisissez un fichier et cliquez sur **Ouvrir**. JeffWrite lit les fichiers PNG, JPEG, GIF, BMP, TIFF, WebP et SVG. Une image provenant d'un fichier est conservée dans le document sous sa forme d'origine (une image WebP ou SVG est conservée au format PNG).
- Vous pouvez aussi cliquer sur **Insertion > Images > Image du presse-papiers**, ou appuyer sur **Ctrl+V**, après avoir copié une image (par exemple une capture d'écran). L'image est conservée dans le document : elle est toujours présente lorsque vous enregistrez puis rouvrez le fichier.
- Vous pouvez également faire glisser un fichier image depuis le gestionnaire de fichiers de votre ordinateur vers une page. L'image est placée à l'endroit où vous la déposez.

L'image est insérée à la position du curseur, à la place de la sélection éventuelle. Elle prend la taille qu'elle demande, sans dépasser la largeur de la colonne ni la hauteur du texte de la page, et ses proportions sont conservées. L'image est ensuite sélectionnée et l'onglet **Format de l'image** apparaît à droite du ruban.

Une image trop grande (plus de 40 millions de pixels, un côté de plus de 30 000 pixels ou un fichier de plus de 48 Mo) n'est pas insérée, et la barre d'état l'indique. Il en va de même pour un fichier qui n'est pas une image.

## Modifier la taille

Cliquez sur l'image pour la sélectionner. Huit petits carrés, les **poignées**, apparaissent aux coins et sur les côtés.

- Faites glisser une poignée d'**angle** pour agrandir ou réduire l'image en conservant ses proportions.
- Faites glisser une poignée **latérale** pour modifier un seul côté.
- Vous pouvez aussi taper une valeur dans **Format de l'image > Hauteur** ou **Largeur**. Si l'option **Conserver les proportions** est activée, l'autre valeur s'adapte. La taille d'un côté est comprise entre 2 points et 2 000 points.

Chaque modification peut être annulée séparément.

## Habiller une image avec le texte

**Format de l'image > Habillage du texte** détermine la façon dont le texte entoure l'image. Vous pouvez aussi cliquer avec le bouton droit sur l'image et choisir **Habillage du texte**.

- **Aligné sur le texte** : l'image se comporte comme un caractère de sa ligne et se déplace avec le texte qui l'entoure.
- **Carré** : le texte entoure un rectangle qui contient l'image.
- **Rapproché** : le texte s'approche de l'image autant qu'un rectangle le permet (JeffWrite le traite comme Carré).
- **Haut et bas** : le texte s'arrête au-dessus de l'image et reprend en dessous.
- **Derrière le texte** : l'image se trouve sous le texte, qui passe par-dessus.
- **Devant le texte** : l'image se trouve sur le texte, qui passe en dessous.

## Déplacer une image

Faites glisser l'image. Une image **alignée sur le texte** se place dans le texte à l'endroit où vous la relâchez. Une image avec un autre habillage se place sur la page à l'endroit où vous la relâchez, et y reste même si le texte qui l'entoure change (elle reste attachée à son paragraphe, sur la page de ce paragraphe).

Faire glisser une image alignée sur le texte ne modifie pas son habillage ; pour la rendre flottante, choisissez un habillage tel que **Carré**.

## Décrire une image

Le **texte de remplacement** est une courte description lue à voix haute par les lecteurs d'écran, et affichée lorsque l'image ne peut pas l'être. Sélectionnez l'image et cliquez sur **Format de l'image > Texte de remplacement** (ou cliquez avec le bouton droit sur l'image et choisissez **Texte de remplacement**), tapez la description, puis cliquez sur **OK**.

## Images provenant d'autres documents

JeffWrite affiche et conserve les images des documents qu'il ouvre. Il peut modifier la taille, l'habillage, la position et le texte de remplacement d'une image enregistrée dans le document comme une image simple. Une image enregistrée sous une forme que JeffWrite ne modifie pas (un groupe de dessins, par exemple) peut être sélectionnée et est conservée telle quelle ; ses commandes sont désactivées.
