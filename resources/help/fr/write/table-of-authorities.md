# Créer une table des sources juridiques
<!-- keywords: table des sources juridiques, sources juridiques, citation, marquer une citation, jurisprudence, loi, texte législatif, règle, règlement, traité, passim, mémoire juridique, TSJ, table des sources, Alt+Maj+I, catégorie -->

Une **table des sources juridiques** est une liste que comporte un mémoire juridique : les décisions de justice, les lois et les autres ouvrages cités dans le mémoire, avec les pages qui les citent. Vous commencez par **marquer** chaque citation, puis vous **insérez** la table.

## Marquer une citation

1. Sélectionnez la citation dans votre texte, par exemple le nom d'une décision avec ses numéros.
2. Cliquez sur **Références > Marquer la citation**, ou appuyez sur **Alt+Maj+I**.
3. Cochez **Citation longue**. C'est ce que la table affiche. Saisissez une **Citation courte** si vous utilisez une forme plus brève plus loin dans le texte.
4. Choisissez une **Catégorie** : Jurisprudence, Lois, Autres sources, Règles, Traités, Règlements ou Dispositions constitutionnelles. Neuf autres catégories numérotées sont disponibles pour votre usage personnel.
5. Cliquez sur **OK**.

Marquez chaque passage qui cite la source. La table ne mentionne la source qu'une seule fois, avec toutes les pages.

## Insérer la table

1. Cliquez à l'endroit où la table doit figurer.
2. Cliquez sur **Références > Table des sources juridiques**.
3. Choisissez une catégorie, ou **Toutes** pour afficher toutes les catégories comportant des marques. Choisissez les points de suite, si vous voulez utiliser **passim**, et si vous voulez placer le nom de la catégorie au-dessus de ses citations.
4. Cliquez sur **OK**.

**Passim** est un mot latin qui signifie « çà et là ». Lorsqu'une source est citée sur cinq pages ou plus, la table affiche ce mot au lieu d'une longue liste de numéros.

## Maintenir la table à jour

Cliquez dans la table, puis cliquez sur **Mettre à jour les sources juridiques** (dans le groupe **Table des sources juridiques** de l'onglet **Références**), ou appuyez sur **F9**.
