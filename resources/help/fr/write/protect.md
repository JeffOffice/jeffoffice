# Protéger un document et verrouiller le suivi
<!-- keywords: protéger, protection, restreindre la modification, lecture seule, mot de passe, verrouiller le suivi, options de suivi des modifications, nom d'utilisateur, initiales, modifications suivies uniquement, commentaires uniquement, arrêter la protection -->

La protection limite ce que les utilisateurs peuvent faire dans un document. Ces outils se trouvent dans l'onglet **Révision**.

## Restreindre la modification

1. Cliquez sur **Restreindre la modification** dans le groupe **Protéger**.
2. Choisissez ce que les utilisateurs peuvent faire :
   - **Aucune modification (lecture seule)** : le texte ne peut pas être modifié.
   - **Modifications suivies** : les utilisateurs peuvent modifier le document, mais chaque modification est suivie, et le suivi des modifications ne peut pas être désactivé.
   - **Commentaires** : les utilisateurs peuvent ajouter des commentaires, mais ne peuvent pas modifier le texte.
   - **Remplissage de formulaires** : le texte est en lecture seule.
3. Saisissez un mot de passe, deux fois. Vous pouvez laisser le mot de passe vide. Dans ce cas, tout le monde peut arrêter la protection.
4. Cliquez sur **Appliquer la protection**.

La barre de titre affiche alors « Protégé ». Pour arrêter la protection, cliquez de nouveau sur **Restreindre la modification**, puis sur **Arrêter la protection**. Saisissez le mot de passe s'il y en a un.

Un mot de passe évite que des personnes de bonne foi modifient le document par erreur. Ce n'est pas une sécurité forte. N'utilisez pas la protection pour cacher des informations confidentielles.

Le mot de passe est enregistré dans le fichier sous la forme d'un nombre brouillé, appelé empreinte. Le mot de passe lui-même n'est jamais enregistré. Si vous l'oubliez, JeffWrite ne peut pas le récupérer.

## Verrouiller le suivi

Cliquez sur **Options de suivi**, puis sur **Verrouiller le suivi**. Toutes les modifications effectuées à partir de ce moment sont suivies. Personne ne peut désactiver le suivi des modifications, ni accepter ou refuser une modification, sans le mot de passe. Cela revient à protéger le document pour les modifications suivies.

## Modifier votre nom sur les modifications

Cliquez sur **Options de suivi**, puis sur **Options de suivi des modifications**. Saisissez votre nom et vos initiales. Ils signeront les modifications et les commentaires que vous effectuerez à partir de ce moment.
