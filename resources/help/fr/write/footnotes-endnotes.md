# Notes de bas de page et de fin

<!-- keywords: note de bas de page, note de fin, note, notes, renvoi, référence, citation, source, insérer une note de bas de page, insérer une note de fin, onglet Références, numérotation, bas de page, fin du document, légende, Ctrl+Alt+F, Ctrl+Alt+D, format de numérotation, commencer à, recommencer, convertir, permuter, séparateur, avis de suite, numérotation, emplacement, chiffres romains, lettres, symboles, options des notes de bas de page et de fin -->

Une **note** apporte un complément d'information sur certains mots sans interrompre la phrase. Un petit chiffre en exposant dans le texte, appelé le **renvoi**, indique la note qui lui correspond. Une **note de bas de page** est placée en bas de la page qui contient son renvoi. Une **note de fin** est placée après le dernier texte du document, ou à la fin d'une section lorsque le fichier le demande.

## Ajouter une note de bas de page

1. Cliquez à l'endroit où doit figurer le renvoi, juste après les mots que la note concerne.
2. Cliquez sur **Références > Insérer une note de bas de page**, ou appuyez sur **Ctrl+Alt+F**.

JeffWrite insère le renvoi dans le texte et crée une nouvelle note en bas de page, portant le même numéro. Le point d'insertion passe dans la note, ce qui vous permet de la rédiger immédiatement.

Les notes sont numérotées dans l'ordre de leurs renvois dans le texte. Si vous ajoutez une note de bas de page avant d'autres, chaque note suivante augmente d'un numéro, et le renvoi dans le texte affiche également le nouveau numéro.

## Ajouter une note de fin

Cliquez à l'endroit où doit figurer le renvoi, puis cliquez sur **Références > Insérer une note de fin**, ou appuyez sur **Ctrl+Alt+D**. JeffWrite insère le renvoi dans le texte et crée une nouvelle note de fin après le dernier texte, avec son numéro ; le point d'insertion passe dans cette note. Les notes de fin ont leur propre numérotation, dans le style demandé par le fichier.

## Modifier la numérotation des notes

Cliquez sur la petite flèche située dans l'angle du groupe **Notes de bas de page** de l'onglet **Références**. La boîte de dialogue comporte une partie pour les notes de bas de page et une partie pour les notes de fin :

- **Format de nombre** définit l'apparence des numéros : 1, 2, 3 ; a, b, c ; A, B, C ; i, ii, iii ; I, II, III ; ou les symboles \*, †, ‡, §.
- **Commencer à** est le numéro de la première note. Si vous choisissez 3 et le format i, ii, iii, la première note affiche iii.
- **Numérotation** indique quand les numéros recommencent : jamais (**Continu**), à chaque nouvelle section ou, pour les notes de bas de page, en haut de chaque page.
- **Emplacement** (notes de fin uniquement) place les notes de fin à la fin de chaque section ou à la fin du document.

Les notes de bas de page changent immédiatement. Pour les notes de fin, JeffWrite relit le document afin que chaque marque et chaque note adopte la nouvelle présentation ; la liste d'annulations repart alors de zéro. La modification est enregistrée avec le fichier, de sorte que les autres programmes affichent les mêmes numéros.

## Convertir les notes de bas de page en notes de fin, ou l'inverse

Cliquez sur **Références > Convertir...** (un petit bouton placé à côté des boutons des notes). La boîte de dialogue propose quatre choix :

- **Convertir toutes les notes de bas de page en notes de fin**
- **Convertir toutes les notes de fin en notes de bas de page**
- **Permuter les notes de bas de page et les notes de fin** : chaque note de bas de page devient une note de fin, et chaque note de fin devient une note de bas de page.
- **Convertir cette note** : ce choix est disponible lorsque le point d'insertion se trouve dans une note, et il ne modifie que celle-ci.

Le texte de chaque note est conservé. Chaque note adopte la présentation de son nouveau type, et les notes sont à nouveau numérotées. L'opération se fait en une seule étape : **Annuler** rétablit toutes les notes.

## Modifier le trait situé au-dessus des notes

Une note comporte trois éléments qui ne sont pas du texte :

- Le **séparateur** est le trait qui sépare le texte des notes.
- Le **séparateur de suite** est le trait situé au-dessus d'une note qui se poursuit depuis la page précédente.
- L'**avis de suite** est le texte situé sous une note qui se poursuit sur la page suivante, par exemple « Suite à la page suivante. »

Cliquez sur **Références > Séparateurs...**. Pour chaque élément, choisissez **Trait**, **Texte** (puis saisissez le texte) ou **Aucun**. Les notes de fin ne possèdent que le séparateur, car elles se déroulent dans le texte et ne sont pas coupées au bas d'une page ; les deux autres éléments d'une note de fin, s'ils existent dans le fichier, sont conservés tels quels. Un élément qui contient davantage qu'un trait ou quelques mots, par exemple une image, affiche **Tel qu'dans le fichier**, et JeffWrite le conserve tel quel. La boîte de dialogue exige qu'au moins une note du type concerné existe. Lorsque vous modifiez un élément d'une note de fin, JeffWrite relit le document, comme pour la numérotation, et la liste d'annulations repart de zéro.

## Modifier une note

Cliquez dans le texte d'une note en bas de page, ou après le dernier texte pour une note de fin. Le point d'insertion s'y place. Saisissez, sélectionnez, coupez, copiez, collez et modifiez la mise en forme des mots comme dans le texte, et choisissez un style pour son paragraphe : le paragraphe reste une partie de la note. Une note peut comporter plusieurs paragraphes.

Deux éléments d'une note ne sont pas du texte, et aucune modification ne peut les changer : le numéro qui commence la note et le court trait situé au-dessus des notes. Si vous appuyez sur **Retour arrière** juste après le numéro, rien ne se passe. Une sélection qui irait d'une note à une autre s'arrête à la fin de la note où vous avez commencé.

Pour quitter une note, appuyez sur **Échap**, appuyez sur **Haut** à sa première ligne ou sur **Bas** à sa dernière ligne, ou cliquez dans le texte de la page. Le point d'insertion revient dans le texte, juste après le renvoi de la note. Une note longue peut se poursuivre en bas de la page suivante ; les touches de direction passent alors d'une partie à l'autre, et la note n'est quittée qu'à sa toute première et sa toute dernière ligne. Une note qui possède deux renvois apparaît sur les deux pages, et c'est la page sur laquelle vous avez cliqué que vous modifiez.

## Supprimer ou déplacer une note

- Supprimez un renvoi, et sa note disparaît avec lui. Les notes suivantes sont à nouveau numérotées. **Annuler** rétablit les deux.
- Coupez un renvoi et collez-le ailleurs : sa note se déplace avec lui.
- Copiez un renvoi et collez-le : vous obtenez une seconde note contenant les mêmes mots, que vous pouvez modifier indépendamment.
- Certains fichiers comportent deux renvois vers une même note. Si vous en supprimez un, la note reste. Si vous supprimez le dernier, la note disparaît.

## Ce que JeffWrite conserve

- Une partie du fichier que vous n'avez pas modifiée est enregistrée exactement comme elle était. Lorsque vous modifiez une note, seules les notes modifiées sont réécrites, et tout élément de ces notes que JeffWrite ne peut pas modifier (une image, un signet, un lien, un champ) reste à sa place.
- Le trait situé au-dessus des notes, et celui qui précède une note se poursuivant depuis la page précédente, sont conservés tels que le fichier les contient, jusqu'à leur modification dans **Séparateurs de notes**.
- Si le fichier ne contient aucune note, la première que vous ajoutez crée aussi les éléments nécessaires à une partie de notes, afin que les autres programmes ouvrent le fichier sans message.
- Une note reste dans le fichier tant qu'un élément la cite : le texte, un en-tête ou un pied de page, une zone de texte ou une autre note. Lorsque le dernier de ces éléments la supprime, la note disparaît.
- Un document peut contenir jusqu'à 5 000 notes de chaque type citées par son texte. Lorsqu'il en contient autant, **Insérer une note de bas de page** et **Insérer une note de fin** sont désactivés, et la barre d'état indique la raison. Les notes que vous insérez puis annulez ne sont pas comptées.
- **Rechercher et remplacer** et le volet **Orthographe** (F7) parcourent le texte du document, et non ses notes.

## Annuler

**Annuler** (Ctrl+Z) rétablit la dernière modification effectuée, quel que soit son emplacement : dans le texte, dans un en-tête ou un pied de page, ou dans une note. Si elle concernait une note de bas de page, JeffWrite place le point d'insertion à cet endroit pour vous le montrer. **Rétablir** la refait.
