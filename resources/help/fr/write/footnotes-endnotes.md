# Notes de bas de page et notes de fin

<!-- keywords: marque personnalisée, sous le texte, colonnes, symbole, note de bas de page, note de fin, note, notes, renvoi, référence, citation, source, insérer une note de bas de page, insérer une note de fin, onglet Références, numéro, bas de page, fin du document, légende, Ctrl+Alt+F, Ctrl+Alt+D, format de numérotation, commencer à, recommencer, convertir, permuter, séparateur, avis de suite, numérotation, emplacement, chiffres romains, lettres, symboles, options des notes de bas de page et de fin -->

Une **note** apporte des précisions sur certains mots sans interrompre la phrase. Un petit chiffre en exposant dans le texte, appelé **appel de note**, renvoie à la note correspondante. Une **note de bas de page** est placée au bas de la page qui contient son appel. Une **note de fin** est placée après le dernier texte du document, ou à la fin d'une section lorsque le fichier le demande.

## Ajouter une note de bas de page

1. Cliquez à l'endroit où l'appel de note doit apparaître, juste après les mots que la note concerne.
2. Cliquez sur **Références > Insérer une note de bas de page**, ou appuyez sur **Ctrl+Alt+F**.

JeffWrite insère l'appel de note dans le texte et une nouvelle note au bas de la page, portant le même numéro. Le curseur se place dans la note, pour que vous puissiez saisir votre texte immédiatement.

Les notes sont numérotées dans l'ordre de leurs appels dans le texte. Si vous ajoutez une note de bas de page avant d'autres, chaque note suivante passe au numéro suivant, et l'appel dans le texte affiche également le nouveau numéro.

## Utiliser une marque personnalisée

Ouvrez la boîte de dialogue depuis **Références > Note de bas de page et note de fin**, et regardez **Nouvelle note** en bas. Choisissez **Note de bas de page** ou **Note de fin**, saisissez une marque telle que \* ou †† dans **Marque personnalisée** (ou cliquez sur **Symbole...** pour en choisir une), puis cliquez sur **Insérer**. L'appel dans le texte et la note commencent alors par votre marque au lieu d'un numéro. Une note ayant sa propre marque ne reçoit pas de numéro, et les notes qui suivent ne sont pas comptées différemment. Si **Marque personnalisée** reste vide, **Insérer** numérote la note normalement. L'insertion se fait en une seule étape : **Annuler** retire ensemble l'appel, la marque et la note.

## Ajouter une note de fin

Cliquez à l'endroit où l'appel de note doit apparaître, puis cliquez sur **Références > Insérer une note de fin**, ou appuyez sur **Ctrl+Alt+D**. JeffWrite insère l'appel dans le texte et une nouvelle note de fin après le dernier texte, avec son numéro, et le curseur se place dans cette note. Les notes de fin ont leur propre numérotation, selon le style demandé par le fichier.

## Modifier la numérotation des notes

Cliquez sur la petite flèche dans le coin du groupe **Notes de bas de page** de l'onglet **Références**. La boîte de dialogue comporte une partie pour les notes de bas de page et une partie pour les notes de fin :

- **Format de nombre** définit l'apparence des numéros : 1, 2, 3 ; a, b, c ; A, B, C ; i, ii, iii ; I, II, III ; ou les marques \*, †, ‡, §.
- **Commencer à** est le numéro de la première note. Si vous choisissez 3 et le format i, ii, iii, la première note affiche iii.
- **Numérotation** indique quand les numéros recommencent : jamais (**Continue**), à chaque nouvelle section ou, pour les notes de bas de page, en haut de chaque page.
- **Emplacement** indique où sont placées les notes. Pour les notes de bas de page, **Bas de page** les place au pied de la page, et **Sous le texte** les place juste après la dernière ligne de texte de la page, de sorte qu'une page courte a ses notes près des mots. Pour les notes de fin, elles sont placées à la fin de chaque section ou à la fin du document.
- **Colonnes** (notes de bas de page uniquement) place les notes de bas de page sur deux colonnes ou plus, côte à côte, au pied de la page. Chaque note reste entière dans une colonne, et une note trop haute pour sa colonne n'est pas coupée.

Les notes de bas de page et les notes de fin changent immédiatement, et un seul **Annuler** annule la modification, avec les marques et les notes telles qu'elles étaient. La modification est enregistrée avec le fichier, de sorte que les autres logiciels affichent les mêmes numéros.

## Transformer des notes de bas de page en notes de fin, ou inversement

Cliquez sur **Références > Convertir...** (un petit bouton à côté des boutons de notes). La boîte propose quatre choix :

- **Convertir toutes les notes de bas de page en notes de fin**
- **Convertir toutes les notes de fin en notes de bas de page**
- **Permuter les notes de bas de page et les notes de fin** : chaque note de bas de page devient une note de fin, et chaque note de fin devient une note de bas de page.
- **Convertir cette note** : ce choix est actif lorsque le curseur se trouve dans une note, et il ne modifie que celle-ci.

Le texte de chaque note le suit. Chaque note prend l'apparence de son nouveau type, et les notes sont à nouveau numérotées. C'est une seule étape : **Annuler** rétablit toutes les notes.

## Modifier le trait au-dessus des notes

Une note comporte trois éléments qui ne sont pas du texte :

- Le **séparateur** est le trait entre le texte et les notes.
- Le **séparateur de suite** est le trait au-dessus d'une note qui se poursuit depuis la page précédente.
- L'**avis de suite** est le texte placé sous une note qui se poursuit sur la page suivante, par exemple « Suite page suivante ».

Cliquez sur **Références > Séparateurs...**. Pour chaque élément, choisissez **Trait**, **Texte** (et saisissez le texte) ou **Aucun**. Les notes de fin n'ont que le séparateur, car elles ne sont pas coupées au bas d'une page ; les deux autres éléments qu'un fichier peut contenir pour une note de fin sont conservés tels quels. Un élément qui contient plus qu'un trait ou quelques mots, par exemple une image, affiche **Selon le fichier**, et JeffWrite le conserve tel quel. La boîte de dialogue exige au moins une note du type concerné. Lorsque vous modifiez un élément d'une note de fin, JeffWrite relit le document, comme pour la numérotation, et la liste d'**Annuler** repart de zéro.

## Modifier une note

Cliquez dans le texte d'une note au bas de la page, ou après le dernier texte pour une note de fin. Le curseur s'y place. Saisissez, sélectionnez, coupez, copiez, collez et modifiez la mise en forme des mots comme dans le texte, et choisissez un style pour son paragraphe : le paragraphe reste une partie de la note. Une note peut comporter plusieurs paragraphes.

Deux éléments d'une note ne sont pas du texte, et aucune modification ne peut les changer : le numéro qui commence la note, et le court trait au-dessus des notes. Si vous appuyez sur **Retour arrière** juste après le numéro, rien ne se passe. Une sélection qui passerait d'une note à une autre s'arrête à la fin de la note où vous l'avez commencée.

Pour quitter une note, appuyez sur **Échap**, appuyez sur **Haut** à sa première ligne ou sur **Bas** à sa dernière ligne, ou cliquez dans le texte de la page. Le curseur revient dans le texte, juste après l'appel de la note. Une note longue peut se poursuivre au bas de la page suivante ; les touches de direction passent d'une partie à l'autre, et la note n'est quittée qu'à sa toute première et sa toute dernière ligne. Une note qui possède deux appels est présente sur les deux pages, et c'est la page sur laquelle vous avez cliqué qui détermine l'endroit où vous la modifiez.

## Supprimer ou déplacer une note

- Supprimez un appel, et sa note disparaît avec lui. Les notes qui suivent sont à nouveau numérotées. **Annuler** rétablit les deux.
- Coupez un appel et collez-le ailleurs : sa note le suit.
- Copiez un appel et collez-le : vous obtenez une seconde note avec le même texte, que vous pouvez modifier indépendamment.
- Certains fichiers comportent deux appels vers une même note. Supprimez-en un, et la note reste. Supprimez le dernier, et la note disparaît.

## Ce que JeffWrite conserve

- Une partie du fichier que vous n'avez pas modifiée est enregistrée exactement comme elle était. Lorsque vous modifiez une note, seules les notes modifiées sont réécrites, et tout élément qu'elles contiennent et que JeffWrite ne peut pas modifier (image, signet, lien, champ) reste à sa place.
- Le trait au-dessus des notes, et le trait au-dessus d'une note qui se poursuit depuis la page précédente, sont conservés tels que le fichier les contient, jusqu'à ce que vous les modifiiez dans **Séparateurs de notes**.
- Si le fichier ne contient aucune note, la première que vous ajoutez crée aussi ce dont une partie des notes a besoin, pour que les autres logiciels ouvrent le fichier sans message.
- Une note reste dans le fichier tant qu'un élément la cite : le texte, un en-tête ou un pied de page, une zone de texte ou une autre note. Lorsque le dernier élément la libère, la note disparaît.
- Un document peut contenir jusqu'à 5 000 notes de chaque type citées dans son texte. Lorsqu'il en atteint le nombre, **Insérer une note de bas de page** et **Insérer une note de fin** sont désactivées, et la barre d'état l'indique. Les notes insérées puis annulées ne sont pas comptées.
- **Rechercher et remplacer** et le volet **Orthographe** (F7) parcourent aussi les notes. Le volet Orthographe ouvre une note de bas de page pour y montrer un mot, et un mot figurant dans une note de fin peut être ignoré ou ajouté, mais non modifié.

## Annuler

**Annuler** (Ctrl+Z) rétablit la dernière modification effectuée, où qu'elle se trouve : dans le texte, dans un en-tête ou un pied de page, ou dans une note. Si elle concernait une note de bas de page, JeffWrite place le curseur à cet endroit pour vous le montrer. **Rétablir** l'applique à nouveau.
