# Table des matières
<!-- keywords: table des matières, TDM, sommaire, titres, mettre à jour la table, supprimer la table, numéros de page, points de suite, liens hypertexte, F9 -->

Une **table des matières** répertorie vos titres avec la page sur laquelle se trouve chacun d'eux. JeffWrite la crée à partir des paragraphes qui utilisent les styles de titre.

## Insérer une table des matières

1. Appliquez à vos titres les styles **Titre 1**, **Titre 2**, etc.
2. Cliquez à l'endroit où placer la table.
3. Cliquez sur **Références > Table des matières**.
4. Choisissez le nombre de niveaux à afficher, si les numéros de page s'affichent et sont alignés à droite, les points ou traits qui les précèdent (les **points de suite**), et si chaque ligne est un lien. Cliquez sur **OK**.

Par exemple, avec 2 niveaux, un document comportant les titres `Introduction` (Titre 1) et `Contexte` (Titre 2) obtient deux lignes, chacune avec son numéro de page, la seconde légèrement en retrait.

## Mettre à jour la table

Cliquez dans la table et appuyez sur **F9**, ou cliquez sur **Références > Mettre à jour la table**. Choisissez :

- **Mettre à jour les numéros de page uniquement** si vous n'avez modifié aucun titre.
- **Mettre à jour toute la table** si vous avez ajouté, supprimé ou renommé des titres.

La mise à jour est une seule étape, que la commande **Annuler** permet d'annuler.

## Une table très longue

Une table contient jusqu'à 20 000 lignes. Si votre document comporte davantage de titres, la table s'arrête à cette limite, et JeffWrite vous en informe lorsqu'il crée ou met à jour la table.

## Supprimer la table

Cliquez dans la table, puis cliquez sur **Références > Supprimer la table des matières**.

## Suivre une ligne

Si les lignes sont des liens, maintenez la touche **Ctrl** enfoncée et cliquez sur l'une d'elles pour atteindre le titre correspondant.

## Modifier l'apparence des lignes

Les lignes utilisent les styles **TM 1** à **TM 9**. Modifiez l'un d'eux dans le volet Styles, puis mettez à jour toute la table.
