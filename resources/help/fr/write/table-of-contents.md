# Table des matières

<!-- keywords: table des matières, sommaire, TOC, titres, mettre à jour la table, supprimer la table, numéros de page, points de suite, liens hypertexte, F9, galerie, table automatique, table manuelle, marquer l'entrée, champ TC, ajouter du texte, Alt+Maj+O -->

Une **table des matières** répertorie vos titres avec la page sur laquelle se trouve chacun d'eux. JeffWrite la crée à partir des paragraphes qui utilisent les styles de titre.

## Insérer une table des matières

1. Attribuez aux titres les styles **Titre 1**, **Titre 2**, et ainsi de suite.
2. Cliquez à l'endroit où la table doit apparaître.
3. Cliquez sur **Références > Table des matières**.
4. Choisissez le nombre de niveaux à afficher, si les numéros de page apparaissent et s'alignent à droite, les points ou traits qui les précèdent (les **points de suite**), et si chaque ligne est un lien. Cliquez sur **OK**.

Par exemple, avec 2 niveaux, un document comportant les titres `Introduction` (Titre 1) et `Contexte` (Titre 2) obtient deux lignes, chacune avec son numéro de page, la seconde étant un peu plus en retrait.

## Choisir une table prédéfinie

Cliquez sur la petite flèche de **Références > Table des matières** pour ouvrir la galerie :

- **Sommaire** affiche le titre « Sommaire » au-dessus d'une table créée à partir de vos titres.
- **Table des matières avec titre complet** affiche le titre « Table des matières » au-dessus d'une table créée à partir de vos titres.
- **Table des matières à compléter** contient des lignes de texte fictif que vous remplacez en tapant par-dessus. Elle n'est pas mise à jour.
- **Table des matières...** ouvre la boîte décrite ci-dessus, pour effectuer vous-même les choix souhaités.
- **Supprimer la table des matières** supprime la table.

## Ajouter une ligne pour des mots qui ne sont pas un titre

1. Sélectionnez les mots, ou cliquez à l'endroit que la ligne doit désigner.
2. Cliquez sur **Références > Marquer l'entrée**, ou appuyez sur **Alt+Maj+O**.
3. Tapez le texte de la ligne, choisissez son niveau (de 1 à 9), puis cliquez sur **OK**.
4. Lorsque vous insérez la table, activez **Inclure les entrées marquées avec Marquer l'entrée**.

Marquer l'entrée insère dans votre texte un **champ d'entrée de table** masqué (un champ TC). Une table qui inclut les entrées affiche le texte de chaque champ au niveau du champ, dans l'ordre du texte, avec sa page. Une lettre saisie dans **Identificateur de table** permet de distinguer deux ensembles : une table qui demande la lettre C ne répertorie que les entrées marquées C. Activez **Ignorer le numéro de page** pour une ligne qui ne doit pas en afficher.

## Transformer un paragraphe en titre

Cliquez dans le paragraphe, puis cliquez sur **Références > Ajouter du texte** et choisissez **Niveau 1**, **Niveau 2** ou **Niveau 3**. Le paragraphe reçoit le style Titre 1, 2 ou 3, de sorte que la table le répertorie. **Ne pas afficher dans la table des matières** rétablit le style de corps de texte habituel du paragraphe.

## Mettre à jour la table

Cliquez à l'intérieur de la table et appuyez sur **F9**, ou cliquez sur **Références > Mettre à jour la table**. Choisissez :

- **Mettre à jour les numéros de page uniquement** lorsque vous n'avez modifié aucun titre.
- **Mettre à jour toute la table** lorsque vous avez ajouté, supprimé ou renommé des titres.

La mise à jour est une seule action que **Annuler** permet de rétablir.

## Une table très longue

Une table peut comporter jusqu'à 20 000 lignes. Si votre document contient davantage de titres, la table s'arrête à cette limite, et JeffWrite vous en avertit lorsqu'il crée ou met à jour la table.

## Supprimer la table

Cliquez à l'intérieur de la table, puis cliquez sur **Références > Supprimer la table des matières**.

## Suivre une ligne

Si les lignes sont des liens, maintenez **Ctrl** enfoncé et cliquez sur l'une d'elles pour atteindre son titre.

## Modifier l'apparence des lignes

Les lignes utilisent les styles **TOC 1** à **TOC 9**. Modifiez l'un d'eux dans le volet Styles, puis mettez à jour toute la table.
