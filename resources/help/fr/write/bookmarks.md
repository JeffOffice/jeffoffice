# Signets
<!-- keywords: signet, signets, atteindre, aller à, marquer un emplacement, supprimer un signet, signets masqués, Ctrl+Maj+F5 -->

Un **signet** donne un nom à un emplacement ou à un passage de texte, pour que vous puissiez y accéder directement ou y faire référence à partir d'un renvoi.

## Ajouter un signet

1. Sélectionnez le texte à marquer, ou cliquez à l'endroit où placer la marque.
2. Cliquez sur **Insertion > Signet**, ou appuyez sur **Ctrl+Maj+F5**.
3. Tapez un nom. Il doit commencer par une lettre et peut contenir des lettres, des chiffres et des traits de soulignement, mais pas d'espaces. Il peut comporter jusqu'à 40 caractères.
4. Cliquez sur **Ajouter**.

Si vous ajoutez un nom déjà utilisé, le signet est déplacé vers le nouvel emplacement.

## Atteindre ou supprimer un signet

Ouvrez la boîte de dialogue **Signet**, choisissez le nom dans la liste, puis cliquez sur **Atteindre**, ou double-cliquez sur le nom. Cliquez sur **Supprimer** pour supprimer le signet. Le texte est conservé.

Utilisez **Trier par** pour afficher les noms dans l'ordre alphabétique ou dans l'ordre où ils apparaissent dans le texte. Cochez **Signets masqués** pour voir ceux que JeffWrite et d'autres programmes créent pour leur propre usage, dont le nom commence par un trait de soulignement.

## Exemple

Sélectionnez les mots `Quarterly results`, appuyez sur **Ctrl+Maj+F5**, tapez `results`, puis cliquez sur **Ajouter**. Plus tard, ouvrez **Références > Renvoi**, choisissez **Signet**, puis insérez **Numéro de page** pour `results`. Le texte affiche la page où se trouve le signet.
