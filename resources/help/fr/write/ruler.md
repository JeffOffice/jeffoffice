# Utiliser la règle
<!-- keywords: règle, retrait, retraits, retrait de première ligne, retrait négatif, retrait gauche, retrait droit, tabulation, taquet de tabulation, taquets de tabulation, marge, marges, faire glisser, unités, pouces, centimètres, afficher la règle, masquer la règle -->

La **règle** située au-dessus des pages affiche les marges, les retraits du paragraphe dans lequel se trouve le curseur et ses taquets de tabulation. Faites glisser un marqueur pour le modifier. **Affichage > Règle** affiche ou masque la règle.

La partie blanche de la règle correspond à la zone de texte de la page où se trouve le curseur ; les extrémités grises correspondent aux marges de gauche et de droite. Les graduations partent de la marge de gauche, dans l'unité définie dans Fichier > Options (pouces, centimètres, millimètres, points ou picas).

## Retraits

- Le **retrait de première ligne** est le marqueur du haut. Faites-le glisser pour déplacer la première ligne du paragraphe.
- Le **retrait négatif** est le triangle du bas. Faites-le glisser pour déplacer toutes les lignes sauf la première.
- Le **retrait gauche** est le petit carré situé sous le triangle. Faites-le glisser pour déplacer ensemble la première ligne et les autres lignes.
- Le **retrait droit** est le triangle situé à l'extrémité droite.

Si plusieurs paragraphes sont sélectionnés, chacun se déplace de la même distance. Maintenez la touche **Alt** enfoncée pendant le glissement pour un déplacement plus précis ; sinon, les marqueurs s'alignent sur les graduations de la règle.

## Taquets de tabulation

La case située à l'extrémité gauche de la règle indique le type de taquet de tabulation qu'ajoute un clic : **gauche**, **centré**, **droite** ou **décimal**. Cliquez sur cette case pour changer de type.

- Cliquez sur la règle pour ajouter un taquet de tabulation de ce type.
- Faites glisser un taquet de tabulation pour le déplacer. Ses points de suite (les points ou le trait qui remplissent l'espace qui le précède) se déplacent avec lui.
- Faites glisser un taquet de tabulation vers le haut ou vers le bas hors de la règle pour le supprimer.

Un paragraphe peut comporter jusqu'à 64 taquets de tabulation.

## Marges

Faites glisser la limite entre la marge grise et la zone de texte blanche pour modifier la **marge de gauche** ou la **marge de droite** de la section dans laquelle se trouve le curseur. Le texte et les retraits se déplacent avec elle.

Chaque modification effectuée sur la règle peut être annulée en une seule étape.
