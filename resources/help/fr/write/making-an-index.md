# Créer un index

<!-- keywords: index, marquer une entrée, marquer tout, sous-entrée, renvoi, voir, XE, INDEX, plage de pages, numéro de page en gras, colonnes, entrée intégrée, lettres d'en-tête, Alt+Maj+X, mettre à jour l'index -->

Un **index** est une liste alphabétique de mots et de notions, accompagnée des pages où ils se trouvent. Vous commencez par **marquer** les mots à faire figurer dans l'index, puis vous **insérez** l'index.

## Marquer une entrée

1. Sélectionnez le ou les mots à répertorier, ou cliquez à l'endroit où l'entrée doit pointer.
2. Cliquez sur **Références > Marquer l'entrée**, ou appuyez sur **Alt+Maj+X**.
3. Vérifiez l'**Entrée principale**. Saisissez une **Sous-entrée** si l'entrée comporte une partie qui lui est subordonnée. Par exemple, l'entrée principale `Pommes` avec la sous-entrée `Fuji`.
4. Choisissez ce qu'affiche le numéro de page :
   - **Page active** répertorie la page où se trouve la marque.
   - **Plage de pages** répertorie les pages couvertes par un signet, par exemple 5-7.
   - **Renvoi** répertorie des mots au lieu d'une page, par exemple « Voir Fruits ».
5. Activez **Numéro de page en gras** ou **Numéro de page en italique** si le numéro doit ressortir.
6. Cliquez sur **Marquer** pour marquer cet emplacement, ou sur **Marquer tout** pour marquer chaque emplacement où apparaissent les mêmes mots (avec les mêmes majuscules).

Une marque est un **champ d'entrée d'index** (champ XE) masqué. Elle n'affiche rien sur la page.

## Insérer l'index

1. Cliquez à l'endroit où l'index doit apparaître.
2. Cliquez sur **Références > Insérer un index**.
3. Choisissez la présentation : **En retrait** place chaque sous-entrée sur sa propre ligne, et **Entrée intégrée** place les sous-entrées après l'entrée, sur une même ligne. Choisissez si les numéros de page doivent être **alignés à droite**, le **caractère** des points de suite, et si une lettre doit en-tête chaque groupe.
4. Cliquez sur **OK**.

L'index répertorie les entrées par ordre alphabétique. Les numéros de page d'une même entrée sont listés une seule fois chacun, dans l'ordre des pages, séparés par des virgules.

## Mettre l'index à jour

Cliquez dans l'index, puis cliquez sur **Références > Mettre à jour l'index**, ou appuyez sur **F9**. Les marques que vous avez ajoutées sont répertoriées, les marques supprimées disparaissent, et les pages sont recalculées.
