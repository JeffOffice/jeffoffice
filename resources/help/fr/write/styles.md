# Utiliser les styles

Un **style** est un ensemble d'aspects enregistrés : une police, une taille, un espacement, et plus encore. Lorsque vous appliquez un style à un paragraphe, celui-ci prend tous ces aspects en une seule fois. Si vous modifiez le style, chaque paragraphe qui l'utilise change également. C'est pourquoi les styles gardent les longs documents bien ordonnés.

JeffWrite propose deux types de styles :

- Un **style de paragraphe** définit l'aspect de paragraphes entiers. **Titre 1** et **Normal** sont des styles de paragraphe.
- Un **style de caractère** définit l'aspect des mots que vous sélectionnez. **Forte** est un style de caractère.

## Appliquer un style à votre texte

1. Cliquez dans un paragraphe, ou sélectionnez les mots à modifier.
2. Cliquez sur un style dans la galerie **Styles** de l'onglet **Accueil**. Vous pouvez aussi appuyer sur **Ctrl+Maj+N** pour Normal, ou sur **Ctrl+Alt+1**, **Ctrl+Alt+2** ou **Ctrl+Alt+3** pour Titre 1, 2 ou 3.

Un style de paragraphe s'applique à chaque paragraphe que vous touchez. Un style de caractère s'applique aux mots sélectionnés.

## Ouvrir le volet Styles

Cliquez sur la petite flèche dans le coin du groupe **Styles**, ou appuyez sur **Ctrl+Alt+Maj+S**. Le volet **Styles** s'ouvre à droite. Il affiche les styles de votre document, chacun dans son propre aspect.

- Le style situé à votre curseur est en gras, avec une flèche devant son nom.
- Cliquez sur un style pour l'appliquer à votre sélection.
- Utilisez la liste sous les styles pour choisir ceux à afficher :
  - **En cours d'utilisation** n'affiche que les styles utilisés dans votre texte.
  - **Tous les styles** affiche tous les styles, y compris ceux que votre document ne contient pas encore. Un style est ajouté au document la première fois que vous l'utilisez.
  - **Recommandés** affiche les styles destinés à être visibles. Un style masqué tant qu'il n'est pas utilisé apparaît ici dès que vous l'utilisez.
- Cliquez sur **Gérer…** sous la liste pour choisir, pour chaque style, s'il est **Recommandé** (affiché dans la galerie), s'il est **Masqué** (exclu de toutes les listes) et son **Ordre dans les listes**. Un numéro plus bas apparaît en premier. Cliquez sur **OK** : toutes les modifications sont appliquées en une seule fois, si bien qu'un seul **Annuler** les rétablit.
- Dans **Gérer…**, cliquez sur **Supprimer** pour retirer un style que vous avez créé. Les paragraphes qui l'utilisaient reviennent à Normal, et les styles qui étaient basés sur lui se basent sur ce qu'il était lui-même basé. Les styles fournis avec JeffWrite ne peuvent pas être supprimés. La suppression se fait en une seule étape : **Annuler** rétablit le style.
- Dans **Gérer…**, cliquez sur **Importer depuis un fichier…** pour copier des styles d'un autre document. Choisissez le fichier, cochez les styles souhaités, puis cliquez sur **OK**. Un style qui en nécessite un autre l'apporte avec lui. Les styles que vous possédez déjà sont conservés, sauf si vous cochez **Remplacer les styles portant le même nom**. L'importation s'annule en une seule étape.
- Dans **Gérer…**, cliquez sur **Exporter vers un fichier…** pour enregistrer certains de vos styles dans un fichier modèle (un fichier **.dotx**). Cochez les styles souhaités, cliquez sur **OK**, puis choisissez où enregistrer le fichier. Un autre document peut les récupérer depuis ce fichier avec **Importer depuis un fichier…**. Un style qui en nécessite un autre l'apporte avec lui.
- Cochez **Verrouillé** pour verrouiller un style. Cochez ensuite **Limiter la mise en forme aux styles non verrouillés** pour activer la limitation. Tant qu'elle est active, personne ne peut mettre en forme le texte manuellement, par exemple avec **Gras** ou **Centrer**, ni utiliser un style verrouillé. Les autres styles restent disponibles. La barre d'état l'indique lorsqu'une commande est refusée. Décochez la case pour désactiver la limitation. Si le document est protégé par un mot de passe, arrêtez d'abord cette protection dans **Révision > Restreindre la modification**. La limitation et les verrouillages sont enregistrés dans le fichier.
- Sous la liste, la zone **Trier** classe les styles. **Alphabétique** trie par nom. **Selon les recommandations** place en premier les styles les plus utiles. **Par type** affiche les styles de paragraphe, puis les styles liés, puis les styles de caractère. **Basé sur** regroupe chaque style avec le style sur lequel il est construit.

## Créer un style à partir de votre texte

1. Mettez en forme un paragraphe comme vous le souhaitez. Par exemple, mettez-le en gras, centrez-le et réglez la taille.
2. Cliquez sur **Nouveau style** en bas du volet, ou cliquez sur **Créer un style** dans l'onglet **Accueil**.
3. Saisissez un **Nom**. Un nom peut comporter jusqu'à 255 caractères, et il ne peut pas être identique au nom d'un autre style.
4. Vérifiez les autres choix, puis cliquez sur **OK**.

Le **Type de style** peut être **Paragraphe**, **Caractère** ou **Lié**. Un style lié est un style de paragraphe associé à un style de caractère de même aspect (portant le nom du style de paragraphe, auquel on ajoute « Car »). Ainsi, l'aspect peut être appliqué à un paragraphe entier ou seulement à certains mots. Lorsque vous modifiez plus tard le style de paragraphe, son style de caractère adopte lui aussi le nouvel aspect.

**Disponible dans** permet de choisir **Dans ce document uniquement** ou **Nouveaux documents basés sur ce modèle**. Avec le second choix, le style est également enregistré dans le modèle à partir duquel les nouveaux documents sont créés.

Le nouveau style est enregistré avec votre document, et votre paragraphe l'adopte. Un seul **Annuler** (Ctrl+Z) supprime le style.

## Modifier un style

1. Cliquez dans un paragraphe qui utilise le style, ou cliquez sur le style dans le volet.
2. Cliquez sur **Modifier** en bas du volet, ou cliquez sur **Modifier le style** dans l'onglet **Accueil**.
3. Modifiez ce que vous souhaitez, puis cliquez sur **OK**.

La boîte de dialogue propose les options suivantes :

- **Nom** est le nom du style. Un style fourni avec JeffWrite conserve son nom.
- **Basé sur** est le style dont celui-ci part. Le nouveau style ressemble à ce style, sauf pour ce que vous modifiez. Si vous modifiez plus tard le style de base, celui-ci suit la modification.
- **Style du paragraphe suivant** est le style qu'obtient le paragraphe suivant lorsque vous appuyez sur **Entrée** à la fin de celui-ci. Un titre est généralement suivi de Normal.
- **Police**, **taille**, **Gras**, **Italique**, **Souligné** et **couleur** définissent l'aspect des mots.
- **Alignement**, **retraits**, **espacement** et **interligne** définissent l'aspect des paragraphes.
- **Ajouter à la galerie de styles** place le style dans la galerie de l'onglet **Accueil**.
- **Mise à jour automatique** fait suivre au style votre mise en forme. Lorsque vous modifiez un paragraphe qui utilise ce style, le style change en conséquence, ainsi que tous les autres paragraphes qui l'utilisent.

Lorsque vous modifiez un style, les paragraphes qui l'utilisent changent. Si vous avez donné à un paragraphe un aspect propre, comme un mot en rouge, il conserve cet aspect.

Si vous cliquez sur **OK** sans rien modifier, le document reste inchangé.

## Mettre un style à jour selon votre texte

Mettez un paragraphe en forme comme vous le souhaitez. Cliquez ensuite sur **Mettre à jour le style pour correspondre à la sélection** dans l'onglet **Accueil**. Le style de ce paragraphe reprend les modifications que vous avez faites, et chaque paragraphe qui utilise ce style les suit.

## Enregistrer une liste comme style de liste

Un **style de liste** est une liste numérotée ou à puces portant un nom. Il conserve les neuf niveaux : la numérotation ou la puce de chaque niveau, son texte, sa valeur de départ et la position du texte.

1. Cliquez sur **Liste à plusieurs niveaux** dans l'onglet **Accueil**, puis sur **Définir une nouvelle liste à plusieurs niveaux…**.
2. Réglez les niveaux comme vous le souhaitez.
3. Cochez **Enregistrer comme style de liste** et saisissez un nom. Si le nom est vide ou déjà utilisé, la zone l'indique et reste ouverte.
4. Cliquez sur **OK**. Les paragraphes sélectionnés adoptent le style de liste.

Le style de liste apparaît désormais à deux endroits : sous **Styles de liste** dans la galerie **Liste à plusieurs niveaux** (les 100 premiers), et dans le volet **Styles** (tous). Sélectionnez des paragraphes et cliquez sur son nom pour leur appliquer le style de liste.

- **Le modifier.** Cliquez sur **Liste à plusieurs niveaux**, puis sur **Modifier le style de liste**, et sur le nom ; ou choisissez le style de liste dans le volet **Styles** et cliquez sur **Modifier…**. Chaque paragraphe qui utilise le style de liste change avec lui, dans le texte comme dans les en-têtes, les pieds de page et les notes. Dans le texte, la modification se fait en une seule étape : un seul **Annuler** la rétablit.
- **Le supprimer.** Cliquez sur **Liste à plusieurs niveaux**, sur **Supprimer le style de liste**, puis sur le nom. Les paragraphes conservent leur numérotation et leurs puces exactement telles qu'elles apparaissent. Ils ne suivent simplement plus de style.
- **L'enregistrer dans un fichier.** Un style de liste est conservé dans un fichier `.docx` sous forme de style de numérotation, et dans un fichier `.odt` sous forme de style de liste. Il est restauré comme style de liste lorsque vous rouvrez le fichier. Un fichier peut contenir jusqu'à 1 000 styles de liste ; les autres sont utilisés comme listes simples.

Un niveau peut toujours être lié à un style de paragraphe, comme dans toute liste à plusieurs niveaux. Le style de paragraphe est alors numéroté par le style de liste, et **Modifier le style de liste** affiche ce lien pour que vous puissiez le changer.

Si la zone n'a aucune liste à associer au style (par exemple, si le texte sélectionné est verrouillé), aucun style de liste n'est enregistré, et un message l'indique.
