# Utiliser les styles
<!-- keywords: styles, style, volet Styles, titre, normal, créer un style, nouveau style, modifier le style, changer de style, basé sur, style suivant, mettre à jour automatiquement, galerie, style de caractère, style de paragraphe, ctrl+alt+maj+s -->

Un **style** est un ensemble de mises en forme enregistré : une police, une taille, un espacement, etc. Lorsque vous appliquez un style à un paragraphe, celui-ci prend toutes ces mises en forme d'un coup. Lorsque vous modifiez le style, tous les paragraphes qui l'utilisent changent aussi. C'est pourquoi les styles permettent de garder les longs documents bien ordonnés.

JeffWrite propose deux types de styles :

- Un **style de paragraphe** définit l'apparence de paragraphes entiers. **Titre 1** et **Normal** sont des styles de paragraphe.
- Un **style de caractère** définit l'apparence des mots que vous sélectionnez. **Gras** est un style de caractère.

## Appliquer un style à votre texte

1. Cliquez dans un paragraphe, ou sélectionnez les mots à modifier.
2. Cliquez sur un style dans la galerie **Styles** de l'onglet **Accueil**. Vous pouvez aussi appuyer sur **Ctrl+Maj+N** pour Normal, ou sur **Ctrl+Alt+1**, **Ctrl+Alt+2** ou **Ctrl+Alt+3** pour Titre 1, 2 ou 3.

Un style de paragraphe s'applique à tous les paragraphes concernés par la sélection. Un style de caractère s'applique aux mots sélectionnés.

## Ouvrir le volet Styles

Cliquez sur la petite flèche dans le coin du groupe **Styles**, ou appuyez sur **Ctrl+Alt+Maj+S**. Le volet **Styles** s'ouvre à droite. Il répertorie les styles de votre document, chacun affiché avec sa propre apparence.

- Le style à l'emplacement du curseur apparaît en gras, précédé d'une flèche.
- Cliquez sur un style pour l'appliquer à votre sélection.
- Utilisez la liste située sous les styles pour choisir ceux à afficher :
  - **En cours d'utilisation** n'affiche que les styles utilisés par votre texte.
  - **Tous les styles** affiche tous les styles, y compris ceux que votre document ne contient pas encore. Un style est ajouté au document la première fois que vous l'utilisez.
  - **Recommandés** affiche les styles destinés à être visibles. Un style masqué jusqu'à son utilisation apparaît ici dès que vous l'utilisez.

## Créer un style à partir de votre texte

1. Mettez en forme un paragraphe comme vous le souhaitez. Par exemple, mettez-le en gras, centrez-le et définissez la taille.
2. Cliquez sur **Nouveau style** en bas du volet, ou sur **Créer un style** dans l'onglet **Accueil**.
3. Tapez un **Nom**. Un nom peut comporter jusqu'à 255 caractères et ne peut pas être celui d'un autre style.
4. Vérifiez les autres options, puis cliquez sur **OK**.

Le nouveau style est enregistré avec votre document et appliqué à votre paragraphe. Une seule commande **Annuler** (Ctrl+Z) supprime le style.

## Modifier un style

1. Cliquez dans un paragraphe qui utilise le style, ou cliquez sur le style dans le volet.
2. Cliquez sur **Modifier** en bas du volet, ou sur **Modifier le style** dans l'onglet **Accueil**.
3. Apportez les modifications souhaitées, puis cliquez sur **OK**.

La boîte de dialogue propose les options suivantes :

- **Nom** est le nom du style. Un style fourni avec JeffWrite conserve son nom.
- **Basé sur** est le style de départ. Le nouveau style ressemble à ce style, à l'exception de ce que vous modifiez. Si vous modifiez ensuite le style de base, ce style suit.
- **Style du paragraphe suivant** est le style attribué au paragraphe suivant lorsque vous appuyez sur **Entrée** à la fin de celui-ci. Un titre est généralement suivi du style Normal.
- **Police**, **taille**, **Gras**, **Italique**, **Souligné** et **couleur** définissent l'apparence des mots.
- **Alignement**, **retrait**, **espacement** et **interligne** définissent l'apparence des paragraphes.
- **Ajouter à la galerie de styles** place le style dans la galerie de l'onglet **Accueil**.
- **Mettre à jour automatiquement** fait suivre au style votre mise en forme. Lorsque vous modifiez un paragraphe qui utilise ce style, le style change en conséquence, de même que tous les autres paragraphes qui l'utilisent.

Lorsque vous modifiez un style, les paragraphes qui l'utilisent changent. Si vous avez donné à un paragraphe une mise en forme propre, comme un mot en rouge, il la conserve.

Si vous cliquez sur **OK** sans rien modifier, le document reste inchangé.

## Mettre à jour un style d'après votre texte

Mettez en forme un paragraphe comme vous le souhaitez. Cliquez ensuite sur **Mettre à jour le style pour correspondre à la sélection** dans l'onglet **Accueil**. Le style de ce paragraphe reprend vos modifications, et tous les paragraphes qui utilisent ce style suivent.
