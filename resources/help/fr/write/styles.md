# Utiliser les styles
<!-- keywords: styles, style, volet Styles, titre, normal, créer un style, nouveau style, modifier le style, changer de style, basé sur, style suivant, mise à jour automatique, galerie, style de caractère, style de paragraphe, ctrl+alt+maj+s, mise en forme, modèle de style -->

Un **style** est un ensemble de mises en forme enregistrées : une police, une taille, un espacement, et bien plus encore. Lorsque vous appliquez un style à un paragraphe, celui-ci prend toutes ces mises en forme en une seule fois. Si vous modifiez le style, chaque paragraphe qui l'utilise change lui aussi. C'est pourquoi les styles permettent de garder les longs documents bien ordonnés.

JeffWrite propose deux types de styles :

- Un **style de paragraphe** définit la mise en forme de paragraphes entiers. **Titre 1** et **Normal** sont des styles de paragraphe.
- Un **style de caractère** définit la mise en forme des mots que vous sélectionnez. **Forte** est un style de caractère.

## Appliquer un style à votre texte

1. Cliquez dans un paragraphe, ou sélectionnez les mots que vous voulez modifier.
2. Cliquez sur un style dans la galerie **Styles** de l'onglet **Accueil**. Vous pouvez aussi appuyer sur **Ctrl+Maj+N** pour Normal, ou sur **Ctrl+Alt+1**, **Ctrl+Alt+2** ou **Ctrl+Alt+3** pour Titre 1, 2 ou 3.

Un style de paragraphe est appliqué à chaque paragraphe que vous touchez. Un style de caractère est appliqué aux mots que vous avez sélectionnés.

## Ouvrir le volet Styles

Cliquez sur la petite flèche dans le coin du groupe **Styles**, ou appuyez sur **Ctrl+Alt+Maj+S**. Le volet **Styles** s'ouvre à droite. Il affiche les styles de votre document, chacun dans sa propre mise en forme.

- Le style à l'emplacement de votre curseur est en gras, avec une flèche devant son nom.
- Cliquez sur un style pour l'appliquer à votre sélection.
- Utilisez la liste sous les styles pour choisir ceux à afficher :
  - **Utilisés** n'affiche que les styles utilisés dans votre texte.
  - **Tous les styles** affiche tous les styles, y compris ceux que votre document ne contient pas encore. Un style est ajouté au document la première fois que vous l'utilisez.
  - **Recommandés** affiche les styles destinés à être vus. Un style masqué tant qu'il n'est pas utilisé apparaît ici dès que vous l'utilisez.
- Sous la liste, la zone **Trier** classe les styles. **Alphabétique** les trie par nom. **Recommandé** place en premier les styles les plus utiles. **Par type** affiche les styles de paragraphe, puis les styles liés, puis les styles de caractère. **Basé sur** regroupe chaque style avec le style sur lequel il est construit.

## Créer un style à partir de votre texte

1. Mettez en forme un paragraphe comme vous le souhaitez. Par exemple, mettez-le en gras, centrez-le et définissez la taille.
2. Cliquez sur **Nouveau style** en bas du volet, ou cliquez sur **Créer un style** dans l'onglet **Accueil**.
3. Saisissez un **Nom**. Un nom peut comporter jusqu'à 255 caractères, et il ne peut pas être identique au nom d'un autre style.
4. Vérifiez les autres options, puis cliquez sur **OK**.

Le nouveau style est enregistré avec votre document, et votre paragraphe l'adopte. Un clic sur **Annuler** (Ctrl+Z) supprime le style.

## Modifier un style

1. Cliquez dans un paragraphe qui a ce style. Vous pouvez aussi cliquer sur le style dans le volet.
2. Cliquez sur **Modifier** en bas du volet, ou cliquez sur **Modifier le style** dans l'onglet **Accueil**.
3. Modifiez ce que vous souhaitez, puis cliquez sur **OK**.

La boîte de dialogue propose les options suivantes :

- **Nom** est le nom du style. Un style fourni avec JeffWrite conserve son nom.
- **Basé sur** est le style à partir duquel celui-ci est construit. Le nouveau style ressemble à ce style, sauf pour ce que vous modifiez. Si vous modifiez ensuite le style de base, ce style le suit.
- **Style du paragraphe suivant** est le style que reçoit le paragraphe suivant lorsque vous appuyez sur **Entrée** à la fin de celui-ci. Un titre est généralement suivi de Normal.
- **Police**, **taille**, **Gras**, **Italique**, **Souligné** et **couleur** définissent l'apparence des mots.
- **Alignement**, **retrait**, **espacement** et **interligne** définissent l'apparence des paragraphes.
- **Ajouter à la galerie de styles** place le style dans la galerie de l'onglet **Accueil**.
- **Mettre à jour automatiquement** fait suivre au style votre mise en forme. Lorsque vous modifiez un paragraphe qui a ce style, le style change pour correspondre, et tous les autres paragraphes qui l'utilisent suivent.

Lorsque vous modifiez un style, les paragraphes qui l'utilisent changent. Si vous avez donné à un paragraphe une mise en forme qui lui est propre, comme un mot en rouge, il la conserve.

Si vous cliquez sur **OK** sans rien modifier, le document n'est pas changé.

## Mettre un style à jour selon votre texte

Mettez en forme un paragraphe comme vous le souhaitez. Cliquez ensuite sur **Mettre à jour le style pour correspondre à la sélection** dans l'onglet **Accueil**. Le style de ce paragraphe reprend les modifications que vous avez faites, et chaque paragraphe qui utilise ce style les suit.
