# Citations et bibliographie
<!-- keywords: citation, source, bibliographie, ouvrages cités, références, APA, MLA, Chicago, Harvard, IEEE, gérer les sources, insérer une citation, style de citation, auteur, livre, revue, périodique -->

Une **source** est un livre, un article, une page web ou tout autre document que vous citez ou dont vous vous inspirez. Une **citation** est la courte mention d'une source dans votre texte, par exemple (Smith, 2020). Une **bibliographie** est la liste des sources placée à la fin. JeffWrite conserve vos sources dans une seule liste, rédige pour vous chaque citation et chaque entrée de bibliographie, et met tout à jour lorsque vous changez de style.

## Ajouter une citation

1. Cliquez à l'endroit où la citation doit apparaître.
2. Cliquez sur **Références > Insérer une citation**.
3. Choisissez une source dans la liste, ou cliquez sur **Nouvelle source** pour en créer une.
4. Saisissez les **Pages** si la citation les mentionne. Activez **Omettre l'auteur** ou **Omettre l'année** si la phrase les indique déjà, ou **Afficher le titre**.
5. Cliquez sur **Insérer**.

## Créer une source

Dans la zone Source, choisissez le **type de source**. La zone demande alors les informations propres à ce type : un livre demande un titre, une année, une ville et un éditeur ; un article demande le nom de la revue, le volume, le numéro et les pages. Saisissez chaque auteur sur une ligne, au format `Nom, Prénom Deuxième prénom`. Une société ou un groupe peut être l'auteur, dans **Organisation comme auteur**. Le **nom de balise** est le nom court utilisé par une citation ; JeffWrite en crée un à partir de l'auteur et de l'année, par exemple Smi20.

## Gérer vos sources

Cliquez sur **Références > Gérer les sources**. La boîte de dialogue affiche deux listes :

- La **Liste principale** vous appartient. Chaque document que vous rédigez peut puiser des sources dans cette liste.
- La **Liste actuelle** regroupe les sources de ce document.

Utilisez **Copier** pour déplacer une source d'une liste à l'autre, **Nouvelle** pour créer une source, **Modifier** pour la changer et **Supprimer** pour la retirer. Un aperçu montre comment la source apparaît dans la bibliographie. Les sources créées dans la boîte Insérer une citation sont aussi ajoutées à la liste principale.

## Choisir un style

Cliquez sur **Références > Style de citation**, puis choisissez **APA (6e édition)**, **MLA (7e édition)**, **Chicago (15e édition)**, **Harvard** ou **IEEE**. Les éditions sont indiquées parce que des éditions plus récentes de ces guides existent, et elles ne sont pas intégrées au programme. Chaque citation et chaque bibliographie du document passent à ce style. Avec IEEE, une citation est un numéro entre crochets, par exemple [1], dans l'ordre de la première citation des sources.

## Ajouter la bibliographie

Cliquez à l'endroit où la liste doit apparaître, cliquez sur **Références > Bibliographie**, puis choisissez **Bibliographie**, **Références** ou **Ouvrages cités**. JeffWrite ajoute un titre et la liste des sources que vous avez citées, dans l'ordre. Une source que vous n'avez jamais citée n'apparaît pas dans la liste. Si vous citez d'autres sources plus tard, cliquez dans la liste et appuyez sur **F9** pour la générer à nouveau.

## Ce qui est enregistré

Vos sources sont enregistrées dans le fichier, sous une forme que les autres traitements de texte peuvent lire. Un fichier ouvert conserve ses sources telles quelles tant que vous ne les modifiez pas.
