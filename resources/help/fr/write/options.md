Vos paramètres se trouvent dans la fenêtre **Options de JeffWrite**. Cliquez sur **Fichier > Options** pour l'ouvrir. Cliquez sur **OK** pour conserver vos modifications, ou sur **Annuler** pour les abandonner.

## Statistiques d'utilisation

**Envoyer des statistiques d'utilisation anonymes** vous permet de partager des informations sur la façon dont JeffWrite est utilisé. Anonymes signifie que ces informations ne disent rien de votre identité. Lorsque cette option est activée, JeffWrite envoie ces informations une fois par jour, ainsi que le jour d'une mise à jour : le fait qu'il s'agit de JeffWrite, sa version, votre système d'exploitation et votre langue, le nombre de démarrages, la fréquence d'utilisation de chaque commande et le type de fichier ouvert ou enregistré. Si JeffWrite se ferme de manière inattendue, il envoie également un rapport de plantage au démarrage suivant. JeffWrite n'envoie jamais vos fichiers, leurs noms ni leur contenu, ni rien de ce que vous avez tapé. Si cette option est désactivée, aucun rapport de plantage n'est envoyé non plus.

Ce choix s'applique à toutes les applications JeffOffice : si vous le modifiez ici, il est modifié dans chacune d'elles. JeffWrite vous pose la question lors de son premier démarrage, dans une fenêtre intitulée **Aidez-nous à améliorer JeffWrite**.

- **Déclaration de confidentialité**, à côté de la case à cocher, ouvre notre déclaration de confidentialité sur jeffoffice.com/privacy. Elle indique ce qui est envoyé, où, et pendant combien de temps nous le conservons. Nous conservons les statistiques pendant 24 mois.
- Le **numéro d'installation** est affiché sous la case à cocher. Il s'agit d'un numéro aléatoire créé pour votre copie de JeffOffice, identique dans toutes les applications JeffOffice. Il ne dit rien de vous. Cliquez sur **Copier** pour le copier. Si les statistiques sont désactivées, ou si aucun numéro n'a encore été créé, la mention **aucun** s'affiche.
- Pour faire supprimer les statistiques que nous détenons déjà, envoyez votre numéro d'installation à info@jeffoffice.com **avant** de désactiver les statistiques. La désactivation efface ce numéro de votre ordinateur, et sans lui, nous ne pouvons pas savoir quels enregistrements vous concernent.
- Pour désactiver les statistiques sans ouvrir JeffWrite, attribuez une valeur quelconque à la variable d'environnement `JP_NO_TELEMETRY` avant de le démarrer. Rien n'est alors comptabilisé ni envoyé, et JeffWrite ne pose pas la question du premier démarrage.
