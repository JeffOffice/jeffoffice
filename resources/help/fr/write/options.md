Vos paramètres se trouvent dans la fenêtre **Options de JeffWrite**. Cliquez sur **Fichier > Options** pour l'ouvrir. Cliquez sur **OK** pour conserver vos modifications, ou sur **Annuler** pour les abandonner.

## Enregistrer

La page **Enregistrer** de la fenêtre Options comporte trois choix.

- **Enregistrer les nouveaux documents sous** détermine le type de fichier que **Enregistrer sous** propose en premier pour un document qui n'a pas encore de fichier : un fichier .docx ou un fichier .odt.
- **Enregistrer les informations de récupération automatique toutes les** indique le nombre de minutes qui s'écoulent entre les copies de sauvegarde que JeffWrite conserve du travail non enregistré. Voir [Ouvrir, enregistrer, imprimer et exporter](open-save).
- **Emplacement de fichier par défaut** est le dossier dans lequel s'ouvrent les boîtes **Ouvrir** et **Enregistrer sous**. Cliquez sur **Parcourir** pour le choisir. Laissez ce champ vide pour démarrer dans votre dossier Documents.

## Affichage

La page **Affichage** choisit ce qu'une fenêtre affiche à son ouverture.

- **Afficher les marques de mise en forme** active les marques de paragraphe et les autres signes qui ne sont pas imprimés. Chaque fenêtre peut toujours les activer ou les désactiver avec le bouton **¶**.
- **Afficher le quadrillage des tableaux** dessine les bordures discrètes des cellules de tableau qui n'ont pas de traits.

Une modification sur cette page s'applique immédiatement à la fenêtre active, ainsi qu'à chaque fenêtre ouverte ensuite.

## Options avancées

**Afficher les mesures en** choisit l'unité de la règle et des boîtes de dialogue : pouces, centimètres, millimètres, points ou picas. Un point vaut 1/72 de pouce. Un pica vaut 12 points.

## Statistiques d'utilisation

**Envoyer des statistiques d'utilisation anonymes** vous permet de partager des informations sur la façon dont JeffWrite est utilisé. Anonyme signifie que ces informations ne disent rien sur vous. Lorsque cette option est activée, JeffWrite envoie ces informations une fois par jour, ainsi que le jour de la mise à jour : qu'il s'agit de JeffWrite, sa version, votre système d'exploitation et votre langue, le nombre de fois où il a été démarré, la fréquence d'utilisation de chaque commande, et le type de fichier que vous avez ouvert ou enregistré. Si JeffWrite se ferme brusquement, il envoie également un rapport d'erreur au prochain démarrage. JeffWrite n'envoie jamais vos fichiers, leurs noms ni leur contenu, ni ce que vous avez saisi. Si cette option est désactivée, aucun rapport d'erreur n'est envoyé non plus.

Ce choix concerne l'ensemble des applications JeffOffice : le modifier ici le modifie dans chacune d'elles. JeffWrite vous pose la question la première fois qu'il démarre, dans une fenêtre intitulée **Aidez à améliorer JeffWrite**.

- **Déclaration de confidentialité**, à côté de la case à cocher, ouvre notre déclaration de confidentialité à l'adresse jeffoffice.com/privacy. Elle indique ce qui est envoyé, où cela va et combien de temps nous le conservons. Nous conservons les statistiques pendant 24 mois.
- **Numéro d'installation** est affiché sous la case à cocher. Il s'agit d'un numéro aléatoire généré pour votre copie de JeffOffice, identique dans toutes les applications JeffOffice. Il ne contient aucune information sur vous. Cliquez sur **Copier** pour le copier. Si les statistiques sont désactivées, ou si aucun numéro n'a encore été généré, il indique **aucun**.
- Pour faire supprimer les statistiques que nous détenons déjà, envoyez votre numéro d'installation à info@jeffoffice.com **avant** de désactiver les statistiques. Les désactiver efface le numéro de votre ordinateur, et sans lui nous ne pouvons pas savoir quels enregistrements vous concernent.
- Pour désactiver les statistiques sans ouvrir JeffWrite, définissez la variable d'environnement `JP_NO_TELEMETRY` avec une valeur quelconque avant de le démarrer. Rien n'est alors comptabilisé ni envoyé, et JeffWrite ne pose pas la question du premier démarrage.
