Vos paramètres se trouvent dans la fenêtre **Options de JeffWrite**. Cliquez sur **Fichier > Options** pour l'ouvrir. Cliquez sur **OK** pour conserver vos modifications, ou sur **Annuler** pour les abandonner.

## Enregistrer

La page **Enregistrer** de la fenêtre Options propose quatre choix.

- **Enregistrer les nouveaux documents sous** définit le type de fichier que **Enregistrer sous** propose en premier pour un document qui n'a pas encore de fichier : un fichier .docx ou un fichier .odt.
- **Enregistrer les informations de récupération automatique toutes les** indique le nombre de minutes entre deux copies de sauvegarde que JeffWrite conserve pour le travail non enregistré. Voir [Ouvrir, enregistrer, imprimer et exporter](open-save).
- **Emplacement de fichier par défaut** est le dossier dans lequel s'ouvrent les boîtes **Ouvrir** et **Enregistrer sous**. Cliquez sur **Parcourir** pour le choisir. Laissez ce champ vide pour démarrer dans votre dossier Documents.
- **Supprimer les informations personnelles de ce fichier à l'enregistrement** retire l'auteur, la personne qui a enregistré le fichier en dernier, la société, le responsable, les noms et initiales des commentaires, ainsi que les noms et dates des modifications suivies, dans le fichier écrit (un fichier .docx ou .odt, un modèle et un document envoyé par courrier électronique). Le contenu du fichier reste tel quel. Les propriétés personnalisées du fichier sont conservées, et le document ouvert n'est pas modifié. Ce choix est le même dans toutes les applications JeffOffice : le modifier dans l'une le modifie dans toutes les autres. Pour ne le faire qu'une fois, utilisez **Inspecter le document** dans [Infos](info). La même case se trouve sur la page **Infos**.

## Affichage

La page **Affichage** définit ce qu'une fenêtre montre à son ouverture.

- **Afficher les marques de mise en forme** active les marques de paragraphe et autres signes qui ne s'impriment pas. Chaque fenêtre peut toujours les activer ou les désactiver avec le bouton **¶**.
- **Afficher le quadrillage des tableaux** dessine les bordures discrètes des cellules de tableau qui n'ont pas de traits.

Une modification sur cette page s'applique immédiatement à la fenêtre active, ainsi qu'à chaque fenêtre ouverte ensuite.

## Options avancées

**Afficher les mesures en** choisit l'unité de la règle et des boîtes de dialogue : pouces, centimètres, millimètres, points ou picas. Un point vaut 1/72 de pouce. Un pica vaut 12 points.

**Utiliser Ctrl+clic pour suivre un lien** est activé par défaut : maintenez **Ctrl** et cliquez sur un lien pour y accéder ; un simple clic place seulement le curseur dans les mots du lien. Désactivez cette option pour suivre un lien par un simple clic. Maintenir **Maj** pendant le clic permet toujours de sélectionner du texte.

**Autoriser le glisser-déplacer du texte** vous permet de sélectionner des mots et de les faire glisser vers un nouvel emplacement. Maintenez **Ctrl** en relâchant le bouton pour copier les mots au lieu de les déplacer. Désactivez cette option si vous glissez le texte par erreur.

**La saisie remplace le texte sélectionné** est activée par défaut : lorsque des mots sont sélectionnés et que vous tapez, les nouvelles lettres prennent leur place. Désactivez cette option, et les nouvelles lettres s'ajouteront après les mots sélectionnés.

**Utiliser la touche Insertion pour activer et désactiver le mode Refrappe** est désactivée par défaut. Lorsqu'elle est activée, la touche **Insertion** alterne entre deux modes de saisie. Normalement, chaque lettre tapée repousse les lettres suivantes. En mode **Refrappe**, chaque lettre tapée remplace la lettre située après le curseur. Appuyez de nouveau sur **Insertion** pour revenir au mode normal.

Ces choix s'appliquent immédiatement à la fenêtre active, ainsi qu'à chaque fenêtre ouverte ensuite.

## Personnaliser

L'onglet **Personnaliser** comporte trois pages : **Ruban**, **Barre d'outils rapide** et **Clavier**. La page **Clavier** permet de choisir les raccourcis clavier des commandes de JeffWrite. Voir « Choisir vos propres raccourcis clavier » dans la rubrique sur le clavier.

### Personnaliser le ruban

La page **Ruban** affiche les onglets du ruban, chacun avec ses groupes.

- **Masquer ou afficher un onglet ou un groupe.** Décochez la case située à côté pour le masquer, et cochez-la pour l'afficher à nouveau. Un groupe masqué ne prend plus de place, et ses commandes restent accessibles par leurs raccourcis clavier. **Accueil** n'a pas de case, car il reste toujours affiché, de même que le bouton **Fichier**. Un onglet qui n'apparaît que lorsqu'un élément est sélectionné, comme une image ou un tableau, se trouve en fin de liste et n'a pas de case.
- **Créer votre propre onglet ou groupe.** Saisissez un nom dans la zone **Nom**, puis cliquez sur **Nouvel onglet**. Pour créer un groupe, choisissez un onglet, puis cliquez sur **Nouveau groupe**. Un groupe personnel peut figurer sur n'importe quel onglet, y compris un onglet qui n'apparaît que lorsqu'un élément est sélectionné.
- **Ajouter des commandes à votre groupe.** Choisissez votre groupe, recherchez une commande dans la liste **Commandes** (saisissez dans la zone **Rechercher des commandes** pour réduire la liste), puis cliquez sur **Ajouter une commande**. Toute commande qui a un nom peut être ajoutée. Une commande ne peut figurer qu'une fois dans un groupe.
- **Renommer.** Choisissez un onglet, un groupe ou une commande personnels, saisissez le nouveau nom, puis cliquez sur **Renommer**. Une commande renommée fait toujours la même chose ; le nouveau nom ne figure que sur son bouton. Pour rendre à une commande son nom d'origine, renommez-la avec un nom vide.
- **Réorganiser.** Choisissez un onglet, puis cliquez sur **Monter** ou **Descendre**. Vous pouvez déplacer les onglets du ruban ainsi que les vôtres, mais pas les onglets qui n'apparaissent que lorsqu'un élément est sélectionné. Vos groupes et vos commandes se déplacent de la même façon à l'intérieur de leur onglet ou de leur groupe. Les groupes du ruban conservent leur ordre.
- **Supprimer.** Choisissez un onglet, un groupe ou une commande personnels, puis cliquez sur **Supprimer**.

**Réinitialiser un élément** rétablit l'onglet choisi : il est affiché, ses groupes aussi, et les groupes que vous y avez ajoutés disparaissent. Un onglet personnel est supprimé. **Tout réinitialiser** rétablit l'ensemble du ruban, y compris l'ordre des onglets.

Rien ne change tant que vous ne cliquez pas sur **OK**. Ensuite, chaque fenêtre ouverte de JeffWrite affiche votre ruban, ainsi que chaque fenêtre ouverte ultérieurement. JeffWrite ne conserve que ce qui diffère du ruban habituel : ainsi, un onglet ou un groupe ajouté par une version ultérieure apparaît automatiquement. Vos onglets et groupes reçoivent des info-touches (les lettres affichées lorsque vous appuyez sur **Alt**) qui ne se confondent pas avec les autres. Vous pouvez avoir 20 onglets personnels, 30 groupes personnels par onglet et 60 commandes par groupe.

### Personnaliser la barre d'outils rapide

La page **Barre d'outils rapide** concerne la petite barre d'outils située en haut à gauche de la fenêtre. Sa liste de gauche affiche ce qui figure actuellement sur la barre, et la liste **Commandes** de droite contient toutes les commandes qui ont un nom (saisissez dans la zone **Rechercher des commandes** pour la réduire, comme sur la page **Ruban**).

- **Ajouter une commande.** Choisissez-la dans la liste **Commandes**, puis cliquez sur **Ajouter une commande**. Elle est placée à la fin de la barre. Une commande qui ouvre un menu conserve son menu sur la barre d'outils. Une commande ne peut figurer qu'une fois sur la barre.
- **Clic droit.** Vous pouvez aussi faire un clic droit sur une commande du ruban et choisir **Ajouter à la barre d'outils rapide**, ou faire un clic droit sur un bouton de la barre et choisir **Supprimer de la barre d'outils rapide**. Le même menu contient **Personnaliser la barre d'outils rapide** et **Personnaliser le ruban**, qui ouvrent cette page.
- **Ajouter un séparateur.** Cliquez sur **Ajouter un séparateur** pour placer un trait fin à la fin de la barre, puis déplacez-le où vous le souhaitez.
- **Réorganiser.** Choisissez une commande ou un séparateur dans la liste de gauche, puis cliquez sur **Monter** ou **Descendre**.
- **Supprimer.** Choisissez-le, puis cliquez sur **Supprimer**.

**Réinitialiser un élément** rétablit la commande choisie : à l'emplacement habituel dans JeffWrite, ou hors de la barre d'outils si JeffWrite ne l'y place pas habituellement. **Tout réinitialiser** rétablit la barre d'outils fournie avec JeffWrite. Le bouton Tout réinitialiser de cette page ne modifie pas votre ruban, et celui de la page **Ruban** ne modifie pas votre barre d'outils.

Rien ne change tant que vous ne cliquez pas sur **OK**. Ensuite, chaque fenêtre ouverte de JeffWrite affiche votre barre d'outils, ainsi que chaque fenêtre ouverte ultérieurement. La barre peut comporter au total 100 commandes et séparateurs. Lorsqu'il y a plus de boutons qu'il n'en tient dans le tiers de la largeur de la fenêtre, les autres attendent derrière un bouton **»** à la fin de la barre, afin que le titre de la fenêtre ne soit jamais repoussé hors de l'écran. JeffWrite conserve dans votre liste une commande qu'une version ultérieure ne possède plus, et l'affiche de nouveau si elle revient. Les boutons reçoivent des info-touches : les chiffres de 1 à 9, puis deux lettres, dans l'ordre où ils se trouvent sur la barre. La barre d'outils est toujours située en haut à gauche, à côté du bouton **Fichier**.

## Statistiques d'utilisation

**Envoyer des statistiques d'utilisation anonymes** vous permet de partager des informations sur la façon dont JeffWrite est utilisé. Anonyme signifie que ces informations ne disent rien sur votre identité. Lorsque cette option est activée, JeffWrite envoie ces informations une fois par jour, ainsi que le jour de la mise à jour : le nom du logiciel, sa version, votre système d'exploitation et votre langue, le nombre de fois où il a été démarré, la fréquence d'utilisation de chaque commande, et le type de fichier ouvert ou enregistré. Si JeffWrite se ferme de manière inattendue, il envoie aussi un rapport d'erreur au démarrage suivant. JeffWrite n'envoie jamais vos fichiers, leurs noms, ni rien de leur contenu, ni ce que vous saisissez. Si cette option est désactivée, aucun rapport d'erreur n'est envoyé non plus.

Ce choix concerne toutes les applications JeffOffice : le modifier ici le modifie dans chacune d'elles. JeffWrite vous pose la question la première fois qu'il démarre, dans une fenêtre intitulée **Aidez à améliorer JeffWrite**.

- **Déclaration de confidentialité**, à côté de la case à cocher, ouvre notre déclaration de confidentialité à l'adresse jeffoffice.com/privacy. Elle indique ce qui est envoyé, où, et pendant combien de temps nous le conservons. Nous conservons les statistiques pendant 24 mois.
- **Numéro d'installation** s'affiche sous la case à cocher. Il s'agit d'un numéro aléatoire attribué à votre copie de JeffOffice, identique dans toutes les applications JeffOffice. Il ne contient aucune information sur vous. Cliquez sur **Copier** pour le copier. Si les statistiques sont désactivées, ou si aucun numéro n'a encore été créé, la mention **aucun** s'affiche.
- Pour faire supprimer les statistiques que nous détenons déjà, envoyez votre numéro d'installation à info@jeffoffice.com **avant** de désactiver les statistiques. La désactivation efface ce numéro de votre ordinateur, et sans lui nous ne pouvons pas savoir quels enregistrements vous appartiennent.
- Pour désactiver les statistiques sans ouvrir JeffWrite, définissez la variable d'environnement `JP_NO_TELEMETRY` avec une valeur quelconque avant de le démarrer. Rien n'est alors compté ni envoyé, et JeffWrite ne pose pas la question du premier démarrage.
