# Ajouter des commentaires et y répondre
<!-- keywords: commentaire, commentaires, répondre, réponse, résoudre, rouvrir, supprimer un commentaire, nouveau commentaire, révision, relecture, bulle, marge, fil de discussion, ctrl+alt+m, annotation, remarque, note pour le réviseur -->

Un **commentaire** est une note placée dans la marge à propos de certains mots. Il ne modifie pas le texte et ne s'imprime que si vous le demandez. Utilisez les commentaires pour poser une question, expliquer une modification ou laisser un message à la prochaine personne qui lira le document.

## Ajouter un commentaire

1. Sélectionnez les mots concernés par le commentaire, ou cliquez à l'endroit où il doit figurer.
2. Cliquez sur **Révision > Nouveau commentaire**, ou appuyez sur **Ctrl+Alt+M**. Vous pouvez aussi cliquer avec le bouton droit et choisir **Nouveau commentaire**.
3. Tapez le commentaire et cliquez sur **OK**.

Le commentaire apparaît sous forme de bulle dans la marge, à côté de la ligne, avec les initiales de son auteur, ainsi que dans le volet **Révision**, avec le nom et l'heure. Le nom et les initiales sont ceux définis dans **Fichier > Options**.

L'ajout d'un commentaire constitue une seule étape : **Ctrl+Z** l'annule donc.

## Lire les commentaires

- **Révision > Suivant** et **Révision > Précédent** (dans le groupe **Commentaires**) permettent de passer d'un commentaire à l'autre et sélectionnent les mots concernés.
- **Révision > Volet Révisions** ouvre la liste de tous les commentaires, dans l'ordre où ils figurent dans le document. Un clic sur l'un d'eux affiche les mots concernés. Les réponses sont listées sous le commentaire auquel elles répondent.
- **Révision > Afficher les commentaires** affiche ou masque les bulles dans la marge. Cela ne modifie pas le document.

## Répondre à un commentaire

Cliquez sur le commentaire dans le volet **Révision**, tapez votre texte dans la zone **Répondre**, puis appuyez sur **Entrée** (ou cliquez sur **Publier la réponse**). Vous pouvez aussi placer le curseur dans les mots concernés et cliquer sur **Répondre au commentaire** dans le menu contextuel. La réponse est enregistrée avec le commentaire auquel elle répond, de sorte que les autres programmes les affichent ensemble.

## Résoudre un commentaire

Lorsqu'une question a obtenu sa réponse, cliquez sur **Résoudre** dans le volet **Révision** (ou choisissez **Résoudre le commentaire** dans le menu contextuel). Le commentaire et ses réponses s'affichent alors estompés et restent dans le document. Cliquez sur **Rouvrir** pour les rétablir normalement.

## Modifier ou supprimer un commentaire

- Double-cliquez sur un commentaire dans le volet **Révision** pour en modifier le contenu.
- **Révision > Supprimer** supprime le commentaire dans lequel se trouve le curseur, ainsi que ses réponses. Cliquez sur la flèche située en dessous et choisissez **Supprimer tous les commentaires du document** pour supprimer tous les commentaires.

La suppression d'un commentaire constitue une seule étape : **Ctrl+Z** le rétablit donc.

## Commentaires dans les fichiers provenant d'autres programmes

Les commentaires, leurs réponses et leur état résolu sont conservés lorsqu'un fichier provient d'un autre programme et lorsque vous l'enregistrez de nouveau, même si vous ne les affichez jamais.
