# Ajouter et répondre aux commentaires
<!-- keywords: commentaire, commentaires, répondre, réponse, résoudre, rouvrir, supprimer commentaire, nouveau commentaire, révision, bulle, marge, fil, ctrl+alt+m, annotation, note pour le réviseur -->

Un **commentaire** est une note placée dans la marge, à côté de certains mots. Il ne modifie pas le texte et ne s'imprime pas, sauf si vous le demandez. Utilisez les commentaires pour poser une question, expliquer une modification ou laisser un message à la prochaine personne qui lira le document.

## Ajouter un commentaire

1. Sélectionnez les mots auxquels le commentaire se rapporte. Vous pouvez aussi simplement cliquer à l'endroit voulu.
2. Cliquez sur **Révision > Nouveau commentaire**, ou appuyez sur **Ctrl+Alt+M**. Vous pouvez aussi faire un clic droit et choisir **Nouveau commentaire**.
3. Saisissez le commentaire, puis cliquez sur **OK**.

Le commentaire apparaît sous forme de bulle dans la marge, à côté de la ligne, avec les initiales de son auteur. Il apparaît aussi dans le volet **Révisions**, avec le nom et l'heure. Le nom et les initiales sont ceux indiqués dans **Fichier > Options**.

Ajouter un commentaire est une seule étape : **Ctrl+Z** l'annule.

## Lire les commentaires

- **Révision > Suivant** et **Révision > Précédent** (dans le groupe **Commentaires**) passent d'un commentaire au suivant et sélectionnent les mots auxquels il se rapporte.
- **Révision > Volet Révisions** ouvre la liste de tous les commentaires, dans l'ordre où ils figurent dans le document. Un clic sur l'un d'eux affiche les mots correspondants. Les réponses sont listées sous le commentaire auquel elles répondent.
- **Révision > Afficher les commentaires** active ou désactive les bulles dans la marge. Cela ne modifie pas le document.

## Répondre à un commentaire

Cliquez sur le commentaire dans le volet **Révisions**, saisissez votre texte dans la zone **Répondre**, puis appuyez sur **Entrée** (ou cliquez sur **Publier la réponse**). Vous pouvez aussi placer le curseur dans les mots concernés et cliquer sur **Répondre au commentaire** dans le menu contextuel. La réponse est enregistrée avec le commentaire auquel elle répond, afin que les autres logiciels affichent les deux ensemble.

## Résoudre un commentaire

Lorsqu'une question a reçu une réponse, cliquez sur **Résoudre** dans le volet **Révisions** (ou choisissez **Résoudre le commentaire** dans le menu contextuel). Le commentaire et ses réponses apparaissent alors en grisé, et restent dans le document. Cliquez sur **Rouvrir** pour les remettre dans leur apparence normale.

## Modifier ou supprimer un commentaire

- Double-cliquez sur un commentaire dans le volet **Révisions** pour modifier son texte.
- **Révision > Supprimer** supprime le commentaire où se trouve le curseur, ainsi que ses réponses. Cliquez sur la flèche située sous ce bouton et choisissez **Supprimer tous les commentaires affichés** pour supprimer les commentaires visibles, ou **Supprimer tous les commentaires du document** pour supprimer tous les commentaires. « Affichés » signifie que l'option **Commentaires** du menu **Afficher les marques** est activée et que, lorsque le volet **Révisions** est ouvert, le commentaire est celui du réviseur choisi dans ce volet. Chaque commentaire supprimé entraîne avec lui les réponses placées sous lui, de sorte qu'aucune réponse ne reste sans le commentaire auquel elle répond. Un commentaire d'un autre réviseur qui ne se trouve pas sous un commentaire supprimé est conservé, même dans le même fil : si le premier commentaire d'un fil est d'une autre personne, seules les réponses du réviseur choisi sont supprimées. Les commentaires résolus sont traités de la même façon que les autres. Les commentaires placés dans les zones de texte, les en-têtes et les notes ne sont pas listés et ne sont pas supprimés par cette commande.

Supprimer un commentaire est une seule étape : **Ctrl+Z** le rétablit.

## Commentaires dans les fichiers provenant d'autres logiciels

Les commentaires, leurs réponses et leur état résolu ou non sont conservés lorsqu'un fichier provient d'un autre logiciel, ainsi que lorsque vous l'enregistrez de nouveau, même si vous ne les avez jamais affichés.
