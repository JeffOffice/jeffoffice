# Utiliser les styles
<!-- keywords: style, galerie de styles, style de paragraphe, style de caractère, titre 1, titre 2, titre 3, titre, nouveau style, modifier le style, changer de style, importer des styles, normal, corps de texte, sous-titre -->

Un style est un ensemble de mises en forme enregistré sous un nom. Lorsque vous appliquez le style **Titre 1**, le texte reçoit en une seule fois la police, la taille, la couleur et l'espacement de ce style. Si vous modifiez le style par la suite, tous les paragraphes qui l'utilisent changent aussi.

Il existe deux types de style :

- Un **style de paragraphe** met en forme des paragraphes entiers.
- Un **style de caractère** ne met en forme que les lettres que vous sélectionnez. **Accentuation** (italique) et **Forte** (gras) sont des styles de caractère.

## Appliquer un style

1. Cliquez dans un paragraphe ou sélectionnez le texte. Pour un style de caractère, sélectionnez les mots.
2. Dans **Accueil > Styles**, cliquez sur un style de la galerie.

Si une zone de texte est sélectionnée à la place, le style s'applique à tous ses paragraphes. La galerie affiche quelques styles. Utilisez les flèches **Ligne précédente** et **Ligne suivante** pour en voir davantage, ou le bouton **Tout afficher** pour les voir tous.

Une nouvelle composition commence avec ces styles : Normal, Corps de texte, Titre, Sous-titre, Titre 1 à Titre 4, Citation, Légende, Puce de liste, Adresse, Nom de l'organisation, Slogan, Téléphone Télécopie Courriel, Accentuation et Forte. Les styles de titre utilisent la police des titres de la composition : si vous choisissez un nouveau jeu de polices, ils changent donc aussi. Voir [Couleurs et polices du jeu](color-schemes).

Utilisez **Titre 1**, **Titre 2** et **Titre 3** pour vos titres. JeffPub crée une table des matières à partir de ceux-ci. Voir [Table des matières, notes de bas de page et notes de fin](references).

## Créer un nouveau style

1. Mettez en forme un texte comme vous voulez que le style apparaisse. Laissez le point d'insertion dedans.
2. Cliquez sur **Tout afficher** dans la galerie **Styles**, puis cliquez sur **Nouveau style…**.
3. Saisissez un **Nom du style**. Vérifiez ou modifiez les autres paramètres.
4. Cliquez sur **OK**.

Le nouveau style apparaît dans la galerie. Il n'est pas encore appliqué à votre texte : cliquez dessus dans la galerie.

Pour aller plus vite, choisissez **Nouveau style à partir d'un exemple**. Saisissez un nom pour le style, à partir du texte sélectionné. JeffPub crée le style et l'applique immédiatement.

## Modifier un style

1. Cliquez dans un paragraphe qui utilise le style.
2. Cliquez sur **Tout afficher** dans la galerie **Styles**, puis cliquez sur **Modifier le style…**.
3. Modifiez la police, la taille, le gras, l'italique, la couleur, l'alignement, les retraits ou l'espacement. Cliquez sur **OK**.

Tous les paragraphes ayant ce style changent aussitôt.

La boîte de dialogue propose aussi ces options :

- **Style du paragraphe suivant :** le style obtenu lorsque vous appuyez sur Entrée à la fin d'un paragraphe. Après un titre, vous voulez généralement **Normal**.
- **Style de caractère :** cochez cette case pour créer un style qui ne met en forme que le texte sélectionné.
- **Basé sur :** le style dont part celui-ci. Un style ne conserve que ce que vous y modifiez : si vous changez le style de base, tous les styles qui en dérivent changent aussi, ainsi que le texte qui les utilise. Un paramètre indique **à partir de la base** lorsqu'il vient du style de base, et **défini ici** lorsque ce style le définit. **Rétablir la valeur de base** remet un paramètre à celle du style de base. Le texte que vous avez mis en forme vous-même garde son aspect.
- **Supprimer le style :** supprime le style. Les styles qui en dérivent se basent alors sur son propre style de base, et leur aspect ne change pas.

## Importer des styles d'une autre composition

1. Cliquez sur **Tout afficher** dans la galerie **Styles**, puis cliquez sur **Importer des styles…**.
2. Choisissez une composition JeffPub ou un fichier .pub.

Les styles qui portent le même nom sont remplacés. Les autres styles sont ajoutés. Le texte d'un style remplacé prend son nouvel aspect, sauf ce que vous avez défini vous-même sur le texte.
