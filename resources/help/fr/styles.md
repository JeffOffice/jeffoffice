# Utiliser les styles
<!-- keywords: style, styles, galerie de styles, style de paragraphe, style de caractère, titre 1, titre 2, titre 3, titre, nouveau style, modifier le style, changer de style, importer des styles, normal, corps de texte, sous-titre -->

Un style est un ensemble de mises en forme enregistré sous un nom. Lorsque vous appliquez le style **Titre 1**, le texte reçoit en une seule fois la police, la taille, la couleur et l'espacement de ce style. Si vous modifiez le style par la suite, tous les paragraphes qui l'utilisent changent également.

Il existe deux types de style :

- Un **style de paragraphe** met en forme des paragraphes entiers.
- Un **style de caractère** met en forme uniquement les lettres sélectionnées. **Accentuation** (italique) et **Élevé** (gras) sont des styles de caractère.

## Appliquer un style

1. Cliquez dans un paragraphe ou sélectionnez le texte. Pour un style de caractère, sélectionnez les mots.
2. Dans **Accueil > Styles**, cliquez sur un style dans la galerie.

Si vous sélectionnez plutôt une zone de texte, le style s'applique à tous ses paragraphes. La galerie affiche quelques styles. Utilisez les flèches **Ligne précédente** et **Ligne suivante** pour en voir d'autres, ou le bouton **Afficher tout** pour les voir tous.

Une nouvelle composition comporte les styles suivants : Normal, Corps de texte, Titre, Sous-titre, Titre 1 à Titre 4, Citation, Légende, Liste à puces, Adresse, Nom de l'organisation, Slogan, Téléphone Télécopie E-mail, Accentuation et Élevé. Les styles de titre utilisent la police des titres de la composition : le choix d'un nouveau jeu de polices les modifie donc. Consultez [Jeux de couleurs et de polices](color-schemes).

Utilisez **Titre 1**, **Titre 2** et **Titre 3** pour vos titres. JeffPub s'en sert pour créer une table des matières. Consultez [Table des matières, notes de bas de page et notes de fin](references).

## Créer un style

1. Mettez en forme du texte selon l'aspect souhaité pour le style. Laissez le curseur dans ce texte.
2. Cliquez sur **Afficher tout** dans la galerie **Styles**, puis sur **Nouveau style…**.
3. Tapez un nom dans **Nom du style :**. Vérifiez ou modifiez les autres paramètres.
4. Cliquez sur **OK**.

Le nouveau style apparaît dans la galerie. Il n'est pas encore appliqué à votre texte : cliquez dessus dans la galerie.

Pour aller plus vite, choisissez **Nouveau style à partir d'un exemple**. Tapez un nom pour le style basé sur le texte sélectionné. JeffPub crée le style et l'applique immédiatement.

## Modifier un style

1. Cliquez dans un paragraphe qui utilise le style.
2. Cliquez sur **Afficher tout** dans la galerie **Styles**, puis sur **Modifier le style…**.
3. Modifiez la police, la taille, le gras, l'italique, la couleur, l'alignement ou l'espacement. Cliquez sur **OK**.

Tous les paragraphes utilisant ce style changent immédiatement.

La boîte de dialogue propose également les options suivantes :

- **Style du paragraphe suivant :** le style obtenu lorsque vous appuyez sur Entrée à la fin d'un paragraphe. Après un titre, vous voulez généralement **Normal**.
- **Style de caractère :** cochez cette case pour créer un style qui ne met en forme que le texte sélectionné.
- **Basé sur :** JeffPub enregistre ce choix, mais un style ne change pas lorsque le style sur lequel il est basé est modifié.

## Importer les styles d'une autre composition

1. Cliquez sur **Afficher tout** dans la galerie **Styles**, puis sur **Importer des styles…**.
2. Choisissez une composition JeffPub ou un fichier .pub.

Les styles portant le même nom sont remplacés. Les autres styles sont ajoutés. Le texte déjà saisi conserve son aspect jusqu'à ce que vous lui appliquiez de nouveau le style.
