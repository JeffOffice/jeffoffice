# Info : propriétés, mots de passe et inspection

Cliquez sur **Fichier > Info** pour afficher les informations de votre classeur et le protéger avant de le partager. Appuyez sur **Échap** pour revenir à votre classeur.

## Emplacement du fichier

En haut de la page, l'emplacement d'enregistrement du fichier est indiqué. Cliquez sur **Afficher dans le dossier** pour ouvrir ce dossier. Cliquez sur **Copier le chemin** pour copier le chemin, afin de le coller dans un e-mail ou une conversation.

## Propriétés

Les propriétés sont des informations sur le classeur, comme son titre ou son auteur. La page comporte une zone pour chacune d'elles : **Titre**, **Auteur**, **Objet**, **Mots clés**, **Catégories**, **Commentaires**, **Société** et **Responsable**. Saisissez du texte dans une zone, puis appuyez sur **Tab** ou **Entrée**. JeffCrunch conserve la modification et l'écrit dans le fichier lors du prochain enregistrement du classeur. La page indique également les dates de création, d'enregistrement et d'impression du classeur.

Cliquez sur **Propriétés personnalisées** pour créer vos propres propriétés, comme **Projet** ou **Client**. Cliquez sur **Ajouter**, saisissez un nom, choisissez le type de valeur (texte, nombre entier, nombre, oui ou non, ou date), puis saisissez la valeur. JeffCrunch les enregistre telles que vous les avez saisies.

## Marquer comme final

Cliquez sur **Marquer comme final** pour indiquer aux lecteurs que le classeur est terminé. JeffCrunch enregistre le classeur, puis le maintient en lecture seule. Lorsqu'une personne l'ouvre, la barre de titre indique qu'il est en lecture seule. Il s'agit d'un moyen discret de dire « merci de ne pas modifier ce document ». Ce n'est pas un verrou, car toute personne peut choisir de nouveau **Marqué comme final** pour le modifier.

## Chiffrer avec un mot de passe

Cliquez sur **Chiffrer avec un mot de passe** pour demander un mot de passe à chaque ouverture du fichier. C'est la même chose que **Protéger par mot de passe**. Voir [Ouvrir des classeurs protégés par mot de passe](open-password). Un mot de passe protège un fichier **.xlsx** avec une protection renforcée. Si vous oubliez un mot de passe, il **ne peut pas être retrouvé**.

Pour empêcher les modifications d'une feuille ou de sa mise en page, voir [Protéger une feuille ou le classeur](protect).

## Inspecter le classeur

Cliquez sur **Inspecter le classeur** avant d'envoyer un classeur à quelqu'un. Cette commande énumère les éléments du fichier que vous ne souhaitez peut-être pas partager, avec le nombre de chacun trouvé :

- **Notes** : notes laissées par des personnes sur des cellules. **Supprimer tout** les retire.
- **Propriétés du document et informations personnelles** : l'auteur, la personne qui a enregistré le fichier en dernier, la société et le responsable. **Supprimer tout** les efface.
- **Feuilles masquées** : feuilles qui n'apparaissent pas sous forme d'onglets. **Afficher tout** les affiche, afin que vous puissiez voir leur contenu et supprimer celles que vous ne voulez pas garder.
- **Liens externes** : liens vers des valeurs d'autres classeurs. Cette liste se contente de les compter. Rompez-les dans l'onglet **Données**.
- **Données XML personnalisées** : données ajoutées au fichier par d'autres programmes. Cette liste se contente de les compter.

Enregistrez ensuite le classeur pour conserver la copie nettoyée.
