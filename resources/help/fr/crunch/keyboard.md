# Utiliser JeffCrunch au clavier
<!-- keywords: clavier, raccourcis, touches, raccourcis clavier, flèche, ctrl, maj, début, fin, page précédente, page suivante, tabulation, entrée, tout sélectionner, copier, F9, F1, zoom, touches d'accès, info-touches -->

Sur un Mac, la touche **Commande** (⌘) remplace la touche **Ctrl** dans les tableaux ci-dessous, sauf indication contraire.

## Déplacement et sélection

| Touches | Effet |
| --- | --- |
| Touches fléchées | Déplacent la cellule active d'une cellule, en ignorant les lignes et colonnes masquées |
| Maj+flèche | Étend la sélection d'une cellule |
| Ctrl+flèche | Va jusqu'au bord des données (Échap arrête une longue recherche) |
| Ctrl+Maj+flèche | Étend la sélection jusqu'au bord des données |
| Début | Va à la première colonne de la ligne |
| Ctrl+Début | Va à la première cellule (A1, ou à la première cellule défilante lorsque des lignes ou colonnes sont figées) |
| Ctrl+Fin | Va à la dernière cellule contenant une valeur ou une mise en forme |
| Page suivante, Page précédente | Descendent ou remontent d'un écran |
| Tab, Maj+Tab | Vont à droite ou à gauche (dans les cellules sélectionnées, s'il y en a plusieurs) |
| Entrée, Maj+Entrée | Descendent ou remontent (dans les cellules sélectionnées, s'il y en a plusieurs) |
| Ctrl+Espace | Sélectionne la colonne entière |
| Maj+Espace | Sélectionne la ligne entière |
| {key:SelectAll} | Sélectionne tout |

## Modification des cellules

| Touches | Effet |
| --- | --- |
| Tout caractère | Commence une saisie dans la cellule active, à la place de son contenu |
| F2 | Modifie le contenu de la cellule active, dans la cellule ; pendant la saisie d'une formule, passe de la désignation des cellules à la modification du texte |
| F4 | Pendant la saisie d'une formule, ajoute des $ à l'adresse au curseur pour figer certaines parties (A1, $A$1, A$1, $A1) |
| Entrée, Maj+Entrée | Valident la saisie, et descendent ou remontent |
| Tab, Maj+Tab | Valident la saisie, et vont à droite ou à gauche |
| Échap | Annule la saisie |
| Alt+Entrée | Insère un saut de ligne dans la cellule |
| Suppr | Efface les cellules sélectionnées |
| {key:Undo}, {key:Redo} | Annule, rétablit |
| {key:Save} | Enregistre |
| {key:Cut}, {key:Copy}, {key:Paste} | Couper, copier, coller (Échap supprime le contour des cellules copiées) |
| Ctrl+Alt+V | Collage spécial |
| Ctrl et la touche plus, Ctrl et la touche moins | Insèrent ou suppriment des lignes ou des colonnes entières si elles sont sélectionnées |
| Ctrl+D, Ctrl+R | Recopie vers le bas, recopie vers la droite |
| Ctrl+E | Remplissage instantané |
| Alt et la touche égal | Somme |
| Ctrl+0, Ctrl+9 | Masquent les colonnes, masquent les lignes |
| Alt+Bas | Ouvre la liste d'une cellule qui en comporte une |
| {key:Find} | Rechercher |
| Ctrl+H (sur un Mac, Option+Commande+F) | Rechercher et remplacer |
| F5, Ctrl+G | Atteint une cellule, une plage ou un nom |
| Ctrl+Maj+L | Active ou désactive le filtre |
| Maj+F3 | Choisit une fonction |
| Ctrl+F3 | La liste des noms |
| F9, Maj+F9 | Recalcule tout, recalcule cette feuille |
| Tab, Entrée | Pendant la saisie d'une formule : prend la fonction ou le nom sélectionné dans la liste |
| Échap | Arrête une recherche, un tri ou un filtre en cours |

## Touches d'accès

Appuyez sur **Alt** pour afficher une lettre sur chaque onglet du ruban et sur chaque commande, puis appuyez sur les lettres. Appuyez sur **Alt**, puis sur **F**, pour ouvrir l'écran Fichier. Appuyez sur **Échap** pour revenir en arrière.
