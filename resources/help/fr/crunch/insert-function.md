# Choisir une fonction
<!-- keywords: fonction, choisir une fonction, fx, formule, argument, catégorie, rechercher, toutes les fonctions, somme automatique, Maj+F3 -->

Choisissez **Choisir une fonction** dans l'onglet Formules (**Maj+F3**), ou **Toutes les fonctions** dans le menu **Somme automatique**.

Tapez dans la zone de recherche un nom ou ce que vous voulez faire (« arrondir à l'inférieur », « assembler du texte ») : la liste affiche les fonctions correspondantes, en commençant par celles dont le nom commence par les mots saisis. **Catégorie** limite la liste aux fonctions de finances, de date et heure, de maths et trigonométrie, de statistiques, de recherche et référence, de texte, de logique, d'information ou de base de données.

Sélectionnez une fonction pour voir sa syntaxe, ce qu'elle fait et ses arguments. Un argument entre crochets est facultatif, et « autres du même type » signifie que vous pouvez en indiquer autant que nécessaire. Cliquez sur **OK** (ou double-cliquez sur la fonction).

La cellule passe en mode modification avec la formule commencée : **=SOMME()**, le curseur placé entre les parenthèses, prêt pour les arguments. Si vous êtes déjà en train de taper une formule, la fonction est insérée à l'emplacement du curseur. Seules les fonctions que JeffCrunch sait calculer sont proposées.

## Messages sur les cellules

Une cellule dotée d'une règle limitant ce qui peut y être saisi peut aussi avoir un message (un titre et une phrase). Il s'affiche à côté de la cellule tant que celle-ci est sélectionnée. Les listes qui lisent des cellules d'une autre feuille fonctionnent également.
