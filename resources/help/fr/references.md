# Table des matières, notes de bas de page et notes de fin
<!-- keywords: table des matières, sommaire, TDM, page de sommaire, note de bas de page, note de fin, notes, références, citations, renvoi, mettre à jour la table, numéros de page, points de suite, styles de titre -->

Le groupe **Références** de l'onglet **Insertion** propose des outils pour les compositions longues : table des matières, notes de bas de page et notes de fin.

## Ajouter une table des matières

Une table des matières répertorie vos titres avec leurs numéros de page, pour que les lecteurs trouvent facilement ce qu'ils cherchent.

1. Appliquez à chaque titre l'un des styles **Titre 1**, **Titre 2** ou **Titre 3**. Voir [Utiliser les styles](styles).
2. Cliquez dans le texte à l'endroit où vous voulez la table, ou cliquez sur une page vide.
3. Cliquez sur **Insertion > Références > Table des matières**.

JeffPub ajoute un titre, **Sommaire**, et une ligne pour chaque titre. Chaque ligne se termine par des points de suite et un numéro de page. Les lignes **Titre 1** sont en gras, et chaque niveau inférieur est décalé de 0,6 cm supplémentaire.

Si vous avez cliqué dans du texte, la table est insérée à cet endroit. Sinon, si la page est vide, elle est placée dans une nouvelle zone de texte sur cette page. Dans les autres cas, JeffPub ajoute une nouvelle page après la page active pour l'accueillir.

S'il n'y a encore aucun titre, la table l'indique. Ajoutez des titres, puis mettez-la à jour.

### Tenir la table à jour

La table ne se met pas à jour d'elle-même. Après avoir modifié des titres ou déplacé des pages, cliquez sur **Insertion > Références > Mettre à jour la table**. Tous les numéros de page sont actualisés et toutes les tables de la composition sont mises à jour. JeffPub réécrit entièrement la table : ne tapez donc pas de modifications à l'intérieur. Modifiez plutôt les titres.

## Ajouter une note de bas de page

Une note de bas de page est une courte note placée en bas de la page. Un petit numéro en exposant dans le texte y renvoie.

1. Cliquez dans le texte à l'endroit où le numéro doit apparaître.
2. Cliquez sur **Insertion > Références > Note de bas de page**, ou appuyez sur Ctrl+Alt+F.
3. Tapez la note dans la boîte de dialogue **Insérer une note de bas de page**.
4. Cliquez sur **OK**.

JeffPub numérote les notes de bas de page 1, 2, 3, etc. Il place chaque note en bas de la colonne qui contient son numéro, sous un court trait. Le texte de la note est légèrement plus petit que votre texte. Si une note et la ligne qui porte son numéro ne tiennent pas dans l'espace restant de la colonne, elles passent toutes deux à la colonne suivante.

Une note de bas de page plus haute qu'une colonne entière est fractionnée. La première partie reste en bas de la colonne qui contient son numéro, et la ligne portant le numéro reste au-dessus. La suite continue en bas de la colonne suivante, ou de la zone de texte liée suivante, même sur une autre page. Elle se place alors au-dessus des notes propres à cette colonne, sous un trait aussi large que la colonne. Une note longue se poursuit sur autant de colonnes que nécessaire.

S'il ne reste aucune colonne pour la suite, l'article est trop long pour ses zones de texte. L'indicateur rouge de texte en excès apparaît, comme pour tout texte qui ne tient pas. [Liez une autre zone de texte](linked-text) ou libérez de la place, et la suite de la note apparaît.

## Ajouter une note de fin

Une note de fin ressemble à une note de bas de page, mais toutes les notes sont regroupées à la fin de l'article, sous le titre **Notes**.

1. Cliquez dans le texte à l'endroit où le numéro doit apparaître.
2. Cliquez sur **Insertion > Références > Note de fin**, ou appuyez sur Ctrl+Alt+D.
3. Tapez la note dans la boîte de dialogue **Insérer une note de fin** et cliquez sur **OK**.

## Modifier une note

Cliquez juste à côté du numéro d'une note dans le texte, puis cliquez de nouveau sur **Note de bas de page** ou **Note de fin**. La boîte de dialogue **Modifier la note de bas de page** ou **Modifier la note de fin** s'ouvre avec le texte de la note. Pour supprimer une note, supprimez son numéro dans le texte.

Les notes fonctionnent dans les zones de texte, mais pas dans les cellules de tableau.
