# Onglet Aide
<!-- keywords: onglet aide, aide, assistance, support, contacter le support, commentaires, avis, nouveautés, notes de version, raccourcis clavier, F1, signaler un problème, suggérer une idée -->

L'onglet **Aide** figure toujours sur le ruban, après l'onglet **Affichage**. Il permet d'obtenir de l'aide, de signaler un problème ou de suggérer une idée.

- Groupe **Aide** : quatre boutons. Voir [Bienvenue dans JeffPub](start) et [Obtenir de l'aide et signaler des problèmes](support).

| Bouton | Action | Info-touches |
|---|---|---|
| **Aide** | Ouvre le volet Aide à droite. Vous pouvez aussi appuyer sur F1 ou cliquer sur le bouton **?** à l'extrémité droite de la rangée d'onglets. | Alt, Y, H |
| **Commentaires** | Ouvre une page GitHub sur laquelle vous pouvez signaler un problème ou suggérer une idée. Un compte GitHub gratuit est nécessaire. | Alt, Y, K |
| **Raccourcis clavier** | Ouvre la rubrique d'aide consacrée à l'utilisation de JeffPub au clavier, avec la liste des touches de chaque commande. | Alt, Y, S |
| **Nouveautés** | Ouvre les notes de votre version de JeffPub sur GitHub, dans votre navigateur web. | Alt, Y, W |
