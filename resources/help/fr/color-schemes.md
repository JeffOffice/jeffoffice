# Jeux de couleurs et de polices
<!-- keywords: jeu de couleurs, thème, palette, couleurs, jeu de polices, polices, arrière-plan, fond, arrière-plan de la page, dégradé, texture, motif, modifier le modèle, couleurs d'accent, police des titres, police du corps de texte, changer le style -->

Un jeu de couleurs est un ensemble de couleurs partagé par toute votre composition. Un jeu de polices est une paire de polices, l'une pour les titres et l'autre pour le corps de texte. Changer de jeu modifie le style de la composition en une seule opération. Les outils se trouvent dans l'onglet **Création de page**.

## Choisir un jeu de couleurs

Cliquez sur un jeu dans la galerie de **Création de page > Jeux**. Plus de 90 jeux sont proposés.

Chaque jeu comporte huit couleurs : Principale, Accent 1 à Accent 5, Lien hypertexte et Lien hypertexte visité. Lorsque vous colorez un objet avec l'une de ces couleurs, l'objet suit le jeu. Par exemple, une bannière remplie avec Accent 1 change de couleur lorsque vous choisissez un nouveau jeu. Une couleur que vous avez composée vous-même reste identique.

## Créer votre propre jeu de couleurs

1. Cliquez sur **Créer un nouveau jeu de couleurs…** en bas de la galerie.
2. Dans la fenêtre **Créer un jeu de couleurs**, cliquez sur chaque bouton de couleur et choisissez une couleur.
3. Tapez un nom dans **Nom du jeu de couleurs** et cliquez sur **OK**.

Les nouvelles couleurs s'appliquent immédiatement à votre composition.

## Choisir un jeu de polices

Cliquez sur **Création de page > Jeux > Polices**. Chaque choix affiche le nom du jeu et ses deux polices, par exemple « Modern — Montserrat / Open Sans ». Le texte qui utilise les polices du jeu change. Le texte auquel une police précise a été appliquée ne change pas.

- **Créer un nouveau jeu de polices…** : choisissez une **Police des titres**, une **Police du corps de texte** et un nom.
- **Mettre à jour le jeu de polices** : supprime les polices fixes de vos styles, afin que le texte de ces styles utilise les polices du jeu.

## Définir un arrière-plan de page

1. Accédez à la page.
2. Cliquez sur **Création de page > Arrière-plan de la page > Arrière-plan**.
3. Choisissez **Aucun arrière-plan**, une couleur unie ou un dégradé (une couleur qui se fond dans une autre). Les couleurs proviennent de votre jeu de couleurs.

En bas de la galerie, **Autres arrière-plans…** ouvre la fenêtre **Mettre en forme l'arrière-plan**, avec des onglets Dégradé, Texture, Image, Motif et Nuance. **Appliquer l'arrière-plan à toutes les pages** copie cet arrière-plan sur chaque page.

Pour utiliser une image, sélectionnez-la et cliquez sur **Création de page > Arrière-plan de la page > Appliquer l'image comme arrière-plan**. L'image devient l'arrière-plan et l'objet image est supprimé.

Un arrière-plan appartient à une page. Un arrière-plan placé sur une page maître s'affiche sur toutes les pages qui utilisent cette page maître, sauf si la page possède son propre arrière-plan. Une page maître est une page d'arrière-plan dont le contenu se répète sur d'autres pages.

## Modifier le modèle

**Création de page > Modèle > Modifier le modèle** ouvre une galerie de conceptions. Choisissez-en une : JeffPub place le texte et les images de la composition ouverte dans cette conception. Vous pouvez l'appliquer à la composition ouverte, ou créer une nouvelle composition et laisser celle-ci telle quelle. Votre jeu de couleurs et votre jeu de polices ne changent que si vous en choisissez d'autres dans la galerie. Pour changer le style d'une composition sans modifier sa conception, modifiez plutôt ses jeux et ses arrière-plans comme indiqué ici. Consultez [Modifier le modèle d'une composition](change-template).
