# Onglet Révision

L'onglet **Révision** vérifie vos mots, les traduit et gère les commentaires.

- **Vérification** comprend **Orthographe** (F7), **Dictionnaire des synonymes** (Maj+F7), **Statistiques** et **Vérifier l'accessibilité**. Voir [Mettre en forme le texte](text).
- **Langue** comprend **Traduire**, **Définir la langue de vérification** et **Ne pas vérifier l'orthographe**. Voir ci-dessous.
- **Commentaires** comprend **Nouveau commentaire** (Ctrl+Alt+M), **Supprimer** avec son menu, **Précédent**, **Suivant** et **Afficher les commentaires**. Voir [Commentaires](comments).

## Définir la langue d'un texte

La vérification orthographique contrôle chaque texte dans sa propre langue. Pour changer la langue de certains mots, sélectionnez-les, ou sélectionnez une zone de texte ou un espace réservé entier, puis cliquez sur **Définir la langue de vérification** dans le groupe **Langue**. Choisissez la langue dans la liste, puis cliquez sur **OK**. Les mots de cette langue sont vérifiés avec le dictionnaire de cette langue, et le fichier conserve ce choix lorsque vous l'enregistrez au format de présentation ou de présentation OpenDocument. Le texte que vous n'avez pas marqué est vérifié en anglais américain.

## Ne pas vérifier certains textes

Certains textes ne doivent pas être vérifiés : un code, un nom ou une ligne dans une langue inventée. Sélectionnez-les, puis cliquez sur **Ne pas vérifier l'orthographe** dans le groupe **Langue**. Les soulignements ondulés rouges disparaissent. Cliquez à nouveau dessus pour que le texte soit de nouveau vérifié. La zone de notes ne contient que du texte brut : elle n'a donc pas de langue propre.

## Traduire du texte

1. Sélectionnez les mots dans une zone de texte ou dans les notes. Pour traduire tout le contenu d'une zone de texte, sélectionnez la zone.
2. Cliquez sur **Traduire** dans le groupe **Langue**.
3. Choisissez la langue de traduction.
4. Cliquez sur **OK**.

Votre navigateur web ouvre alors un service de traduction nommé LibreTranslate, avec votre texte. Rien n'est envoyé tant que vous ne cliquez pas sur **OK**. Vous pouvez modifier l'adresse du service dans la zone prévue, par exemple pour utiliser un service que vous faites fonctionner vous-même. Seules les adresses web sécurisées (https) sont utilisées, ainsi que les adresses http de cet ordinateur. Au maximum 5 000 lettres sont envoyées.

## Vérifier l'accessibilité

**Vérifier l'accessibilité** ouvre une petite fenêtre qui répertorie ce qui peut être difficile à utiliser pour certaines personnes : une image ou une forme sans texte de remplacement, une diapositive sans titre, un tableau sans ligne d'en-tête, une vidéo, un texte difficile à lire sur son arrière-plan, et des objets que le lecteur d'écran lit dans un ordre différent de leur position apparente. Le texte doit présenter un contraste de 4,5 pour 1 avec son arrière-plan (3 pour 1 pour un texte de 18 points ou plus, ou de 14 points ou plus en gras) ; lorsque le texte se trouve sur une image, une astuce vous invite à vérifier le contraste à l'œil. Un lecteur d'écran lit les objets d'une diapositive de l'arrière vers l'avant de la pile. Cliquez sur **Ordre de lecture** pour les afficher dans cet ordre, puis utilisez **Lire plus tôt** et **Lire plus tard** (ou faites-les glisser) pour le modifier ; chaque déplacement correspond à une étape d'**Annuler**. Un lecteur d'écran utilise la première ligne d'un tableau pour nommer ses colonnes : sélectionnez un problème de tableau, puis cliquez sur **Utiliser la première ligne comme en-tête** pour activer la ligne d'en-tête (une étape d'**Annuler**). JeffDeck ne peut pas encore ajouter de sous-titres à une vidéo : chaque vidéo est donc signalée sous forme d'astuce, sans correction, car les vidéos doivent disposer de sous-titres pour les personnes qui ne peuvent pas entendre. Cliquez sur un problème pour accéder à sa diapositive et sélectionner l'objet. Donnez à une image un texte de remplacement dans le volet **Format de l'image**, ou marquez-la comme décorative, puis cliquez sur **Vérifier à nouveau**. Vous pouvez aussi lancer la vérification depuis **Fichier > Informations**.
