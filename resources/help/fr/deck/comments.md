# Commentaires
<!-- keywords: commentaires, commentaire, répondre, résoudre, révision, relecture, retour, marqueur, notes pour d'autres, auteur, initiales, supprimer des commentaires, commentaire suivant, commentaire précédent, afficher les commentaires -->

Un **commentaire** est une note pour vous-même ou pour un relecteur, épinglée à un endroit d'une diapositive. Les commentaires ne s'affichent pas dans le diaporama ni à l'impression. Les personnes peuvent répondre à un commentaire et le marquer comme résolu une fois traité.

## Ajouter un commentaire

1. Cliquez sur la diapositive, puis cliquez sur **Révision > Commentaires > Nouveau commentaire** (Ctrl+Alt+M).
2. Si **Fichier > Options** ne contient pas encore de nom pour vous, JeffDeck vous demande votre nom et vos initiales, et les conserve. Vous pourrez les modifier plus tard. Voir [Modifier les paramètres de JeffDeck](options).
3. Le volet **Commentaires** s'ouvre à côté de la diapositive, avec une zone qui indique **Saisissez un commentaire**. Saisissez votre texte, puis cliquez sur **Publier**. Cliquez sur **Annuler** pour l'abandonner.

Chaque commentaire affiche un petit marqueur sur la diapositive. Un clic sur un marqueur ouvre ce commentaire dans le volet. Faites glisser un marqueur pour déplacer le commentaire à un autre endroit de la diapositive.

## Lire, répondre et résoudre

Le volet Commentaires affiche la liste des commentaires de la diapositive active. Chaque commentaire est une carte qui présente l'auteur, la date, le texte et ses réponses.

- Saisissez votre texte dans la zone **Répondre**, puis cliquez sur **Répondre**.
- Cliquez sur **Résoudre** lorsque le commentaire est traité. Un commentaire résolu porte la mention **Résolu**, et son marqueur devient gris. Cliquez sur **Rouvrir** pour le réactiver.
- Utilisez le bouton en forme de crayon sur un commentaire ou une réponse pour le **Modifier**, et le bouton en forme de corbeille pour le **Supprimer**.
- Cliquez sur **Révision > Commentaires > Précédent** ou **Suivant** pour parcourir chaque commentaire de la présentation, sur sa diapositive.

Pour masquer le volet et les marqueurs, cliquez sur **Révision > Commentaires > Afficher les commentaires**, ou sur la croix **X** en haut du volet. Cliquez de nouveau sur **Afficher les commentaires** pour les rétablir. Une présentation qui contient des commentaires s'ouvre avec ceux-ci affichés.

## Supprimer des commentaires

**Révision > Commentaires > Supprimer** propose un menu. Choisissez **Supprimer** pour le commentaire ouvert, **Supprimer tous les commentaires de cette diapositive**, ou **Supprimer tous les commentaires de cette présentation**. Ctrl+Z annule l'opération.

## Dans le fichier

Les commentaires sont enregistrés dans le fichier .pptx avec leurs réponses, afin que les personnes avec qui vous le partagez puissent les voir.
