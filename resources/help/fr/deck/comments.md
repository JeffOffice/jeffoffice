# Commentaires
<!-- keywords: commentaires, commentaire, répondre, réponse, résoudre, révision, relecture, avis, retour, marqueur, notes aux autres, auteur, initiales, supprimer les commentaires, commentaire suivant, commentaire précédent, afficher les commentaires -->

Un **commentaire** est une note pour vous-même ou pour un relecteur, attachée à un emplacement d'une diapositive. Les commentaires n'apparaissent ni dans le diaporama ni à l'impression. Il est possible de répondre à un commentaire, et de le marquer comme résolu une fois traité.

## Ajouter un commentaire

1. Cliquez sur la diapositive, puis cliquez sur **Révision > Commentaires > Nouveau commentaire** (Ctrl+Alt+M).
2. Si aucun nom n'est encore défini pour vous dans **Fichier > Options**, JeffDeck vous demande votre nom et vos initiales et les y conserve. Vous pourrez les modifier plus tard. Voir [Modifier les paramètres de JeffDeck](options).
3. Le volet **Commentaires** s'ouvre à côté de la diapositive, avec une zone indiquant **Tapez un commentaire**. Tapez votre texte, puis cliquez sur **Publier**. Cliquez sur **Annuler** pour l'abandonner.

Chaque commentaire affiche un petit marqueur sur la diapositive. Un clic sur un marqueur ouvre ce commentaire dans le volet. Faites glisser un marqueur pour déplacer le commentaire à un autre endroit de la diapositive.

## Lire, répondre et résoudre

Le volet Commentaires présente les commentaires de la diapositive active. Chaque commentaire est une carte qui indique l'auteur, la date, le texte et les réponses.

- Tapez dans la zone **Répondre** et cliquez sur **Répondre** pour répondre.
- Cliquez sur **Résoudre** lorsque le commentaire a été traité. Un commentaire résolu porte la mention **Résolu** et son marqueur devient gris. Cliquez sur **Rouvrir** pour le réactiver.
- Utilisez le bouton en forme de crayon d'un commentaire ou d'une réponse pour le **Modifier**, et le bouton en forme de corbeille pour le **Supprimer**.
- Cliquez sur **Révision > Commentaires > Précédent** ou **Suivant** pour parcourir chaque commentaire de la présentation, sur sa diapositive.

Pour masquer le volet et les marqueurs, cliquez sur **Révision > Commentaires > Afficher les commentaires**, ou sur le **X** en haut du volet. Cliquez de nouveau sur **Afficher les commentaires** pour les faire réapparaître. Une présentation qui contient des commentaires s'ouvre avec les commentaires affichés.

## Supprimer des commentaires

**Révision > Commentaires > Supprimer** propose un menu. Choisissez **Supprimer** pour le commentaire ouvert, **Supprimer tous les commentaires de cette diapositive** ou **Supprimer tous les commentaires de cette présentation**. Ctrl+Z annule la suppression.

## Dans le fichier

Les commentaires sont enregistrés dans le fichier .pptx avec leurs réponses : les personnes avec qui vous le partagez peuvent donc les voir.
