# Lancer le diaporama et utiliser le mode Présentateur
<!-- keywords: diaporama, lancer, présenter, présentation, démarrer, plein écran, à partir du début, à partir de la diapositive actuelle, mode présentateur, répéter, répétition, minuteur, chronomètre, notes, commentaires, diapositive suivante, deux écrans, moniteurs, écran noir, écran blanc, touches, échap, arrêter le diaporama, diapositives masquées, liens -->

Le diaporama affiche vos diapositives une par une, en plein écran. Le mode Présentateur est une seconde fenêtre réservée à vous, avec vos notes, un minuteur et un aperçu de la diapositive suivante.

## Lancer le diaporama

- Appuyez sur **F5** ou cliquez sur **Diaporama > Lancer le diaporama > À partir du début**. Le bouton **À partir du début** se trouve également dans la barre d'outils Accès rapide, en haut à gauche.
- Appuyez sur **Maj+F5** ou cliquez sur **À partir de la diapositive actuelle** pour commencer à la diapositive sur laquelle vous vous trouvez. Le bouton de diaporama de la barre d'état fait de même.

Les diapositives masquées sont ignorées. Après la dernière diapositive, un écran noir affiche « Fin du diaporama, cliquez pour quitter. ». À la fin du diaporama, vous revenez dans la fenêtre, sur la dernière diapositive affichée par le diaporama.

## Se déplacer dans le diaporama

- **Suivant :** cliquez ou appuyez sur Droite, Bas, Espace, Entrée, Pg suiv ou N.
- **Précédent :** cliquez avec le bouton droit ou appuyez sur Gauche, Haut, Retour arrière, Pg préc ou P. Cette action revient d'une étape d'animation en arrière, ou passe à la diapositive précédente.
- **Première et dernière diapositive :** appuyez sur Origine ou Fin.
- **Atteindre une diapositive :** tapez son numéro, puis appuyez sur Entrée.
- **Écran noir :** appuyez sur B ou sur la touche point. Appuyez de nouveau pour réafficher la diapositive. **Écran blanc :** appuyez sur W ou sur la touche virgule.
- **Arrêter le diaporama :** appuyez sur Échap.

Si une diapositive comporte des animations, chaque clic ou chaque touche lance l'étape suivante avant de passer à la suite. Consultez [Animations](animations). Si l'option **Manuellement** est désactivée dans les paramètres de transition d'une diapositive, un clic ne fait pas avancer le diaporama, mais les touches le font. Consultez [Transitions entre les diapositives](transitions).

Un clic sur un lien l'ouvre s'il s'agit d'une page web ou d'une adresse e-mail. Les autres liens n'ont pas encore d'effet dans le diaporama.

## Mode Présentateur avec deux écrans

Avec deux écrans, le diaporama s'affiche sur un écran pour le public, et le mode Présentateur s'ouvre sur l'écran où se trouve la fenêtre. Cela se produit lorsque l'option **Diaporama > Moniteurs > Utiliser le mode Présentateur** est cochée, ce qui est le cas sauf si vous la décochez. Avec un seul écran, le diaporama l'occupe entièrement et le mode Présentateur ne s'ouvre pas.

## Répéter avec le mode Présentateur

Pour tester votre diaporama sur un seul écran, cliquez sur **Diaporama > Moniteurs > Mode Présentateur** ou appuyez sur Alt+F5. Le diaporama s'ouvre dans une petite fenêtre dans un coin de l'écran, et le mode Présentateur s'ouvre à côté.

JeffDeck n'enregistre pas le temps passé sur chaque diapositive. Pour qu'une diapositive passe automatiquement à la suivante, définissez **Après** sous l'onglet **Transitions**.

## Contenu du mode Présentateur

- La diapositive que voit actuellement le public, en grand. Un clic dessus fait avancer le diaporama.
- Sous **Suivante**, la diapositive qu'affichera le prochain clic, ou la même diapositive s'il lui reste des étapes à jouer.
- Vos **Notes** pour la diapositive. Cliquez sur **A+** et **A-** pour agrandir ou réduire le texte. Vous lisez les notes ici et vous les modifiez dans la zone de notes de la fenêtre principale.
- Un minuteur qui compte depuis le début du diaporama, avec **Pause** (qui devient **Reprendre**) et **Réinitialiser**.
- L'heure et le numéro de la diapositive, par exemple « Diapositive 3 sur 12 ».
- Les boutons **Précédente** et **Suivante**, **Écran noir**, **Voir toutes les diapositives** et **Arrêter le diaporama**. **Voir toutes les diapositives** affiche toutes les diapositives sous forme de grille. Cliquez sur l'une d'elles pour l'atteindre.

Les touches ci-dessus fonctionnent dans les deux fenêtres. La fermeture du mode Présentateur arrête le diaporama.
