# Onglet Diaporama
<!-- keywords: onglet diaporama, ruban, à partir du début, à partir de la diapositive actuelle, masquer la diapositive, configurer, moniteurs, utiliser le mode présentateur, mode présentateur, répéter, répétition, lancer, présenter, projeter, f5 -->

L'onglet **Diaporama** permet de lancer le diaporama et de le configurer.

- Le groupe **Démarrage du diaporama** contient **À partir du début** (F5) et **À partir de la diapositive actuelle** (Maj+F5).
- Le groupe **Configurer** contient **Masquer la diapositive**, qui exclut du diaporama la diapositive active.
- Le groupe **Moniteurs** contient la case à cocher **Utiliser le mode Présentateur**, à utiliser lorsque vous disposez de deux écrans, et **Mode Présentateur** (Alt+F5), qui ouvre le diaporama dans une petite fenêtre avec le mode Présentateur à côté, pour vous permettre de répéter sur un seul écran.

Voir [Lancer le diaporama et utiliser le mode Présentateur](show).
