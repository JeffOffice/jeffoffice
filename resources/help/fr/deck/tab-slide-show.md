# Onglet Diaporama

L'onglet **Diaporama** permet de lancer le diaporama et de le configurer.

- Le groupe **Démarrage du diaporama** contient **À partir du début** (F5) et **À partir de la diapositive actuelle** (Maj+F5). **Diaporama personnalisé** affiche la liste de vos diaporamas personnalisés par nom, pour que vous puissiez en lire un. Sa commande **Diaporamas personnalisés** permet de les créer, de les modifier, de les copier et de les supprimer.
- Le groupe **Configurer** contient **Configurer le diaporama**, qui permet de choisir le type de diaporama, les diapositives à lire, la lecture en boucle et le mode de défilement. **Masquer la diapositive** exclut du diaporama la diapositive sur laquelle vous vous trouvez. **Vérification du minutage** lit le diaporama et enregistre le temps passé sur chaque diapositive. La case à cocher **Utiliser le minutage** fait passer automatiquement le diaporama à la diapositive suivante une fois le temps de chaque diapositive écoulé.
- Le groupe **Moniteurs** contient la case à cocher **Utiliser le mode Présentateur**, à utiliser lorsque vous disposez de deux écrans, et **Mode Présentateur** (Alt+F5), qui ouvre le diaporama dans une petite fenêtre avec le mode Présentateur à côté, pour vous permettre de répéter sur un seul écran.

Pendant le diaporama, appuyez sur Ctrl+P pour le stylet, Ctrl+I pour le surligneur, Ctrl+L pour le pointeur laser et Ctrl+E pour la gomme. Appuyez sur Ctrl+A ou Échap pour revenir à la flèche.
