# Pages maîtres, en-têtes et numéros de page
<!-- keywords: page maître, page d'arrière-plan, gabarit, en-tête, pied de page, numéro de page, numérotation, page maître double, pages en vis-à-vis, titre courant, répéter sur chaque page, logo sur chaque page, appliquer la page maître -->

Une page maître est une page d'arrière-plan : tout ce que vous y placez apparaît sur chaque page qui l'utilise. Utilisez une page maître pour les éléments qui se répètent, comme un logo, un en-tête, un pied de page ou des numéros de page. Modifiez la page maître une seule fois, et toutes les pages qui l'utilisent sont modifiées.

## Modifier une page maître

1. Cliquez sur **Affichage > Affichages > Page maître**.
2. L'onglet **Page maître** apparaît. Ajoutez ou modifiez des zones de texte, des images et des formes comme vous le feriez sur une page. La barre d'état indique la page maître sur laquelle vous vous trouvez, par exemple « Page maître A ».
3. Cliquez sur **Page maître > Fermer > Fermer la page maître** lorsque vous avez terminé.

Les objets de la page maître apparaissent sur vos pages, mais vous ne pouvez pas les y sélectionner. Pour les modifier, revenez à la page maître.

## Ajouter et gérer des pages maîtres

Sous l'onglet **Page maître**, dans le groupe **Page maître**, utilisez **Ajouter une page maître**, **Dupliquer**, **Renommer** et **Supprimer**. Chaque page maître reçoit une lettre : A, B, C, etc. La suppression d'une page maître transfère ses pages vers la première page maître. Une composition conserve toujours au moins une page maître.

## Utiliser une page maître sur vos pages

- **Création de page > Pages > Pages maîtres** répertorie vos pages maîtres, par exemple « (A) Page maître A ». Choisissez-en une pour la page active, ou choisissez **Aucun**.
- Sous l'onglet **Page maître**, **Appliquer à** propose **Appliquer à toutes les pages** et **Appliquer à la page active**.
- Cliquez avec le bouton droit sur une page dans la liste des pages, puis choisissez **Pages maîtres**.

Pour modifier une autre page maître, appliquez-la d'abord à une page. Cliquez ensuite sur **Affichage > Affichages > Page maître**.

## Pages maîtres doubles

Les livres comportent des pages en vis-à-vis : une page de gauche et une page de droite. Cliquez sur **Page maître > Disposition > Page maître double** pour concevoir les deux côtés en même temps. La page 1 est une page de droite : les pages impaires utilisent donc la moitié droite et les pages paires la moitié gauche. Dans la fenêtre **Repères de disposition**, l'onglet **Repères de marge** nomme alors les marges latérales **Intérieur** et **Extérieur**.

## Ajouter un en-tête ou un pied de page

Un en-tête est un texte placé en haut de chaque page. Un pied de page est un texte placé en bas.

1. Cliquez sur **Insertion > En-tête et pied de page > En-tête** (ou **Pied de page**).
2. JeffPub ouvre la page maître et place le curseur dans une zone située au-dessus du repère de marge supérieur (ou au-dessous du repère inférieur).
3. Tapez votre texte, puis cliquez sur **Fermer la page maître**.

## Ajouter des numéros de page

1. Cliquez sur **Insertion > En-tête et pied de page > Numéro de page**.
2. Dans la fenêtre **Numéro de page**, choisissez une **Position**, par exemple En bas au centre, et un **Format de numérotation** : 1, 2, 3 ; i, ii, iii ; I, II, III ; ou a, b, c.
3. Désactivez **Afficher le numéro de page sur la première page** si vous ne voulez pas de numéro sur une couverture. JeffPub crée alors une deuxième page maître pour la page 1.
4. Cliquez sur **OK**.

La zone du numéro est placée sur la page maître utilisée par la page active ; elle apparaît donc sur chaque page qui utilise cette page maître. Si le curseur se trouve dans une zone de texte, **Numéro de page** (ou Alt+Maj+P) insère le numéro à cet endroit. La flèche à côté du bouton propose **Insérer le nombre de pages**, pour obtenir « Page 2 sur 8 », et **Format des numéros de page…**, qui définit l'apparence de tous les numéros de page de la composition (1, 2, 3 ; a, b, c ; A, B, C ; i, ii, iii ; ou I, II, III) ainsi que le numéro de départ de la première page. Par exemple, un livre dont la première page est la page 5 commence sa numérotation à 5. Le premier numéro peut aller de 1 à 1000. JeffPub enregistre le premier numéro et le style dans un fichier .pub, et les retrouve à la réouverture.
