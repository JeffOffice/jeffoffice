# Obtenir de l'aide et signaler des problèmes
<!-- keywords: support, assistance, contacter le support, signaler un problème, bogue, bug, commentaires, suggérer, suggestion, demande de fonctionnalité, idée, github, version, plantage, message d'erreur, aide, à propos, mises à jour -->

Si JeffPub se comporte de façon étrange, ou si vous avez une idée pour l'améliorer, faites-le savoir à ceux qui le développent. Cela se passe sur GitHub, un site web où ils assurent le suivi des problèmes et des idées.

## Chercher d'abord une réponse

- Appuyez sur **F1**, ou cliquez sur **Aide > Aide > Aide**, puis tapez quelques mots dans la zone de recherche. Voir [Bienvenue dans JeffPub](start).
- Cliquez sur **Aide > Aide > Raccourcis clavier** pour connaître les touches. Voir [Utiliser JeffPub avec le clavier](keyboard).
- Cliquez sur **Aide > Aide > Nouveautés** pour lire les notes de votre version.
- Si vous avez perdu du travail après la fermeture de JeffPub, voir [Récupérer le travail non enregistré](recover).
- Vérifiez que vous disposez de la dernière version. Cliquez sur **Fichier > À propos**, puis sur **Rechercher des mises à jour**. Le problème est peut-être déjà corrigé.

## Signaler un problème ou suggérer une idée

1. Cliquez sur **Aide > Aide > Commentaires**. Une page GitHub s'ouvre dans votre navigateur web. Un compte GitHub gratuit est nécessaire pour y publier.
2. Donnez-lui un titre court, par exemple « Le texte disparaît à l'impression » ou « Idée : davantage de styles de bordure ».
3. Sous **What would you like to tell us?**, décrivez ce qui n'a pas fonctionné ou ce que vous souhaitez. Notez tout message que vous avez vu.
4. Pour un problème, sous **What did you do just before it happened?**, indiquez vos étapes dans l'ordre, afin que quelqu'un d'autre puisse les reproduire.
5. Laissez la dernière ligne en place. Elle indique votre version de JeffPub et votre système d'exploitation. Si elle manque, ajoutez le numéro de version indiqué dans **Fichier > À propos**.
6. Utilisez le bouton de la page GitHub pour l'envoyer.

Une capture d'écran du problème est utile. Ne publiez pas de composition contenant des informations privées.

## À propos de JeffPub

Cliquez sur **Fichier > À propos** pour voir votre numéro de version, rechercher des mises à jour et lire la licence et les mentions. La page contient aussi des liens vers le code source, les téléchargements et **Signaler un problème**. Pour les options de mise à jour et de statistiques, voir [Modifier les paramètres de JeffPub](options).
