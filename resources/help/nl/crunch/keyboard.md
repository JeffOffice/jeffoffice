# Gebruik JeffCrunch met het toetsenbord
<!-- keywords: toetsenbord, sneltoetsen, toetsen, hotkeys, pijl, ctrl, shift, home, end, page up, page down, tab, enter, alles selecteren, kopiëren, F9, F1, zoomen, toegangstoetsen, toetsenblokjes -->

Op een Mac doet de **Command**-toets (⌘) wat **Ctrl** doet in de onderstaande tabellen, behalve waar een tabel iets anders vermeldt.

## Verplaatsen en selecteren

| Toetsen | Wat ze doen |
| --- | --- |
| Pijltoetsen | Verplaatst de actieve cel één cel, met overslaan van verborgen rijen en kolommen |
| Shift+pijltoets | Breidt de selectie uit met één cel |
| Ctrl+pijltoets | Gaat naar de rand van de gegevens (Esc stopt een lange zoekactie) |
| Ctrl+Shift+pijltoets | Breidt de selectie uit tot de rand van de gegevens |
| Home | Gaat naar de eerste kolom van de rij |
| Ctrl+Home | Gaat naar de eerste cel (A1, of de eerste cel die scrolt als rijen of kolommen zijn vastgezet) |
| Ctrl+End | Gaat naar de laatste cel die iets bevat of een opmaak heeft |
| Page Down, Page Up | Verplaatst omlaag of omhoog met één scherm |
| Tab, Shift+Tab | Verplaatst naar rechts of links (door de geselecteerde cellen, als er meerdere zijn) |
| Enter, Shift+Enter | Verplaatst omlaag of omhoog (door de geselecteerde cellen, als er meerdere zijn) |
| Ctrl+spatiebalk | Selecteert de hele kolom |
| Shift+spatiebalk | Selecteert de hele rij |
| {key:SelectAll} | Selecteert alles |

## Cellen wijzigen

| Toetsen | Wat ze doen |
| --- | --- |
| Elk teken | Begint een invoer in de actieve cel, in plaats van wat de cel bevat |
| F2 | Bewerkt wat de actieve cel bevat, in de cel; tijdens het typen van een formule schakelt u tussen het aanwijzen van cellen en het bewerken van de tekst |
| F4 | Tijdens het typen van een formule zet u delen van het adres bij de cursor vast met $ (A1, $A$1, A$1, $A1) |
| Enter, Shift+Enter | Bevestigt de invoer en gaat omlaag of omhoog |
| Tab, Shift+Tab | Bevestigt de invoer en gaat naar rechts of links |
| Esc | Annuleert de invoer |
| Alt+Enter | Begint een nieuwe regel in de cel |
| Delete | Wist de geselecteerde cellen |
| {key:Undo}, {key:Redo} | Ongedaan maken, opnieuw |
| {key:Save} | Opslaan |
| {key:Cut}, {key:Copy}, {key:Paste} | Knippen, kopiëren, plakken (Esc haalt de rand weg van de gekopieerde cellen) |
| Ctrl+Alt+V | Plakken speciaal |
| Ctrl en het plusteken, Ctrl en het minteken | Invoegen, verwijderen (rijen of kolommen als hele rijen of kolommen zijn geselecteerd) |
| Ctrl+D, Ctrl+R | Omlaag doorvoeren, naar rechts doorvoeren |
| Ctrl+E | Snel invullen |
| Alt en het isgelijkteken | Som |
| Ctrl+0, Ctrl+9 | Verbergt de kolommen, verbergt de rijen |
| Alt+pijl omlaag | Opent de lijst van een cel die een lijst heeft |
| {key:Find} | Zoeken |
| Ctrl+H (op een Mac Optie+Command+F) | Zoeken en vervangen |
| F5, Ctrl+G | Gaat naar een cel, een celbereik of een naam |
| Ctrl+Shift+L | Schakelt het filter in of uit |
| Shift+F3 | Kiest een functie |
| Ctrl+F3 | De lijst met namen |
| F9, Shift+F9 | Alles opnieuw berekenen, dit blad opnieuw berekenen |
| Tab, Enter | Terwijl een formule wordt getypt: neemt de functie of naam over die in de lijst is gemarkeerd |
| Esc | Stopt een lopende zoekactie, sortering of filter |

## Toegangstoetsen

Druk op **Alt** om op elk linttabblad en bij elke opdracht een letter te zien, en druk daarna op de letters. Druk op **Alt** en daarna op **F** om het scherm Bestand te openen. Druk op **Esc** om terug te gaan.
