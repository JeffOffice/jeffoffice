# JeffCrunch gebruiken met het toetsenbord
<!-- keywords: toetsenbord, sneltoetsen, toetsen, toetscombinaties, pijltoetsen, ctrl, shift, home, end, page up, page down, tab, enter, alles selecteren, kopiëren, F9, F1, zoomen, toegangstoetsen, toetsenblokjes -->

Op een Mac doet de **Command**-toets (⌘) wat **Ctrl** doet in de onderstaande tabellen, behalve waar een tabel iets anders aangeeft.

## Verplaatsen en selecteren

| Toetsen | Wat ze doen |
| --- | --- |
| Pijltoetsen | De actieve cel één cel verplaatsen, verborgen rijen en kolommen worden overgeslagen |
| Shift+pijltoets | De selectie met één cel uitbreiden |
| Ctrl+pijltoets | Naar de rand van de gegevens gaan (Esc stopt een lange zoekactie) |
| Ctrl+Shift+pijltoets | De selectie uitbreiden tot de rand van de gegevens |
| Home | Naar de eerste kolom van de rij gaan |
| Ctrl+Home | Naar de eerste cel gaan (A1, of de eerste cel die meeschuift als rijen of kolommen zijn geblokkeerd) |
| Ctrl+End | Naar de laatste cel gaan die iets bevat of een opmaak heeft |
| Page Down, Page Up | Een scherm omlaag of omhoog gaan |
| Tab, Shift+Tab | Naar rechts of links gaan (door de geselecteerde cellen, als er meerdere zijn) |
| Enter, Shift+Enter | Omlaag of omhoog gaan (door de geselecteerde cellen, als er meerdere zijn) |
| Ctrl+spatiebalk | De hele kolom selecteren |
| Shift+spatiebalk | De hele rij selecteren |
| {key:SelectAll} | Alles selecteren |

## Cellen wijzigen

| Toetsen | Wat ze doen |
| --- | --- |
| Elk teken | Een invoer in de actieve cel beginnen, ter vervanging van wat erin staat |
| F2 | De inhoud van de actieve cel in de cel bewerken |
| Enter, Shift+Enter | De invoer behouden en omlaag of omhoog gaan |
| Tab, Shift+Tab | De invoer behouden en naar rechts of links gaan |
| Esc | De invoer annuleren |
| Alt+Enter | Een nieuwe regel in de cel beginnen |
| Delete | De geselecteerde cellen wissen |
| {key:Undo}, {key:Redo} | Ongedaan maken, opnieuw |
| {key:Save} | Opslaan |
| {key:Cut}, {key:Copy}, {key:Paste} | Knippen, kopiëren, plakken (Esc verwijdert de rand rond de gekopieerde cellen) |
| Ctrl+Alt+V | Plakken speciaal |
| Ctrl en de plustoets, Ctrl en de mintoets | Invoegen, verwijderen (rijen of kolommen als hele rijen of kolommen zijn geselecteerd) |
| Ctrl+D, Ctrl+R | Omlaag doorvoeren, naar rechts doorvoeren |
| Alt en het isgelijkteken | AutoSom |
| Ctrl+0, Ctrl+9 | De kolommen verbergen, de rijen verbergen |
| Alt+pijl-omlaag | De lijst openen van een cel die een lijst heeft |
| {key:Find} | Zoeken |
| Ctrl+H (op een Mac Option+Command+F) | Zoeken en vervangen |
| F5, Ctrl+G | Naar een cel, een bereik of een naam gaan |
| Ctrl+Shift+L | Het filter in- of uitschakelen |
| Shift+F3 | Een functie kiezen |
| Ctrl+F3 | De lijst met namen |
| F9, Shift+F9 | Alles opnieuw berekenen, dit blad opnieuw berekenen |
| Tab, Enter | Tijdens het typen van een formule: de functie of naam overnemen die in de lijst is gemarkeerd |
| Esc | Een lopende zoekactie, sortering of filtering stoppen |

## Toegangstoetsen

Druk op **Alt** om een letter te zien bij elk tabblad en elke opdracht op het lint en druk dan op de letters. Druk op **Alt** en dan op **F** voor het scherm Bestand. Druk op **Esc** om terug te gaan.
