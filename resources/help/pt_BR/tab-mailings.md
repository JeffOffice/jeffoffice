# Guia Correspondências
<!-- keywords: guia correspondências, guia mala direta, destinatários, campos de mesclagem, etiquetas, cartas modelo, cartas personalizadas, faixa de opções -->

A guia **Correspondências** está sempre na faixa de opções. Ela reúne as ferramentas de mala direta, que preenche uma publicação com dados de uma lista de pessoas. Para abri-la pelo teclado, pressione **Alt** e depois **M**.

- **Iniciar**: inicie o assistente de mala direta ou uma mesclagem para email, escolha ou digite uma lista de destinatários e edite-a. Consulte [Mala direta e mesclagem de catálogo](mail-merge).
- **Gravar e Inserir Campos**: adicione um bloco de endereço, uma linha de saudação, um campo de mesclagem ou um campo de imagem. Consulte [Mala direta e mesclagem de catálogo](mail-merge).
- **Visualizar Resultados**: veja os dados reais no lugar dos campos e percorra os registros. Consulte [Mala direta e mesclagem de catálogo](mail-merge).
- **Concluir**: mescle para a impressora, para uma nova publicação, para um PDF ou para email, ou exporte a lista. Consulte [Mala direta e mesclagem de catálogo](mail-merge).
