# Usar o JeffPub com o teclado
<!-- keywords: teclado, atalhos, teclas de atalho, atalhos de teclado, dicas de tecla, keytips, tecla alt, f6, tecla tab, teclas de direção, setas, sem mouse, navegar, navegação, teclas de acesso, foco, faixa de opções pelo teclado -->

Você pode acessar os comandos da faixa de opções, a lista de páginas e os objetos da página sem usar o mouse. Há três maneiras: teclas de atalho para comandos comuns, Dicas de Tecla para a faixa de opções e a navegação com F6, Tab e as teclas de direção.

## Mover-se entre as partes da janela

Pressione **F6** para mover o **foco** do teclado (o local para onde vai o próximo pressionamento de tecla) para a próxima parte da janela. A ordem é a faixa de opções, a lista de páginas, a página e de volta à faixa de opções. Pressione **Shift+F6** para ir no sentido contrário. Se a lista de páginas estiver oculta, ela será ignorada. Quando você usa o teclado, um contorno colorido mostra qual controle está com o foco.

Pressione **F1** para obter Ajuda sobre o que você está fazendo. Pressione **Ctrl+F1** para recolher ou expandir a faixa de opções.

## Usar as Dicas de Tecla na faixa de opções

As Dicas de Tecla são pequenas letras que aparecem na faixa de opções. Com elas, você acessa qualquer botão sem o mouse.

1. Pressione e solte **Alt**. Aparecem letras no botão **Arquivo**, em cada guia e na Barra de Ferramentas de Acesso Rápido. Os botões da Barra de Ferramentas de Acesso Rápido usam os números de 1 a 4.
2. Pressione a letra da guia desejada, como **H** para **Página Inicial**. Aparecem as letras dos botões dessa guia.
3. Digite as letras do botão desejado. Por exemplo, **T** e depois **B** corresponde a **Desenhar caixa de texto**.

Você também pode manter Alt pressionada e pressionar a letra de uma guia de uma só vez. Alt+H abre a guia **Página Inicial**. Alt+F abre a página **Arquivo**. Alt+Y abre a guia **Ajuda**.

Pressione **Esc** para voltar uma etapa. Pressione qualquer outra tecla para ocultar as letras. Letras esmaecidas pertencem a um botão que não pode ser usado no momento, como um que exige um objeto selecionado.

## Mover-se pela faixa de opções com as teclas de direção

1. Pressione F6 para ir até a guia atual.
2. Pressione **Seta para a Esquerda** ou **Seta para a Direita** para trocar de guia.
3. Pressione **Seta para Baixo** para entrar nos botões. Use as teclas de direção para se mover entre eles. **Tab** e **Shift+Tab** também levam ao controle seguinte ou anterior.
4. Pressione **Enter** ou **Espaço** para usar um botão. Um botão com menu abre o menu.
5. Pressione **Esc** para voltar à página.

## Trabalhar na página

Clique na área da página ou pressione F6 até chegar a ela. Em seguida:

- **Tab** seleciona o próximo objeto. **Shift+Tab** seleciona o anterior.
- As **teclas de direção** deslocam o objeto selecionado um pouco. Mantenha **Alt** pressionada para o menor deslocamento. Para definir o tamanho do deslocamento, consulte [Alterar as configurações do JeffPub](options).
- **Enter** ou **F2** edita o texto da caixa de texto, forma ou tabela selecionada. Você também pode simplesmente começar a digitar.
- **Delete** exclui o objeto selecionado. Com células de uma tabela selecionadas, ela apaga o texto delas.
- **Esc** encerra a edição do texto. A caixa de texto continua selecionada. Pressione Esc novamente para cancelar a seleção.

Enquanto você digita em uma tabela, **Tab** leva à próxima célula. Pressionar Tab na última célula adiciona uma linha.
