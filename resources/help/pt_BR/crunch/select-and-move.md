# Selecionar células e navegar
<!-- keywords: selecionar, seleção, célula, intervalo, linha, coluna, clicar, arrastar, shift, ctrl, setas, home, end, page up, page down, tab, enter, linha inteira, coluna inteira, caixa de nome, ir para, rolar, barra de status, soma, média, contagem -->

**Selecionar** células significa escolher aquelas às quais o próximo comando se aplica. As células selecionadas ficam coloridas, com uma borda verde ao redor. A **célula ativa** é a que tem o cursor, e ela continua branca dentro da seleção.

## Com o mouse

- **Clique** em uma célula para selecioná-la. Clique dentro de uma célula mesclada para selecionar a célula mesclada inteira.
- **Arraste** sobre as células para selecionar um bloco. Se você arrastar além da borda da janela, a planilha rola.
- Use **Shift+clique** em outra célula para selecionar da célula ativa até ela.
- Clique em uma **letra de coluna** ou em um **número de linha** para selecionar a coluna ou a linha inteira. Arraste sobre as letras ou os números, ou use Shift+clique, para selecionar várias.
- Clique no **canto** onde as letras e os números se encontram para selecionar tudo.
- Gire a **roda do mouse** para rolar três linhas. Mantenha **Shift** pressionada para rolar para os lados, ou **Ctrl** para aplicar zoom.

## Com o teclado

As teclas de direção movem a célula ativa, pulando linhas e colunas ocultas. Mantenha **Shift** pressionada para estender a seleção. **Ctrl** com uma seta vai até a borda dos dados: até o fim de uma sequência de células com conteúdo ou, a partir do fim de uma sequência, até a próxima célula com conteúdo. Consulte [Usar o JeffCrunch com o teclado](keyboard) para ver todas as teclas.

## Ir para uma célula

Digite um endereço na **Caixa de nome**, como **C5**, **A1:D10**, **B:D** ou **3:7**, e pressione **Enter**.

## Os números da seleção

Quando você seleciona duas ou mais células, a barra de status mostra a **média**, a **contagem** e a **soma** das células. A contagem é o número de células com conteúdo; a média e a soma usam apenas os números. Linhas e colunas ocultas não são consideradas. Para copiar a seleção como texto, pressione **Ctrl+C**.
