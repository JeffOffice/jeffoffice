A guia **Ajuda** tem **Ajuda** (F1), **Atalhos de Teclado**, que abre esta página, **Novidades** e **Feedback**, que abrem as respectivas páginas da web.

No Mac, a tecla **Command** (⌘) faz o que **Ctrl** faz nas tabelas abaixo, exceto quando a tabela indicar o contrário.

## Movendo e selecionando

| Teclas | O que fazem |
| --- | --- |
| Teclas de seta | Movem a célula ativa uma célula, pulando linhas e colunas ocultas |
| Shift+seta | Estende a seleção uma célula |
| Ctrl+seta | Vai até a borda dos dados (Esc interrompe uma pesquisa longa) |
| Ctrl+Shift+seta | Estende a seleção até a borda dos dados |
| End, depois uma seta | Vai até a borda dos dados (a barra de status mostra End) |
| Ctrl+A | Seleciona o intervalo ao redor da célula ativa e, depois, a planilha inteira (a planilha inteira de uma vez, quando a seleção já for maior que o intervalo) |
| Ctrl+Shift+* | Seleciona o intervalo ao redor da célula ativa |
| Ctrl+clique ou Ctrl+arrastar | Adiciona um intervalo à seleção |
| Ctrl+Shift+Enter | Insere a fórmula como fórmula de matriz sobre as células selecionadas |
| Home | Vai até a primeira coluna da linha |
| Ctrl+Home | Vai até a primeira célula (A1, ou a primeira célula que rola quando linhas ou colunas estão congeladas) |
| Ctrl+End | Vai até a última célula que contém algo ou tem formatação |
| Page Down, Page Up | Desce ou sobe uma tela |
| Tab, Shift+Tab | Move para a direita ou para a esquerda (pelas células selecionadas, se houver várias) |
| Enter, Shift+Enter | Desce ou sobe (pelas células selecionadas, se houver várias) |
| Ctrl+Espaço | Seleciona a coluna inteira |
| Shift+Espaço | Seleciona a linha inteira |
| {key:SelectAll} | Seleciona tudo |

## Alterando células

| Teclas | O que fazem |
| --- | --- |
| Qualquer caractere | Inicia uma entrada na célula ativa, no lugar do que ela contém |
| F2 | Edita o conteúdo da célula ativa, na própria célula; ao digitar uma fórmula, alterna entre apontar para células e editar o texto |
| F4 | Ao digitar uma fórmula, fixa partes do endereço na posição do cursor com $ (A1, $A$1, A$1, $A1) |
| Enter, Shift+Enter | Confirma a entrada e desce ou sobe |
| Tab, Shift+Tab | Confirma a entrada e move para a direita ou para a esquerda |
| Esc | Cancela a entrada |
| Alt+Enter | Inicia uma nova linha na célula |
| Delete | Limpa as células selecionadas |
| {key:Undo}, {key:Redo} | Desfazer, refazer |
| {key:Save} | Salvar |
| {key:Cut}, {key:Copy}, {key:Paste} | Recortar, copiar, colar (Esc remove a borda das células copiadas) |
| Ctrl+Alt+V | Colar Especial |
| Ctrl e a tecla de mais, Ctrl+Shift e a tecla de mais, Ctrl e a tecla de menos | Inserir, excluir (linhas ou colunas, se forem selecionadas inteiras; as teclas de mais inserem células recortadas ou copiadas sem alterações desde a cópia e, do contrário, células em branco) |
| Teclas de seta, Shift+seta, Ctrl+seta (Option+seta no Mac), Enter, Esc | Depois de Mover ou Redimensionar Nota: movem a caixa da nota, redimensionam-na, fazem os passos de 1 pixel, confirmam ou cancelam |
| Ctrl+D, Ctrl+R | Preencher para baixo, preencher para a direita |
| Ctrl+E | Preenchimento Relâmpago |
| Alt e o sinal de igual | Soma |
| Ctrl+0, Ctrl+9 | Ocultar colunas, ocultar linhas |
| Alt+Seta para baixo | Abre a lista de uma célula que tenha uma |
| {key:Find} | Localizar |
| Ctrl+H (no Mac, Option+Command+F) | Localizar e Substituir |
| F5, Ctrl+G | Ir para uma célula, um intervalo ou um nome |
| Ctrl+Shift+L | Ativa ou desativa o filtro |
| Shift+F3 | Escolher uma função |
| Ctrl+F3 | A lista de nomes |
| F9, Shift+F9 | Recalcular tudo, recalcular esta planilha |
| Tab, Enter | Ao digitar uma fórmula: escolhe a função ou o nome marcado na lista |
| Esc | Interrompe uma pesquisa, uma classificação ou um filtro em andamento |

## Escolha suas próprias teclas de atalho

Você pode alterar as teclas de qualquer comando ou atribuir uma tecla a um comando que não tenha nenhuma. Clique em **Arquivo > Opções** e, em seguida, na guia **Personalizar**.

1. Digite na caixa **Pesquisar** para encontrar um comando pelo nome ou pelas teclas. A lista é agrupada pelas guias da faixa de opções, e cada comando mostra as suas teclas. Os comandos que não estão na faixa de opções aparecem em **Outros**.
2. Clique no comando. As teclas dele aparecem em **Teclas para este comando**.
3. Clique na caixa **Substituir pelas novas teclas**... *(ver nota)* 

Observação: o texto acima usa a denominação exata do programa para a caixa, que é **Pressione as novas teclas**. Corrigindo o passo:

3. Clique na caixa **Pressione as novas teclas** e pressione as teclas desejadas, como **Ctrl+Shift+B**. Em seguida, clique em **Atribuir**. Um comando pode ter até quatro teclas.
4. Para remover uma tecla, clique nela na lista e depois em **Remover**.

Se outro comando já usar as teclas pressionadas, o JeffCrunch informa qual é. Clique em **Substituir Atribuição** para dar as teclas a este comando; o outro comando perde essas teclas. Nada muda até você clicar em **OK**. Depois disso, todas as janelas abertas do JeffCrunch usam as suas teclas, assim como qualquer janela que você abrir depois. Dicas de tela, menus e a tabela de atalhos abaixo mostram as suas teclas.

Um símbolo também pode ter teclas. Veja **Inserir um símbolo** em [Digitar em células](edit-cells): clique em **Tecla de Atalho** na caixa Símbolo. Ele então aparece nesta lista como qualquer comando.

**Redefinir Um** restaura as teclas usuais do comando escolhido. **Redefinir Tudo** restaura as teclas usuais de todos os comandos. O JeffCrunch guarda apenas os comandos cujas teclas você alterou, de modo que um comando que você não alterou recebe as teclas melhores que uma versão posterior lhe atribuir.

Algumas teclas não podem ser atribuídas a um comando, porque o sistema ou a digitação as utilizam. O JeffCrunch informa **reservada** quando você pressiona uma delas. As teclas reservadas são **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z**, **Ctrl+A**, **Tab**, **Shift+Tab**, **Enter**, **Esc**, **Backspace**, **Delete**, **Alt+F4**, as teclas de seta, **Home**, **End**, **Page Up**, **Page Down** e **Espaço**, **F1**, **F6**, **Shift+F6**, **Ctrl+Y**, **Ctrl+Shift+Z**, **Ctrl** com uma seta, **Home**, **End**, **Backspace** ou **Delete** (com ou sem **Shift**, quando isso faz sentido em uma caixa de texto), e uma tecla de letra, número ou símbolo pressionada sozinha ou com **Shift**. Uma tecla que outra parte da janela já usa também é reservada. **Salvar**, **Desfazer** e **Refazer** sempre mantêm pelo menos uma tecla. No Mac, **Ctrl** aqui significa a tecla **Command**.

## Teclas de acesso

Pressione **Alt** para ver uma letra em cada guia e comando da faixa de opções e, em seguida, pressione as letras. Pressione **Alt** e depois **F** para abrir a tela Arquivo. Pressione **Esc** para voltar.
