A guia **Ajuda** tem **Ajuda** (F1), **Atalhos de Teclado**, que abre esta página, **Novidades** e **Feedback**, que abrem suas respectivas páginas da web.

Em um Mac, a tecla **Command** (⌘) faz o que **Ctrl** faz nas tabelas abaixo, exceto quando uma tabela indicar o contrário.

## Mover e selecionar

| Teclas | O que fazem |
| --- | --- |
| Teclas de seta | Movem a célula ativa uma célula, pulando linhas e colunas ocultas |
| Shift+seta | Estendem a seleção uma célula |
| Ctrl+seta | Vão até a borda dos dados (Esc interrompe uma pesquisa longa) |
| Ctrl+Shift+seta | Estendem a seleção até a borda dos dados |
| End, depois uma seta | Vão até a borda dos dados (a barra de status mostra End) |
| Ctrl+A | Selecionam o intervalo em volta da célula ativa e, depois, a planilha inteira (a planilha inteira de uma vez, quando a seleção já for maior que o intervalo) |
| Ctrl+Shift+* | Selecionam o intervalo em volta da célula ativa |
| Ctrl+clique ou Ctrl+arrastar | Adicionam um intervalo à seleção |
| Ctrl+Shift+Enter | Insere a fórmula como fórmula de matriz sobre as células selecionadas |
| Home | Vai até a primeira coluna da linha |
| Ctrl+Home | Vai até a primeira célula (A1, ou a primeira célula que rola quando linhas ou colunas estão congeladas) |
| Ctrl+End | Vai até a última célula que contém algo ou tem formatação |
| Page Down, Page Up | Descem ou sobem uma tela |
| Tab, Shift+Tab | Movem para a direita ou para a esquerda (pelas células selecionadas, se houver várias) |
| Enter, Shift+Enter | Movem para baixo ou para cima (pelas células selecionadas, se houver várias) |
| Ctrl+Espaço | Seleciona a coluna inteira |
| Shift+Espaço | Seleciona a linha inteira |
| {key:SelectAll} | Seleciona tudo |

## Alterar células

| Teclas | O que fazem |
| --- | --- |
| Qualquer caractere | Inicia uma entrada na célula ativa, no lugar do que ela contém |
| F2 | Edita o conteúdo da célula ativa, na própria célula; ao digitar uma fórmula, alterna entre apontar para células e editar o texto |
| F4 | Ao digitar uma fórmula, fixa partes do endereço no cursor com $ (A1, $A$1, A$1, $A1) |
| Enter, Shift+Enter | Confirmam a entrada e movem para baixo ou para cima |
| Tab, Shift+Tab | Confirmam a entrada e movem para a direita ou para a esquerda |
| Esc | Cancela a entrada |
| Alt+Enter | Inicia uma nova linha na célula |
| Delete | Limpa as células selecionadas |
| {key:Undo}, {key:Redo} | Desfazer, refazer |
| F4 | Repete o último comando nas células selecionadas (Ctrl+Y também faz isso, quando não há nada para refazer) |
| {key:Save} | Salvar |
| {key:Cut}, {key:Copy}, {key:Paste} | Recortar, copiar, colar (Esc remove a borda das células copiadas) |
| Ctrl+Alt+V | Colar Especial |
| Ctrl e a tecla de mais, Ctrl+Shift e a tecla de mais, Ctrl e a tecla de menos | Inserem e excluem (linhas ou colunas, se linhas ou colunas inteiras estiverem selecionadas; as teclas de mais inserem células recortadas ou copiadas sem alterações desde então e, caso contrário, células em branco) |
| Teclas de seta, Shift+seta, Ctrl+seta (Option+seta em um Mac), Enter, Esc | Depois de Mover ou Redimensionar Nota: movem a caixa da nota, redimensionam-na, definem os passos como 1 pixel, mantêm a alteração ou a descartam |
| Ctrl+D, Ctrl+R | Preencher para baixo, preencher para a direita |
| Ctrl+E | Preenchimento Relâmpago |
| Alt e o sinal de igual | Soma |
| Ctrl+0, Ctrl+9 | Ocultam as colunas, ocultam as linhas |
| Alt+Seta para baixo | Abre a lista de uma célula que tenha uma |
| {key:Find} | Localizar |
| Ctrl+H (em um Mac, Option+Command+F) | Localizar e Substituir |
| F5, Ctrl+G | Ir para uma célula, um intervalo ou um nome |
| Ctrl+Shift+L | Ativa ou desativa o filtro |
| Shift+F3 | Escolher uma função |
| Ctrl+F3 | A lista de nomes |
| F9, Shift+F9 | Recalcular tudo, recalcular esta planilha |
| Tab, Enter | Enquanto uma fórmula está sendo digitada: aceitam a função ou o nome marcado na lista |
| Esc | Interrompe uma pesquisa, uma classificação ou um filtro em andamento |

## Escolha suas próprias teclas de atalho

Você pode alterar as teclas de qualquer comando ou atribuir uma tecla a um comando que não tem nenhuma. Clique em **Arquivo > Opções** e, depois, na guia **Personalizar**.

1. Digite na caixa **Pesquisar** para encontrar um comando pelo nome ou pelas teclas. A lista é agrupada pelas guias da faixa de opções, e cada comando mostra suas teclas. Os comandos que não estão na faixa de opções aparecem em **Outros**.
2. Clique no comando. Suas teclas aparecem em **Teclas para este comando**.
3. Clique na caixa **Pressione as novas teclas** e pressione as teclas desejadas, como **Ctrl+Shift+B**. Depois, clique em **Atribuir**. Um comando pode ter até quatro teclas.
4. Para remover uma tecla, clique nela na lista e clique em **Remover**.

Se outro comando já usar as teclas que você pressionou, o JeffCrunch informa qual é. Clique em **Assumir Atribuição** para dar essas teclas a este comando; o outro comando as perde. Nada muda até você clicar em **OK**. Depois disso, todas as janelas abertas do JeffCrunch usam suas teclas, assim como qualquer janela que você abrir depois. Dicas de tela, menus e a tabela de atalhos abaixo mostram suas teclas.

Um símbolo também pode ter teclas. Veja **Inserir um símbolo** em [Digitar em células](edit-cells): clique em **Tecla de Atalho** na caixa Símbolo. Ele então aparece nesta lista como qualquer comando.

**Redefinir Um** restaura as teclas usuais do comando escolhido. **Redefinir Tudo** restaura as teclas usuais de todos os comandos. O JeffCrunch guarda apenas os comandos cujas teclas você alterou, de modo que um comando que você não alterou recebe as teclas melhores que uma versão posterior lhe atribuir.

Algumas teclas não podem ser atribuídas a um comando, porque o sistema ou a digitação as utilizam. O JeffCrunch informa **reservada** quando você pressiona uma delas. As teclas reservadas são **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z**, **Ctrl+A**, **Tab**, **Shift+Tab**, **Enter**, **Esc**, **Backspace**, **Delete**, **Alt+F4**, as teclas de seta, **Home**, **End**, **Page Up**, **Page Down** e **Espaço**, **F1**, **F6**, **Shift+F6**, **Ctrl+Y**, **Ctrl+Shift+Z**, **Ctrl** com uma seta, **Home**, **End**, **Backspace** ou **Delete** (com ou sem **Shift**, quando isso fizer sentido em uma caixa de texto), e uma letra, um dígito ou uma tecla de símbolo pressionados sozinhos ou com **Shift**. Uma tecla que outra parte da janela já usa também é reservada. **Salvar**, **Desfazer** e **Refazer** sempre mantêm pelo menos uma tecla. Em um Mac, **Ctrl** aqui significa a tecla **Command**.

## Teclas de acesso

Pressione **Alt** para ver uma letra em cada guia e comando da faixa de opções e, depois, pressione as letras. Pressione **Alt** e, depois, **F** para abrir a tela Arquivo. Pressione **Esc** para voltar.
