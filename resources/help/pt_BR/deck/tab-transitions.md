# Guia Transições

A guia **Transições** define como a apresentação de slides passa para o slide em que você está.

- **Visualizar** tem o botão **Visualizar**, que reproduz a transição no slide para que você possa vê-la.
- **Transição para Este Slide** é uma galeria de efeitos: **Nenhum**, **Transformar**, **Esmaecer**, **Empurrar**, **Revelar Gradualmente**, **Dividir**, **Revelar**, **Cobrir**, **Descobrir**, **Zoom**, **Cortar**, **Dissolver**, **Persianas**, **Damas**, **Pente**, **Barras Aleatórias**, **Círculo**, **Losango**, **Cruz**, **Cunha**, **Roda**, **Forma**, **Clarão**, **Notícia Relâmpago**, **Faixas** e **Aleatório**. **Opções de Efeito** escolhe a direção, **Para Fora** e **Para Dentro**, horizontal ou vertical, os raios de uma roda ou o formato de uma forma, para os efeitos que os têm. Para **Transformar**, escolhe **Objetos**, **Palavras** ou **Caracteres**.
- **Intervalo** tem **Duração**, **Ao Clicar com o Mouse**, **Após** com os respectivos segundos, e **Aplicar a Todos**. Uma transformação dura 2 segundos ao ser escolhida. Os demais efeitos duram 0,7 segundo.

Veja [Transições entre slides](transitions).
