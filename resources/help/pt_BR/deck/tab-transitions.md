# Guia Transições
<!-- keywords: guia transições, aba transições, faixa de opções, visualizar, transição para este slide, opções de efeito, duração, ao clicar com o mouse, após, aplicar a todos, transformar, morph, objetos, palavras, caracteres, esmaecer, empurrar, revelar, dividir, cobrir, descobrir, zoom, recortar, efeito de transição, passagem de slide -->

A guia **Transições** define como a apresentação de slides passa para o slide em que você está.

- **Visualizar** tem o comando **Visualizar**, que reproduz a transição para o slide para que você possa vê-la.
- **Transição para Este Slide** é uma galeria de efeitos: **Nenhuma**, **Transformar**, **Esmaecer**, **Empurrar**, **Revelar**, **Dividir**, **Revelar Gradualmente**, **Cobrir**, **Descobrir**, **Zoom** e **Recortar**. **Opções de Efeito** escolhe a direção, ou **Para Fora** e **Para Dentro**, nos efeitos que têm essas opções. Para **Transformar**, escolhe **Objetos**, **Palavras** ou **Caracteres**.
- **Intervalo** tem **Duração**, **Ao Clicar com o Mouse**, **Após** com os segundos e **Aplicar a Todos**. Uma transformação leva 2 segundos quando você a escolhe. Os outros efeitos levam 0,7 segundo.

Consulte [Transições entre slides](transitions).
