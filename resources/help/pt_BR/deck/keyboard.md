# Use o JeffDeck com o teclado
<!-- keywords: teclado, atalhos, teclas de atalho, atalhos de teclado, dicas de tecla, keytips, tecla alt, tecla tab, teclas de seta, sem mouse, navegar, teclas de acesso, teclas da apresentação de slides, f5, esc -->

Você pode fazer a maior parte das coisas no JeffDeck sem usar o mouse. Há teclas de atalho para comandos comuns, Dicas de Tecla para a faixa de opções, e teclas que funcionam no slide, no painel de slides, na Classificação de Slides, no modo de exibição de Estrutura de Tópicos e na apresentação de slides.

## Use as Dicas de Tecla na faixa de opções

As Dicas de Tecla são pequenas letras que aparecem na faixa de opções. Elas permitem chegar a qualquer botão sem o mouse.

1. Pressione e solte **Alt**. Letras aparecem no botão **Arquivo**, em cada guia e na barra de ferramentas rápida. Os botões da barra de ferramentas rápida usam os números de 1 a 3.
2. Pressione a letra da guia que você quer. As guias usam **P** para **Página Inicial**, **N** para **Inserir**, **G** para **Design**, **K** para **Transições**, **S** para **Apresentação de Slides**, **R** para **Revisão** e **W** para **Exibir**. Aparecem as letras dos botões dessa guia.
3. Digite as letras do botão que você quer. Por exemplo, pressione **Alt**, depois **S**, depois **B** para iniciar a apresentação de slides **Do Começo**.

Você também pode manter Alt pressionada e apertar a letra de uma guia de uma só vez. **Alt+P** abre a guia **Página Inicial**. **Alt+A** abre a tela Arquivo.

Pressione **Esc** para voltar um passo. Pressione qualquer outra tecla para ocultar as letras. As letras que parecem apagadas pertencem a um botão que você não pode usar agora.

Pressione **Ctrl+F1** para ocultar os botões da faixa de opções e mostrar apenas os nomes das guias, para ter mais espaço no slide. Pressione de novo para mostrá-los.

## Trabalhe no slide

Clique no slide. Depois:

- **Ctrl+Page Down** vai para o próximo slide, e **Ctrl+Page Up** para o anterior.
- **Tab** seleciona o próximo objeto. **Shift+Tab** seleciona o anterior.
- As **teclas de seta** movem o objeto selecionado um pequeno passo. Mantenha **Alt** pressionada para o menor passo.
- **Enter** ou **F2** edita o texto da caixa de texto, espaço reservado, forma ou tabela selecionada. Você também pode simplesmente começar a digitar.
- **Delete** remove o objeto selecionado.
- **Ctrl+1** abre o painel Formatar Forma para o objeto selecionado.
- **Shift+F10** ou a tecla **Menu** abre o menu de clique com o botão direito no objeto selecionado ou no cursor de texto.
- **Ctrl+F** localiza palavras nos slides e nas anotações. **Ctrl+H** substitui. **Ctrl+G** vai para um slide pelo seu número.
- **Esc** para de editar o texto. A caixa continua selecionada. Pressione Esc de novo para desfazer a seleção.

Ao digitar em uma tabela, **Tab** vai para a próxima célula. Tab na última célula adiciona uma linha.

## No painel de slides

Clique no painel e depois:

- **Seta para Cima** e **Seta para Baixo** vão para o slide anterior ou seguinte. **Home** e **End** vão para o primeiro e o último slide.
- **Enter** adiciona um novo slide depois do que você está.
- **Delete** exclui o slide em que você está.

## Na Classificação de Slides

- As **teclas de seta**, **Home**, **End**, **Page Up** e **Page Down** percorrem a grade. Mantenha **Shift** pressionada para selecionar enquanto se move.
- **Ctrl+A** seleciona todos os slides. **Ctrl+D** duplica os slides selecionados. **Delete** os exclui.
- **Enter** abre o slide no modo de exibição Normal.

## No modo de exibição de Estrutura de Tópicos

- **Enter** no fim de um título inicia um novo slide.
- **Tab** move uma linha para um nível abaixo. **Shift+Tab** a move um nível acima.

## Na apresentação de slides

- **Seta para a Direita**, **Seta para Baixo**, **Espaço**, **Enter**, **Page Down** ou **N** avançam.
- **Seta para a Esquerda**, **Seta para Cima**, **Backspace**, **Page Up** ou **P** voltam.
- **Home** e **End** vão para o primeiro e o último slide. O número de um slide seguido de **Enter** vai para esse slide.
- **B** ou a tecla de ponto escurece a tela. **W** ou a tecla de vírgula a deixa branca. Pressione a mesma tecla de novo para voltar ao slide.
- **Ctrl+P** é a caneta, **Ctrl+I** o marca-texto, **Ctrl+L** o apontador laser e **Ctrl+E** a borracha. **E** apaga a tinta do slide. **Ctrl+A** traz a seta de volta.
- **Esc** traz a seta de volta quando a caneta, o marca-texto, o apontador laser ou a borracha estão escolhidos. Caso contrário, encerra a apresentação.

Pressione **F1** para obter Ajuda sobre o que você está fazendo. A guia **Ajuda** tem **Ajuda**, **Atalhos de Teclado**, que abre esta página, **Novidades** e **Feedback**, que abrem as respectivas páginas da web.
