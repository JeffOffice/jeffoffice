# Formas e caixas de texto
<!-- keywords: forma, formas, caixa de texto, caixatexto, retângulo, seta, estrela, texto explicativo, linha, desenhar, inserir forma, formato da forma, preenchimento, contorno, espessura, traços, girar, alterar forma, editar texto, barra lateral, citação em destaque, faixa, estilos de forma -->

Uma **forma** é uma figura desenhada, como um retângulo, uma seta, uma estrela ou um balão de fala. Uma **caixa de texto** é uma forma que contém palavras. As duas ficam flutuando sobre a página, e as palavras do documento contornam essas figuras. Este tópico mostra como inseri-las e alterá-las.

## Inserir uma forma

1. Coloque o cursor onde a forma deve ficar ancorada. (A forma fica presa a esse parágrafo e se move com ele.)
2. Clique em **Inserir > Formas** e escolha uma forma na lista. As formas são agrupadas em linhas, retângulos, formas básicas, setas de bloco, formas de equação, formas de fluxograma, estrelas e faixas, e textos explicativos.

A forma aparece com suas alças, e a guia **Formato da Forma** é aberta. Ela é azul, com uma linha azul mais escura ao redor. As palavras contornam a forma, com quebra de texto quadrada.

Uma **linha** tem o comprimento de uma forma própria e não tem preenchimento. A **Seta** é uma linha com uma ponta na extremidade.

## Inserir uma caixa de texto

Clique em **Inserir > Caixa de Texto** e escolha um design.

- **Caixa de Texto Simples** tem uma linha fina ao redor. **Caixa de Texto Básica** não tem linha nem cor.
- **Barra Lateral** é uma caixa alta e de cor clara, para uma nota ao lado do texto.
- **Citação em Destaque** é um texto grande em itálico, sem moldura, para uma frase que você quer que as pessoas notem.
- **Faixa** é uma barra escura atravessando a página, com palavras claras.
- **Nota** é uma caixa amarelo-claro.

Para alterar as palavras, selecione a caixa de texto e clique em **Formato da Forma > Editar Texto**. Digite as palavras. Cada linha digitada é um parágrafo. A janela pode editar uma caixa de texto que contenha somente palavras. Se a caixa tiver uma tabela, uma imagem ou uma lista, o comando fica desativado e a caixa é mantida exatamente como estava.

## Alterar uma forma

Clique na forma para selecioná-la. Arraste uma alça para mudar o tamanho, ou arraste a forma para movê-la. Depois use a guia **Formato da Forma**.

- **Estilos de Forma** escolhe um preenchimento e uma linha ao mesmo tempo.
- **Preenchimento da Forma** define a cor dentro da forma. Escolha **Sem Preenchimento** para vê-la transparente.
- **Contorno da Forma** define a cor da linha ao redor. Escolha **Sem Contorno** para remover a linha.
- **Espessura** é a grossura da linha. **Traços** deixa a linha sólida, pontilhada ou tracejada.
- **Alterar Forma** coloca outra forma no mesmo lugar, com o mesmo tamanho e as mesmas cores.
- **Girar** gira a forma em um quarto de volta para a direita ou para a esquerda, ou volta ao ângulo original.
- **Quebra de Texto** define como as palavras contornam a forma. Veja [Adicionar e alterar imagens](pictures) para saber o que cada opção faz.
- **Texto Alternativo** descreve a forma para pessoas que não podem vê-la. **Marcar como Decorativo** indica aos leitores de tela que devem ignorá-la.
- **Altura** e **Largura** definem o tamanho em números.

Cada alteração é uma etapa que pode ser desfeita.

## Formas em outros documentos

O JeffWrite desenha as formas e caixas de texto que um documento contém, com o preenchimento, a linha e o giro delas. Ele pode alterar as que o documento armazena como forma ou caixa de texto simples. Um grupo de formas é mantido como estava.
