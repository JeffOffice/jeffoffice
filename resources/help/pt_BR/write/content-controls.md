# Criar formulários com controles de conteúdo
<!-- keywords: controle de conteúdo, controles de conteúdo, formulário, formulários, preencher, texto simples, lista suspensa, lista de opções, seletor de data, calendário, caixa de seleção, título, tag, espaço reservado, bloquear, não pode ser excluído, propriedades -->

Um **controle de conteúdo** é uma caixa no seu texto que uma pessoa preenche: uma linha de texto, uma escolha em uma lista, uma data de um calendário ou uma caixa de seleção. Use-os para criar um formulário que outras pessoas possam preencher sem alterar o restante do documento.

## Inserir um controle

1. Coloque o cursor onde o controle deve ficar.
2. Escolha **Inserir > Controle de Conteúdo** e, em seguida, escolha o tipo:
   - **Texto Simples:** uma caixa para palavras. Ela mostra o espaço reservado "Digite o texto" até que alguém digite algo. Com palavras selecionadas, o controle é criado em volta delas.
   - **Lista Suspensa:** uma lista de opções. Ela mostra "Escolha um item" até que um seja selecionado.
   - **Seletor de Data:** uma data de um calendário. Ela mostra "Escolha uma data" até que uma seja selecionada.
   - **Caixa de Seleção:** uma pequena caixa que fica marcada ou desmarcada.

Um controle recebe um leve sombreamento para que você veja onde ele começa e termina. Quando o cursor está em um controle, ele tem uma borda, e o título aparece em uma guia acima dele. Inserir um controle é uma única etapa para desfazer.

## Preencher um controle

- **Texto Simples:** clique no espaço reservado e digite. O que você digitar ocupa o seu lugar. Pressione Shift+Enter para quebrar a linha; Enter não cria um novo parágrafo dentro de um controle.
- **Lista Suspensa:** clique no controle (ou pressione Enter ou Alt+Seta para Baixo com o cursor nele) e clique em um item. O item escolhido ficará marcado na próxima vez.
- **Seletor de Data:** clique no controle e, em seguida, clique em um dia no calendário. **Hoje** insere a data de hoje. **Limpar** restaura o espaço reservado.
- **Caixa de Seleção:** clique nela, ou pressione a barra de espaço com o cursor nela, para marcar ou desmarcar.

Uma lista suspensa, um seletor de data e uma caixa de seleção guardam apenas o que é escolhido para eles: não é possível digitar neles.

## Alterar as propriedades de um controle

Coloque o cursor no controle e escolha **Inserir > Controle de Conteúdo > Propriedades**. Você pode definir:

- **Título** e **Tag:** o título aparece na guia acima do controle. A tag é um nome curto que outros programas podem usar para localizar o controle.
- **Itens da lista** (lista suspensa): Adicionar, renomear (clique duas vezes em um item), Remover, Mover para Cima e Mover para Baixo. Uma lista comporta até 1.000 itens.
- **Formato da data** (seletor de data): escolha um formato ou digite o seu, como MMMM d, yyyy. A caixa mostra como a data de hoje aparece nesse formato.
- **O controle não pode ser excluído:** o controle permanece, embora o conteúdo dentro dele possa ser alterado.
- **O conteúdo não pode ser editado:** o controle pode ser excluído, mas o conteúdo dentro dele não pode ser alterado.

Escolha **OK** para aplicar as alterações como uma única etapa para desfazer.

## Bom saber

- Um documento comporta até 10.000 controles, e os controles podem ficar uns dentro dos outros até 8 níveis de profundidade.
- Os controles de arquivos de outros programas são exibidos e mantidos como estavam. Um tipo que o JeffWrite não consegue criar (como texto formatado, imagem, caixa de combinação ou seção de repetição) é mantido no lugar; você pode alterar seu título, tag e bloqueios, mas não sua lista de conteúdo.
- Os controles são salvos em arquivos `.docx`. Em outros formatos de arquivo, as palavras permanecem, mas o controle não.
