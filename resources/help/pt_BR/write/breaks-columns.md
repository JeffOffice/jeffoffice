# Quebras, colunas, hifenização e números de linha

Todos estes recursos estão na guia **Layout**, no grupo **Configurar Página**.

## Quebras

Escolha **Layout > Quebras**.

- **Página** (Ctrl+Enter) encerra a página. O que vem depois vai para o topo da página seguinte.
- **Coluna** (Ctrl+Shift+Enter) encerra a coluna. O que vem depois vai para o topo da coluna seguinte. Na última coluna de uma página, o conteúdo vai para a página seguinte.
- **Próxima Página** inicia uma nova seção em uma nova página.
- **Contínua** inicia uma nova seção na mesma página. Use-a para mudar o número de colunas no meio de uma página.
- **Página Par** e **Página Ímpar** iniciam uma nova seção na próxima página de número par ou ímpar. Se a página ficaria com o número errado, deixa-se uma página em branco antes dela.

Uma **seção** é uma parte do documento com configuração de página própria, de modo que pode ter margens, colunas e números de linha próprios. Um cabeçalho ou rodapé não recebe quebra.

## Margens

**Layout > Margens** tem as margens **Normal**, **Estreita**, **Moderada** e **Larga**. **Espelhadas** serve para páginas que ficam frente a frente, como em um livro. Ela torna a margem interna (a do lado da encadernação) mais larga que a externa. **Espelhar Margens** liga ou desliga a mesma configuração. **Margens Personalizadas** abre a janela Configurar Página.

## Colunas

**Layout > Colunas** tem **Uma**, **Duas** e **Três** colunas de largura igual. **Esquerda** tem uma coluna estreita à esquerda e uma larga à direita. **Direita** é o contrário.

**Mais Colunas** abre uma janela. Defina o **número de colunas** (até 32). Desmarque **Largura de coluna igual** para definir a largura de cada coluna e o espaço depois dela. Marque **Linha entre colunas** para desenhar uma linha fina entre as colunas. Escolha **Esta seção** ou **Documento inteiro**.

## Hifenização

**Layout > Hifenização > Automática** divide palavras longas no fim de uma linha, com um hífen, para que a margem direita fique mais uniforme. **Nenhuma** desativa o recurso. Ele usa as listas de palavras do idioma do texto. Aplica-se ao documento inteiro.

**Opções de Hifenização** tem dois números. A **zona de hifenização** é o espaço vazio, em pontos, no fim de uma linha. Uma palavra só é dividida se levar a palavra inteira para a linha seguinte deixar mais espaço do que isso. O **limite** é o número máximo de linhas seguidas que podem terminar com hífen. Depois disso, a palavra seguinte passa inteira para a linha de baixo. "Sem limite" permite que qualquer número de linhas seguidas termine com hífen.

**Hifenizar Palavras em Maiúsculas** é uma caixa de seleção no mesmo menu. Quando está marcada, uma palavra escrita em MAIÚSCULAS também pode ser dividida. Desmarque-a para manter essas palavras inteiras. Ela fica esmaecida enquanto Hifenização estiver em **Nenhuma**, pois, nesse caso, nenhuma palavra é dividida.

## Números de linha

**Layout > Números de Linha** coloca um número ao lado de cada linha, na margem. **Contínua** conta de página em página. **Reiniciar a Cada Página** e **Reiniciar a Cada Seção** recomeçam em 1. **Nenhuma** remove os números. **Opções de Numeração de Linhas** abre uma janela em que você pode contar de um número diferente de 1 (a cada 5 linhas, por exemplo), escolher o primeiro número e definir o espaço entre os números e o texto.

Para deixar um parágrafo de fora, abra a caixa **Parágrafo**, vá até as quebras de linha e de página e marque **Suprimir números de linha**. Esse parágrafo não recebe números, e suas linhas não são contadas. Salvo como arquivo OpenDocument (.odt), a escolha é mantida no parágrafo.
