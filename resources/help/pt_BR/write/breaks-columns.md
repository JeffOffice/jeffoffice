# Quebras, colunas, hifenização e numeração de linhas

Todos estes recursos estão na guia **Layout**, no grupo **Configurar Página**.

## Quebras

Escolha **Layout > Quebras**.

- **Página** (Ctrl+Enter) encerra a página. O que vem depois vai para o topo da página seguinte.
- **Coluna** (Ctrl+Shift+Enter) encerra a coluna. O que vem depois vai para o topo da coluna seguinte. Na última coluna de uma página, o conteúdo passa para a página seguinte.
- **Próxima Página** inicia uma nova seção em uma nova página.
- **Contínua** inicia uma nova seção na mesma página. Use-a para mudar o número de colunas no meio de uma página.
- **Página Par** e **Página Ímpar** iniciam uma nova seção na próxima página de número par ou ímpar. Se a página ficaria com o número errado, uma página em branco é deixada antes dela.

Uma **seção** é uma parte do documento com configuração de página própria, por isso pode ter margens, colunas e numeração de linhas próprias. Um cabeçalho ou rodapé não recebe quebra.

## Margens

**Layout > Margens** tem as margens **Normal**, **Estreita**, **Moderada** e **Larga**. **Espelhadas** é para páginas que ficam frente a frente, como em um livro. Ela deixa a margem interna (a que fica junto à encadernação) mais larga que a externa. **Margens Espelhadas** liga ou desliga a mesma configuração. **Margens Personalizadas** abre a janela Configurar Página.

## Colunas

**Layout > Colunas** tem **Uma**, **Duas** e **Três** colunas de largura igual. **Esquerda** tem uma coluna estreita à esquerda e uma larga à direita. **Direita** é o inverso.

**Mais Colunas** abre uma janela. Defina o **Número de colunas** (até 32). Desmarque **Largura igual das colunas** para definir a largura de cada coluna e o espaço depois dela. Marque **Linha entre** para desenhar uma linha fina entre as colunas. Escolha **Esta seção** ou **Documento inteiro**.

## Hifenização

**Layout > Hifenização > Automática** divide palavras longas no fim de uma linha, com um hífen, para que a margem direita fique mais uniforme. **Nenhuma** desativa o recurso. Ele usa as listas de palavras do idioma do texto. Aplica-se ao documento inteiro.

**Opções de Hifenização** tem dois números. A **zona de hifenização** é o espaço vazio, em pontos, no fim de uma linha. Uma palavra só é dividida se passar a palavra inteira para a linha seguinte deixar mais espaço vazio do que isso. O **limite** é o número máximo de linhas seguidas que podem terminar com hífen. Depois disso, a próxima palavra vai inteira para a linha seguinte. "Sem limite" permite que qualquer número de linhas seguidas termine com hífen.

**Hifenizar Palavras em Maiúsculas** é uma caixa de seleção no mesmo menu. Quando está marcada, uma palavra em LETRAS MAIÚSCULAS também pode ser dividida. Desmarque-a para manter essas palavras inteiras. Ela fica esmaecida enquanto a Hifenização estiver em **Nenhuma**, pois, nesse caso, nenhuma palavra é dividida.

## Numeração de linhas

**Layout > Números de Linha** coloca um número ao lado de cada linha, na margem. **Contínua** conta de uma página para a outra. **Reiniciar a Cada Página** e **Reiniciar a Cada Seção** recomeçam em 1. **Nenhuma** remove a numeração. **Opções de Numeração de Linhas** abre uma janela em que você pode contar de um número diferente de 1 (por exemplo, a cada 5 linhas), escolher o primeiro número e definir o espaço entre os números e o texto.
