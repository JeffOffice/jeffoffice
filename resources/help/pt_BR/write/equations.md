# Equações

<!-- keywords: equação, equações, matemática, fórmula, fração, raiz quadrada, sobrescrito, subscrito, expoente, soma, integral, grego, símbolo, inserir equação, alt+= -->

Uma **equação** é uma linha de matemática, como uma fração ou uma raiz quadrada. Este tópico mostra como digitar uma equação e colocá-la em um documento.

## Inserir uma equação

1. Coloque o cursor onde a equação deve ir.
2. Clique em **Inserir > Equação**, ou pressione **Alt+=**.
3. Digite a equação em uma linha. Embaixo da caixa, você vê como ela ficará. Clique em **OK**.

A equação é salva no documento no formato padrão para matemática, para que outros programas possam abri-la.

## Como digitar

- **Frações:** digite uma barra. `a/b` é a sobre b. `(x+1)/(x-1)` trata cada grupo entre parênteses como uma parte. `\frac{1}{2}` também funciona.
- **Potências:** digite um acento circunflexo. `x^2` é x elevado ao quadrado. `e^(i*pi)` usa o grupo entre parênteses.
- **Subscritos:** digite um sublinhado. `x_i` é x com um i pequeno embaixo. Você pode usar os dois, como em `x_i^2`.
- **Raízes:** digite `sqrt(x+1)` para uma raiz quadrada. Digite `sqrt[3]{x}` para uma raiz cúbica.
- **Somas, integrais e produtos:** digite `\sum_(i=1)^n i`, `\int_0^1 x` ou `\prod_(k=1)^n k`. A parte depois do sublinhado fica embaixo (ou na parte inferior do sinal de integral), e a parte depois do acento circunflexo fica em cima.
- **Símbolos:** digite uma barra invertida e um nome. `\alpha` é α, `\pi` é π, `\infty` é ∞, `\leq` é ≤, `\neq` é ≠, `\times` é ×, `\pm` é ±, e `\to` é →. Cerca de 70 nomes funcionam.
- **Funções:** `sin`, `cos`, `tan`, `log`, `ln`, `exp`, `lim`, `min` e `max` mantêm seus nomes inteiros.

Na página, o JeffWrite mostra uma equação como uma linha de texto. A equação no arquivo mantém suas frações e raízes, para que outros programas a disponham corretamente.

## Equações em outros documentos

O JeffWrite mostra as equações que um documento contém e as mantém como estavam. Ele não altera uma equação que já está em um documento. Para mudá-la, exclua-a e insira-a novamente.
