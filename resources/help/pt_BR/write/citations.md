# Citações e bibliografia
<!-- keywords: citação, fonte, bibliografia, obras citadas, referências, referência bibliográfica, APA, MLA, Chicago, Harvard, IEEE, gerenciar fontes, inserir citação, estilo de citação, autor, livro, periódico -->

Uma **fonte** é um livro, um artigo, uma página da Web ou qualquer outro material que você cita ou no qual se baseia. Uma **citação** é a menção curta a uma fonte no seu texto, como (Silva, 2020). A **bibliografia** é a lista de fontes no final. O JeffWrite mantém suas fontes em uma única lista, cria para você cada citação e cada entrada da bibliografia, e atualiza todas quando você muda o estilo.

## Adicionar uma citação

1. Clique no ponto onde a citação deve aparecer.
2. Clique em **Referências > Inserir Citação**.
3. Escolha uma fonte da lista ou clique em **Nova Fonte** para criar uma.
4. Digite as **Páginas**, se a citação precisar indicá-las. Marque **Omitir o autor** ou **Omitir o ano** se a frase já os mencionar, ou **Mostrar o título**.
5. Clique em **Inserir**.

## Criar uma fonte

Na caixa Fonte, escolha o **tipo de fonte**. A caixa então pede os dados que esse tipo exige: um livro pede título, ano, cidade e editora; um artigo pede nome do periódico, volume, número e páginas. Digite cada autor em uma linha, no formato `Sobrenome, Nome Intermediário`. Uma empresa ou um grupo pode ser o autor em **Organização como autor**. O **nome de marcação** é o nome curto que a citação usa; o JeffWrite cria um para você a partir do autor e do ano, como Sil20.

## Gerenciar suas fontes

Clique em **Referências > Gerenciar Fontes**. A caixa mostra duas listas:

- A **Lista mestra** pertence a você. Qualquer documento que você escrever pode usar fontes dela.
- A **Lista atual** contém as fontes deste documento.

Use **Copiar** para mover uma fonte de uma lista para a outra, **Nova** para criar uma fonte, **Editar** para alterar uma e **Excluir** para removê-la. Uma prévia mostra como a fonte aparece na bibliografia. As fontes criadas na caixa Inserir Citação também vão para a lista mestra.

## Escolher um estilo

Clique em **Referências > Estilo de Citação** e escolha **APA (6ª edição)**, **MLA (7ª edição)**, **Chicago (15ª edição)**, **Harvard** ou **IEEE**. As edições são indicadas porque existem versões mais recentes desses guias, e elas não são integradas ao programa. Todas as citações e a bibliografia do documento mudam para esse estilo. No IEEE, a citação é um número entre colchetes, como [1], na ordem em que as fontes são citadas pela primeira vez.

## Adicionar a bibliografia

Clique onde a lista deve aparecer, clique em **Referências > Bibliografia** e escolha **Bibliografia**, **Referências** ou **Obras Citadas**. O JeffWrite adiciona um título e uma lista das fontes que você citou, na ordem em que aparecem. Uma fonte que você nunca citou não entra na lista. Se você citar mais fontes depois, clique na lista e pressione **F9** para refazê-la.

## O que é salvo

Suas fontes são salvas no arquivo, em um formato que outros processadores de texto conseguem ler. Um arquivo que você abre mantém suas fontes exatamente como estavam, até que você as altere.
