# Criar um índice de autoridades
<!-- keywords: índice de autoridades, autoridades, citação, marcar citação, jurisprudência, legislação, outras autoridades, regra, tratado, passim, petição, TA, TOA, Alt+Shift+I, categoria, tabela de autoridades -->

Um **índice de autoridades** é uma lista que uma petição jurídica contém: as decisões judiciais, leis e outras obras que a petição cita, com as páginas em que cada uma é citada. Primeiro você **marca** cada citação e, depois, **insere** o índice.

## Marcar uma citação

1. Selecione a citação no texto, como o nome de uma decisão judicial com seus números.
2. Clique em **Referências > Marcar Citação** ou pressione **Alt+Shift+I**.
3. Marque a **Citação longa**. É isso que o índice mostra. Digite uma **Citação curta** se você usar uma forma mais curta mais adiante no texto.
4. Escolha uma **Categoria**: Jurisprudência, Legislação, Outras Autoridades, Regras, Tratados, Regulamentos ou Disposições Constitucionais. Há mais nove categorias numeradas para uso próprio.
5. Clique em **OK**.

Marque cada ponto do texto que cite a autoridade. O índice lista a autoridade uma única vez, com todas as páginas.

## Inserir o índice

1. Clique onde o índice deve aparecer.
2. Clique em **Referências > Índice de Autoridades**.
3. Escolha uma categoria ou **Todas** para listar todas as categorias que tenham marcações. Escolha o preenchimento de tabulação, se deseja usar **passim**, e se deseja colocar o nome da categoria acima das suas citações.
4. Clique em **OK**.

**Passim** é uma palavra latina que significa "aqui e ali". Quando uma autoridade é citada em cinco páginas ou mais, o índice mostra a palavra em vez de uma longa lista de números.

## Manter o índice atualizado

Clique no índice e depois em **Atualizar Autoridades** (no grupo **Índice de Autoridades** da guia **Referências**), ou pressione **F9**.
