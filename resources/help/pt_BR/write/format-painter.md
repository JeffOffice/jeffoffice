# Copiar uma aparência com Copiar formatação
<!-- keywords: copiar formatação, copiar formato, colar formatação, pincel, pintar formatação, mesma aparência, mesmo formato, ctrl+shift+c, ctrl+shift+v, clique duplo, clicar duas vezes -->

**Copiar formatação** copia a aparência de um texto e a aplica a outro texto. Use esse recurso quando quiser que uma palavra ou um parágrafo fique exatamente igual a outro.

## Copiar uma aparência para um lugar

1. Selecione as palavras que têm a aparência desejada. Ou clique no parágrafo.
2. Clique em **Copiar formatação** na guia **Página Inicial**. O botão fica pressionado, e a barra de status lembra o que fazer.
3. Selecione com o mouse as palavras que você deseja alterar. Quando você soltar o botão do mouse, elas recebem a aparência, e Copiar formatação é desativado.

Se você clicar em uma palavra sem selecionar, a palavra recebe a aparência.

## Copiar uma aparência para vários lugares

Clique duas vezes em **Copiar formatação**. O recurso continua ativado. Sempre que você selecionar um texto com o mouse, esse texto recebe a aparência. Pressione **Esc**, ou clique no botão novamente, para parar.

## O que é copiado

- A aparência dos caracteres: a fonte, o tamanho, negrito, itálico, sublinhado, cor e mais.
- A aparência do parágrafo, se você copiou a partir de uma marca de parágrafo. Para copiar a partir de uma marca de parágrafo, selecione o parágrafo inteiro até o início do próximo, ou clique no parágrafo sem selecionar. O alinhamento, os recuos, o espaçamento e o estilo do parágrafo vêm junto. Eles são aplicados aos parágrafos que você pinta quando a seleção inclui o final de um parágrafo.
- Se você selecionar apenas palavras, somente a aparência dos caracteres é copiada.

A lista em que um parágrafo está, e a posição dele no documento, não são alteradas.

Cada vez que Copiar formatação pinta, isso conta como uma etapa. **Desfazer** (Ctrl+Z) a reverte.

## Usar o teclado

- **Ctrl+Shift+C** copia a aparência da seleção.
- **Ctrl+Shift+V** aplica essa aparência à seleção.
