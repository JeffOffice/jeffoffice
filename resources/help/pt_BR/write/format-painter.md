# Copiar uma aparência com o Copiar Formatação
<!-- keywords: pincel de formatação, copiar formatação, colar formatação, copiar formato, pincel, pintar, mesma aparência, mesma formatação, ctrl+shift+c, ctrl+shift+v, clique duplo -->

O **Copiar Formatação** copia a aparência de um texto e a aplica a outro texto. Use-o quando quiser que uma palavra ou um parágrafo fique exatamente com a mesma aparência de outro.

## Copiar uma aparência para um lugar

1. Selecione as palavras que têm a aparência desejada. Ou clique no parágrafo.
2. Clique em **Copiar Formatação** na guia **Página Inicial**. O botão fica pressionado, e a barra de status lembra o que fazer.
3. Selecione com o mouse as palavras que você deseja alterar. Quando você soltar o botão do mouse, elas recebem a aparência, e o Copiar Formatação é desativado.

Se você clicar em uma palavra sem selecionar nada, a palavra recebe a aparência.

## Copiar uma aparência para vários lugares

Clique duas vezes em **Copiar Formatação**. Ele permanece ativado. Sempre que você selecionar um texto com o mouse, esse texto recebe a aparência. Pressione **Esc**, ou clique no botão novamente, para parar.

## O que é copiado

- A aparência dos caracteres: a fonte, o tamanho, negrito, itálico, sublinhado, cor e muito mais.
- A aparência do parágrafo, se você copiou a partir de uma marca de parágrafo. Para copiar a partir de uma marca de parágrafo, selecione o parágrafo inteiro até o início do próximo, ou clique no parágrafo sem selecionar nada. O alinhamento, os recuos, o espaçamento e o estilo do parágrafo vêm junto. Eles são aplicados aos parágrafos que você pintar quando a seleção incluir o final de um parágrafo.
- Se você selecionar apenas palavras, somente a aparência dos caracteres será copiada.

A lista em que um parágrafo está e a posição dele no documento não são alteradas.

Cada vez que o Copiar Formatação pinta, isso conta como uma etapa. **Desfazer** (Ctrl+Z) a desfaz.

## Usar o teclado

- **Ctrl+Shift+C** copia a aparência da seleção.
- **Ctrl+Shift+V** aplica essa aparência à seleção.
