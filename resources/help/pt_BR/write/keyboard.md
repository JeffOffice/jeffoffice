# Usar o JeffWrite com o teclado
<!-- keywords: teclado, atalhos, atalhos de teclado, teclas, teclas de atalho, dicas de tecla, ctrl, alt, navegar, mover, selecionar, ponto de inserção, cursor -->

Você pode fazer tudo no JeffWrite com o teclado. Esta página lista as teclas.

## Mover e selecionar

- As **teclas de direção** movem o ponto de inserção. O **ponto de inserção** é a linha piscante que mostra onde o texto será digitado.
- **Ctrl+Seta para a Esquerda** e **Ctrl+Seta para a Direita** movem uma palavra.
- **Home** e **End** movem para o início e o fim de uma linha. **Ctrl+Home** e **Ctrl+End** movem para o início e o fim do documento.
- **Page Up** e **Page Down** movem uma janela de texto.
- Mantenha **Shift** pressionada com qualquer uma dessas teclas para selecionar texto enquanto se move.
- **Ctrl+A** seleciona tudo.

## Digitar e excluir

- **Enter** inicia um novo parágrafo. **Shift+Enter** inicia uma nova linha no mesmo parágrafo.
- **Ctrl+Enter** inicia uma nova página.
- **Esc** fecha um cabeçalho ou rodapé que você está editando e sai de uma nota de rodapé que você está editando, voltando ao texto.
- **Tab** adiciona uma tabulação. Em uma lista, aumenta um nível do item. **Shift+Tab** diminui um nível.
- **Backspace** e **Delete** removem texto. Mantenha **Ctrl** pressionada para remover uma palavra.

## Acessar a faixa de opções

Pressione **Alt** para mostrar uma letra em cada guia. Pressione a letra para abrir a guia e, em seguida, as letras que aparecerem para chegar a um botão. Pressione **Esc** para voltar um passo. **F6** move o foco do teclado entre a faixa de opções e a página.
