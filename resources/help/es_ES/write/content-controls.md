# Crear formularios con controles de contenido
<!-- keywords: control de contenido, controles de contenido, formulario, formularios, rellenar, texto sin formato, lista desplegable, desplegable, selector de fecha, calendario, casilla de verificación, casilla, título, etiqueta, marcador de posición, bloquear, no se puede eliminar, propiedades -->

Un **control de contenido** es un cuadro de su texto que una persona rellena: una línea de texto, una opción de una lista, una fecha de un calendario o una casilla de verificación. Use los controles para crear un formulario que otros puedan completar sin cambiar el resto del documento.

## Insertar un control

1. Coloque el cursor donde debe ir el control.
2. Elija **Insertar > Control de contenido** y, a continuación, seleccione el tipo:
   - **Texto sin formato:** un cuadro para palabras. Muestra el marcador de posición «Escriba texto» hasta que alguien escriba. Si hay palabras seleccionadas, el control se crea alrededor de ellas.
   - **Lista desplegable:** una lista de opciones. Muestra «Elija un elemento» hasta que se elija uno.
   - **Selector de fecha:** una fecha de un calendario. Muestra «Elija una fecha» hasta que se elija una.
   - **Casilla de verificación:** una casilla pequeña que se marca o se desmarca.

Un control aparece con un sombreado claro para que pueda ver dónde empieza y dónde termina. Cuando el cursor está en un control, este tiene un contorno, y su título aparece en una pestaña encima de él. Insertar un control es un solo paso que se puede deshacer.

## Rellenar un control

- **Texto sin formato:** haga clic en el marcador de posición y escriba. Lo que escriba lo reemplazará. Pulse Mayús+Entrar para hacer un salto de línea; dentro de un control, Entrar no crea un párrafo nuevo.
- **Lista desplegable:** haga clic en el control (o pulse Entrar o Alt+Flecha abajo con el cursor en él) y haga clic en un elemento. El elemento elegido aparecerá marcado la próxima vez.
- **Selector de fecha:** haga clic en el control y, después, haga clic en un día del calendario. **Hoy** inserta la fecha de hoy. **Borrar** devuelve el marcador de posición.
- **Casilla de verificación:** haga clic en ella, o pulse la barra espaciadora con el cursor en el control, para marcarla o desmarcarla.

Una lista desplegable, un selector de fecha y una casilla de verificación solo contienen lo que se elige para ellos: no se puede escribir en ellos.

## Cambiar las propiedades de un control

Coloque el cursor en el control y elija **Insertar > Control de contenido > Propiedades**. Puede configurar:

- **Título y Etiqueta:** el título aparece en la pestaña encima del control. La etiqueta es un nombre corto que otros programas pueden usar para localizar el control.
- **Elementos de la lista** (lista desplegable): Agregar, cambiar nombre (haga doble clic en un elemento), Quitar, Subir y Bajar. Una lista admite hasta 1000 elementos.
- **Formato de fecha** (selector de fecha): elija un formato o escriba el suyo, por ejemplo MMMM d, yyyy. El cuadro muestra cómo se verá la fecha de hoy con ese formato.
- **El control no se puede eliminar:** el control permanece, aunque se puede cambiar lo que contiene.
- **El contenido no se puede editar:** el control se puede eliminar, pero no se puede cambiar lo que contiene.

Elija **Aceptar** para aplicar los cambios como un solo paso que se puede deshacer.

## Conviene saber

- Un documento admite hasta 10 000 controles, y los controles pueden anidarse hasta 8 niveles de profundidad.
- Los controles de ficheros de otros programas se muestran y se conservan tal como estaban. Un tipo que JeffWrite no puede crear (como texto enriquecido, una imagen, un cuadro combinado o una sección repetida) se mantiene en su sitio; puede cambiar su título, su etiqueta y sus bloqueos, pero no su lista de contenido.
- Los controles se guardan en ficheros `.docx`. En otros tipos de fichero se conservan las palabras, pero el control no.
