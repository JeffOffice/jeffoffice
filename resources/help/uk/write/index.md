# Довідка JeffWrite
<!-- keywords: зміст, довідка, теми, початок, вміст, допомога -->

Введіть текст у поле пошуку вгорі, щоб знайти тему або команду для виконання. Натисніть **F1** будь-коли, щоб отримати довідку щодо дії, яку ви виконуєте: вкладки стрічки або сторінки екрана «Файл», на якій ви перебуваєте.
