# Безпека: до чого може звертатися файл

<!-- keywords: центр довіри, безпека, макроси, пов'язані файли, посилання, пов'язані малюнки, пов'язані медіа, інтернет, завантажені, лише для читання, захищені, зовнішні посилання, програми, безпечно, параметри безпеки, довіра -->

Файл може вказувати на інші об'єкти: файли, веб-сторінки, відео, навіть програми. Сторінка **Безпека** дозволяє вирішити, що JeffDeck робитиме з такими посиланнями. Клацніть **Файл > Параметри**, а потім вкладку **Безпека**. Клацніть **OK**, щоб зберегти зміни, або **Скасувати**, щоб відмовитися від них.

Ці параметри стосуються всіх застосунків JeffOffice: змінивши один у одному застосунку, ви змінюєте його в усіх. Рядок для того, чого застосунок не підтримує, має напис **Не застосовується** і є неактивним (сірим).

## Макроси

Макроси — це невеликі програми, які зберігаються всередині файла. JeffDeck зберігає їх у файлі, тож вони залишаються на місці під час збереження, але програма **ніколи їх не запускає**. Немає жодного параметра, який би їх запускав.

## Пов'язані файли та зв'язки з книгами

Це не застосовується в JeffDeck: програма не має пов'язаних файлів для оновлення. Рядок неактивний (сірий).

## Пов'язані відео та звуки

Ідеться про відео або звук, на який слайд **посилається**, а не про той, що міститься всередині презентації.

- **Ніколи не відтворювати** — звичайний вибір. Пов'язане відео або звук позначається як пов'язане і не відтворюється.
- **Запитати перед виконанням** запитує щоразу, коли ви вперше відтворюєте кожен пов'язаний файл.
- **Відтворити** відтворює файл без запиту.

Навіть за вибору **Відтворити** відтворюється лише відео- або звуковий файл, чия назва вказує на цей комп'ютер. Веб-адреса, файл на іншому комп'ютері, програма, посилання чи спеціальний файл, а також файл, який насправді не є відео або звуком, ніколи не відтворюються. Пов'язаний файл може мати розмір до 256 МБ. Файл зчитується у фоновому режимі до 20 секунд, тож повільний диск не може зупинити JeffDeck. Мережевий диск, який виглядає як локальний (під'єднаний диск або папка в /Volumes чи /mnt), зчитується як локальний файл, тому може працювати повільно. За вибору **Запитати перед виконанням** показ слайдів запитує один раз, на початку, про всі пов'язані файли в ньому.

## Файли з інтернету або з інших комп'ютерів

Завантажений файл або файл, що розміщений на іншому комп'ютері вашої мережі, може бути небезпечним. Цей параметр визначає, як JeffDeck його відкриває.

- **Спочатку відкривати лише для читання** — звичайний вибір. Файл відкривається для читання, але змінити його не можна. Під файлом з'являється смуга, яка це повідомляє. Клацніть **Увімкнути редагування** на цій смузі, щоб змінити лише цей файл (до закриття програми). Коли ви згодом збережете його на місці, позначку завантаження буде знято. Або скористайтеся командою **Зберегти як**, щоб створити копію, чи змініть цей параметр на наступний варіант.
- **Відкривати звичайно** відкриває всі файли однаково.

Файл, який ви відкриваєте командами **Відкрити як копію**, **Відкрити та відновити** або **Відкрити лише для читання** на екрані **Файл**, відкривається так, незалежно від цього параметра.

## Посилання, які запускають програми

Посилання, яке запускало б програму або скрипт (файл із розширенням .exe, .bat, .sh тощо), **завжди відхиляється**. JeffDeck повідомляє про це, і нічого не запускається. Посилання на файл на іншому комп'ютері ніколи не відкривається без вашого запиту. Жоден параметр цього не змінює.
