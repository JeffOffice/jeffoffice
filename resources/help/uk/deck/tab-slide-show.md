# Вкладка «Показ слайдів»

Вкладка **Показ слайдів** запускає показ і налаштовує його.

- **Почати показ слайдів** має пункти **З початку** (F5) і **З поточного слайда** (Shift+F5). **Настроюваний показ** показує ваші користувацькі покази за назвами, тож ви можете відтворити один із них. Його команда **Користувацькі покази** створює, змінює, копіює й видаляє їх.
- **Налаштування** містить **Налаштування показу слайдів**, де вибирається тип показу, які слайди відтворюються, чи показ повторюється без кінця і як відбувається перехід далі. **Приховати слайд** виводить поточний слайд із показу. **Репетиція часу** відтворює показ і фіксує, скільки часу ви витрачаєте на кожен слайд. Прапорець **Використовувати час** змушує показ переходити далі самостійно після часу, відведеного для кожного слайда.
- **Монітори** містить прапорець **Використовувати режим доповідача**, який потрібен, коли у вас два екрани, список **Показувати презентацію на**, де вибирається екран для показу слайдів (Автоматично або екран за назвою та розміром), і **Режим доповідача** (Alt+F5), який відкриває показ у невеликому вікні разом із режимом доповідача, щоб ви могли виконати репетицію на одному екрані.

Поки показ відтворюється, натисніть Ctrl+P для пера, Ctrl+I для маркера, Ctrl+L для лазерної указки та Ctrl+E для гумки. Щоб повернути стрілку, натисніть Ctrl+A або Esc.
