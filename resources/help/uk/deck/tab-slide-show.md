# Вкладка «Показ слайдів»
<!-- keywords: вкладка показ слайдів, стрічка, з початку, з поточного слайда, довільний показ, довільні покази, приховати слайд, налаштування, налаштування показу слайдів, репетиція часу, використовувати час, монітори, використовувати режим доповідача, режим доповідача, репетиція, відтворити, показ, F5 -->

Вкладка **Показ слайдів** запускає показ і налаштовує його.

- **Почати показ слайдів** містить команди **Із самого початку** (F5) і **Із поточного слайда** (Shift+F5). **Користувацький показ слайдів** показує ваші користувацькі покази за назвою, щоб ви могли відтворити один із них. Команда **Довільні покази** створює, змінює, копіює та видаляє їх.
- **Налаштування** містить команду **Налаштування показу слайдів**, яка визначає тип показу, які слайди відтворюються, чи повторюється показ і як відбувається перехід далі. **Приховати слайд** виключає поточний слайд із показу. **Репетиція часу** відтворює показ і записує, скільки часу ви витрачаєте на кожен слайд. Прапорець **Використовувати час** змушує показ переходити далі автоматично після часу, відведеного для кожного слайда.
- **Монітори** містить прапорець **Використовувати режим доповідача**, який потрібен, коли у вас два екрани, та команду **Режим доповідача** (Alt+F5), яка відкриває показ у невеликому вікні, а поруч відкриває режим доповідача, щоб ви могли репетирувати на одному екрані.

Під час показу натисніть Ctrl+P для пера, Ctrl+I для маркера, Ctrl+L для лазерної указки та Ctrl+E для гумки. Щоб повернути стрілку, натисніть Ctrl+A або Esc.
