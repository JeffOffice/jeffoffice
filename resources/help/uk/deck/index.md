# JeffDeck: довідка
<!-- keywords: зміст, довідка, теми, початок, допомога -->

Введіть текст у поле пошуку вгорі, щоб знайти тему або команду для виконання. Натисніть **F1** будь-коли, щоб отримати довідку про те, що ви робите: вкладку стрічки, на якій ви перебуваєте, панель, у якій працюєте, або вибраний об'єкт.
