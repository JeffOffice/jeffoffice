# JeffDeck: довідка
<!-- keywords: зміст, довідка, теми, початок -->

Введіть текст у поле пошуку вгорі, щоб знайти тему або команду для виконання. Натисніть **F1** будь-коли, щоб отримати довідку щодо того, що ви робите: вкладки стрічки, області, у якій ви перебуваєте, або обраного об'єкта.
