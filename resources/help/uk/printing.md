# Друк публікації

Друк виконується на сторінці **Друк**. Параметри ви вибираєте ліворуч, а попередній перегляд кожної сторінки з'являється праворуч. **Масштаб** над переглядом збільшує сторінку понад розмір, який вміщується у вікні; прокрутіть, щоб побачити решту.

## Друк публікації

1. Натисніть Ctrl+P або клацніть **Файл > Друк**. На панелі швидкого доступу також є кнопка **Друк**.
2. Поруч із кнопкою **Друк** задайте **Копії**.
3. Виберіть **Принтер**. Список завершується пунктом **Зберегти як PDF**, який створює файл PDF замість паперового відбитка. Якщо копій більше однієї, **Розібрати за комплектами** друкує весь комплект заново для кожної копії (1, 2, 3, потім знову 1, 2, 3), а якщо цей параметр вимкнено, копії кожної сторінки виходять разом (1, 1, 2, 2, 3, 3). Файл PDF створюється один раз, незалежно від кількості копій.
4. У розділі **Діапазон** виберіть **Усі сторінки**, **Поточна сторінка**, **Виділений фрагмент** (лише виділені об'єкти на їхніх місцях на поточній сторінці; об'єкт у групі друкується разом із усією групою, об'єкти головної сторінки пропускаються, а попередній перегляд показує лише те, що буде надруковано; пункт неактивний, якщо нічого не виділено) або **Сторінки**. Для **Сторінки** введіть сторінки в полі **Сторінки**: номери сторінок і діапазони, розділені комами, наприклад 1-3, 5.
5. Виберіть інші потрібні параметри. Їх наведено нижче.
6. Натисніть **Друк**.

Натисніть **Властивості принтера…**, щоб відкрити системне вікно друку з параметрами вашого принтера. Вибране там зберігається для завдання друку, а кількість копій, розбирання за комплектами та папір повертаються на цю сторінку. Для друку на обидва боки аркуша параметр **Остання сторінка першою** зберігає кожен лицьовий бік разом із його зворотним.

Праворуч у попередньому перегляді є стрілки для переходу від сторінки до сторінки. Позначте **Показувати лінійки** або **Показувати номери сторінок**, щоб бачити їх у попередньому перегляді.

## Вибір макета

Список **Макет** визначає, як сторінки розміщуються на папері:

- **Одна сторінка на аркуш** друкує кожну сторінку окремо. Сторінка, завелика для паперу, друкується частинами. Сторінка, трохи завелика, зменшується, щоб вміститися.
- **Кілька сторінок на аркуш** розміщує різні сторінки на одному аркуші.
- **Кілька копій на аркуш** повторює одну сторінку по аркушу. Використовуйте це для візитних карток і наклейок.
- **Буклет, складання збоку** та **Буклет, складання зверху** розміщують дві сторінки на кожному аркуші в правильному порядку, щоб складена стопка читалася по порядку. Складання збоку ставить дві сторінки поруч. Складання зверху ставить одну сторінку над другою.
- **Плиткою (плакати й банери)** друкує велику сторінку частинами на кількох аркушах, з невеликим перекриттям, щоб ви могли вирівняти аркуші.

## Інші параметри

- **Папір**: Letter, Legal, Tabloid, A4, A3 або **Як у публікації**.
- **Остання сторінка першою** друкує аркуші у зворотному порядку, щоб стопка вийшла в правильній послідовності. Пункт неактивний, якщо ви друкуєте на обидва боки вручну, бо тоді JeffPub сам задає порядок.
- **Сторони**: **Друк на одному боці** або **Друк на обидва боки** з перегортанням по довгому краю чи по короткому краю. **Друк на обидва боки вручну** призначено для принтера, який не може друкувати на обидва боки. JeffPub друкує перші, треті, п'яті тощо сторінки (для буклета — сторони аркуша), після чого з'являється повідомлення з проханням перевернути стопку й покласти її назад у принтер. Коли ви натиснете **ОК**, друкуються решта сторінок, починаючи з останньої. Завдання з однією сторінкою не потребує перевертання. Збереження PDF вимикає цей вибір, бо файл не має сторін. Попередній перегляд тоді показує, на якому аркуші й боці розташована кожна сторінка.
- **Колір**: **Складений RGB** для повнокольорового друку або **Складені відтінки сірого** для відтінків сірого.
- **Друкувати всі записи злиття пошти**: доступно, коли публікація має список отримувачів. Див. [злиття пошти](mail-merge).

## Мітки друкарні та розділення кольорів

Ці параметри потрібні для роботи, яку віддають друкарні. Уточніть у друкарні, що саме їй потрібно.

- **Мітки обрізу** показують, де обрізати. **Мітки вильотів** показують додатковий край. **Мітки реєстрації** допомагають сумістити кольори. **Смуги щільності** та **Кольорові смуги** дають друкарні змогу перевірити фарбу. **Відомості про завдання** друкують назву, сторінку й дату.
- **Дозволити вильоти** друкує об'єкти, які виходять за межі сторінки, тож після обрізання не лишається білого краю. Цей додатковий край називається **виліт**.
- Мітки друкуються поза сторінкою, тому використовуйте папір більшого розміру, ніж ваша сторінка.
- **Розділення (пластини CMYK)** у розділі **Колір** друкує по одному аркушу для кожної фарби: **Блакитний**, **Пурпуровий**, **Жовтий** і **Чорний**, а також для всіх спеціальних кольорів, які використовує публікація (спеціальний колір — це заздалегідь змішана особлива фарба). Позначте або зніміть позначки з пластин, які потрібні.

Щоб підготувати PDF для друкарні, див. [PDF-файли та друкарні](pdf).
