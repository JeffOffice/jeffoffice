На вкладці **Основне** є **Довідка** (F1), **Комбінації клавіш**, яка відкриває цю сторінку, **Що нового** і **Зворотний зв'язок**, які відкривають свої веб-сторінки.

На Mac клавіша **Command** (⌘) виконує ту саму дію, що й **Ctrl** у таблицях нижче, якщо в таблиці не зазначено інакше.

## Переміщення та виділення

| Клавіші | Що вони роблять |
| --- | --- |
| Клавіші зі стрілками | Переміщують активну комірку на одну комірку, пропускаючи приховані рядки й стовпці |
| Shift+стрілка | Розширює виділення на одну комірку |
| Ctrl+стрілка | Переходить до краю даних (Esc зупиняє тривалий пошук) |
| Ctrl+Shift+стрілка | Розширює виділення до краю даних |
| End, потім стрілка | Переходить до краю даних (у рядку стану з'являється End) |
| Ctrl+A | Виділяє блок навколо активної комірки, потім весь аркуш (одразу весь аркуш, якщо виділення вже більше за блок) |
| Ctrl+Shift+* | Виділяє блок навколо активної комірки |
| Ctrl+клацання або Ctrl+перетягування | Додає діапазон до виділення |
| Ctrl+Shift+Enter | Вводить формулу як формулу масиву для виділених комірок |
| Home | Переходить до першого стовпця рядка |
| Ctrl+Home | Переходить до першої комірки (A1 або першої комірки, яка прокручується, якщо закріплено рядки чи стовпці) |
| Ctrl+End | Переходить до останньої комірки, яка містить дані або має формат |
| Page Down, Page Up | Переміщують униз або вгору на один екран |
| Tab, Shift+Tab | Переміщують вправо або вліво (по виділених комірках, якщо їх кілька) |
| Enter, Shift+Enter | Переміщують униз або вгору (по виділених комірках, якщо їх кілька) |
| Ctrl+пробіл | Виділяє весь стовпець |
| Shift+пробіл | Виділяє весь рядок |
| {key:SelectAll} | Виділяє все |

## Призначення власних комбінацій клавіш

Можна змінити клавіші будь-якої команди або призначити клавіші команді, яка їх не має. Клацніть **Файл > Параметри**, потім вкладку **Настроювання**.

1. Введіть у полі **Пошук** назву команди або її клавіші. Список згрупований за вкладками стрічки, і для кожної команди показано її клавіші. Команди, яких немає на стрічці, перелічено в розділі **Інші**.
2. Клацніть команду. Її клавіші перелічено в розділі **Клавіші для цієї команди**.
3. Клацніть поле **Натисніть нові клавіші** та натисніть потрібні клавіші, наприклад **Ctrl+Shift+B**. Потім клацніть **Призначити**. Команда може мати до чотирьох клавіш.
4. Щоб прибрати клавішу, клацніть її в списку та клацніть **Видалити**.

Якщо ці клавіші вже призначено іншій команді, JeffCrunch повідомить, якій саме. Клацніть **Перейняти**, щоб передати клавіші цій команді; інша команда їх втратить. Нічого не зміниться, доки ви не натиснете **OK**. Після цього кожне відкрите вікно JeffCrunch використовуватиме ваші клавіші, так само як і кожне вікно, відкрите пізніше. Підказки, меню та наведена нижче таблиця комбінацій показують ваші клавіші.

Клавіші можна призначити й символу. Див. **Вставлення символу** у розділі [Введення тексту в комірки](edit-cells): клацніть **Клавіша швидкого доступу** в полі «Символ». Тоді символ з'явиться в цьому списку, як і будь-яка команда.

**Скинути одну** повертає стандартні клавіші вибраної команди. **Скинути все** повертає стандартні клавіші кожної команди. JeffCrunch зберігає лише ті команди, клавіші яких ви змінили, тож команда, яку ви не змінювали, отримає кращі клавіші, які їй додасть пізніша версія.

Деякі клавіші не можна призначити команді, оскільки їх потребують система або введення тексту. JeffCrunch повідомляє **зарезервовано**, коли ви натискаєте таку клавішу. Зарезервовано такі клавіші: **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z**, **Ctrl+A**, **Tab**, **Shift+Tab**, **Enter**, **Esc**, **Backspace**, **Delete**, **Alt+F4**, клавіші зі стрілками, **Home**, **End**, **Page Up**, **Page Down** і **пробіл**, **F1**, **F6**, **Shift+F6**, **Ctrl+Y**, **Ctrl+Shift+Z**, **Ctrl** зі стрілкою, **Home**, **End**, **Backspace** або **Delete** (з **Shift» або без нього там, де це має сенс у текстовому полі), а також клавіша літери, цифри чи символу, натиснута окремо або з **Shift**. Клавіші, які вже використовує інша частина вікна, теж зарезервовано. **Зберегти**, **Скасувати** і **Повторити** завжди мають принаймні одну клавішу. На Mac **Ctrl** тут означає клавішу **Command**.

## Клавіші доступу

Натисніть **Alt**, щоб побачити літеру на кожній вкладці стрічки та кожній команді, потім натисніть ці літери. Натисніть **Alt**, а потім **Ф**, щоб відкрити екран «Файл». Натисніть **Esc**, щоб повернутися назад.
