# Безпека: до чого може звертатися файл
<!-- keywords: центр довіри, безпека, макроси, пов'язані файли, посилання, пов'язані малюнки, пов'язані медіа, інтернет, завантажено, лише для читання, захищено, зовнішні посилання, програми, безпечно, довіра, параметри безпеки -->

Файл може вказувати на інші об'єкти: файли, веб-сторінки, відео, навіть програми. На вкладці **Безпека** ви вирішуєте, що JeffCrunch робитиме з такими посиланнями. Клацніть **Файл > Параметри**, а потім вкладку **Безпека**. Клацніть **OK**, щоб зберегти зміни, або **Скасувати**, щоб відмовитися від них.

Ці параметри спільні для всіх застосунків JeffOffice: змінивши один у одному застосунку, ви змінюєте його в усіх. Рядок для того, чого застосунок не має, містить напис **Не застосовується** і є неактивним (сірим).

## Макроси

Макроси — це невеликі програми, які зберігаються всередині файлу. JeffCrunch зберігає їх у файлі, тож вони лишаються на місці під час збереження, і він **ніколи не запускає їх**. Немає параметра, який би їх запускав.

## Пов'язані файли й посилання на книги

Ідеться про інші книги, з яких книга отримує числа; такі зв'язки називаються **посиланнями**. Вибір визначає, що JeffCrunch робить, коли відкриває книгу, що їх містить.

- **Запитувати мене** — звичайний вибір. JeffCrunch запитує, чи оновлювати числа з інших книг.
- **Оновлювати їх** оновлює їх без запиту.
- **Ніколи не оновлювати їх** зберігає числа, які файл зберіг раніше.

Вибір, зроблений для однієї книги в меню **Дані > Змінити посилання** (**Запит під час запуску**), має пріоритет для цієї книги. Книга з позначкою «ніколи» завжди лишається без змін. Книга на іншому комп'ютері ніколи не читається під час відкриття файлу, незалежно від вибору. Ви й далі можете в будь-який час скористатися командою **Оновити значення** у вікні **Змінити посилання**.

## Пов'язані відео та звуки

Це не застосовується в JeffCrunch: у ньому немає пов'язаних відео чи звуків для відтворення. Рядок неактивний (сірий).

## Файли з інтернету або з інших комп'ютерів

Файл, який ви завантажили або який розташований на іншому комп'ютері у вашій мережі, може бути небезпечним. Цей параметр визначає, як JeffCrunch його відкриває.

- **Спершу відкривати лише для читання** — звичайний вибір. Файл відкривається для читання, але змінити його не можна. Про це повідомляє смуга під файлом. Клацніть **Увімкнути редагування** на смузі, щоб змінити лише цей файл (до закриття програми). Коли ви згодом збережете його на місці, позначку завантаження з файлу буде знято. Або скористайтеся командою **Зберегти як**, щоб створити копію, чи змініть цей параметр на наступний варіант.
- **Відкривати звичайно** відкриває кожен файл однаково.

Файл, відкритий командами **Відкрити як копію**, **Відкрити та відновити** або **Відкрити лише для читання** на екрані **Файл**, відкривається так незалежно від цього параметра.

## Посилання, які запускають програму

Посилання, яке запускало б програму або сценарій (файл із розширенням .exe, .bat, .sh тощо), **завжди відхиляється**. JeffCrunch повідомляє про це, і нічого не запускається. Посилання на файл на іншому комп'ютері ніколи не відкривається без вашого підтвердження. Жоден параметр цього не змінює.
