# Довідка JeffCrunch
<!-- keywords: зміст, довідка, теми, початок -->

Введіть текст у поле пошуку вгорі, щоб знайти тему або команду для виконання. Натисніть **F1** будь-коли, щоб отримати довідку щодо того, що ви робите: вкладку стрічки або сторінку екрана «Файл», на якій ви перебуваєте.
