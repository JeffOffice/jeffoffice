# Робота з файлами .pub

<!-- keywords: pub, .pub, файл pub, відкрити pub, зберегти pub, перетворення, сумісність, імпорт, старі публікації, інші програми, jpub, формат, відсутні шрифти, резервна копія оригіналу, формат файлу -->

Файл .pub — це публікація, створена іншими програмами для настільної верстки. JeffPub відкриває файли .pub, створені починаючи з 1998 року. Він також може зберегти вашу роботу як файл .pub. Власний формат JeffPub має розширення .jpub.

## Відкриття файлу .pub

1. Натисніть Ctrl+O або клацніть **Файл > Відкрити**.
2. Клацніть **Огляд**, виберіть файл .pub і клацніть **Відкрити**.

Ви також можете перетягнути файл на сторінку. Текст, малюнки, фігури й таблиці переносяться разом із пов'язаними текстовими полями. Більшість сторінок виглядають майже так, як оригінал, але не кожна деталь поки збігається. Деякі текстові поля можуть переносити рядки на одне-два слова раніше або пізніше, ніж раніше.

Якщо шрифту з файлу немає на вашому комп'ютері, JeffPub використовує схожий відкритий шрифт. Шрифти, вбудовані у файл .pub, не імпортуються. Якщо JeffPub має вам щось повідомити після відкриття, у рядку стану внизу вікна з'являється примітка.

Якщо файл не відкривається, JeffPub повідомляє, що він може бути пошкоджений або використовувати можливості, які програма ще не вміє читати. Те саме стосується файлу, який містить текст або фігури, але жодного з них JeffPub не може розмістити на сторінці: такий файл не відкривається як порожні сторінки, тож ви не зможете випадково перезаписати його, і файл залишається без змін.

## Перевірка результату

Відкриття є перетворенням, тому перегляньте кожну сторінку. Перевірте переноси рядків, шрифти й малюнки. Скористайтеся [Перевіркою дизайну](design-checker), щоб знайти текст, який не вміщується.

## Збереження як файл .pub

- Клацніть **Файл > Експорт**, а потім **Зберегти як файл .pub**.
- Або клацніть **Файл > Зберегти як** і для **Тип файлу** виберіть **Файли публікацій .pub (\*.pub)**.

Коли JeffPub зберігає файл .pub, він може записати сторінки, текстові поля та пов'язані текстові поля, форматування тексту, фігури, лінії, малюнки, таблиці, заливки, тіні, художні написи, стилі, буклети, складені листівки, конверти, номери сторінок і посилання. Якщо чогось немає у формі .pub, JeffPub повідомляє, скільки об'єктів він пропустив. Ці об'єкти залишаються у вашій публікації й зберігаються, коли ви зберігаєте файл у форматі .jpub. Коментарі також не мають форми .pub: JeffPub повідомляє, що пропустив їх, і вони зберігаються лише у файлах .jpub. Докладніше про це в розділі Довідки «Коментарі».

## Захист оригіналу

Коли ви відкрили файл .pub і натискаєте Ctrl+S, JeffPub записує зміни назад у той самий файл .pub. Щоб зберегти оригінал:

- Увімкніть **Завжди створювати резервну копію** в **Файл > Параметри** на вкладці **Збереження**. Тоді JeffPub збереже попередній файл під назвою «Backup of» та його ім'ям.
- Або почніть із **Файл > Зберегти як** і збережіть файл .jpub. Файл .jpub зберігає все.

Зберігайте початкові файли, доки не переконаєтеся, що нові правильні.
