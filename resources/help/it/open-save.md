# Aprire e salvare pubblicazioni
<!-- keywords: aprire, salvare, salva con nome, salvare una copia, chiudere, file recenti, aggiunti, tipi di file, jpub, rinominare, backup, proprietà, nuovo nome, copia, CTRL+S -->

JeffPub salva il lavoro in file .jpub. Apre e salva anche file .pub. Vedere [Usare i file .pub](pub-files).

## Salvare

Premere CTRL+S, fare clic sul pulsante **Salva** nella barra di accesso rapido oppure scegliere **File > Salva**. La prima volta JeffPub chiede un nome e una posizione. In seguito, Salva sostituisce il file con la versione più recente del lavoro.

Un asterisco (*) dopo il nome nella barra del titolo indica che ci sono modifiche non salvate. Salvare spesso. Se JeffPub si chiude in modo imprevisto, vedere [Recuperare il lavoro non salvato](recover).

Per conservare l'ultima copia salvata di un file, attivare **Crea sempre una copia di backup**. A ogni salvataggio, JeffPub copia prima il file precedente in un file denominato "Backup di" seguito dal nome, nella stessa cartella. Questa opzione si trova in **File > Opzioni**, nella scheda **Salvataggio**.

## Salvare con un nuovo nome

Scegliere **File > Salva con nome** oppure premere F12. Digitare un nome, scegliere **Salva come** e fare clic su **Salva**. Le opzioni disponibili sono:

- **Pubblicazione JeffPub (*.jpub)** è la scelta standard.
- **File di pubblicazione .pub (*.pub)** crea un file .pub.
- **PDF (*.pdf)** crea un PDF e lascia invariata la pubblicazione.
- **Modello JeffPub (*.jpub)** aggiunge la pubblicazione a **Modelli personali**.

Dopo un salvataggio in formato .jpub o .pub, la barra del titolo mostra il nuovo nome e si continua a lavorare nel nuovo file.

## Aprire

1. Premere CTRL+O oppure scegliere **File > Apri**.
2. Fare clic su **Sfoglia** per scegliere un file. In alternativa, fare clic su un nome in **Aggiunti** o **Pubblicazioni recenti**.

È anche possibile trascinare un file .jpub o .pub sulla pagina. Se la pubblicazione corrente contiene modifiche non salvate, JeffPub chiede prima cosa farne.

Fare clic con il pulsante destro del mouse su un nome nell'elenco e scegliere **Aggiungi all'elenco** (il nome rimane in cima) oppure **Rimuovi dall'elenco**. Un nome in grigio indica che JeffPub non trova più il file. Per cambiare il numero di nomi recenti visualizzati, vedere [Modificare le impostazioni di JeffPub](options).

## Chiudere

Scegliere **File > Chiudi** oppure premere CTRL+F4. JeffPub chiede se salvare le modifiche, quindi mostra una pagina vuota.

## Proprietà e impostazioni di stampa

**File > Proprietà** mostra informazioni sulla pubblicazione: pagine, dimensioni pagina, immagini, parole, autore e date. Fare clic su **Modifica proprietà…** per impostarne titolo, autore, oggetto, parole chiave e commenti. Da questa pagina si possono aprire anche le informazioni aziendali, le **Impostazioni stampa commerciale** (vedere [File PDF e tipografie](pdf)) e la [Verifica struttura](design-checker).

## Se Windows non consente a JeffPub di salvare

Sicurezza di Windows può impedire ai programmi di salvare in cartelle come Documenti. In questo caso JeffPub mostra un messaggio con la procedura per consentirlo. In alternativa, salvare in un'altra cartella.
