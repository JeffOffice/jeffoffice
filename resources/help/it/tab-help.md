# Scheda Guida
<!-- keywords: scheda guida, guida, aiuto, supporto, assistenza, contattare il supporto, commenti e suggerimenti, feedback, novità, note sulla versione, note di rilascio, tasti di scelta rapida, scorciatoie da tastiera, F1, segnalare un problema, suggerire un'idea -->

La scheda **Guida** è sempre presente sulla barra multifunzione, dopo la scheda **Visualizza**. Usarla per ottenere assistenza, segnalare un problema o suggerire un'idea.

- Gruppo **Guida**: quattro pulsanti. Vedere [Benvenuti in JeffPub](start) e [Ottenere assistenza e segnalare problemi](support).

| Pulsante | Funzione | Suggerimento tasti |
|---|---|---|
| **Guida** | Apre il riquadro della Guida a destra. È anche possibile premere F1 o fare clic sul pulsante **?** all'estremità destra della riga delle schede. | ALT, Y, H |
| **Commenti e suggerimenti** | Apre una pagina di GitHub in cui segnalare un problema o suggerire un'idea. È necessario un account GitHub gratuito. | ALT, Y, K |
| **Tasti di scelta rapida** | Apre l'argomento della Guida sull'uso di JeffPub con la tastiera, con l'elenco dei tasti di ogni comando. | ALT, Y, S |
| **Novità** | Apre le note relative alla versione di JeffPub in uso su GitHub, nel browser Web. | ALT, Y, W |
