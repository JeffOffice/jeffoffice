# Lavorare con i file .pub

<!-- keywords: pub, .pub, file pub, apri pub, salva pub, converti, compatibilità, importa, pubblicazioni vecchie, altri programmi, jpub, formato, caratteri mancanti, backup originale, formato file, file di pubblicazione, desktop publishing -->

Un file .pub è una pubblicazione creata con altri programmi di desktop publishing. JeffPub apre i file .pub creati dal 1998. Può anche salvare il tuo lavoro come file .pub. Il formato proprio di JeffPub è .jpub.

## Aprire un file .pub

1. Premi Ctrl+O oppure fai clic su **File > Apri**.
2. Fai clic su **Sfoglia**, scegli il file .pub e fai clic su **Apri**.

Puoi anche trascinare il file nella pagina. Testo, immagini, forme e tabelle vengono importati, insieme alle caselle di testo collegate. La maggior parte delle pagine appare simile all'originale, ma non ogni dettaglio coincide ancora. Alcune caselle di testo possono terminare una parola in più o in meno rispetto a prima.

Se un carattere del file non è installato sul computer, JeffPub usa al suo posto un carattere aperto simile. I caratteri incorporati nel file .pub non vengono importati. Se JeffPub ha qualcosa da segnalarti dopo l'apertura, nella barra di stato in fondo alla finestra compare una nota.

Se il file non si apre, JeffPub indica che potrebbe essere danneggiato o che usa funzioni che non è ancora in grado di leggere. Lo stesso vale per un file che contiene testo o forme ma nessun elemento che JeffPub possa collocare in una pagina: non viene aperto come pagine vuote, così non rischi di sovrascriverlo per errore, e il file resta com'era.

## Verificare il risultato

Aprire un file equivale a una conversione, quindi controlla ogni pagina. Verifica le interruzioni di riga, i caratteri e le immagini. Usa la [Verifica struttura](design-checker) per individuare il testo che non entra nello spazio disponibile.

## Salvare come file .pub

- Fai clic su **File > Esporta**, quindi su **Salva come file .pub**.
- Oppure fai clic su **File > Salva con nome** e scegli **File di pubblicazione .pub (*.pub)** in **Salva come tipo**.

Quando JeffPub salva un file .pub, può scrivere pagine, caselle di testo e caselle di testo collegate, formattazione del testo, forme, linee, immagini, tabelle, riempimenti, ombreggiature, testo artistico, stili, opuscoli, biglietti piegati, buste, numeri di pagina e collegamenti. Se qualcosa non ha una forma equivalente nel formato .pub, JeffPub ti indica quanti oggetti ha escluso. Tali oggetti restano nella pubblicazione e vengono conservati quando salvi come file .jpub. Anche i commenti non hanno una forma equivalente nel formato .pub: JeffPub ti avvisa che li ha esclusi, e vengono conservati solo nei file .jpub. Per saperne di più, consulta l'argomento Commenti di questa Guida.

## Proteggere l'originale

Quando apri un file .pub e premi Ctrl+S, JeffPub scrive le modifiche nello stesso file .pub. Per conservare al sicuro l'originale:

- Attiva **Crea sempre una copia di backup** in **File > Opzioni**, nella scheda **Salvataggio**. JeffPub conserva così il file precedente con il nome "Backup di" seguito dal nome originale.
- Oppure inizia da **File > Salva con nome** e salva un file .jpub. Un file .jpub conserva tutto.

Conserva i file originali finché non sei sicuro che quelli nuovi siano corretti.
