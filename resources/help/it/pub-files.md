# Usare i file .pub
<!-- keywords: pub, .pub, file pub, aprire pub, salvare pub, convertire, conversione, compatibilità, importare, importazione, vecchie pubblicazioni, altri programmi, jpub, formato, tipi di carattere mancanti, font mancanti, backup originale, copia di sicurezza, formato file -->

Un file .pub è una pubblicazione creata con altri programmi di desktop publishing. JeffPub apre i file .pub creati a partire dal 1998 e può anche salvare il lavoro come file .pub. Il formato nativo di JeffPub è .jpub.

## Aprire un file .pub

1. Premere CTRL+O oppure fare clic su **File > Apri**.
2. Fare clic su **Sfoglia**, selezionare il file .pub e fare clic su **Apri**.

È anche possibile trascinare il file sulla pagina. Vengono importati testo, immagini, forme e tabelle, oltre alle caselle di testo collegate. La maggior parte delle pagine risulta molto simile all'originale, ma non tutti i dettagli corrispondono ancora. In alcune caselle di testo, il testo potrebbe terminare una o due parole prima o dopo rispetto all'originale.

Se un tipo di carattere del file non è presente nel computer, JeffPub usa al suo posto un tipo di carattere open simile. I tipi di carattere incorporati nel file .pub non vengono importati. Se dopo l'apertura JeffPub deve comunicare qualcosa, viene visualizzata una nota nella barra di stato nella parte inferiore della finestra.

Se il file non si apre, JeffPub segnala che potrebbe essere danneggiato o che usa funzionalità che il programma non è ancora in grado di leggere.

## Controllare il risultato

L'apertura è una conversione, quindi è consigliabile controllare ogni pagina. Verificare le interruzioni di riga, i tipi di carattere e le immagini. Usare [Verifica struttura](design-checker) per individuare il testo che non rientra nello spazio disponibile.

## Salvare come file .pub

- Fare clic su **File > Esporta**, quindi su **Salva come file .pub**.
- Oppure fare clic su **File > Salva con nome** e scegliere **File di pubblicazione .pub (*.pub)** in **Tipo file**.

Quando salva un file .pub, JeffPub può scrivere pagine, caselle di testo e caselle di testo collegate, formattazione del testo, forme, linee, immagini, tabelle, riempimenti, ombreggiature, testo artistico, stili, opuscoli, biglietti piegati, buste, numeri di pagina e collegamenti. Se un elemento non ha un equivalente nel formato .pub, JeffPub indica quanti oggetti sono stati esclusi. Tali oggetti restano nella pubblicazione e vengono conservati quando si salva come file .jpub.

## Proteggere l'originale

Quando si apre un file .pub e si preme CTRL+S, JeffPub salva le modifiche nello stesso file .pub. Per conservare l'originale:

- Attivare **Crea sempre una copia di backup** in **File > Opzioni**, nella scheda **Salvataggio**. JeffPub conserva così il file precedente con il nome "Backup of" seguito dal nome del file.
- Oppure iniziare con **File > Salva con nome** e salvare un file .jpub. Un file .jpub conserva tutto.

Conservare i file originali finché non si è certi che i nuovi file siano corretti.
