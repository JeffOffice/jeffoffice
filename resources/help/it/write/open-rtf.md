# Apri file RTF
<!-- keywords: rtf, testo ricco, formato testo ricco, apri rtf, .rtf, documenti meno recenti, importa, apri, converti -->

**RTF** (Rich Text Format) è un tipo di file di documento che quasi tutti gli elaboratori di testi sanno leggere e scrivere. JeffWrite apre i file **.rtf** e ne mantiene il testo e l'aspetto.

## Aprire un file RTF

Premi **Ctrl+O**, oppure fai clic su **File > Apri** e poi su **Sfoglia**. Scegli **Rich Text Format (*.rtf)** nell'elenco dei tipi di file per vedere solo questi file, oppure seleziona il file dall'elenco di tutti i documenti. Puoi anche trascinare un file .rtf su una finestra di JeffWrite oppure indicarne il nome quando avvii JeffWrite da una riga di comando.

JeffWrite riconosce un file RTF dal suo contenuto e non dal nome, quindi un file con un'estensione diversa si apre comunque se è davvero un file RTF.

## Cosa viene importato

JeffWrite legge queste parti di un file RTF:

- Testo in qualsiasi lingua, con i suoi tipi di carattere, dimensioni, colori, grassetto, corsivo, sottolineatura, barrato, apice, pedice ed evidenziazione.
- Impostazioni dei paragrafi: allineamento, rientri, spaziatura, tabulazioni, bordi, sfondo e le impostazioni Mantieni con il successivo e Mantieni righe assieme.
- Stili, elenchi numerati ed elenchi puntati.
- Tabelle, incluse le tabelle annidate, con bordi, sfondo, larghezze delle colonne e celle unite.
- Dimensioni della pagina, margini, colonne, orientamento della pagina, sezioni, intestazioni e piè di pagina.
- Note a piè di pagina, note di chiusura, campi dei numeri di pagina, altri campi e segnalibri.
- Revisioni: testo aggiunto, testo eliminato, interruzioni di paragrafo aggiunte o eliminate e modifiche all'aspetto. Una **modifica registrata** è una modifica contrassegnata da un revisore. Vedi [Tieni traccia delle modifiche e accettale o rifiutale](track-changes).
- Immagini in formato PNG, JPEG, EMF e WMF, interruzioni di pagina e interruzioni di colonna.

Se una parte del file non può essere letta, JeffWrite ti indica che cosa ha omesso. Alcuni file RTF contengono elementi che in JeffWrite non possono ancora essere gestiti, come disegni o equazioni. Vengono omessi, ma il testo che li circonda viene mantenuto.

## Salvare le modifiche

Puoi salvare un documento come file .rtf: scegli **Rich Text Format (*.rtf)** in **Salva con nome**, oppure premi **Ctrl+S** su un documento che proviene da un file .rtf. Il file mantiene testo e aspetto, stili, elenchi, tabelle, impostazioni di pagina, intestazioni e piè di pagina, collegamenti e immagini (PNG, JPEG ed EMF). Non mantiene note a piè di pagina, note di chiusura, commenti, revisioni, equazioni, forme o caselle di testo. Quando salvi, JeffWrite ti indica che cosa ha omesso.
