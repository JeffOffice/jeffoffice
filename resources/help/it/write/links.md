## Collegamenti

Un **collegamento** (detto anche collegamento ipertestuale) è un testo che ti porta da un'altra parte quando lo selezioni con Ctrl+clic. Può puntare a un indirizzo web, a un indirizzo di posta elettronica, a un titolo o a un **segnalibro** dello stesso documento, a un file del computer oppure a un nuovo documento che JeffWrite crea per te.

1. Seleziona le parole che diventeranno il collegamento. Oppure non selezionare nulla e digita le parole nella casella **Testo da visualizzare**.
2. Premi **Ctrl+K**, oppure scegli **Inserisci > Collegamento**.
3. In **Collegamento a**, scegli dove deve portare il collegamento:
   - **Indirizzo web:** digita l'indirizzo. Puoi omettere "https://": JeffWrite lo aggiunge.
   - **Indirizzo di posta elettronica:** digita l'indirizzo. "mailto:" viene aggiunto automaticamente.
   - **Posizione nel documento:** scegli un titolo o un segnalibro dall'elenco. A un titolo viene assegnato un segnalibro nascosto tutto suo, così il collegamento continua a funzionare dopo aver salvato il documento e averlo riaperto, in qualsiasi tipo di file. L'elenco mostra i tuoi segnalibri e i titoli. (Per creare un segnalibro, usa **Inserisci > Segnalibro**.)
   - **File esistente:** digita il percorso completo di un file del computer, oppure premi **Sfoglia**.
   - **Nuovo documento:** digita il percorso completo di un nuovo documento vuoto, che termini con .docx o .odt, oppure premi **Sfoglia**. JeffWrite crea il documento in quella posizione e vi collega il testo. Non sovrascrive mai un file già esistente.
4. Se vuoi, digita una **Descrizione comando**. È il breve testo che compare quando il puntatore si ferma sul collegamento.
5. Fai clic su **OK**. Se l'indirizzo non può essere usato da JeffWrite, la finestra resta aperta e indica il motivo.

Le parole assumono l'aspetto del collegamento (blu e sottolineato). Per annullare l'operazione basta un passo.

Per **modificare** un collegamento, posiziona il punto di inserimento al suo interno e premi di nuovo Ctrl+K. **Rimuovi collegamento** in quella finestra, oppure **Inserisci > Rimuovi collegamento**, elimina il collegamento e mantiene le parole.

Usa **Ctrl+clic** su un collegamento per seguirlo. Un collegamento a un segnalibro sposta il punto di inserimento in quel punto. Un collegamento a un indirizzo web o di posta elettronica apre il browser o il programma di posta. Un collegamento a un file chiede conferma e poi apre il file con il programma associato. Per la tua sicurezza, JeffWrite segue solo collegamenti web, di posta elettronica, FTP, telefonici e a file. Un collegamento a un file deve indicare il percorso completo di un file del computer, e il file deve essere un documento o un'immagine (ad esempio .docx, .odt, .pdf, .txt, .xlsx, .pptx, .png o .jpg). Non vengono mai aperti collegamenti a un programma, a uno script, a un file di un altro computer o a un percorso incompleto. JeffWrite non cerca il file prima di chiedere conferma.

## Testo da un file

**Inserisci > Testo da file** inserisce il testo di un altro file nel documento, nel punto in cui si trova il cursore. Può trattarsi di un documento (.docx, .doc, .rtf o .odt) oppure di un file di testo semplice. Un documento conserva i suoi caratteri, stili, immagini e collegamenti. In un file di testo semplice, ogni riga diventa un paragrafo. Un file può avere una dimensione massima di 64 megabyte. Per annullare l'operazione basta un passo.
