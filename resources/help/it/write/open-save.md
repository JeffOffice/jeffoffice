# Aprire, salvare, stampare ed esportare

Fai clic su **File** in alto a sinistra per visualizzare la schermata File. Contiene le pagine Nuovo, Apri, Stampa ed Esporta e i comandi Salva e Salva con nome. Premi **ESC** per tornare al documento.

## Creare un nuovo documento

Premi **CTRL+N** oppure fai clic su **File > Nuovo** e quindi su **Documento vuoto**. Il nuovo documento si apre in una finestra separata. Se la finestra in cui ti trovi è vuota e non è mai stata salvata, il nuovo documento prende il suo posto.

## Aprire un documento

Premi **CTRL+O** oppure fai clic su **File > Apri**. Fai clic su **Sfoglia** per scegliere un file. JeffWrite apre questi tipi di file:

- **.docx** è un documento.
- **.dotx** è un modello. Un modello si apre come nuovo documento basato su di esso, quindi il modello resta invariato.
- Si aprono anche i file **.docm** e **.dotm**. JeffWrite non ne conserva le macro: lo segnala la prima volta che salvi un documento di questo tipo e salva un file .docx.
- **.doc** e **.dot** sono i tipi di documento e modello meno recenti. JeffWrite li legge e salva le modifiche in un nuovo file .docx.
- **.odt**, **.ott** e **.fodt** sono file OpenDocument. JeffWrite li legge tutti e tre. Salva i file .odt e salva le modifiche a un file .ott o .fodt in un nuovo file .odt. Vedi [Aprire e salvare file OpenDocument](open-odt).
- **.rtf** è il formato Rich Text Format. JeffWrite lo legge e salva le modifiche in un nuovo file .docx. Vedi [Aprire file RTF](open-rtf).

La pagina **Apri** elenca anche i documenti aperti o salvati di recente. Fai clic su uno di essi per aprirlo. Fai clic con il pulsante destro del mouse su un documento per aggiungerlo in cima all'elenco o per rimuoverlo dall'elenco.

Se un file contiene parti che JeffWrite non è ancora in grado di modificare, come il layout di una tabella o un'intestazione, le conserva. Vedi [Benvenuti in JeffWrite](start). Se una parte di un file non è leggibile, JeffWrite indica cosa ha omesso. In questo caso non sovrascrive il file: il comando Salva chiede un nuovo nome, in modo che l'originale conservi ciò che nella copia è andato perso.

## Salvare un documento

Premi **CTRL+S** per salvare. La prima volta JeffWrite chiede un nome. **Salva con nome** (F12) salva una copia con un nuovo nome. Scegli **Modello (*.dotx)** per salvare un modello. Un file proveniente da un tipo di file meno recente viene sempre salvato con un nuovo nome, quindi il file originale non viene mai sovrascritto.

## Recuperare il lavoro non salvato

Ogni pochi minuti JeffWrite salva una copia di riserva del lavoro non salvato, in un file in una cartella apposita. Se il programma si chiude in modo imprevisto, propone queste copie al successivo avvio. Per visualizzarle in seguito, fai clic su **File > Apri > Recupera lavoro non salvato**. Puoi scegliere quali aprire e salvare ognuna dove preferisci.

## Stampare

Premi **CTRL+P** oppure fai clic su **File > Stampa**. Scegli la stampante, le copie e le pagine, controlla ogni pagina nell'anteprima e fai clic su **Stampa**. Vedi [Stampare](print).

## Creare un PDF

Fai clic su **File > Esporta > Esporta in PDF**. Scegli un nome. Il PDF ha lo stesso aspetto su qualsiasi computer, perché i tipi di carattere sono incorporati al suo interno.
