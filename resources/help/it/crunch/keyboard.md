# Usare JeffCrunch con la tastiera
<!-- keywords: tastiera, tasti di scelta rapida, scorciatoie, tasti, frecce, tasti di direzione, ctrl, maiusc, home, fine, pagina su, pagina giù, tab, invio, seleziona tutto, copia, F9, F1, zoom, tasti di accesso, suggerimenti tasti -->

Su un Mac, il tasto **Comando** (⌘) svolge la funzione di **CTRL** nelle tabelle seguenti, salvo dove indicato diversamente.

## Spostarsi e selezionare

| Tasti | Funzione |
| --- | --- |
| Tasti di direzione | Spostano la cella attiva di una cella, saltando righe e colonne nascoste |
| MAIUSC+tasto di direzione | Estende la selezione di una cella |
| CTRL+tasto di direzione | Va al bordo dei dati (ESC interrompe una ricerca lunga) |
| CTRL+MAIUSC+tasto di direzione | Estende la selezione fino al bordo dei dati |
| HOME | Va alla prima colonna della riga |
| CTRL+HOME | Va alla prima cella (A1, oppure la prima cella che scorre quando righe o colonne sono bloccate) |
| CTRL+FINE | Va all'ultima cella che contiene qualcosa o ha un formato |
| PAGGIÙ, PAGSU | Sposta in basso o in alto di una schermata |
| TAB, MAIUSC+TAB | Sposta a destra o a sinistra (all'interno delle celle selezionate, se ce ne sono più di una) |
| INVIO, MAIUSC+INVIO | Sposta in basso o in alto (all'interno delle celle selezionate, se ce ne sono più di una) |
| CTRL+BARRA SPAZIATRICE | Seleziona l'intera colonna |
| MAIUSC+BARRA SPAZIATRICE | Seleziona l'intera riga |
| {key:SelectAll} | Seleziona tutto |

## Modificare le celle

| Tasti | Funzione |
| --- | --- |
| Qualsiasi carattere | Inizia un nuovo inserimento nella cella attiva, sostituendone il contenuto |
| F2 | Modifica il contenuto della cella attiva direttamente nella cella |
| INVIO, MAIUSC+INVIO | Conferma l'inserimento e sposta in basso o in alto |
| TAB, MAIUSC+TAB | Conferma l'inserimento e sposta a destra o a sinistra |
| ESC | Annulla l'inserimento |
| ALT+INVIO | Inizia una nuova riga nella cella |
| CANC | Cancella le celle selezionate |
| {key:Undo}, {key:Redo} | Annulla, ripeti |
| {key:Save} | Salva |
| {key:Cut}, {key:Copy}, {key:Paste} | Taglia, copia, incolla (ESC rimuove il bordo delle celle copiate) |
| CTRL+ALT+V | Incolla speciale |
| CTRL e il tasto più, CTRL e il tasto meno | Inserisci, elimina (righe o colonne se sono selezionate per intero) |
| CTRL+D, CTRL+R | Riempi in basso, riempi a destra |
| ALT e il segno di uguale | Somma automatica |
| CTRL+0, CTRL+9 | Nasconde le colonne, nasconde le righe |
| ALT+GIÙ | Apre l'elenco di una cella che ne ha uno |
| {key:Find} | Trova |
| CTRL+H (su un Mac, Opzione+Comando+F) | Trova e sostituisci |
| F5, CTRL+G | Va a una cella, a un intervallo o a un nome |
| CTRL+MAIUSC+L | Attiva o disattiva il filtro |
| MAIUSC+F3 | Scegli una funzione |
| CTRL+F3 | L'elenco dei nomi |
| F9, MAIUSC+F9 | Ricalcola tutto, ricalcola questo foglio |
| TAB, INVIO | Durante la digitazione di una formula: inserisce la funzione o il nome evidenziato nell'elenco |
| ESC | Interrompe una ricerca, un ordinamento o un filtro in corso |

## Tasti di accesso

Premi **ALT** per visualizzare una lettera su ogni scheda e comando della barra multifunzione, quindi premi le lettere. Premi **ALT**, quindi **F**, per la schermata File. Premi **ESC** per tornare indietro.
