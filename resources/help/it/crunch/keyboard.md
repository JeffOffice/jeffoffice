# Usare JeffCrunch con la tastiera
<!-- keywords: tastiera, scorciatoie, tasti, tasti di scelta rapida, freccia, ctrl, maiusc, home, fine, pagina su, pagina giù, tab, invio, seleziona tutto, copia, F9, F1, zoom, tasti di accesso, suggerimenti tasti -->

La scheda **Guida** contiene **Guida** (F1), **Scorciatoie da tastiera**, che apre questa pagina, **Novità** e **Commenti e suggerimenti**, che aprono le rispettive pagine web.

Su Mac, il tasto **Comando** (⌘) fa ciò che fa **Ctrl** nelle tabelle seguenti, salvo dove una tabella indica diversamente.

## Spostarsi e selezionare

| Tasti | Funzione |
| --- | --- |
| Tasti freccia | Sposta la cella attiva di una cella, saltando le righe e le colonne nascoste |
| Maiusc+freccia | Estende la selezione di una cella |
| Ctrl+freccia | Va al bordo dei dati (Esc interrompe una ricerca lunga) |
| Ctrl+Maiusc+freccia | Estende la selezione fino al bordo dei dati |
| Home | Va alla prima colonna della riga |
| Ctrl+Home | Va alla prima cella (A1, oppure alla prima cella che scorre quando righe o colonne sono bloccate) |
| Ctrl+Fine | Va all'ultima cella che contiene qualcosa o ha una formattazione |
| Pagina giù, Pagina su | Sposta verso il basso o verso l'alto di una schermata |
| Tab, Maiusc+Tab | Sposta a destra o a sinistra (tra le celle selezionate, se ce ne sono più di una) |
| Invio, Maiusc+Invio | Sposta verso il basso o verso l'alto (tra le celle selezionate, se ce ne sono più di una) |
| Ctrl+Barra spaziatrice | Seleziona l'intera colonna |
| Maiusc+Barra spaziatrice | Seleziona l'intera riga |
| {key:SelectAll} | Seleziona tutto |

## Modificare le celle

| Tasti | Funzione |
| --- | --- |
| Qualsiasi carattere | Avvia una voce nella cella attiva, al posto di ciò che contiene |
| F2 | Modifica il contenuto della cella attiva, direttamente nella cella; durante la digitazione di una formula, passa dalla selezione delle celle alla modifica del testo |
| F4 | Durante la digitazione di una formula, blocca con $ parti dell'indirizzo sotto il cursore (A1, $A$1, A$1, $A1) |
| Invio, Maiusc+Invio | Conferma la voce e sposta verso il basso o verso l'alto |
| Tab, Maiusc+Tab | Conferma la voce e sposta a destra o a sinistra |
| Esc | Annulla la voce |
| Alt+Invio | Inserisce una nuova riga nella cella |
| Canc | Cancella le celle selezionate |
| {key:Undo}, {key:Redo} | Annulla, ripeti |
| {key:Save} | Salva |
| {key:Cut}, {key:Copy}, {key:Paste} | Taglia, copia, incolla (Esc elimina il bordo delle celle copiate) |
| Ctrl+Alt+V | Incolla speciale |
| Ctrl e il tasto più, Ctrl e il tasto meno | Inserisce ed elimina (righe o colonne, se ne sono selezionate intere) |
| Ctrl+D, Ctrl+R | Riempi verso il basso, riempi verso destra |
| Ctrl+E | Riempimento rapido |
| Alt e il tasto uguale | Somma |
| Ctrl+0, Ctrl+9 | Nasconde le colonne, nasconde le righe |
| Alt+Freccia giù | Apre l'elenco di una cella che ne ha uno |
| {key:Find} | Trova |
| Ctrl+H (su Mac, Opzione+Comando+F) | Trova e sostituisci |
| F5, Ctrl+G | Va a una cella, un intervallo o un nome |
| Ctrl+Maiusc+L | Attiva o disattiva il filtro |
| Maiusc+F3 | Scegli una funzione |
| Ctrl+F3 | Elenco dei nomi |
| F9, Maiusc+F9 | Ricalcola tutto, ricalcola questo foglio |
| Tab, Invio | Mentre si digita una formula: accetta la funzione o il nome evidenziato nell'elenco |
| Esc | Interrompe una ricerca, un ordinamento o un filtro in corso |

## Tasti di accesso

Premi **Alt** per vedere una lettera su ogni scheda e comando della barra multifunzione, quindi premi le lettere. Premi **Alt**, poi **F**, per aprire la schermata File. Premi **Esc** per tornare indietro.
