# Usare JeffCrunch con la tastiera
<!-- keywords: tastiera, scelte rapide, tasti, tasti di scelta rapida, freccia, ctrl, maiusc, home, fine, pagina su, pagina giù, tab, invio, seleziona tutto, copia, F9, F1, zoom, tasti di accesso, suggerimenti tasti, scorciatoie, combinazioni di tasti -->

Su Mac, il tasto **Comando** (⌘) fa ciò che fa **Ctrl** nelle tabelle seguenti, salvo dove una tabella indica diversamente.

## Spostarsi e selezionare

| Tasti | Funzione |
| --- | --- |
| Tasti freccia | Sposta la cella attiva di una cella, saltando righe e colonne nascoste |
| Maiusc+freccia | Estende la selezione di una cella |
| Ctrl+freccia | Va al bordo dei dati (Esc interrompe una ricerca lunga) |
| Ctrl+Maiusc+freccia | Estende la selezione fino al bordo dei dati |
| Home | Va alla prima colonna della riga |
| Ctrl+Home | Va alla prima cella (A1, oppure alla prima cella che scorre quando le righe o le colonne sono bloccate) |
| Ctrl+Fine | Va all'ultima cella che contiene dati o ha una formattazione |
| Pagina giù, Pagina su | Sposta in basso o in alto di una schermata |
| Tab, Maiusc+Tab | Sposta a destra o a sinistra (tra le celle selezionate, se ce ne sono più di una) |
| Invio, Maiusc+Invio | Sposta in basso o in alto (tra le celle selezionate, se ce ne sono più di una) |
| Ctrl+Barra spaziatrice | Seleziona l'intera colonna |
| Maiusc+Barra spaziatrice | Seleziona l'intera riga |
| {key:SelectAll} | Seleziona tutto |

## Modificare le celle

| Tasti | Funzione |
| --- | --- |
| Qualsiasi carattere | Avvia l'immissione nella cella attiva, al posto del suo contenuto |
| F2 | Modifica il contenuto della cella attiva, direttamente nella cella; mentre si digita una formula, passa dalla selezione delle celle alla modifica del testo |
| F4 | Mentre si digita una formula, blocca con $ parti dell'indirizzo nel punto del cursore (A1, $A$1, A$1, $A1) |
| Invio, Maiusc+Invio | Conferma l'immissione e sposta in basso o in alto |
| Tab, Maiusc+Tab | Conferma l'immissione e sposta a destra o a sinistra |
| Esc | Annulla l'immissione |
| Alt+Invio | Inserisce una nuova riga nella cella |
| Canc | Cancella le celle selezionate |
| {key:Undo}, {key:Redo} | Annulla, ripeti |
| {key:Save} | Salva |
| {key:Cut}, {key:Copy}, {key:Paste} | Taglia, copia, incolla (Esc elimina il bordo delle celle copiate) |
| Ctrl+Alt+V | Incolla speciale |
| Ctrl e il tasto più, Ctrl e il tasto meno | Inserisce o elimina (righe o colonne, se sono selezionate intere) |
| Ctrl+D, Ctrl+R | Riempi in basso, riempi a destra |
| Ctrl+E | Riempimento rapido |
| Alt e il segno uguale | Somma |
| Ctrl+0, Ctrl+9 | Nasconde le colonne, nasconde le righe |
| Alt+Freccia giù | Apre l'elenco di una cella che ne ha uno |
| {key:Find} | Trova |
| Ctrl+H (su Mac, Opzione+Comando+F) | Trova e sostituisci |
| F5, Ctrl+G | Va a una cella, a un intervallo o a un nome |
| Ctrl+Maiusc+L | Attiva o disattiva il filtro |
| Maiusc+F3 | Sceglie una funzione |
| Ctrl+F3 | Elenco dei nomi |
| F9, Maiusc+F9 | Ricalcola tutto, ricalcola questo foglio |
| Tab, Invio | Mentre si digita una formula: accetta la funzione o il nome evidenziato nell'elenco |
| Esc | Interrompe una ricerca, un ordinamento o un filtro in corso |

## Tasti di accesso

Premi **Alt** per vedere una lettera su ogni scheda e comando della barra multifunzione, quindi premi le lettere. Premi **Alt**, poi **F**, per aprire la schermata File. Premi **Esc** per tornare indietro.
