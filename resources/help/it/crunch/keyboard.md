# Usare JeffCrunch con la tastiera
<!-- keywords: tastiera, tasti di scelta rapida, scorciatoie, tasti, combinazioni di tasti, frecce, ctrl, maiusc, home, fine, pag su, pag giù, tab, invio, seleziona tutto, copia, F9, F1, zoom, tasti di accesso, suggerimenti tasti -->

Su un Mac, il tasto **Comando** (⌘) svolge la funzione di **Ctrl** nelle tabelle seguenti, salvo dove indicato diversamente.

## Spostarsi e selezionare

| Tasti | Funzione |
| --- | --- |
| Tasti di direzione | Spostano la cella attiva di una cella, ignorando righe e colonne nascoste |
| Maiusc+freccia | Estende la selezione di una cella |
| Ctrl+freccia | Va al bordo dei dati (Esc interrompe una ricerca lunga) |
| Ctrl+Maiusc+freccia | Estende la selezione fino al bordo dei dati |
| Home | Va alla prima colonna della riga |
| Ctrl+Home | Va alla prima cella (A1, oppure la prima cella che scorre quando righe o colonne sono bloccate) |
| Ctrl+Fine | Va all'ultima cella che contiene qualcosa o ha un formato |
| Pag giù, Pag su | Spostano in basso o in alto di una schermata |
| Tab, Maiusc+Tab | Spostano a destra o a sinistra (all'interno delle celle selezionate, se ce ne sono più di una) |
| Invio, Maiusc+Invio | Spostano in basso o in alto (all'interno delle celle selezionate, se ce ne sono più di una) |
| Ctrl+Barra spaziatrice | Seleziona l'intera colonna |
| Maiusc+Barra spaziatrice | Seleziona l'intera riga |
| {key:SelectAll} | Seleziona tutto |

## Modificare le celle

| Tasti | Funzione |
| --- | --- |
| Qualsiasi carattere | Inizia una voce nella cella attiva, sostituendone il contenuto |
| F2 | Modifica il contenuto della cella attiva direttamente nella cella; durante la digitazione di una formula, passa dalla selezione delle celle alla modifica del testo e viceversa |
| F4 | Durante la digitazione di una formula, blocca con $ parti dell'indirizzo in corrispondenza del cursore (A1, $A$1, A$1, $A1) |
| Invio, Maiusc+Invio | Confermano la voce e spostano in basso o in alto |
| Tab, Maiusc+Tab | Confermano la voce e spostano a destra o a sinistra |
| Esc | Annulla la voce |
| Alt+Invio | Inizia una nuova riga nella cella |
| Canc | Cancella le celle selezionate |
| {key:Undo}, {key:Redo} | Annulla, ripeti |
| {key:Save} | Salva |
| {key:Cut}, {key:Copy}, {key:Paste} | Taglia, copia, incolla (Esc rimuove il bordo dalle celle copiate) |
| Ctrl+Alt+V | Incolla speciale |
| Ctrl e il tasto più, Ctrl e il tasto meno | Inserisci, elimina (righe o colonne se sono selezionate per intero) |
| Ctrl+D, Ctrl+R | Riempi in basso, riempi a destra |
| Alt e il segno di uguale | Somma |
| Ctrl+0, Ctrl+9 | Nascondi le colonne, nascondi le righe |
| Alt+Giù | Apre l'elenco di una cella che ne ha uno |
| {key:Find} | Trova |
| Ctrl+H (su un Mac, Opzione+Comando+F) | Trova e sostituisci |
| F5, Ctrl+G | Va a una cella, un intervallo o un nome |
| Ctrl+Maiusc+L | Attiva o disattiva il filtro |
| Maiusc+F3 | Scegli una funzione |
| Ctrl+F3 | Elenco dei nomi |
| F9, Maiusc+F9 | Ricalcola tutto, ricalcola questo foglio |
| Tab, Invio | Durante la digitazione di una formula: inseriscono la funzione o il nome evidenziato nell'elenco |
| Esc | Interrompe una ricerca, un ordinamento o un filtro in corso |

## Tasti di accesso

Premi **Alt** per visualizzare una lettera su ogni scheda e comando della barra multifunzione, quindi premi le lettere. Premi **Alt** e poi **F** per la schermata File. Premi **Esc** per tornare indietro.
