# Scheda Visualizza

<!-- keywords: schermo intero, f11, scheda visualizza, barra multifunzione, schema diapositiva, visualizzazioni master, normale, visualizzazione struttura, sequenza diapositive, pagina note, visualizzazione lettura, righello, griglia, guide, note, zoom, adatta alla finestra, visualizzazioni presentazione, visualizza, vista -->

La scheda **Visualizza** modifica l'aspetto delle diapositive sullo schermo mentre lavori. Queste scelte non modificano le diapositive stesse.

- **Visualizzazioni presentazione** consente di passare tra **Normale**, **Visualizzazione struttura** e **Sequenza diapositive**. Vedi [Visualizzazione struttura, Sequenza diapositive e visualizzazione Schema diapositiva](views).
- **Visualizzazioni master** contiene **Schema diapositiva**, che apre la visualizzazione Schema diapositiva per modificare gli schemi e i layout delle diapositive.
- **Mostra** contiene le caselle di controllo **Righello**, **Griglia** e **Guide** nella diapositiva, oltre al pulsante **Note**, che mostra o nasconde la casella delle note. Vedi [Note del relatore](notes).
- **Zoom** contiene un menu **Zoom**, da 400% a 10%, e **Adatta alla finestra**, che ridimensiona la diapositiva in modo che riempia la finestra. Vedi [Orientarsi nella finestra](window).
- **Finestra** contiene **Schermo intero** (F11), che riempie tutto lo schermo con la finestra; premi **F11** o **Esc** per tornare indietro (**Esc** prima deseleziona un oggetto selezionato o interrompe la digitazione di un testo). Contiene anche **Nuova finestra**, che apre di nuovo il file della presentazione in una seconda finestra (una presentazione senza ancora un file apre una nuova finestra vuota), e **Cambia finestra**, che elenca le finestre aperte così da portarne in primo piano una. Esempio: una modifica fatta in una finestra compare nell'altra dopo averla salvata e aver riaperto il file in quella finestra.
