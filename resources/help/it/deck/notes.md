# Note del relatore
<!-- keywords: note, note del relatore, riquadro note, casella note, note relatore, pagina note, appunti, punti chiave, stampa note, nascondi note, mostra note -->

Le **note del relatore** sono gli appunti che si vogliono tenere a mente durante la presentazione. Il pubblico non le vede mai. Ogni diapositiva ha le proprie note.

## Scrivere le note

La casella delle note si trova sotto la diapositiva. Fare clic sulla casella e digitare. Quando è vuota, mostra **Fare clic per inserire le note**. Le note sono testo normale. Appartengono alla diapositiva corrente, quindi per vedere o scrivere le note di un'altra diapositiva fare clic su di essa.

Il testo digitato diventa un unico passaggio che CTRL+Z può annullare quando si fa una pausa nella digitazione o si fa clic altrove.

Per cambiare l'altezza della casella, trascinare la linea che la separa dalla diapositiva. Per nasconderla e lasciare più spazio alla diapositiva, fare clic su **Visualizza > Mostra > Note** oppure sul pulsante **Note** nella barra di stato. Fare di nuovo clic per visualizzarla.

## Usare le note durante la presentazione

La Visualizzazione Relatore mostra le note della diapositiva sullo schermo, con le dimensioni scelte. Vedere [Avviare la presentazione e usare la Visualizzazione Relatore](show).

## Stampare le note

Per stampare le diapositive con le relative note sotto, scegliere **Pagine note** nella pagina Stampa. Le note possono essere incluse anche in un PDF. Vedere [Stampa, PDF e immagini delle diapositive](printing).

## Le note nelle copie

Una diapositiva duplicata o riutilizzata da un'altra presentazione porta con sé le proprie note. Vedere [Aggiungere, modificare ed eliminare diapositive](slides) e [Riutilizzare diapositive da un'altra presentazione](reuse).

Il comando **Pagina note** nella scheda **Visualizza** serve a lavorare sulle note nel formato di una pagina stampata. Non è ancora disponibile.
