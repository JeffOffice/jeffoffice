# JeffDrive

JeffDrive keeps a folder the same on all of your computers, using any S3-compatible storage. It is part of the JeffOffice family, but it is a separate download with its own repository: <https://github.com/JeffOffice/jeffdrive>. Its design is [docs/design.md](https://github.com/JeffOffice/jeffdrive/blob/main/docs/design.md) there.

What lives in this repository is only the JeffOffice apps' side of it: when JeffDrive is installed, JeffWrite, JeffCrunch, JeffDeck, and JeffPub show a JeffDrive shortcut in Open and Save, a sync mark in the title bar, and "Version History" and "Share Link" in the File menu. None of that is built yet.
